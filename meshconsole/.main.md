Entry point for the MeshAgent executable, handling platform-specific initialization, signal/control handlers, macOS bundle and TCC permission detection, and startup of the agent host container.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `agentHost` | Global | `MeshAgentHostContainer*` singleton used across signal handlers |
| `CtrlHandler` | Function (Win32) | Handles `CTRL_C_EVENT` / `CTRL_BREAK_EVENT` to gracefully stop the agent |
| `BreakSink` | Function (POSIX) | `SIGINT` handler with two-stage shutdown: graceful then forced `exit(1)` |
| `kvm_serviceWriteSink` | Function (macOS + `_LINKVM`) | Writes KVM server output to `STDOUT_FILENO` |
| `discover_service_id_from_plist` | Function (macOS + `_LINKVM`) | Scans `/Library/LaunchAgents` plists to resolve the agent's `serviceId` from its binary path |
| `parse_service_id` | Function (macOS + `_LINKVM`) | Parses `meshagent.{serviceName}.{companyName}-agent` label format into components |
| `get_embedded_version` | Function (macOS) | Reads `CFBundleShortVersionString` from the embedded `__TEXT/__info_plist` Mach-O section |
| `wmain` / `main` | Function | Cross-platform entry point; converts Win32 wide args to UTF-8, installs crash handler (POSIX), handles macOS Finder launch modes, and delegates to `MeshAgent_Start` |

## Usage Example

Build and run the agent directly from the repository:

```bash
# Clone and build
git clone https://github.com/flamingo-stack/meshagent.git
cd meshagent
cmake -B build && cmake --build build

# Run with embedded JavaScript disabled
./meshagent --no-embedded=1

# macOS: launch with CMD key held (double-click from Finder) to show Installation Assistant
# macOS: launch with SHIFT key held to force-show TCC permissions UI
```

macOS Finder launch detection (skipped for install/upgrade flags):

```c
// Checks LAUNCHED_FROM_FINDER env var and modifier key state
CGEventFlags flags = CGEventSourceFlagsState(kCGEventSourceStateCombinedSessionState);
if (flags & kCGEventFlagMaskCommand) {
    show_install_assistant_window(); // CMD + double-click
} else if (flags & kCGEventFlagMaskShift) {
    show_tcc_permissions_window(0); // SHIFT + double-click
}
```
