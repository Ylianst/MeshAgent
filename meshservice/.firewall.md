Windows Firewall configuration module for the MeshAgent, providing COM-based APIs to add and remove firewall rules required for agent communication on Windows platforms.

## Key Components

| Function | Description |
|---|---|
| `SetupWindowsFirewallOld` | Legacy method (XP-era) that registers the agent as an authorized application via `INetFwAuthorizedApplications` |
| `SetupWindowsFirewall` | Modern method that creates four explicit firewall rules (TCP/UDP on ports 16990 and 16991) via `INetFwPolicy2`/`INetFwRules`; falls back to `SetupWindowsFirewallOld` on failure |
| `ClearWindowsFirewall` | Removes all four named agent rules and the authorized-application entry, cleaning up both the modern and legacy firewall registrations |

### Firewall Rules Created

| Rule Name | Protocol | Port | Purpose |
|---|---|---|---|
| `Mesh Agent peer-to-peer (UDP)` | UDP | 16990 | Local P2P traffic |
| `Mesh Agent management (UDP)` | UDP | 16991 | STUN/WebRTC internet traffic |
| `Mesh Agent peer-to-peer (TCP)` | TCP | 16990 | Local P2P traffic |
| `Mesh Agent management (TCP)` | TCP | 16991 | Management traffic |

## Usage Example

```cpp
#include <windows.h>
#include <objbase.h>

// Initialize COM before calling any firewall function
CoInitializeEx(NULL, COINIT_APARTMENTTHREADED);

// Register firewall rules for the agent process
int result = SetupWindowsFirewall(L"C:\\Program Files\\MeshAgent\\meshagent.exe");
if (result == 0) {
    // SetupWindowsFirewall automatically falls back to legacy mode
}

// Remove all firewall rules on uninstall
ClearWindowsFirewall(L"C:\\Program Files\\MeshAgent\\meshagent.exe");

CoUninitialize();
```

> **Note:** All three functions are compiled only on Windows (`WIN32`) excluding MinCore builds (`_MINCORE`). COM must be initialized by the caller prior to invoking these functions. All functions return `1` on success and `0` on failure.
