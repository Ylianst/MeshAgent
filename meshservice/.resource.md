Auto-generated Microsoft Visual C++ resource header for the MeshService Windows application, defining numeric identifiers for dialogs, controls, icons, and bitmaps used in `MeshService.rc`.

## Key Components

| Identifier | Value | Purpose |
|---|---|---|
| `IDD_INSTALLDIALOG` | 103 | Install workflow dialog |
| `IDD_DETAILSDIALOG` | 111 | Agent details dialog |
| `IDB_BITMAP_MC` | 108 | MeshCentral bitmap resource |
| `IDI_MCICON` / `IDI_MAINICON` | 113 | Application icon |
| `IDC_INSTALLBUTTON` | 1002 | Install action button |
| `IDC_UNINSTALLBUTTON` | 1004 | Uninstall action button |
| `IDC_CONNECTBUTTON` | 1009 | Connect action button |
| `IDC_STATUSTEXT` | 1005 | Status label control |
| `IDC_VERSIONTEXT` | 1006 | Agent version display |
| `IDC_AGENTVERSION` | 1013 | Agent version field |
| `IDC_MESH_NAME` | 1015 | Mesh name label |
| `IDC_MESH_IDENTIFIER` | 1016 | Mesh ID field |
| `IDC_SERVER_IDENTIFIER` | 1017 | Server ID field |
| `IDC_SERVER_LOCATION` | 1014 | Server URL field |
| `IDC_AUTOPROXY_CHECK` | 1032 | Auto-proxy checkbox |
| `IDC_TABS` | 1021 | Tab control |
| `IDC_IMAGE` | 1023 | Branding image control |

## Usage Example

```c
#include "resource.h"

// Reference a dialog by its resource ID
HWND hDlg = CreateDialog(
    hInstance,
    MAKEINTRESOURCE(IDD_INSTALLDIALOG),
    hParent,
    InstallDialogProc
);

// Get a control within the dialog
HWND hBtn = GetDlgItem(hDlg, IDC_INSTALLBUTTON);
SetWindowText(hBtn, L"Install Agent");

// Update status text
SetDlgItemText(hDlg, IDC_STATUSTEXT, L"Connecting to server...");
```

> **Note:** Identifiers sharing the same value (e.g., `IDC_BUTTON2`/`IDC_INSTALLBUTTON` = 1002) are aliases generated by Visual Studio's resource editor and refer to the same control.
