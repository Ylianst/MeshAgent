Windows service entry point for the MeshAgent, handling service lifecycle management, UI dialogs, and agent initialization on Windows platforms.

## Key Components

- **`serviceFile` / `serviceName`** — Display strings for the Windows service registration (`"Mesh Agent"` / `"Mesh Agent background service"`)
- **`ServiceMain`** — Windows SCM entry point; registers service control handler, initializes `MeshAgentHostContainer`, and starts the agent loop
- **`ServiceCtrlHandler`** — Handles SCM control codes (`SERVICE_CONTROL_STOP`, `SERVICE_CONTROL_INTERROGATE`, etc.) and updates `serviceStatus`
- **`DialogHandler` / `DialogHandler2`** — `INT_PTR CALLBACK` dialog procedures for the agent's interactive Windows UI
- **`agent`** — Global `MeshAgentHostContainer*` holding the running agent instance
- **`g_serviceArgc` / `g_serviceArgv`** — Preserved command-line arguments passed from `ServiceMain` to the agent core
- **`g_dialogCtx` / `g_dialogLanguage` / `g_dialogTranslationObject`** — Duktape JS context and localization state for the settings/tray dialog
- **`DIALOG_LANG`** — Optional language override string for dialog localization

## Usage Example

The file is not called directly; it is registered with the Windows SCM via `StartServiceCtrlDispatcher`:

```c
// Typical WinMain wiring (elsewhere in the project)
SERVICE_TABLE_ENTRY serviceTable[] = {
    { serviceFile, (LPSERVICE_MAIN_FUNCTION)ServiceMain },
    { NULL, NULL }
};
StartServiceCtrlDispatcher(serviceTable);

// Inside ServiceMain (this file)
serviceStatusHandle = RegisterServiceCtrlHandler(
    serviceFile, ServiceCtrlHandler);
serviceStatus.dwCurrentState = SERVICE_RUNNING;
SetServiceStatus(serviceStatusHandle, &serviceStatus);

// Agent is allocated and started
agent = MeshAgent_Create();
MeshAgent_Start(agent, g_serviceArgc, g_serviceArgv);
```

## Notes

- Windows-only (`WIN32`); uses `WinHTTP`, `WtsApi32`, `ShlObj`, and optionally `WinSock2/1`
- Debug builds link `<crtdbg.h>` with `_CRTDBG_MAP_ALLOC` for heap leak detection
- The embedded `image_b64[]` string is a Base64-encoded PNG used in the tray/dialog UI
- Source: [`ServiceMain.c`](https://github.com/flamingo-stack/meshagent/blob/main/ServiceMain.c)
