TurboJPEG C API header providing interfaces for JPEG compression, decompression, and YUV image transformation in memory, part of the libjpeg-turbo project.

## Key Components

### Enumerations

| Enum | Description |
|------|-------------|
| `TJSAMP` | Chrominance subsampling levels: `TJSAMP_444`, `TJSAMP_422`, `TJSAMP_420`, `TJSAMP_GRAY`, `TJSAMP_440`, `TJSAMP_411` |
| `TJPF` | Pixel formats: RGB, BGR, RGBX, BGRX, XBGR, XRGB, GRAY, RGBA, BGRA, ABGR, ARGB, CMYK |
| `TJCS` | JPEG colorspaces: RGB, YCbCr, GRAY, CMYK, YCCK |

### Constants & Lookup Tables

| Name | Description |
|------|-------------|
| `TJ_NUMSAMP` | Number of subsampling options (6) |
| `TJ_NUMPF` | Number of pixel formats (12) |
| `TJ_NUMCS` | Number of JPEG colorspaces (5) |
| `tjMCUWidth[]` | MCU block width per subsampling level |
| `tjMCUHeight[]` | MCU block height per subsampling level |
| `tjRedOffset[]` | Red channel byte offset per pixel format |
| `tjGreenOffset[]` | Green channel byte offset per pixel format |
| `tjBlueOffset[]` | Blue channel byte offset per pixel format |
| `tjPixelSize[]` | Bytes per pixel for each pixel format |

## Usage Example

```c
#include "turbojpeg.h"
#include <stdio.h>

int main(void) {
    /* Query pixel size for RGB format */
    int rgb_size = tjPixelSize[TJPF_RGB];   /* 3 bytes */
    int rgba_size = tjPixelSize[TJPF_RGBA]; /* 4 bytes */

    /* Get MCU dimensions for 4:2:0 subsampling */
    int mcu_w = tjMCUWidth[TJSAMP_420];   /* 16 pixels */
    int mcu_h = tjMCUHeight[TJSAMP_420];  /* 16 pixels */

    /* Look up red channel offset for BGRX format */
    int red_pos = tjRedOffset[TJPF_BGRX]; /* 2 */

    printf("RGB pixel size: %d, MCU: %dx%d\n", rgb_size, mcu_w, mcu_h);
    return 0;
}
```

## Notes

- YUV image planes follow YCbCr convention; luminance plane width/height are padded to the nearest subsampling factor multiple.
- CMYK pixels can be compressed to YCCK JPEG but RGB↔CMYK conversion requires an external color management system.
- 4:4:0 and 4:1:1 subsampling modes are not fully hardware-accelerated in libjpeg-turbo.
