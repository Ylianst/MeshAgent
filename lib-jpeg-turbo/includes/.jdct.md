Private header defining shared types, macros, and function declarations used by the JPEG forward and inverse DCT (Discrete Cosine Transform) modules in libjpeg-turbo.

## Key Components

### Type Definitions

| Type | Description |
|---|---|
| `DCTELEM` | Forward DCT working element (`int`/`short` for 8-bit, `JLONG` for 12-bit samples) |
| `UDCTELEM` | Unsigned variant of `DCTELEM` for quantization output |
| `UDCTELEM2` | Double-width unsigned type for quantization intermediate values |
| `ISLOW_MULT_TYPE` | Multiplier type for slow (accurate) IDCT (`MULTIPLIER`) |
| `IFAST_MULT_TYPE` | Multiplier type for fast IDCT (`MULTIPLIER` or `JLONG`) |
| `FLOAT_MULT_TYPE` | Multiplier type for floating-point IDCT (`FAST_FLOAT`) |

> **SIMD note:** When `WITH_SIMD` is defined, `DCTELEM` uses `short` (16-bit) instead of `int` to enable parallel SIMD processing.

### Macros

| Macro | Purpose |
|---|---|
| `IDCT_range_limit(cinfo)` | Returns pointer to the output range-limiting table |
| `RANGE_MASK` | Mask for fast range clamping (2 bits wider than legal sample range) |
| `FIX(x)` | Converts a floating-point constant to a fixed-point `JLONG` scaled by `CONST_SCALE` |
| `DESCALE(x, n)` | Rounds and right-shifts a scaled `JLONG` back to normal range |
| `MULTIPLY16C16(var, const)` | Optimized 16×16→32-bit multiply (variable × constant) |
| `MULTIPLY16V16(var1, var2)` | Optimized 16×16→32-bit multiply (variable × variable) |

### Forward DCT Functions

```c
void jpeg_fdct_islow(DCTELEM *data);   // Slow (high accuracy) integer FDCT
void jpeg_fdct_ifast(DCTELEM *data);   // Fast integer FDCT
void jpeg_fdct_float(FAST_FLOAT *data); // Floating-point FDCT
```

### Inverse DCT Functions

Full 8×8 block plus scaled-down variants for partial decoding:

```c
void jpeg_idct_islow(j_decompress_ptr cinfo, jpeg_component_info *compptr,
                     JCOEFPTR coef_block, JSAMPARRAY output_buf,
                     JDIMENSION output_col);  // 8x8 slow/accurate IDCT

// Additional size variants: 1x1, 2x2, 3x3 ... 7x7, 9x9 ... 16x16
void jpeg_idct_4x4(...);
void jpeg_idct_16x16(...);
// etc.
```

## Usage Example

```c
/* Fixed-point arithmetic using macros from jdct.h */
#define CONST_BITS 13

/* Scale a real DCT coefficient constant at compile time */
JLONG scaled = FIX(0.7071067812);  /* ~= 1/sqrt(2), scaled by 2^13 */

/* Multiply two 16-bit values efficiently */
JLONG result = MULTIPLY16C16(input_val, scaled);

/* Descale the result back after accumulation */
DCTELEM output = (DCTELEM) DESCALE(result, CONST_BITS);

/* Clamp output to valid sample range [0..MAXJSAMPLE] */
JSAMPLE *range_table = IDCT_range_limit(cinfo);
JSAMPLE clamped = range_table[output & RANGE_MASK];
```
