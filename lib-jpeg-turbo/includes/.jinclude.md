Central include shim for the libjpeg-turbo library that consolidates system header inclusion and provides portable abstractions for memory and I/O operations.

## Key Components

### Configuration Guard
- Includes `jconfig.h` and sets `JCONFIG_INCLUDED` to prevent duplicate inclusion by `jpeglib.h`

### Conditional System Headers
| Macro | Header Included |
|---|---|
| `HAVE_STDDEF_H` | `<stddef.h>` |
| `HAVE_STDLIB_H` | `<stdlib.h>` |
| `NEED_SYS_TYPES_H` | `<sys/types.h>` |
| `NEED_BSD_STRINGS` | `<strings.h>` |
| *(default)* | `<string.h>` |

`<stdio.h>` is always included unconditionally for `FILE` references in `jpeglib.h`.

### Memory Macros
- **`MEMZERO(target, size)`** — Zeroes a memory region; maps to `bzero()` on BSD or `memset()` on ANSI/SysV systems
- **`MEMCOPY(dest, src, size)`** — Copies a memory region; maps to `bcopy()` on BSD or `memcpy()` on ANSI/SysV systems

### I/O Macros
- **`JFREAD(file, buf, sizeofbuf)`** — Wraps `fread()` with consistent argument order and casting
- **`JFWRITE(file, buf, sizeofbuf)`** — Wraps `fwrite()` with consistent argument order and casting

> ⚠️ `JFREAD`/`JFWRITE` argument order differs from the underlying C standard library functions.

## Usage Example

```c
/* Internal libjpeg-turbo usage only — not for application code */
#include "jinclude.h"

/* Zero out a buffer portably */
MEMZERO(my_buffer, sizeof(my_buffer));

/* Copy data portably */
MEMCOPY(dest_ptr, src_ptr, num_bytes);

/* Read from a FILE stream */
size_t bytes_read = JFREAD(input_file, buf, buf_size);

/* Write to a FILE stream */
size_t bytes_written = JFWRITE(output_file, buf, buf_size);
```

> **Note:** This header is intended for internal libjpeg-turbo use only. Application code should include `jpeglib.h` directly.
