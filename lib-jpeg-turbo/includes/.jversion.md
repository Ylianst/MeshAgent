Defines version identification macros for the libjpeg-turbo JPEG library, selecting the appropriate version string based on the configured `JPEG_LIB_VERSION` at compile time.

## Key Components

| Macro | Description |
|---|---|
| `JVERSION` | Version string selected conditionally based on `JPEG_LIB_VERSION` (supports 6b, 7, and 8d) |
| `JCOPYRIGHT` | Full multi-line copyright notice listing all contributors in project-defined order |
| `JCOPYRIGHT_SHORT` | Condensed single-line copyright string for display in headers or help output |

## Usage Example

```c
#include "jversion.h"

/* Print version and copyright at application startup */
printf("libjpeg-turbo version: %s\n", JVERSION);
printf("%s\n", JCOPYRIGHT_SHORT);

/* Full copyright notice for --version flag */
printf("%s\n", JCOPYRIGHT);
```

**Version selection logic:**

```c
/* Compile-time selection based on JPEG_LIB_VERSION:
 *   >= 80  →  "8d  15-Jan-2012"
 *   >= 70  →  "7  27-Jun-2009"
 *   else   →  "6b  27-Mar-1998"
 */
```

## Notes

- `JVERSION` is resolved entirely at **compile time** via preprocessor conditionals — no runtime overhead.
- `JCOPYRIGHT` lists contributors in a defined order: libjpeg-turbo authors (newest contribution first), then upstream IJG authors.
- Source: [jversion.h](https://github.com/flamingo-stack/meshagent/blob/main/jversion.h)
