Shared header for JPEG Huffman entropy decoding routines, used by both the sequential (`jdhuff.c`) and progressive (`jdphuff.c`) decoder modules in libjpeg-turbo.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `d_derived_tbl` | Derived Huffman table with lookahead cache (`HUFF_LOOKAHEAD = 8` bits), `maxcode`, `valoffset` arrays, and a 256-entry `lookup` table for fast symbol extraction |
| `bit_buf_type` | Platform-adaptive bit buffer — `size_t` (64-bit) on 64-bit targets, `unsigned long` (32-bit) otherwise |
| `bitread_perm_state` | Persistent bit-reader state saved across MCU boundaries (`get_buffer`, `bits_left`) |
| `bitread_working_state` | Working bit-reader state within an MCU, including source pointer and back-link to `j_decompress_ptr` |

### Functions

- **`jpeg_make_d_derived_tbl`** — Expands a raw `JHUFF_TBL` into the optimized `d_derived_tbl` format
- **`jpeg_fill_bit_buffer`** — Refills `get_buffer` from the input stream when insufficient bits remain
- **`jpeg_huff_decode`** — Out-of-line slow-path decoder for codes longer than `HUFF_LOOKAHEAD` bits

### Macros

| Macro | Purpose |
|-------|---------|
| `BITREAD_LOAD_STATE` / `BITREAD_SAVE_STATE` | Transfer state between permanent storage and local registers |
| `CHECK_BIT_BUFFER(state, n, action)` | Ensure at least `n` bits are available; suspend on failure |
| `GET_BITS(n)` / `PEEK_BITS(n)` / `DROP_BITS(n)` | Inline bit extraction primitives |
| `HUFF_DECODE` | Full decode path with lookahead fast path and slow-path fallback |
| `HUFF_DECODE_FAST` | Aggressive inline decode variant; skips suspension checks for speed |

## Usage Example

```c
/* Typical usage inside a Huffman decoder loop */
d_derived_tbl *dctbl;
bitread_working_state br_state;
bit_buf_type get_buffer;
int bits_left, symbol;

BITREAD_LOAD_STATE(cinfo, entropy->bitstate);

HUFF_DECODE(symbol, br_state, dctbl, return FALSE, slow_path);
/* symbol now contains the decoded Huffman value */

BITREAD_SAVE_STATE(cinfo, entropy->bitstate);
```

> **Source:** [`jdhuff.h`](https://github.com/flamingo-stack/meshagent/blob/main/jdhuff.h) — part of the libjpeg-turbo Huffman decoding subsystem. No other modules outside `jdhuff.c` and `jdphuff.c` should include this header.
