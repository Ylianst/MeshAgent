Header file declaring lossless JPEG image transformation utilities and marker-copying support used by `jpegtran`-style applications, built on top of libjpeg-turbo.

## Key Components

### Enumerations

| Type | Values | Purpose |
|------|--------|---------|
| `JXFORM_CODE` | `NONE`, `FLIP_H`, `FLIP_V`, `TRANSPOSE`, `TRANSVERSE`, `ROT_90`, `ROT_180`, `ROT_270` | Specifies the image transform operation |
| `JCROP_CODE` | `UNSET`, `POS`, `NEG`, `FORCE` | Controls crop parameter interpretation (sign and override behavior) |
| `JCOPY_OPTION` | `NONE`, `COMMENTS`, `ALL` | Controls which optional JPEG markers are copied from source to destination |

### `jpeg_transform_info` Struct

Caller-configured parameters for a transform operation. Must not be modified after `jtransform_request_workspace` is called. Key fields:

- **`transform`** — the `JXFORM_CODE` to apply
- **`perfect`**, **`trim`**, **`force_grayscale`**, **`crop`** — boolean option flags
- **`slow_hflip`** — use a non-destructive (slower) horizontal flip to preserve source coefficients
- **`crop_*`** fields — crop region dimensions and offsets with associated `JCROP_CODE` qualifiers
- Internal fields (`workspace_coef_arrays`, `output_width`, etc.) — managed by the library

### Transform Functions (requires `TRANSFORMS_SUPPORTED`)

- **`jtransform_parse_crop_spec`** — parses an X11 geometry-style crop string into `jpeg_transform_info`
- **`jtransform_request_workspace`** — allocates coefficient array workspace
- **`jtransform_adjust_parameters`** — updates destination image parameters to reflect the transform
- **`jtransform_execute_transform`** — performs the actual lossless transform on DCT coefficients
- **`jtransform_perfect_transform`** — checks whether a transform is perfectly lossless given image and MCU dimensions

### Marker Copy Functions

- **`jcopy_markers_setup`** — configures the decompressor to retain selected markers
- **`jcopy_markers_execute`** — copies retained markers to the destination compressor

## Usage Example

```c
jpeg_transform_info info = { 0 };
info.transform       = JXFORM_ROT_90;
info.trim            = TRUE;
info.force_grayscale = FALSE;
info.crop            = FALSE;

/* Optional: parse a crop region */
jtransform_parse_crop_spec(&info, "640x480+10+10");

/* Allocate workspace based on source image */
jtransform_request_workspace(srcinfo, &info);

/* Copy JPEG comments from source to destination */
jcopy_markers_setup(srcinfo, JCOPYOPT_COMMENTS);
jpeg_read_header(srcinfo, TRUE);

/* Adjust destination parameters, then execute */
jvirt_barray_ptr *coefs = jpeg_read_coefficients(srcinfo);
jtransform_adjust_parameters(srcinfo, dstinfo, coefs, &info);
jpeg_write_coefficients(dstinfo, jtransform_adjust_parameters(...));
jtransform_execute_transform(srcinfo, dstinfo, coefs, &info);

jcopy_markers_execute(srcinfo, dstinfo, JCOPYOPT_COMMENTS);
```

> **Note:** Partial iMCU blocks at image edges impose constraints on lossless transforms. Use `trim` to drop untransformable edge blocks, or check `jtransform_perfect_transform` before proceeding when `perfect` mode is required. See [`transupp.c`](https://github.com/flamingo-stack/meshagent/blob/main/transupp.c) for implementation details.
