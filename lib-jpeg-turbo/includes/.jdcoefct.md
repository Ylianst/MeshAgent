Internal JPEG decompression coefficient controller header defining the private buffer controller structure and MCU row initialization logic used during JPEG decode operations.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `my_coef_controller` | `typedef struct` | Private buffer controller extending `jpeg_d_coef_controller` with input tracking state |
| `my_coef_ptr` | `typedef` | Convenience pointer type alias for `my_coef_controller` |
| `start_iMCU_row()` | `LOCAL(void)` | Resets within-iMCU-row counters for each new input row |
| `MCU_buffer` | Field | Array of `D_MAX_BLOCKS_IN_MCU` block row pointers for entropy decoder output |
| `whole_image` | Field (conditional) | Virtual block arrays per component, enabled by `D_MULTISCAN_FILES_SUPPORTED` |
| `coef_bits_latch` | Field (conditional) | Latched coefficient Al values for block smoothing, enabled by `BLOCK_SMOOTHING_SUPPORTED` |
| `SAVED_COEFS` | `#define` | Constant (`6`) indicating how many coefficient bits (`coef_bits[0..5]`) are saved |

**Conditional compilation guards:**
- `BLOCK_SMOOTHING_SUPPORTED` — disabled automatically when `D_PROGRESSIVE_SUPPORTED` is absent
- `D_MULTISCAN_FILES_SUPPORTED` — gates multi-pass virtual array allocation

## Usage Example

```c
/* Typical internal usage during decompression initialization */
my_coef_ptr coef = (my_coef_ptr) cinfo->coef;

/* Initialize row counters before processing a new iMCU row */
start_iMCU_row(cinfo);

/* Access MCU row tracking state */
while (coef->MCU_ctr < expected_mcus) {
    /* entropy decoder writes into MCU_buffer slots */
    decode_mcu(cinfo, coef->MCU_buffer);
    coef->MCU_ctr++;
}
```

> **Note:** This header is internal to the libjpeg-turbo decompression pipeline. It is not part of the public API and should only be included after defining `JPEG_INTERNALS`. See the full source at [`jdcoefct.h`](https://github.com/flamingo-stack/meshagent/blob/main/jdcoefct.h).
