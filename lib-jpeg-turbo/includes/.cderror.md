Defines error and message codes for the `cjpeg`/`djpeg` applications as part of the Independent JPEG Group (IJG) library, extending the core JPEG error system with format-specific codes.

## Key Components

### Dual-Inclusion Mechanism
Uses a macro-based pattern to serve two purposes from a single file:
- **Enum generation** — included without `JMESSAGE` defined, produces a `ADDON_MESSAGE_CODE` enum starting at `JMSG_FIRSTADDONCODE=1000`
- **String table generation** — included again with `JMESSAGE(code, string)` defined (see `jerror.c`), produces a message string table

### Error Code Groups (compile-time gated)

| Guard | Codes | Description |
|---|---|---|
| `BMP_SUPPORTED` | `JERR_BMP_*`, `JTRC_BMP_*` | BMP format errors and trace messages |
| `GIF_SUPPORTED` | `JERR_GIF_*`, `JTRC_GIF_*`, `JWRN_GIF_*` | GIF format errors, warnings, and traces |
| `PPM_SUPPORTED` | `JERR_PPM_*`, `JTRC_PPM/PGM_*` | PPM/PGM format errors and traces |
| `RLE_SUPPORTED` | `JERR_RLE_*`, `JTRC_RLE_*` | RLE format errors and traces |
| `TARGA_SUPPORTED` | `JERR_TGA_*`, `JTRC_TGA_*` | Targa format errors and traces |

### Common Codes (always present)
- `JERR_BAD_CMAP_FILE` — invalid color map file
- `JERR_TOO_MANY_COLORS` — colormap entry limit exceeded
- `JERR_UNKNOWN_FORMAT` — unrecognized input format
- `JERR_UNSUPPORTED_FORMAT` — unsupported output format
- `JERR_UNGETC_FAILED` — stream unget failure
