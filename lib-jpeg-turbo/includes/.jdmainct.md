Header file defining the private buffer controller structure and initialization logic for the JPEG decompressor's main controller, used during the iMCU row output pipeline.

## Key Components

### `my_main_controller` (struct)
Private controller object extending `jpeg_d_main_controller` with:

| Field | Type | Description |
|---|---|---|
| `buffer` | `JSAMPARRAY[MAX_COMPONENTS]` | Allocated row group workspace |
| `buffer_full` | `boolean` | Flags whether an iMCU row has been received |
| `rowgroup_ctr` | `JDIMENSION` | Counts row groups sent to postprocessor |
| `xbuffer[2]` | `JSAMPIMAGE` | Dual pointer lists for context-mode operation |
| `whichptr` | `int` | Active pointer set selector |
| `context_state` | `int` | State machine status |
| `rowgroups_avail` | `JDIMENSION` | Row groups available to postprocessor |
| `iMCU_row_ctr` | `JDIMENSION` | iMCU row counter for image boundary detection |

### Context State Constants

```c
#define CTX_PREPARE_FOR_IMCU    0   /* need to prepare for MCU row */
#define CTX_PROCESS_IMCU        1   /* feeding iMCU to postprocessor */
#define CTX_POSTPONED_ROW       2   /* feeding postponed row group */
```

### `set_wraparound_pointers()` (local function)
Initializes the wraparound pointer entries at the top and bottom of each component's pointer list, transitioning the state from top-of-image to normal processing mode.

## Usage Example

```c
/* Transition pointer lists from top-of-image to normal state */
set_wraparound_pointers(cinfo);

/* Check context state before processing */
my_main_ptr main_ptr = (my_main_ptr) cinfo->main;
if (main_ptr->context_state == CTX_PROCESS_IMCU) {
    /* feed current iMCU row to postprocessor */
}
```

> **Note:** This header is internal to the libjpeg decompression pipeline. It is not part of the public API and should only be included via `jpeglib.h` internals.
