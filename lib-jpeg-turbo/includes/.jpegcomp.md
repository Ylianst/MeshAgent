Provides JPEG library version compatibility macros that abstract structural field name differences between libjpeg versions 6x and 7+.

## Key Components

### Version Branch: `JPEG_LIB_VERSION >= 70`

Maps internal compatibility macros to the **libjpeg v7+ field names**, which introduced separate horizontal/vertical DCT scaling:

| Macro | Resolves To |
|---|---|
| `_DCT_scaled_size` | `DCT_h_scaled_size` |
| `_DCT_h_scaled_size` | `DCT_h_scaled_size` |
| `_DCT_v_scaled_size` | `DCT_v_scaled_size` |
| `_min_DCT_scaled_size` | `min_DCT_h_scaled_size` |
| `_min_DCT_h_scaled_size` | `min_DCT_h_scaled_size` |
| `_min_DCT_v_scaled_size` | `min_DCT_v_scaled_size` |
| `_jpeg_width` | `jpeg_width` |
| `_jpeg_height` | `jpeg_height` |

### Version Branch: `JPEG_LIB_VERSION < 70`

Maps the same macros to the **libjpeg v6x unified field names**, where horizontal and vertical scaling shared a single field:

| Macro | Resolves To |
|---|---|
| `_DCT_scaled_size` | `DCT_scaled_size` |
| `_DCT_h_scaled_size` | `DCT_scaled_size` |
| `_DCT_v_scaled_size` | `DCT_scaled_size` |
| `_min_DCT_scaled_size` | `min_DCT_scaled_size` |
| `_jpeg_width` | `image_width` |
| `_jpeg_height` | `image_height` |

## Usage Example

Internal library code uses the compatibility macros instead of version-specific field names:

```c
#include "jpegcomp.h"

/* Works correctly regardless of libjpeg version (6x or 7+) */
int h_size = compptr->_DCT_h_scaled_size;
int v_size = compptr->_DCT_v_scaled_size;

int width  = cinfo->_jpeg_width;
int height = cinfo->_jpeg_height;
```

> **Note:** This header is considered internal to the JPEG library. Application code should not include it directly.
