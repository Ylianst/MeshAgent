Defines the error and message codes for the libjpeg-turbo JPEG library, along with macros for reporting errors and trace messages within the JPEG compression/decompression pipeline.

## Key Components

### Message Code Enum (`J_MESSAGE_CODE`)
A dual-purpose header that generates either an enum of message codes or a string table depending on how `JMESSAGE` is defined at include time. Code categories:

| Prefix | Purpose |
|--------|---------|
| `JERR_*` | Fatal error codes (e.g., `JERR_FILE_READ`, `JERR_OUT_OF_MEMORY`) |
| `JTRC_*` | Informational trace/debug messages (e.g., `JTRC_SOF`, `JTRC_JFIF`) |
| `JWRN_*` | Non-fatal warnings (e.g., `JWRN_HUFF_BAD_CODE`, `JWRN_JPEG_EOF`) |
| `JMSG_*` | Special entries (version, copyright, fallback message) |

### Error-Reporting Macros
Convenience macros that set `msg_code` and optional integer parameters on the `cinfo->err` structure, then invoke `error_exit`:

- `ERREXIT(cinfo, code)` — fatal error, no parameters
- `ERREXIT1(cinfo, code, p1)` — fatal error with 1 parameter
- `ERREXIT2(cinfo, code, p1, p2)` — fatal error with 2 parameters
- `ERREXIT3(cinfo, code, p1, p2, p3)` — fatal error with 3 parameters
- `ERREXIT4(cinfo, code, p1, p2, p3, p4)` — fatal error with 4 parameters

## Usage Example

```c
#include "jerror.h"

/* Trigger a fatal error with a message code */
if (input_file == NULL)
  ERREXIT(cinfo, JERR_FILE_READ);

/* Trigger a fatal error with parameters */
if (num_components > max_components)
  ERREXIT2(cinfo, JERR_COMPONENT_COUNT, num_components, max_components);

/* Generate message string table (in jerror.c) */
#define JMESSAGE(code, string)  string ,

#include "jerror.h"
  NULL
};
```
