Internal JPEG library header defining the module interface structures and state machine constants for both the compression and decompression pipelines in libjpeg-turbo.

## Key Components

### Buffer Mode Enum
- **`J_BUF_MODE`** — Controls buffer controller operation: `JBUF_PASS_THRU`, `JBUF_SAVE_SOURCE`, `JBUF_CRANK_DEST`, `JBUF_SAVE_AND_PASS`

### Global State Constants
- **`CSTATE_*`** (100–103) — Compression pipeline states (start, scanning, raw, write-coefficients)
- **`DSTATE_*`** (200–210) — Decompression pipeline states (start through stopping)

### Compression Module Structs
| Struct | Role |
|---|---|
| `jpeg_comp_master` | Pass orchestration |
| `jpeg_c_main_controller` | Downsampled-data buffer |
| `jpeg_c_prep_controller` | Pre-processing / input buffer |
| `jpeg_c_coef_controller` | Coefficient buffer |
| `jpeg_color_converter` | Colorspace conversion |
| `jpeg_downsampler` | Spatial downsampling |
| `jpeg_forward_dct` | Forward DCT + quantization |
| `jpeg_entropy_encoder` | Huffman/arithmetic encoding |
| `jpeg_marker_writer` | JFIF/EXIF marker output |

### Decompression Module Structs
| Struct | Role |
|---|---|
| `jpeg_decomp_master` | Output-pass orchestration |
| `jpeg_input_controller` | Bitstream consumption |
| `jpeg_d_main_controller` | Downsampled-data buffer |
| `jpeg_d_coef_controller` | Coefficient buffer + virtual arrays |
| `jpeg_d_post_controller` | Post-processing / color quantization buffer |
| `jpeg_marker_reader` | Marker parsing state |
| `jpeg_entropy_decoder` | Huffman/arithmetic decoding |
| `jpeg_inverse_dct` | Per-component IDCT + dequantization |
| `jpeg_upsampler` | Spatial upsampling |
| `jpeg_color_deconverter` | Colorspace output conversion |
| `jpeg_color_quantizer` | Color quantization / precision reduction |

### Utility Macros
- **`LEFT_SHIFT(a, b)`** — Sanitizer-safe signed left shift via unsigned cast
- **`RIGHT_SHIFT(x, shft)`** — Portable signed right shift (handles `RIGHT_SHIFT_IS_UNSIGNED`)
- **`MAX(a, b)` / `MIN(a, b)`** — Standard min/max helpers
- **`JLONG`** — Typedef for `long`, guaranteed ≥ 32-bit signed

## Usage Example

```c
/* Checking codec state before processing */
#include "jpegint.h"

void check_compress_ready(j_compress_ptr cinfo) {
  if (cinfo->global_state != CSTATE_SCANNING)
    ERREXIT(cinfo, JERR_BAD_STATE);

  /* Invoke the main controller's data processor */
  (*cinfo->main->process_data)(cinfo, input_buf, &row_ctr, rows_avail);
}

/* Safe arithmetic shift */
JLONG value = LEFT_SHIFT(sample - 128, 3);
JLONG rounded = (value + (1 << (SHIFT - 1))) >> SHIFT;
```

> **Note:** This header is intended for internal JPEG library use. Application code should use the public `jpeglib.h` API instead.
