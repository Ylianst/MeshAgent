Utility header providing cross-platform compatibility macros and a high-resolution timer function for the TurboJPEG benchmark and test utilities.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `snprintf` | Macro (Win32) | Remaps to `_snprintf_s` with `_TRUNCATE` on MSVC (excluded for MinGW) |
| `strcasecmp` | Macro (Win32) | Remaps to `stricmp` for case-insensitive string comparison |
| `strncasecmp` | Macro (Win32) | Remaps to `strnicmp` for length-limited case-insensitive comparison |
| `min(a, b)` | Macro | Returns the lesser of two values |
| `max(a, b)` | Macro | Returns the greater of two values |
| `gettime()` | Function (extern) | Returns current wall-clock time as a `double` (seconds) |

## Usage Example

```c
#include "tjutil.h"
#include <stdio.h>

int main(void) {
    double start, elapsed;
    int a = 5, b = 10;

    /* Cross-platform min/max */
    printf("min: %d, max: %d\n", min(a, b), max(a, b));

    /* High-resolution timing */
    start = gettime();
    /* ... perform benchmark operation ... */
    elapsed = gettime() - start;
    printf("Elapsed: %.6f seconds\n", elapsed);

    /* Case-insensitive comparison (works on both POSIX and Win32) */
    if (strcasecmp("JPEG", "jpeg") == 0)
        printf("Strings match (case-insensitive)\n");

    return 0;
}
```

## Notes

- `min`/`max` use include guards to avoid redefinition conflicts with system headers.
- The `snprintf` shim is skipped for MinGW (`__MINGW32__`), which already provides a standards-compliant implementation.
- `gettime()` is declared `extern`; its implementation is platform-specific (typically using `clock_gettime` on POSIX or `QueryPerformanceCounter` on Windows).
