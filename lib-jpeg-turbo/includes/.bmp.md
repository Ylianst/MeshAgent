Header file declaring the BMP image I/O interface used within the libjpeg-turbo toolchain for loading and saving uncompressed bitmap images.

## Key Components

| Function | Description |
|---|---|
| `loadbmp` | Reads a BMP file from disk into a raw pixel buffer |
| `savebmp` | Writes a raw pixel buffer to disk as a BMP file |
| `bmpgeterr` | Returns the last error message string |

**Parameters shared by `loadbmp` / `savebmp`:**
- `filename` — path to the BMP file
- `buf` — pixel data buffer (allocated by `loadbmp`, caller-supplied for `savebmp`)
- `w` / `h` — image width and height in pixels
- `pf` — pixel format constant from `turbojpeg.h` (e.g. `TJPF_RGB`, `TJPF_BGR`)
- `bottomup` — non-zero for bottom-up (Windows BMP default) row order

## Usage Example

```c
#include "bmp.h"

unsigned char *buf = NULL;
int w, h;

/* Load a BMP file in RGB format, top-down row order */
if (loadbmp("input.bmp", &buf, &w, &h, TJPF_RGB, 0) < 0) {
    fprintf(stderr, "Load error: %s\n", bmpgeterr());
    return -1;
}

/* ... process pixel data in buf ... */

/* Save result back to disk */
if (savebmp("output.bmp", buf, w, h, TJPF_RGB, 0) < 0) {
    fprintf(stderr, "Save error: %s\n", bmpgeterr());
}

free(buf);
```

> Both functions return `0` on success and a negative value on failure. Always call `bmpgeterr()` immediately after a failure to retrieve the diagnostic message before any subsequent call overwrites it.
