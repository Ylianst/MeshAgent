Internal JPEG decompression header defining the private upsampler subobject and its supporting types used during the upsampling phase of JPEG decoding.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `upsample1_ptr` | `typedef` | Function pointer type for a per-component upsampling routine |
| `my_upsampler` | `struct` | Private upsampler state extending `jpeg_upsampler` with buffers, method pointers, and expansion factors |
| `my_upsample_ptr` | `typedef` | Convenience pointer type for `my_upsampler` |

### `my_upsampler` Fields

| Field | Type | Purpose |
|---|---|---|
| `pub` | `jpeg_upsampler` | Public base object (must be first) |
| `color_buf` | `JSAMPARRAY[MAX_COMPONENTS]` | Intermediate color-conversion row buffer; full-size components point directly into input data |
| `methods` | `upsample1_ptr[MAX_COMPONENTS]` | Per-component upsampling dispatch table |
| `next_row_out` | `int` | Tracks how many rows have been emitted from `color_buf` |
| `rows_to_go` | `JDIMENSION` | Remaining image rows to process |
| `rowgroup_height` | `int[MAX_COMPONENTS]` | Input row-group height per component |
| `h_expand` / `v_expand` | `UINT8[MAX_COMPONENTS]` | Cached horizontal/vertical pixel expansion factors for `int_expand` |

## Usage Example

```c
/* Cast the generic upsampler pointer to the private type */
my_upsample_ptr upsample = (my_upsample_ptr) cinfo->upsample;

/* Dispatch per-component upsampling */
for (int ci = 0; ci < cinfo->num_components; ci++) {
    (*upsample->methods[ci])(cinfo,
                             &cinfo->comp_info[ci],
                             input_rows[ci],
                             &upsample->color_buf[ci]);
}
```

> **Note:** This header is internal to the JPEG library. It is not part of the public API and should only be included after defining `JPEG_INTERNALS`.
