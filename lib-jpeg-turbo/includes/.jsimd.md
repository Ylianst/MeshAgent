SIMD acceleration interface header for the libjpeg-turbo JPEG library, declaring capability-check and conversion functions for color space conversion, downsampling, upsampling, and Huffman encoding operations.

## Key Components

### Capability Check Functions (`jsimd_can_*`)
Return non-zero if SIMD acceleration is available for the given operation on the current platform.

| Function | Purpose |
|---|---|
| `jsimd_can_rgb_ycc` | RGB → YCbCr color conversion |
| `jsimd_can_rgb_gray` | RGB → grayscale conversion |
| `jsimd_can_ycc_rgb` | YCbCr → RGB color conversion |
| `jsimd_can_ycc_rgb565` | YCbCr → RGB565 color conversion |
| `jsimd_can_h2v2_downsample` | 2×2 downsampling |
| `jsimd_can_h2v1_downsample` | 2×1 downsampling |
| `jsimd_can_h2v2_smooth_downsample` | Smooth 2×2 downsampling |
| `jsimd_can_huff_encode_one_block` | Huffman block encoding |

### Color Conversion Functions
- `jsimd_rgb_ycc_convert` — RGB to YCbCr (compression path)
- `jsimd_rgb_gray_convert` — RGB to grayscale (compression path)
- `jsimd_ycc_rgb_convert` — YCbCr to RGB (decompression path)
- `jsimd_ycc_rgb565_convert` — YCbCr to RGB565 (decompression path)
- `jsimd_c_null_convert` — Pass-through no-op conversion

### Downsampling Functions
- `jsimd_h2v2_downsample` / `jsimd_h2v1_downsample` — 2:1 horizontal/vertical downsampling
- `jsimd_h2v2_smooth_downsample` — Smooth 2×2 downsampling with filtering

### Upsampling Functions
- `jsimd_h2v2_upsample` / `jsimd_h2v1_upsample` — Basic upsampling
- `jsimd_h2v2_fancy_upsample` / `jsimd_h2v1_fancy_upsample` — Interpolated upsampling
- `jsimd_h2v2_merged_upsample` / `jsimd_h2v1_merged_upsample` — Combined upsample + color convert
- `jsimd_int_upsample` — Integer ratio upsampling

### Huffman Encoding
- `jsimd_huff_encode_one_block` — SIMD-accelerated Huffman encoding of a single DCT block

## Usage Example

```c
/* Check for SIMD support before using accelerated path */
if (jsimd_can_rgb_ycc()) {
    jsimd_rgb_ycc_convert(cinfo, input_buf, output_buf, output_row, num_rows);
} else {
    /* Fall back to non-SIMD implementation */
    jpeg_rgb_ycc_convert(cinfo, input_buf, output_buf, output_row, num_rows);
}

/* Accelerated Huffman encoding */
if (jsimd_can_huff_encode_one_block()) {
    buffer = jsimd_huff_encode_one_block(
        state, buffer, block, last_dc_val, dctbl, actbl
    );
}
```
