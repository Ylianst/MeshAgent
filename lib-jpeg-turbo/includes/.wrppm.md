Header defining the private PPM destination structure used during JPEG-to-PPM image decompression output.

## Key Components

- **`ppm_dest_struct`** — Private destination object extending `djpeg_dest_struct` with PPM-specific I/O fields:
  - `iobuffer` — Raw byte buffer passed to `fwrite`
  - `pixrow` — Decompressor output row buffer (typically aliased to `iobuffer`)
  - `buffer_width` — Size of the I/O buffer in bytes
  - `samples_per_row` — Number of `JSAMPLE` values per output row
- **`ppm_dest_ptr`** — Convenience typedef for `ppm_dest_struct *`

## Usage Example

```c
#ifdef PPM_SUPPORTED

ppm_dest_ptr dest = (ppm_dest_ptr) malloc(sizeof(ppm_dest_struct));

/* Allocate I/O buffer for one row of pixel data */
dest->samples_per_row = cinfo->output_width * cinfo->output_components;
dest->buffer_width    = dest->samples_per_row * sizeof(JSAMPLE);
dest->iobuffer        = (char *) malloc(dest->buffer_width);

/* Point decompressor row buffer at the same memory */
dest->pixrow = (JSAMPROW) dest->iobuffer;

#endif
```

## Notes

- The entire struct is conditionally compiled under `PPM_SUPPORTED`, so this header has no effect unless PPM output is enabled in the build.
- `iobuffer` and `pixrow` typically point to the same allocation, allowing the decompressor to write directly into the `fwrite` buffer and avoid an extra copy.
- Part of the [Independent JPEG Group](https://github.com/flamingo-stack/meshagent) libjpeg integration within the meshagent codebase.
