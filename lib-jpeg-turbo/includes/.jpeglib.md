The primary application interface header for the libjpeg-turbo JPEG codec library, defining all public data structures, constants, enumerations, and compression/decompression object fields used by client applications.

## Key Components

### Constants
| Macro | Value | Purpose |
|---|---|---|
| `DCTSIZE` | 8 | DCT block dimension (8×8) |
| `DCTSIZE2` | 64 | Total DCT block elements |
| `NUM_QUANT_TBLS` | 4 | Max quantization tables |
| `NUM_HUFF_TBLS` | 4 | Max Huffman tables |
| `C_MAX_BLOCKS_IN_MCU` | 10 | Compressor MCU block limit |
| `D_MAX_BLOCKS_IN_MCU` | 10 | Decompressor MCU block limit |

### Image Buffer Types
- **`JSAMPROW`** — pointer to one row of pixel samples
- **`JSAMPARRAY`** — 2-D sample array (multiple rows)
- **`JSAMPIMAGE`** — 3-D sample array (color-indexed)
- **`JBLOCKROW` / `JBLOCKARRAY` / `JBLOCKIMAGE`** — equivalent types for DCT coefficient blocks

### Core Structs
- **`JQUANT_TBL`** — DCT quantization table (natural order, 64 `UINT16` values)
- **`JHUFF_TBL`** — Huffman coding table (bits + symbol arrays)
- **`jpeg_component_info`** — per-channel metadata (sampling factors, DCT dimensions, MCU geometry)
- **`jpeg_scan_info`** — progressive scan script entry (component indices, spectral selection)
- **`jpeg_marker_struct`** — saved APPn/COM marker linked list node

### Enumerations
- **`J_COLOR_SPACE`** — color space selector including `JCS_GRAYSCALE`, `JCS_RGB`, `JCS_YCbCr`, `JCS_CMYK`, and libjpeg-turbo extensions (`JCS_EXT_*`, `JCS_RGB565`)
- **`J_DCT_METHOD`** — `JDCT_ISLOW`, `JDCT_IFAST`, `JDCT_FLOAT`
- **`J_DITHER_MODE`** — `JDITHER_NONE`, `JDITHER_ORDERED`, `JDITHER_FS`

### Common Object Macro
`jpeg_common_fields` injects shared fields (`err`, `mem`, `progress`, `client_data`, `is_decompressor`) into both compression and decompression master structs.

## Usage Example

```c
#include "jpeglib.h"
#include <stdio.h>

/* Decompress a JPEG file to raw RGB */
void decompress_jpeg(const char *filename) {
    struct jpeg_decompress_struct cinfo;
    struct jpeg_error_mgr jerr;

    FILE *fp = fopen(filename, "rb");

    cinfo.err = jpeg_std_error(&jerr);
    jpeg_create_decompress(&cinfo);
    jpeg_stdio_src(&cinfo, fp);
    jpeg_read_header(&cinfo, TRUE);

    /* Select color space and DCT method */
    cinfo.out_color_space = JCS_EXT_RGBA;
    cinfo.dct_method      = JDCT_ISLOW;

    jpeg_start_decompress(&cinfo);

    JSAMPARRAY buffer = (*cinfo.mem->alloc_sarray)(
        (j_common_ptr)&cinfo, JPOOL_IMAGE,
        cinfo.output_width * cinfo.output_components, 1);

    while (cinfo.output_scanline < cinfo.output_height) {
        jpeg_read_scanlines(&cinfo, buffer, 1);
        /* process buffer[0] here */
    }

    jpeg_finish_decompress(&cinfo);
    jpeg_destroy_decompress(&cinfo);
    fclose(fp);
}
```

> **Source:** [`jpeglib.h`](https://github.com/flamingo-stack/meshagent/blob/main/jpeglib.h) — Part of the libjpeg-turbo library bundled with MeshAgent. Most applications only need this header plus optionally `jerror.h` for error code details.
