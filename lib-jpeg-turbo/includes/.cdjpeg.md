Shared header for the `cjpeg` and `djpeg` sample applications, defining the plugin interfaces and utility declarations used by image format I/O modules. Not used by the core JPEG library itself.

## Key Components

### Structs

| Struct | Purpose |
|---|---|
| `cjpeg_source_struct` | Virtual function table for **compression** input modules (read image formats → JPEG) |
| `djpeg_dest_struct` | Virtual function table for **decompression** output modules (JPEG → write image formats) |
| `cdjpeg_progress_mgr` | Extended `jpeg_progress_mgr` that tracks extra format-conversion passes in the progress monitor |

### I/O Module Initializers

Format readers (`cjpeg_source_ptr`) and writers (`djpeg_dest_ptr`) for BMP, GIF, PPM, RLE, and Targa:

```c
cjpeg_source_ptr jinit_read_bmp(j_compress_ptr cinfo);
djpeg_dest_ptr   jinit_write_bmp(j_decompress_ptr cinfo, boolean is_os2);
cjpeg_source_ptr jinit_read_ppm(j_compress_ptr cinfo);
djpeg_dest_ptr   jinit_write_ppm(j_decompress_ptr cinfo);
// ...and equivalents for GIF, RLE, Targa
```

### Support Routines

- **`rdswitch.c`** utilities: `read_quant_tables`, `read_scan_script`, `set_quality_ratings`, `set_quant_slots`, `set_sample_factors`
- **`rdcolmap.c`**: `read_color_map`
- **`cdjpeg.c`** common helpers: `enable_signal_catcher`, `start_progress_monitor`, `end_progress_monitor`, `keymatch`, `read_stdin`, `write_stdout`

### Macros

- `READ_BINARY` / `WRITE_BINARY` — portable `fopen()` mode strings (handles `DONT_USE_B_MODE`)
- `EXIT_FAILURE` / `EXIT_SUCCESS` / `EXIT_WARNING` — standard exit codes with fallback definitions

## Usage Example

```c
/* Typical cjpeg format module registration */
cjpeg_source_ptr src = jinit_read_ppm(&cinfo);
src->input_file = fopen("input.ppm", READ_BINARY);

/* Start the progress monitor with extra passes */
struct cdjpeg_progress_mgr progress;
progress.total_extra_passes = 1;
start_progress_monitor((j_common_ptr)&cinfo, &progress);
```
