SIMD-accelerated DCT function declarations for the libjpeg JPEG codec, covering forward transform, inverse transform, sample conversion, and quantization operations.

## Key Components

### Capability Probes (`jsimd_can_*`)
Returns non-zero if the current CPU supports the SIMD implementation for that operation. Always call before invoking the corresponding function.

| Function | Purpose |
|---|---|
| `jsimd_can_convsamp` / `jsimd_can_convsamp_float` | Integer / float sample conversion |
| `jsimd_can_fdct_islow` / `ifast` / `float` | Forward DCT variants |
| `jsimd_can_quantize` / `jsimd_can_quantize_float` | Quantization |
| `jsimd_can_idct_2x2` … `12x12` | Scaled inverse DCT sizes |
| `jsimd_can_idct_islow` / `ifast` / `float` | Full-size inverse DCT variants |

### Forward Path (Encode)
- **`jsimd_convsamp`** / **`jsimd_convsamp_float`** — converts a block of `JSAMPARRAY` pixels into DCT workspace coefficients
- **`jsimd_fdct_islow`** / **`jsimd_fdct_ifast`** / **`jsimd_fdct_float`** — applies the forward DCT (slow-integer, fast-integer, or floating-point)
- **`jsimd_quantize`** / **`jsimd_quantize_float`** — quantizes the DCT coefficients into the output coefficient block

### Inverse Path (Decode)
- **`jsimd_idct_2x2`**, **`4x4`**, **`6x6`**, **`12x12`** — partial inverse DCTs for scaled-down decoding
- **`jsimd_idct_islow`** / **`jsimd_idct_ifast`** / **`jsimd_idct_float`** — full 8×8 inverse DCT variants

## Usage Example

```c
/* Encoding: forward DCT + quantize */
if (jsimd_can_convsamp()) {
    jsimd_convsamp(sample_data, start_col, workspace);
} else {
    jpeg_convsamp_fallback(sample_data, start_col, workspace);
}

if (jsimd_can_fdct_islow()) {
    jsimd_fdct_islow(workspace);
}

if (jsimd_can_quantize()) {
    jsimd_quantize(coef_block, divisors, workspace);
}

/* Decoding: scaled inverse DCT (e.g., quarter-size) */
if (jsimd_can_idct_4x4()) {
    jsimd_idct_4x4(cinfo, compptr, coef_block, output_buf, output_col);
}
```
