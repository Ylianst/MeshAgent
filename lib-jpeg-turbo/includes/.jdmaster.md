Brief description of the file's purpose: Defines the private master control structure for the JPEG decompressor, extending the public `jpeg_decomp_master` interface with internal state tracking for multi-pass decompression and color quantization.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `my_decomp_master` | `typedef struct` | Private decompressor master state, embedding the public `jpeg_decomp_master` as its first member |
| `pub` | `struct jpeg_decomp_master` | Public fields inherited/exposed to the JPEG library framework |
| `pass_number` | `int` | Tracks how many decompression passes have been completed |
| `using_merged_upsample` | `boolean` | Flag indicating whether the merged upsample/color-convert path is active |
| `quantizer_1pass` | `struct jpeg_color_quantizer *` | Saved reference to the single-pass color quantizer module |
| `quantizer_2pass` | `struct jpeg_color_quantizer *` | Saved reference to the two-pass color quantizer module |
| `my_master_ptr` | `typedef` | Convenience pointer type alias for `my_decomp_master *` |

## Usage Example

```c
/* Accessing the private master state from a decompress object */
my_master_ptr master = (my_master_ptr) cinfo->master;

/* Check which upsample path is active */
if (master->using_merged_upsample) {
    /* merged upsample + color convert path */
} else {
    /* separate upsample and color convert path */
}

/* Switch quantizer based on pass number */
if (master->pass_number == 0) {
    cinfo->cquantize = master->quantizer_1pass;
} else {
    cinfo->cquantize = master->quantizer_2pass;
}
```

> **Note:** The `pub` member must remain first in the struct. The JPEG library casts `cinfo->master` (a `jpeg_decomp_master *`) directly to `my_master_ptr`, relying on C struct layout guarantees to safely access private fields.
