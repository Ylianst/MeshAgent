Declares shared types and function prototypes for Huffman entropy encoding used by both the sequential (`jchuff.c`) and progressive (`jcphuff.c`) JPEG encoders in libjpeg-turbo.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `MAX_COEF_BITS` | Macro | Maximum DCT coefficient magnitude bits — `10` for 8-bit samples, `14` for 12-bit samples |
| `c_derived_tbl` | Struct | Derived Huffman table holding per-symbol codes (`ehufco[256]`) and code lengths (`ehufsi[256]`); a length of `0` means no code is assigned |
| `jpeg_make_c_derived_tbl` | Function | Expands a raw `JHUFF_TBL` definition into the `c_derived_tbl` derived format for encoder use |
| `jpeg_gen_optimal_table` | Function | Generates an optimal Huffman table definition from a symbol frequency histogram |

## Usage Example

```c
#include "jchuff.h"

/* Build a derived DC Huffman table for table slot 0 */
c_derived_tbl *dc_tbl = NULL;
jpeg_make_c_derived_tbl(cinfo, TRUE, 0, &dc_tbl);

/* Encode a symbol using the derived table */
int symbol = 3;
unsigned int code   = dc_tbl->ehufco[symbol];
char         length = dc_tbl->ehufsi[symbol];
/* length == 0 means the symbol has no assigned code */

/* Regenerate the table from collected frequency data */
long freq[257] = { 0 };
/* ... accumulate symbol counts into freq[] ... */
jpeg_gen_optimal_table(cinfo, htbl, freq);
```

## Notes

- DCT coefficients are bounded to `[-1024, +1023]` (8-bit) or `[-16384, +16383]` (12-bit), so magnitude fits within `MAX_COEF_BITS`.
- This header is **internal** — only `jchuff.c` and `jcphuff.c` should include it.
