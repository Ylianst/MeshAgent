Interface header defining the boundary between platform-independent and platform-specific portions of the libjpeg-turbo memory manager. Only `jmemmgr.c` and system-dependent memory manager implementations need to include this file.

## Key Components

### Memory Allocation Functions

| Function | Description |
|---|---|
| `jpeg_get_small` | Allocates small memory chunks (behaves like `malloc`; returns `NULL` on failure) |
| `jpeg_free_small` | Releases small memory chunks (behaves like `free`) |
| `jpeg_get_large` | Allocates large memory chunks (up to `MAX_ALLOC_CHUNK`) |
| `jpeg_free_large` | Releases large memory chunks |
| `jpeg_mem_available` | Reports free memory available before backing store is required |

### Lifecycle Functions

| Function | Description |
|---|---|
| `jpeg_mem_init` | System-dependent initialization; returns default `max_memory_to_use` |
| `jpeg_mem_term` | System-dependent cleanup after all memory is freed |
| `jpeg_open_backing_store` | Opens a backing-store object and wires up its read/write/close function pointers |

### Constants & Macros

- **`MAX_ALLOC_CHUNK`** — Maximum bytes per single allocation call (default `1000000000L`; overridable in `jconfig.h`)
- **`TEMP_NAME_LENGTH`** — Maximum length of a temporary backing-store filename (`64`)

### `backing_store_info` Struct

Holds state for a single backing-store (temp file or memory block). Contains three function pointers (`read_backing_store`, `write_backing_store`, `close_backing_store`) plus platform-specific fields selected at compile time:

- **Default:** `FILE *temp_file` + `char temp_name[]`
- **`USE_MSDOS_MEMMGR`:** `handle_union` covering DOS file handles, XMS, and EMS handles
- **`USE_MAC_MEMMGR`:** `short temp_file`, `FSSpec`, and `char temp_name[]`

## Usage Example

```c
/* Implementing a custom system-dependent memory manager */

EXTERN(void *)
jpeg_get_small(j_common_ptr cinfo, size_t sizeofobject)
{
    return malloc(sizeofobject);  /* simplest possible implementation */
}

EXTERN(void)
jpeg_free_small(j_common_ptr cinfo, void *object, size_t sizeofobject)
{
    free(object);
}

EXTERN(size_t)
jpeg_mem_available(j_common_ptr cinfo, size_t min_bytes_needed,
                   size_t max_bytes_needed, size_t already_allocated)
{
    /* Return 95% of remaining budget to guard against overestimation */
    size_t budget = cinfo->mem->max_memory_to_use - already_allocated;
    return (budget > 0) ? (budget - budget / 20) : 0;
}
```
