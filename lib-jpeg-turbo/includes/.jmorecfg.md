Supplementary JPEG configuration header defining platform-specific type aliases, capability feature flags, and internal compiler/linkage macros for the libjpeg-turbo library.

## Key Components

### Type Definitions

| Type | Description |
|------|-------------|
| `JSAMPLE` | Single pixel sample value (8-bit or 12-bit depending on `BITS_IN_JSAMPLE`) |
| `JCOEF` | DCT frequency coefficient (`short`) |
| `JOCTET` | Compressed datastream byte (exactly 8 bits) |
| `JDIMENSION` | Image dimension (`unsigned int`, max 64K per JPEG spec) |
| `UINT8`, `UINT16`, `INT16`, `INT32` | Portable integer types with platform fallbacks |
| `boolean` | Integer-backed boolean (if `HAVE_BOOLEAN` is not defined) |

### Key Macros

| Macro | Purpose |
|-------|---------|
| `MAX_COMPONENTS` | Maximum color channels per image (default: 10) |
| `GETJSAMPLE(v)` / `GETJOCTET(v)` | Safe value extraction with sign/mask handling |
| `MAXJSAMPLE` / `CENTERJSAMPLE` | Sample range bounds (255/128 for 8-bit; 4095/2048 for 12-bit) |
| `JPEG_MAX_DIMENSION` | Maximum image dimension (65500) |
| `METHODDEF`, `LOCAL`, `GLOBAL`, `EXTERN` | Function linkage qualifiers |
| `JMETHOD(type, name, args)` | Function pointer declaration helper |

### Internal Capability Flags (`JPEG_INTERNALS`)

- **DCT algorithms:** `DCT_ISLOW_SUPPORTED`, `DCT_IFAST_SUPPORTED`, `DCT_FLOAT_SUPPORTED`
- **Encoder features:** `C_PROGRESSIVE_SUPPORTED`, `ENTROPY_OPT_SUPPORTED`, `INPUT_SMOOTHING_SUPPORTED`
- **Decoder features:** `D_PROGRESSIVE_SUPPORTED`, `IDCT_SCALING_SUPPORTED`, `QUANT_1PASS_SUPPORTED`, `QUANT_2PASS_SUPPORTED`

## Usage Example

```c
#include "jpeglib.h"

/* Access a pixel sample safely across signed/unsigned char platforms */
JSAMPLE pixel = some_buffer[i];
int value = GETJSAMPLE(pixel);  /* Always yields 0..MAXJSAMPLE */

/* Declare an image dimension */
JDIMENSION width = 1920;
JDIMENSION height = 1080;

/* Use boolean type */
boolean done = FALSE;
```

> Most developers do not need to modify this file. Platform-specific type sizes and capability flags are resolved automatically via `configure` or CMake during the libjpeg-turbo build.
