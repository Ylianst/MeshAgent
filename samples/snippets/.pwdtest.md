A demonstration script showing how to securely read password input from stdin in a MeshAgent JavaScript environment, with echo disabled and per-keypress canonical mode for masked input display.

## Key Components

- **`console.echo = false`** — Disables local terminal echo so typed characters are not displayed
- **`console.canonical = false`** — Switches stdin to raw/non-canonical mode, processing each keypress individually rather than line-by-line
- **`process.stdin` data handler** — Captures keypresses and implements password masking logic:
  - Backspace (`127`/`8`): Clears and redraws the `*` mask line
  - Carriage Return (`10`/`13`): Prints the captured password and exits
  - All other keys: Appends to buffer and prints `*`
- **`process.on('exit')`** — Restores `console.echo` and `console.canonical` to defaults, preventing the terminal from remaining in raw mode after the process exits

## Usage Example

```bash
# Run directly via MeshAgent's JavaScript runtime
meshcmd RunScript --script pwdtest.js
```

```javascript
// Core pattern reusable in other scripts
console.echo = false;
console.canonical = false;

process.stdin.chars = '';
process.stdin.on('data', function (c) {
    if (c[0] === 13) {
        // process captured password: this.chars
        process.exit();
    } else {
        this.chars += c.toString();
        process.stdout.write('*');
    }
});

process.on('exit', function () {
    console.echo = true;
    console.canonical = true;
});
```

> **Note:** The `process.on('exit')` cleanup is critical on POSIX systems. Omitting it leaves the terminal in raw/no-echo mode after the script exits, which can make the shell appear unresponsive.
