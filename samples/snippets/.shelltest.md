Cross-platform demonstration of spawning a child process and capturing its `stdout` output synchronously using MeshAgent's `child_process` module.

## Key Components

- **`child_process.execFile`** — Spawns a platform-appropriate directory listing command:
  - **Windows**: `cmd.exe /C dir`
  - **POSIX**: `/bin/ls -la`
- **`child.stdout.on('data', ...)`** — Accumulates stdout chunks into a string buffer
- **`child.waitExit()`** — Synchronously blocks until the child process completes
- **`console.log`** — Prints the captured output to the console

## Usage Example

```javascript
// Spawn a child process and capture its output
var child = require('child_process').execFile('/bin/ls', ['ls', '-la']);

// Buffer stdout chunks
child.stdout.str = '';
child.stdout.on('data', function (c) { this.str += c.toString(); });

// Wait for process to finish, then print
child.waitExit();
console.log(child.stdout.str);
process.exit();
```

## Notes

- `waitExit()` is a **MeshAgent-specific** synchronous method; it is not available in standard Node.js.
- The pattern of initializing `.str = ''` on the stream object is a lightweight alternative to collecting chunks in a separate array.
- Useful as a starting point for scripting automation tasks that shell out to OS utilities.
