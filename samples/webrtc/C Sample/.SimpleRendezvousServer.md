Lightweight HTTP/WebSocket rendezvous server interface providing GET, POST, and WebSocket upgrade handling with optional TLS and HTTP Basic Auth support.

## Key Components

### Enumerations

| Type | Values | Description |
|---|---|---|
| `SimpleRendezvousServer_WebSocket_DataTypes` | `BINARY`, `TEXT` | WebSocket frame data type |
| `SimpleRendezvousServer_DoneFlag` | `NotDone`, `Done`, `Partial`, `LastPartial` | Message completion state |
| `SimpleRendezvousServer_FragmentFlags` | `Incomplete`, `Complete` | WebSocket fragmentation state |

### Opaque Handles

- **`SimpleRendezvousServer`** — server instance handle
- **`SimpleRendezvousServerToken`** — per-connection token

### Callbacks

- **`SimpleRendezvousServer_OnGET`** — fires on HTTP GET; receives path and local receiver address
- **`SimpleRendezvousServer_OnPOST`** — fires on HTTP POST; receives path, body data, and length
- **`SimpleRendezvousServer_OnWebSocket`** — fires on WebSocket frame; receives buffer, type, and done flag
- **`SimpleRendezvousServer_OnWebSocketClose`** — fires when a WebSocket connection closes

### Core Functions

- **`SimpleRendezvousServer_Create`** — creates a server bound to a local port on the given async chain
- **`SimpleRendezvousServer_Respond`** — sends an HTTP response (success/failure + HTML body)
- **`SimpleRendezvousServer_UpgradeWebSocket`** — upgrades a connection to WebSocket with optional reassembly buffer
- **`SimpleRendezvousServer_WebSocket_Send`** — sends a WebSocket frame with fragmentation and memory ownership control
- **`SimpleRendezvousServer_WebSocket_Close`** — closes a WebSocket connection
- **`SimpleRendezvousServer_SetSSL`** *(optional, `!MICROSTACK_NOTLS`)* — attaches an `SSL_CTX` for TLS

### Auth Helpers

- **`SimpleRendezvousServer_IsAuthenticated`** — checks Basic Auth against a realm
- **`SimpleRendezvousServer_GetUsername`** — retrieves the authenticated username
- **`SimpleRendezvousServer_ValidatePassword`** — validates the supplied password

## Usage Example

```c
void onGET(SimpleRendezvousServer s, SimpleRendezvousServerToken token,
           char *path, char *localAddr) {
    char *body = "<html>OK</html>";
    SimpleRendezvousServer_Respond(s, token, 200, body, strlen(body),
                                   ILibAsyncSocket_MemoryOwnership_USER);
}

void onPOST(SimpleRendezvousServer s, SimpleRendezvousServerToken token,
            char *path, char *data, int dataLen) {
    // handle posted data
}

// Create server on port 8080
SimpleRendezvousServer srv = SimpleRendezvousServer_Create(
    chain, 8080, onGET, onPOST
);

// Upgrade an existing token to WebSocket
SimpleRendezvousServer_UpgradeWebSocket(token, 65536, wsHandler, wsCloseHandler);

// Send a binary WebSocket frame
SimpleRendezvousServer_WebSocket_Send(
    token,
    SimpleRendezvousServer_WebSocket_DataType_BINARY,
    buf, bufLen,
    ILibAsyncSocket_MemoryOwnership_STATIC,
    SimpleRendezvousServer_FragmentFlag_Complete
);
```
