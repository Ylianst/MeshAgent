A sample application demonstrating WebRTC data channel communication using Intel's MicroStack library, with a built-in HTTP/WebSocket rendezvous server for SDP offer/answer exchange between a native C client and a browser.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `mConnectionFactory` | Global | WebRTC connection factory instance |
| `mConnection` | Global | Active WebRTC peer connection |
| `mDataChannel` | Global | Active WebRTC data channel pointer |
| `stunServerList[]` | Global | Array of 9 public STUN server hostnames |
| `OnDataChannelData` | Callback | Handles incoming string data on a data channel |
| `OnDataChannelClosed` | Callback | Fires when a data channel is closed by the peer |
| `OnDataChannelAck` | Callback | Fires when the remote peer ACKs a locally created data channel |
| `WebRTCConnectionSink` | Callback | Handles connect/disconnect events; creates `MyDataChannel` on connect |
| `WebRTCDataChannelSink` | Callback | Handles data channels initiated by the remote peer |
| `CandidateSink` | Callback | Sends STUN-discovered candidates (active/answerer role) via HTTP or WebSocket |
| `PassiveCandidateSink` | Callback | Sends STUN-discovered candidates (passive/offerer role) embedded in HTML |
| `Rendezvous_OnGet` | Handler | Serves HTML pages and WebSocket upgrades for `/active`, `/passive`, `/websocket`, `/websocketInit` |
| `Rendezvous_OnPost` | Handler | Receives browser SDP offers via HTTP POST and generates answers |
| `OnWebSocket` | Handler | Handles SDP exchange over a WebSocket connection |

## Usage Example

```bash
# Run without STUN (local network only)
./WebRTC_MicroStackSample

# Run with STUN (public ICE candidate gathering)
./WebRTC_MicroStackSample STUN
```

```c
/* Connection flow triggered when browser POSTs an SDP offer */
mConnection = ILibWrapper_WebRTC_ConnectionFactory_CreateConnection(
    mConnectionFactory,
    &WebRTCConnectionSink,
    &WebRTCDataChannelSink,
    &WebRTCConnectionSendOkSink
);
ILibWrapper_WebRTC_Connection_SetStunServers(mConnection, stunServerList, 9);

/* Generate answer SDP and send back to browser */
char *answer = ILibWrapper_WebRTC_Connection_SetOffer(
    mConnection, data, dataLen, NULL /* or &CandidateSink if STUN enabled */
);
SimpleRendezvousServer_Respond(sender, token, 1, answer,
    strlen(answer), ILibAsyncSocket_MemoryOwnership_CHAIN);
```

Browser endpoints:
- `GET /active` — browser creates the SDP offer; server answers
- `GET /passive` — server generates the SDP offer; browser answers
- `GET /websocketInit` — upgrades to WebSocket for SDP exchange
