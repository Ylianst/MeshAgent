The main Windows Forms UI controller for the WebRTC sample application, managing the rendezvous server, WebRTC session lifecycle, named pipe communication, and STUN server configuration.

## Key Components

| Member | Description |
|---|---|
| `MainForm(string[] args)` | Constructor that initializes the HTTP rendezvous server, WebRTC logger, and optionally connects via named pipe if a pipe name argument is provided |
| `mServer` | `SimpleRendezvousServer` instance handling HTTP GET/POST for WebRTC signaling |
| `userForms` | Dictionary mapping URL paths to active `SessionForm` instances |
| `OnGet` / `OnPost` | HTTP request handlers routing `/start`, `/passive`, and session-specific paths |
| `GetNewPOC` | Creates an active WebRTC session form and returns an HTML offer page |
| `GetNewPassivePOC` | Creates a passive WebRTC session form, awaiting an SDP offer before responding |
| `StartClient` / `StartRead` | Named pipe client/server async read-write for inter-process WebRTC signaling |
| `browserButton_Click` | Launches a second process connected via named pipe for local peer-to-peer testing |
| `RendezvousData` | Inner class holding synchronization handles and data buffers for signaling exchange |
| `stunSettingsButton_Click` | Opens STUN server configuration dialog and applies settings to new sessions |

## Usage Example

```csharp
// Launch with no args: acts as rendezvous server + UI host
Application.Run(new MainForm(new string[] { }));

// Launch with a pipe name arg: connects as pipe client, generates an SDP offer,
// and sends it to the server process
Application.Run(new MainForm(new string[] { "bbtest" }));

// Internally, the rendezvous server handles browser connections:
// GET /start      → returns active WebRTC HTML page with embedded offer URL
// GET /passive    → returns passive HTML page with Base64-encoded SDP
// POST /{session} → forwards browser SDP answer to the matching SessionForm
```

> **Note:** The constructor auto-launches the WebRTC default logger in a browser tab and uses `WebRTCConnection.ChainAlwaysRunning = true` to keep the ICE/DTLS chain alive across sessions.
