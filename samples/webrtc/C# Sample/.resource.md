## Usage Example

This file is auto-managed by the Visual Studio resource editor and is not intended for manual modification. It is conditionally compiled only when invoked by AppStudio (`APSTUDIO_INVOKED`):

```c
#ifdef APSTUDIO_INVOKED
#ifndef APSTUDIO_READONLY_SYMBOLS
#define _APS_NEXT_RESOURCE_VALUE  101
#define _APS_NEXT_COMMAND_VALUE   40001
#define _APS_NEXT_CONTROL_VALUE   1001
#define _APS_NEXT_SYMED_VALUE     101
#endif
#endif
```
