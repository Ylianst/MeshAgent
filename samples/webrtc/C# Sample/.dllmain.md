Defines the DLL entry point for the meshagent Windows dynamic-link library. This is a standard boilerplate `DllMain` implementation that handles process and thread lifecycle events.

## Key Components

- **`DllMain`** — The mandatory Win32 entry point called by the Windows loader whenever the DLL is attached to or detached from a process or thread. Accepts the standard parameters:
  - `hModule` — Handle to the DLL module
  - `ul_reason_for_call` — Reason code for the call (attach/detach)
  - `lpReserved` — Reserved pointer (static vs. dynamic load context)

## Lifecycle Events Handled

| Event | Description |
|---|---|
| `DLL_PROCESS_ATTACH` | DLL loaded into a process |
| `DLL_THREAD_ATTACH` | New thread created in the process |
| `DLL_THREAD_DETACH` | Thread exits cleanly |
| `DLL_PROCESS_DETACH` | DLL unloaded from the process |

All four cases are currently no-ops (fall through to `break`), returning `TRUE` to indicate successful initialization.

## Usage Example

```cpp
// No direct invocation needed — Windows calls DllMain automatically.
// To load this DLL dynamically at runtime:
HMODULE hDll = LoadLibrary(TEXT("meshagent.dll"));
if (hDll != NULL) {
    // Resolve exported functions via GetProcAddress
    FreeLibrary(hDll);
}
```

> **Note:** Custom initialization logic (e.g., resource allocation, thread-local storage) can be added inside the relevant `case` blocks if needed in future development. See the full source at [`dllmain.cpp`](https://github.com/flamingo-stack/meshagent/blob/main/dllmain.cpp).
