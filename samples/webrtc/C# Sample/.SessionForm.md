A Windows Forms dialog that manages a single WebRTC peer-to-peer session, handling connection lifecycle, data channel creation, and real-time text messaging between peers.

## Key Components

| Member | Description |
|---|---|
| `SessionForm()` | Constructor; initializes `WebRTCConnection` and wires up connection events |
| `isConnected` | Read-only property indicating active connection state |
| `Value` | Random integer used as a unique session identifier |
| `Connection` | Exposes the underlying `WebRTCConnection` instance |
| `SetStunServers()` | Configures STUN servers (optionally shuffled) on the connection |
| `GetOffer()` | Generates a WebRTC SDP offer asynchronously via `CustomAwaiter<string>` |
| `GetOfferResponse()` | Accepts an SDP offer and returns an HTTP/1.1 200 response containing the SDP answer |
| `mConnection_OnConnected` | Creates a local data channel (`MyDataChannel`) once the peer connects |
| `mConnection_OnDataChannel` | Handles a remotely-initiated data channel |
| `mData_OnStringReceiveData` | Appends incoming messages to the message log |
| `sendButton_Click` | Sends text or handles special commands (`*CLOSE*`, `*PAUSE*`, `*RESUME*`) |

## Usage Example

```csharp
// Create and display a session form
SessionForm session = new SessionForm();
session.SetStunServers(false, "stun:stun.example.com:3478");
session.Show();

// Generate an SDP offer to send to the remote peer
```

> **Special send commands:** typing `*CLOSE*`, `*PAUSE*`, or `*RESUME*` in the input box controls the data channel/connection directly rather than sending a chat message.
