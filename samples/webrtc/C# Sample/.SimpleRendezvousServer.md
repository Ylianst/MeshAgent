A lightweight HTTP rendezvous server used in WebRTC signaling samples. It listens on a random local TCP port, parses minimal HTTP GET and POST requests, and dispatches them to async delegate handlers for WebRTC offer/answer exchange.

## Key Components

| Member | Type | Description |
|---|---|---|
| `SimpleRendezvousServer()` | Constructor | Binds a `TcpListener` to any available port and begins accepting connections |
| `Port` | Property | Returns the dynamically assigned local TCP port |
| `OnGet` | `GetHandler` delegate | Async callback invoked for HTTP GET requests; receives sender, remote endpoint, and path |
| `OnPost` | `PostHandler` delegate | Async callback invoked for HTTP POST requests; receives sender, path, and request body |
| `ReadWrapper` | Private class | Holds per-connection state: `TcpClient`, stream, read buffer, offset, and byte count |
| `OnAccept` | Private method | Accepts incoming TCP connections and initiates async buffer reads |
| `OnRead` | Private async method | Accumulates bytes, detects HTTP header boundaries, and routes to `ProcessGet` or `ProcessPost` |
| `ProcessGet` / `ProcessPost` | Private async methods | Extract the URL path and body, then invoke the appropriate delegate |

## Usage Example

```csharp
var server = new SimpleRendezvousServer();
Console.WriteLine($"Listening on port: {server.Port}");

// Handle GET requests (e.g., serve a static page)
server.OnGet = async (sender, from, path) =>
{
    byte[] html = Encoding.UTF8.GetBytes("HTTP/1.1 200 OK\r\n\r\n<html>Hello</html>");
    return html;
};

// Handle POST requests (e.g., WebRTC offer/answer signaling)
server.OnPost = async (sender, path, body) =>
{
    // Process SDP offer from body, return answer
    byte[] answer = Encoding.UTF8.GetBytes("HTTP/1.1 200 OK\r\n\r\n" + body);
    return answer;
};
```

> **Note:** This server is intentionally minimal — it uses a fixed 32 KB read buffer and does not support chunked transfer encoding, keep-alive, or concurrent request pipelining. It is intended for local signaling in WebRTC samples only, not production use.
