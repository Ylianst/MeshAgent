Entry point for the `WebRTC_Sample` Windows Forms application. Bootstraps the UI thread and launches the main application window.

## Key Components

- **`Program` (static class)** — Application host class containing the WinForms startup sequence.
- **`Main(string[] args)`** — STAThread entry point that enables visual styles, configures text rendering, and starts the `MainForm` message loop with any command-line arguments passed through.

## Usage Example

```csharp
// Launched automatically by the .NET runtime.
// Command-line args are forwarded to MainForm for configuration:
// e.g., WebRTC_Sample.exe --server wss://signaling.example.com

[STAThread]
static void Main(string[] args)
{
    Application.EnableVisualStyles();
    Application.SetCompatibleTextRenderingDefault(false);
    Application.Run(new MainForm(args)); // args passed to MainForm
}
```

> **Note:** The `[STAThread]` attribute is required for COM interop compatibility in WinForms applications, particularly for clipboard and drag-and-drop operations.
