Precompiled header file for Windows-based C/C++ projects that aggregates frequently used, infrequently changed system includes to improve compilation speed.

## Key Components

| Element | Purpose |
|---|---|
| `#pragma once` | Prevents multiple inclusion of this header |
| `targetver.h` | Sets the minimum supported Windows version |
| `WIN32_LEAN_AND_MEAN` | Strips rarely-used APIs from `windows.h` to reduce compile overhead |
| `windows.h` | Core Windows API header |

## Usage Example

```c
// stdafx.cpp — required to generate the precompiled header binary
#include "stdafx.h"

// In any other .cpp file, include stdafx.h first
#include "stdafx.h"
#include <stdio.h>

int main() {
    MessageBox(NULL, L"Hello", L"MeshAgent", MB_OK);
    return 0;
}
```

## Notes

- Adding heavy but stable headers here (e.g., `<vector>`, `<string>`, STL containers) speeds up incremental builds significantly.
- `WIN32_LEAN_AND_MEAN` excludes subsystems such as Cryptography, DDE, RPC, and Shell — add specific headers manually if those APIs are needed.
- The `// TODO` comment marks the intended extension point for project-specific includes.
