A Windows Forms debug utility for visualizing real-time WebRTC connection diagnostics, including congestion control, retransmission, and data throughput metrics.

## Key Components

| Member | Description |
|---|---|
| `DebugForm(WebRTCConnection)` | Constructor accepting a `WebRTCConnection` to monitor |
| `DebugForm_Load` | Creates a debug `WebRTCDataChannel` and wires up all diagnostic event handlers |
| `StartSendingJunk()` | Continuously sends 4KB random-byte payloads to stress-test the connection and measure send throughput |
| `mConnection_DebugEvents_OnFastRecovery` | Tracks entry/exit of SCTP fast recovery mode |
| `mConnection_DebugEvents_OnSendRetry` | Calculates and displays normal packet retransmission rate (KB/s) |
| `mConnection_DebugEvents_OnSendFastRetry` | Calculates and displays fast retransmission rate (KB/s) |
| `mConnection_DebugEvents_OnT3RTX` | Monitors T3-RTX timer state (enabled, disabled, expired) |
| `mConnection_DebugEvents_OnCongestionWindowSizeChanged` | Displays current SCTP congestion window size in bytes |

## Usage Example

```csharp
// Open the debug view for an active WebRTC connection
WebRTCConnection connection = /* your established connection */;

var debugForm = new DebugForm(connection);
debugForm.Show();

// On load, the form automatically:
// 1. Creates a "DebugChannel" data channel
// 2. Subscribes to congestion/retransmission events
// 3. Begins flooding the channel with random data to measure throughput
```

> **Note:** This form is intended for development/diagnostic use only. It actively floods the data channel with random traffic via `StartSendingJunk()` to exercise the underlying SCTP transport and surface congestion control behavior in real time.
