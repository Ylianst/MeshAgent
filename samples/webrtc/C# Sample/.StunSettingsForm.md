A Windows Forms dialog for configuring STUN server settings used in WebRTC peer connection setup.

## Key Components

- **`StunSettingsForm`** — Partial `Form` class providing a modal dialog to enable/disable and configure STUN servers
- **`StunServersInUse`** (`bool`) — Property that gets/sets the enabled state of STUN server usage via a checkbox
- **`StunServers`** (`string[]`) — Property that gets/sets the list of STUN server URLs, stored as newline-delimited text in a multiline textbox
- **`okButton_Click`** — Sets `DialogResult.OK` and closes the dialog
- **`cancelButton_Click`** — Sets `DialogResult.Cancel` and closes the dialog
- **`stunCheckBox_CheckedChanged`** — Enables or disables the STUN server text input based on the checkbox state

## Usage Example

```csharp
using (var form = new StunSettingsForm())
{
    // Pre-populate with existing settings
    form.StunServersInUse = true;
    form.StunServers = new[] {
        "stun:stun.l.google.com:19302",
        "stun:stun1.l.google.com:19302"
    };

    if (form.ShowDialog() == DialogResult.OK && form.StunServersInUse)
    {
        string[] selectedServers = form.StunServers;
        // Apply servers to WebRTC ICE configuration
    }
}
```

The dialog binds UI state directly through properties — toggling the checkbox enables/disables the text input, and the `StunServers` property handles newline splitting/joining automatically.
