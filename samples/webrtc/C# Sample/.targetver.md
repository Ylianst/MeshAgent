Defines the target Windows platform version for the MeshAgent build by including the Windows SDK version header.

## Key Components

- **`SDKDDKVer.h` include** — Sets the highest available Windows platform as the compilation target, enabling access to the latest Windows API surface.

## Usage Example

To target a specific Windows version instead of the latest, modify before the `SDKDDKVer.h` include:

```c
#include <WinSDKVer.h>
#define _WIN32_WINNT 0x0601  // Target Windows 7
#include <SDKDDKVer.h>
```

## Notes

- This header is Windows-specific and is included automatically by the MSVC build system.
- Modifying `_WIN32_WINNT` here limits available APIs to the specified platform, useful for maintaining broader OS compatibility.
- See the full file at [`targetver.h`](https://github.com/flamingo-stack/meshagent/blob/main/targetver.h).
