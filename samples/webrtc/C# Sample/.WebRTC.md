Windows DLL export/import header for the MicrostackWrapper WebRTC integration layer, defining the API boundary for the `CMicrostackWrapper` class.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MICROSTACKWRAPPER_API` | Macro | Controls `__declspec(dllexport)` vs `__declspec(dllimport)` based on build context |
| `CMicrostackWrapper` | Class | Exported wrapper class serving as the primary interface for WebRTC/Microstack integration |
| `nMicrostackWrapper` | `int` | Exported global integer variable |
| `fnMicrostackWrapper` | Function | Exported utility function returning `int` |

## Usage Example

**Consuming the DLL in an external project:**

```c
// Include header without MICROSTACKWRAPPER_EXPORTS defined
// so symbols are imported, not exported
#include "WebRTC.h"

int main(void) {
    CMicrostackWrapper wrapper;   // Imports from MicrostackWrapper.dll
    int result = fnMicrostackWrapper();
    return result;
}
```

**Building the DLL itself:**

```bash
# MICROSTACKWRAPPER_EXPORTS must be defined when compiling the DLL
cl /D MICROSTACKWRAPPER_EXPORTS /LD WebRTC.cpp /Fe:MicrostackWrapper.dll
```

## Notes

- The `MICROSTACKWRAPPER_EXPORTS` symbol is defined **only** during DLL compilation; consumer projects must **not** define it.
- `CMicrostackWrapper` is a scaffold class — the constructor is implemented but method bodies are pending (`TODO` placeholder).
- This file is Windows-specific (`__declspec`) and will require `#pragma` guards or platform abstractions for cross-platform builds.
