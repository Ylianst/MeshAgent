Declares the public interface for the Duktape CommonJS module system, providing the initialization function and related constants for module resolution.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `DUK_MODULE_DUKTAPE_H_INCLUDED` | Guard macro | Prevents multiple inclusion of the header |
| `DUK_COMMONJS_MODULE_ID_LIMIT` | Constant (`256`) | Maximum byte length for a resolved CommonJS module identifier, accounting for the current module ID, the requested (possibly relative) module ID, and a separating slash |
| `duk_module_duktape_init` | Function declaration | Registers the CommonJS module loader into a Duktape heap context |

## Usage Example

```c
#include "duktape.h"
#include "duk_module_duktape.h"

int main(void) {
    duk_context *ctx = duk_create_heap_default();

    /* Install CommonJS require() support into the context */
    duk_module_duktape_init(ctx);

    /* Now ctx supports require('my_module') up to
     * DUK_COMMONJS_MODULE_ID_LIMIT (256) bytes in resolved path length */
    duk_eval_string(ctx, "var m = require('mylib'); m.hello();");

    duk_destroy_heap(ctx);
    return 0;
}
```

> **Note:** `duk_module_duktape_init` must be called once per `duk_context` before any `require()` calls. Module identifier paths (current + requested + `/`) must not exceed `DUK_COMMONJS_MODULE_ID_LIMIT` bytes or resolution will fail.
