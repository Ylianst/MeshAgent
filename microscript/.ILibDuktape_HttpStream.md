Duktape-based HTTP stream implementation for the MeshAgent JavaScript runtime, providing HTTP client requests, server responses, WebSocket handling, and related stream abstractions over the microstack networking layer.

## Key Components

### Structs

| Struct | Purpose |
|---|---|
| `ILibDuktape_HttpStream_Data` | Core HTTP stream state: duplex stream, body stream, buffer, WCDO pointer, connection metadata |
| `ILibDuktape_Http_ClientRequest_WriteData` | Tracks outbound client request buffer, headers, content-length, and retry state |
| `ILibDuktape_HttpStream_ServerResponse_State` | Server response state: context, write stream, implicit header handling, chunked transfer flags |
| `ILibDuktape_WebSocket_State` | Full WebSocket state: fragmentation, masking, permessage-deflate, compression metrics, encoded/decoded duplex streams |
| `ILibDuktape_HttpStream_ServerResponse_BufferedImplicit_State` | Buffered implicit header state for server responses with flexible buffer tail |

### Functions

| Function | Description |
|---|---|
| `ILibDuktape_HttpStream_http_get` | Implements `http.get()` — accepts a URL string or options object, calls `http.request()`, and auto-calls `end()` |
| `ILibDuktape_HttpStream_http_checkIdentity` | Identity-check wrapper that forwards arguments to the underlying function stored on the current Duktape function object |
| `ILibDuktape_HttpStream_http_ConvertOptionToSend` | Converts an options object into a serialized HTTP request buffer for transmission |
| `ILibDuktape_Headers_IsChunkSupported` | Returns whether chunked transfer encoding is supported based on HTTP version |
| `ILibDuktape_serverResponse_resetHttpStream` | Resets the HTTP stream after a server response completes, finalizing the WCDO and body stream |
| `ILibDuktape_Digest_CalculateNonce` | Generates an MD5-based digest authentication nonce from expiration time and heap pointer |
| `ILibDuktape_HttpStream_ServerResponse_PUSH` | Pushes a server response object onto the Duktape stack |

### Internal Key Constants

All internal property keys use `\xFF` prefix (hidden Duktape string namespace) to avoid collisions, e.g. `ILibDuktape_ClientRequest`, `ILibDuktape_WebSocket_StatePtr`, `ILibDuktape_HTTPStream2Socket`.

## Usage Example

```c
// Register http.get() on the Duktape context (simplified)
duk_push_c_function(ctx, ILibDuktape_HttpStream_http_get, DUK_VARARGS);
duk_put_prop_string(ctx, httpObj, "get");

// Check chunked transfer encoding support based on parsed headers
ILibHTTPPacket *header = /* parsed response header */;
if (ILibDuktape_Headers_IsChunkSupported(header)) {
    // Enable chunked transfer for HTTP/1.1+
}

// Calculate a digest nonce for authentication
char nonce[33];
ILibDuktape_Digest_CalculateNonce(ctx, heapptr, expirationTime, opaque, opaqueLen, nonce);
```
