Header file that exposes the initialization interface for WebRTC bindings within the Duktape JavaScript engine integration layer.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibDuktape_WebRTC_Init` | Function declaration | Registers WebRTC objects and methods into a Duktape JS context |
| `___ILibDuktape_WebRTC___` | Include guard macro | Prevents duplicate inclusion of this header |

## Usage Example

```c
#include "ILibDuktape_WebRTC.h"

/* Register WebRTC bindings into an existing Duktape context */
duk_context *ctx = duk_create_heap_default();
ILibDuktape_WebRTC_Init(ctx);
```

Call `ILibDuktape_WebRTC_Init` once per Duktape heap during engine setup, typically alongside other `ILibDuktape_*_Init` calls that bootstrap the full JavaScript runtime environment.

## Notes

- Depends on `duktape.h`; the Duktape SDK must be available on the include path.
