Implements the Duktape JavaScript `EventEmitter` class for the MeshAgent embedded scripting engine, providing Node.js-compatible event-driven programming patterns (`.on()`, `.once()`, `.emit()`, `.removeListener()`) within a C-based Duktape runtime.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_EventEmitter` | struct | Core emitter state: listener table, return value table, spin lock for thread-safe listener counts |
| `ILibDuktape_EventEmitter_GetEmitter_fromObject` | function | Retrieves the emitter struct from a heap pointer to a JS object |
| `ILibDuktape_EventEmitter_HasListeners2` | function | Thread-safe check for listener count on a named event; parses the serialized count table |
| `ILibDuktape_EventEmitter_emit` | function | Core dispatch: iterates registered handlers, handles `once` removal, propagates arguments, captures return values |
| `ILibDuktape_EventEmitter_emit_removeListener` | function | Internal helper that fires the `removeListener` event after a `once` handler is consumed |
| `ILibDuktape_EventEmitter_DefaultNewListenerHandler` | function | Default `newListener` hook, used to replay missed events on late registration |
| `ILibDuktape_EventEmitter_EmitterUtils` / `EventTable` / `CountTable` | string keys | Internal hidden property keys (`\xFF`-prefixed) for listener arrays and count metadata |

## Usage Example

From JavaScript running inside the MeshAgent runtime (after `require('events')`):

```javascript
var events = require('events');

function MyDevice() {
    // Attach EventEmitter methods to this object
    this._emitter = events.inherits(this);
    this._emitter.createEvent('data');
    this._emitter.createEvent('close');
}

var dev = new MyDevice();

dev.on('data', function(chunk) {
    console.log('Received:', chunk);
});

dev.once('close', function() {
    console.log('Connection closed (fires once)');
});

// Internal C code calls the equivalent of:
dev.emit('data', 'hello world');
dev.emit('close');
```

From C, triggering an event:

```c
ILibDuktape_EventEmitter_SetupEmitEx(ctx, objIndex, "data");
duk_push_string(ctx, "hello world");
if (duk_pcall_method(ctx, 2) != 0) {
    ILibDuktape_Process_UncaughtExceptionEx(ctx, "MyDevice.data emit error");
}
duk_pop(ctx);
```
