Header file for the Duktape JavaScript engine filesystem (`fs`) module, exposing the initialization function that registers filesystem bindings into a Duktape context.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibDuktape_fs_init` | Function | Registers the `fs` module and its methods into the given Duktape JavaScript context |

## Usage Example

```c
#include "ILibDuktape_fs.h"

/* After creating a Duktape context, initialize the fs module */
duk_context *ctx = duk_create_heap_default();
ILibDuktape_fs_init(ctx);

/* The 'fs' object is now available in JavaScript executed within ctx */
duk_eval_string(ctx, "fs.readFileSync('/etc/hostname', 'utf8')");
```

## Notes

- Must be called once per Duktape context before evaluating any JavaScript that uses the `fs` module.
- Part of the MeshAgent Duktape binding layer; see related init headers (`ILibDuktape_net.h`, `ILibDuktape_http.h`) for the same pattern.
- Source: [`ILibDuktape_fs.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibDuktape_fs.h)
