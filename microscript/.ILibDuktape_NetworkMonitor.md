Duktape binding header that exposes a `NetworkMonitor` JavaScript object for monitoring network interface state changes within the MeshAgent Duktape scripting runtime.

## Key Components

### JavaScript Class: `NetworkMonitor`

Accessible in scripts via `require('NetworkMonitor')`. Emits the following events:

| Event | Description | Parameters |
|-------|-------------|------------|
| `change` | Fired when any network interface changes state | — |
| `add` | Fired when a new IP address is assigned to an interface | `addr` — the IP address added |
| `remove` | Fired when an IP address is removed from an interface | `addr` — the IP address removed |

### C Function

- **`ILibDuktape_NetworkMonitor_Init(duk_context *ctx)`** — Registers the `NetworkMonitor` module into the provided Duktape context, making it available to JavaScript via `require`.

## Usage Example

```javascript
// JavaScript (inside MeshAgent scripting runtime)
var monitor = require('NetworkMonitor');

monitor.on('change', function () {
    console.log('A network interface changed state');
});

monitor.on('add', function (addr) {
    console.log('IP address added:', addr);
});

monitor.on('remove', function (addr) {
    console.log('IP address removed:', addr);
});
```

```c
// C — initialize the module into a Duktape context
#include "ILibDuktape_NetworkMonitor.h"

void setup(duk_context *ctx) {
    ILibDuktape_NetworkMonitor_Init(ctx);
}
```
