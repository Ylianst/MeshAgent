UDP datagram socket bindings header for the Duktape JavaScript engine, exposing Node.js-style `dgram` module functionality to the embedded JS runtime.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibDuktape_DGram_Init` | Function | Registers the `dgram` module and its bindings into the provided Duktape context |

## Usage Example

```c
#include "ILibDuktape_Dgram.h"
#include "duktape.h"

/* Initialize the dgram module within a Duktape context */
duk_context *ctx = duk_create_heap_default();
ILibDuktape_DGram_Init(ctx);

/* The dgram module is now available in JavaScript running in ctx:
 *
 * var dgram = require('dgram');
 * var sock = dgram.createSocket('udp4');
 * sock.bind(5000);
 * sock.on('message', function(msg, rinfo) { ... });
 */
```

## Notes

- This header is a thin registration interface; implementation lives in the corresponding `.c` source file.
- Follows the standard `ILibDuktape_*_Init` pattern used throughout the MeshAgent Duktape binding layer.
- Requires a valid, fully initialized `duk_context` before calling `ILibDuktape_DGram_Init`.
