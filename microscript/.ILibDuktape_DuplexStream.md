Header defining the DuplexStream abstraction for the Duktape JavaScript engine integration layer, combining readable and writable stream interfaces into a single bidirectional stream, along with a Transform stream variant for data transformation pipelines.

## Key Components

### Structs

- **`ILibDuktape_DuplexStream`** — Core duplex stream context holding pointers to the underlying readable/writable streams plus callbacks for write, end, pause, and resume events.
- **`ILibDuktape_Transform`** — Transform stream context that sits between a writable source and readable target, supporting native transform, unshift, and piped-sink callbacks.

### Function Pointer Types

| Type | Description |
|---|---|
| `ILibDuktape_DuplexStream_WriteHandler` | Called when data is written to the stream |
| `ILibDuktape_DuplexStream_EndHandler` | Called when the writable side ends |
| `ILibDuktape_DuplexStream_PauseResumeHandler` | Called on backpressure pause/resume |
| `ILibDuktape_DuplexStream_UnshiftHandler` | Called to push bytes back into the stream |
| `ILibDuktape_TransformStream_TransformHandler` | Called to process/transform buffered data |

### Functions & Macros

- **`ILibDuktape_DuplexStream_InitEx`** — Initializes a full duplex stream with all handlers; `ILibDuktape_DuplexStream_Init` is a convenience macro omitting the unshift handler.
- **`ILibDuktape_Transform_InitEx`** / **`ILibDuktape_Transform_Init`** — Initializes a transform stream with optional unshift and piped-sink handlers.
- **`ILibDuktape_DuplexStream_GetNativeWritable`** — Retrieves the native writable stream handle from a Duktape context.
- **`ILibDuktape_DuplexStream_WriteData` / `WriteDataEx` / `WriteEnd` / `Ready` / `Closed`** — Memory-safe macros for pushing data, signaling end-of-stream, and managing stream lifecycle.

## Usage Example

```c
ILibDuktape_DuplexStream *stream = ILibDuktape_DuplexStream_Init(
    ctx,
    myWriteHandler,   // called when consumer writes data in
    myEndHandler,     // called when writable side is finished
    myPauseHandler,   // called on backpressure
    myResumeHandler,  // called when backpressure clears
    userData
);

// Push data to the readable side
ILibDuktape_DuplexStream_WriteData(stream, buffer, bufferLen);

// Signal end of readable output
ILibDuktape_DuplexStream_WriteEnd(stream);
```
