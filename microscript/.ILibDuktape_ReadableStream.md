Provides the C header interface for implementing Node.js-style Readable Streams within the Duktape JavaScript engine embedding layer used by MeshAgent.

## Key Components

### Core Struct: `ILibDuktape_readableStream`

The primary data structure representing a readable stream instance, containing:

- `ctx` — Duktape JS context pointer
- `paused` / `paused_data` — pause state and buffered data
- `emitter` — linked `ILibDuktape_EventEmitter` for event dispatch
- `nextWriteable` / `pipeArray` — pipe destination tracking
- `pipeLock` / `pipe_pendingCount` — cross-platform atomic pipe synchronization (Win32 `LONG`, GCC `__ATOMIC_SEQ_CST`, or mutex fallback)

### Callback Typedefs

| Typedef | Purpose |
|---|---|
| `ILibDuktape_readableStream_PauseResumeHandler` | Called when stream is paused or resumed |
| `ILibDuktape_readableStream_MethodHookHandler` | Hook invoked on pipe to a writable stream |
| `ILibDuktape_readableStream_UnShiftHandler` | Called to push data back into the stream buffer |

### Functions & Macros

| Symbol | Description |
|---|---|
| `ILibDuktape_ReadableStream_InitEx()` | Full initializer with pause, resume, and unshift handlers |
| `ILibDuktape_ReadableStream_Init()` | Convenience macro wrapping `InitEx` without unshift handler |
| `ILibDuktape_readableStream_WriteDataEx()` | Write a buffer into the stream (supports reserved offset) |
| `ILibDuktape_readableStream_WriteData()` | Macro shorthand for `WriteDataEx` with zero offset |
| `ILibDuktape_readableStream_WriteEnd()` | Signal end-of-stream |
| `ILibDuktape_readableStream_Closed()` | Notify that the stream has been closed |
| `ILibDuktape_ReadableStream_DestroyPausedData()` | Free buffered data held during a pause |
| `ILibDuktape_readableStream_SetPauseResumeHandlers()` | Runtime reassignment of pause/resume callbacks |

## Usage Example

```c
// Initialize a readable stream on the current Duktape stack object
ILibDuktape_readableStream *rs = ILibDuktape_ReadableStream_Init(
    ctx, MyPauseHandler, MyResumeHandler, myUserData
);

// Push data into the stream from a native source
ILibDuktape_readableStream_WriteData(rs, dataBuffer, dataLen);

// Signal end of data
ILibDuktape_readableStream_WriteEnd(rs);
```
