Header file providing utility macros, types, and function declarations for integrating the Duktape JavaScript engine with the MeshAgent's C runtime, including context management, property access helpers, and event loop dispatch.

## Key Components

### Types & Structs
- **`ILibDuktape_ContextData`** — Per-context metadata: nonce, execution count/time, chain pointer, flags
- **`ILibDuktape_LogTypes`** — Enum for log severity levels (`Normal`, `Warn`, `Error`, `Info1`–`Info3`)
- **`Duktape_EventLoopDispatch`** — Callback typedef for event loop dispatch handlers

### Context Macros
- **`duk_ctx_context_data(ctx)`** — Retrieves associated `ILibDuktape_ContextData*`
- **`duk_ctx_is_alive(ctx)`** / **`duk_ctx_is_valid(nonce, ctx)`** — Liveness and validity checks
- **`duk_ctx_shutting_down(ctx)`** — Detects heap teardown in progress
- **`duk_ctx_chain(ctx)`** — Safely retrieves the ILib chain pointer

### Property Access Functions
- **`Duktape_GetStringPropertyValue`** / **`Duktape_GetIntPropertyValue`** / **`Duktape_GetBooleanProperty`** — Typed property readers with defaults
- **`Duktape_GetBufferProperty`** / **`Duktape_GetHeapptrProperty`** — Binary and heap pointer accessors
- **`Duktape_Duplicate_GetString`** / **`Duktape_Duplicate_GetBufferProperty`** — Heap-copying variants

### Collection Macros
- **`duk_array_*`** — Array push/pop/shift/join/remove/clone operations
- **`duk_queue_*`** — FIFO queue primitives built on arrays
- **`duk_table_*`** — Key/value table helpers

### Event Loop & Execution
- **`Duktape_RunOnEventLoop`** — Dispatches a callback to the ILib event loop with nonce validation
- **`ILibDuktape_ExecutorTimeout_Start/Stop`** — Execution time guard for JS contexts

## Usage Example

```c
// Check context is alive before accessing data
if (duk_ctx_is_valid(my_nonce, ctx)) {
    void *chain = duk_ctx_chain(ctx);

    // Read a string property with default fallback
    char *name = Duktape_GetStringPropertyValue(ctx, -1, "name", "unknown");

    // Dispatch work to the event loop
    Duktape_RunOnEventLoop(chain, my_nonce, ctx, my_handler, NULL, user_data);
}

// Read an integer property
int timeout = Duktape_GetIntPropertyValue(ctx, -1, "timeout", 5000);
```
