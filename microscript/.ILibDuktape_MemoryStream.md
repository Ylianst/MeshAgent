A Duktape JavaScript binding that implements an in-memory `DuplexStream` buffer accumulator, similar to a `StringBuilder`, for use in the MeshAgent scripting environment.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_MemoryStream` | `struct` | Internal state holding the Duktape context, dynamic buffer pointer, and accumulated length |
| `ILibDuktape_MemoryStream_OnWrite` | Function | Write handler; appends incoming data to the internal buffer, doubling capacity as needed |
| `ILibDuktape_MemoryStream_OnEnd` | Function | End-of-stream handler; forwards the end signal to the underlying `DuplexStream` |
| `ILibDuktape_MemoryStream_buffer` | `duk_ret_t` | Getter that exposes the accumulated bytes as a Node.js-compatible `Buffer` object |
| `ILibDuktape_MemoryStream_writeBE` | `duk_ret_t` | Shared handler for `writeUInt8`, `writeUInt16BE`, and `writeUInt32BE` methods |
| `ILibDuktape_MemoryStream_new` | `duk_ret_t` | Constructor; initializes the `DuplexStream`, dynamic buffer (default 4096 bytes), and instance methods |
| `ILibDuktape_MemoryStream_Init` | Function | Registers the `MemoryStream` module with the Duktape module search system |

## Usage Example

From the Duktape/JavaScript side (within MeshAgent scripts):

```javascript
var MemoryStream = require('MemoryStream');
var ms = new MemoryStream(8192); // optional initial size in bytes

ms.write('Hello, ');
ms.writeUInt16BE(0x576F);   // big-endian 16-bit write
ms.writeUInt8(0x21);        // single byte write

ms.end();

ms.on('finish', function () {
    var buf = ms.buffer;    // Node.js Buffer of accumulated bytes
    console.log(buf.length);
});
```

**Notes:**
- The internal buffer grows automatically — it doubles in size when capacity is exhausted, or expands by the incoming chunk size if the chunk is larger than the current buffer.
- `MemoryStream` implements the `DuplexStream` interface, so it is compatible with pipe chains.
