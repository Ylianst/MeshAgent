Header file exposing the Duktape JavaScript binding for TCP/IP networking (`net` module) within the MeshAgent microstack, including global tunnel/proxy configuration support.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibDuktape_net_init` | Function | Registers the `net` module into a Duktape JS context, binding it to the microstack event chain |
| `ILibDuktape_globalTunnel_data` | Struct | Holds proxy server address, exception table, and credentials for a global tunnel |
| `ILibDuktape_GetGlobalTunnel` | Function | Retrieves the existing global tunnel configuration from a Duktape context |
| `ILibDuktape_GetNewGlobalTunnelEx` | Function | Allocates and registers a new global tunnel, with a `native` flag to control allocation mode |
| `ILibDuktape_GetNewGlobalTunnel` | Macro | Convenience wrapper for `ILibDuktape_GetNewGlobalTunnelEx` with `native=1` |
| `ILibDuktape_SOCKET2OPTIONS` | Macro | Internal heap-stash key (`\xFF_NET_SOCKET2OPTIONS`) for socket options storage |

## Usage Example

```c
#include "ILibDuktape_net.h"

// Initialize the net module into a Duktape context
void setup_js_runtime(duk_context *ctx, void *chain) {
    ILibDuktape_net_init(ctx, chain);
}

// Configure a global HTTP proxy tunnel
ILibDuktape_globalTunnel_data *tunnel = ILibDuktape_GetNewGlobalTunnel(ctx);
if (tunnel != NULL) {
    // proxyServer, proxyUser, proxyPass are populated
    // before any net.connect() calls in JS
    strncpy(tunnel->proxyUser, "admin", sizeof(tunnel->proxyUser) - 1);
    strncpy(tunnel->proxyPass, "secret", sizeof(tunnel->proxyPass) - 1);
}

// Retrieve an existing tunnel later
ILibDuktape_globalTunnel_data *existing = ILibDuktape_GetGlobalTunnel(ctx);
```

## Notes

- Requires Winsock2 headers (`winsock2.h`, `ws2tcpip.h`) on Windows builds when `WINSOCK2` is defined.
- `ILibDuktape_globalTunnel_data.exceptionsTable` is an `ILibHashtable` used to bypass the proxy for specific hosts.
- Source: [`ILibDuktape_net.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibDuktape_net.h)
