Header file that registers and resolves native and JavaScript modules within a Duktape JavaScript engine context, enabling a custom `require()`-style module search system.

## Key Components

### Type Definition

- **`ILibDuktape_ModSearch_PUSH_Object`** — Function pointer type for native module push handlers; called with the Duktape context and chain pointer to expose a native object to JS.

### Functions

| Function | Description |
|---|---|
| `ILibDuktape_ModSearch_Init` | Initializes the module search system, binding it to a Duktape context, chain, and optional data store. |
| `ILibDuktape_ModSearch_AddHandler` | Registers a native C handler for a given module ID, invoked when JS calls `require(id)`. |
| `ILibDuktape_ModSearch_AddHandler_AlsoIncludeJS` | Appends supplementary JavaScript source to run alongside a registered native handler. |
| `ILibDuktape_ModSearch_AddModule` | Macro shorthand for `AddModuleEx` — registers a raw JS string as a named module (no mtime). |
| `ILibDuktape_ModSearch_AddModuleEx` | Registers a raw JS string module with an optional modification timestamp. |
| `ILibDuktape_ModSearch_AddModuleObject` | Registers a pre-existing Duktape heap object as a named module. |
| `ILibDuktape_ModSearch_GetJSModule` | Retrieves a registered JS module by ID, pushing it onto the Duktape stack. |
| `ILibDuktape_ModSearch_GetJSModuleDate` | Returns the stored modification timestamp (`uint32_t`) for a named module. |
| `ILibDuktape_ModSearch_IsRequired` | Checks whether a given module ID has already been required/loaded. |

## Usage Example

```c
// Initialize the module search system
ILibDuktape_ModSearch_Init(ctx, chain, myDataStore);

// Register a native C module
ILibDuktape_ModSearch_AddHandler(ctx, "my-native-module", MyModule_Push);

// Register an inline JavaScript module
const char *jsSource = "exports.hello = function(){ return 'world'; };";
ILibDuktape_ModSearch_AddModule(ctx, "my-js-module", jsSource, (int)strlen(jsSource));

// Check if a module was already loaded
if (ILibDuktape_ModSearch_IsRequired(ctx, "my-js-module", strlen("my-js-module"))) {
    // already required
}
```
