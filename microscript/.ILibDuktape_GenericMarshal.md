Header file defining the generic marshaling interface for the Duktape JavaScript engine integration, providing type conversion infrastructure between C and JavaScript contexts.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_GenericMarshal_CallTypes` | `enum` | Specifies the calling/marshaling convention to use |
| `ILibDuktape_GenericMarshal_CallTypes_DEFAULT` | `enum value` | Standard marshaling behavior (`0`) |
| `ILibDuktape_GenericMarshal_CallTypes_COM_VARIANT` | `enum value` | COM `VARIANT`-based marshaling (`1`) |
| `ILibDuktape_GenericMarshal_init` | `function` | Registers the generic marshal module into a Duktape context |

## Usage Example

```c
#include "ILibDuktape_GenericMarshal.h"

/* Initialize a Duktape context and register the marshal module */
duk_context *ctx = duk_create_heap_default();
if (ctx != NULL)
{
    ILibDuktape_GenericMarshal_init(ctx);

    /* ctx is now ready for generic marshaling operations,
       including COM VARIANT interop on supported platforms */
}
```

## Notes

- Include guard: `__DuktapeGenericMarshal__`
- Depends on `duktape.h` — a Duktape context (`duk_context *`) must be created before calling `init`
- `COM_VARIANT` mode is intended for Windows COM interoperability scenarios
