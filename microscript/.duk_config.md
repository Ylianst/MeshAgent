Auto-generated configuration header for Duktape v2.6.0 that provides cross-platform compiler, architecture, and OS detection macros for the Duktape JavaScript engine.

## Key Components

### Platform Detection Macros (`DUK_F_*`)
Internal feature-flag macros that identify the build environment:

| Category | Examples |
|---|---|
| OS/Platform | `DUK_F_APPLE`, `DUK_F_WINDOWS`, `DUK_F_LINUX`, `DUK_F_BSD`, `DUK_F_ANDROID` |
| Architecture | `DUK_F_X86`, `DUK_F_X64`, `DUK_F_ARM`, `DUK_F_ARM64`, `DUK_F_MIPS`, `DUK_F_RISCV` |
| Compiler | `DUK_F_GCC`, `DUK_F_CLANG`, `DUK_F_MSVC`, `DUK_F_TINYC`, `DUK_F_VBCC` |
| Language Standard | `DUK_F_C99`, `DUK_F_CPP`, `DUK_F_CPP11` |

### Runtime Configuration Macros (`DUK_USE_*`)
Public macros consumed by the Duktape engine, set based on detected platform:

- **Date/Time:** `DUK_USE_DATE_NOW_GETTIMEOFDAY`, `DUK_USE_DATE_TZO_GMTIME_R`, `DUK_USE_DATE_PRS_STRPTIME`, `DUK_USE_DATE_FMT_STRFTIME`
- **OS String:** `DUK_USE_OS_STRING` (e.g., `"osx"`, `"linux"`, `"windows"`)
- **Jump Buffer:** `DUK_JMPBUF_TYPE`, `DUK_SETJMP`, `DUK_LONGJMP`

## Usage Example

This header is included automatically by Duktape internals. You generally do not include it directly, but you can query detected macros:

```c
#include "duk_config.h"

/* Check platform at compile time */
#if defined(DUK_F_WINDOWS)
    /* Windows-specific initialization */
#elif defined(DUK_F_LINUX)
    /* Linux-specific initialization */
#endif

/* GCC version check (e.g., >= 4.5.1 == 40501) */
#if defined(DUK_F_GCC) && DUK_F_GCC_VERSION >= 40501
    /* Use GCC 4.5.1+ features */
#endif
```
