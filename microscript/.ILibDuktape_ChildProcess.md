Header file that exposes the initialization interface for the Duktape JavaScript `child_process` module within the MeshAgent runtime.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_ChildProcess_Manager` | Macro (string) | Hidden Duktape heap-stash key (`"\xFF_ChildProcess_Manager"`) used to store the child process manager object |
| `ILibDuktape_ChildProcess_Init` | Function | Registers the `child_process` module bindings into the given Duktape context |

## Usage Example

```c
#include "ILibDuktape_ChildProcess.h"

// During JavaScript engine setup, register the child_process module
void setup_duktape_modules(duk_context *ctx)
{
    ILibDuktape_ChildProcess_Init(ctx);

    // The child_process module is now available in JS:
    // var cp = require('child_process');
    // cp.execFile('/usr/bin/ls', ['-la'], {}, function(err, stdout) { ... });
}
```

## Notes

- The `\xFF` prefix on `ILibDuktape_ChildProcess_Manager` makes the stash key non-enumerable and collision-safe within Duktape's internal property namespace.
- This header must be included once during engine initialization; subsequent `require('child_process')` calls in JavaScript resolve through Duktape's module system without re-invoking `Init`.
- Depends on [`duktape.h`](https://github.com/flamingo-stack/meshagent/blob/main/duktape.h) from the embedded Duktape engine.
