Header file for the Duktape JavaScript engine polyfill layer, exposing initialization functions and debug flags that add browser/Node.js-compatible APIs to the embedded JS runtime.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `g_displayStreamPipeMessages` | `extern int` | Debug flag to enable logging of stream pipe events |
| `g_displayFinalizerMessages` | `extern int` | Debug flag to enable logging of finalizer lifecycle events |
| `ILibDuktape_Polyfills_Init` | Function | Registers native C-backed polyfills into the Duktape context |
| `ILibDuktape_Polyfills_JS_Init` | Function | Registers JavaScript-implemented polyfills into the Duktape context |

## Usage Example

```c
#include "ILibDuktape_Polyfills.h"

// Optionally enable debug output
g_displayStreamPipeMessages = 1;
g_displayFinalizerMessages  = 1;

// Initialize a Duktape context
duk_context *ctx = duk_create_heap_default();

// Register native (C) polyfills first, then JS-layer polyfills
ILibDuktape_Polyfills_Init(ctx);
ILibDuktape_Polyfills_JS_Init(ctx);
```

The two-phase initialization (`_Init` then `_JS_Init`) allows native C bindings to be in place before any JavaScript-level polyfills that may depend on them are evaluated.
