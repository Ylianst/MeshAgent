Header file that exposes SHA-256 hashing functionality to the Duktape JavaScript engine by registering related bindings into a Duktape context.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibDuktape_SHA256_Init` | Function | Registers SHA-256 bindings into the provided Duktape context |
| `___DUKTAPE_SHA256___` | Guard macro | Standard include guard preventing double inclusion |

## Usage Example

```c
#include "ILibDuktape_SHA256.h"

/* Initialize SHA-256 support in a Duktape context */
duk_context *ctx = duk_create_heap_default();
if (ctx) {
    ILibDuktape_SHA256_Init(ctx);
    /* SHA-256 is now available to scripts running in ctx */
}
```

## Notes

- Depends on `duktape.h`; ensure Duktape is available in your include path.
- Call `ILibDuktape_SHA256_Init` once per `duk_context` before executing scripts that require SHA-256 operations.
- Part of the broader MeshAgent Duktape integration layer. See related initializers (e.g., other `ILibDuktape_*_Init` functions) in the [repository](https://github.com/flamingo-stack/meshagent) for the full scripting surface.
