Header file defining the `ScriptContainer` module for the MeshAgent's Duktape JavaScript engine, providing process-isolated script execution with configurable security permissions.

## Key Components

### Enumerations

- **`SCRIPT_ENGINE_SECURITY_FLAGS`** — Bitmask flags controlling sandbox permissions for a JavaScript engine instance:
  - `SCRIPT_ENGINE_NO_MESH_AGENT_ACCESS` — Blocks MeshAgent object access
  - `SCRIPT_ENGINE_NO_GENERIC_MARSHAL_ACCESS` — Blocks `_GenericMarshal`
  - `SCRIPT_ENGINE_NO_PROCESS_SPAWNING` — Blocks `ILibProcessPipe`
  - `SCRIPT_ENGINE_NO_FILE_SYSTEM_ACCESS` — Blocks `fs` module
  - `SCRIPT_ENGINE_NO_NETWORK_ACCESS` — Blocks networking classes
  - `SCRIPT_ENGINE_NO_DEBUGGER` — Disables debugger attachment

### Structs

- **`SCRIPT_ENGINE_SETTINGS`** — Configuration struct for engine initialization, holding the chain, security flags, timeout, data store, exit handler, pipe manager, and executable path.

### Core Functions

| Function | Description |
|---|---|
| `ILibDuktape_ScriptContainer_InitializeJavaScriptEngineEx3` | Full engine init with explicit parameters |
| `ILibDuktape_ScriptContainer_InitializeJavaScriptEngineEx2` | Engine init via `SCRIPT_ENGINE_SETTINGS` struct |
| `ILibDuktape_ScriptContainer_InitMaster` | Initializes the master container process |
| `ILibDuktape_ScriptContainer_StartSlave` | Starts a process-isolated child container |
| `ILibDuktape_ScriptContainer_CompileJavaScriptEx` | Compiles JavaScript payload with optional filename |
| `ILibDuktape_ScriptContainer_ExecuteByteCode` | Executes previously compiled bytecode |
| `ILibDuktape_ScriptContainer_CheckEmbedded` | Checks for embedded scripts in the binary |

### Convenience Macros

- **`ILibDuktape_ScriptContainer_InitializeJavaScriptEngineEx`** — Wraps `Ex3` with minimal engine init
- **`ILibDuktape_ScriptContainer_InitializeJavaScriptEngine`** — Simplified init omitting exe path and pipe manager
- **`ILibDuktape_ScriptContainer_CompileJavaScript`** — Compiles without a filename hint

## Usage Example

```c
// Initialize a sandboxed JavaScript engine with network access blocked
SCRIPT_ENGINE_SETTINGS settings = {
    .chain           = myChain,
    .securityFlags   = SCRIPT_ENGINE_NO_NETWORK_ACCESS | SCRIPT_ENGINE_NO_FILE_SYSTEM_ACCESS,
    .executionTimeout = 30,
    .db              = myDataStore,
    .exitHandler     = onExit,
    .exitUserObject  = NULL,
    .pipeManager     = myPipeManager,
    .exePath         = "/usr/bin/meshagent"
};

duk_context *ctx = ILibDuktape_ScriptContainer_InitializeJavaScriptEngineEx2(&settings);

// Compile and execute a script
if (ILibDuktape_ScriptContainer_CompileJavaScript(ctx, scriptPayload, scriptLen) == 0) {
    ILibDuktape_ScriptContainer_ExecuteByteCode(ctx);
}
```
