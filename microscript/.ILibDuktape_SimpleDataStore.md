Duktape binding header that exposes `ILibSimpleDataStore` functionality to the JavaScript runtime, enabling scripts to interact with a shared key-value data store.

## Key Components

| Symbol | Description |
|---|---|
| `ILibDuktape_SimpleDataStore_init` | Registers the `SimpleDataStore` object and its methods into the Duktape context, bound to a shared `ILibSimpleDataStore` instance |
| `ILibDuktape_SimpleDataStore_raw_GetCachedValues_Array` | Pushes all cached key-value entries from the data store onto the Duktape stack as a JavaScript **Array** |
| `ILibDuktape_SimpleDataStore_raw_GetCachedValues_Object` | Pushes all cached key-value entries from the data store onto the Duktape stack as a JavaScript **Object** |

## Usage Example

```c
#include "ILibDuktape_SimpleDataStore.h"

// Initialize the Duktape context and open a SimpleDataStore
duk_context *ctx = duk_create_heap_default();
ILibSimpleDataStore db = ILibSimpleDataStore_Create("agent.db");

// Register the data store binding into the JS runtime
ILibDuktape_SimpleDataStore_init(ctx, db);

// Retrieve cached values as an object onto the Duktape stack
ILibDuktape_SimpleDataStore_raw_GetCachedValues_Object(ctx, db);
// Stack top now holds a JS object: { "key1": "value1", ... }

// Retrieve cached values as an array onto the Duktape stack
ILibDuktape_SimpleDataStore_raw_GetCachedValues_Array(ctx, db);
// Stack top now holds a JS array: [["key1", "value1"], ...]
```

## Notes

- Depends on `duktape.h` and `microstack/ILibSimpleDataStore.h`; both must be present in the include path.
- The `sharedDb` instance passed to `init` is shared across the JS environment — ensure thread safety if accessed concurrently.
- Source: [`ILibDuktape_SimpleDataStore.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibDuktape_SimpleDataStore.h)
