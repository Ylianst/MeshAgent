C header defining the EventEmitter abstraction layer for the Duktape JavaScript engine, enabling Node.js-style event-driven programming within MeshAgent's native C components.

## Key Components

### Types & Structs

| Name | Description |
|---|---|
| `ILibDuktape_EventEmitter` | Core struct holding Duktape context, event listener tables, return value tracking, and spin lock |
| `ILibDuktape_EventEmitter_Types` | Enum distinguishing `EXPLICIT` vs `IMPLICIT` event registration |
| `ILibDuktape_EventEmitter_Handler` | Callback signature for native event handlers |
| `ILibDuktape_EventEmitter_HookHandler` | Callback fired when a listener is hooked onto an event |

### Functions

| Name | Description |
|---|---|
| `ILibDuktape_EventEmitter_Create` | Allocates and attaches a new emitter to the current Duktape object |
| `ILibDuktape_EventEmitter_GetEmitter` | Retrieves an emitter from a stack index |
| `ILibDuktape_EventEmitter_AddOn` | Registers a persistent native event listener |
| `ILibDuktape_EventEmitter_AddOnce` | Registers a one-shot native event listener |
| `ILibDuktape_EventEmitter_RemoveAllListeners` | Invokes JS `removeAllListeners()` on the emitter |
| `ILibDuktape_EventEmitter_ForwardEvent` | Forwards events between two emitter objects |
| `ILibDuktape_EventEmitter_AddHook` / `ClearHook` | Attaches/detaches C-level hooks triggered on listener registration |

### Key Macros

| Macro | Description |
|---|---|
| `ILibDuktape_EventEmitter_SetupEmit` | Prepares the Duktape stack to call `emit(eventName, ...)` |
| `ILibDuktape_EventEmitter_SetupOn` | Prepares the stack to call `.on(eventName, handler)` |
| `ILibDuktape_EventEmitter_HasListeners` | Returns whether an event has active listeners |
| `ILibDuktape_EventEmitter_AddOn_Infrastructure` | Adds an internal infrastructure-flagged listener |

## Usage Example

```c
// Create an emitter on the current Duktape object
ILibDuktape_EventEmitter *emitter = ILibDuktape_EventEmitter_Create(ctx);

// Register an event definition
ILibDuktape_EventEmitter_CreateEventEx(emitter, "data");

// Add a one-shot native listener
ILibDuktape_EventEmitter_AddOnce(emitter, "data", callbackHeapPtr);

// Check if listeners exist before emitting
if (ILibDuktape_EventEmitter_HasListeners(emitter, "data")) {
    ILibDuktape_EventEmitter_SetupEmit(ctx, objHeapPtr, "data");
    // push arguments, then duk_pcall_method(ctx, argCount)
}

// Forward an event from one object to another
ILibDuktape_EventEmitter_ForwardEvent(ctx, sourceIdx, "data", targetIdx, "data");
```
