Header file for the Duktape JavaScript engine binding that exposes encryption stream functionality to the scripting environment.

## Key Components

- **`ILibDuktape_EncryptionStream_init`** — Registers the encryption stream module into the provided Duktape context, making encryption/decryption stream APIs available to JavaScript code running within the engine.

## Usage Example

```c
#include "ILibDuktape_EncryptionStream.h"

// Initialize a Duktape context
duk_context *ctx = duk_create_heap_default();

// Register the encryption stream module
ILibDuktape_EncryptionStream_init(ctx);

// The encryption stream API is now available in JS scripts
// evaluated within this context
duk_eval_string(ctx, "var stream = new EncryptionStream(key, iv);");
```

## Notes

- Requires a valid `duk_context` pointer; must be called after the Duktape heap is created and before any scripts that depend on the encryption stream module are evaluated.
- Part of the broader `ILibDuktape_*` binding layer in the [meshagent](https://github.com/flamingo-stack/meshagent) project, which bridges native C functionality into the embedded JavaScript runtime.
