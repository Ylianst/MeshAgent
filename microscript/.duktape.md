Public API header for Duktape 2.6.0, the embeddable JavaScript engine, defining the complete C interface for creating and managing JS execution contexts.

## Key Components

### Type Definitions
- `duk_context` — opaque pointer to a Duktape interpreter heap/thread
- `duk_c_function` — signature for native C functions callable from JavaScript
- `duk_alloc_function` / `duk_realloc_function` / `duk_free_function` — custom memory allocator callbacks
- `duk_fatal_function` — unrecoverable error handler callback
- `duk_safe_call_function` — protected call callback
- `duk_debug_*_function` — debugger transport callbacks (read, write, peek, flush, detach)

### Structs
- `duk_thread_state` — opaque 128-byte buffer for suspend/resume state
- `duk_memory_functions` — groups allocator function pointers with a userdata pointer
- `duk_function_list_entry` — maps a string key to a `duk_c_function` with an argument count, for bulk registration
- `duk_number_list_entry` — maps a string key to a `duk_double_t` constant
- `duk_time_components` — broken-down time representation (year, month, day, hours, minutes, seconds, milliseconds, weekday)

### Version Constants
- `DUK_VERSION` — `20600L` (major×10000 + minor×100 + patch), usable in `#if` guards
- `DUK_GIT_COMMIT` / `DUK_GIT_DESCRIBE` / `DUK_GIT_BRANCH` — build identification strings

### Runtime Constants
- `DUK_INVALID_INDEX` — sentinel for an invalid value stack index
- `DUK_VARARGS` — marks a native function as accepting a variable argument count
- `DUK_API_ENTRY_STACK` — minimum extra stack slots (`64`) guaranteed on function entry
- `DUK_DEBUG_PROTOCOL_VERSION` — debugger wire protocol version (`2`)

## Usage Example

```c
#include "duktape.h"

/* Native function exposed to JavaScript */
static duk_ret_t my_add(duk_context *ctx) {
    duk_double_t a = duk_require_number(ctx, 0);
    duk_double_t b = duk_require_number(ctx, 1);
    duk_push_number(ctx, a + b);
    return 1; /* one return value */
}

/* Bulk-register functions using duk_function_list_entry */
static const duk_function_list_entry my_funcs[] = {
    { "add", my_add, 2 },
    { NULL, NULL, 0 } /* sentinel */
};

int main(void) {
    duk_context *ctx = duk_create_heap_default();

    duk_push_global_object(ctx);
    duk_put_function_list(ctx, -1, my_funcs);

    duk_eval_string(ctx, "add(3, 4)");
    printf("Result: %f\n", duk_get_number(ctx, -1)); /* 7.0 */

    duk_destroy_heap(ctx);
    return 0;
}
```

> **Version guard pattern** — use `DUK_VERSION` to conditionally compile against API changes:

```c
#if DUK_VERSION >= 20600L
/* Use 2.6.0+ API */
#endif
```
