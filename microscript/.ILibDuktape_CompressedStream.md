Duktape bindings header for the CompressedStream module, exposing zlib-based stream compression/decompression functionality to the JavaScript runtime.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_CompressedStream_init` | Function | Registers the `CompressedStream` object and its methods into the given Duktape context |
| `___DUKTAPE_COMPRESSED_STREAM___` | Guard macro | Standard include guard preventing double inclusion |

## Usage Example

```c
#include "ILibDuktape_CompressedStream.h"

/* During engine/module initialization */
duk_context *ctx = duk_create_heap_default();

/* Register CompressedStream into the JS runtime */
ILibDuktape_CompressedStream_init(ctx);

/* CompressedStream is now available to JavaScript running in ctx */
```

From JavaScript (after init):

```javascript
// Pipe a readable stream through a compressor
const compressor = new CompressedStream.Compressor();
source.pipe(compressor).pipe(destination);
```

## Notes

- Must be called once per Duktape context before any JS code attempts to use `CompressedStream`.
- Depends on `duktape.h` — ensure the Duktape library is available in the include path.
- Source implementation lives in the corresponding `.c` file; see the full repository at [flamingo-stack/meshagent](https://github.com/flamingo-stack/meshagent).
