Duktape binding header that exposes the `ILibSimpleDataStore` key-value store to the Duktape JavaScript engine.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibDuktape_SimpleDataStore_init` | Function | Registers the `ILibSimpleDataStore` binding into a Duktape context, making the shared database accessible from JavaScript |

## Usage Example

```c
#include "s.h"

// Initialize a Duktape context and bind a shared data store
duk_context *ctx = duk_create_heap_default();
ILibSimpleDataStore sharedDb = ILibSimpleDataStore_Create("mystore.db");

// Expose the data store to JavaScript running in the Duktape context
ILibDuktape_SimpleDataStore_init(ctx, sharedDb);

// JavaScript code running in ctx can now access the data store
duk_eval_string(ctx, "store.Get('myKey');");
```

## Dependencies

- [`duktape.h`](https://github.com/flamingo-stack/meshagent/blob/main/duktape.h) — Duktape embeddable JavaScript engine API
- [`microstack/ILibSimpleDataStore.h`](https://github.com/flamingo-stack/meshagent/blob/main/microstack/ILibSimpleDataStore.h) — Lightweight key-value data store implementation

> **Note:** This header is guarded by `__DUKTAPE_SIMPLEDATASTORE__` to prevent duplicate inclusion.
