Defines the `ILibDuktape_WritableStream` interface, providing a writable stream abstraction that bridges Duktape JavaScript contexts with native C write/end handlers in the MeshAgent microstack.

## Key Components

### Types & Callbacks

| Type | Description |
|---|---|
| `ILibDuktape_WritableStream_WriteHandler` | Called when data is written to the stream; returns transport done state |
| `ILibDuktape_WritableStream_EndHandler` | Called when the stream is ended/closed |
| `ILibDuktape_WriteableStream_WriteFlushNative` | Native flush callback for write operations |
| `ILibDuktape_WritableStream_PipeHandler` | Called when a readable source is piped into this stream |

### Struct: `ILibDuktape_WritableStream`

Core structure holding stream state:

- `ctx` / `obj` — Duktape context and associated JS object
- `WriteSink` / `EndSink` — Native write and end callback functions
- `OnWriteFlush` / `OnWriteFlushEx` — JS and native flush hooks
- `pipedReadable` / `pipedReadable_native` — Tracks piped readable source
- `WaitForEnd` — Flag to defer completion until end is signaled

### Functions

| Function | Description |
|---|---|
| `ILibDuktape_WritableStream_Init` | Initializes a writable stream on the Duktape stack, wiring write/end handlers |
| `ILibDuktape_WritableStream_Ready` | Signals the stream is ready to accept writes |
| `ILibDuktape_WritableStream_Finish` | Signals the stream has completed all operations |

### Macro

- `ILibDuktape_WritableStream_WSPTRS` — Hidden property key (`"\xFF_WritableStream_PTRS"`) used to store native stream pointer on the JS object

## Usage Example

```c
ILibDuktape_WritableStream_WriteHandler writeCallback = myWriteHandler;
ILibDuktape_WritableStream_EndHandler endCallback = myEndHandler;

// Initialize writable stream onto current Duktape stack object
ILibDuktape_WritableStream *ws = ILibDuktape_WritableStream_Init(
    ctx,
    writeCallback,
    endCallback,
    myUserData
);

// Signal the stream is ready for data
ILibDuktape_WritableStream_Ready(ws);

// After all data has been processed
ILibDuktape_WritableStream_Finish(ws);
```
