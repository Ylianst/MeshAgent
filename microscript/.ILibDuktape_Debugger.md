Header file for the Duktape JavaScript debugger integration, providing initialization and script configuration for debug sessions over a network port.

## Key Components

| Symbol | Description |
|--------|-------------|
| `ILibDuktape_Debugger_Init` | Initializes the Duktape debugger and attaches it to a given context, listening on the specified TCP port |
| `ILibDuktape_Debugger_SetScript` | Registers the JavaScript source and filename to be debugged |

## Usage Example

```c
#include "ILibDuktape_Debugger.h"

duk_context *ctx = duk_create_heap_default();

// Load script content to debug
const char *script = "var x = 1 + 2;";
const char *fileName = "main.js";

ILibDuktape_Debugger_SetScript(
    (char *)script, (int)strlen(script),
    (char *)fileName, (int)strlen(fileName)
);

// Start debugger on port 9091
ILibDuktape_Debugger_Init(ctx, 9091);
```

## Notes

- `ILibDuktape_Debugger_SetScript` should be called **before** `ILibDuktape_Debugger_Init` to ensure script metadata is available at debugger startup.
- The debug port (`debugPort`) must be accessible on the host network interface for a client debugger (e.g., a Duktape-compatible IDE plugin) to connect.
- Guard macro `__DUKTAPE_DEBUGGER__` prevents multiple inclusion.
