A header-only C module that intercepts `stdout`/`stderr` and duplicates all `printf` output to both the console and a rotating log file, with cross-platform support for Windows and POSIX systems.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `LOG_MAX_SIZE` | 10 MB | Triggers log rotation |
| `LOG_BUFFER_SIZE` | 4096 bytes | Internal pipe/read buffer |
| `LOG_FILENAME` | `meshcentral-agent.log` | Active log file name |
| `LOG_ARCHIVE_FILENAME` | `meshcentral-agent.log.old.gz` | Single compressed archive |
| `LOG_PATH_SIZE` | 512 | Max path length |

### Global State

- **`g_log_file`** — File handle for the active log file
- **`g_log_directory`** — Optional directory prefix for log paths
- **`g_current_log_size`** — Tracks bytes written; triggers rotation check
- **`g_daemon_mode`** — Suppresses console writes when not attached to a TTY
- **`g_pipe_fds`** — Pipe pair used for `stdout` tee redirection

### Core Functions

- **`enable_file_logging(dir, prefix)`** — Entry point; opens log file, creates the pipe, spawns the tee thread, and redirects `stdout`. Returns `1` on success, `0` on failure.
- **`tee_thread_func`** — Background thread (POSIX `pthread` / Win32 `HANDLE`) that reads from the pipe and writes to both the original `stdout` FD and the log file.
- **`rotate_log_file()`** — Closes the active log, compresses it via `compress_file_to_gzip()`, removes the old archive, and reopens a fresh log file.
- **`check_and_rotate(bytes)`** — Increments `g_current_log_size`; calls `rotate_log_file()` when `LOG_MAX_SIZE` is exceeded.
- **`compress_file_to_gzip(src, dst)`** — Uses `zlib`'s `gzopen`/`gzwrite` on POSIX; falls back to a plain file copy on Windows.
- **`lock_log()` / `unlock_log()`** — Thin wrappers over `pthread_mutex_lock` (POSIX) or `EnterCriticalSection` (Windows).

## Usage Example

```c
#include "openframe_file_logger.h"

int main(void) {
    /* Start logging to /var/log/meshagent directory */
    if (!enable_file_logging("/var/log/meshagent", NULL)) {
        fprintf(stderr, "Logging setup failed\n");
        return 1;
    }

    /* All printf calls now write to both console and meshcentral-agent.log */
    printf("MeshAgent started\n");
    printf("Connecting to server...\n");

    return 0;
}
```

> **Note:** This is a header-only implementation (all functions are `static inline`). Include it in exactly one translation unit per binary to avoid multiple-definition errors. Link against `-lz` (zlib) and `-lpthread` on POSIX targets.
