Dual-mode Windows cryptography module that provides RSA key generation and X.509 self-signed certificate management using Windows CAPI (32-bit/XP compatibility) or Windows CNG with optional TPM support (64-bit).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `wincrypto_open()` | Function | Opens/initializes the crypto provider, cert store, and generates a new RSA key pair and self-signed certificate if needed |
| `wincrypto_close()` | Function | Releases all crypto handles (provider, cert context, cert store) |
| `wincrypto_isopen()` | Function | Returns non-zero if provider, cert store, and cert context are all valid |
| `wincrypto_setregistry()` / `wincrypto_setregistryA()` | Functions | Writes a named string value to the MeshAgent2 registry key (`HKLM` for service, `HKCU` for console) |
| `wincrypto_getregistry()` / `wincrypto_getregistryA()` | Functions | Reads a named string value from the MeshAgent2 registry key |
| `wincrypto_hProv` | Global | Active CNG (`NCRYPT_PROV_HANDLE`) or CAPI (`HCRYPTPROV`) provider handle |
| `wincrypto_certCtx` | Global | Active `PCCERT_CONTEXT` for the node certificate |
| `wincrypto_CngProviders` | Array (64-bit) | Ordered list of CNG providers tried at open: TPM platform provider, then MS Key Storage |
| `wincrypto_CapiProviders` | Array (32-bit) | Ordered list of CAPI CSPs tried at open: Intel IPT, then default |

## Usage Example

```cpp
#include "wincrypto.h"

// Open or create a MeshAgent node certificate (pass 1 to force regeneration)
if (wincrypto_open(0) == 0) {
    // Initialization failed
    return -1;
}

if (wincrypto_isopen()) {
    // wincrypto_certCtx and wincrypto_hProv are ready for use
    // e.g., pass wincrypto_certCtx to a TLS handshake
}

// Persist provider name to registry
wincrypto_setregistry(L"ProviderName", L"Microsoft Platform Crypto Provider");

// Read it back
char* val = NULL;
int len = wincrypto_getregistry(L"ProviderName", &val);
if (len > 0) { /* use val */ free(val); }

// Release all resources
wincrypto_close();
```

> **Platform note:** On 64-bit builds, the module attempts `Microsoft Platform Crypto Provider` (TPM-backed) before falling back to `MS_KEY_STORAGE_PROVIDER`. On 32-bit builds, it attempts `Intel IPT Cryptographic Provider` before the default CAPI CSP. Key size defaults to RSA-3072, falling back to RSA-2048 if unsupported.
