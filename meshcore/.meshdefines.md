Brief header defining core constants and command enumerations for the MeshAgent remote management protocol.

## Key Components

### Constants

| Macro | Value | Description |
|---|---|---|
| `MESH_AGENT_PORT` | `16990` | Default agent communication port |
| `MESH_AGENT_STUN_PORT` | `16991` | Default STUN protocol port |
| `MESH_AGENT_VERSION` | `1` | Agent version used by the self-update system |

### `RemoteManagementCommands` Enum

Defines the full set of command codes exchanged between the MeshAgent and management consoles. Commands are grouped by functional area:

| Range | Category |
|---|---|
| `0–18` | KVM (keyboard, video, mouse) input and display control |
| `21, 27` | Echo and jumbo packet framing |
| `50–58` | File system operations (list, move, delete, copy, transfer, upload, search) |
| `59–65` | Session control, user consent, debug/error logging |
| `70` | Agent command encapsulation |

## Usage Example

```c
#include "meshdefines.h"

void handle_command(int cmd) {
    switch (cmd) {
        case MNG_KVM_KEY:
            // Handle keyboard input
            break;
        case MNG_FILETRANSFER:
            // Handle file transfer
            break;
        case MNG_USERCONSENT:
            // Notify console of user consent state
            break;
        default:
            break;
    }
}

// Open the default agent socket
int sock = open_socket(MESH_AGENT_PORT);
```
