Provides a single function declaration for verifying digital signatures on files, used to validate authenticity before installation or upgrade operations.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `signcheck_verifysign` | Function declaration | Verifies the digital signature of a given file |

### `signcheck_verifysign`

```c
int signcheck_verifysign(char* filename, int upgrade);
```

| Parameter | Type | Description |
|---|---|---|
| `filename` | `char*` | Path to the file whose signature will be verified |
| `upgrade` | `int` | Flag indicating whether the check is part of an upgrade flow |

**Returns:** `int` — typically `0` on success, non-zero on failure (implementation-defined).

## Usage Example

```c
#include "signcheck.h"

int main(void) {
    const char* agent_binary = "/usr/local/bin/meshagent";

    // Verify signature before a standard install
    int result = signcheck_verifysign((char*)agent_binary, 0);
    if (result != 0) {
        fprintf(stderr, "Signature verification failed\n");
        return 1;
    }

    // Verify signature during an upgrade
    int upgrade_result = signcheck_verifysign((char*)agent_binary, 1);
    if (upgrade_result != 0) {
        fprintf(stderr, "Upgrade signature verification failed\n");
        return 1;
    }

    return 0;
}
```

## Notes

- The `upgrade` parameter allows the implementation to apply different validation logic or logging depending on the operation context.
- Part of the [MeshAgent](https://github.com/flamingo-stack/meshagent) security layer, ensuring only trusted binaries are executed or deployed.
