Internal inflate state definitions for zlib's decompression engine, defining the state machine modes and persistent state structure used between `inflate()` calls.

## Key Components

### `inflate_mode` Enum

A comprehensive state machine enumeration tracking decompression progress across `inflate()` calls. States are grouped by purpose:

| Group | States |
|---|---|
| Header parsing | `HEAD`, `FLAGS`, `TIME`, `OS`, `EXLEN`, `EXTRA`, `NAME`, `COMMENT`, `HCRC` |
| Dictionary | `DICTID`, `DICT` |
| Deflate blocks | `TYPE`, `TYPEDO`, `STORED`, `COPY_`, `COPY`, `TABLE`, `LENLENS`, `CODELENS` |
| Deflate codes | `LEN_`, `LEN`, `LENEXT`, `DIST`, `DISTEXT`, `MATCH`, `LIT` |
| Trailer/terminal | `CHECK`, `LENGTH`, `DONE`, `BAD`, `MEM`, `SYNC` |

Starts at value `16180` to aid in debugging state corruption.

### `inflate_state` Struct

Approximately 7KB of persistent state maintained between `inflate()` calls, organized into logical sub-sections:

- **Stream control** — `strm`, `mode`, `last`, `wrap`, `havedict`, `flags`, `dmax`
- **Integrity** — `check`, `total`, `head` (gzip header storage)
- **Sliding window** — `wbits`, `wsize`, `whave`, `wnext`, `window` (up to 32KB allocated separately)
- **Bit accumulator** — `hold`, `bits`
- **Copy state** — `length`, `offset`
- **Code tables** — `lencode`, `distcode`, `lenbits`, `distbits`
- **Dynamic table building** — `ncode`, `nlen`, `ndist`, `have`, `next`, `lens[320]`, `work[288]`, `codes[ENOUGH]`

## Usage Example

This header is **internal to zlib** and not intended for application use. Applications should only include `zlib.h`. Internal consumers access the state by casting the opaque stream pointer:

```c
/* Internal zlib usage only */
#include "inflate.h"

struct inflate_state FAR *state;
state = (struct inflate_state FAR *)strm->state;

/* Check current decompression mode */
if (state->mode == BAD) {
    /* handle data error */
}

/* Inspect sliding window parameters */
unsigned window_size = state->wsize;  /* 0 if windowing not active */
```

> **Note:** Compile with `NO_GZIP` defined to disable gzip header/trailer decoding and avoid linking CRC code when not needed. For shared libraries, leave gzip support enabled (default).
