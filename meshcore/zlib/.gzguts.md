Internal header defining shared types, constants, and macros used across zlib's `gz*` file operation implementations (`gzlib.c`, `gzread.c`, `gzwrite.c`).

## Key Components

### `gz_state` Structure
The core internal state for an open gzip file, containing:
- **`x` (`gzFile_s`)** — Exposed fields used by the `gzgetc()` macro (available bytes, next data pointer, current position)
- **Mode/descriptor fields** — `mode`, `fd`, `path`, `size`, `want`, `in`, `out`, `direct`
- **Read-specific** — `how`, `start`, `eof`, `past`
- **Write-specific** — `level`, `strategy`
- **Seek state** — `skip`, `seek`
- **Error state** — `err`, `msg`
- **Stream** — embedded `z_stream strm` (inflate/deflate engine)

```c
typedef gz_state FAR *gz_statep;  // pointer type used throughout gz* internals
```

### Mode Constants
```c
#define GZ_NONE   0
#define GZ_READ   7247
#define GZ_WRITE  31153
#define GZ_APPEND 1
```
Magic values provide a lightweight integrity check on the passed `gz_statep`.

### Processing Mode (`how`)
```c
#define LOOK 0   // scan for gzip header
#define COPY 1   // pass-through (no decompression)
#define GZIP 2   // decompress gzip stream
```

### Buffer Size
```c
#define GZBUFSIZE 8192  // default I/O buffer; doubled for read output / write input
```

### Error Utilities
```c
#define zstrerror() strerror(errno)          // POSIX
#define zstrerror() gz_strwinerror(...)      // Windows CE
void ZLIB_INTERNAL gz_error(gz_statep, int, const char *);
```

### Platform Portability Macros
- `ZLIB_INTERNAL` — marks symbols as hidden (GCC visibility)
- `local` — alias for `static` (non-linkage meaning) for debugger clarity
- `snprintf`/`vsnprintf` shims for MSVC, Turbo C, MS-DOS, VMS, and other legacy targets
- `WIDECHAR` defined on Windows/Cygwin for wide-character path support
- `GT_OFF(x)` — safely compares unsigned values against the signed `z_off64_t` maximum

## Usage Example

This header is for **internal zlib use only** and is not part of the public API. It is included at the top of each `gz*` implementation file:

```c
/* Inside gzread.c, gzwrite.c, gzlib.c */
#include "gzguts.h"

local int gz_load(gz_statep state, unsigned char *buf, unsigned len, unsigned *have) {
    /* state->fd, state->in, state->err all come from gz_state */
    if (state->mode != GZ_READ) {
        gz_error(state, Z_STREAM_ERROR, "not opened for reading");
        return -1;
    }
    /* ... */
}
```

> **Note:** Do not include `gzguts.h` in application code. Use the public `zlib.h` API (`gzopen`, `gzread`, `gzwrite`, etc.) instead.
