Configuration header for the zlib compression library that defines platform-specific types, macros, symbol prefixes, and compiler compatibility settings used across the zlib codebase.

## Key Components

### Symbol Prefixing (`Z_PREFIX`)
When compiled with `-DZ_PREFIX`, all public zlib symbols are remapped to `z_`-prefixed equivalents (e.g., `deflate` → `z_deflate`, `inflate` → `z_inflate`). This prevents naming conflicts when embedding zlib alongside other libraries.

### Platform Detection Macros
Normalizes platform identifiers across compilers and OSes:
- `MSDOS`, `OS2`, `WINDOWS`, `WIN32` — legacy and modern Windows targets
- `SYS16BIT` — 16-bit systems requiring `MAXSEG_64K` allocation limits
- `STDC` / `STDC99` — C standard compliance detection

### Type Definitions
- `z_size_t` — portable size type; maps to `size_t` (STDC), `unsigned long` (fallback), or custom (`NO_SIZE_T`)
- `z_const` — conditionally expands to `const` when `ZLIB_CONST` is defined

### Compression Parameters
- `MAX_MEM_LEVEL` — max `memLevel` for `deflateInit2`; defaults to `9` (or `8` on 16-bit systems)
- `MAX_WBITS` — max window size bits; defaults to `15` (32K LZ77 window)

### DLL / Calling Convention Support
- `ZLIB_DLL` — enables `__declspec(dllexport/dllimport)` on Windows
- `ZLIB_WINAPI` — switches export convention to `WINAPI`/`WINAPIV`
- `ZEXTERN`, `ZEXPORT`, `ZEXPORTVA` — portability macros for symbol visibility

### Function Prototype Macros
- `OF(args)` — expands to full prototype args on STDC, empty `()` otherwise
- `Z_ARG(args)` — same pattern for `stdarg`-style functions

## Usage Example

```c
/* Embed zlib without symbol conflicts */
#define Z_PREFIX
#include "zconf.h"
#include "zlib.h"

/* z_deflate, z_inflate, etc. are now used instead of deflate/inflate */

/* Tune memory usage for constrained environments */
/* Compile with: -DMAX_WBITS=14 -DMAX_MEM_LEVEL=7 */
/* Memory: (1 << (14+2)) + (1 << (7+9)) = 64K + 64K = 128K for deflate */

/* Enable const-correctness */
#define ZLIB_CONST
#include "zconf.h"
/* z_const expands to 'const' throughout the API */
```
