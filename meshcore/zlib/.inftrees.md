Internal header for zlib's Huffman decode table structures, used exclusively by `inflate.c` and `infback.c` to build and traverse prefix-code lookup tables.

## Key Components

### `code` struct
A four-byte entry in a Huffman decode table:

| Field | Type | Description |
|---|---|---|
| `op` | `unsigned char` | Operation type: literal, table link, length/distance, end-of-block, or invalid |
| `bits` | `unsigned char` | Number of bits consumed by this code entry |
| `val` | `unsigned short` | Output byte, base length/distance, or offset to next sub-table |

### `op` Bit Patterns

```text
00000000 - literal
0000tttt - table link (tttt = index bits in linked table)
0001eeee - length or distance (eeee = extra bits to read)
01100000 - end of block
01000000 - invalid code
```

### Constants

```c
#define ENOUGH_LENS  852   /* max literal/length table entries */
#define ENOUGH_DISTS 592   /* max distance table entries       */
#define ENOUGH       1444  /* total maximum table entries      */
```

### `codetype` enum
Selects which Huffman table `inflate_table()` builds:

```c
typedef enum { CODES, LENS, DISTS } codetype;
```

### `inflate_table()`
Builds a Huffman decode table from a set of code lengths:

```c
int inflate_table(codetype type, unsigned short *lens,
                  unsigned codes, code **table,
                  unsigned *bits, unsigned short *work);
```

## Usage Example

```c
/* Internal zlib usage only — not for application code */
code *next = fixed_len_table;
unsigned bits = 9;
unsigned short work[288];
unsigned short lens[288];

/* Build fixed literal/length decode table */
inflate_table(LENS, lens, 288, &next, &bits, work);
```

> **Warning:** This header is internal to zlib. Applications must use only `zlib.h`. Table sizes (`ENOUGH_LENS`, `ENOUGH_DISTS`) are computed via `examples/enough.c` and must be recalculated if root table sizes change.
