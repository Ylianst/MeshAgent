Internal zlib utility header providing shared type definitions, platform-specific configuration, memory management macros, and diagnostic helpers used exclusively by the zlib compression library internals.

## Key Components

### Type Aliases

| Type | Underlying Type | Purpose |
|------|----------------|---------|
| `uch` / `uchf` | `unsigned char` / FAR ptr | Byte-level data |
| `ush` / `ushf` | `unsigned short` / FAR ptr | Short integers |
| `ulg` | `unsigned long` | Long integers |

### Constants & Macros

| Macro | Value / Purpose |
|-------|----------------|
| `DEF_WBITS` | Default window bits for decompression (`MAX_WBITS`) |
| `DEF_MEM_LEVEL` | Default memory level (8) |
| `STORED_BLOCK` / `STATIC_TREES` / `DYN_TREES` | Block type identifiers (0, 1, 2) |
| `MIN_MATCH` / `MAX_MATCH` | Match length bounds (3 / 258) |
| `PRESET_DICT` | Preset dictionary flag (`0x20`) in zlib header |
| `OS_CODE` | Platform identifier (defaults to 3 = Unix) |
| `ZSWAP32(q)` | Reverses byte order in a 32-bit value |

### Error Handling

- `ERR_MSG(err)` — Looks up error string from `z_errmsg[]`
- `ERR_RETURN(strm, err)` — Sets stream message and returns error code

### Memory Management

- `ZALLOC(strm, items, size)` — Calls stream's custom allocator
- `ZFREE(strm, addr)` — Calls stream's custom free function
- `TRY_FREE(s, p)` — Conditionally frees if pointer is non-null
- `zmemcpy` / `zmemcmp` / `zmemzero` — Portable memory utilities (mapped to `memcpy`/`memcmp`/`memset` or custom implementations)
- `zcalloc` / `zcfree` — Internal allocator/free wrappers

### Diagnostic Macros (enabled via `ZLIB_DEBUG`)

- `Assert(cond, msg)` — Assertion with error output
- `Trace(x)` / `Tracev(x)` / `Tracevv(x)` — Verbosity-gated `fprintf` tracing
- `Tracec(c,x)` / `Tracecv(c,x)` — Conditional verbosity-gated tracing

## Usage Example

> ⚠️ This header is **internal to zlib only** — application code must use `zlib.h` instead.

```c
/* Internal zlib source file usage only */
#include "zutil.h"

/* Allocate a buffer using stream's allocator */
uchf *buf = (uchf *)ZALLOC(strm, 1024, sizeof(uch));

/* Zero-initialize the buffer */
zmemzero(buf, 1024);

/* Swap bytes in a 32-bit checksum */
ulg swapped = ZSWAP32(0x12345678); /* → 0x78563412 */

/* Free if non-null */
TRY_FREE(strm, buf);
```
