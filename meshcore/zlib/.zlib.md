The public C header for zlib 1.2.11, defining the complete interface for the general-purpose deflate/inflate compression library, including stream structures, constants, and function prototypes.

## Key Components

### Core Types
- **`z_stream`** — Central stream struct holding input/output buffer pointers (`next_in`, `next_out`), byte counts (`avail_in`, `avail_out`, `total_in`, `total_out`), custom allocators (`zalloc`, `zfree`), and Adler-32/CRC-32 checksum (`adler`)
- **`gz_header`** — gzip header metadata (filename, comment, modification time, OS, CRC flag)
- **`alloc_func` / `free_func`** — Custom memory allocator callback typedefs

### Constants

| Group | Key Values |
|---|---|
| Flush modes | `Z_NO_FLUSH`, `Z_SYNC_FLUSH`, `Z_FULL_FLUSH`, `Z_FINISH` |
| Return codes | `Z_OK (0)`, `Z_STREAM_END (1)`, `Z_STREAM_ERROR (-2)`, `Z_DATA_ERROR (-3)` |
| Compression levels | `Z_NO_COMPRESSION (0)`, `Z_BEST_SPEED (1)`, `Z_BEST_COMPRESSION (9)`, `Z_DEFAULT_COMPRESSION (-1)` |
| Strategies | `Z_DEFAULT_STRATEGY`, `Z_FILTERED`, `Z_HUFFMAN_ONLY`, `Z_RLE`, `Z_FIXED` |

### Key Functions
- **`zlibVersion()`** — Returns the runtime library version string for compatibility checks
- **`deflate()`** — Compresses data from `next_in` to `next_out` using the configured flush mode
- **`deflateInit()`** — Initializes a compression stream at a given level

## Usage Example

```c
#include "zlib.h"
#include <string.h>

int compress_data(const char *input, uLong input_len,
                  Bytef *output, uLong *output_len) {
    z_stream strm;

    /* Zero-initialize; zalloc/zfree/opaque set to Z_NULL uses malloc/free */
    strm.zalloc   = Z_NULL;
    strm.zfree    = Z_NULL;
    strm.opaque   = Z_NULL;
    strm.next_in  = (z_const Bytef *)input;
    strm.avail_in = input_len;

    int ret = deflateInit(&strm, Z_DEFAULT_COMPRESSION);
    if (ret != Z_OK) return ret;

    strm.next_out  = output;
    strm.avail_out = *output_len;

    ret = deflate(&strm, Z_FINISH);
    *output_len = strm.total_out;
    deflateEnd(&strm);

    return (ret == Z_STREAM_END) ? Z_OK : Z_STREAM_ERROR;
}
```

> **Version check:** Always verify `zlibVersion()[0] == ZLIB_VERSION[0]` at startup to catch incompatible library/header mismatches.
