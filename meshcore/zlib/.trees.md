## Usage Example

This header is included internally by `trees.c` when compiled without `-DGEN_TREES_H`. It is not meant to be included directly by application code.

```c
/* In trees.c, these tables are referenced directly: */
#include "trees.h"

/* Encode a literal/length symbol using the static tree */
int code = static_ltree[symbol].Code;
int len  = static_ltree[symbol].Len;

/* Resolve a raw distance to its DEFLATE slot */
int dist_slot = _dist_code[raw_dist];
int base      = base_dist[dist_slot];

/* Resolve a match length to its DEFLATE slot */
int len_slot = _length_code[match_len - MIN_MATCH];
int base_len = base_length[len_slot];
```
