Internal header defining the complete compression state for zlib's DEFLATE implementation. This file is **not intended for application use** — only the public `zlib.h` API should be consumed by end users.

## Key Components

### Constants & Macros

| Constant | Value | Purpose |
|---|---|---|
| `LENGTH_CODES` | 29 | Number of length codes (excluding END_BLOCK) |
| `LITERALS` | 256 | Literal byte count (0–255) |
| `L_CODES` | 286 | Total literal/length codes including END_BLOCK |
| `D_CODES` | 30 | Distance codes |
| `MAX_BITS` | 15 | Maximum Huffman code bit length |
| `HEAP_SIZE` | 573 | Maximum Huffman tree heap size |

### Stream State Codes

```text
INIT_STATE (42) → GZIP_STATE (57) → EXTRA_STATE (69) → NAME_STATE (73)
                                  → COMMENT_STATE (91) → HCRC_STATE (103)
                                                        → BUSY_STATE (113)
                                                        → FINISH_STATE (666)
```

### Core Types

- **`ct_data`** — Huffman tree node holding frequency/code and parent/length values via unions
- **`tree_desc`** — Descriptor linking a dynamic tree to its static counterpart and max code
- **`deflate_state`** — Primary internal state struct holding all LZ77 sliding window fields, hash chain tables, Huffman trees (`dyn_ltree`, `dyn_dtree`, `bl_tree`), bit buffer, and stream metadata

### Internal Tree Functions (from `trees.c`)

```c
void _tr_init(deflate_state *s);
int  _tr_tally(deflate_state *s, unsigned dist, unsigned lc);
void _tr_flush_block(deflate_state *s, charf *buf, ulg stored_len, int last);
void _tr_flush_bits(deflate_state *s);
void _tr_align(deflate_state *s);
void _tr_stored_block(deflate_state *s, charf *buf, ulg stored_len, int last);
```

### Key Utility Macros

```c
put_byte(s, c)     // Append byte to pending output buffer
MAX_DIST(s)        // Maximum LZ77 match distance for stream s
d_code(dist)       // Map distance value to distance code index
MIN_LOOKAHEAD      // Minimum window lookahead bytes (MAX_MATCH + MIN_MATCH + 1)
```

## Usage Example

This header is used internally by `deflate.c` and `trees.c` only:

```c
/* Internal usage pattern — not for application code */
#include "deflate.h"

void example_internal(deflate_state *s) {
    /* Append a byte to the pending output buffer */
    put_byte(s, 0x42);

    /* Check available lookahead before match search */
    if (s->lookahead < MIN_LOOKAHEAD) {
        fill_window(s);
    }

    /* Flush Huffman block via trees.c function */
    _tr_flush_block(s, NULL, 0L, 1 /* last */);
}
```

> **Warning:** Include `zlib.h` in application code. Direct use of `deflate.h` is unsupported and subject to breaking changes.
