Internal zlib header declaring the fast inflate path used during decompression. This file is part of the zlib library's private implementation and is **not intended for application use**.

## Key Components

| Symbol | Description |
|--------|-------------|
| `inflate_fast` | Core fast-path decompression function that processes stored, fixed, and dynamic Huffman-coded data in bulk for performance |
| `ZLIB_INTERNAL` | Visibility attribute restricting the symbol to internal library linkage |
| `OF((...))` | Portability macro expanding to a standard C prototype |

## Usage Example

```c
/* Internal zlib usage only — do not call from application code */
#include "inffast.h"

/* Called internally by inflate() when enough input/output buffer
   space is available to use the fast decoding loop */
void inflate_example(z_streamp strm, unsigned start) {
    inflate_fast(strm, start);
}
```

> **Warning:** Applications must never include or call `inffast.h` / `inflate_fast` directly. Always use the public API via `zlib.h`:

```c
#include <zlib.h>

/* Correct public usage */
z_stream strm = {0};
inflateInit(&strm);
inflate(&strm, Z_NO_FLUSH);
inflateEnd(&strm);
```

## Notes

- `start` parameter indicates the output position at the beginning of the inflate call, used for copy-distance bounds checking
- The implementation in `inffast.c` is subject to change between zlib releases
- See [`zlib.h`](https://github.com/flamingo-stack/meshagent/blob/main/zlib.h) for the stable public API
