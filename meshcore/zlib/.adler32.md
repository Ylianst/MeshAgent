Computes the Adler-32 checksum for data streams, part of the zlib compression library (Copyright 1995–2011, 2016 Mark Adler).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `adler32_z` | Function (exported) | Core checksum computation accepting `z_size_t` length |
| `adler32` | Function (exported) | Public API wrapper over `adler32_z` with `uInt` length |
| `adler32_combine_` | Function (local) | Internal logic to combine two Adler-32 checksums |
| `adler32_combine` | Function (exported) | Public combine API using `z_off_t` offset |
| `adler32_combine64` | Function (exported) | Public combine API using `z_off64_t` (64-bit offset) |
| `BASE` | Macro | Modulus value `65521` (largest prime below 65536) |
| `NMAX` | Macro | Max bytes (`5552`) processable before a modulo reduction is required |
| `DO1`–`DO16` | Macros | Loop-unrolled sum accumulators for performance |
| `MOD`, `MOD28`, `MOD63` | Macros | Modulo reduction, with optional no-divide variants via `NO_DIVIDE` |

## Usage Example

```c
#include "zlib.h"

/* Compute checksum of a buffer */
uLong checksum = adler32(0L, Z_NULL, 0);       /* initialize */
checksum = adler32(checksum, data, data_len);   /* process data */

/* Combine checksums of two contiguous segments */
uLong combined = adler32_combine(checksum_part1, checksum_part2, len_part2);
```

## Performance Notes

- Processes data in blocks of `NMAX` (5552) bytes, minimizing expensive modulo operations.
- Inner loops are unrolled 16× via `DO16` for throughput.
- Define `NO_DIVIDE` at compile time to replace hardware division with bit-shift approximations on processors lacking division instructions.
