Header file defining power state control actions and system information retrieval for the MeshAgent platform.

## Key Components

### Enum: `AgentPowerStateActions`

Enumerates all supported power and device state actions the agent can trigger:

| Value | Constant | Description |
|---|---|---|
| `0` | `POWERSTATE_NOP` | No operation |
| `1` | `POWERSTATE_LOGOFF` | Log off current user |
| `2` | `POWERSTATE_SHUTDOWN` | Shut down the system |
| `3` | `POWERSTATE_REBOOT` | Reboot the system |
| `4` | `POWERSTATE_SLEEP` | Put system to sleep |
| `5` | `POWERSTATE_HIBERNATE` | Hibernate the system |
| `6` | `POWERSTATE_DISPLAYON` | Turn display on |
| `7` | `POWERSTATE_KEEPAWAKE` | Prevent system sleep |
| `8` | `POWERSTATE_BEEP` | Emit a beep |
| `9` | `POWERSTATE_CTRLALTDEL` | Send Ctrl+Alt+Del |
| `13` | `POWERSTATE_VIBRATE` | Trigger device vibration |
| `14` | `POWERSTATE_FLASH` | Trigger device flash |

### Functions

- **`MeshInfo_GetSystemInformation(char** data)`** — Retrieves system information, writing it to the provided buffer pointer. Returns an integer status code.
- **`MeshInfo_PowerState(AgentPowerStateActions flg, int force)`** — Executes the specified power state action. The `force` parameter bypasses confirmation or graceful handling when non-zero.

## Usage Example

```c
#include "meshinfo.h"

// Retrieve system information
char *sysInfo = NULL;
int len = MeshInfo_GetSystemInformation(&sysInfo);

// Reboot the system (forced)
MeshInfo_PowerState(POWERSTATE_REBOOT, 1);

// Keep the display awake without forcing
MeshInfo_PowerState(POWERSTATE_KEEPAWAKE, 0);
```
