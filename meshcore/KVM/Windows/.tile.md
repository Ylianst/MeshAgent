Header file for Windows GDI+-based screen tile capture, providing functions to capture, compress, and manage desktop screen regions (tiles) for remote desktop/KVM functionality.

## Key Components

### Structs

- **`tileInfo_t`** — Tracks tile state with a CRC checksum (`int crc`) and a `flags` byte indicating the tile's current processing status.

### Enums

- **`TILE_FLAGS_ENUM`** — Tile lifecycle states:
  - `TILE_TODO` — CRC not yet calculated
  - `TILE_SENT` — CRC calculated, tile transmitted
  - `TILE_MARKED_NOT_SENT` — CRC calculated, tile not transmitted
  - `TILE_DONT_SEND` — CRC calculated, transmission not required

### Functions

| Function | Description |
|---|---|
| `initialize_gdiplus()` | Initializes the GDI+ subsystem; returns status code |
| `teardown_gdiplus()` | Shuts down GDI+ and frees resources |
| `get_tile_at(x, y, buffer, bufferSize, desktop, row, col)` | Captures a compressed tile at grid position `(row, col)` / pixel position `(x, y)` |
| `get_desktop_buffer(buffer, bufferSize, ...)` | Captures the full desktop into a raw buffer |
| `get_bmp_info(width, height)` | Returns a `BITMAPINFO` descriptor for given dimensions |
| `set_tile_compression(type, level)` | Configures compression algorithm and quality level |
| `switch_to_desktop_context()` | Switches thread/session context to the active desktop |

## Usage Example

```c
// Initialize GDI+ before capturing
if (initialize_gdiplus() != 0) { /* handle error */ }

// Configure compression
set_tile_compression(COMPRESSION_TYPE_JPEG, 75);

// Switch to the active desktop session
switch_to_desktop_context();

// Capture a single tile at grid position (row=0, col=0)
void *tileBuffer = NULL;
long long tileSize = 0;
get_tile_at(0, 0, &tileBuffer, &tileSize, desktopHandle, 0, 0);

// Cleanup
teardown_gdiplus();
```

> **Note:** This header is conditionally compiled only when `_LINKVM` is defined and targets **Windows only** (requires `<Windows.h>`). It is part of the KVM/remote desktop subsystem within [meshagent](https://github.com/flamingo-stack/meshagent).
