Header file defining the KVM (Keyboard, Video, Mouse) input control interface for remote desktop functionality within the MeshAgent `_LINKVM` subsystem.

## Key Components

### `KVM_MouseCursors` Enum

Enumerates all supported remote mouse cursor states, including:

| Value | Description |
|---|---|
| `KVM_MouseCursor_NOCHANGE` (`-1`) | No cursor change requested |
| `KVM_MouseCursor_ARROW` (`0`) | Standard pointer |
| `KVM_MouseCursor_HAND` (`3`) | Clickable element cursor |
| `KVM_MouseCursor_WAIT` (`13`) | Busy/loading cursor |
| `KVM_MouseCursor_NONE` (`14`) | Hidden cursor |
| `KVM_MouseCursor_NOTALLOWED` (`15`) | Restricted action cursor |
| `KVM_MouseCursor_COL_RESIZE` (`16`) | Column resize cursor |

### Functions

| Function | Description |
|---|---|
| `KVM_InitMouseCursors(void*)` | Initializes mouse cursor state with a pending packets buffer |
| `KVM_UnInitMouseCursors()` | Tears down cursor resources |
| `MouseAction(double, double, int, short)` | Sends a mouse event with absolute coordinates, button state, and scroll wheel delta |
| `KeyAction(unsigned char, int)` | Sends a keycode press or release event |
| `KeyActionUnicode(WORD, int)` | Sends a Unicode character key event |
| `TouchInit()` / `TouchUnInit()` | Initializes and tears down touch input support |
| `TouchAction1(...)` | Sends a single touch point event by ID, flags, and coordinates |
| `TouchAction2(char*, int, int)` | Sends a batch touch event from raw data with scaling |

## Usage Example

```c
#if defined(_LINKVM)

// Initialize cursor tracking with an outbound packet queue
KVM_InitMouseCursors(pendingPackets);

// Move mouse to absolute position (50%, 50%) and left-click
MouseAction(0.5, 0.5, 1, 0);

// Send key press and release for a scancode
KeyAction(0x41, 0); // Key down
KeyAction(0x41, 1); // Key up

// Send a Unicode character
KeyActionUnicode(L'A', 0);
KeyActionUnicode(L'A', 1);

// Cleanup
KVM_UnInitMouseCursors();

#endif
```

## Notes

- All declarations are conditionally compiled under `#if defined(_LINKVM)`, meaning this interface is only active when KVM remote control support is enabled at build time.
