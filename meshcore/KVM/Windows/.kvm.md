Conditional header for KVM (Keyboard-Video-Mouse) relay functionality, compiled only when the `_LINKVM` preprocessor symbol is defined.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibKVM_WriteHandler` | `typedef` | Callback function pointer invoked when KVM data is ready to be written; returns an `ILibTransport_DoneState` |
| `kvm_relay_setup` | Function | Initializes the KVM relay session with the executable path, pipe manager, write handler, and session ID |
| `kvm_relay_feeddata` | Function | Feeds incoming raw data into the KVM relay pipeline for processing |
| `kvm_relay_reset` | Function | Resets the relay state, re-registering the write handler and reserved context |
| `kvm_pause` | Function | Pauses or resumes KVM streaming (`pause = 1` to pause, `0` to resume) |
| `kvm_cleanup` | Function | Tears down and releases all KVM relay resources |
| `kvm_setupSasPermissions` | Function | Configures Secure Attention Sequence (SAS) permissions required for remote desktop interaction on Windows |

## Usage Example

```c
#define _LINKVM
#include "kvm.h"

// Write handler callback
ILibTransport_DoneState my_write_handler(char *buffer, int bufferLen, void *reserved) {
    // Send buffer over transport
    return ILibTransport_DoneState_Complete;
}

// Initialize KVM relay
kvm_relay_setup("/usr/bin/meshagent", pipeMgr, my_write_handler, NULL, sessionId);

// Configure SAS permissions (Windows remote desktop)
kvm_setupSasPermissions();

// Feed incoming data from the remote client
kvm_relay_feeddata(incomingBuf, incomingLen, my_write_handler, NULL);

// Pause streaming temporarily
kvm_pause(1);

// Resume and eventually clean up
kvm_pause(0);
kvm_cleanup();
```

## Notes

- The entire header is gated behind `#ifdef _LINKVM`; define this symbol at compile time to enable KVM support.
- Part of the [MeshAgent](https://github.com/flamingo-stack/meshagent) remote management agent.
- Depends on `microstack/ILibParsers.h` for transport state types.
