Header file defining the Linux KVM (Keyboard/Video/Mouse) relay interface for X11-based remote desktop capture and control within the MeshAgent platform.

## Key Components

### Type Definition

- **`ILibKVM_WriteHandler`** — Function pointer type for write completion callbacks. Signature: `ILibTransport_DoneState(*)(char *buffer, int bufferLen, void *reserved)`

### Public Functions

| Function | Description |
|---|---|
| `kvm_set_x11_locations` | Configures dynamic library paths for X11 dependencies (`libX11`, `libXtst`, `libXext`, `libXfixes`, `libX11-kb`) |
| `kvm_relay_setup` | Initializes the KVM relay session; returns a session handle. Accepts a pipe manager, write handler callback, user ID, auth token, and display ID |
| `kvm_relay_feeddata` | Feeds incoming remote control data (keyboard/mouse events) into the relay pipeline |
| `kvm_relay_reset` | Resets the relay state for the given session |
| `kvm_pause` | Pauses or resumes KVM capture/streaming |
| `kvm_cleanup` | Releases all KVM resources and shuts down the relay |

### Dependencies

- **X11** (`Xlib.h`, `Xutil.h`) — Display and window management
- **`linux_tile.h`** — Screen tiling/capture logic
- **`linux_events.h`** — Input event handling
- **`ILibParsers.h`** — MeshAgent microstack transport utilities
- FreeBSD compatibility guard (`#ifndef _FREEBSD`) skips Linux-specific `linux/stat.h`

## Usage Example

```c
#include "linux_kvm.h"

ILibTransport_DoneState my_write_handler(char *buffer, int bufferLen, void *reserved) {
    // Send buffer to remote client
    return ILibTransport_DoneState_Complete;
}

// Configure X11 library paths
kvm_set_x11_locations("/usr/lib/libX11.so", "/usr/lib/libXtst.so",
                      "/usr/lib/libXext.so", "/usr/lib/libXfixes.so",
                      "/usr/lib/libxkbfile.so");

// Start KVM relay session
void *session = kvm_relay_setup(pipeMgr, my_write_handler, NULL, 1000, "authtoken", ":0");

// Feed incoming input data
kvm_relay_feeddata(inputBuf, inputLen);

// Teardown
kvm_cleanup();
```
