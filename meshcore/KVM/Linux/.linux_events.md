Header defining X11/XTest/XKB dynamic library bindings and Windows-compatible virtual key code constants for Linux input event simulation in the MeshAgent remote control subsystem.

## Key Components

### Structs

| Struct | Purpose |
|---|---|
| `x11_struct` | Function pointer table for dynamically loaded `libX11` — display open/close, event polling, keyboard mapping, window attributes |
| `x11tst_struct` | Function pointer table for dynamically loaded `libXtst` — synthetic mouse motion, button, and key injection via XTest |
| `xkb_struct` | Function pointer table for dynamically loaded `libxkb` — keyboard state query, modifier lock, and event selection |

### Global Exports

- `x11tst_exports` — runtime-resolved XTest function pointers
- `xkb_exports` — runtime-resolved XKB function pointers

### Enums & Defines

- `MOUSE_EVENTS` — bitmask constants for left/right/middle button press and release events
- `VK_*` defines — full Windows virtual key code mapping (`0x01`–`0xBD`+) covering mouse buttons, alphanumeric keys, function keys F1–F24, numpad, navigation, IME, and media keys

## Usage Example

```c
#include "linux_events.h"

// Simulate a left mouse click using XTest bindings
void simulate_click(Display *d, int x, int y) {
    x11tst_exports->XTestFakeMotionEvent(d, -1, x, y, 0);
    x11tst_exports->XTestFakeButtonEvent(d, Button1, True, 0);
    x11tst_exports->XTestFakeButtonEvent(d, Button1, False, 0);
    x11tst_exports->XFlush(d);
}

// Simulate pressing the Enter key using a VK code
void simulate_enter(Display *d) {
    KeyCode kc = x11tst_exports->XKeysymToKeycode(d, XK_Return);
    x11tst_exports->XTestFakeKeyEvent(d, kc, True, 0);
    x11tst_exports->XTestFakeKeyEvent(d, kc, False, 0);
    x11tst_exports->XFlush(d);
}
```
