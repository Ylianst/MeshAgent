Header file providing JPEG image compression utilities for Linux (and macOS) platforms, wrapping the libjpeg/libjpeg-turbo library with a simplified buffer-based API.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MAX_BUFFER` | Macro | Maximum output buffer size (22,528 bytes / 22 KiB) |
| `JPEG_error_handler` | `typedef` | Function pointer type for custom JPEG error callbacks — signature: `void fn(char *msg)` |
| `write_JPEG_buffer` | Function | Compresses a raw image into a JPEG byte buffer |
| `default_JPEG_error_handler` | Variable | Default error handler instance; can be replaced with a custom handler |

### Platform Handling
Automatically selects the correct libjpeg headers at compile time:
- **macOS (`__APPLE__`)** — uses bundled `lib-jpeg-turbo` headers
- **Linux** — uses system-installed `<jpeglib.h>` / `<jerror.h>`

## Usage Example

```c
#include "linux_compression.h"

// Optional: install a custom error handler
void my_error_handler(char *msg) {
    fprintf(stderr, "JPEG error: %s\n", msg);
}

int main(void) {
    // Raw RGB image data (width × height × 3 channels)
    JSAMPLE image_buffer[640 * 480 * 3];

    // populate image_buffer with pixel data ...

    default_JPEG_error_handler = my_error_handler;

    int bytes_written = write_JPEG_buffer(
        image_buffer,
        640,   // image_width
        480,   // image_height
        85     // quality (1-100)
    );

    if (bytes_written > 0) {
        // Compressed JPEG data is now available;
        // bytes_written indicates the output size (≤ MAX_BUFFER)
    }
    return 0;
}
```

> **Note:** The output buffer is capped at `MAX_BUFFER` (22 KiB). Choose quality levels accordingly for larger images to avoid truncation.
