Header file defining the tile-based screen capture and comparison interface for Linux remote desktop functionality, used in the MeshAgent's KVM/screen sharing subsystem.

## Key Components

### Enum: `TILE_FLAGS_ENUM`

Tracks the processing state of each screen tile:

| Flag | Description |
|---|---|
| `TILE_TODO` | Tile CRC not yet calculated |
| `TILE_SENT` | CRC calculated; tile transmitted |
| `TILE_MARKED_NOT_SENT` | CRC calculated; tile not transmitted |
| `TILE_DONT_SEND` | CRC calculated; transmission not required |

### Struct: `tileInfo_t`

Holds per-tile metadata:

```c
struct tileInfo_t {
    int crc;                    // Computed CRC for change detection
    enum TILE_FLAGS_ENUM flag;  // Current tile processing state
};
```

### Exported Functions

| Function | Description |
|---|---|
| `reset_tile_info(old_height_count)` | Resets tile state tracking for a given tile row count |
| `adjust_screen_size(pixels)` | Recalculates tile grid on screen resolution change |
| `getTileAt(x, y, buffer, bufferSize, desktop, desktopsize, row, col)` | Extracts and encodes a single tile at the specified grid position |
| `getScreenBuffer(desktop, desktopsize, image)` | Captures the full screen into a buffer from an `XImage` |
| `set_tile_compression(type, level)` | Configures compression algorithm and level for tile encoding |

## Usage Example

```c
#include "linux_tile.h"

char *desktop = NULL;
long long desktopsize = 0;
XImage *image = /* acquire via XGetImage */;

// Configure compression
set_tile_compression(COMPRESSION_ZLIB, 6);

// Capture the full screen
getScreenBuffer(&desktop, &desktopsize, image);

// Extract a specific tile
void *tileBuffer = NULL;
long long tileSize = 0;
getTileAt(0, 0, &tileBuffer, &tileSize, desktop, desktopsize, 0, 0);
```
