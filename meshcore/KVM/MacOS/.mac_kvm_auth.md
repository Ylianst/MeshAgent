macOS-only header for KVM socket peer authentication via Apple's Code Signing framework, ensuring only legitimate meshagent binaries can connect.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `verify_peer_codesign` | Function | Verifies the process connected to a socket fd is a valid meshagent binary |
| `get_self_code` | Function | Retrieves the calling process's own `SecCodeRef` for signature comparison |
| `codesign_matches` | Function | Compares two `SecCodeRef` handles to confirm they represent the same binary |
| `CODESIGNING_APIS_DECLARED` | Guard macro | Forward-declares `SecCodeCreateWithPID` for older SDK compatibility |

All declarations are wrapped in `#ifdef __APPLE__` and are no-ops on non-Apple platforms.

## Usage Example

```c
#ifdef __APPLE__
#include "mac_kvm_auth.h"

int accept_kvm_connection(int server_fd) {
    int client_fd = accept(server_fd, NULL, NULL);
    if (client_fd < 0) return -1;

    // Reject connections from non-meshagent processes
    if (!verify_peer_codesign(client_fd)) {
        close(client_fd);
        return -1;
    }

    return client_fd; // Trusted connection
}

// Manual signature comparison (optional lower-level usage)
void check_signatures(void) {
    SecCodeRef self = get_self_code();  // Caller must CFRelease
    SecCodeRef peer = /* obtain from peer PID */;

    if (codesign_matches(self, peer)) {
        // Same binary — proceed
    }

    CFRelease(self);
}
#endif
```

## Notes

- Entire API is **macOS-only**; guard all call sites with `#ifdef __APPLE__`.
- `get_self_code` returns a `SecCodeRef` — the **caller is responsible for `CFRelease`**.
- Depends on the **Security** framework (`-framework Security` linker flag).
