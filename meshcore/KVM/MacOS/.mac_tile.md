Header file for macOS screen tile management used in remote desktop capture operations, defining tile state tracking and screen buffer utilities via Carbon framework integration.

## Key Components

### Enum: `TILE_FLAGS_ENUM`
Tracks the processing state of each screen tile:

| Flag | Description |
|---|---|
| `TILE_TODO` | Tile CRC not yet calculated |
| `TILE_SENT` | CRC calculated and tile transmitted |
| `TILE_MARKED_NOT_SENT` | CRC calculated, tile not transmitted |
| `TILE_DONT_SEND` | CRC calculated, transmission not required |

### Struct: `tileInfo_t`
Holds per-tile metadata:
- `crc` — Checksum used for change detection
- `flag` — Current tile state from `TILE_FLAGS_ENUM`

### Exported Functions

| Function | Description |
|---|---|
| `reset_tile_info(old_height_count)` | Resets tile state array for a given row count |
| `adjust_screen_size(pixels)` | Recalculates tile grid based on new screen dimensions |
| `getTileAt(x, y, ...)` | Extracts and compresses a single tile from the desktop buffer |
| `getScreenBuffer(desktop, desktopsize, image)` | Populates a raw screen buffer from a `CGImageRef` |
| `set_tile_compression(type, level)` | Configures compression algorithm and level for tile encoding |

## Usage Example

```c
#include "mac_tile.h"

unsigned char *desktop = NULL;
long long desktopSize = 0;
void *tileBuf = NULL;
long long tileSize = 0;

// Capture screen into buffer
CGImageRef img = CGDisplayCreateImage(kCGDirectMainDisplay);
getScreenBuffer(&desktop, &desktopSize, img);

// Configure compression and extract a tile
set_tile_compression(1, 6);
getTileAt(0, 0, &tileBuf, &tileSize, desktop, desktopSize, 0, 0);
```

> **Note:** Depends on the macOS Carbon framework (`CGImageRef`) and shares compression utilities with the Linux sibling module at `../Linux/linux_compression.h`.
