macOS input event definitions and virtual key code mappings for the MeshAgent remote desktop/KVM subsystem, providing a Windows-compatible `VK_*` keycode interface over macOS Carbon APIs.

## Key Components

### Enums

- **`MOUSE_EVENTS`** — Mouse button event flags (down/up) for left, right, and middle buttons, matching Windows `MOUSEEVENTF_*` values

### Defines

- **`VK_*` Virtual Key Codes** — Full set of Windows-compatible virtual key constants (`0x01`–`0xFE`) covering:
  - Mouse buttons (`VK_LBUTTON`, `VK_RBUTTON`, `VK_MBUTTON`)
  - Control keys (`VK_SHIFT`, `VK_CONTROL`, `VK_MENU`, `VK_ESCAPE`, etc.)
  - Alphanumeric keys (`VK_A`–`VK_Z`, `VK_0`–`VK_9`)
  - Function keys (`VK_F1`–`VK_F24`)
  - Numpad keys (`VK_NUMPAD0`–`VK_NUMPAD9`, arithmetic operators)
  - Media/browser keys (`VK_VOLUME_UP`, `VK_BROWSER_BACK`, etc.)
  - OEM/punctuation keys (`VK_OEM_1`–`VK_OEM_CLEAR`)
  - IME keys (`VK_KANA`, `VK_HANGUL`, `VK_KANJI`, etc.)

### Structs

- **`keymap_t`** — Maps a platform keycode (`unsigned int`) to a Windows virtual key byte (`unsigned char vk`)

### Extern Functions

- **`MouseAction(double absX, double absY, int button, short wheel)`** — Synthesizes a macOS mouse event at absolute screen coordinates
- **`KeyAction(unsigned char vk, int up)`** — Synthesizes a key press/release event from a `VK_*` code
- **`KeyActionUnicode(uint16_t unicode, int up)`** — Synthesizes a key event from a raw Unicode code point

## Usage Example

```c
#include "mac_events.h"

// Move mouse and left-click at (800, 600)
MouseAction(800.0, 600.0, MOUSEEVENTF_LEFTDOWN, 0);
MouseAction(800.0, 600.0, MOUSEEVENTF_LEFTUP, 0);

// Press and release the 'A' key
KeyAction(VK_A, 0); // key down
KeyAction(VK_A, 1); // key up

// Send a Unicode character (e.g., é = U+00E9)
KeyActionUnicode(0x00E9, 0);
KeyActionUnicode(0x00E9, 1);
```
