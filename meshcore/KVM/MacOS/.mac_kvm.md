Header file defining the KVM (Keyboard/Video/Mouse) session management interface for macOS, providing function declarations for creating, managing, and relaying KVM sessions used in remote desktop functionality.

## Key Components

### Type Definition
- **`ILibKVM_WriteHandler`** — Function pointer typedef for a write handler callback, accepting a buffer, length, and reserved pointer; returns an `ILibTransport_DoneState`.

### Function Declarations

| Function | Description |
|---|---|
| `kvm_check_permission()` | Verifies required macOS accessibility/screen recording permissions |
| `kvm_create_session()` | Creates a KVM session on-demand (directory, signal file, and socket) |
| `kvm_cleanup_session()` | Cleans up the KVM session, triggering `-kvm1` exit |
| `kvm_pause()` | Pauses or resumes the KVM stream |
| `kvm_relay_setup()` | Initializes the KVM relay with process pipe manager and write handler |
| `kvm_relay_reset()` | Resets the KVM relay state |
| `kvm_cleanup()` | Performs full KVM resource cleanup |

## Usage Example

```c
#include "mac_kvm.h"

// Check permissions before starting
kvm_check_permission();

// Create a KVM session
kvm_create_session("MyCompany", "MeshService", "serviceID", "/path/to/exe");

// Set up relay with a write handler callback
ILibKVM_WriteHandler myWriteHandler = my_write_callback;
void *relay = kvm_relay_setup("/path/to/exe", pipeMgr, myWriteHandler, NULL, uid,
                               "MyCompany", "MeshService", "serviceID");

// Pause the KVM stream
kvm_pause(1);

// Cleanup when done
kvm_cleanup_session();
kvm_cleanup();
```
