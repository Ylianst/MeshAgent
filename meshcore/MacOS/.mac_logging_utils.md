Shared logging utility header for macOS components, providing dual-output logging to both `stderr` and a log file to aid troubleshooting of installation and upgrade issues.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MESH_LOG_FILE` | Macro | Log file path: `/tmp/meshagent-install-ui.log` |
| `mesh_log_message` | Function | Logs a `printf`-style formatted message to both `stderr` and `MESH_LOG_FILE` |

## Usage Example

```c
#include "mac_logging_utils.h"

int main(void) {
    mesh_log_message("Starting installation for version %s", "1.2.3");
    mesh_log_message("Install path: %s", "/usr/local/bin/meshagent");

    int result = run_install();
    if (result != 0) {
        mesh_log_message("Installation failed with code %d", result);
        return 1;
    }

    mesh_log_message("Installation completed successfully");
    return 0;
}
```

Output is written simultaneously to `stderr` (for live feedback) and `/tmp/meshagent-install-ui.log` (for post-mortem diagnostics).

## Notes

- The log file location `MESH_LOG_FILE` is fixed at `/tmp/meshagent-install-ui.log` and is suitable for ephemeral install-time logging.
- Accepts variadic `printf`-style format strings, so no additional string formatting is needed before calling.
- Source: [`mac_logging_utils.h`](https://github.com/flamingo-stack/meshagent/blob/main/mac_logging_utils.h)
