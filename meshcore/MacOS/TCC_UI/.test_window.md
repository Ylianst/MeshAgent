A minimal test driver for the macOS TCC permissions window, used to manually verify that `show_tcc_permissions_window()` launches correctly and returns the expected result codes.

## Key Components

| Symbol | Description |
|--------|-------------|
| `main()` | Entry point that invokes the TCC permissions window and prints the user's response to stdout |

**Dependencies:**
- `mac_permissions_window.h` — declares `show_tcc_permissions_window()`

**Return codes handled:**

| Code | Meaning |
|------|---------|
| `1` | User selected "Do not remind me again" |
| other | User closed the window normally |

## Usage Example

Build and run directly from the terminal to smoke-test the permissions dialog:

```bash
# Compile (macOS only)
gcc test_window.c mac_permissions_window.c -o test_window \
    -framework Cocoa

# Run
./test_window
```

Expected output (normal close):

```text
Launching TCC Permissions Window...
User closed window normally
```

Expected output (suppressed):

```text
Launching TCC Permissions Window...
User selected: Do not remind me again
```

> **Note:** This file is a development utility and is not intended for production use. See the full source at [`test_window.c`](https://github.com/flamingo-stack/meshagent/blob/main/test_window.c).
