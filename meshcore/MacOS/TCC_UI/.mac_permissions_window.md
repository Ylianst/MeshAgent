Header file declaring the macOS TCC (Transparency, Consent, and Control) permissions window interface for the MeshAgent daemon, providing both synchronous and asynchronous variants for displaying required system permission prompts.

## Key Components

| Function | Description |
|---|---|
| `show_tcc_permissions_window` | Synchronous/modal display of the TCC permissions UI |
| `show_tcc_permissions_window_async` | Non-blocking variant that spawns a child process |

### `show_tcc_permissions_window(int show_reminder_checkbox)`

Displays a modal window prompting the user to grant three required TCC permissions:

- **Accessibility**
- **Full Disk Access**
- **Screen & System Audio Recording**

The `show_reminder_checkbox` flag controls whether a "Do not remind me again" option is presented (pass `0` when triggered by an explicit `SHIFT+click`).

**Returns:** `0` on "Finish", `1` if the user opted out of future reminders.

### `show_tcc_permissions_window_async(const char* exe_path, void* pipeManager, int uid)`

Spawns the meshagent executable as a child process with the `-tccCheck` flag using `ILibProcessPipe_Manager_SpawnProcessEx3`. The child writes the reminder preference (`0` or `1`) to stdout on close.

**Returns:** A file descriptor (stdout pipe read end) for reading the result, or `-1` on failure.

## Usage Example

```c
#include "mac_permissions_window.h"

/* Synchronous — block until user dismisses */
int result = show_tcc_permissions_window(1 /* show checkbox */);
if (result == 1) {
    /* User opted out of future reminders */
}

/* Asynchronous — non-blocking, reads result from fd later */
int fd = show_tcc_permissions_window_async(
    "/usr/local/bin/meshagent",
    pipeManager,
    501 /* uid */
);
if (fd < 0) {
    /* Spawn failed or UI already running */
}
/* Read reminder preference from fd when ready */
```

> **Platform note:** This header is macOS-only and guarded by `#ifdef __cplusplus` for C++ compatibility. See the implementation in the [meshagent repository](https://github.com/flamingo-stack/meshagent).
