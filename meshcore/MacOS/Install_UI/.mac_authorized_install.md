Declares the C interface for executing MeshAgent install and upgrade operations on macOS using native Authorization Services for privileged execution.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ProgressCallback` | Block typedef | Callback block receiving a `const char* line` for streaming install/upgrade output |
| `set_progress_callback` | Function | Registers (or clears with `NULL`) the active `ProgressCallback` block |
| `execute_meshagent_install` | Function | Runs `meshagent -install` with admin privileges via macOS Authorization Services |
| `execute_meshagent_upgrade` | Function | Runs `meshagent -upgrade` with admin privileges via macOS Authorization Services |
| `read_existing_update_setting` | Function | Reads the current `disableUpdate` setting from an existing installation (checks `.msh` → `meshagent.db` → default enabled) |

## Usage Example

```c
#include "mac_authorized_install.h"
#include <stdio.h>

int main(void) {
    // Register a progress callback to stream output lines
    set_progress_callback(^(const char* line) {
        printf("[meshagent] %s\n", line);
    });

    // Install meshagent with updates enabled
    int result = execute_meshagent_install(
        "/usr/local/mesh/",
        "/tmp/config.msh",
        1  // enableDisableUpdate: 1 = enabled
    );

    if (result != 0) {
        fprintf(stderr, "Install failed: %d\n", result);
        return result;
    }

    // Check update setting of an existing install before upgrading
    int updateEnabled = read_existing_update_setting("/usr/local/mesh/");
    if (updateEnabled < 0) {
        fprintf(stderr, "Could not read update setting\n");
        return 1;
    }

    // Upgrade using the previously read update setting
    return execute_meshagent_upgrade("/usr/local/mesh/", updateEnabled);
}
```

## Notes

- This header is C++ compatible via the `extern "C"` guard.
- `ProgressCallback` uses an Objective-C **block** (`^`), requiring a clang compiler with blocks support (standard on macOS).
- `execute_meshagent_install` and `execute_meshagent_upgrade` trigger the native macOS authentication dialog; the calling process does **not** need to run as root.
- Return values follow Unix convention: `0` = success, non-zero = failure.
