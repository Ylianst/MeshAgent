Header file defining the interface for the macOS MeshAgent Installation Assistant GUI window, providing types and a function to collect installation configuration from the user.

## Key Components

### Enums

- **`InstallMode`** — Selects between two installation workflows:
  - `INSTALL_MODE_UPGRADE` (`0`) — Upgrade an existing MeshAgent installation
  - `INSTALL_MODE_NEW` (`1`) — Perform a fresh installation

### Structs

- **`InstallResult`** — Captures all user selections from the installation dialog:

| Field | Type | Description |
|---|---|---|
| `mode` | `InstallMode` | Selected installation mode |
| `installPath` | `char[1024]` | Target install directory |
| `mshFilePath` | `char[1024]` | Path to the `.msh` configuration file |
| `enableDisableUpdate` | `int` | `1` to enable auto-update, `0` to disable |
| `cancelled` | `int` | `1` if user cancelled, `0` if user confirmed |

### Functions

- **`show_install_assistant_window(void)`** — Displays the modal installation assistant window and returns an `InstallResult` with the user's selections. Compatible with both C and C++ via `extern "C"` linkage guards.

## Usage Example

```c
#include "mac_install_window.h"
#include <stdio.h>

int main(void) {
    InstallResult result = show_install_assistant_window();

    if (result.cancelled) {
        printf("Installation cancelled by user.\n");
        return 0;
    }

    if (result.mode == INSTALL_MODE_NEW) {
        printf("New install to: %s\n", result.installPath);
        printf("Using .msh file: %s\n", result.mshFilePath);
    } else {
        printf("Upgrading existing install at: %s\n", result.installPath);
    }

    printf("Auto-update enabled: %d\n", result.enableDisableUpdate);
    return 0;
}
```
