Provides shared CoreFoundation-based utilities for securely parsing macOS LaunchDaemon plist files to extract meshagent configuration data, avoiding shell injection risks.

## Key Components

### `MeshPlistInfo` struct
Holds parsed plist data including:

| Field | Type | Description |
|---|---|---|
| `plistPath` | `char[1024]` | Path to the plist file |
| `label` | `char[256]` | Plist `Label` value |
| `programPath` | `char[1024]` | First entry in `ProgramArguments` |
| `hasDisableUpdate` | `int` | `1` if `--disableUpdate=1` found in args |
| `modTime` | `time_t` | File modification timestamp |

### Functions

| Function | Returns | Description |
|---|---|---|
| `mesh_parse_launchdaemon_plist()` | `int` | Parses a full plist, populates `MeshPlistInfo`; returns `1` on success |
| `mesh_plist_get_label()` | `char*` | Extracts the `Label` string (caller must `free()`) |
| `mesh_plist_get_program_path()` | `char*` | Extracts first `ProgramArguments` path (caller must `free()`) |
| `mesh_plist_has_argument()` | `int` | Checks for a specific argument in `ProgramArguments`; returns `1` if found |

## Usage Example

```c
#include "mac_plist_utils.h"
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    const char* plistPath = "/Library/LaunchDaemons/meshagent.plist";
    MeshPlistInfo info;

    // Parse full plist into struct
    if (mesh_parse_launchdaemon_plist(plistPath, &info)) {
        printf("Label:   %s\n", info.label);
        printf("Program: %s\n", info.programPath);
        printf("Updates disabled: %s\n", info.hasDisableUpdate ? "yes" : "no");
    }

    // Check for a specific argument
    if (mesh_plist_has_argument(plistPath, "--disableUpdate=1")) {
        printf("Update flag detected\n");
    }

    // Retrieve label independently (caller must free)
    char* label = mesh_plist_get_label(plistPath);
    if (label) {
        printf("Label: %s\n", label);
        free(label);
    }

    return 0;
}
```

## Notes

- All parsing uses CoreFoundation APIs — **no shell invocation**, no injection risk.
- `mesh_plist_get_label()` and `mesh_plist_get_program_path()` return heap-allocated strings; always call `free()` on the result.
- Source: [`mac_plist_utils.h`](https://github.com/flamingo-stack/meshagent/blob/main/mac_plist_utils.h)
