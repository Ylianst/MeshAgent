Declares a shared UI helper for macOS that provides consistent label creation utilities used across TCC permissions and installation assistant windows.

## Key Components

### `mesh_createLabel`

```c
NSTextField* mesh_createLabel(NSString* text, NSRect frame, BOOL bold);
```

Creates a non-editable, non-selectable `NSTextField` label with standardized styling:

| Parameter | Type | Description |
|-----------|------|-------------|
| `text` | `NSString*` | Display text for the label |
| `frame` | `NSRect` | Position and size of the label |
| `bold` | `BOOL` | `YES` for 13pt bold system font; `NO` for 12pt system font with secondary label color |

## Usage Example

```c
#import "mac_ui_helpers.h"

// Bold section header
NSTextField* header = mesh_createLabel(
    @"Required Permissions",
    NSMakeRect(20, 200, 300, 20),
    YES
);
[parentView addSubview:header];

// Regular descriptive label (gray, 12pt)
NSTextField* description = mesh_createLabel(
    @"Allow access to continue installation.",
    NSMakeRect(20, 175, 300, 16),
    NO
);
[parentView addSubview:description];
```

## Notes

- Returns an **autoreleased** `NSTextField` — retain if needed beyond the current autorelease pool
- Intended for internal use across MeshAgent's macOS UI surfaces (TCC permissions dialogs, installation assistant windows)
