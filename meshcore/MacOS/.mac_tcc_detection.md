Checks and reports the status of macOS Transparency, Consent, and Control (TCC) permissions required by the calling process, covering Full Disk Access, Accessibility, and Screen Recording.

## Key Components

### Enum: `TCC_PermissionStatus`

Represents the result of a TCC permission check:

| Value | Description |
|---|---|
| `TCC_PERMISSION_DENIED` | Permission explicitly denied |
| `TCC_PERMISSION_GRANTED_USER` | Granted via System Settings |
| `TCC_PERMISSION_GRANTED_MDM` | Granted via MDM `MDMOverrides.plist` |
| `TCC_PERMISSION_NOT_DETERMINED` | Not yet requested or determined |
| `TCC_PERMISSION_ERROR` | Error during status check |

### Struct: `TCC_AllPermissions`

Bundles the status of all three required permissions:

- `fda` — Full Disk Access
- `accessibility` — Accessibility
- `screen_recording` — Screen & System Audio Recording

### Functions

| Function | Description |
|---|---|
| `check_fda_permission()` | Opens `TCC.db` to verify Full Disk Access |
| `check_accessibility_permission()` | Uses `AXIsProcessTrusted()` |
| `check_screen_recording_permission()` | Uses `CGPreflightScreenCaptureAccess()` |
| `check_all_permissions()` | Returns all three statuses at once |

## Usage Example

```c
#include "mac_tcc_detection.h"
#include <stdio.h>

int main(void) {
    TCC_AllPermissions perms = check_all_permissions();

    if (perms.fda != TCC_PERMISSION_GRANTED_USER &&
        perms.fda != TCC_PERMISSION_GRANTED_MDM) {
        printf("Full Disk Access not granted.\n");
    }

    if (perms.accessibility == TCC_PERMISSION_DENIED) {
        printf("Accessibility permission denied.\n");
    }

    if (perms.screen_recording == TCC_PERMISSION_NOT_DETERMINED) {
        printf("Screen Recording permission not yet requested.\n");
    }

    return 0;
}
```

> **Note:** This header is macOS-only and depends on system frameworks (`ApplicationServices`, `CoreGraphics`). It is C/C++ compatible via the `extern "C"` guard.
