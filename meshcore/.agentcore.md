Brief overview of the file's purpose in 1-2 sentences.

`agentcore.h` is the primary header for the MeshAgent core, defining the central `MeshAgentHostContainer` state structure along with all enumerations, command types, and function prototypes required to create, configure, start, and stop a mesh agent instance.

## Key Components

### Types & Enums

| Name | Description |
|---|---|
| `MeshAgentHostContainer` | Central agent state struct holding all runtime fields: connection state, crypto certs, JS engine contexts, platform info, and OpenFrame config |
| `AgentIdentifiers` | Platform/OS agent IDs (Windows x86/x64, Linux, macOS, Android, ChromeOS, NodeJS, etc.) |
| `MeshCommand_AuthInfo_CapabilitiesMask` | Bitmask flags for agent capabilities: `DESKTOP`, `TERMINAL`, `FILES`, `CONSOLE`, `JAVASCRIPT`, `TEMPORARY`, `RECOVERY`, `COMPRESSION` |
| `MeshCommands_Binary` | Binary command opcodes exchanged between MeshServer and MeshAgent (auth, core module updates, agent hash/update, host info) |
| `MeshAgent_Posix_PlatformTypes` | POSIX init system identifiers: `SYSTEMD`, `INITD`, `LAUNCHD`, `BSD`, `PROCD`, `WINDOWS` |
| `MeshAgentHost_BatteryInfo` | Battery state flags: `HIGH`, `LOW`, `CRITICAL`, `CHARGING`, `NONE`, `UNKNOWN` |
| `JS_ENGINE_CONTEXT` | 16-byte opaque identifier for a Duktape JS engine context |

### Packed Command Structs

| Struct | Description |
|---|---|
| `MeshAgent_Commands_SCRIPT_CreateContext` | Create a JS execution context with security flags and timeout |
| `MeshAgent_Commands_SCRIPT_DeleteContext` | Delete an existing JS execution context |
| `MeshAgent_Commands_SCRIPT_ExecuteString` | Execute a script string in a named JS context |

### Functions

| Function | Description |
|---|---|
| `MeshAgent_Create(capabilities)` | Allocates and initializes a new `MeshAgentHostContainer` |
| `MeshAgent_Destroy(agent)` | Frees all resources held by an agent instance |
| `MeshAgent_Start(agent, argc, argv)` | Parses args and starts the agent event loop |
| `MeshAgent_Stop(agent)` | Signals the agent to stop gracefully |
| `MeshAgent_PerformSelfUpdate(...)` | Triggers an in-place binary self-update |
| `MeshAgent_MakeAbsolutePathEx(...)` | Resolves a relative path against a base path |
| `MeshAgent_MakeAbsolutePath(base, local)` | Convenience macro wrapping `MakeAbsolutePathEx` with no backslash escaping |

## Usage Example

```c
#include "agentcore.h"

int main(int argc, char **argv)
{
    // Create agent with terminal + file capabilities
    MeshAgentHostContainer *agent = MeshAgent_Create(
        MeshCommand_AuthInfo_CapabilitiesMask_TERMINAL |
        MeshCommand_AuthInfo_CapabilitiesMask_FILES
    );

    if (agent == NULL) { return 1; }

    // Start the agent (blocks until stopped)
    int result = MeshAgent_Start(agent, argc, argv);

    MeshAgent_Destroy(agent);
    return result;
}
```

## Notable DB Configuration Keys

The header documents several runtime-tunable database keys including `disableUpdate`, `forceUpdate`, `jsDebugPort`, `controlChannelIdleTimeout`, `coreDumpEnabled`, `fakeUpdate`, and `logUpdate`. These are set in the agent's `ILibSimpleDataStore` (`masterDb`) to alter agent behavior without recompilation.
