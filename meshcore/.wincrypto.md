Windows-only cryptographic utility header providing a thin wrapper around the Windows CryptoAPI. Exposes functions for certificate management, hashing, signing, encryption, and Windows Registry access.

## Key Components

### Types

- **`wincrypto_object`** — Opaque handle (`void*`) representing an open cryptographic context tied to a certificate.

### Registry Functions

| Function | Description |
|---|---|
| `wincrypto_setregistry` / `wincrypto_setregistryA` | Write a registry value (wide or ANSI) |
| `wincrypto_getregistry` / `wincrypto_getregistryA` | Read a registry value into a heap-allocated string |

### Crypto Context Functions

| Function | Description |
|---|---|
| `wincrypto_open` | Open/create a crypto context; optionally generate a new certificate under `rootSubject` |
| `wincrypto_isopen` | Check whether a context handle is valid |
| `wincrypto_close` | Release a context handle |

### Cryptographic Operations

| Function | Description |
|---|---|
| `wincrypto_random` | Generate `length` random bytes into `result` |
| `wincrypto_md5` | Compute MD5 digest |
| `wincrypto_sha256` | Compute SHA-256 digest |
| `wincrypto_sha384` | Compute SHA-384 digest |
| `wincrypto_sign` | Sign data using the private key in the context |
| `wincrypto_decrypt` | Decrypt data using the private key in the context |
| `wincrypto_getcert` | Export the DER/PEM certificate bytes from the context |
| `wincrypto_mkCert` | Create a new certificate (`1`=Root, `2`=Server, `3`=Client) |

## Usage Example

```c
#ifdef WIN32
#include "wincrypto.h"

// Open (or create) a crypto context
wincrypto_object ctx = wincrypto_open(1, "CN=MyRoot");
if (!wincrypto_isopen(ctx)) { /* handle error */ }

// Generate 32 random bytes
char rand_buf[32];
wincrypto_random(32, rand_buf);

// Compute SHA-256
char digest[32];
wincrypto_sha256("hello", 5, digest);

// Sign data
char *sig = NULL;
int sig_len = wincrypto_sign(ctx, "hello", 5, &sig);

// Clean up
wincrypto_close(ctx);
#endif
```

> **Note:** All functions use `__fastcall` calling convention and are guarded by `#ifdef WIN32`. This header is not available on non-Windows platforms.
