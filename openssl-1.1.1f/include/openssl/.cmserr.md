Auto-generated OpenSSL error code header for the CMS (Cryptographic Message Syntax) subsystem, defining numeric constants for function codes and reason codes used in CMS error reporting.

## Key Components

### Function
- **`ERR_load_CMS_strings()`** — Registers human-readable CMS error strings with the OpenSSL error system. Must be called before CMS error messages can be retrieved via `ERR_reason_error_string()`.

### Macro Groups

- **`CMS_F_*` — Function codes** (99–183): Numeric identifiers for ~90 CMS internal functions (e.g., `CMS_F_CMS_ENCRYPT`, `CMS_F_CMS_SIGN`, `CMS_F_CMS_VERIFY`). Used as the "function" field in OpenSSL error records.

- **`CMS_R_*` — Reason codes** (99–181): Numeric identifiers for ~90 error conditions (e.g., `CMS_R_NO_CIPHER`, `CMS_R_DECRYPT_ERROR`, `CMS_R_VERIFICATION_FAILURE`). Used as the "reason" field in OpenSSL error records.

## Usage Example

```c
#include <openssl/cms.h>
#include <openssl/err.h>

/* Load CMS error strings at application startup */
ERR_load_CMS_strings();

CMS_ContentInfo *ci = CMS_encrypt(certs, in, cipher, flags);
if (!ci) {
    /* Prints something like:
     * error:XXXXXXXX:CMS routines:CMS_encrypt:no cipher */
    ERR_print_errors_fp(stderr);
}

/* Inspect the error stack manually */
unsigned long err = ERR_get_error();
int reason = ERR_GET_REASON(err);
if (reason == CMS_R_NO_CIPHER) {
    /* handle missing cipher case */
}
```

## Notes

- The file is **auto-generated** by `util/mkerr.pl` — do not edit manually.
- The entire header is guarded by `#ifndef OPENSSL_NO_CMS`, so it compiles away when CMS support is disabled in the OpenSSL build configuration.
