OpenSSL MD4 cryptographic hash function header, providing the public API and data structures for computing MD4 message digests.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `MD4_CBLOCK` | `64` | Block size in bytes |
| `MD4_LBLOCK` | `16` | Block size in 32-bit words |
| `MD4_DIGEST_LENGTH` | `16` | Output digest size in bytes (128 bits) |
| `MD4_LONG` | `unsigned int` | Base integer type (minimum 32 bits) |

### `MD4_CTX` Structure

Internal hash state container with four 32-bit state registers (`A`, `B`, `C`, `D`), bit-length counters (`Nl`, `Nh`), a data block buffer, and a byte counter (`num`).

### Functions

| Function | Description |
|---|---|
| `MD4_Init(MD4_CTX *c)` | Initializes a new MD4 context |
| `MD4_Update(MD4_CTX *c, const void *data, size_t len)` | Feeds data into the hash computation |
| `MD4_Final(unsigned char *md, MD4_CTX *c)` | Finalizes and writes the 16-byte digest |
| `MD4(const unsigned char *d, size_t n, unsigned char *md)` | One-shot convenience wrapper |
| `MD4_Transform(MD4_CTX *c, const unsigned char *b)` | Low-level single-block compression function |

## Usage Example

```c
#include <openssl/md4.h>
#include <stdio.h>

/* Incremental hashing */
void hash_incremental(const unsigned char *data, size_t len) {
    MD4_CTX ctx;
    unsigned char digest[MD4_DIGEST_LENGTH];

    MD4_Init(&ctx);
    MD4_Update(&ctx, data, len);
    MD4_Final(digest, &ctx);
}

/* One-shot hashing */
void hash_oneshot(const unsigned char *data, size_t len) {
    unsigned char digest[MD4_DIGEST_LENGTH];
    MD4(data, len, digest);
}
```

> **⚠️ Security Warning:** MD4 is cryptographically broken and must not be used for security-sensitive purposes. It is provided solely for legacy protocol compatibility (e.g., older NTLM implementations). Guarded by `OPENSSL_NO_MD4` at compile time.
