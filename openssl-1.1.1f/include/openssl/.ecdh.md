Header file that includes the OpenSSL elliptic curve (`ec.h`) interface, serving as a legacy compatibility shim for code that previously included `ecdh.h` directly.

## Key Components

- **`<openssl/ec.h>`** — Transitively includes the full OpenSSL EC (Elliptic Curve) API, which itself encompasses ECDH (Elliptic Curve Diffie-Hellman) key exchange functionality.

## Usage Example

```c
/* Legacy code using the old ecdh.h path */
#include <openssl/ecdh.h>

/* Perform ECDH key exchange */
EC_KEY *key = EC_KEY_new_by_curve_name(NID_X9_62_prime256v1);
EC_KEY_generate_key(key);

unsigned char shared_secret[32];
int secret_len = ECDH_compute_key(
    shared_secret,
    sizeof(shared_secret),
    EC_KEY_get0_public_key(peer_key),
    key,
    NULL
);

EC_KEY_free(key);
```

> **Note:** Prefer including `<openssl/ec.h>` directly in new code. This header exists solely for backward compatibility with older OpenSSL consumers that referenced `ecdh.h` before the API was consolidated.
