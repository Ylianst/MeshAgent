OpenSSL DSA (Digital Signature Algorithm) public API header, providing key lifecycle management, signing/verification operations, parameter generation, and pluggable method dispatch for DSA cryptographic operations.

## Key Components

### Types & Constants
- `DSA_SIG` — opaque struct holding a DSA signature's `r` and `s` BIGNUM components
- `OPENSSL_DSA_MAX_MODULUS_BITS` — maximum modulus size (10000 bits)
- `OPENSSL_DSA_FIPS_MIN_MODULUS_BITS` — FIPS minimum modulus (1024 bits)
- `DSA_FLAG_FIPS_METHOD`, `DSA_FLAG_NON_FIPS_ALLOW`, `DSA_FLAG_CACHE_MONT_P` — behavioral flags

### Key Lifecycle
- `DSA_new` / `DSA_free` / `DSA_up_ref` — allocate, release, and reference-count DSA objects
- `DSA_generate_parameters_ex` — generate domain parameters (p, q, g) per FIPS 186-4
- `DSA_generate_key` — derive public/private key pair from parameters

### Signing & Verification
- `DSA_do_sign` / `DSA_do_verify` — low-level sign/verify returning `DSA_SIG`
- `DSA_sign` / `DSA_verify` — higher-level DER-encoded sign/verify
- `DSA_SIG_get0` / `DSA_SIG_set0` — access or assign `r`/`s` components

### Parameter Accessors
- `DSA_get0_pqg` / `DSA_set0_pqg` — get/set prime `p`, subprime `q`, generator `g`
- `DSA_get0_key` / `DSA_set0_key` — get/set public and private keys

### Method Dispatch (`DSA_METHOD`)
- `DSA_meth_new` / `DSA_meth_free` / `DSA_meth_dup` — manage custom method tables
- `DSA_meth_set_sign`, `DSA_meth_set_verify`, `DSA_meth_set_keygen`, etc. — plug in custom cryptographic callbacks

### Serialization Macros
- `d2i_DSAparams_bio` / `i2d_DSAparams_bio` — DER encode/decode parameters via BIO
- `d2i_DSAPublicKey` / `d2i_DSAPrivateKey` — deserialize keys from DER

## Usage Example

```c
#include <openssl/dsa.h>
#include <openssl/bn.h>

/* Generate DSA key and sign a digest */
DSA *dsa = DSA_new();
DSA_generate_parameters_ex(dsa, 2048, NULL, 0, NULL, NULL, NULL);
DSA_generate_key(dsa);

unsigned char digest[32] = { /* SHA-256 output */ };
DSA_SIG *sig = DSA_do_sign(digest, sizeof(digest), dsa);

const BIGNUM *r, *s;
DSA_SIG_get0(sig, &r, &s);

int ok = DSA_do_verify(digest, sizeof(digest), sig, dsa);

DSA_SIG_free(sig);
DSA_free(dsa);
```
