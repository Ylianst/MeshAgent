OpenSSL OCSP (Online Certificate Status Protocol) header providing data structures, constants, and function declarations for checking X.509 certificate revocation status via OCSP requests and responses.

## Key Components

### Revocation Status Constants
- `OCSP_REVOKED_STATUS_*` — CRLReason enumeration values (unspecified, keyCompromise, cACompromise, etc.)
- `V_OCSP_CERTSTATUS_GOOD/REVOKED/UNKNOWN` — Certificate status codes
- `OCSP_RESPONSE_STATUS_*` — Response status codes (successful, malformedRequest, internalError, etc.)

### Verification Flags
Bitmask flags controlling OCSP verification behavior:
- `OCSP_NOCERTS`, `OCSP_NOVERIFY`, `OCSP_NOCHAIN`, `OCSP_NOSIGS`, `OCSP_TRUSTOTHER`, etc.

### Core Types
- `OCSP_CERTID` — Certificate identifier
- `OCSP_REQUEST` / `OCSP_ONEREQ` — OCSP request structures
- `OCSP_RESPONSE` / `OCSP_BASICRESP` — OCSP response structures
- `OCSP_SINGLERESP` — Per-certificate response entry
- `OCSP_REQ_CTX` — Non-blocking HTTP request context

### Key Functions
- `OCSP_cert_to_id()` — Build a cert ID from subject/issuer certificates
- `OCSP_request_add0_id()` — Add a certificate ID to a request
- `OCSP_sendreq_bio()` / `OCSP_sendreq_nbio()` — Send OCSP request over BIO
- `OCSP_response_get1_basic()` — Extract basic response from response
- `OCSP_resp_find_status()` — Look up revocation status for a cert ID
- `OCSP_check_validity()` — Validate thisUpdate/nextUpdate time window
- `OCSP_basic_sign()` / `OCSP_request_sign()` — Sign requests and responses

## Usage Example

```c
/* Check certificate revocation status via OCSP */
OCSP_CERTID *id = OCSP_cert_to_id(NULL, subject_cert, issuer_cert);
OCSP_REQUEST *req = OCSP_REQUEST_new();
OCSP_request_add0_id(req, id);
OCSP_request_add1_nonce(req, NULL, -1);

/* Send request */
OCSP_RESPONSE *resp = OCSP_sendreq_bio(bio, "/", req);
int rc = OCSP_response_status(resp);
if (rc == OCSP_RESPONSE_STATUS_SUCCESSFUL) {
    OCSP_BASICRESP *bs = OCSP_response_get1_basic(resp);
    int status, reason;
    ASN1_GENERALIZEDTIME *revtime, *thisupd, *nextupd;
    OCSP_resp_find_status(bs, id, &status, &reason,
                          &revtime, &thisupd, &nextupd);
    /* status: V_OCSP_CERTSTATUS_GOOD / REVOKED / UNKNOWN */
    OCSP_BASICRESP_free(bs);
}
OCSP_RESPONSE_free(resp);
OCSP_REQUEST_free(req);
```
