Public API header for OpenSSL's Deterministic Random Bit Generator (DRBG), implementing the NIST SP 800-90Ar1 standard for cryptographically secure random number generation.

## Key Components

### Constants & Flags

| Macro | Value | Description |
|---|---|---|
| `RAND_DRBG_STRENGTH` | `256` | Default security strength in bits |
| `RAND_DRBG_TYPE` | `NID_aes_256_ctr` | Default cipher (AES-256-CTR) |
| `RAND_DRBG_FLAG_CTR_NO_DF` | `0x1` | Disable derivation function in CTR mode |

### Lifecycle Functions

- `RAND_DRBG_new` / `RAND_DRBG_secure_new` — allocate a DRBG instance (optionally in secure memory)
- `RAND_DRBG_set` / `RAND_DRBG_set_defaults` — configure type and flags
- `RAND_DRBG_instantiate` / `RAND_DRBG_uninstantiate` — seed and tear down the DRBG state
- `RAND_DRBG_free` — release the instance

### Entropy & Generation

- `RAND_DRBG_generate` — produce random bytes with optional additional input and prediction resistance
- `RAND_DRBG_bytes` — simplified random byte generation
- `RAND_DRBG_reseed` — manually trigger a reseed

### Global Instances

- `RAND_DRBG_get0_master` / `RAND_DRBG_get0_public` / `RAND_DRBG_get0_private` — access the process-wide shared DRBGs

### Callback Typedefs

Custom entropy/nonce providers via `RAND_DRBG_get_entropy_fn`, `RAND_DRBG_cleanup_entropy_fn`, `RAND_DRBG_get_nonce_fn`, and `RAND_DRBG_cleanup_nonce_fn`, registered with `RAND_DRBG_set_callbacks`.

## Usage Example

```c
/* Create and instantiate a DRBG with personalization string */
RAND_DRBG *drbg = RAND_DRBG_new(NID_aes_256_ctr, 0, NULL);
if (drbg == NULL) handle_error();

const unsigned char pers[] = "my_app_context";
if (!RAND_DRBG_instantiate(drbg, pers, sizeof(pers) - 1))
    handle_error();

/* Generate 32 random bytes */
unsigned char buf[32];
if (!RAND_DRBG_bytes(drbg, buf, sizeof(buf)))
    handle_error();

RAND_DRBG_uninstantiate(drbg);
RAND_DRBG_free(drbg);
```
