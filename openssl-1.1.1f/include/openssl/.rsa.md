OpenSSL RSA public key cryptography header defining the RSA API, including key generation, encryption/decryption, signing/verification, padding schemes, and EVP_PKEY context controls.

## Key Components

### Constants & Flags

| Constant | Value | Description |
|---|---|---|
| `OPENSSL_RSA_MAX_MODULUS_BITS` | 16384 | Maximum RSA modulus size |
| `RSA_F4` | 0x10001 | Common public exponent (65537) |
| `RSA_FLAG_BLINDING` | 0x0008 | Enable blinding countermeasure |
| `RSA_FLAG_NO_BLINDING` | 0x0080 | Disable blinding |
| `RSA_FLAG_EXT_PKEY` | 0x0020 | Key stored in external hardware |

### Padding Schemes

| Constant | Description |
|---|---|
| `RSA_PKCS1_PADDING` | Standard PKCS#1 v1.5 padding |
| `RSA_PKCS1_OAEP_PADDING` | OAEP padding (recommended for encryption) |
| `RSA_PKCS1_PSS_PADDING` | PSS padding (for signatures via EVP) |
| `RSA_NO_PADDING` | Raw RSA, no padding |
| `RSA_X931_PADDING` | X9.31 padding |

### Key Functions

- **`RSA_new` / `RSA_free`** — Allocate and free RSA objects
- **`RSA_generate_key_ex`** — Generate standard RSA key pair
- **`RSA_generate_multi_prime_key`** — Generate multi-prime RSA key
- **`RSA_public_encrypt` / `RSA_private_decrypt`** — Encrypt/decrypt data
- **`RSA_private_encrypt` / `RSA_public_decrypt`** — Sign/verify raw data
- **`RSA_check_key` / `RSA_check_key_ex`** — Validate key consistency
- **`RSA_set0_key` / `RSA_get0_key`** — Set/get key components (n, e, d)
- **`RSA_set0_factors` / `RSA_get0_factors`** — Set/get prime factors (p, q)
- **`RSA_set0_crt_params`** — Set CRT parameters for fast private operations

### Structures

- **`rsa_pss_params_st` (RSA_PSS_PARAMS)** — PSS signature parameters (hash, MGF, salt length)
- **`RSA_OAEP_PARAMS`** — OAEP encryption parameters (hash, MGF, label source)

### EVP_PKEY Context Macros

Convenience macros wrapping `RSA_pkey_ctx_ctrl` / `EVP_PKEY_CTX_ctrl`:

- `EVP_PKEY_CTX_set_rsa_padding` — Set padding scheme
- `EVP_PKEY_CTX_set_rsa_keygen_bits` — Set key size for generation
- `EVP_PKEY_CTX_set_rsa_pss_saltlen` — Configure PSS salt length
- `EVP_PKEY_CTX_set_rsa_oaep_md` — Set OAEP digest algorithm
- `EVP_PKEY_CTX_set_rsa_mgf1_md` — Set MGF1 digest

## Usage Example

```c
#include <openssl/rsa.h>
#include <openssl/evp.h>

/* Generate a 2048-bit RSA key pair */
RSA *rsa = RSA_new();
BIGNUM *e = BN_new();
BN_set_word(e, RSA_F4); /* public exponent = 65537 */

RSA_generate_key_ex(rsa, 2048, e, NULL);

/* Encrypt with OAEP padding */
unsigned char ciphertext[256];
int ct_len = RSA_public_encrypt(
    plaintext_len, plaintext,
    ciphertext, rsa,
    RSA_PKCS1_OAEP_PADDING
);

/* Decrypt */
unsigned char recovered[256];
int pt_len = RSA_private_decrypt(
    ct_len, ciphertext,
    recovered, rsa,
    RSA_PKCS1_OAEP_PADDING
);

RSA_free(rsa);
BN_free(e);
```

> **Note:** For new code, prefer the higher-level EVP API (`EVP_PKEY`, `EVP_PKEY_CTX`) over direct RSA calls. `RSA_generate_key` is deprecated; use `RSA_generate_key_ex` instead.
