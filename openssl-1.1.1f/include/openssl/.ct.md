OpenSSL Certificate Transparency (CT) header providing types, enumerations, and function declarations for working with Signed Certificate Timestamps (SCTs) and CT policy evaluation as defined in RFC 6962.

## Key Components

### Enumerations
- `ct_log_entry_type_t` — Log entry type: X.509 certificate or pre-certificate
- `sct_version_t` — SCT version (currently only V1)
- `sct_source_t` — SCT origin: TLS extension, X.509v3 extension, or OCSP stapled response
- `sct_validation_status_t` — Validation result states (valid, invalid, unknown log, unverified, etc.)

### Constants
- `SCT_MIN_RSA_BITS` — Minimum RSA key size (2048 bits, per RFC 6962)
- `CT_V1_HASHLEN` — Hash length for CT v1 (SHA-256)

### CT Policy Evaluation Context (`CT_POLICY_EVAL_CTX`)
Manages the context required for SCT validation, including the peer certificate, issuer, trusted log store, and evaluation timestamp.

| Function | Purpose |
|---|---|
| `CT_POLICY_EVAL_CTX_new` / `_free` | Lifecycle management |
| `CT_POLICY_EVAL_CTX_set1_cert` | Bind peer certificate |
| `CT_POLICY_EVAL_CTX_set1_issuer` | Bind certificate issuer |
| `CT_POLICY_EVAL_CTX_set_shared_CTLOG_STORE` | Attach trusted log store |
| `CT_POLICY_EVAL_CTX_set_time` | Set reference time (ms since Unix epoch) |

### SCT Lifecycle & Accessors
- `SCT_new` / `SCT_new_from_base64` / `SCT_free` / `SCT_LIST_free` — Creation and cleanup
- Getters/setters for: version, log entry type, log ID, timestamp, signature NID, extensions, signature bytes, and source

### Validation
- `SCT_validate` — Validates a single SCT against a policy context
- `SCT_LIST_validate` — Validates all SCTs in a stack

### Serialization
- `i2o_SCT_LIST` / `o2i_SCT_LIST` — TLS wire format encode/decode
- `i2d_SCT_LIST` / `d2i_SCT_LIST` — DER format encode/decode

## Usage Example

```c
/* Validate SCTs received from a TLS handshake */
CT_POLICY_EVAL_CTX *ctx = CT_POLICY_EVAL_CTX_new();

CT_POLICY_EVAL_CTX_set1_cert(ctx, peer_cert);
CT_POLICY_EVAL_CTX_set1_issuer(ctx, issuer_cert);
CT_POLICY_EVAL_CTX_set_shared_CTLOG_STORE(ctx, log_store);
CT_POLICY_EVAL_CTX_set_time(ctx, (uint64_t)time(NULL) * 1000);

int result = SCT_LIST_validate(sct_list, ctx);
if (result == 1) {
    /* All SCTs valid */
} else if (result == 0) {
    /* One or more SCTs invalid */
    SCT *sct;
    for (int i = 0; i < sk_SCT_num(sct_list); i++) {
        sct = sk_SCT_value(sct_list, i);
        printf("SCT status: %s\n", SCT_validation_status_string(sct));
    }
}

CT_POLICY_EVAL_CTX_free(ctx);
SCT_LIST_free(sct_list);
```
