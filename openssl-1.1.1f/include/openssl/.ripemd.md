OpenSSL RIPEMD-160 cryptographic hash function header, defining the context structure and API for computing 160-bit message digests.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `RIPEMD160_CBLOCK` | `64` | Block size in bytes |
| `RIPEMD160_LBLOCK` | `16` | Block size in 32-bit words |
| `RIPEMD160_DIGEST_LENGTH` | `20` | Output digest size in bytes |

### `RIPEMD160_CTX` Structure

Holds the incremental hash state:

- `A, B, C, D, E` — Five 32-bit chaining variables
- `Nl, Nh` — Message length counters (low/high)
- `data[RIPEMD160_LBLOCK]` — Current message block buffer
- `num` — Number of bytes currently buffered

### Functions

| Function | Description |
|---|---|
| `RIPEMD160_Init` | Initializes a new hash context |
| `RIPEMD160_Update` | Feeds data into an in-progress hash |
| `RIPEMD160_Final` | Finalizes and writes the 20-byte digest |
| `RIPEMD160` | One-shot convenience function |
| `RIPEMD160_Transform` | Processes a single raw 64-byte block |

## Usage Example

```c
/* Incremental hashing */
RIPEMD160_CTX ctx;
unsigned char digest[RIPEMD160_DIGEST_LENGTH];

RIPEMD160_Init(&ctx);
RIPEMD160_Update(&ctx, data_chunk1, len1);
RIPEMD160_Update(&ctx, data_chunk2, len2);
RIPEMD160_Final(digest, &ctx);

/* One-shot hashing */
unsigned char *result = RIPEMD160(input, input_len, digest);
```

> **Note:** Guarded by `OPENSSL_NO_RMD160` — if RIPEMD-160 is disabled in your OpenSSL build, this header exposes no symbols.
