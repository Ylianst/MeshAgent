OpenSSL X.509v3 certificate extension definitions, structures, and function type declarations for parsing, encoding, and validating X.509 version 3 extensions.

## Key Components

### Extension Method Callbacks
| Typedef | Description |
|---|---|
| `X509V3_EXT_NEW` / `X509V3_EXT_FREE` | Allocate/free extension objects |
| `X509V3_EXT_D2I` / `X509V3_EXT_I2D` | DER decode/encode |
| `X509V3_EXT_I2S` / `X509V3_EXT_S2I` | String conversion (single-value extensions) |
| `X509V3_EXT_I2V` / `X509V3_EXT_V2I` | Config value conversion (multi-valued extensions) |
| `X509V3_EXT_I2R` / `X509V3_EXT_R2I` | Raw text conversion |

### Core Structures
- **`v3_ext_method`** — Extension handler registration (NID, flags, codec callbacks)
- **`v3_ext_ctx`** — Context for extension processing (issuer/subject cert, CRL, config DB)
- **`GENERAL_NAME`** — General name union supporting 9 name types (`GEN_DNS`, `GEN_EMAIL`, `GEN_URI`, etc.)
- **`BASIC_CONSTRAINTS`** — CA flag and path length
- **`DIST_POINT`** / `CRL_DIST_POINTS` — CRL distribution points
- **`AUTHORITY_KEYID`** — Authority key identifier
- **`POLICYINFO`** / `CERTIFICATEPOLICIES` — Certificate policy OID and qualifiers
- **`NAME_CONSTRAINTS`** — Permitted/excluded subtrees
- **`PROXY_CERT_INFO_EXTENSION`** — RFC 3820 proxy certificate info

### Flag Constants
- **`EXFLAG_*`** — Precomputed certificate property flags (`EXFLAG_CA`, `EXFLAG_SI`, `EXFLAG_PROXY`)
- **`KU_*`** — Key usage bits (`KU_DIGITAL_SIGNATURE`, `KU_KEY_CERT_SIGN`, etc.)
- **`XKU_*`** — Extended key usage flags (`XKU_SSL_SERVER`, `XKU_CODE_SIGN`, etc.)
- **`CRL_REASON_*`** — CRL revocation reason codes

## Usage Example

```c
#include <openssl/x509v3.h>
#include <openssl/x509.h>

/* Check if a certificate is a CA with key signing capability */
void inspect_cert(X509 *cert) {
    uint32_t flags = X509_get_extension_flags(cert);
    uint32_t ku    = X509_get_key_usage(cert);

    if (flags & EXFLAG_CA) {
        printf("Certificate is a CA\n");
    }

    if (ku & KU_KEY_CERT_SIGN) {
        printf("May sign certificates\n");
    }

    /* Extract Subject Alternative Names */
    GENERAL_NAMES *sans = X509_get_ext_d2i(cert, NID_subject_alt_name, NULL, NULL);
    if (sans) {
        for (int i = 0; i < sk_GENERAL_NAME_num(sans); i++) {
            GENERAL_NAME *name = sk_GENERAL_NAME_value(sans, i);
            if (name->type == GEN_DNS) {
                printf("SAN DNS: %s\n",
                    ASN1_STRING_get0_data(name->d.dNSName));
            }
        }
        GENERAL_NAMES_free(sans);
    }
}
```
