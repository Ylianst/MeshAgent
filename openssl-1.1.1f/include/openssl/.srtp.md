DTLS-SRTP extension header for OpenSSL, providing SRTP protection profile constants and API declarations for negotiating SRTP cipher suites over DTLS connections.

## Key Components

### Protection Profile Constants

| Constant | Value | Description |
|---|---|---|
| `SRTP_AES128_CM_SHA1_80` | `0x0001` | AES-128 Counter Mode with HMAC-SHA1-80 |
| `SRTP_AES128_CM_SHA1_32` | `0x0002` | AES-128 Counter Mode with HMAC-SHA1-32 |
| `SRTP_AES128_F8_SHA1_80` | `0x0003` | AES-128 F8 Mode with HMAC-SHA1-80 |
| `SRTP_AES128_F8_SHA1_32` | `0x0004` | AES-128 F8 Mode with HMAC-SHA1-32 |
| `SRTP_NULL_SHA1_80` | `0x0005` | Null encryption with HMAC-SHA1-80 |
| `SRTP_NULL_SHA1_32` | `0x0006` | Null encryption with HMAC-SHA1-32 |
| `SRTP_AEAD_AES_128_GCM` | `0x0007` | AEAD AES-128-GCM (RFC 7714) |
| `SRTP_AEAD_AES_256_GCM` | `0x0008` | AEAD AES-256-GCM (RFC 7714) |

### API Functions (guarded by `OPENSSL_NO_SRTP`)

- **`SSL_CTX_set_tlsext_use_srtp`** — Registers SRTP profiles on an `SSL_CTX` context (applies to all connections).
- **`SSL_set_tlsext_use_srtp`** — Registers SRTP profiles on an individual `SSL` connection.
- **`SSL_get_srtp_profiles`** — Returns the stack of supported SRTP profiles for a connection.
- **`SSL_get_selected_srtp_profile`** — Returns the single SRTP profile negotiated after the handshake.

## Usage Example

```c
#include <openssl/srtp.h>

/* Server: advertise AES-128-GCM and fallback AES-128-CM profiles */
SSL_CTX *ctx = SSL_CTX_new(DTLS_server_method());

if (SSL_CTX_set_tlsext_use_srtp(ctx, "SRTP_AEAD_AES_128_GCM:SRTP_AES128_CM_SHA1_80") != 0) {
    /* handle error */
}

/* After handshake: retrieve the negotiated profile */
SRTP_PROTECTION_PROFILE *profile = SSL_get_selected_srtp_profile(ssl);
if (profile) {
    printf("Negotiated SRTP profile: %s (id=0x%04x)\n",
           profile->name, profile->id);
}
```
