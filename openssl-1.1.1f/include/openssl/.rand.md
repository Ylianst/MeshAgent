OpenSSL random number generation interface header, defining the `RAND_METHOD` dispatch table and declaring the public RAND API for seeding, generating, and managing cryptographic entropy.

## Key Components

### `rand_meth_st` (RAND_METHOD)
Custom RNG engine vtable with six function pointers:

| Field | Description |
|---|---|
| `seed` | Seed the RNG with external data |
| `bytes` | Generate cryptographically strong bytes |
| `cleanup` | Free RNG resources |
| `add` | Add entropy with a randomness estimate |
| `pseudorand` | Generate pseudo-random bytes (deprecated path) |
| `status` | Query RNG readiness |

### Core Functions

| Function | Description |
|---|---|
| `RAND_bytes` | Generate cryptographically strong random bytes |
| `RAND_priv_bytes` | Generate bytes for private use (keys, nonces) |
| `RAND_seed` / `RAND_add` | Feed entropy into the RNG pool |
| `RAND_set_rand_method` / `RAND_get_rand_method` | Swap in a custom `RAND_METHOD` |
| `RAND_set_rand_engine` | Set an ENGINE-backed RNG (requires ENGINE support) |
| `RAND_load_file` / `RAND_write_file` | Persist entropy seed files |
| `RAND_poll` | Platform-level entropy poll |
| `RAND_keep_random_devices_open` | Control `/dev/urandom` fd lifecycle |

### Deprecated / Conditional
- `RAND_pseudo_bytes` — deprecated in 1.1.0; use `RAND_bytes`
- `RAND_screen` / `RAND_event` — Windows-only, deprecated in 1.1.0
- EGD functions (`RAND_egd`, `RAND_query_egd_bytes`) — gated on `OPENSSL_NO_EGD`

## Usage Example

```c
#include <openssl/rand.h>

/* Generate 32 bytes of cryptographically strong random data */
unsigned char key[32];
if (RAND_bytes(key, sizeof(key)) != 1) {
    /* Handle error */
}

/* Optionally install a custom RNG method */
RAND_METHOD my_method = {
    .seed  = my_seed,
    .bytes = my_bytes,
    /* ... */
};
RAND_set_rand_method(&my_method);
```
