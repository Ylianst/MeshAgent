Simple text-based database header from OpenSSL, providing a lightweight flat-file database structure with indexing and hash-based lookup capabilities.

## Key Components

### Data Structure

- **`TXT_DB`** — Core database struct containing:
  - `num_fields` — number of fields per record
  - `data` — stack of string arrays (rows)
  - `index` — array of hash tables for indexed fields
  - `qual` — per-index qualifier/filter function pointers
  - `error`, `arg1`, `arg2`, `arg_row` — error reporting state

### Error Codes

| Constant | Value | Meaning |
|---|---|---|
| `DB_ERROR_OK` | 0 | Success |
| `DB_ERROR_MALLOC` | 1 | Memory allocation failure |
| `DB_ERROR_INDEX_CLASH` | 2 | Duplicate index entry |
| `DB_ERROR_INDEX_OUT_OF_RANGE` | 3 | Field index out of bounds |
| `DB_ERROR_NO_INDEX` | 4 | Index does not exist |
| `DB_ERROR_INSERT_INDEX_CLASH` | 5 | Insert violates index uniqueness |
| `DB_ERROR_WRONG_NUM_FIELDS` | 6 | Row has wrong field count |

### Functions

- **`TXT_DB_read`** — Parses a `BIO` stream into a `TXT_DB` with `num` fields per row
- **`TXT_DB_write`** — Serializes a `TXT_DB` back to a `BIO` stream
- **`TXT_DB_create_index`** — Creates a hash index on a field with optional qualifier, hash, and comparison functions
- **`TXT_DB_get_by_index`** — Performs a hash-based lookup on an indexed field
- **`TXT_DB_insert`** — Inserts a new row, enforcing all active indexes
- **`TXT_DB_free`** — Releases all database memory

## Usage Example

```c
#include <openssl/txt_db.h>
#include <openssl/bio.h>

/* Read a tab-delimited flat file with 6 fields */
BIO *in = BIO_new_file("index.txt", "r");
TXT_DB *db = TXT_DB_read(in, 6);
BIO_free(in);

if (!db) {
    /* handle error */
}

/* Create a hash index on field 3 (e.g., serial number) */
TXT_DB_create_index(db, 3, NULL,
                    (OPENSSL_LH_HASHFUNC)OPENSSL_LH_strhash,
                    (OPENSSL_LH_COMPFUNC)strcmp);

/* Lookup a row by indexed field */
OPENSSL_STRING query[] = { "12345", NULL };
OPENSSL_STRING *row = TXT_DB_get_by_index(db, 3, query);

TXT_DB_free(db);
```
