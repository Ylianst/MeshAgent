Internal OpenSSL configuration API header providing low-level primitives for managing `CONF` (configuration) data structures — sections, key-value pairs, and memory lifecycle.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `_CONF_new_section` | Function | Creates a new named section in a `CONF` object |
| `_CONF_get_section` | Function | Retrieves a section by name (read-only) |
| `_CONF_get_section_values` | Function | Returns all key-value pairs within a section as a `STACK_OF(CONF_VALUE)` |
| `_CONF_add_string` | Function | Adds a `CONF_VALUE` string entry to a section |
| `_CONF_get_string` | Function | Looks up a string value by section and key name |
| `_CONF_get_number` | Function | Looks up a numeric (`long`) value by section and key name |
| `_CONF_new_data` | Function | Initialises internal data storage for a `CONF` object |
| `_CONF_free_data` | Function | Releases internal data storage from a `CONF` object |

## Usage Example

```c
#include <openssl/conf.h>
#include "conf_api.h"

CONF *conf = NCONF_new(NULL);

/* Initialise internal data */
_CONF_new_data(conf);

/* Create a section and add a key-value pair */
CONF_VALUE *section = _CONF_new_section(conf, "database");
CONF_VALUE *entry    = /* ... construct CONF_VALUE ... */;
_CONF_add_string(conf, section, entry);

/* Retrieve values */
const char *host = _CONF_get_string(conf, "database", "host");
long        port  = _CONF_get_number(conf, "database", "port");

/* Cleanup */
_CONF_free_data(conf);
NCONF_free(conf);
```

> **Note:** All symbols are prefixed with `_CONF_` and are considered **internal** OpenSSL APIs. Prefer the public `NCONF_*` / `CONF_*` interfaces for application code.
