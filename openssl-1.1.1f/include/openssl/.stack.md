Low-level OpenSSL generic stack (dynamic array) interface, providing type-agnostic push/pop/find/sort operations on `OPENSSL_STACK`. In practice, use the type-safe `STACK_OF(T)` macros built on top of this header.

## Key Components

### Types

| Type | Description |
|---|---|
| `OPENSSL_STACK` | Opaque stack struct; prefer `STACK_OF(...)` |
| `OPENSSL_sk_compfunc` | Comparator callback `(const void*, const void*) → int` |
| `OPENSSL_sk_freefunc` | Element destructor callback `(void*)` |
| `OPENSSL_sk_copyfunc` | Element copy callback `(const void*) → void*` |

### Core Functions

| Function | Description |
|---|---|
| `OPENSSL_sk_new` / `_new_null` / `_new_reserve` | Allocate a stack, optionally with comparator and pre-allocated capacity |
| `OPENSSL_sk_reserve` | Pre-allocate capacity to avoid reallocs |
| `OPENSSL_sk_push` / `OPENSSL_sk_unshift` | Append or prepend an element |
| `OPENSSL_sk_pop` / `OPENSSL_sk_shift` | Remove and return from top or front |
| `OPENSSL_sk_insert` / `OPENSSL_sk_delete` / `OPENSSL_sk_delete_ptr` | Insert or remove at a specific index or by pointer |
| `OPENSSL_sk_find` / `OPENSSL_sk_find_ex` | Search (exact match / inexact bisect) |
| `OPENSSL_sk_sort` / `OPENSSL_sk_is_sorted` | Sort in-place; query sorted state |
| `OPENSSL_sk_dup` / `OPENSSL_sk_deep_copy` | Shallow or deep copy |
| `OPENSSL_sk_pop_free` | Free stack and all elements via destructor |
| `OPENSSL_sk_zero` | Zero element count without freeing |

### Legacy Compatibility

When `OPENSSL_API_COMPAT < 0x10100000L`, short aliases (`sk_push`, `sk_pop`, etc.) are defined for pre-1.1 code.

## Usage Example

```c
#include <openssl/stack.h>

/* Comparator for string pointers */
int str_cmp(const void *a, const void *b) {
    return strcmp(*(const char **)a, *(const char **)b);
}

OPENSSL_STACK *sk = OPENSSL_sk_new(str_cmp);

const char *item = "hello";
OPENSSL_sk_push(sk, item);

int count = OPENSSL_sk_num(sk);          /* 1 */
void *val = OPENSSL_sk_value(sk, 0);     /* "hello" */

OPENSSL_sk_sort(sk);
OPENSSL_sk_pop_free(sk, free);           /* free stack + elements */
```

> **Note:** For type safety, prefer the `STACK_OF(T)` macros (e.g., `STACK_OF(X509)`) defined in `<openssl/safestack.h>` rather than calling `OPENSSL_sk_*` directly.
