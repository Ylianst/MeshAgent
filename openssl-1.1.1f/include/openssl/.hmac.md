OpenSSL HMAC (Hash-based Message Authentication Code) API header providing cryptographic message authentication functions using a shared secret key combined with a hash function.

## Key Components

| Function | Description |
|---|---|
| `HMAC()` | One-shot convenience function to compute HMAC in a single call |
| `HMAC_CTX_new()` | Allocates and initializes a new HMAC context |
| `HMAC_CTX_free()` | Frees a previously allocated HMAC context |
| `HMAC_CTX_reset()` | Resets a context for reuse without reallocation |
| `HMAC_Init_ex()` | Initializes/reinitializes context with key, digest, and optional engine |
| `HMAC_Update()` | Feeds data into an in-progress HMAC computation |
| `HMAC_Final()` | Finalizes computation and writes the HMAC digest |
| `HMAC_CTX_copy()` | Copies state from one context to another |
| `HMAC_CTX_get_md()` | Retrieves the digest algorithm associated with a context |
| `HMAC_CTX_set_flags()` | Sets behavioral flags on a context |
| `HMAC_size()` | Returns the output size of the HMAC digest in bytes |

> **Note:** `HMAC_Init()` is deprecated since OpenSSL 1.1.0. Use `HMAC_Init_ex()` instead.

## Usage Example

**One-shot HMAC (simplest approach):**

```c
#include <openssl/hmac.h>
#include <openssl/evp.h>

unsigned char result[EVP_MAX_MD_SIZE];
unsigned int result_len;

const char *key  = "secret";
const char *data = "message to authenticate";

HMAC(EVP_sha256(), key, strlen(key),
     (unsigned char *)data, strlen(data),
     result, &result_len);
```

**Incremental HMAC (streaming data):**

```c
HMAC_CTX *ctx = HMAC_CTX_new();

HMAC_Init_ex(ctx, key, strlen(key), EVP_sha256(), NULL);
HMAC_Update(ctx, chunk1, chunk1_len);
HMAC_Update(ctx, chunk2, chunk2_len);
HMAC_Final(ctx, result, &result_len);

HMAC_CTX_free(ctx);
```
