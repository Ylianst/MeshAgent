OpenSSL asynchronous job management interface header, providing APIs for non-blocking cryptographic operations using cooperative multitasking primitives.

## Key Components

### Types
| Type | Description |
|------|-------------|
| `ASYNC_JOB` | Opaque handle representing a suspended async job |
| `ASYNC_WAIT_CTX` | Context holding file descriptors used to signal job completion |
| `OSSL_ASYNC_FD` | Platform-specific async file descriptor (`HANDLE` on Windows, `int` on POSIX) |

### Status Codes
| Constant | Value | Meaning |
|----------|-------|---------|
| `ASYNC_ERR` | `0` | Error occurred |
| `ASYNC_NO_JOBS` | `1` | No job slots available |
| `ASYNC_PAUSE` | `2` | Job paused, waiting for I/O |
| `ASYNC_FINISH` | `3` | Job completed |

### Key Functions
- **`ASYNC_init_thread`** / **`ASYNC_cleanup_thread`** — Initialize and tear down the async job pool for the current thread
- **`ASYNC_start_job`** — Launch or resume an async job, invoking `func(args)`
- **`ASYNC_pause_job`** — Voluntarily yield control from within a running job
- **`ASYNC_get_current_job`** — Retrieve the currently executing `ASYNC_JOB`
- **`ASYNC_WAIT_CTX_*`** — Manage the set of file descriptors that signal job readiness
- **`ASYNC_block_pause`** / **`ASYNC_unblock_pause`** — Temporarily suppress pause capability
- **`ASYNC_is_capable`** — Runtime check for async support on the current platform

## Usage Example

```c
ASYNC_WAIT_CTX *wctx = ASYNC_WAIT_CTX_new();
ASYNC_JOB *job = NULL;
int retval, status;

/* Start or resume the async job */
status = ASYNC_start_job(&job, wctx, &retval, my_async_func, args, sizeof(*args));

switch (status) {
    case ASYNC_PAUSE:
        /* Poll wctx FDs, then call ASYNC_start_job again to resume */
        break;
    case ASYNC_FINISH:
        /* retval holds my_async_func's return value */
        break;
    case ASYNC_ERR:
    case ASYNC_NO_JOBS:
        /* Handle error */
        break;
}

ASYNC_WAIT_CTX_free(wctx);
```
