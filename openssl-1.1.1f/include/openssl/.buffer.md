OpenSSL dynamic buffer management header providing the `BUF_MEM` structure and associated memory allocation/manipulation functions.

## Key Components

### Struct

- **`buf_mem_st` (`BUF_MEM`)** — Core buffer structure with fields:
  - `length` — current number of bytes in use
  - `data` — pointer to buffer contents
  - `max` — total allocated buffer size
  - `flags` — behavior flags (e.g., `BUF_MEM_FLAG_SECURE`)

### Constants

| Constant | Value | Description |
|---|---|---|
| `BUF_MEM_FLAG_SECURE` | `0x01` | Allocates buffer in secure (locked) memory |

### Functions

| Function | Description |
|---|---|
| `BUF_MEM_new()` | Allocates a new `BUF_MEM` with default settings |
| `BUF_MEM_new_ex(flags)` | Allocates a new `BUF_MEM` with custom flags |
| `BUF_MEM_free(a)` | Frees a `BUF_MEM` and its data |
| `BUF_MEM_grow(str, len)` | Grows buffer to at least `len` bytes |
| `BUF_MEM_grow_clean(str, len)` | Grows buffer, zeroing new memory |
| `BUF_reverse(out, in, siz)` | Reverses `siz` bytes from `in` into `out` |

### Deprecated Macros

Legacy `BUF_*` string utilities now alias to their `OPENSSL_*` equivalents (e.g., `BUF_strdup` → `OPENSSL_strdup`).

## Usage Example

```c
#include <openssl/buffer.h>

/* Standard buffer */
BUF_MEM *buf = BUF_MEM_new();
BUF_MEM_grow(buf, 256);
memcpy(buf->data, "hello", 5);
buf->length = 5;
BUF_MEM_free(buf);

/* Secure buffer (zeroed on free, locked memory) */
BUF_MEM *secure_buf = BUF_MEM_new_ex(BUF_MEM_FLAG_SECURE);
BUF_MEM_grow_clean(secure_buf, 128);
BUF_MEM_free(secure_buf);
```

> **Note:** The `BUF_*` string macros (`BUF_strdup`, `BUF_strndup`, etc.) are deprecated as of OpenSSL 1.1. Prefer their `OPENSSL_*` equivalents directly.
