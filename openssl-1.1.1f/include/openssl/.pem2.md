Minimal PEM v2 header that pulls in OpenSSL PEM error definitions via `pemerr.h`. Acts as a thin include guard wrapper.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `HEADER_PEM2_H` | Include guard macro | Prevents multiple inclusion of this header |
| `<openssl/pemerr.h>` | Dependency | Transitively exposes all PEM error codes and reason strings |

## Usage Example

```c
#include <openssl/pem2.h>

/* PEM error codes are now available, e.g.: */
int err = ERR_get_error();
if (ERR_GET_LIB(err) == ERR_LIB_PEM) {
    /* handle PEM-specific error */
}
```

> **Note:** In most cases you should include `<openssl/pem.h>` directly, which provides the full PEM API. This header exists primarily for internal OpenSSL use and backward compatibility.
