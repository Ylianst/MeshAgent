OpenSSL MD5 cryptographic hash function interface header, providing the public API and data structures for computing MD5 message digests.

## Key Components

### Constants
| Macro | Value | Description |
|---|---|---|
| `MD5_CBLOCK` | `64` | Block size in bytes |
| `MD5_LBLOCK` | `16` | Block size in 32-bit words |
| `MD5_DIGEST_LENGTH` | `16` | Output digest size in bytes (128 bits) |
| `MD5_LONG` | `unsigned int` | Internal word type (minimum 32 bits) |

### `MD5_CTX` Structure
Internal state container for incremental hashing:
- `A, B, C, D` — four 32-bit state registers
- `Nl, Nh` — 64-bit message length counter (low/high words)
- `data[MD5_LBLOCK]` — current block buffer
- `num` — bytes currently buffered

### Functions
| Function | Description |
|---|---|
| `MD5_Init` | Initialize a new `MD5_CTX` context |
| `MD5_Update` | Feed data into the running hash computation |
| `MD5_Final` | Finalize and output the 16-byte digest |
| `MD5` | One-shot convenience: hash a buffer in a single call |
| `MD5_Transform` | Low-level single-block compression (advanced use) |

## Usage Example

**Incremental hashing:**
```c
MD5_CTX ctx;
unsigned char digest[MD5_DIGEST_LENGTH];

MD5_Init(&ctx);
MD5_Update(&ctx, data_chunk1, len1);
MD5_Update(&ctx, data_chunk2, len2);
MD5_Final(digest, &ctx);
```

**One-shot hashing:**
```c
unsigned char digest[MD5_DIGEST_LENGTH];
MD5((unsigned char *)input, strlen(input), digest);
```

> **Note:** MD5 is cryptographically broken and should not be used for security-sensitive purposes (e.g., digital signatures, password hashing). Use SHA-256 or stronger alternatives for new code.
