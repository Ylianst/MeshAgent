OpenSSL OSSL_STORE public API header defining the interface for loading cryptographic objects (keys, certificates, CRLs) from URI-addressed resources via a pluggable loader architecture.

## Key Components

### Core Context & Channel Functions
| Function | Description |
|---|---|
| `OSSL_STORE_open()` | Opens a store channel to a URI resource |
| `OSSL_STORE_load()` | Reads one data item from an open channel |
| `OSSL_STORE_eof()` | Checks if end-of-data is reached |
| `OSSL_STORE_error()` | Checks if an error occurred |
| `OSSL_STORE_close()` | Closes the channel and frees context |
| `OSSL_STORE_ctrl()` / `OSSL_STORE_vctrl()` | Fine-tunes channel behavior |

### Info Object (`OSSL_STORE_INFO`)
Wraps loaded cryptographic objects. Supported types:
- `OSSL_STORE_INFO_NAME` — resource name/listing entry
- `OSSL_STORE_INFO_PARAMS` — `EVP_PKEY` parameters
- `OSSL_STORE_INFO_PKEY` — private/public key
- `OSSL_STORE_INFO_CERT` — X.509 certificate
- `OSSL_STORE_INFO_CRL` — certificate revocation list

### Search API (`OSSL_STORE_SEARCH`)
Constructors for filtering loaded objects:
- `OSSL_STORE_SEARCH_by_name()`, `_by_issuer_serial()`, `_by_key_fingerprint()`, `_by_alias()`

### Loader Registration (`OSSL_STORE_LOADER`)
Pluggable backend interface. Set handler callbacks via:
- `OSSL_STORE_LOADER_set_open/load/eof/error/close/ctrl/find/expect()`
- `OSSL_STORE_register_loader()` / `OSSL_STORE_unregister_loader()`

## Usage Example

```c
/* Open a store, iterate over all certs, then close */
OSSL_STORE_CTX *ctx = OSSL_STORE_open("file:///etc/ssl/certs/ca.pem",
                                       ui_method, ui_data, NULL, NULL);
if (!ctx) { /* handle error */ }

OSSL_STORE_expect(ctx, OSSL_STORE_INFO_CERT); /* optional filter */

while (!OSSL_STORE_eof(ctx)) {
    OSSL_STORE_INFO *info = OSSL_STORE_load(ctx);
    if (!info) continue;

    if (OSSL_STORE_INFO_get_type(info) == OSSL_STORE_INFO_CERT) {
        X509 *cert = OSSL_STORE_INFO_get0_CERT(info);
        /* use cert */
    }
    OSSL_STORE_INFO_free(info);
}

OSSL_STORE_close(ctx);
```
