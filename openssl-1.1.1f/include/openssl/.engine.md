OpenSSL Engine framework header defining the plugin interface for cryptographic algorithm providers.

## Key Components

### Method Flags (`ENGINE_METHOD_*`)
Bitfield constants controlling which cryptographic algorithms an engine handles:

| Flag | Value | Algorithm |
|------|-------|-----------|
| `ENGINE_METHOD_RSA` | `0x0001` | RSA operations |
| `ENGINE_METHOD_DSA` | `0x0002` | DSA operations |
| `ENGINE_METHOD_DH` | `0x0004` | Diffie-Hellman |
| `ENGINE_METHOD_EC` | `0x0800` | Elliptic curve |
| `ENGINE_METHOD_CIPHERS` | `0x0040` | Symmetric ciphers |
| `ENGINE_METHOD_DIGESTS` | `0x0080` | Hash digests |
| `ENGINE_METHOD_ALL` | `0xFFFF` | All algorithms |

### Engine Behavior Flags (`ENGINE_FLAGS_*`)
- `ENGINE_FLAGS_MANUAL_CMD_CTRL` — Engine handles control commands itself
- `ENGINE_FLAGS_BY_ID_COPY` — Returns deep copies on `ENGINE_by_id()` (for stateful engines)
- `ENGINE_FLAGS_NO_REGISTER_ALL` — Excludes engine from `ENGINE_register_all_complete()`

### Control Commands (`ENGINE_CTRL_*`)
Built-in control commands (1–18) for engine discovery and configuration, plus `ENGINE_CMD_BASE` (200) as the starting offset for engine-specific commands.

### Key Types

```c
typedef struct ENGINE_CMD_DEFN_st {
    unsigned int cmd_num;    /* Command number */
    const char  *cmd_name;   /* Command name */
    const char  *cmd_desc;   /* Short description */
    unsigned int cmd_flags;  /* Expected input type */
} ENGINE_CMD_DEFN;

typedef int (*ENGINE_GEN_INT_FUNC_PTR)(ENGINE *);
typedef int (*ENGINE_CTRL_FUNC_PTR)(ENGINE *, int, long, void *, void (*f)(void));
typedef EVP_PKEY *(*ENGINE_LOAD_KEY_PTR)(ENGINE *, const char *, UI_METHOD *, ...);
```

## Usage Example

```c
#include <openssl/engine.h>

/* Load and initialize a named engine */
ENGINE *e = ENGINE_by_id("pkcs11");
if (e) {
    /* Configure via control command */
    ENGINE_ctrl_cmd_string(e, "MODULE_PATH", "/usr/lib/pkcs11.so", 0);

    if (ENGINE_init(e)) {
        /* Register for RSA and EC operations only */
        ENGINE_set_default(e, ENGINE_METHOD_RSA | ENGINE_METHOD_EC);
    }
    ENGINE_free(e);
}

/* Enumerate engine commands */
int cmd = ENGINE_ctrl(e, ENGINE_CTRL_GET_FIRST_CMD_TYPE, 0, NULL, NULL);
while (cmd > 0) {
    cmd = ENGINE_ctrl(e, ENGINE_CTRL_GET_NEXT_CMD_TYPE, cmd, NULL, NULL);
}
```

> **Note:** The ENGINE API is deprecated as of OpenSSL 3.0 in favor of the [Provider API](https://www.openssl.org/docs/man3.0/man7/provider.html). New implementations should use `OSSL_PROVIDER` instead.
