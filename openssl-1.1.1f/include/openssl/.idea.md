Public API header for the IDEA (International Data Encryption Algorithm) symmetric block cipher, part of OpenSSL's legacy cipher support. Guarded by `OPENSSL_NO_IDEA` to allow compile-time exclusion.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `IDEA_ENCRYPT` | `1` | Direction flag for encryption |
| `IDEA_DECRYPT` | `0` | Direction flag for decryption |
| `IDEA_BLOCK` | `8` | Block size in bytes |
| `IDEA_KEY_LENGTH` | `16` | Key size in bytes (128-bit) |

### Types

- **`IDEA_INT`** — `unsigned int` alias used internally for cipher arithmetic
- **`IDEA_KEY_SCHEDULE`** — Expanded key schedule struct holding a `9×6` subkey matrix derived from the raw key

### Functions

| Function | Description |
|---|---|
| `IDEA_options()` | Returns a build-info string |
| `IDEA_set_encrypt_key()` | Derives an encryption key schedule from a 16-byte key |
| `IDEA_set_decrypt_key()` | Derives a decryption schedule from an existing encryption schedule |
| `IDEA_ecb_encrypt()` | Encrypts/decrypts a single 8-byte block (ECB mode) |
| `IDEA_cbc_encrypt()` | CBC mode encrypt/decrypt with IV |
| `IDEA_cfb64_encrypt()` | CFB-64 mode streaming encrypt/decrypt |
| `IDEA_ofb64_encrypt()` | OFB-64 mode streaming encrypt |
| `IDEA_encrypt()` | Raw single-block core cipher operation |

Legacy lowercase aliases (e.g. `idea_cbc_encrypt`) are available when `OPENSSL_API_COMPAT < 0x10100000L`.

## Usage Example

```c
#include <openssl/idea.h>

unsigned char key[IDEA_KEY_LENGTH] = { /* 16 bytes */ };
unsigned char iv[IDEA_BLOCK]       = { 0 };
unsigned char in[64]               = { /* plaintext */ };
unsigned char out[64];

IDEA_KEY_SCHEDULE enc_ks, dec_ks;

/* Encrypt */
IDEA_set_encrypt_key(key, &enc_ks);
IDEA_cbc_encrypt(in, out, sizeof(in), &enc_ks, iv, IDEA_ENCRYPT);

/* Decrypt */
IDEA_set_decrypt_key(&enc_ks, &dec_ks);
memset(iv, 0, sizeof(iv));
IDEA_cbc_encrypt(out, in, sizeof(out), &dec_ks, iv, IDEA_DECRYPT);
```

> **Note:** IDEA is a legacy cipher not recommended for new designs. Prefer AES where possible.
