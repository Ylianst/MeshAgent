OpenSSL MD2 message digest algorithm header, providing the interface for computing MD2 cryptographic hashes. Part of the legacy OpenSSL digest suite, conditionally compiled when `OPENSSL_NO_MD2` is not defined.

## Key Components

| Component | Description |
|---|---|
| `MD2_CTX` | Context struct holding digest state, checksum, and buffered data block |
| `MD2_DIGEST_LENGTH` | Output digest size: 16 bytes (128 bits) |
| `MD2_BLOCK` | Internal block size: 16 bytes |
| `MD2_Init()` | Initializes an `MD2_CTX` context |
| `MD2_Update()` | Feeds data into the digest computation |
| `MD2_Final()` | Finalizes and outputs the 16-byte digest |
| `MD2()` | One-shot convenience function for computing MD2 over a buffer |
| `MD2_options()` | Returns a string describing compile-time options |

## Usage Example

```c
#include <openssl/md2.h>
#include <stdio.h>

int main(void) {
    const unsigned char input[] = "hello world";
    unsigned char digest[MD2_DIGEST_LENGTH];
    MD2_CTX ctx;

    /* Incremental API */
    MD2_Init(&ctx);
    MD2_Update(&ctx, input, sizeof(input) - 1);
    MD2_Final(digest, &ctx);

    /* One-shot API */
    MD2(input, sizeof(input) - 1, digest);

    for (int i = 0; i < MD2_DIGEST_LENGTH; i++)
        printf("%02x", digest[i]);
    printf("\n");
    return 0;
}
```

> **⚠️ Security Warning:** MD2 is cryptographically broken and must not be used in security-sensitive applications. It is retained in OpenSSL for legacy compatibility only and is disabled by default (`OPENSSL_NO_MD2`).
