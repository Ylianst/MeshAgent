OpenSSL SSL3 protocol constants and definitions header for the SSL/TLS v3 record layer, cipher suites, alert codes, and protocol parameters used throughout the OpenSSL library.

## Key Components

### Signalling Cipher Suite Values (SCSVs)
- `SSL3_CK_SCSV` — Renegotiation info signal (RFC 5746, `0x030000FF`)
- `SSL3_CK_FALLBACK_SCSV` — Downgrade attack prevention signal (`0x03005600`)

### Cipher Suite Constants (`SSL3_CK_*`)
Numeric identifiers for SSL3 cipher suites grouped by key exchange method:
- **RSA** — `SSL3_CK_RSA_NULL_MD5` through `SSL3_CK_RSA_DES_192_CBC3_SHA`
- **DH/DHE** — Static and ephemeral Diffie-Hellman variants (DSS and RSA auth)
- **ADH** — Anonymous DH cipher suites

### Cipher Suite Names
- `SSL3_RFC_*` — RFC-standard cipher name strings (e.g., `"TLS_RSA_WITH_3DES_EDE_CBC_SHA"`)
- `SSL3_TXT_*` — OpenSSL short-form names (e.g., `"DES-CBC3-SHA"`); `EDH_*` variants kept for backward compatibility

### Protocol Size Constants
| Constant | Value | Description |
|---|---|---|
| `SSL3_MASTER_SECRET_SIZE` | 48 | Master secret length in bytes |
| `SSL3_RANDOM_SIZE` | 32 | Random nonce size |
| `SSL3_RT_HEADER_LENGTH` | 5 | Record layer header size |
| `SSL3_RT_MAX_PLAIN_LENGTH` | 16384 | Max plaintext per record |
| `SSL3_RT_MAX_MD_SIZE` | 64 | Max MAC digest size |

### Record Types (`SSL3_RT_*`)
```c
SSL3_RT_CHANGE_CIPHER_SPEC  // 20
SSL3_RT_ALERT               // 21
SSL3_RT_HANDSHAKE           // 22
SSL3_RT_APPLICATION_DATA    // 23
DTLS1_RT_HEARTBEAT          // 24
```

### Alert Codes (`SSL3_AD_*`)
Fatal and warning alert values including `SSL3_AD_CLOSE_NOTIFY`, `SSL3_AD_BAD_RECORD_MAC`, `SSL3_AD_HANDSHAKE_FAILURE`, and certificate-related alerts.

### TLS Crypto Pseudo-types (`TLS1_RT_CRYPTO_*`)
Internal content-type flags used for key material logging (premaster, master secret, client/server random, MAC keys, IVs).

## Usage Example

```c
#include <openssl/ssl3.h>

/* Check protocol version */
if (SSL_version(ssl) == SSL3_VERSION) {
    /* SSL 3.0 connection detected */
}

/* Use size constants for buffer allocation */
unsigned char master_secret[SSL3_MASTER_SECRET_SIZE]; /* 48 bytes */
unsigned char random_buf[SSL3_RANDOM_SIZE];            /* 32 bytes */

/* Check for fatal alert */
if (alert_desc == SSL3_AD_HANDSHAKE_FAILURE) {
    /* Handle fatal handshake failure */
}

/* Max packet buffer sizing */
unsigned char pkt_buf[SSL3_RT_MAX_PACKET_SIZE];
```

> **Note:** SSL 3.0 is deprecated and insecure. These constants are retained for legacy compatibility. Modern applications should use TLS 1.2+ via the OpenSSL API. See the [OpenSSL source](https://github.com/flamingo-stack/meshagent) and [community support](https://www.openmsp.ai/) for integration guidance.
