Provides the ECDSA (Elliptic Curve Digital Signature Algorithm) interface by including the OpenSSL EC library header, exposing elliptic curve cryptography primitives for digital signature operations.

## Key Components

- **`<openssl/ec.h>`** — Transitively exposes all EC and ECDSA types and functions, including:
  - `ECDSA_sign()` / `ECDSA_verify()` — Sign and verify data using ECDSA
  - `ECDSA_do_sign()` / `ECDSA_do_verify()` — Sign/verify returning/accepting an `ECDSA_SIG` struct
  - `ECDSA_SIG` — Opaque structure holding the `r` and `s` signature components
  - `EC_KEY` — Elliptic curve key pair (public + private)

## Usage Example

```c
#include "ecdsa.h"
#include <openssl/sha.h>

/* Sign a message digest using an EC private key */
int sign_data(EC_KEY *key, const unsigned char *digest, size_t digest_len) {
    ECDSA_SIG *sig = ECDSA_do_sign(digest, (int)digest_len, key);
    if (!sig) {
        return -1; /* signing failed */
    }

    /* Use sig->r and sig->s as needed */
    ECDSA_SIG_free(sig);
    return 0;
}

/* Verify a signature against a digest */
int verify_data(EC_KEY *key, const unsigned char *digest,
                size_t digest_len, ECDSA_SIG *sig) {
    return ECDSA_do_verify(digest, (int)digest_len, sig, key);
    /* Returns 1 (valid), 0 (invalid), or -1 (error) */
}
```

## Notes

- This header is a thin wrapper; all ECDSA functionality is provided by OpenSSL's `libcrypto`.
