OpenSSL ASN.1 (Abstract Syntax Notation One) type definitions, tag constants, encoding macros, and function declaration helpers used throughout the OpenSSL cryptographic library.

## Key Components

### ASN.1 Tag Constants
- `V_ASN1_*` — Universal tag values (e.g., `V_ASN1_INTEGER`, `V_ASN1_SEQUENCE`, `V_ASN1_UTF8STRING`)
- `B_ASN1_*` — Bitmask flags for use with `d2i_ASN1_type_bytes()` and `ASN1_mbstring_copy()`
- `V_ASN1_NEG`, `V_ASN1_NEG_INTEGER`, `V_ASN1_NEG_ENUMERATED` — Sign indicators for internal use

### Core Structures
- `asn1_string_st` (`ASN1_STRING`) — Base type holding length, type tag, raw data pointer, and flags
- `ASN1_ENCODING` — Saves raw DER encoding for signature validation integrity
- `ASN1_STRING_TABLE` — Defines per-NID string size/mask constraints

### String Flags
- `ASN1_STRING_FLAG_BITS_LEFT` — Unused bits indicator for BIT_STRING
- `ASN1_STRING_FLAG_NDEF` — Placeholder for indefinite-length constructed data
- `ASN1_STRING_FLAG_CONT` — CMS incomplete content marker
- `ASN1_STRING_FLAG_MSTRING` — Marks MSTRING multi-type strings
- `ASN1_STRING_FLAG_X509_TIME` — RFC 5280 time format parsing

### Function Declaration Macros
- `DECLARE_ASN1_FUNCTIONS(type)` — Declares `type_new()`, `type_free()`, `d2i_type()`, `i2d_type()`
- `DECLARE_ASN1_ENCODE_FUNCTIONS(type, itname, name)` — DER encode/decode pair
- `DECLARE_ASN1_ALLOC_FUNCTIONS_name(type, name)` — Allocator/deallocator only
- `D2I_OF(type)` / `I2D_OF(type)` — Function pointer typedefs for codec callbacks
- `CHECKED_D2I_OF` / `CHECKED_I2D_OF` — Type-safe codec pointer casts

### MBSTRING Constants
- `MBSTRING_UTF8`, `MBSTRING_ASC`, `MBSTRING_BMP`, `MBSTRING_UNIV` — Multibyte string encoding flags

## Usage Example

```c
#include <openssl/asn1.h>

/* Declare encode/decode functions for a custom type */
DECLARE_ASN1_FUNCTIONS(ASN1_INTEGER)

/* Check ASN.1 tag type */
ASN1_STRING *str = /* ... */;
if (str->type == V_ASN1_UTF8STRING) {
    /* handle UTF-8 string */
}

/* Use bitmask to accept multiple string types */
int accepted = B_ASN1_PRINTABLESTRING | B_ASN1_UTF8STRING | B_ASN1_IA5STRING;
```
