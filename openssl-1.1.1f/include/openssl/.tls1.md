TLS 1.x protocol constants, extension type definitions, alert codes, and function declarations for OpenSSL's TLS implementation, covering TLS 1.0 through TLS 1.3.

## Key Components

### Version Constants
- `TLS1_VERSION` (`0x0301`) through `TLS1_3_VERSION` (`0x0304`) — numeric version identifiers
- `TLS_ANY_VERSION` (`0x10000`) — sentinel for multi-version methods
- `TLS1_get_version(s)` / `TLS1_get_client_version(s)` — macros to extract TLS version from an SSL object

### Alert Codes (`TLS1_AD_*`, `TLS13_AD_*`)
Fatal and warning alert definitions (e.g., `TLS1_AD_UNKNOWN_CA`, `TLS13_AD_MISSING_EXTENSION`) used during handshake and record processing.

### Extension Types (`TLSEXT_TYPE_*`)
Numeric IDs for all standard TLS extensions including SNI, ALPN, session tickets, key share, PSK, supported groups, OCSP status, and TLS 1.3-specific extensions.

### Signature & Hash Algorithm IDs
- `TLSEXT_signature_*` — RSA, DSA, ECDSA, GOST variants
- `TLSEXT_hash_*` — MD5, SHA-1, SHA-224/256/384/512, GOST digests

### Key Functions
- `SSL_export_keying_material()` — RFC 5705 keying material exporter
- `SSL_export_keying_material_early()` — TLS 1.3 early exporter master secret
- `SSL_get_servername()` / `SSL_get_servername_type()` — SNI retrieval
- `SSL_get_sigalgs()` / `SSL_get_shared_sigalgs()` — signature algorithm negotiation
- `SSL_check_chain()` — certificate chain validation
- `SSL_CTX_set_tlsext_max_fragment_length()` / `SSL_set_tlsext_max_fragment_length()` — MFL extension control

### Convenience Macros
Wrappers around `SSL_ctrl()` for common extension operations (SNI hostname, OCSP status, session ticket keys, servername callbacks, debug callbacks).

## Usage Example

```c
#include <openssl/tls1.h>
#include <openssl/ssl.h>

/* Set SNI hostname on client connection */
SSL_set_tlsext_host_name(ssl, "example.com");

/* Retrieve negotiated server name on server side */
const char *name = SSL_get_servername(ssl, TLSEXT_NAMETYPE_host_name);

/* Export 32 bytes of keying material (RFC 5705) */
unsigned char out[32];
int rc = SSL_export_keying_material(
    ssl, out, sizeof(out),
    "my_label", 8,
    NULL, 0, 0   /* no context */
);

/* Enable OCSP stapling */
SSL_set_tlsext_status_type(ssl, TLSEXT_STATUSTYPE_ocsp);

/* Limit maximum TLS fragment to 4096 bytes */
SSL_set_tlsext_max_fragment_length(ssl, TLSEXT_max_fragment_length_4096);
```
