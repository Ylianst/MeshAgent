OpenSSL RC5 symmetric block cipher header defining the RC5-32 algorithm interface, key structures, and encryption/decryption function declarations.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `RC5_ENCRYPT` | `1` | Encrypt operation flag |
| `RC5_DECRYPT` | `0` | Decrypt operation flag |
| `RC5_32_BLOCK` | `8` | Block size in bytes |
| `RC5_32_KEY_LENGTH` | `16` | Default key length (max 255) |
| `RC5_8_ROUNDS` | `8` | 8-round variant |
| `RC5_12_ROUNDS` | `12` | 12-round variant |
| `RC5_16_ROUNDS` | `16` | 16-round variant |

### Types

- **`RC5_32_KEY`** — Key schedule struct holding round count and expanded key data array sized for up to 16 rounds.

### Functions

| Function | Description |
|---|---|
| `RC5_32_set_key` | Expands raw key bytes into an `RC5_32_KEY` schedule |
| `RC5_32_ecb_encrypt` | ECB mode single-block encrypt/decrypt |
| `RC5_32_encrypt` | Raw block encryption (in-place) |
| `RC5_32_decrypt` | Raw block decryption (in-place) |
| `RC5_32_cbc_encrypt` | CBC mode multi-block encrypt/decrypt |
| `RC5_32_cfb64_encrypt` | 64-bit CFB mode streaming encrypt/decrypt |
| `RC5_32_ofb64_encrypt` | 64-bit OFB mode streaming encrypt |

## Usage Example

```c
#include <openssl/rc5.h>

RC5_32_KEY key;
unsigned char raw_key[RC5_32_KEY_LENGTH] = { /* 16 bytes */ };
unsigned char iv[RC5_32_BLOCK] = { 0 };
unsigned char plaintext[64]    = "Hello, RC5!";
unsigned char ciphertext[64];

/* Expand key with 12 rounds (RC5-32/12/16 variant) */
RC5_32_set_key(&key, RC5_32_KEY_LENGTH, raw_key, RC5_12_ROUNDS);

/* Encrypt using CBC mode */
RC5_32_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                   &key, iv, RC5_ENCRYPT);
```

> **Note:** Guarded by `OPENSSL_NO_RC5` — RC5 support must be enabled at OpenSSL build time. Prefer AES for new implementations; RC5 is provided for legacy compatibility.
