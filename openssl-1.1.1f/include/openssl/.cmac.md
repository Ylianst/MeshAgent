OpenSSL CMAC (Cipher-based Message Authentication Code) API header providing the interface for computing and verifying MAC values using symmetric block ciphers.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `CMAC_CTX` | Opaque struct | Context holding CMAC state across operations |
| `CMAC_CTX_new` | Function | Allocates and initializes a new CMAC context |
| `CMAC_CTX_cleanup` | Function | Clears sensitive data from a context without freeing it |
| `CMAC_CTX_free` | Function | Cleans up and frees a CMAC context |
| `CMAC_CTX_get0_cipher_ctx` | Function | Returns the underlying `EVP_CIPHER_CTX` (borrowed reference) |
| `CMAC_CTX_copy` | Function | Copies one CMAC context into another |
| `CMAC_Init` | Function | Initializes the CMAC operation with a key and cipher |
| `CMAC_Update` | Function | Feeds data into the running CMAC computation |
| `CMAC_Final` | Function | Finalizes computation and outputs the MAC value |
| `CMAC_resume` | Function | Resumes a previously finalized CMAC context for additional data |

## Usage Example

```c
#include <openssl/cmac.h>
#include <openssl/evp.h>

unsigned char key[16] = { /* 128-bit AES key */ };
unsigned char data[]  = "message to authenticate";
unsigned char mac[16];
size_t mac_len;

/* Allocate context */
CMAC_CTX *ctx = CMAC_CTX_new();

/* Initialize with AES-128-CBC */
CMAC_Init(ctx, key, sizeof(key), EVP_aes_128_cbc(), NULL);

/* Feed message data */
CMAC_Update(ctx, data, sizeof(data) - 1);

/* Retrieve the MAC (16 bytes for AES-128) */
CMAC_Final(ctx, mac, &mac_len);

/* Clean up */
CMAC_CTX_free(ctx);
```

> **Note:** The entire API is compiled out when OpenSSL is built with `OPENSSL_NO_CMAC`. Guard any calling code with `#ifndef OPENSSL_NO_CMAC` to maintain portability.
