Provides EBCDIC ↔ ASCII character encoding conversion utilities used within OpenSSL for mainframe/IBM system compatibility.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `os_toascii` | `const unsigned char[256]` | Lookup table mapping EBCDIC byte values to ASCII |
| `os_toebcdic` | `const unsigned char[256]` | Lookup table mapping ASCII byte values to EBCDIC |
| `ebcdic2ascii()` | Function | Converts a buffer from EBCDIC encoding to ASCII in-place |
| `ascii2ebcdic()` | Function | Converts a buffer from ASCII encoding to EBCDIC in-place |

All symbols are prefixed with `_openssl_` via macros to prevent name collisions with other libraries or system headers.

## Usage Example

```c
#include "ebcdic.h"
#include <string.h>

void convert_example(void) {
    /* Convert an ASCII string to EBCDIC */
    char src[] = "Hello";
    char dest[6];

    ascii2ebcdic(dest, src, strlen(src));

    /* Convert back to ASCII */
    char result[6];
    ebcdic2ascii(result, dest, strlen(src));

    /* Single-byte lookup via table */
    unsigned char ascii_val = os_toascii[(unsigned char)ebcdic_byte];
}
```

> **Note:** Both conversion functions write directly into `dest` and return a pointer to it. The caller is responsible for ensuring `dest` is large enough to hold `count` bytes.
