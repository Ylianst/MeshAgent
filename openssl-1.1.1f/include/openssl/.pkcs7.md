OpenSSL PKCS#7 (Cryptographic Message Syntax) header defining data structures and the public API for creating, signing, encrypting, and verifying PKCS#7/CMS messages, including S/MIME support.

## Key Components

### Core Structures

| Structure | Description |
|---|---|
| `PKCS7` | Top-level container; holds type discriminator and a union of all content variants |
| `PKCS7_SIGNER_INFO` | Signer metadata: digest algorithm, encrypted digest, authenticated/unauthenticated attributes, private key |
| `PKCS7_RECIP_INFO` | Recipient metadata: key encryption algorithm and encrypted session key |
| `PKCS7_SIGNED` | Signed-data content type (version, digest algorithms, certs, CRLs, signer infos) |
| `PKCS7_ENVELOPE` | Enveloped-data content type (recipients + encrypted content) |
| `PKCS7_SIGN_ENVELOPE` | SignedAndEnveloped combined content type |
| `PKCS7_ENC_CONTENT` | Encrypted content block (cipher algorithm + ciphertext) |
| `PKCS7_DIGEST` | Digest-data content type |
| `PKCS7_ENCRYPT` | Encrypted-data content type |
| `PKCS7_ISSUER_AND_SERIAL` | Certificate identifier (issuer name + serial number) |

### Type-Check Macros

- `PKCS7_type_is_signed(a)` — checks for `NID_pkcs7_signed`
- `PKCS7_type_is_encrypted(a)` — checks for `NID_pkcs7_encrypted`
- `PKCS7_type_is_enveloped(a)` — checks for `NID_pkcs7_enveloped`
- `PKCS7_type_is_data(a)`, `PKCS7_type_is_digest(a)` — other content types
- `PKCS7_is_detached(p7)` — true when signed with a detached signature

### S/MIME Operation Flags

| Flag | Value | Purpose |
|---|---|---|
| `PKCS7_TEXT` | `0x1` | Add/strip text MIME headers |
| `PKCS7_NOCERTS` | `0x2` | Omit certificates |
| `PKCS7_NOSIGS` | `0x4` | Do not verify signatures |
| `PKCS7_DETACHED` | `0x40` | Use detached signature |
| `PKCS7_STREAM` | `0x1000` | Enable streaming I/O |
| `PKCS7_PARTIAL` | `0x4000` | Partial initialization (add signers later) |
| `PKCS7_REUSE_DIGEST` | `0x8000` | Reuse existing digest |

### Key Functions

**Sign / Verify**
- `PKCS7_sign()` — create a signed PKCS#7 structure in one call
- `PKCS7_sign_add_signer()` — add an additional signer to an existing structure
- `PKCS7_verify()` — verify signatures against a certificate store
- `PKCS7_get0_signers()` — retrieve signing certificates

**Encrypt / Decrypt**
- `PKCS7_encrypt()` — encrypt data for a set of recipient certificates
- `PKCS7_decrypt()` — decrypt using a private key and matching certificate

**Low-Level Data Processing**
- `PKCS7_dataInit()` / `PKCS7_dataFinal()` — initialize and finalize streaming I/O
- `PKCS7_dataDecode()` — decode and decrypt enveloped data
- `PKCS7_dataVerify()` / `PKCS7_signatureVerify()` — low-level signature verification

**I/O**
- `d2i_PKCS7_bio()` / `i2d_PKCS7_bio()` — DER encode/decode via BIO
- `SMIME_write_PKCS7()` / `SMIME_read_PKCS7()` — S/MIME format I/O
- `PEM_write_bio_PKCS7_stream()` — PEM streaming output
- `BIO_new_PKCS7()` — create a BIO chain that processes PKCS#7 on the fly

**Attribute Helpers**
- `PKCS7_add_signed_attribute()` / `PKCS7_get_signed_attribute()` — manage authenticated attributes
- `PKCS7_add_attrib_smimecap()` / `PKCS7_get_smimecap()` — S/MIME capabilities attribute
- `PKCS7_add0_attrib_signing_time()` — add signing time attribute
- `PKCS7_add1_attrib_digest()` — add message digest attribute

## Usage Example

```c
#include <openssl/pkcs7.h>
#include <openssl/pem.h>

/* --- Sign data and write as S/MIME --- */
PKCS7 *sign_data(X509 *cert, EVP_PKEY *pkey,
                 STACK_OF(X509) *chain, BIO *data) {
    int flags = PKCS7_STREAM | PKCS7_DETACHED | PKCS7_TEXT;

    PKCS7 *p7 = PKCS7_sign(cert, pkey, chain, data, flags);
    if (!p7) {
        /* handle error */
        return NULL;
    }

    /* Reset data BIO for writing */
    BIO_reset(data);

    BIO *out = BIO_new_fp(stdout, BIO_NOCLOSE);
    SMIME_write_PKCS7(out, p7, data, flags);

    BIO_free(out);
    return p7;
}

/* --- Verify an S/MIME message --- */
int verify_smime(BIO *in, X509_STORE *store) {
    BIO *content = NULL;
    PKCS7 *p7 = SMIME_read_PKCS7(in, &content);
    if (!p7) return 0;

    int ok = PKCS7_verify(p7, NULL, store,
                          content, NULL, PKCS7_TEXT);
    PKCS7_free(p7);
    BIO_free(content);
    return ok;
}

/* --- Encrypt for recipients --- */
PKCS7 *encrypt_for(STACK_OF(X509) *recipients, BIO *plaintext) {
    return PKCS7_encrypt(recipients, plaintext,
                         EVP_aes_256_cbc(),
                         PKCS7_STREAM);
}

/* --- Decrypt --- */
int decrypt_pkcs7(PKCS7 *p7, EVP_PKEY *pkey, X509 *cert, BIO *out) {
    return PKCS7_decrypt(p7, pkey, cert, out, 0);
}
```
