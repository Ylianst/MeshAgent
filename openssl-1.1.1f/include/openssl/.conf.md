OpenSSL configuration management header defining the interfaces for loading, parsing, and managing configuration files and modules.

## Key Components

### Types & Structures

| Type | Description |
|------|-------------|
| `CONF_VALUE` | Core config entry holding `section`, `name`, and `value` strings |
| `CONF_METHOD` | Vtable struct with function pointers for config backend operations |
| `CONF` | Config object wrapping a `CONF_METHOD`, method data, and an `LHASH_OF(CONF_VALUE)` |
| `CONF_IMODULE` | Instance of a loaded config module |
| `CONF_MODULE` | Registered config module definition |

### Module Flags

| Flag | Value | Meaning |
|------|-------|---------|
| `CONF_MFLAGS_IGNORE_ERRORS` | `0x1` | Skip load errors |
| `CONF_MFLAGS_SILENT` | `0x4` | Suppress output |
| `CONF_MFLAGS_NO_DSO` | `0x8` | Disable DSO loading |
| `CONF_MFLAGS_IGNORE_MISSING_FILE` | `0x10` | Tolerate absent files |
| `CONF_MFLAGS_DEFAULT_SECTION` | `0x20` | Fall back to default section |

### Legacy API (`CONF_*`)
- `CONF_load` / `CONF_load_bio` / `CONF_load_fp` — load config into an `LHASH`
- `CONF_get_string` / `CONF_get_number` / `CONF_get_section` — query values
- `CONF_free` / `CONF_dump_bio` — cleanup and serialization

### Modern API (`NCONF_*`)
- `NCONF_new` / `NCONF_free` / `NCONF_free_data` — lifecycle management
- `NCONF_load` / `NCONF_load_bio` / `NCONF_load_fp` — file loading
- `NCONF_get_string` / `NCONF_get_number_e` / `NCONF_get_section` — value access
- `NCONF_default` / `NCONF_WIN32` — built-in method factories

### Module System
- `CONF_modules_load` / `CONF_modules_load_file` — load modules from config
- `CONF_module_add` — register a custom module with init/finish callbacks
- `CONF_imodule_get_*` / `CONF_imodule_set_*` — inspect/modify module instances

## Usage Example

```c
#include <openssl/conf.h>

/* Load a config file using the modern NCONF API */
CONF *conf = NCONF_new(NCONF_default());
long eline = 0;

if (!NCONF_load(conf, "/etc/ssl/openssl.cnf", &eline)) {
    fprintf(stderr, "Error on line %ld\n", eline);
    NCONF_free(conf);
    return -1;
}

/* Read a value from a named section */
const char *val = NCONF_get_string(conf, "req", "default_bits");
if (val)
    printf("default_bits = %s\n", val);

/* Load and run any [openssl_conf] modules */
CONF_modules_load(conf, "myapp", CONF_MFLAGS_IGNORE_MISSING_FILE);

NCONF_free(conf);
```
