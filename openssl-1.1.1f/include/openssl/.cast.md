OpenSSL CAST-128 symmetric block cipher interface header, providing key scheduling and encryption/decryption operations in multiple cipher modes.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `CAST_ENCRYPT` | `1` | Direction flag for encryption |
| `CAST_DECRYPT` | `0` | Direction flag for decryption |
| `CAST_BLOCK` | `8` | Block size in bytes |
| `CAST_KEY_LENGTH` | `16` | Maximum key length in bytes |

### Types

- **`CAST_KEY`** — Key schedule struct holding 32 subkeys (`data[32]`) and a `short_key` flag for reduced-round operation with keys shorter than 128 bits.

### Functions

| Function | Description |
|---|---|
| `CAST_set_key` | Expands raw key bytes into a `CAST_KEY` schedule |
| `CAST_ecb_encrypt` | Encrypts/decrypts a single 8-byte ECB block |
| `CAST_encrypt` | Raw block encryption (in-place) |
| `CAST_decrypt` | Raw block decryption (in-place) |
| `CAST_cbc_encrypt` | CBC mode encrypt/decrypt over arbitrary length |
| `CAST_cfb64_encrypt` | 64-bit CFB streaming mode |
| `CAST_ofb64_encrypt` | 64-bit OFB streaming mode |

## Usage Example

```c
#include <openssl/cast.h>

/* Key setup */
CAST_KEY key;
unsigned char raw_key[CAST_KEY_LENGTH] = { /* 16 bytes */ };
CAST_set_key(&key, CAST_KEY_LENGTH, raw_key);

/* CBC encryption */
unsigned char iv[CAST_BLOCK] = {0};
unsigned char plaintext[16]  = "Hello, CAST-128!";
unsigned char ciphertext[16];

CAST_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                 &key, iv, CAST_ENCRYPT);

/* CBC decryption (reset IV first) */
unsigned char iv2[CAST_BLOCK] = {0};
unsigned char recovered[16];
CAST_cbc_encrypt(ciphertext, recovered, sizeof(ciphertext),
                 &key, iv2, CAST_DECRYPT);
```

> **Note:** CAST is disabled when OpenSSL is built with `OPENSSL_NO_CAST`. Prefer AES for new applications; CAST-128 is provided for legacy compatibility.
