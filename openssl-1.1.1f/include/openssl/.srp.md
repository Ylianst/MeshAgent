OpenSSL SRP (Secure Remote Password) protocol header defining data structures, constants, and function declarations for SRP-based authentication on both client and server sides.

## Key Components

### Structures

| Type | Description |
|------|-------------|
| `SRP_gN_cache` | Caches base64 and `BIGNUM` representations of generator/modulus pairs |
| `SRP_user_pwd` | Stores per-user credentials: identity, salt (`s`), verifier (`v`), generator (`g`), and modulus (`N`) |
| `SRP_VBASE` | Verifier database holding all user passwords, a cache of `g`/`N` pairs, and a seed key for simulated users |
| `SRP_gN` | Named `g`/`N` parameter pair (e.g., RFC 5054 well-known groups) |

### Server-Side Functions

- `SRP_Calc_B` — Computes the server public value `B`
- `SRP_Calc_server_key` — Derives the shared session key on the server
- `SRP_Verify_A_mod_N` — Validates the client's public value `A`
- `SRP_Calc_u` — Computes the random scrambling parameter `u`

### Client-Side Functions

- `SRP_Calc_x` — Derives the private key `x` from salt, username, and password
- `SRP_Calc_A` — Computes the client public value `A`
- `SRP_Calc_client_key` — Derives the shared session key on the client
- `SRP_Verify_B_mod_N` — Validates the server's public value `B`

### Verifier Database Functions

- `SRP_VBASE_new` / `SRP_VBASE_free` / `SRP_VBASE_init` — Lifecycle management for the verifier database
- `SRP_VBASE_get1_by_user` — Looks up a user record (caller owns the returned pointer)
- `SRP_create_verifier` / `SRP_create_verifier_BN` — Generates a salt and verifier for a new user

### Error Constants

```c
SRP_NO_ERROR                    // 0 — success
SRP_ERR_VBASE_INCOMPLETE_FILE   // 1
SRP_ERR_VBASE_BN_LIB            // 2
SRP_ERR_OPEN_FILE               // 3
SRP_ERR_MEMORY                  // 4
```

## Usage Example

```c
/* Server: initialize verifier database and look up a user */
SRP_VBASE *vb = SRP_VBASE_new(NULL);
if (SRP_VBASE_init(vb, "/etc/srp/verifiers.txt") != SRP_NO_ERROR) {
    /* handle error */
}

SRP_user_pwd *user = SRP_VBASE_get1_by_user(vb, "alice");
if (user) {
    /* Compute server public value B */
    BIGNUM *b = /* ephemeral private key */;
    BIGNUM *B  = SRP_Calc_B(b, user->N, user->g, user->v);

    /* After receiving client's A, compute session key */
    BIGNUM *u   = SRP_Calc_u(A, B, user->N);
    BIGNUM *key = SRP_Calc_server_key(A, user->v, u, b, user->N);

    SRP_user_pwd_free(user);
}
SRP_VBASE_free(vb);
```

> **Note:** `SRP_VBASE_get_by_user` is deprecated since OpenSSL 1.1.0. Use `SRP_VBASE_get1_by_user` instead, and free the returned pointer when done. The minimum accepted modulus size is `SRP_MINIMAL_N` (1024 bits).
