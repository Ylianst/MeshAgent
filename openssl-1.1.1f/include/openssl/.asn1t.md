OpenSSL ASN.1 template system header defining macros, structures, and type descriptors for encoding and decoding ASN.1 data structures using the OpenSSL template engine.

## Key Components

### Item Definition Macros
- **`ASN1_ITEM_start` / `ASN1_ITEM_end`** — Open/close an `ASN1_ITEM` definition (exported or static)
- **`ASN1_ITEM_TEMPLATE` / `ASN1_ITEM_TEMPLATE_END`** — Declare a primitive wrapper type

### SEQUENCE Macros
- **`ASN1_SEQUENCE` / `ASN1_SEQUENCE_END`** — Declare a standard SEQUENCE type
- **`ASN1_SEQUENCE_cb`** — SEQUENCE with a custom callback (`ASN1_AUX`)
- **`ASN1_SEQUENCE_ref`** — SEQUENCE with reference counting support
- **`ASN1_SEQUENCE_enc`** — SEQUENCE preserving raw encoding
- **`ASN1_NDEF_SEQUENCE` / `ASN1_NDEF_SEQUENCE_END`** — Indefinite-length SEQUENCE
- **`ASN1_BROKEN_SEQUENCE`** — Non-standard/broken SEQUENCE variant

### CHOICE Macros
- **`ASN1_CHOICE` / `ASN1_CHOICE_END`** — Declare a CHOICE type (requires `type` selector field)
- **`ASN1_CHOICE_END_selector`** — CHOICE with a custom selector field name
- **`ASN1_CHOICE_cb`** — CHOICE with callback

### Field Descriptor Macros
| Macro | Description |
|---|---|
| `ASN1_SIMPLE` | Plain untagged field |
| `ASN1_EMBED` | Embedded (inline, not pointer) field |
| `ASN1_OPT` | Optional field |
| `ASN1_IMP` | Implicit tagged field |
| `ASN1_EXP` | Explicit tagged field |
| `ASN1_IMP_OPT` | Implicit tagged optional field |
| `ASN1_ADB_OBJECT` | ADB dispatch by OID |
| `ASN1_ADB_INTEGER` | ADB dispatch by integer |

## Usage Example

```c
/* Define a simple ASN.1 SEQUENCE structure */
typedef struct my_struct_st {
    ASN1_INTEGER *version;
    ASN1_UTF8STRING *name;
} MY_STRUCT;

ASN1_SEQUENCE(MY_STRUCT) = {
    ASN1_SIMPLE(MY_STRUCT, version, ASN1_INTEGER),
    ASN1_OPT(MY_STRUCT, name, ASN1_UTF8STRING),
} ASN1_SEQUENCE_END(MY_STRUCT)

/* Define a CHOICE type */
typedef struct my_choice_st {
    int type;
    union {
        ASN1_INTEGER *num;
        ASN1_UTF8STRING *str;
    } value;
} MY_CHOICE;

ASN1_CHOICE(MY_CHOICE) = {
    ASN1_IMP(MY_CHOICE, value.num, ASN1_INTEGER, 0),
    ASN1_IMP(MY_CHOICE, value.str, ASN1_UTF8STRING, 1),
} ASN1_CHOICE_END(MY_CHOICE)
```
