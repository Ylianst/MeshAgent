OpenSSL EVP (Envelope) high-level cryptographic API header defining symmetric ciphers, message digests, and asymmetric key types for unified cryptographic operations.

## Key Components

### Constants & Macros

| Macro | Value | Purpose |
|---|---|---|
| `EVP_MAX_MD_SIZE` | 64 | Max digest output (SHA-512) |
| `EVP_MAX_KEY_LENGTH` | 64 | Max symmetric key size |
| `EVP_MAX_IV_LENGTH` | 16 | Max IV size |
| `PKCS5_DEFAULT_ITER` | 2048 | Default PBKDF2 iterations |

### Key Type Identifiers (`EVP_PKEY_*`)
Covers RSA, DSA, DH, EC, HMAC, CMAC, HKDF, Poly1305, X25519, Ed25519, X448, Ed448, SM2, and more.

### Cipher Modes (`EVP_CIPH_*`)
Stream, ECB, CBC, CFB, OFB, CTR, GCM, CCM, XTS, WRAP, OCB.

### Message Digest API (`EVP_MD_meth_*`)
- `EVP_MD_meth_new` / `EVP_MD_meth_dup` / `EVP_MD_meth_free` — lifecycle management
- `EVP_MD_meth_set_init` / `set_update` / `set_final` — custom digest callbacks
- `EVP_MD_meth_set_flags` — behavior flags (FIPS, XOF, ONESHOT)

### Cipher API (`EVP_CIPHER_meth_*`)
- `EVP_CIPHER_meth_new` / `EVP_CIPHER_meth_dup` / `EVP_CIPHER_meth_free` — lifecycle management
- `EVP_CIPHER_meth_set_init` / `set_do_cipher` / `set_cleanup` — cipher operation callbacks
- `EVP_CIPHER_meth_set_ctrl` — custom control handler

## Usage Example

```c
#include <openssl/evp.h>

/* Create a custom message digest method */
EVP_MD *md = EVP_MD_meth_new(NID_sha256, EVP_PKEY_RSA);
EVP_MD_meth_set_result_size(md, 32);
EVP_MD_meth_set_input_blocksize(md, 64);
EVP_MD_meth_set_init(md, my_init_fn);
EVP_MD_meth_set_update(md, my_update_fn);
EVP_MD_meth_set_final(md, my_final_fn);

/* Use and clean up */
/* ... register and use md ... */
EVP_MD_meth_free(md);

/* Create a custom cipher */
EVP_CIPHER *cipher = EVP_CIPHER_meth_new(NID_aes_128_cbc, 16, 16);
EVP_CIPHER_meth_set_iv_length(cipher, EVP_MAX_IV_LENGTH);
EVP_CIPHER_meth_set_flags(cipher, EVP_CIPH_CBC_MODE | EVP_CIPH_FLAG_DEFAULT_ASN1);
EVP_CIPHER_meth_set_init(cipher, my_cipher_init);
EVP_CIPHER_meth_set_do_cipher(cipher, my_do_cipher);
EVP_CIPHER_meth_free(cipher);
```
