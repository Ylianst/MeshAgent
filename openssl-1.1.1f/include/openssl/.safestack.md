Type-safe wrapper macros over OpenSSL's generic `OPENSSL_STACK`, enabling strongly-typed stack (dynamic array) operations for arbitrary C types.

## Key Components

| Macro / Type | Description |
|---|---|
| `STACK_OF(type)` | Declares a typed stack struct `stack_st_<type>` |
| `SKM_DEFINE_STACK_OF(t1, t2, t3)` | Core macro generating all typed inline stack operations for a type triple |
| `DEFINE_STACK_OF(t)` | Convenience wrapper for non-const homogeneous types |
| `DEFINE_STACK_OF_CONST(t)` | Variant for const-element stacks |
| `DEFINE_SPECIAL_STACK_OF(t1, t2)` | For types where the stack name differs from the element type |
| `DEFINE_SPECIAL_STACK_OF_CONST(t1, t2)` | Const variant of the above |
| `OPENSSL_STRING` / `OPENSSL_CSTRING` | Typedefs for `char *` / `const char *` with pre-built stacks |
| `OPENSSL_BLOCK` | Typedef for `void *` with a pre-built stack |

`SKM_DEFINE_STACK_OF` generates typed inline functions including: `_num`, `_value`, `_new`, `_new_null`, `_new_reserve`, `_reserve`, `_free`, `_zero`, `_delete`, `_delete_ptr`, `_push`, `_unshift`, `_pop`, `_shift`, `_pop_free`, `_insert`, `_set`, `_find`, `_find_ex`, `_sort`, `_is_sorted`, `_dup`, `_deep_copy`, `_set_cmp_func`.

## Usage Example

```c
/* Define a typed stack for a custom struct */
typedef struct my_cert_st MY_CERT;

DEFINE_STACK_OF(MY_CERT)

/* Now use generated typed functions */
STACK_OF(MY_CERT) *certs = sk_MY_CERT_new_null();
sk_MY_CERT_push(certs, cert_ptr);

int count = sk_MY_CERT_num(certs);
MY_CERT *item = sk_MY_CERT_value(certs, 0);

/* Free stack and all elements using a custom free function */
sk_MY_CERT_pop_free(certs, MY_CERT_free);

/* Use built-in string stack */
STACK_OF(OPENSSL_STRING) *names = sk_OPENSSL_STRING_new_null();
sk_OPENSSL_STRING_push(names, "example.com");
```
