Obsolete OpenSSL header file that previously contained ASN.1 macro definitions. This file has been removed from active use and exists solely to produce a compile-time error directing developers to update their software.

## Key Components

- `#error` directive — Emits a fatal compile-time error with the message: `"This file is obsolete; please update your software."`

## Usage Example

Any attempt to include this header will result in a compile-time failure:

```c
#include <openssl/asn1_mac.h>
/* Error: "This file is obsolete; please update your software." */
```

> **Action required:** Remove all `#include <openssl/asn1_mac.h>` directives from your codebase. Refer to the current [OpenSSL ASN.1 API](https://www.openssl.org/docs/man1.1.1/man3/) for replacement macros and functions.
