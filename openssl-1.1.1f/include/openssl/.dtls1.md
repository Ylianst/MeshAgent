DTLS (Datagram Transport Layer Security) protocol version constants and message header length definitions for the OpenSSL DTLS implementation.

## Key Components

### Version Constants

| Constant | Value | Description |
|---|---|---|
| `DTLS1_VERSION` | `0xFEFF` | DTLS 1.0 protocol version |
| `DTLS1_2_VERSION` | `0xFEFD` | DTLS 1.2 protocol version |
| `DTLS_MIN_VERSION` | `DTLS1_VERSION` | Minimum supported DTLS version |
| `DTLS_MAX_VERSION` | `DTLS1_2_VERSION` | Maximum supported DTLS version |
| `DTLS1_BAD_VER` | `0x0100` | Legacy bad version indicator |
| `DTLS_ANY_VERSION` | `0x1FFFF` | Multi-version method sentinel |

### Message Length Constants

| Constant | Value | Description |
|---|---|---|
| `DTLS1_COOKIE_LENGTH` | `256` | Max cookie buffer length (note: actual DTLS max is 255) |
| `DTLS1_RT_HEADER_LENGTH` | `13` | Record layer header size in bytes |
| `DTLS1_HM_HEADER_LENGTH` | `12` | Handshake message header size in bytes |
| `DTLS1_CCS_HEADER_LENGTH` | `1` | ChangeCipherSpec header size in bytes |
| `DTLS1_AL_HEADER_LENGTH` | `2` | Alert header size in bytes |

### Fragment/Timeout Constants

| Constant | Value | Description |
|---|---|---|
| `DTLS1_HM_BAD_FRAGMENT` | `-2` | Return code for malformed fragment |
| `DTLS1_HM_FRAGMENT_RETRY` | `-3` | Return code signaling fragment retry |
| `DTLS1_TMO_READ_COUNT` | `2` | Read timeout multiplier |
| `DTLS1_TMO_WRITE_COUNT` | `2` | Write timeout multiplier |
| `DTLS1_TMO_ALERT_COUNT` | `12` | Alert timeout multiplier |

## Usage Example

```c
#include <openssl/dtls1.h>

/* Version negotiation check */
if (version < DTLS_MIN_VERSION || version > DTLS_MAX_VERSION) {
    /* Unsupported DTLS version */
    return SSL_ERROR;
}

/* Allocate buffer using defined header length */
uint8_t record_buf[DTLS1_RT_HEADER_LENGTH + payload_len];

/* Check handshake fragment processing result */
int ret = dtls1_process_handshake_fragment(s);
if (ret == DTLS1_HM_BAD_FRAGMENT) {
    /* Discard and continue */
} else if (ret == DTLS1_HM_FRAGMENT_RETRY) {
    /* Request retransmission */
}
```

> **Note:** `DTLS1_COOKIE_LENGTH` is set to `256` rather than the protocol maximum of `255` for historical compatibility reasons.
