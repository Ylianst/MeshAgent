Platform detection and portability header for OpenSSL, providing OS identification macros, cross-platform type definitions, linkage attributes, and compiler portability utilities.

## Key Components

### OS Detection Macros
Cascading preprocessor logic to define exactly one primary platform macro:

| Macro | Platform |
|---|---|
| `OPENSSL_SYS_WINDOWS` | Any Windows variant (Win32, Win64, WinNT, WinCE) |
| `OPENSSL_SYS_UNIX` | Default; unset when a specific OS is detected |
| `OPENSSL_SYS_VMS` | OpenVMS (DEC/HP) |
| `OPENSSL_SYS_LINUX` | Linux |
| `OPENSSL_SYS_VOS` | Stratus VOS |
| `OPENSSL_SYS_UEFI` | UEFI firmware environment |

### Linkage Macros
- **`OPENSSL_EXPORT`** — marks symbols exported from a shared library (`__declspec(dllexport)` on Windows DLL builds)
- **`OPENSSL_EXTERN`** — marks symbols imported from a shared library (`__declspec(dllimport)` on Windows DLL builds)

### Global Variable Macros
- **`OPENSSL_IMPLEMENT_GLOBAL(type, name, value)`** — defines a global variable (or function-wrapped accessor)
- **`OPENSSL_DECLARE_GLOBAL(type, name)`** — declares the global in headers
- **`OPENSSL_GLOBAL_REF(name)`** — dereferences the global portably

### Portable Type Aliases
- **`ossl_ssize_t`** / **`OSSL_SSIZE_MAX`** — signed size type across Windows, UEFI, and POSIX
- **`int8_t` … `uint64_t`** — fixed-width integer typedefs for UEFI and legacy MSVC (≤ VS2008); otherwise pulls from `<stdint.h>` / `<inttypes.h>`

### Compiler Portability Macros
- **`ossl_inline`** — portable `inline` keyword (C99, GCC, MSVC)
- **`ossl_noreturn`** — portable `_Noreturn` / `__attribute__((noreturn))`
- **`ossl_unused`** — portable `__attribute__((unused))`
- **`__owur`** — warn-on-unused-result (enabled by `DEBUG_UNUSED`)

## Usage Example

```c
/* Declaring and defining a shared global portably */

/* foobar.h */
#include <openssl/e_os2.h>
OPENSSL_DECLARE_GLOBAL(int, foobar);
#define foobar OPENSSL_GLOBAL_REF(foobar)

/* foobar.c */
OPENSSL_IMPLEMENT_GLOBAL(int, foobar, 0)

/* Exporting a function from an OpenSSL shared library */
OPENSSL_EXPORT int OPENSSL_some_function(void);
```
