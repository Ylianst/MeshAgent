OpenSSL X.509 certificate management header providing core data structures, constants, and function declarations for handling digital certificates, CRLs, certificate requests, and related PKI operations.

## Key Components

### Core Structures
- **`X509_ALGOR`** — Algorithm identifier (OID + parameters)
- **`X509_VAL`** — Certificate validity period (`notBefore`/`notAfter`)
- **`X509_TRUST`** — Trust checking callback with trust ID, flags, and name
- **`X509_INFO`** — Container bundling a certificate, CRL, and private key
- **`X509_PKEY`** — PKCS#8 encrypted private key holder
- **`NETSCAPE_SPKAC`** / **`NETSCAPE_SPKI`** — Netscape signed public key and challenge structures
- **`PBEPARAM`**, **`PBE2PARAM`**, **`PBKDF2PARAM`**, **`SCRYPT_PARAMS`** — Password-based encryption parameter structures

### Key Usage Flags (`X509v3_KU_*`)
Bitmasks for certificate key usage extensions: `DIGITAL_SIGNATURE`, `KEY_ENCIPHERMENT`, `KEY_CERT_SIGN`, `CRL_SIGN`, etc.

### Trust IDs (`X509_TRUST_*`)
Standard trust contexts: `SSL_CLIENT`, `SSL_SERVER`, `EMAIL`, `OBJECT_SIGN`, `OCSP_SIGN`, `TSA`.

### Print Flags
- **`X509_FLAG_*`** — Control fields shown by `X509_print_ex()`
- **`XN_FLAG_*`** — Control `X509_NAME` formatting (RFC 2253, oneline, multiline)

### Key Functions
- **`X509_verify`** / **`X509_sign`** — Certificate signature verification and signing
- **`X509_CRL_verify`** / **`X509_CRL_sign`** — CRL verification and signing
- **`X509_REQ_verify`** / **`X509_REQ_sign`** — CSR verification and signing
- **`X509_digest`** / **`X509_pubkey_digest`** — Compute digests over certificate data
- **`NETSCAPE_SPKI_b64_decode`** / **`NETSCAPE_SPKI_b64_encode`** — Base64 encode/decode SPKI
- **`X509_CRL_METHOD_new`** — Register custom CRL handling methods

## Usage Example

```c
#include <openssl/x509.h>
#include <openssl/pem.h>

/* Verify a certificate against a public key */
int verify_cert(X509 *cert, EVP_PKEY *pubkey) {
    int ret = X509_verify(cert, pubkey);
    if (ret <= 0) {
        fprintf(stderr, "Verification failed\n");
        return 0;
    }
    return 1;
}

/* Sign a certificate request */
int sign_csr(X509_REQ *req, EVP_PKEY *pkey) {
    return X509_REQ_sign(req, pkey, EVP_sha256());
}

/* Compute SHA-256 digest of a certificate */
void cert_digest(X509 *cert) {
    unsigned char md[SHA256_DIGEST_LENGTH];
    unsigned int len;
    X509_digest(cert, EVP_sha256(), md, &len);
}
```
