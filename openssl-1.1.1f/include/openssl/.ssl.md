OpenSSL SSL/TLS public API header defining core types, constants, and interfaces for establishing and managing SSL/TLS connections within the OpenSSL library.

## Key Components

### Core Type Definitions
- **`SSL_METHOD`** — Protocol method structure (TLS/DTLS version-specific)
- **`SSL_CIPHER`** — Cipher suite descriptor
- **`SSL_SESSION`** — Session state for resumption
- **`SSL_CONF_CTX`** — Configuration context
- **`SRTP_PROTECTION_PROFILE`** — SRTP profile for DTLS-SRTP (RFC 5764)

### Session Constants
| Constant | Value | Purpose |
|---|---|---|
| `SSL_MAX_SSL_SESSION_ID_LENGTH` | 32 | Max session ID length |
| `SSL_MAX_MASTER_KEY_LENGTH` | 48 | Max master key length |
| `SSL_MAX_PIPELINES` | 32 | Max encrypt/decrypt pipelines |

### Cipher Text Selectors (`SSL_TXT_*`)
String aliases for cipher selection (passed to `SSL_CTX_set_cipher_list`), covering key exchange (`kRSA`, `kDHE`, `kECDHE`), authentication (`aRSA`, `aECDSA`), encryption (`AES`, `CHACHA20`), and MAC algorithms (`SHA256`, `SHA384`).

### Default Cipher Lists
- **`SSL_DEFAULT_CIPHER_LIST`** — `"ALL:!COMPLEMENTOFDEFAULT:!eNULL"` for TLS 1.2 and below
- **`TLS_DEFAULT_CIPHERSUITES`** — TLS 1.3 suites (AES-256-GCM, ChaCha20-Poly1305, AES-128-GCM)

### Extension Context Flags (`SSL_EXT_*`)
Bitmask flags controlling where custom TLS extensions are valid (e.g., `SSL_EXT_TLS1_3_ONLY`, `SSL_EXT_CLIENT_HELLO`).

### Callback Typedefs
- **`SSL_verify_cb`** — Certificate verification callback
- **`custom_ext_add_cb` / `custom_ext_parse_cb`** — Legacy custom extension callbacks
- **`SSL_custom_ext_add_cb_ex` / `SSL_custom_ext_parse_cb_ex`** — Extended custom extension callbacks with context and chain index

## Usage Example

```c
#include <openssl/ssl.h>

/* Initialize context with TLS method */
SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());

/* Set cipher list for TLS 1.2 and below */
SSL_CTX_set_cipher_list(ctx, SSL_DEFAULT_CIPHER_LIST);

/* Set cipher suites for TLS 1.3 */
SSL_CTX_set_ciphersuites(ctx, TLS_DEFAULT_CIPHERSUITES);

/* Register a custom verification callback */
SSL_CTX_set_verify(ctx, SSL_VERIFY_PEER, my_verify_cb);

SSL *ssl = SSL_new(ctx);
/* ... connect, handshake, read/write ... */
SSL_free(ssl);
SSL_CTX_free(ctx);
```
