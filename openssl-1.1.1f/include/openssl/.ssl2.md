Legacy SSLv2 protocol constants header, providing minimal version and message type definitions retained for historical compatibility within the OpenSSL library.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `SSL2_VERSION` | `0x0002` | SSLv2 protocol version identifier |
| `SSL2_MT_CLIENT_HELLO` | `1` | Message type for SSLv2 Client Hello handshake message |

## Usage Example

```c
#include <openssl/ssl2.h>

/* Check if a negotiated version matches SSLv2 */
if (negotiated_version == SSL2_VERSION) {
    /* SSLv2 is deprecated and insecure - reject connection */
    reject_connection();
}

/* Identify an SSLv2 handshake message type */
if (msg_type == SSL2_MT_CLIENT_HELLO) {
    handle_legacy_client_hello();
}
```

> **⚠️ Security Warning:** SSLv2 is cryptographically broken and deprecated. These constants exist solely for legacy detection and compatibility purposes. Never use SSLv2 in production systems.

## Notes

- This header is a stub — the full SSLv2 implementation was removed from OpenSSL due to severe security vulnerabilities (e.g., [DROWN attack](https://drownattack.com/))
- The `extern "C"` guards ensure C++ compatibility
- Use TLS 1.2+ (`TLS_VERSION`) for any active protocol negotiation
