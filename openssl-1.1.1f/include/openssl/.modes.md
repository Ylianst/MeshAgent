OpenSSL block cipher mode of operation definitions and function declarations for symmetric encryption primitives used across the cryptographic library.

## Key Components

### Function Pointer Types

| Type | Description |
|------|-------------|
| `block128_f` | Single 128-bit block encryption/decryption |
| `cbc128_f` | CBC mode operation |
| `ctr128_f` | CTR mode streaming operation |
| `ccm128_f` | CCM mode with CMAC computation |
| `ocb128_f` | OCB mode with offset/checksum state |

### Cipher Mode APIs

| Mode | Functions |
|------|-----------|
| **CBC** | `CRYPTO_cbc128_encrypt`, `CRYPTO_cbc128_decrypt` |
| **CTR** | `CRYPTO_ctr128_encrypt`, `CRYPTO_ctr128_encrypt_ctr32` |
| **OFB** | `CRYPTO_ofb128_encrypt` |
| **CFB** | `CRYPTO_cfb128_encrypt`, `CRYPTO_cfb128_8_encrypt`, `CRYPTO_cfb128_1_encrypt` |
| **CTS** | `CRYPTO_cts128_encrypt`, `CRYPTO_cts128_decrypt` (block and CBC variants) |
| **NIST CTS** | `CRYPTO_nistcts128_encrypt`, `CRYPTO_nistcts128_decrypt` |
| **GCM** | Full AEAD context API via `GCM128_CONTEXT` |
| **CCM** | Full AEAD context API via `CCM128_CONTEXT` |
| **XTS** | `CRYPTO_xts128_encrypt` via `XTS128_CONTEXT` |
| **Key Wrap** | `CRYPTO_128_wrap`, `CRYPTO_128_unwrap` (padded variants included) |
| **OCB** | Full AEAD context API via `OCB128_CONTEXT` (conditional on `OPENSSL_NO_OCB`) |

## Usage Example

```c
#include <openssl/modes.h>

/* CBC encryption using a custom block function */
unsigned char ivec[16] = {0};

CRYPTO_cbc128_encrypt(plaintext, ciphertext, len,
                      key_schedule, ivec, my_block_fn);

/* GCM AEAD encrypt */
GCM128_CONTEXT *ctx = CRYPTO_gcm128_new(key, my_block_fn);
CRYPTO_gcm128_setiv(ctx, iv, iv_len);
CRYPTO_gcm128_aad(ctx, aad, aad_len);
CRYPTO_gcm128_encrypt(ctx, plaintext, ciphertext, len);
CRYPTO_gcm128_tag(ctx, tag, 16);
CRYPTO_gcm128_release(ctx);
```

> **Note:** All mode functions operate on 128-bit (16-byte) blocks. AEAD modes (GCM, CCM, OCB) require full context lifecycle management: init → set IV → process AAD → encrypt/decrypt → finalize tag.
