OpenSSL core cryptography header providing fundamental infrastructure for memory management, thread safety, version information, and extensible data storage used throughout the OpenSSL library.

## Key Components

### Thread Safety
- `CRYPTO_RWLOCK` — opaque read/write lock type
- `CRYPTO_THREAD_lock_new()` / `CRYPTO_THREAD_lock_free()` — lock lifecycle
- `CRYPTO_THREAD_read_lock()` / `CRYPTO_THREAD_write_lock()` / `CRYPTO_THREAD_unlock()` — lock operations
- `CRYPTO_atomic_add()` — atomic integer addition

### Memory Management Macros
Wrappers that inject `__FILE__`/`__LINE__` for leak tracking:
- `OPENSSL_malloc(n)` / `OPENSSL_zalloc(n)` / `OPENSSL_free(addr)`
- `OPENSSL_realloc()` / `OPENSSL_clear_realloc()` / `OPENSSL_clear_free()`
- `OPENSSL_memdup()` / `OPENSSL_strdup()` / `OPENSSL_strndup()`
- `OPENSSL_secure_malloc()` / `OPENSSL_secure_zalloc()` / `OPENSSL_secure_free()` — secure heap variants

### Extensible Extra Data (`CRYPTO_EX_DATA`)
Allows attaching arbitrary data to OpenSSL objects (SSL, X509, RSA, etc.):
- `CRYPTO_get_ex_new_index()` — register a new index with callbacks
- `CRYPTO_new_ex_data()` / `CRYPTO_dup_ex_data()` / `CRYPTO_free_ex_data()`
- `CRYPTO_set_ex_data()` / `CRYPTO_get_ex_data()`

### Version Info
- `OpenSSL_version_num()` — numeric version
- `OpenSSL_version(type)` — string version (`OPENSSL_VERSION`, `OPENSSL_CFLAGS`, etc.)

### String Utilities
- `OPENSSL_strlcpy()` / `OPENSSL_strlcat()` / `OPENSSL_strnlen()`
- `OPENSSL_buf2hexstr()` / `OPENSSL_hexstr2buf()` / `OPENSSL_hexchar2int()`
- `OPENSSL_cleanse()` — securely zero memory

## Usage Example

```c
#include <openssl/crypto.h>

/* Thread-safe allocation and ex_data usage */
int ex_idx;

void example(void) {
    CRYPTO_RWLOCK *lock = CRYPTO_THREAD_lock_new();

    /* Tracked allocation */
    char *buf = OPENSSL_malloc(256);
    OPENSSL_strlcpy(buf, "hello", 256);

    /* Secure heap for sensitive data */
    unsigned char *key = OPENSSL_secure_malloc(32);
    /* ... use key ... */
    OPENSSL_cleanse(key, 32);
    OPENSSL_secure_free(key);

    OPENSSL_free(buf);
    CRYPTO_THREAD_lock_free(lock);

    /* Version check */
    if (OpenSSL_version_num() < 0x10100000L) {
        /* handle old version */
    }
}

/* Register ex_data index for a custom SSL attachment */
ex_idx = CRYPTO_get_ex_new_index(
    CRYPTO_EX_INDEX_SSL, 0, NULL, NULL, NULL, NULL
);
```
