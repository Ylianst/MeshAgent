OpenSSL data compression interface header providing context management and block-level compress/expand operations via pluggable `COMP_METHOD` backends.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `COMP_CTX_new` | Function | Allocates a new compression context for the given method |
| `COMP_CTX_free` | Function | Releases a compression context |
| `COMP_CTX_get_method` | Function | Returns the `COMP_METHOD` associated with a context |
| `COMP_CTX_get_type` | Function | Returns the numeric type identifier of a context |
| `COMP_get_type` | Function | Returns the numeric type identifier of a method |
| `COMP_get_name` | Function | Returns the human-readable name of a method |
| `COMP_compress_block` | Function | Compresses `ilen` bytes from `in` into `out` |
| `COMP_expand_block` | Function | Decompresses `ilen` bytes from `in` into `out` |
| `COMP_zlib` | Function | Returns the built-in zlib `COMP_METHOD` |
| `BIO_f_zlib` | Function | Returns a zlib BIO filter (available when `ZLIB` and `HEADER_BIO_H` are defined) |

> The entire API is guarded by `OPENSSL_NO_COMP`; if that macro is defined, no symbols are declared.

## Usage Example

```c
#include <openssl/comp.h>

/* Compress a block using zlib */
COMP_METHOD *method = COMP_zlib();
COMP_CTX    *ctx    = COMP_CTX_new(method);

unsigned char out[4096];
int out_len = COMP_compress_block(ctx, out, sizeof(out), in, in_len);
if (out_len < 0) {
    /* handle error */
}

/* Decompress */
unsigned char restored[4096];
int res_len = COMP_expand_block(ctx, restored, sizeof(restored), out, out_len);

COMP_CTX_free(ctx);
```
