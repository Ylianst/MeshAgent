Central OpenSSL type definitions header that provides forward declarations and typedefs for all major OpenSSL data structures used across the library.

## Key Components

### ASN1 Types
Typedefs mapping ASN.1 string variants to `asn1_string_st`, with a `NO_ASN1_TYPEDEFS` fallback that maps them all to `ASN1_STRING` macros:

| Type | Description |
|---|---|
| `ASN1_INTEGER` | ASN.1 integer |
| `ASN1_BIT_STRING` | Bit string |
| `ASN1_UTCTIME` / `ASN1_GENERALIZEDTIME` | Time types |
| `ASN1_UTF8STRING` | UTF-8 string |
| `ASN1_BOOLEAN` / `ASN1_NULL` | Primitive types (`int`) |

### Cryptographic Primitives
- **Big Number:** `BIGNUM`, `BN_CTX`, `BN_BLINDING`, `BN_MONT_CTX`, `BN_RECP_CTX`, `BN_GENCB`
- **EVP (Envelope):** `EVP_CIPHER`, `EVP_CIPHER_CTX`, `EVP_MD`, `EVP_MD_CTX`, `EVP_PKEY`, `EVP_PKEY_CTX`
- **Algorithms:** `RSA`, `RSA_METHOD`, `RSA_PSS_PARAMS`, `DSA`, `DSA_METHOD`, `DH`, `DH_METHOD`, `EC_KEY`, `EC_KEY_METHOD`
- **RAND:** `RAND_METHOD`, `RAND_DRBG`
- **HMAC:** `HMAC_CTX`

### X.509 / PKI
`X509`, `X509_ALGOR`, `X509_CRL`, `X509_NAME`, `X509_STORE`, `X509_STORE_CTX`, `X509_VERIFY_PARAM`, `X509_POLICY_TREE`, `PKCS8_PRIV_KEY_INFO`

### TLS / SSL
`SSL`, `SSL_CTX`, `SSL_DANE`, `COMP_CTX`, `COMP_METHOD`

### Certificate Transparency
`SCT`, `SCT_CTX`, `CTLOG`, `CTLOG_STORE`, `CT_POLICY_EVAL_CTX`

### Portable Integer Types
```c
/* C99 with intmax_t support */
typedef intmax_t  ossl_intmax_t;
typedef uintmax_t ossl_uintmax_t;

/* Fallback for pre-C99 */
typedef long          ossl_intmax_t;
typedef unsigned long ossl_uintmax_t;
```

## Usage Example

```c
#include <openssl/ossl_typ.h>

/* Use forward-declared types without pulling in full headers */
EVP_PKEY     *pkey = NULL;
EVP_MD_CTX   *mdctx = EVP_MD_CTX_new();
X509         *cert = NULL;
BIGNUM       *bn = BN_new();
RSA          *rsa = RSA_new();

/* Portable max-width integer parsing */
ossl_intmax_t  value;
ossl_uintmax_t uvalue;
```

> **Note:** This header is included transitively by most OpenSSL headers. Include it directly only when you need type-only declarations without pulling in full struct definitions or function prototypes.
