## Key Components

- **`ERR_load_SSL_strings()`** — Registers SSL error strings with the OpenSSL error system; must be called before SSL error messages are human-readable.

#include <openssl/sslerr.h>
#include <openssl/err.h>

int main(void) {
    /* Load SSL error strings so ERR_print_errors produces readable output */
    ERR_load_SSL_strings();

    SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());

}

> **Note:** In OpenSSL 1.1.0+, `ERR_load_SSL_strings()` is called automatically by `SSL_library_init()` / `OPENSSL_init_ssl()`. Direct calls are rarely needed in modern code.
