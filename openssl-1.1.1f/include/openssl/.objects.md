OpenSSL object identifier (OID) management header providing the public API for looking up, creating, and comparing ASN.1 object identifiers, along with a generic name registry and type-safe binary search utilities.

## Key Components

### `OBJ_NAME` Registry
A named-object registry supporting multiple type namespaces (digest methods, ciphers, public key methods, compression methods) with alias support.

| Constant | Value | Description |
|---|---|---|
| `OBJ_NAME_TYPE_MD_METH` | `0x01` | Message digest methods |
| `OBJ_NAME_TYPE_CIPHER_METH` | `0x02` | Cipher methods |
| `OBJ_NAME_TYPE_PKEY_METH` | `0x03` | Public key methods |
| `OBJ_NAME_ALIAS` | `0x8000` | Flag marking an alias entry |

### OID Lookup Functions
- `OBJ_nid2obj` / `OBJ_nid2ln` / `OBJ_nid2sn` — NID to object/long name/short name
- `OBJ_obj2nid` / `OBJ_txt2nid` / `OBJ_ln2nid` / `OBJ_sn2nid` — reverse lookups
- `OBJ_txt2obj` / `OBJ_obj2txt` — text/DER conversions
- `OBJ_cmp` — compare two `ASN1_OBJECT` instances

### Signature Algorithm Helpers
- `OBJ_find_sigid_algs` — resolve a combined signature NID to digest + key NIDs
- `OBJ_find_sigid_by_algs` — reverse lookup
- `OBJ_add_sigid` — register a new combination

### Type-Safe Binary Search Macros
Macros that generate strongly-typed wrappers around `OBJ_bsearch_` / `OBJ_bsearch_ex_`:
- `DECLARE_OBJ_BSEARCH_CMP_FN` / `IMPLEMENT_OBJ_BSEARCH_CMP_FN` — file-scoped
- `DECLARE_OBJ_BSEARCH_GLOBAL_CMP_FN` / `IMPLEMENT_OBJ_BSEARCH_GLOBAL_CMP_FN` — globally visible

## Usage Example

```c
#include <openssl/objects.h>

/* Look up an OID by NID */
int nid = OBJ_sn2nid("SHA256");
const char *long_name = OBJ_nid2ln(nid); /* "sha256WithRSAEncryption" etc. */

/* Convert text OID to ASN1_OBJECT */
ASN1_OBJECT *obj = OBJ_txt2obj("2.16.840.1.101.3.4.2.1", 1);
char buf[128];
OBJ_obj2txt(buf, sizeof(buf), obj, 0); /* human-readable name */

/* Register a custom OID */
OBJ_create("1.2.3.4.5", "myOID", "My Custom OID");

/* Resolve signature algorithm NIDs */
int dig_nid, pkey_nid;
OBJ_find_sigid_algs(NID_sha256WithRSAEncryption, &dig_nid, &pkey_nid);
```
