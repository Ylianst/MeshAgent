OpenSSL Cryptographic Message Syntax (CMS) public API header, providing types, constants, and function declarations for S/MIME and CMS operations including signing, encryption, and verification of cryptographic messages.

## Key Components

### Core Types
- `CMS_ContentInfo` — Primary structure representing a CMS message
- `CMS_SignerInfo` — Signer information for signed data
- `CMS_RecipientInfo` — Recipient information for enveloped data
- `CMS_ReceiptRequest` / `CMS_Receipt` — S/MIME receipt handling

### Operation Flags
| Flag | Purpose |
|------|---------|
| `CMS_DETACHED` | Detached signature mode |
| `CMS_STREAM` | Streaming I/O support |
| `CMS_BINARY` | Binary content (no MIME encoding) |
| `CMS_NOVERIFY` | Skip certificate verification |
| `CMS_NOCERTS` | Omit certificates from output |

### Recipient Info Types
- `CMS_RECIPINFO_TRANS` — Key transport (RSA)
- `CMS_RECIPINFO_AGREE` — Key agreement (DH/ECDH)
- `CMS_RECIPINFO_KEK` — Key encryption key
- `CMS_RECIPINFO_PASS` — Password-based

## Key Functions

| Function | Purpose |
|----------|---------|
| `CMS_sign()` | Create a signed CMS message |
| `CMS_verify()` | Verify a signed CMS message |
| `CMS_encrypt()` | Create an enveloped (encrypted) message |
| `CMS_decrypt()` | Decrypt an enveloped message |
| `CMS_compress()` / `CMS_uncompress()` | Compressed data content type |
| `SMIME_read_CMS()` / `SMIME_write_CMS()` | S/MIME I/O |

## Usage Example

```c
#include <openssl/cms.h>
#include <openssl/pem.h>

/* Sign data using a certificate and private key */
CMS_ContentInfo *cms = CMS_sign(
    signcert,           /* X509 signing certificate */
    pkey,               /* EVP_PKEY private key */
    NULL,               /* extra certs chain */
    data_bio,           /* BIO containing data to sign */
    CMS_DETACHED | CMS_BINARY
);

/* Write as S/MIME */
SMIME_write_CMS(out_bio, cms, data_bio, CMS_DETACHED);

/* Verify a received CMS message */
int ok = CMS_verify(cms, certs, store, dcont_bio, out_bio, 0);

CMS_ContentInfo_free(cms);
```
