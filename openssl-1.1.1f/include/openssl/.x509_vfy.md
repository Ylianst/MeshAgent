OpenSSL X.509 certificate verification header defining the core structures, error codes, verification flags, and callback function types used for certificate chain validation.

## Key Components

### Types & Enumerations
- **`X509_LOOKUP_TYPE`** — Enum distinguishing lookup results: `X509_LU_NONE`, `X509_LU_X509`, `X509_LU_CRL`
- **Stack types** — `STACK_OF(X509_LOOKUP)`, `STACK_OF(X509_OBJECT)`, `STACK_OF(X509_VERIFY_PARAM)`

### Callback Function Types
| Type | Purpose |
|---|---|
| `X509_STORE_CTX_verify_cb` | Custom verification callback |
| `X509_STORE_CTX_verify_fn` | Full chain verification override |
| `X509_STORE_CTX_get_issuer_fn` | Custom issuer lookup |
| `X509_STORE_CTX_check_revocation_fn` | Revocation check override |
| `X509_STORE_CTX_get_crl_fn` | CRL retrieval |
| `X509_STORE_CTX_check_policy_fn` | Policy validation |
| `X509_STORE_CTX_lookup_certs_fn` | Certificate lookup by name |
| `X509_STORE_CTX_cleanup_fn` | Context cleanup |

### Verification Error Codes (`X509_V_ERR_*`)
75+ error codes covering:
- Chain/issuer errors (2–24)
- CRL errors (3, 8, 11–12)
- Policy errors (42–54)
- Suite B algorithm violations (56–61)
- Host/email/IP mismatches (62–64)
- OCSP status errors (73–75)

### Verification Flags (`X509_V_FLAG_*`)
Bitmask flags controlling verification behavior:
- `X509_V_FLAG_CRL_CHECK` / `X509_V_FLAG_CRL_CHECK_ALL` — CRL lookups
- `X509_V_FLAG_POLICY_CHECK` — Enable policy validation
- `X509_V_FLAG_PARTIAL_CHAIN` — Accept partial trust chains
- `X509_V_FLAG_TRUSTED_FIRST` — Prefer trusted store
- `X509_V_FLAG_NO_CHECK_TIME` — Skip validity period checks
- `X509_V_FLAG_SUITEB_*` — Suite B compliance modes

## Usage Example

```c
#include <openssl/x509_vfy.h>

/* Custom verification callback */
int verify_cb(int ok, X509_STORE_CTX *ctx) {
    int err = X509_STORE_CTX_get_error(ctx);
    if (!ok && err == X509_V_ERR_CERT_HAS_EXPIRED) {
        /* Allow expired certs in this context */
        return 1;
    }
    return ok;
}

/* Set up a store with CRL checking enabled */
X509_STORE *store = X509_STORE_new();
X509_STORE_set_depth(store, 5);
X509_STORE_set_flags(store, X509_V_FLAG_CRL_CHECK | X509_V_FLAG_CRL_CHECK_ALL);
X509_STORE_set_verify_cb(store, verify_cb);

/* Load trusted certs via lookup */
X509_LOOKUP *lookup = X509_STORE_add_lookup(store, X509_LOOKUP_file());
X509_LOOKUP_load_file(lookup, "/etc/ssl/certs/ca-bundle.crt", X509_FILETYPE_PEM);
```
