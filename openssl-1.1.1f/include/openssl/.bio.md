OpenSSL BIO (Basic I/O) abstraction layer header, defining the types, flags, control codes, and function declarations for the BIO subsystem used throughout OpenSSL for all I/O operations.

## Key Components

### BIO Type Classes
- `BIO_TYPE_DESCRIPTOR` — socket/fd-backed BIOs
- `BIO_TYPE_FILTER` — transforming BIOs (SSL, MD, cipher, base64, buffer)
- `BIO_TYPE_SOURCE_SINK` — terminal I/O BIOs (mem, file, null)

### BIO Type Constants
Specific BIO implementations: `BIO_TYPE_MEM`, `BIO_TYPE_FILE`, `BIO_TYPE_FD`, `BIO_TYPE_SOCKET`, `BIO_TYPE_SSL`, `BIO_TYPE_MD`, `BIO_TYPE_BUFFER`, `BIO_TYPE_CONNECT`, `BIO_TYPE_ACCEPT`, `BIO_TYPE_DGRAM`, and SCTP variants.

### Control Codes (`BIO_CTRL_*`)
Integer constants passed to `BIO_ctrl()` for operations like reset, flush, EOF detection, pending byte queries, MTU management, and datagram configuration.

### Flags (`BIO_FLAGS_*`)
Bitmask flags for read/write state, retry signaling (`BIO_FLAGS_SHOULD_RETRY`), memory read-only mode, and base64 formatting.

### Callback Types
- `BIO_callback_fn` — legacy per-operation callback
- `BIO_callback_fn_ex` — extended callback with `size_t` length and processed-byte output

### Key Functions
- `BIO_get_new_index()`, `BIO_set_flags()`, `BIO_test_flags()`, `BIO_clear_flags()`
- `BIO_get_callback()` / `BIO_set_callback()` and `_ex` variants
- `BIO_method_name()`, `BIO_method_type()`

### Retry Macros
- `BIO_should_retry(a)`, `BIO_should_read(a)`, `BIO_should_write(a)`, `BIO_should_io_special(a)`

## Usage Example

```c
#include <openssl/bio.h>

/* Write to a memory BIO, then read back */
BIO *mem = BIO_new(BIO_s_mem());
BIO_write(mem, "hello", 5);

char buf[16];
int n = BIO_read(mem, buf, sizeof(buf));

/* Check if a retry is needed after a non-blocking operation */
if (n <= 0 && BIO_should_retry(mem)) {
    /* retry later */
}

BIO_free(mem);
```
