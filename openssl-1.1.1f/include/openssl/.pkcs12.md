OpenSSL PKCS#12 file format header providing structures, constants, and function declarations for creating, parsing, and managing PKCS#12 (PFX) containers used to bundle private keys with certificates.

## Key Components

### Types & Structures
- `PKCS12` — opaque PKCS#12 container structure
- `PKCS12_SAFEBAG` — safe bag structure holding keys, certificates, or CRLs
- `PKCS12_MAC_DATA` — MAC integrity data structure
- `PKCS12_BAGS` — inner bag content type

### Constants
| Constant | Value | Purpose |
|---|---|---|
| `PKCS12_KEY_ID` | 1 | Key derivation ID for key material |
| `PKCS12_IV_ID` | 2 | Key derivation ID for IV |
| `PKCS12_MAC_ID` | 3 | Key derivation ID for MAC |
| `PKCS12_SALT_LEN` | 8 | Default salt length in bytes |
| `PKCS12_MAC_KEY_LENGTH` | 20 | MAC key length in bytes |

### Core Functions
- `PKCS12_create()` — build a PKCS#12 structure from key, certificate, and CA chain
- `PKCS12_parse()` — extract private key, certificate, and CA chain from a PKCS#12
- `PKCS12_verify_mac()` / `PKCS12_set_mac()` — verify or set the MAC integrity check
- `PKCS12_newpass()` — re-encrypt a PKCS#12 with a new password
- `PKCS12_key_gen_utf8()` — derive key material using PKCS#12 KDF
- `i2d_PKCS12_bio()` / `d2i_PKCS12_bio()` — DER serialize/deserialize via BIO

## Usage Example

```c
#include <openssl/pkcs12.h>

/* Parse a PKCS#12 file loaded into a BIO */
EVP_PKEY *pkey = NULL;
X509     *cert = NULL;
STACK_OF(X509) *ca = NULL;
PKCS12   *p12 = NULL;

FILE *fp = fopen("keystore.p12", "rb");
d2i_PKCS12_fp(fp, &p12);
fclose(fp);

if (!PKCS12_parse(p12, "password", &pkey, &cert, &ca)) {
    /* handle error */
}

PKCS12_free(p12);

/* Create a new PKCS#12 */
PKCS12 *out = PKCS12_create(
    "newpassword", "friendly name",
    pkey, cert, ca,
    NID_pbe_WithSHA1And3_Key_TripleDES_CBC,
    NID_pbe_WithSHA1And40BitRC2_CBC,
    PKCS12_DEFAULT_ITER, 1, 0
);
i2d_PKCS12_fp(stdout, out);
PKCS12_free(out);
```
