OpenSSL MDC2 hash function header, defining the context structure and API for the MDC2 (Message Digest Cipher 2) digest algorithm based on DES encryption.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `MDC2_BLOCK` | `8` | Block size in bytes |
| `MDC2_DIGEST_LENGTH` | `16` | Output digest length in bytes |

### `MDC2_CTX` Structure

Internal context struct holding the hash state:

| Field | Type | Description |
|---|---|---|
| `num` | `unsigned int` | Bytes buffered in current block |
| `data` | `unsigned char[8]` | Partial block buffer |
| `h`, `hh` | `DES_cblock` | Intermediate DES hash values |
| `pad_type` | `int` | Padding scheme: `1` (default) or `2` |

### Functions

- **`MDC2_Init`** — Initializes an `MDC2_CTX` context
- **`MDC2_Update`** — Feeds data into the digest computation
- **`MDC2_Final`** — Finalizes and writes the 16-byte digest to `md`
- **`MDC2`** — One-shot convenience function combining Init/Update/Final

## Usage Example

```c
#include <openssl/mdc2.h>

unsigned char digest[MDC2_DIGEST_LENGTH];
MDC2_CTX ctx;

/* Incremental approach */
MDC2_Init(&ctx);
MDC2_Update(&ctx, (unsigned char *)"hello", 5);
MDC2_Final(digest, &ctx);

/* One-shot approach */
const unsigned char *input = (unsigned char *)"hello world";
MDC2(input, 11, digest);
```

> **Note:** MDC2 is disabled when `OPENSSL_NO_MDC2` is defined (e.g., in FIPS builds or stripped configurations). Guard usage with `#ifndef OPENSSL_NO_MDC2` as needed.
