OpenSSL AES (Advanced Encryption Standard) header defining the `AES_KEY` structure and low-level AES encryption/decryption function signatures used within the MeshAgent codebase.

## Key Components

**Constants**
- `AES_ENCRYPT` / `AES_DECRYPT` — Direction flags (`1`/`0`) passed to mode functions
- `AES_MAXNR` — Maximum number of rounds (`14`, supporting up to AES-256)
- `AES_BLOCK_SIZE` — AES block size in bytes (`16`)

**Types**
- `AES_KEY` — Round key schedule struct holding expanded key (`rd_key`) and round count (`rounds`)

**Key Setup**
- `AES_set_encrypt_key()` — Expands a raw user key (128/192/256-bit) into an encryption schedule
- `AES_set_decrypt_key()` — Expands a raw user key into a decryption schedule

**Block-Level Primitives**
- `AES_encrypt()` / `AES_decrypt()` — Encrypt or decrypt a single 16-byte block

**Cipher Mode Functions**
| Function | Mode |
|---|---|
| `AES_ecb_encrypt` | ECB |
| `AES_cbc_encrypt` | CBC |
| `AES_cfb128_encrypt` | CFB-128 |
| `AES_cfb1_encrypt` / `AES_cfb8_encrypt` | CFB-1 / CFB-8 |
| `AES_ofb128_encrypt` | OFB |
| `AES_ige_encrypt` | IGE (IV = 2 blocks) |
| `AES_bi_ige_encrypt` | Bi-directional IGE (IV = 4 blocks) |

**Key Wrapping**
- `AES_wrap_key()` / `AES_unwrap_key()` — RFC 3394 AES key wrap/unwrap

## Usage Example

```c
#include <openssl/aes.h>
#include <string.h>

unsigned char key_data[16] = { /* 128-bit key bytes */ };
unsigned char iv[AES_BLOCK_SIZE];
unsigned char plaintext[AES_BLOCK_SIZE] = "Hello, MeshAgent";
unsigned char ciphertext[AES_BLOCK_SIZE];

AES_KEY enc_key;

/* Expand the key schedule */
AES_set_encrypt_key(key_data, 128, &enc_key);

memset(iv, 0, sizeof(iv));

/* Encrypt one block using CBC mode */
AES_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                &enc_key, iv, AES_ENCRYPT);
```

> **Note:** This is the legacy low-level OpenSSL AES API. For new code, prefer the higher-level `EVP_*` interfaces (`EVP_EncryptInit_ex`, etc.) which provide algorithm agility and are less error-prone.
