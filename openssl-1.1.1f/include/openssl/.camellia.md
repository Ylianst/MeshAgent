OpenSSL header defining the Camellia symmetric block cipher API, providing key setup and block encryption/decryption across multiple cipher modes.

## Key Components

### Constants
| Constant | Value | Description |
|---|---|---|
| `CAMELLIA_ENCRYPT` | `1` | Encryption direction flag |
| `CAMELLIA_DECRYPT` | `0` | Decryption direction flag |
| `CAMELLIA_BLOCK_SIZE` | `16` | Block size in bytes (128-bit) |
| `CAMELLIA_TABLE_BYTE_LEN` | `272` | Key schedule table size in bytes |

### Types
- **`CAMELLIA_KEY`** — Key structure containing the expanded key schedule (`rd_key`) and round count (`grand_rounds`); double-aligned for 64-bit compatibility

### Functions

| Function | Description |
|---|---|
| `Camellia_set_key` | Expands a raw user key (128/192/256-bit) into a `CAMELLIA_KEY` schedule |
| `Camellia_encrypt` / `Camellia_decrypt` | Single-block ECB operations |
| `Camellia_ecb_encrypt` | ECB mode with direction flag |
| `Camellia_cbc_encrypt` | CBC mode with IV |
| `Camellia_cfb128_encrypt` | CFB-128 mode streaming |
| `Camellia_cfb1_encrypt` | CFB-1 (bit-level) streaming |
| `Camellia_cfb8_encrypt` | CFB-8 (byte-level) streaming |
| `Camellia_ofb128_encrypt` | OFB-128 mode streaming |
| `Camellia_ctr128_encrypt` | CTR mode with 128-bit counter |

## Usage Example

```c
#include <openssl/camellia.h>

CAMELLIA_KEY key;
unsigned char user_key[16] = { /* 128-bit key bytes */ };
unsigned char ivec[CAMELLIA_BLOCK_SIZE] = {0};
unsigned char plaintext[32] = "Hello, Camellia cipher mode!!!!";
unsigned char ciphertext[32];

/* Expand key schedule */
Camellia_set_key(user_key, 128, &key);

/* Encrypt using CBC mode */
Camellia_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                     &key, ivec, CAMELLIA_ENCRYPT);
```

> **Note:** Guarded by `OPENSSL_NO_CAMELLIA` — ensure your OpenSSL build includes Camellia support before use.
