OpenSSL SHA header defining data structures, constants, and function prototypes for the SHA-1, SHA-224, SHA-256, SHA-384, and SHA-512 cryptographic hash family.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `SHA_DIGEST_LENGTH` | 20 | SHA-1 output length in bytes |
| `SHA224_DIGEST_LENGTH` | 28 | SHA-224 output length in bytes |
| `SHA256_DIGEST_LENGTH` | 32 | SHA-256 output length in bytes |
| `SHA384_DIGEST_LENGTH` | 48 | SHA-384 output length in bytes |
| `SHA512_DIGEST_LENGTH` | 64 | SHA-512 output length in bytes |

### Context Structs

- **`SHA_CTX`** — State for SHA-1; holds five 32-bit hash words, bit-length counters, and a data block buffer
- **`SHA256_CTX`** — State for SHA-224/256; eight 32-bit hash words plus digest length field
- **`SHA512_CTX`** — State for SHA-384/512; eight 64-bit (`SHA_LONG64`) hash words, with a union buffer for both 64-bit word and raw byte access

### Function Groups

Each algorithm exposes an identical three-step streaming API plus a one-shot convenience function:

- `*_Init` — Initialize a context
- `*_Update` — Feed data incrementally
- `*_Final` — Finalize and write the digest
- `SHA1()` / `SHA256()` / `SHA512()` etc. — One-shot hash of a buffer
- `*_Transform` — Low-level single-block compression (advanced use)

## Usage Example

```c
#include <openssl/sha.h>
#include <stdio.h>

/* Streaming SHA-256 */
void hash_data(const unsigned char *data, size_t len) {
    SHA256_CTX ctx;
    unsigned char digest[SHA256_DIGEST_LENGTH];

    SHA256_Init(&ctx);
    SHA256_Update(&ctx, data, len);
    SHA256_Final(digest, &ctx);

    for (int i = 0; i < SHA256_DIGEST_LENGTH; i++)
        printf("%02x", digest[i]);
    printf("\n");
}

/* One-shot SHA-1 */
void quick_sha1(const unsigned char *data, size_t len) {
    unsigned char digest[SHA_DIGEST_LENGTH];
    SHA1(data, len, digest);
}
```

> **Note:** SHA-1 is cryptographically broken for collision resistance. Prefer SHA-256 or SHA-512 for new applications.
