Auto-generated OpenSSL error definitions for the `OSSL_STORE` subsystem, providing numeric codes for functions and failure reasons used by the OpenSSL error reporting framework.

## Key Components

### Function
- **`ERR_load_OSSL_STORE_strings()`** — Registers human-readable error strings for `OSSL_STORE` function and reason codes with the OpenSSL error system.

### Function Codes (`OSSL_STORE_F_*`)
Numeric identifiers for store operations where errors may originate, including:
- `FILE_OPEN`, `FILE_LOAD`, `FILE_CTRL`, `FILE_FIND` — file-based store operations
- `OSSL_STORE_OPEN`, `OSSL_STORE_FIND`, `OSSL_STORE_EXPECT` — core store API functions
- `OSSL_STORE_INFO_NEW_*` / `OSSL_STORE_INFO_GET1_*` — store info object constructors/accessors
- `OSSL_STORE_SEARCH_BY_*` — search criteria builders (alias, issuer/serial, fingerprint, name)
- `TRY_DECODE_PKCS12`, `TRY_DECODE_PKCS8ENCRYPTED`, `TRY_DECODE_PARAMS` — decode helpers

### Reason Codes (`OSSL_STORE_R_*`)
Numeric identifiers for specific failure conditions, including:
- `NOT_A_CERTIFICATE`, `NOT_A_CRL`, `NOT_A_KEY`, `NOT_A_NAME` — type mismatch errors
- `INVALID_SCHEME`, `UNREGISTERED_SCHEME` — URI scheme errors
- `BAD_PASSWORD_READ`, `PASSPHRASE_CALLBACK_ERROR` — credential errors
- `UNSUPPORTED_CONTENT_TYPE`, `UNSUPPORTED_OPERATION`, `UNSUPPORTED_SEARCH_TYPE` — capability errors

## Usage Example

```c
#include <openssl/store.h>
#include <openssl/err.h>
#include "storeerr.h"

/* Load OSSL_STORE error strings at application startup */
ERR_load_OSSL_STORE_strings();

OSSL_STORE_CTX *ctx = OSSL_STORE_open("file:///etc/ssl/certs", NULL, NULL, NULL, NULL);
if (!ctx) {
    /* ERR_print_errors will display OSSL_STORE_R_* reason strings */
    ERR_print_errors_fp(stderr);
}
```
