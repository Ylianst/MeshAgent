OpenSSL User Interface (UI) abstraction layer header that defines the API for creating interactive prompts to collect user input such as passwords, passphrases, and boolean responses.

## Key Components

### Types
- **`UI`** — Opaque handle representing a user interface session
- **`UI_METHOD`** — Structure defining the low-level backend implementation (opener, writer, flusher, reader, closer)
- **`UI_STRING`** — Data structure holding prompt/string state including verification data

### Lifecycle Functions
- `UI_new()` / `UI_new_method()` — Create a UI session
- `UI_free()` — Destroy a UI session
- `UI_process()` — Execute all prompts in the session

### String/Prompt Registration
- `UI_add_input_string()` / `UI_dup_input_string()` — Register a text input prompt
- `UI_add_verify_string()` / `UI_dup_verify_string()` — Register a verification prompt
- `UI_add_input_boolean()` / `UI_dup_input_boolean()` — Register a yes/no prompt
- `UI_add_info_string()` / `UI_add_error_string()` — Register informational or error text

### Result Retrieval
- `UI_get0_result()` — Retrieve input result by index
- `UI_get_result_length()` — Get length of a result

### Method Management
- `UI_OpenSSL()` — Built-in console UI method
- `UI_null()` — No-op placeholder method
- `UI_set_default_method()` / `UI_get_default_method()` — Global method configuration
- `UI_construct_prompt()` — Helper to build standard prompt strings

### Flags
| Flag | Value | Description |
|---|---|---|
| `UI_INPUT_FLAG_ECHO` | `0x01` | Echo input to terminal |
| `UI_INPUT_FLAG_DEFAULT_PWD` | `0x02` | Use application-provided default password |
| `UI_INPUT_FLAG_USER_BASE` | `16` | Lowest bit available for custom flags |

### Control Commands
- `UI_CTRL_PRINT_ERRORS` (`1`) — Print OpenSSL error stack before prompting
- `UI_CTRL_IS_REDOABLE` (`2`) — Check if session can be reused

## Usage Example

```c
#include <openssl/ui.h>

char password[128];

/* Create a UI session using the built-in console method */
UI *ui = UI_new_method(UI_OpenSSL());
if (!ui) {
    /* handle error */
}

/* Register a password prompt */
int idx = UI_add_input_string(
    ui,
    "Enter passphrase: ",
    0,           /* no echo flag */
    password,
    1,           /* minsize */
    sizeof(password) - 1  /* maxsize */
);

/* Run all prompts */
if (UI_process(ui) < 0) {
    /* error or cancelled (-2) */
}

/* Retrieve result by index */
const char *result = UI_get0_result(ui, idx);

UI_free(ui);
```
