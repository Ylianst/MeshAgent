OpenSSL RFC 3161 Time-Stamp Protocol (TSP) header, providing type definitions, ASN.1 serialization functions, accessor APIs, and context structures for creating and verifying cryptographic timestamps.

## Key Components

### Core Types
| Type | Description |
|------|-------------|
| `TS_REQ` | Timestamp request structure |
| `TS_RESP` | Timestamp response structure |
| `TS_TST_INFO` | TSTInfo token content |
| `TS_STATUS_INFO` | Response status and failure info |
| `TS_ACCURACY` | Timestamp accuracy (seconds/millis/micros) |
| `TS_MSG_IMPRINT` | Hash algorithm + message digest pair |
| `ESS_SIGNING_CERT` / `ESS_SIGNING_CERT_V2` | Enhanced Security Services signing certificate attributes |

### Status Constants
- `TS_STATUS_GRANTED` (0) — request accepted
- `TS_STATUS_REJECTION` (2) — request denied
- `TS_STATUS_WAITING` (3) — pending
- `TS_INFO_BAD_ALG`, `TS_INFO_BAD_REQUEST`, `TS_INFO_SYSTEM_FAILURE`, etc. — failure reason codes

### Response Generation Flags
- `TS_TSA_NAME` — include TSA name in response
- `TS_ORDERING` — set ordering field to true
- `TS_ESS_CERT_ID_CHAIN` — include full certificate chain in ESS attribute

### Function Families
Each structure follows a consistent pattern:
- `*_new()` / `*_free()` — allocation/deallocation
- `i2d_*` / `d2i_*` — DER encode/decode (memory, FILE, BIO variants)
- `*_dup()` — deep copy
- `*_get_*` / `*_set_*` — field accessors

## Usage Example

```c
#include <openssl/ts.h>

/* Build and serialize a timestamp request */
TS_REQ *req = TS_REQ_new();
TS_REQ_set_version(req, 1);
TS_REQ_set_cert_req(req, 1);

TS_MSG_IMPRINT *imprint = TS_MSG_IMPRINT_new();
X509_ALGOR *alg = /* SHA-256 algorithm */;
TS_MSG_IMPRINT_set_algo(imprint, alg);
TS_MSG_IMPRINT_set_msg(imprint, digest, digest_len);
TS_REQ_set_msg_imprint(req, imprint);

/* DER-encode to BIO */
BIO *bio = BIO_new_file("request.tsq", "wb");
i2d_TS_REQ_bio(bio, req);

/* Parse a timestamp response */
TS_RESP *resp = d2i_TS_RESP_bio(bio_resp, NULL);
TS_STATUS_INFO *status = TS_RESP_get_status_info(resp);
const ASN1_INTEGER *st = TS_STATUS_INFO_get0_status(status);

TS_RESP_free(resp);
TS_REQ_free(req);
BIO_free(bio);
```
