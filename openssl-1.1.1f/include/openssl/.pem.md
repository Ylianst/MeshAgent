OpenSSL PEM (Privacy Enhanced Mail) header defining the public API for reading and writing PEM-encoded cryptographic objects, including certificates, keys, and parameters.

## Key Components

### PEM Type String Constants
String literals used as PEM header/footer labels (e.g., `PEM_STRING_X509`, `PEM_STRING_RSA`, `PEM_STRING_ECPRIVATEKEY`) identifying the encoded object type within `-----BEGIN <type>-----` / `-----END <type>-----` delimiters.

### Implementation Macros
Macro families that generate `PEM_read_*` / `PEM_write_*` function bodies for both `FILE*` and `BIO*` I/O backends:

| Macro | Purpose |
|---|---|
| `IMPLEMENT_PEM_rw` | Read + write (both I/O backends) |
| `IMPLEMENT_PEM_rw_cb` | Read + write with encryption callback |
| `IMPLEMENT_PEM_rw_const` | Read + const write |

### Declaration Macros
Corresponding `DECLARE_PEM_*` macros generate function prototypes for headers.

### Core API Functions

- **`PEM_read_bio`** / **`PEM_read`** — Low-level PEM frame parser returning raw DER bytes
- **`PEM_write_bio`** / **`PEM_write`** — Low-level PEM frame writer
- **`PEM_ASN1_read_bio`** / **`PEM_ASN1_write_bio`** — ASN.1 object deserialization/serialization via BIO
- **`PEM_bytes_read_bio`** — Reads and decrypts PEM data to raw bytes
- **`PEM_X509_INFO_read_bio`** — Parses a PEM stream into a stack of `X509_INFO` objects
- **`PEM_get_EVP_CIPHER_INFO`** / **`PEM_do_header`** — Parse and apply encryption from PEM headers
- **`pem_password_cb`** — Typedef for password callback used during encrypted key I/O

## Usage Example

```c
#include <openssl/pem.h>
#include <openssl/x509.h>

/* Read a certificate from a PEM file */
FILE *fp = fopen("cert.pem", "r");
X509 *cert = PEM_read_X509(fp, NULL, NULL, NULL);
fclose(fp);

/* Write a certificate to a BIO */
BIO *out = BIO_new_fp(stdout, BIO_NOCLOSE);
PEM_write_bio_X509(out, cert);
BIO_free(out);
X509_free(cert);
```
