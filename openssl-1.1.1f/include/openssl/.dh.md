OpenSSL Diffie-Hellman (DH) key exchange public API header, providing types, constants, and function declarations for DH parameter generation, key management, validation, and EVP_PKEY integration.

## Key Components

### Constants & Flags
- `OPENSSL_DH_MAX_MODULUS_BITS` (10000) — maximum allowed modulus size
- `OPENSSL_DH_FIPS_MIN_MODULUS_BITS` (1024) — FIPS-required minimum
- `DH_FLAG_CACHE_MONT_P`, `DH_FLAG_FIPS_METHOD`, `DH_FLAG_NON_FIPS_ALLOW` — behavior flags
- `DH_CHECK_*` / `DH_CHECK_PUBKEY_*` — error code bitmasks for parameter and public key validation

### Core Functions
- `DH_new` / `DH_free` / `DH_up_ref` — lifecycle management
- `DH_generate_parameters_ex` — generate DH parameters (prime + generator)
- `DH_generate_key` — generate a DH key pair
- `DH_compute_key` / `DH_compute_key_padded` — compute shared secret
- `DH_check` / `DH_check_pub_key` / `DH_check_params` — validate parameters and public keys

### Accessor Functions
- `DH_get0_pqg` / `DH_set0_pqg` — get/set prime `p`, subgroup order `q`, generator `g`
- `DH_get0_key` / `DH_set0_key` — get/set public and private key components

### Named/Standard Parameters
- `DH_get_1024_160`, `DH_get_2048_224`, `DH_get_2048_256` — RFC 5114 built-in groups
- `DH_new_by_nid` / `DH_get_nid` — RFC 7919 named groups

### Method Customization (`DH_METHOD`)
- `DH_meth_new` / `DH_meth_free` / `DH_meth_dup` — custom method lifecycle
- Setters for `generate_key`, `compute_key`, `bn_mod_exp`, `init`, `finish`, `generate_params`

### EVP_PKEY Macros
Wrappers around `EVP_PKEY_CTX_ctrl` for configuring DH within the EVP layer:
- `EVP_PKEY_CTX_set_dh_paramgen_prime_len`, `EVP_PKEY_CTX_set_dh_paramgen_generator`
- `EVP_PKEY_CTX_set_dh_kdf_type`, `EVP_PKEY_CTX_set_dh_kdf_md`, `EVP_PKEY_CTX_set_dh_kdf_outlen`

## Usage Example

```c
#include <openssl/dh.h>

/* Generate DH parameters and a key pair */
DH *dh = DH_new();
DH_generate_parameters_ex(dh, 2048, DH_GENERATOR_2, NULL);

int codes = 0;
if (!DH_check(dh, &codes) || codes != 0) {
    /* handle invalid parameters */
}

DH_generate_key(dh);

const BIGNUM *pub_key, *priv_key;
DH_get0_key(dh, &pub_key, &priv_key);

/* Compute shared secret with peer's public key */
unsigned char shared[256];
DH_compute_key(shared, peer_pub_key, dh);

DH_free(dh);
```

> **Note:** For new applications, prefer RFC 7919 named groups via `DH_new_by_nid(nid)` over manual parameter generation.
