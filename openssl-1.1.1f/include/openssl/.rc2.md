OpenSSL RC2 symmetric block cipher header providing key scheduling and encryption/decryption function declarations for the RC2 algorithm.

## Key Components

### Constants
| Constant | Value | Description |
|---|---|---|
| `RC2_ENCRYPT` | `1` | Encryption mode flag |
| `RC2_DECRYPT` | `0` | Decryption mode flag |
| `RC2_BLOCK` | `8` | Block size in bytes |
| `RC2_KEY_LENGTH` | `16` | Default key length in bytes |

### Types
- **`RC2_INT`** — Underlying integer type (`unsigned int`) used for key data
- **`RC2_KEY`** — Key structure holding 64 expanded `RC2_INT` words after key scheduling

### Functions
| Function | Description |
|---|---|
| `RC2_set_key()` | Expands a raw key into an `RC2_KEY` schedule; `bits` controls effective key length |
| `RC2_ecb_encrypt()` | Encrypts/decrypts a single 8-byte ECB block |
| `RC2_encrypt()` | Low-level in-place block encryption |
| `RC2_decrypt()` | Low-level in-place block decryption |
| `RC2_cbc_encrypt()` | CBC mode encryption/decryption over arbitrary-length data |
| `RC2_cfb64_encrypt()` | CFB-64 streaming mode encryption/decryption |
| `RC2_ofb64_encrypt()` | OFB-64 streaming mode encryption |

## Usage Example

```c
#include <openssl/rc2.h>

unsigned char key_data[RC2_KEY_LENGTH] = { /* 16 key bytes */ };
unsigned char iv[RC2_BLOCK]            = { 0 };
unsigned char plaintext[RC2_BLOCK]     = "Hello!!!";
unsigned char ciphertext[RC2_BLOCK];

RC2_KEY key;

/* Expand key with 128 effective bits */
RC2_set_key(&key, RC2_KEY_LENGTH, key_data, 128);

/* Encrypt one block in ECB mode */
RC2_ecb_encrypt(plaintext, ciphertext, &key, RC2_ENCRYPT);

/* Decrypt back */
RC2_ecb_encrypt(ciphertext, plaintext, &key, RC2_DECRYPT);
```

> **Note:** RC2 is a legacy cipher considered cryptographically weak. Prefer AES for new implementations. This header is compiled out when `OPENSSL_NO_RC2` is defined.
