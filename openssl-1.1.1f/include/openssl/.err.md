OpenSSL error reporting header that defines the error state structure, library/reason codes, per-library error macros, and the full public API for recording, retrieving, and formatting errors across all OpenSSL subsystems.

## Key Components

### `ERR_STATE` Struct
A per-thread circular buffer (depth 16) holding packed error codes, optional text data, and source file/line information.

### Error Packing Macros
| Macro | Description |
|---|---|
| `ERR_PACK(l,f,r)` | Pack library, function, reason into a `unsigned long` |
| `ERR_GET_LIB(l)` | Extract library code (bits 24–31) |
| `ERR_GET_FUNC(l)` | Extract function code (bits 12–23) |
| `ERR_GET_REASON(l)` | Extract reason code (bits 0–11) |
| `ERR_FATAL_ERROR(l)` | Test whether the fatal flag is set |

### Library Codes (`ERR_LIB_*`)
Numeric identifiers (1–128) for every OpenSSL subsystem: `ERR_LIB_SSL`, `ERR_LIB_RSA`, `ERR_LIB_EVP`, `ERR_LIB_BIO`, etc. `ERR_LIB_USER` (128) is reserved for application-defined libraries.

### Per-Library Error Macros
Convenience wrappers that call `ERR_PUT_error` with the correct library code and automatic `__FILE__`/`__LINE__` capture: `SSLerr`, `RSAerr`, `EVPerr`, `BIOerr`, etc.

### Key Functions
- **`ERR_put_error`** – Push an error onto the thread-local stack
- **`ERR_get_error` / `ERR_peek_error` / `ERR_peek_last_error`** – Pop or inspect errors (with optional file/line/data variants)
- **`ERR_error_string_n`** – Format a packed error code into a human-readable string
- **`ERR_print_errors` / `ERR_print_errors_fp`** – Dump the error stack to a `BIO` or `FILE`
- **`ERR_set_mark` / `ERR_pop_to_mark`** – Bracket recoverable operations for selective stack cleanup

## Usage Example

```c
#include <openssl/err.h>
#include <openssl/ssl.h>

/* Record an error inside a custom library function */
void my_operation(void) {
    if (some_failure) {
        SSLerr(SSL_F_MY_FUNC, SSL_R_SOME_REASON);
        return;
    }
}

/* Retrieve and print all pending errors */
void report_errors(void) {
    unsigned long code;
    char buf[256];

    while ((code = ERR_get_error()) != 0) {
        ERR_error_string_n(code, buf, sizeof(buf));
        fprintf(stderr, "OpenSSL error: %s\n", buf);
    }
}

/* Use marks to discard errors from a speculative operation */
ERR_set_mark();
if (speculative_call() == 0)
    ERR_pop_to_mark();   /* discard; operation succeeded or error handled */
else
    ERR_clear_last_mark(); /* keep errors for caller inspection */
```
