OpenSSL Whirlpool cryptographic hash function interface header, providing the context structure and API declarations for the Whirlpool-512 digest algorithm.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `WHIRLPOOL_DIGEST_LENGTH` | 64 bytes | Output digest size (512 bits) |
| `WHIRLPOOL_BBLOCK` | 512 bits | Internal block size |
| `WHIRLPOOL_COUNTER` | 32 bytes | Message length counter size |

### `WHIRLPOOL_CTX` Structure

Holds all state for an in-progress Whirlpool hash operation:

- **`H`** — Union holding the 512-bit hash state; aligned to 64-bit via `double q[]`
- **`data[]`** — Input block buffer (512 bits / 8 = 64 bytes)
- **`bitoff`** — Current bit offset within the data buffer
- **`bitlen[]`** — Total message length counter array

### Functions

| Function | Description |
|---|---|
| `WHIRLPOOL_Init` | Initializes a `WHIRLPOOL_CTX` |
| `WHIRLPOOL_Update` | Feeds byte-aligned input data into the hash |
| `WHIRLPOOL_BitUpdate` | Feeds bit-granular input (non-byte-aligned) |
| `WHIRLPOOL_Final` | Finalizes and writes the 64-byte digest |
| `WHIRLPOOL` | One-shot convenience function |

## Usage Example

```c
#include <openssl/whrlpool.h>

/* Incremental hashing */
WHIRLPOOL_CTX ctx;
unsigned char digest[WHIRLPOOL_DIGEST_LENGTH];

WHIRLPOOL_Init(&ctx);
WHIRLPOOL_Update(&ctx, data, data_len);
WHIRLPOOL_Final(digest, &ctx);

/* One-shot hashing */
unsigned char digest[WHIRLPOOL_DIGEST_LENGTH];
WHIRLPOOL(input, input_len, digest);
```

> **Note:** The entire API is conditionally compiled under `OPENSSL_NO_WHIRLPOOL`. Check that this guard is not set in your OpenSSL build if the symbols are missing at link time.
