OpenSSL Blowfish symmetric cipher header defining the `BF_KEY` structure and encryption/decryption API for the Blowfish block cipher algorithm.

## Key Components

### Constants
| Constant | Value | Description |
|---|---|---|
| `BF_ENCRYPT` | `1` | Direction flag for encryption |
| `BF_DECRYPT` | `0` | Direction flag for decryption |
| `BF_ROUNDS` | `16` | Number of Feistel rounds |
| `BF_BLOCK` | `8` | Block size in bytes |
| `BF_LONG` | `unsigned int` | Must be at least 32 bits wide |

### Structures

- **`BF_KEY`** — Expanded key schedule containing the P-array (`BF_ROUNDS + 2` entries) and four 256-entry S-boxes.

### Functions

| Function | Description |
|---|---|
| `BF_set_key` | Initializes a `BF_KEY` from raw key bytes |
| `BF_encrypt` / `BF_decrypt` | Low-level in-place 64-bit block operations |
| `BF_ecb_encrypt` | ECB mode (single block, no chaining) |
| `BF_cbc_encrypt` | CBC mode with IV |
| `BF_cfb64_encrypt` | 64-bit CFB streaming mode |
| `BF_ofb64_encrypt` | 64-bit OFB streaming mode |
| `BF_options` | Returns compile-time option string |

## Usage Example

```c
#include <openssl/blowfish.h>

BF_KEY key;
unsigned char iv[BF_BLOCK] = {0};
unsigned char plaintext[8]  = "Hello!!\0";
unsigned char ciphertext[8];

/* Initialize key from a passphrase */
BF_set_key(&key, 16, (const unsigned char *)"mysecretpassword");

/* Encrypt one block in ECB mode */
BF_ecb_encrypt(plaintext, ciphertext, &key, BF_ENCRYPT);

/* Decrypt back */
BF_ecb_encrypt(ciphertext, plaintext, &key, BF_DECRYPT);
```

> **Note:** Blowfish is considered legacy in modern OpenSSL builds. Prefer AES (`openssl/aes.h`) for new implementations.
