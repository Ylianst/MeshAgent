OpenSSL Elliptic Curve (EC) public API header defining types, methods, and functions for elliptic curve cryptography operations over GF(p) and GF(2^m) fields.

## Key Components

### Types & Enums
- **`point_conversion_form_t`** — Enum defining EC point encoding formats: `POINT_CONVERSION_COMPRESSED` (2), `POINT_CONVERSION_UNCOMPRESSED` (4), `POINT_CONVERSION_HYBRID` (6)
- **`EC_METHOD`** — Opaque struct representing an EC algorithm implementation
- **`EC_GROUP`** — Opaque struct representing an elliptic curve group
- **`EC_POINT`** — Opaque struct representing a point on an elliptic curve

### EC_METHOD Constructors (GF(p))
- `EC_GFp_simple_method()` — Basic GFp implementation
- `EC_GFp_mont_method()` — Montgomery multiplication variant
- `EC_GFp_nist_method()` — Optimized for NIST curves
- `EC_GFp_nistp224/256/521_method()` — 64-bit optimized NIST methods (requires `OPENSSL_NO_EC_NISTP_64_GCC_128` unset)

### EC_GROUP Lifecycle
- `EC_GROUP_new()` / `EC_GROUP_free()` / `EC_GROUP_clear_free()` — Create and destroy groups
- `EC_GROUP_copy()` / `EC_GROUP_dup()` — Copy group parameters

### EC_GROUP Configuration
- `EC_GROUP_set_curve()` / `EC_GROUP_get_curve()` — Set/get curve coefficients (a, b, p)
- `EC_GROUP_set_generator()` — Define the base point with order and cofactor
- `EC_GROUP_get_order()` / `EC_GROUP_get_cofactor()` — Retrieve group order/cofactor
- `EC_GROUP_set_curve_name()` / `EC_GROUP_get_curve_name()` — Named curve NID management

## Usage Example

```c
#include <openssl/ec.h>
#include <openssl/bn.h>

/* Create a named NIST P-256 group */
EC_GROUP *group = EC_GROUP_new_by_curve_name(NID_X9_62_prime256v1);
if (!group) {
    /* handle error */
}

/* Inspect group order */
BIGNUM *order = BN_new();
EC_GROUP_get_order(group, order, NULL);

int bits = EC_GROUP_order_bits(group); /* 256 for P-256 */

/* Set point encoding to uncompressed */
EC_GROUP_set_point_conversion_form(group, POINT_CONVERSION_UNCOMPRESSED);

BN_free(order);
EC_GROUP_free(group);
```

> **Note:** `EC_GROUP_set_curve_GFp()` and `EC_GROUP_set_curve_GF2m()` are deprecated since OpenSSL 1.2.0. Use `EC_GROUP_set_curve()` instead.
