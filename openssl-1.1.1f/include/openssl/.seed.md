Header file providing the OpenSSL interface for the SEED block cipher, a 128-bit symmetric encryption algorithm standardized by KISA (Korea Information Security Agency).

## Key Components

### Constants
| Macro | Value | Description |
|---|---|---|
| `SEED_BLOCK_SIZE` | `16` | Block size in bytes |
| `SEED_KEY_LENGTH` | `16` | Key length in bytes (128-bit) |
| `SEED_LONG` | — | Defined when 32-bit alignment requires `unsigned long` |

### Data Structure
- **`SEED_KEY_SCHEDULE`** — Expanded key schedule; holds 32 words of either `unsigned int` or `unsigned long` depending on platform width requirements.

### Functions

| Function | Description |
|---|---|
| `SEED_set_key` | Expands a 16-byte raw key into a `SEED_KEY_SCHEDULE` |
| `SEED_encrypt` | Encrypts a single 16-byte block |
| `SEED_decrypt` | Decrypts a single 16-byte block |
| `SEED_ecb_encrypt` | ECB mode encrypt/decrypt (`enc=1` encrypts, `enc=0` decrypts) |
| `SEED_cbc_encrypt` | CBC mode encrypt/decrypt with IV |
| `SEED_cfb128_encrypt` | CFB-128 mode encrypt/decrypt with IV and streaming offset |
| `SEED_ofb128_encrypt` | OFB-128 mode encrypt with IV and streaming offset |

## Usage Example

```c
#include <openssl/seed.h>

unsigned char key[SEED_KEY_LENGTH]   = { /* 16-byte key */ };
unsigned char iv[SEED_BLOCK_SIZE]    = { /* 16-byte IV  */ };
unsigned char plaintext[64]          = { /* input data  */ };
unsigned char ciphertext[64];

SEED_KEY_SCHEDULE ks;

/* Expand key once, reuse for multiple operations */
SEED_set_key(key, &ks);

/* CBC encryption */
SEED_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                 &ks, iv, 1 /* enc */);

/* CBC decryption — reinitialise IV first */
memcpy(iv, original_iv, SEED_BLOCK_SIZE);
SEED_cbc_encrypt(ciphertext, plaintext, sizeof(ciphertext),
                 &ks, iv, 0 /* dec */);
```

> **Note:** This header is conditionally compiled out when `OPENSSL_NO_SEED` is defined, which disables SEED support at the OpenSSL build level.
