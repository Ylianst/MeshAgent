OpenSSL Big Number (BIGNUM) library public API header, providing arbitrary-precision integer arithmetic for cryptographic operations such as RSA, DH, and DSA key generation and modular exponentiation.

## Key Components

### Types & Macros
- **`BN_ULONG`** — Platform-specific unsigned word type (32 or 64-bit)
- **`BN_BITS2`**, **`BN_BYTES`** — Word size constants for platform portability
- **`BN_FLG_CONSTTIME`** — Flag enabling constant-time operations to prevent timing side-channel attacks
- **`BN_FLG_SECURE`** — Flag for secure memory allocation
- **`BN_prime_checks_for_size(b)`** — Macro returning optimal Miller-Rabin iteration count per FIPS 186-4

### Memory & Lifecycle
- `BN_new()`, `BN_secure_new()`, `BN_free()`, `BN_clear_free()`, `BN_dup()`
- `BN_CTX_new()`, `BN_CTX_start()`, `BN_CTX_get()`, `BN_CTX_end()`, `BN_CTX_free()`

### Arithmetic Operations
- **Basic:** `BN_add()`, `BN_sub()`, `BN_mul()`, `BN_div()`, `BN_sqr()`, `BN_exp()`
- **Modular:** `BN_mod_add()`, `BN_mod_sub()`, `BN_mod_mul()`, `BN_mod_sqr()`, `BN_mod_exp()`
- **Montgomery:** `BN_mod_exp_mont()`, `BN_mod_exp_mont_consttime()` for efficient modular exponentiation

### Conversion & I/O
- `BN_bin2bn()` / `BN_bn2bin()` — Binary byte array conversion
- `BN_bn2hex()` / `BN_hex2bn()` — Hexadecimal string conversion
- `BN_bn2dec()` / `BN_dec2bn()` — Decimal string conversion
- `BN_bn2mpi()` / `BN_mpi2bn()` — MPI wire format conversion

### Random Number Generation
- `BN_rand()`, `BN_priv_rand()` — Cryptographically secure random BIGNUMs
- `BN_rand_range()`, `BN_priv_rand_range()` — Range-bounded random values

### Primality & Number Theory
- `BN_gcd()` — Greatest common divisor
- `BN_kronecker()` — Kronecker/Jacobi symbol
- `BN_mod_inverse()` — Modular inverse

### Callback Support
- `BN_GENCB_new()`, `BN_GENCB_set()`, `BN_GENCB_call()` — Progress callbacks for slow operations (e.g., key generation)

## Usage Example

```c
#include <openssl/bn.h>

/* Compute r = (a^p) mod m using constant-time Montgomery exponentiation */
void example_modexp(void) {
    BN_CTX *ctx = BN_CTX_new();
    BIGNUM *a = BN_new();
    BIGNUM *p = BN_new();
    BIGNUM *m = BN_new();
    BIGNUM *r = BN_new();

    BN_hex2bn(&a, "DEADBEEF");
    BN_hex2bn(&p, "10001");       /* public exponent */
    BN_hex2bn(&m, "CAFEBABE0000000100000001");

    /* Enable constant-time to resist timing attacks */
    BN_set_flags(p, BN_FLG_CONSTTIME);

    BN_mod_exp_mont_consttime(r, a, p, m, ctx, NULL);

    char *hex = BN_bn2hex(r);
    printf("Result: %s\n", hex);

    OPENSSL_free(hex);
    BN_free(a); BN_free(p); BN_free(m); BN_free(r);
    BN_CTX_free(ctx);
}
```

> **Security note:** Always set `BN_FLG_CONSTTIME` on secret exponents/scalars to enable constant-time code paths and prevent timing side-channel leakage.
