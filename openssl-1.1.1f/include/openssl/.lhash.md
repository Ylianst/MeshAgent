OpenSSL dynamic hash table (lhash) interface header, providing type-safe wrappers and core API declarations for a self-resizing hash table implementation authored by Eric Young.

## Key Components

### Core Types
- `OPENSSL_LHASH` — opaque hash table structure
- `OPENSSL_LH_NODE` — individual hash table node
- `OPENSSL_LH_HASHFUNC` — hash function callback: `unsigned long (*)(const void *)`
- `OPENSSL_LH_COMPFUNC` — comparison function callback: `int (*)(const void *, const void *)`
- `OPENSSL_LH_DOALL_FUNC` / `OPENSSL_LH_DOALL_FUNCARG` — iteration callbacks

### Core API Functions
| Function | Description |
|---|---|
| `OPENSSL_LH_new(h, c)` | Create hash table with given hash/compare functions |
| `OPENSSL_LH_free(lh)` | Destroy hash table |
| `OPENSSL_LH_insert(lh, data)` | Insert item, returns replaced item or NULL |
| `OPENSSL_LH_delete(lh, data)` | Remove and return matching item |
| `OPENSSL_LH_retrieve(lh, data)` | Look up matching item |
| `OPENSSL_LH_doall(lh, func)` | Iterate over all entries |
| `OPENSSL_LH_strhash(c)` | Built-in string hash function |
| `OPENSSL_LH_num_items(lh)` | Return item count |

### Type-Safe Macro System
- `DEFINE_LHASH_OF(type)` — generates a complete typed hash table API for `type` (e.g., `lh_MyType_insert`, `lh_MyType_retrieve`)
- `IMPLEMENT_LHASH_HASH_FN` / `IMPLEMENT_LHASH_COMP_FN` — generate void-pointer-casting wrappers for hash and compare callbacks
- `IMPLEMENT_LHASH_DOALL_ARG` / `IMPLEMENT_LHASH_DOALL_ARG_CONST` — generate typed iteration helpers

## Usage Example

```c
/* Define a typed hash table for a custom struct */
typedef struct { char *name; int value; } MyEntry;

unsigned long MyEntry_hash(const MyEntry *a) { return OPENSSL_LH_strhash(a->name); }
int MyEntry_cmp(const MyEntry *a, const MyEntry *b) { return strcmp(a->name, b->name); }

/* Declare and implement type-safe callback wrappers */
DECLARE_LHASH_HASH_FN(MyEntry, MyEntry)
IMPLEMENT_LHASH_HASH_FN(MyEntry, MyEntry)
DECLARE_LHASH_COMP_FN(MyEntry, MyEntry)
IMPLEMENT_LHASH_COMP_FN(MyEntry, MyEntry)

/* Create and use the hash table */
OPENSSL_LHASH *ht = OPENSSL_LH_new(LHASH_HASH_FN(MyEntry),
                                    LHASH_COMP_FN(MyEntry));
MyEntry e = { "key", 42 };
OPENSSL_LH_insert(ht, &e);

MyEntry lookup = { "key", 0 };
MyEntry *found = OPENSSL_LH_retrieve(ht, &lookup);

OPENSSL_LH_free(ht);
```
