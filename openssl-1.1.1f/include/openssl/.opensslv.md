Defines compile-time version constants for the OpenSSL 1.1.1f library, providing both numeric and string representations of the version for use in version checks and shared library compatibility.

## Key Components

| Macro | Value | Purpose |
|---|---|---|
| `OPENSSL_VERSION_NUMBER` | `0x1010106fL` | Numeric version in `MNNFFPPS` format |
| `OPENSSL_VERSION_TEXT` | `"OpenSSL 1.1.1f  31 Mar 2020"` | Human-readable version string |
| `SHLIB_VERSION_NUMBER` | `"1.1"` | Shared library version (`Major.minor`) |
| `SHLIB_VERSION_HISTORY` | `""` | Colon-separated binary-compatible version history |

### Version Number Encoding (`MNNFFPPS`)

| Field | Bits | Description |
|---|---|---|
| M | Major | Major version |
| NN | Minor | Minor version |
| FF | Fix | Fix level |
| PP | Patch | Patch level |
| S | Status | `0`=dev, `1-e`=beta, `f`=release |

## Usage Example

```c
#include <openssl/opensslv.h>

/* Compile-time version guard */
#if OPENSSL_VERSION_NUMBER < 0x1010100fL
#  error "OpenSSL 1.1.1 or later required"
#endif

/* Print version at runtime */
void print_openssl_version(void) {
    printf("Compiled against: %s\n", OPENSSL_VERSION_TEXT);
    printf("Version number:   0x%09lX\n", OPENSSL_VERSION_NUMBER);
}
```

> **Note:** This header pins OpenSSL to version **1.1.1f (2020-03-31)**. When upgrading OpenSSL, verify `OPENSSL_VERSION_NUMBER` meets your minimum requirements before building.
