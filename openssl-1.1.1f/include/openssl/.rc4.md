RC4 stream cipher interface header from OpenSSL, providing key scheduling and encryption/decryption primitives for the RC4 algorithm.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `RC4_KEY` | `struct` | RC4 key state holding `x`, `y` cursor integers and a 256-element substitution box (`data`) |
| `RC4_options()` | Function | Returns a string describing compile-time RC4 configuration options |
| `RC4_set_key()` | Function | Initialises an `RC4_KEY` from raw bytes; performs the KSA (Key Scheduling Algorithm) |
| `RC4()` | Function | Encrypts or decrypts `len` bytes from `indata` into `outdata` using the supplied key state |

> **Note:** RC4 is disabled when `OPENSSL_NO_RC4` is defined at compile time. The entire API is conditionally compiled out in that case.

## Usage Example

```c
#include <openssl/rc4.h>
#include <string.h>

int main(void) {
    RC4_KEY key;
    const unsigned char secret[] = "mysecretkey";
    const unsigned char plaintext[] = "Hello, RC4!";
    unsigned char ciphertext[sizeof(plaintext)];
    unsigned char recovered[sizeof(plaintext)];

    /* Initialise key state from raw key bytes */
    RC4_set_key(&key, (int)strlen((char *)secret), secret);

    /* Encrypt plaintext → ciphertext */
    RC4(&key, sizeof(plaintext), plaintext, ciphertext);

    /* Re-initialise key to decrypt (RC4 is symmetric) */
    RC4_set_key(&key, (int)strlen((char *)secret), secret);
    RC4(&key, sizeof(plaintext), ciphertext, recovered);

    return 0;
}
```

> ⚠️ **Security Warning:** RC4 is cryptographically broken and should not be used in new systems. Prefer AES-GCM or ChaCha20-Poly1305 for modern applications.
