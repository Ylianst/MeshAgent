OpenSSL Key Derivation Function (KDF) control interface header, providing macro wrappers for configuring TLS 1.0 PRF, HKDF, and scrypt KDF operations via `EVP_PKEY_CTX`.

## Key Components

### Control Constants
| Constant | Purpose |
|---|---|
| `EVP_PKEY_CTRL_TLS_MD/SECRET/SEED` | TLS 1.0 PRF parameters |
| `EVP_PKEY_CTRL_HKDF_MD/SALT/KEY/INFO/MODE` | HKDF parameters |
| `EVP_PKEY_CTRL_PASS` | Password-based derivation |
| `EVP_PKEY_CTRL_SCRYPT_*` | scrypt N/r/p/maxmem parameters |

### HKDF Mode Flags
- `EVP_PKEY_HKDEF_MODE_EXTRACT_AND_EXPAND` — Full HKDF (default)
- `EVP_PKEY_HKDEF_MODE_EXTRACT_ONLY` — Extract phase only
- `EVP_PKEY_HKDEF_MODE_EXPAND_ONLY` — Expand phase only

### Macro Wrappers

**TLS 1.0 PRF:**
- `EVP_PKEY_CTX_set_tls1_prf_md(pctx, md)` — Set digest
- `EVP_PKEY_CTX_set1_tls1_prf_secret(pctx, sec, seclen)` — Set secret
- `EVP_PKEY_CTX_add1_tls1_prf_seed(pctx, seed, seedlen)` — Add seed data

**HKDF:**
- `EVP_PKEY_CTX_set_hkdf_md`, `set1_hkdf_salt`, `set1_hkdf_key`, `add1_hkdf_info`, `hkdf_mode`

**scrypt:**
- `EVP_PKEY_CTX_set1_scrypt_salt`, `set_scrypt_N`, `set_scrypt_r`, `set_scrypt_p`, `set_scrypt_maxmem_bytes`

## Usage Example

```c
/* HKDF key derivation */
EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_HKDF, NULL);
EVP_PKEY_derive_init(pctx);

EVP_PKEY_CTX_set_hkdf_md(pctx, EVP_sha256());
EVP_PKEY_CTX_set1_hkdf_key(pctx, ikm, ikm_len);
EVP_PKEY_CTX_set1_hkdf_salt(pctx, salt, salt_len);
EVP_PKEY_CTX_add1_hkdf_info(pctx, info, info_len);
EVP_PKEY_CTX_hkdf_mode(pctx, EVP_PKEY_HKDEF_MODE_EXTRACT_AND_EXPAND);

EVP_PKEY_derive(pctx, out_key, &out_key_len);
EVP_PKEY_CTX_free(pctx);
```
