Provides Windows CryptoAPI bindings for certificate generation, RSA key management, and cryptographic operations on Windows platforms using native DLL interop via `_GenericMarshal`.

## Key Components

- **`WinCrypto` class** — Main constructor that initializes native proxy bindings to `Kernel32.dll`, `Bcrypt.dll`, and `Crypt32.dll`
- **Crypto constants** — `CRYPT_ALGORITHMS`, `CRYPT_ALGORITHMS_EX`, `CRYPT_EXTENSION_OIDS`, `CRYPT_KEY_ALGORITHMS`, `CRYPT_KEY_USAGES` — OID and flag lookup tables for RSA/SHA algorithms and X.509 extensions
- **`createKeyRestriction()`** — Returns a key usage restriction object with all flags defaulting to `false`
- **`makeCert(options)`** — Builds and signs an X.509 certificate using Windows CryptoAPI (`CertCreateSelfSignCertificate`), supporting custom DN fields, key restrictions, and SHA1/256/384/512 algorithms

## Usage Example

```javascript
var wincrypto = require('win-crypto');
var crypto = new WinCrypto();

// Create key usage restriction
var keyUsage = crypto.createKeyRestriction();
keyUsage.CERT_DIGITAL_SIGNATURE_KEY_USAGE = true;
keyUsage.CERT_KEY_ENCIPHERMENT_KEY_USAGE = true;

// Generate a self-signed certificate
crypto.makeCert({
    CN: 'MyDevice',
    O: 'Flamingo Stack',
    C: 'US',
    _algorithm: 'SHA256',
    _keyRestrictions: keyUsage
});
```

## Notes

- Windows-only; requires native DLL access via `_GenericMarshal`
- Supports both 32-bit and 64-bit pointer sizes (pointer arithmetic branches throughout)
- OID reverse-lookup is pre-built at construction time into `CRYPT_KEY_ALGORITHMS_OIDS`
