Windows COM (Component Object Model) interop helper that provides JavaScript bindings for creating and marshaling COM objects on Windows via the `ole32.dll` native proxy.

## Key Components

| Export | Description |
|---|---|
| `createInstance(RFCLSID, RFIID, options)` | Initializes the COM library and creates a COM object instance via `CoCreateInstance` |
| `marshalFunctions(obj, arr)` | Marshals an array of function definitions from an existing COM object's vtable |
| `marshalInterface(arr)` | Implements a COM interface locally by building a vtable with generic global callbacks |
| `CLSIDFromString(CLSIDString)` | Converts a CLSID string (e.g. `{...}`) to a 16-byte binary CLSID |
| `IIDFromString(IIDString)` | Converts an IID string to a 16-byte binary IID |
| `IID_IUnknown` | Pre-resolved IID for the base `IUnknown` interface |

## Usage Example

```javascript
var winCOM = require('./win-com');

// Convert string identifiers to binary CLSID/IID
var clsid = winCOM.CLSIDFromString('{20D04FE0-3AEA-1069-A2D8-08002B30309D}');
var iid   = winCOM.IIDFromString('{00000000-0000-0000-C000-000000000046}');

// Create a COM object instance
var comObj = winCOM.createInstance(clsid, iid);

// Marshal vtable functions from the COM object
var methods = winCOM.marshalFunctions(comObj, ['QueryInterface', 'AddRef', 'Release', 'MyMethod']);

// Implement a COM interface locally (outbound callbacks)
var impl = winCOM.marshalInterface([
    { name: 'QueryInterface', parms: ['void*','void*','void*'], func: function() { return 0; } },
    { name: 'AddRef',         parms: ['void*'],                 func: function() { return 1; } },
    { name: 'Release',        parms: ['void*'],                 func: function() { return 1; } }
]);

// Cleanup local interface callbacks when done
impl.cleanup();
```

> **Note:** This module is Windows-only and requires the `_GenericMarshal` native module. On 32-bit platforms, all functions passed to `marshalInterface` must include a `cx` (calling convention) property since `__stdcall` cannot be inferred from variadic signatures.
