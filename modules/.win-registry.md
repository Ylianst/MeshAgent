Provides a JavaScript interface for reading and writing Windows Registry keys using native Win32 API calls via `_GenericMarshal`.

## Key Components

- **`windows_registry` (constructor)** — Initializes native proxies for `Kernel32.dll` and `Advapi32.dll`, binding Win32 registry API methods. Exposes `HKEY` root handle constants (`Root`, `CurrentUser`, `LocalMachine`, `Users`).

- **`QueryKey(hkey, path, key)`** — Reads a registry value by key path and value name. Returns the value typed appropriately (`number` for DWORD, `string` for REG_SZ/REG_EXPAND_SZ, `Buffer` for binary). When called without a `key` argument, returns an object with `subkeys`, `values`, and an optional `default` property.

- **`QueryKeyLastModified(hkey, path)`** — Returns the last-modified timestamp of a registry key by querying `RegQueryInfoKeyW` and converting the `FILETIME` result.

- **`WriteKey(hkey, path, key, value)`** — Creates or opens a registry key and writes a value. Automatically maps JavaScript types to registry types (`boolean`/`number` → `REG_DWORD`, `string` → `REG_SZ`, other → `REG_BINARY`).

- **`KEY_DATA_TYPES`** — Constant map of Windows registry value type identifiers (`REG_SZ`, `REG_DWORD`, `REG_BINARY`, etc.).

## Usage Example

```javascript
var reg = require('win-registry');
var registry = new reg.windows_registry();

// Read a string value
var value = registry.QueryKey(
  registry.HKEY.LocalMachine,
  'SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion',
  'ProductName'
);
console.log(value); // e.g., "Windows 10 Pro"

// Enumerate subkeys and values
var result = registry.QueryKey(
  registry.HKEY.CurrentUser,
  'SOFTWARE\\MyApp'
);
console.log(result.subkeys); // ['SubKey1', 'SubKey2']
console.log(result.values);  // ['Setting1', 'Setting2']

// Write a DWORD value
registry.WriteKey(
  registry.HKEY.CurrentUser,
  'SOFTWARE\\MyApp',
  'Enabled',
  1
);

// Get last modified time
var ts = registry.QueryKeyLastModified(
  registry.HKEY.LocalMachine,
  'SOFTWARE\\MyApp'
);
```

> **Note:** This module is Windows-only and requires the `_GenericMarshal` native binding available in the MeshAgent runtime.
