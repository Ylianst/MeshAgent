Windows console helper module that provides programmatic control over the Windows console window and system tray icon functionality via native Win32 API bindings.

## Key Components

### `WindowsConsole` (class, exported as singleton)

Instantiated once and exported via `module.exports`. Only initializes on `win32` platform.

**Native dependencies proxied via `_GenericMarshal`:**
- `kernel32.dll` — `GetConsoleWindow`, `GetCurrentThread`
- `user32.dll` — `ShowWindow`, `LoadImageA`, `GetMessageA`
- `Shell32.dll` — `Shell_NotifyIconA`

**Console window methods:**

| Method | Win32 `nCmdShow` | Description |
|---|---|---|
| `minimize()` | `6` | Minimizes the console window |
| `restore()` | `9` | Restores the console window |
| `hide()` | `0` | Hides the console window |
| `show()` | `5` | Shows the console window |

**Tray icon methods:**

- **`_loadicon(imagePath)`** — Loads an `.ico` file from disk using `LoadImageA` with `LR_LOADFROMFILE | LR_SHARED | LR_DEFAULTSIZE` flags, returns a native icon handle.
- **`SetTrayIcon(options)`** — Creates a system tray icon with an optional balloon/toast notification. Returns a tray icon object with an event emitter interface.

**Tray icon events:**

| Event | Trigger |
|---|---|
| `ToastClicked` | User clicks the toast notification |
| `IconHover` | User hovers over the tray icon |
| `ToastDismissed` | Toast is dismissed (when `balloonOnly` is set) |

**Tray icon object methods:**
- **`remove()`** — Calls `Shell_NotifyIconA(NIM_DELETE)`, stops the message pump, and cleans up references.

## Usage Example

```javascript
var winConsole = require('./win-console');

// Hide/show the console window
winConsole.hide();
winConsole.show();

// Load an icon and create a system tray entry
var icon = winConsole._loadicon('C:\\icons\\app.ico');

var tray = winConsole.SetTrayIcon({
    icon: icon,
    szTip: 'My App',
    szInfo: 'Application is running in the background.',
    szInfoTitle: 'My App'
});

tray.on('ToastClicked', function () {
    console.log('User clicked the toast notification');
    winConsole.show();
});

tray.on('ToastDismissed', function () {
    console.log('Toast was dismissed');
});

// Later, remove the tray icon
tray.remove();
```

> **Note:** This module is a no-op on non-Windows platforms. All properties and methods are only attached when `process.platform === 'win32'`.
