Cross-platform proxy detection and configuration helper that discovers HTTP proxy settings from various OS-level sources (environment variables, package manager configs, system settings) and extends `Array.prototype` with parameter-parsing utilities.

## Key Components

### Array Prototype Extensions
- **`getParameterEx(name, defaultValue)`** — Searches an array of `--key=value` strings for a match by exact prefix, stripping surrounding quotes if present.
- **`getParameter(name, defaultValue)`** — Convenience wrapper for `getParameterEx` that prepends `--` to the name.

### Functions
- **`getAutoProxyDomain()`** — Retrieves the auto-proxy bypass domain from `_MSH().autoproxy` or the `--autoproxy` CLI argument; normalizes it with a leading `.` and returns `null` if no valid domain is found.
- **`linux_getProxy()`** — Probes multiple Linux proxy configuration sources in priority order and returns the first discovered proxy URL string (`http://[user:pass@]host:port`).

### Linux Proxy Sources (in order)
1. `/etc/environment` — `HTTP_PROXY` variable
2. `/etc/profile.d/proxy_setup` — `http_proxy` shell export
3. `/etc/apt/apt.conf.d/proxy.conf` — APT `Acquire::http::proxy`
4. `/etc/apt/apt.conf` — APT `Acquire::http::proxy`
5. `/etc/yum.conf` — `proxy`, `proxy_username`, `proxy_password`
6. `/etc/sysconfig/proxy` + `/root/.curlrc` — openSUSE `HTTP_PROXY` / `PROXY_ENABLED`
7. `/etc/login.conf` — BSD-style login class settings

## Usage Example

```javascript
// Retrieve Linux proxy URL at agent startup
const proxy = linux_getProxy();
if (proxy) {
    console.log('Using proxy:', proxy); // e.g. "http://user:pass@proxy.corp.local:8080"
}

// Get auto-proxy bypass domain from CLI args or MSH config
// process.argv = ['node', 'agent.js', '--autoproxy=corp.local']
const domain = getAutoProxyDomain(); // => ".corp.local"

// Array parameter helpers
const args = ['--host=proxy.corp.local', '--port=8080'];
args.getParameter('host');           // => "proxy.corp.local"
args.getParameterEx('--port', '80'); // => "8080"
```
