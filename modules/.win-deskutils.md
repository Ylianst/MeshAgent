Utility module for Windows desktop feature control, exposing wallpaper and mouse trails accessibility settings via the Win32 `SystemParametersInfoA` API with cross-session dispatch support.

## Key Components

| Export | Type | Description |
|---|---|---|
| `background.get(tsid)` | Function | Retrieves the current desktop wallpaper path |
| `background.set(path, tsid)` | Function | Sets the desktop wallpaper to the given file path |
| `mouse.getTrails(tsid)` | Function | Returns the current mouse trail cursor count (0–1 = disabled) |
| `mouse.setTrails(value, tsid)` | Function | Sets the mouse trail cursor count (0–1 disables the feature) |
| `dispatch(parent, method, args)` | Function | Internal helper invoked by child processes spawned via `sessionDispatch` |

**`tsid` parameter:** All public functions accept an optional Terminal Session ID. Pass `null` to target the currently logged-in user, pass a specific TSID to target that session, or omit (`undefined`) to operate in the current process context.

## Usage Example

```javascript
var deskutils = require('win-deskutils');

// Get the current desktop wallpaper path (current session)
var wallpaper = deskutils.background.get();
console.log('Wallpaper:', wallpaper);

// Set a new wallpaper for the currently logged-in user session
deskutils.background.set('C:\\Windows\\Web\\Wallpaper\\Windows\\img0.jpg', null);

// Get mouse trail count (0 or 1 means disabled)
var trails = deskutils.mouse.getTrails();
console.log('Mouse trails:', trails);

// Enable mouse trails with 5 cursors for a specific session (TSID = 2)
deskutils.mouse.setTrails(5, 2);

// Disable mouse trails for the current logged-in user
deskutils.mouse.setTrails(0, null);
```

> **Note:** When called with a `tsid` of `null` or a specific session ID, these functions automatically spawn a child process in the appropriate Windows user session using `ILibProcessPipe` spawn types. See [Microsoft docs](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfoa) for the underlying system call.
