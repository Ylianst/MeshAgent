Brief description: Provides a CLI utility for querying the live state of a running Mesh Agent process via a local IPC (named pipe or Unix socket) connection.

## Key Components

- **`queryAgent(obj, prev, path)`** — Core IPC communication function. Sends a JSON-encoded query command to the agent's IPC socket and returns a `Promise` resolving with the agent's response. Supports connection reuse via the `prev` parameter.
- **`dataHandler(chunk)`** — Stream data handler attached to the IPC socket. Reads a 4-byte little-endian length prefix, parses the JSON payload, and resolves or rejects the associated promise.
- **`start()`** — Entry point that chains three sequential IPC queries (`connection`, `descriptors`, `timerinfo`), printing each result to stdout. Exits after 3 seconds if the agent is unreachable.
- **`ipcPath`** — Platform-aware IPC path: a named pipe on Windows (`\\.\pipe\<nodeid>-DAIPC`) or a Unix socket file (`./DAIPC`) on other platforms.

## Usage Example

```javascript
// Query agent status directly from CLI (calls start())
var agentStatus = require('_agentStatus');
agentStatus.start();

// Or send a custom IPC query programmatically
var agentStatus = require('_agentStatus');

agentStatus.query('connection').then(function (result, connection) {
    console.log('Agent connected to:', result);
    // Reuse connection for a follow-up query
    return agentStatus.query('descriptors', connection);
}).then(function (descriptors) {
    console.log('Open descriptors:', descriptors);
}).catch(function (err) {
    console.error('IPC query failed:', err);
});
```

## Notes

- The IPC message framing uses a **4-byte LE uint32 length prefix** followed by the JSON body. The length field itself is included in the count (`j.length + 4`).
- The agent node ID is sourced from [`_agentNodeId`](https://github.com/flamingo-stack/meshagent/blob/main/meshcentral-modules/_agentNodeId.js) to construct a unique per-node pipe name.
- A 3-second timeout guard in `start()` prevents indefinite hangs when the agent process is not running.
