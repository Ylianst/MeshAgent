A writable stream utility that computes CRC32 or CRC32C checksums incrementally as data is written through the stream.

## Key Components

- **`create(useCRC32c)`** — Factory function that returns a Node.js `Writable` stream instance configured to compute either a standard CRC32 or CRC32C checksum. Accepts a boolean `useCRC32c` to select the algorithm.
- **`stream.value`** — Read-only property on the returned stream that exposes the current (running) checksum value.
- **`stream._current`** — Internal state tracking the accumulated checksum across all written chunks.

## Usage Example

```javascript
const crc32Stream = require('./crc32-stream');
const fs = require('fs');

// Create a CRC32 checksum stream (pass true for CRC32C)
const checksumStream = crc32Stream.create(false);

checksumStream.on('finish', () => {
    console.log('CRC32 checksum:', checksumStream.value);
});

// Pipe a file through the checksum stream
fs.createReadStream('/path/to/file').pipe(checksumStream);

// Or write chunks manually
const crc32cStream = crc32Stream.create(true); // use CRC32C variant
crc32cStream.write(Buffer.from('hello'));
crc32cStream.write(Buffer.from(' world'));
crc32cStream.end(() => {
    console.log('CRC32C checksum:', crc32cStream.value);
});
```

> **Note:** This module depends on external `crc32` and `crc32c` functions being available in scope. Ensure the appropriate CRC implementation is loaded alongside this file.
