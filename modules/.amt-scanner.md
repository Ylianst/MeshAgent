Discovers Intel AMT (Active Management Technology) devices on a local network by broadcasting RMCP (Remote Management and Control Protocol) ping packets over UDP and collecting responses.

## Key Components

### `AMTScanner` (class)

- **`buildRmcpPing(tag)`** — Constructs a UDP RMCP ping packet with the specified tag byte used to identify responses.
- **`parseRmcpPacket(server, data, rinfo, func)`** — Parses an RMCP response, extracting AMT version, provisioning state, open ports (`16992`/`16993`), and IP address.
- **`parseIPv4Range(range)`** — Converts an IP range string (CIDR notation `192.168.1.0/24` or dash notation `192.168.1.1-192.168.1.254`) into `{ min, max }` numeric bounds.
- **`parseIpv4Addr(addr)`** — Converts a dotted-decimal IP string to a 32-bit integer.
- **`IPv4NumToStr(num)`** — Converts a 32-bit integer back to a dotted-decimal IP string.
- **`scan(rangestr, timeout, callback)`** — Scans an IP range for AMT devices via UDP port `623`, collecting results and returning them via callback and a `found` event after the timeout.

### Events

- **`found`** — Emitted on scan completion with an array of discovered AMT device objects.

## Usage Example

```javascript
const AMTScanner = require('./amt-scanner');

const scanner = new AMTScanner();

// Using callback
scanner.scan('192.168.1.0/24', 5000, function (results) {
    results.forEach(device => {
        console.log(`Found AMT device at ${device.address}`);
        console.log(`  AMT Version: ${device.majorVersion}.${device.minorVersion}`);
        console.log(`  Open Ports: ${device.openPorts.join(', ')}`);
        console.log(`  Provisioning State: ${device.provisioningState}`); // 0=Pre, 1=In, 2=Post
    });
});

// Using event emitter
scanner.on('found', (results) => {
    console.log(`Scan complete. Found ${results.length} AMT device(s).`);
});

scanner.scan('192.168.1.1-192.168.1.50', 3000);
```
