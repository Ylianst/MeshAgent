Provides macOS power management utilities for sleep, restart, and shutdown operations by invoking native system commands via child processes.

## Key Components

- **`powerutil`** — Constructor function that exposes three power management methods as a singleton export.
- **`sleep()`** — Puts the macOS system to sleep using `osascript` via the System Events API.
- **`restart()`** — Restarts the macOS system using `shutdown -r now`.
- **`shutdown()`** — Powers off the macOS system using `shutdown -h now`.

## Usage Example

```javascript
const powerutil = require('./mac-powerutil');

// Put the system to sleep (macOS only)
powerutil.sleep();

// Restart the system (macOS only)
powerutil.restart();

// Shut down the system (macOS only)
powerutil.shutdown();
```

> **Platform restriction:** All three methods are implemented exclusively for `darwin` (macOS). Calling any method on a non-macOS platform throws an error, e.g.:
>
> ```text
> Error: sleep() not implemented on this platform
> ```

## Notes

- The module exports a **singleton instance** — `require('./mac-powerutil')` returns the same `powerutil` object every time.
- Each operation spawns a `/bin/sh` child process synchronously via `waitExit()`, blocking until the command completes.
- `sleep()` relies on `osascript` (AppleScript), while `restart()` and `shutdown()` use the Unix `shutdown` command directly — the latter two typically require elevated privileges (`sudo`).
