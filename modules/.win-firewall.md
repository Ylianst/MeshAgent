Provides a Node.js interface to the Windows Firewall API via COM interop, enabling enumeration, querying, and management of Windows Firewall rules using native Windows COM objects (`INetFwPolicy2`, `INetFwRule`).

## Key Components

- **`getRulesCount()`** — Returns the total number of firewall rules configured on the system.
- **`getRulesCount2(options)`** — Asynchronously retrieves the firewall rules count using a Promise/EventEmitter pattern with progress events.
- **`getFirewallRulesAsync2(p)`** — Internal async iterator that enumerates firewall rules one-by-one via COM's `IEnumVARIANT`, emitting `rule` and `progress` events.
- **`ProfileMaskToString(mask)`** — Converts a bitmask integer to a human-readable profile string (`DOMAIN`, `PRIVATE`, `PUBLIC`).
- **COM GUIDs** — Declares `CLSID_NetFwPolicy2`, `CLSID_NetFwRule`, `IID_INetFwPolicy2`, and `IID_IEnumVARIANT` for Windows Firewall COM instantiation.
- **`protocolNumbers`** — IANA protocol number lookup array (index 0–143) mapping numeric protocol IDs to names (e.g., `6` → `TCP`, `17` → `UDP`).

## Usage Example

```javascript
// Enumerate firewall rules with optional filtering
var fw = require('win-firewall');

// Get count of all rules
var count = fw.getRulesCount();
console.log('Total rules:', count);

// Async enumeration with progress and per-rule events
var result = fw.getRulesCount2({ program: 'C:\\Windows\\System32\\svchost.exe', minimal: false });

result.on('progress', function(pct) {
    console.log('Progress:', pct);
});

result.on('rule', function(rule) {
    console.log('Rule found:', rule.DisplayName, '|', rule.direction, '|', rule.Protocol);
});

result.then(function(rules) {
    console.log('All matching rules:', rules);
});
```

## Options (`getRulesCount2`)

| Option | Type | Description |
|---|---|---|
| `program` | `string` | Filter rules by application path |
| `minimal` | `boolean` | Skip detailed property fetching |
| `noResult` | `boolean` | Suppress resolved array (events only) |
| `timeout` | `number` | Abort enumeration after N milliseconds |

> **Platform:** Windows only. Requires `_GenericMarshal`, `win-com`, and `OleAut32.dll` native bindings available in the [MeshAgent](https://github.com/flamingo-stack/meshagent) runtime.
