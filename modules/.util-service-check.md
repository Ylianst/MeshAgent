Windows-only utility that determines the service name of the currently running MeshAgent process by inspecting the Windows registry and matching process IDs.

## Key Components

### `win_serviceCheck()`
The primary function exported on Windows platforms. Uses a two-phase lookup strategy:

1. **Primary lookup** — Queries `HKLM\SOFTWARE\Open Source` where MeshAgent stores installation registry entries, then uses `service-manager` to check if any listed service's PID matches the current process.
2. **Fallback brute-force** — If no match is found, enumerates all services under `HKLM\SYSTEM\CurrentControlSet\Services`, compares each service's `ImagePath` to `process.execPath`, then verifies the PID match via `service-manager`.

Returns the **service name string** if matched, or `null` if no match is found.

### Platform Export
- **`win32`** — Exports `win_serviceCheck`
- **All other platforms** — Exports a no-op function that always returns `null`

## Usage Example

```javascript
const serviceCheck = require('./util-service-check');

const serviceName = serviceCheck();

if (serviceName) {
  console.log(`Running as Windows service: ${serviceName}`);
} else {
  console.log('Not running as a Windows service (or name could not be determined)');
}
```

## Dependencies

| Module | Purpose |
|---|---|
| `win-registry` | Reads Windows registry keys |
| `service-manager` | Interfaces with the Windows Service Control Manager to retrieve service info and check PID ownership via `isMe()` |
