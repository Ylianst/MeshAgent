A cross-platform `wget` utility module that downloads remote files over HTTP, saves them to a local path, and resolves a SHA-384 hash of the received content. Designed for environments where native `wget` is unavailable, with built-in Windows proxy detection.

## Key Components

- **`wget(remoteUri, localFilePath, wgetoptions)`** — Main export. Returns a Promise enhanced with EventEmitter capabilities.
  - Resolves with a hex-encoded SHA-384 hash of the downloaded file
  - Rejects on network errors or non-200 HTTP status codes
  - **Events:** `bytes` (emitted with running byte total), `abort` (emitted on request abort)
  - **Method:** `.abort()` — cancels the in-flight request
  - **Method:** `.progress()` — returns total bytes received so far
- **Windows Proxy Detection** — Reads `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings` via `win-registry` and initializes `global-tunnel` when a proxy is configured, but only when the MeshAgent control channel is not already connected.

## Usage Example

```javascript
var wget = require('./wget');

var download = wget('http://example.com/file.zip', '/tmp/file.zip');

// Track download progress
download.on('bytes', function(totalBytes) {
    console.log('Received: ' + totalBytes + ' bytes');
});

// Handle completion (resolves with SHA-384 hash)
download.then(function(hash) {
    console.log('Download complete. SHA-384: ' + hash);
}).catch(function(err) {
    console.error('Download failed:', err);
});

// Optional: cancel the download
// download.abort();

// Optional: pass custom HTTP options (e.g., headers, TLS settings)
var download2 = wget(
    'https://secure.example.com/data.tar.gz',
    '/tmp/data.tar.gz',
    { rejectUnauthorized: false }
);
```
