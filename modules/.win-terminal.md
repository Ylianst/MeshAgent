Provides a Windows-native terminal emulation session by wrapping Win32 console APIs (`User32.dll`, `Kernel32.dll`) through a generic marshaling layer, exposing the session as a Node.js Duplex stream.

## Key Components

| Export / Symbol | Description |
|---|---|
| `windows_terminal` | Constructor function that creates and manages a Windows console terminal session |
| `StartEx(width, height, target)` | Launches a legacy Windows terminal session (fixed at 80×25), allocates a hidden console, and returns a Duplex stream for I/O |
| `ClearScreen()` | Clears the console buffer, resets attributes, and repositions the cursor and window using Win32 APIs |
| `SendCursorUpdate()` | Reads `CONSOLE_SCREEN_BUFFER_INFO` and tracks cursor position changes |
| `PowerShellCapable()` | Checks whether PowerShell is installed on the current architecture (`x64` vs other) |
| `_hookThread(target)` | (Referenced but truncated) Sets up Win32 event hooks (`SetWinEventHook`) for console events |

**Win32 dependencies loaded at module level:**

- `User32.dll` — `SetWinEventHook`, `VkKeyScanA`, `MapVirtualKeyA`, `PostThreadMessageA`, `ShowWindow`, message loop helpers
- `Kernel32.dll` — `CreateProcessA`, `AllocConsole`, console buffer/screen APIs, `WriteConsoleInputA`

## Usage Example

```javascript
var WinTerminal = require('./win-terminal');

var term = new WinTerminal();

if (term.PowerShellCapable()) {
    var stream = term.StartEx(80, 25, 'powershell.exe');

    // Write input to the terminal
    stream.write('dir\r\n');

    // Read terminal output
    stream.on('data', function (chunk) {
        process.stdout.write(chunk);
    });

    stream.on('end', function () {
        console.log('Terminal session ended.');
    });
}
```

> **Note:** This module is Windows-only and requires the `_GenericMarshal` native binding available in the [MeshAgent](https://github.com/flamingo-stack/meshagent) runtime. It is not compatible with standard Node.js environments.
