Cross-platform utility that queries the operating system's configured DNS nameserver addresses, exporting a platform-appropriate function at module load time.

## Key Components

| Export | Platform | Method |
|--------|----------|--------|
| `windows_dns()` | Windows | Calls `GetNetworkParams` via `Iphlpapi.dll` using `_GenericMarshal` |
| `linux_dns()` | Linux / FreeBSD | Parses `nameserver` entries from `/etc/resolv.conf` via shell + `awk` |
| `macos_dns()` | macOS | Runs `scutil --dns` and extracts nameserver entries via shell + `awk` |
| Default | Unknown platforms | Returns an empty array `[]` |

The module exports a **single function** (selected at runtime by `process.platform`) that, when called, returns an array of DNS server IP address strings.

## Usage Example

```javascript
// The module auto-selects the correct implementation for the current OS
const getDnsServers = require('./util-dns');

const servers = getDnsServers();
console.log(servers);
// Example output on Linux: ["192.168.1.1", "8.8.8.8"]
// Example output on Windows: ["192.168.1.1"]
// Example output on an unsupported platform: []
```

## Notes

- **Windows**: Uses `_GenericMarshal` (a native interop module specific to the MeshAgent runtime) to call `GetNetworkParams` directly; pointer-size offsets differ between 32-bit (`268`) and 64-bit (`272`) builds.
- **Linux/FreeBSD**: Spawns a shell subprocess and filters `/etc/resolv.conf` for non-commented `nameserver` lines.
- **macOS**: Spawns a shell subprocess using `scutil --dns`, which reflects the system's active DNS configuration including VPN overrides.
- Return values are always an array of strings; errors or parse failures silently return `[]`.
