Embedded firmware blob containing the MeshCommander web application (GZIP-compressed, Base64-encoded) along with the main CLI entry point for `meshcmd` — a command-line tool for managing Intel AMT devices and MeshCentral connectivity.

## Key Components

- **`meshCmdVersion`** — Version string dynamically replaced at build time with the current MeshCentral release.
- **`Large_IntelAmtWebApp`** — Embedded, GZIP-compressed, Base64-encoded MeshCommander v0.7.4 web UI served directly from the binary for Intel AMT firmware interaction.
- **Network globals** — `tcpserver`, `broadcastSockets`, `multicastSockets`, `discoveryInterval` manage local TCP/UDP device discovery.
- **Multicast addresses** — `membershipIPv4` (`239.255.255.235`) and `membershipIPv6` (`FF02:0:0:0:0:0:0:FE`) for AMT device discovery over the local network.
- **AMT stack references** — `amtLms`, `amtMei`, `amtMeiState`, `wsstack`, `amtstack` hold runtime handles to Intel AMT LMS, MEI, WebSocket, and AMT protocol stacks.
- **SMBios** — `SMBiosTables` stores parsed SMBIOS firmware tables used for hardware identification.

## Notes

This file is the entry point for the [`meshcmd`](https://github.com/flamingo-stack/meshagent) CLI. The embedded `Large_IntelAmtWebApp` blob is intentionally large — it is decoded and served at runtime rather than loaded from disk, making `meshcmd` a self-contained binary suitable for deployment on managed endpoints without external file dependencies.
