Cross-platform Wi-Fi network scanner that detects nearby wireless access points on Windows and Linux, emitting structured access point data via an event-driven interface.

## Key Components

### `AccessPoint(ssid, bssid, lq)`
Constructor representing a single wireless access point with SSID, BSSID, and link quality fields. Includes a `toString()` method for human-readable formatting.

### `WiFiScanner`
Main class (EventEmitter) with two methods:

- **`hasWireless()`** — Checks network interfaces via `os.networkInterfaces()` and returns `true` if any interface has type `'wireless'`.
- **`Scan()`** — Initiates a platform-specific Wi-Fi scan:
  - **Windows:** Spawns a `ScriptContainer` child process running `wifi-scanner-windows`, forwarding results as `accessPoint` events.
  - **Linux:** Executes `/sbin/iwlist scan` via `child_process`, parses the stdout output to extract BSSID, ESSID, and signal/quality values.

### Event: `accessPoint`
Emitted for each discovered access point, passing an `AccessPoint` instance with `ssid`, `bssid`, and `lq` properties.

## Usage Example

```javascript
var WiFiScanner = require('./wifi-scanner');

var scanner = new WiFiScanner();

if (scanner.hasWireless()) {
    scanner.on('accessPoint', function (ap) {
        console.log(ap.toString());
        // Output: [AA:BB:CC:DD:EE:FF]: MyNetwork (70)
    });
    scanner.Scan();
} else {
    console.log('No wireless interface found.');
}
```

## Notes

- Requires `MemoryStream` and platform-specific modules (`wifi-scanner-windows` on Windows, `/sbin/iwlist` on Linux).
- Linux parsing targets `iwlist` output format; signal quality may appear as either `Signal level=` or `Quality=` depending on the driver.
- Source: [`wifi-scanner.js`](https://github.com/flamingo-stack/meshagent/blob/main/wifi-scanner.js)
