Cross-platform path construction utility that normalizes file path building across Windows and Unix-like systems.

## Key Components

### `makePath(path1, path2, useCWD)`
The sole export. Combines a base path and filename into a platform-appropriate path string.

| Parameter | Type | Description |
|-----------|------|-------------|
| `path1` | `string` | Base path or executable path |
| `path2` | `string` | Filename, extension (e.g. `.log`), or subdirectory to append |
| `useCWD` | `boolean` | If `true`, replaces `path1`'s directory with the current working directory |

**Behavior:**
- Uses `\\` on Windows, `/` elsewhere, based on `process.platform`
- If `path2` starts with `.`, treats it as a file extension — strips `.exe` from `path1` and appends the new extension
- If `useCWD` is `true`, uses the leaf folder name from `path1` placed under `process.cwd()`
- Otherwise, replaces the filename component of `path1` with `path2`

## Usage Example

```javascript
const makePath = require('./util-pathHelper');

// Replace filename in a path
makePath('/usr/bin/meshagent', 'config.json');
// → '/usr/bin/config.json'

// Swap extension (e.g. .exe → .log)
makePath('C:\\agent\\meshagent.exe', '.log');
// → 'C:\\agent\\meshagent.log'

// Use current working directory instead of path1's directory
makePath('/usr/bin/meshagent', 'config.json', true);
// → '{cwd}/meshagent/config.json'
```

## Notes

- Designed for internal use within [meshagent](https://github.com/flamingo-stack/meshagent)
- Relies on `process.platform` and `process.cwd()` — Node.js runtime only
- No external dependencies
