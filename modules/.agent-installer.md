Cross-platform helper utility that installs and manages the Mesh Agent as a background service, handling parameter normalization, `.msh` configuration file parsing/updating, and installation detection across macOS (bundle and standalone) and other platforms.

## Key Components

| Export / Function | Description |
|---|---|
| `checkParameters(parms)` | Validates and normalizes the installer parameter array; adds defaults from the `.msh` config and ensures `--meshServiceName` is present |
| `normalizeInstallPath(path)` | Normalizes an install path to a trailing-slash directory string |
| `parseMshFile(mshPath)` | Reads and parses a `.msh` key=value config file into an object |
| `updateMshFile(mshPath, updates)` | Updates or appends key=value pairs in an existing `.msh` file |
| `findInstallation(installPath, serviceName, companyName)` | Locates an existing agent installation by checking for an `.app` bundle or standalone binary |
| `detectSourceType()` | Detects whether the agent is running from a macOS `.app` bundle or a standalone binary |
| `detectInstallationType(installPath)` | Returns `'bundle'`, `'standalone'`, or `null` based on what exists at the given path |
| `findBundleInDirectory(installPath)` | Scans a directory for any `.app` bundle containing a `meshagent` binary |
| `findFileCaseInsensitive(directory, targetFilename)` | Case-insensitive file lookup within a directory |
| **Array polyfills** | `getParameter`, `getParameterEx`, `getParameterIndex`, `deleteParameter`, `getParameterValue` — helpers for parsing CLI argument arrays |

## Usage Example

```javascript
// Normalize and validate installer parameters
var parms = process.argv.slice(2);
checkParameters(parms);
// parms now contains --meshServiceName, --description, --displayName, etc.

// Parse an existing .msh configuration file
var msh = parseMshFile('/usr/local/mesh_services/meshagent/meshagent.msh');
console.log(msh.MeshServer); // e.g. "wss://mesh.example.com/agent.ashx"

// Update specific keys in .msh without rewriting unrelated entries
updateMshFile('/usr/local/mesh_services/meshagent/meshagent.msh', {
    MeshID: 'newMeshId',
    Tag: 'production'
});

// Detect whether a bundle or standalone binary is installed
var installType = detectInstallationType('/usr/local/mesh_services/meshagent/');
// Returns: 'bundle', 'standalone', or null

// Detect how the current process was launched
var source = detectSourceType();
if (source.type === 'bundle') {
    console.log('Running from bundle at', source.bundlePath);
}
```
