Provides utilities for creating and inspecting USTAR-format TAR archives as Node.js readable streams, supporting both file lists and directory traversal.

## Key Components

| Export | Description |
|---|---|
| `encodeFiles(files, basePath)` | Creates a readable stream encoding an array of file paths into a TAR archive |
| `encodeFolder(folderPath, recurse)` | Wraps `encodeFiles` after expanding a directory into a file list |
| `showHeader(path, offset)` | Reads and logs USTAR header fields from an existing TAR file at a given byte offset |

### Internal Helpers

- **`generateUstarHeader(path, basePath, uidtable, gidtable)`** — Builds a 512-byte USTAR header buffer for a given file, handling cross-platform UID/GID/mode differences between Windows and POSIX.
- **`expandFolderPaths(folderPath, recurse, arr)`** — Recursively or shallowly enumerates files/directories into a flat array.
- **`loadUstarHeader(path, offset)`** — Reads and checksum-validates a 512-byte USTAR header from an existing TAR file.

## Usage Example

```javascript
const tar = require('./tar-encoder');

// Encode a specific list of files into a TAR stream
const fileStream = tar.encodeFiles(
  ['/home/user/file1.txt', '/home/user/file2.txt'],
  '/home/user'
);
fileStream.pipe(require('fs').createWriteStream('output.tar'));

// Encode an entire folder recursively
const folderStream = tar.encodeFolder('/home/user/myproject', true);
folderStream.pipe(require('fs').createWriteStream('project.tar'));

// Inspect headers of an existing TAR file
tar.showHeader('/path/to/archive.tar', 0);
```

> **Platform note:** On Windows, UID/GID are set to `0` and owner/group names default to `root`. On POSIX systems, real UID/GID metadata is resolved via `user-sessions`.
