Utility for computing a canonical hash of a MeshAgent executable by streaming file bytes while skipping PE authenticode fields (checksum, certificate table) and any embedded MSH policy data.

## Key Components

- **`hashFile(options)`** — Main export. Reads a binary executable and pipes its "signable" content to a writable stream, omitting:
  - PE checksum bytes (4 bytes at `CheckSumPos`)
  - Certificate table pointer bytes (8 bytes at `CertificateTableSizePos`)
  - Embedded MSH policy payload (detected via `exeMeshPolicyGuid` at EOF)

- **`exeMeshPolicyGuid`** — Sentinel GUID (`B996015880544A19B7F7E9BE44914C19`) used to detect an embedded MeshPolicy block appended to the executable.

## Options

| Property | Type | Required | Description |
|---|---|---|---|
| `sourcePath` | `string` | ✅ | Path to the executable file |
| `targetStream` | `stream.Writable` | ✅ | Destination stream for hashed bytes |
| `platform` | `string` | ❌ | `'win32'` or `'other'`; auto-detected via PE_Parser if omitted |

## Usage Example

```javascript
const hashFile = require('./AgentHashTool');
const crypto = require('crypto');

const hash = crypto.createHash('sha384');
hash.on('readable', () => {
  const data = hash.read();
  if (data) {
    console.log('Agent hash:', data.toString('hex'));
  }
});

hashFile({
  sourcePath: '/usr/local/bin/meshagent',
  targetStream: hash,
  platform: 'linux' // optional; omit to auto-detect
});
```

> **Note:** On Windows, `PE_Parser` is required to locate the PE checksum and certificate table offsets. On other platforms, only the MSH policy tail is excluded before hashing.
