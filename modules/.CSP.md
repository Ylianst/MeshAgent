Parses and executes AMT (Intel Active Management Technology) configuration commands via a JSON-based CLI interface, bridging Windows COM interop with AMT's WSMAN/PTHI stack.

## Key Components

| Export / Symbol | Description |
|---|---|
| `comObject` | `ComObjectInterop` instance used to dispatch results or errors back to the calling process |
| `ERRORS` | Named error code map (e.g., `JSON`, `Privileges`, `Wsman`, `Pthi`) used for `process.exit()` and dispatch payloads |
| `isAdmin()` | Checks Windows administrator group membership via `Advapi32.dll` native interop |
| `init()` | Establishes the AMT realm via HTTP digest handshake, retrieves the local system account, and wires up the WSMAN/AMT stack |
| `run()` | Routes `command.Action` + `command.ResourceUri` to the appropriate AMT operation (e.g., GET activation state, certificates, configuration) |

## Usage Example

```bash
# Run from an elevated (admin) shell
CSP "{""Action"": ""GET"", ""ResourceUri"": ""Settings/ActivationState""}" -debug
CSP "{""Action"": ""GET"", ""ResourceUri"": ""Settings/Configuration""}"
```

```javascript
// Internally, the parsed command drives dispatch like:
comObject.dispatch({ controlMode: 1 }); // success result
comObject.dispatch({ ErrorDescription: 'JSON Error - ...', ErrorCode: 65535 }); // error result
process.exit(0); // or process.exit(ERRORS.SomeError)
```

> **Note:** Requires system administrator privileges on Windows. The script will exit with `ERRORS.Privileges` (`65525`) if run without elevation.
