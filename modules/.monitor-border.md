A cross-platform module that draws animated colored borders around all connected monitors, used for visual identification during remote support sessions. Provides platform-specific implementations for Windows (via GDI) and Linux (via X11).

## Key Components

### `windows_monitorborder`
Windows implementation using `user32.dll` and `gdi32.dll` via `_GenericMarshal`.
- **`Start()`** — Queries monitor info and begins an interval (450ms) that cycles through 8 states, drawing animated red/yellow 5px border segments around each monitor using `FillRect`.
- **`Stop()`** — Clears the interval and calls `InvalidateRect` to repaint/remove the drawn borders.

### `linux_monitorborder`
Linux implementation using X11 bindings from `monitor-info`.
- **`Start()`** — Queries display info and draws borders using `XDrawLine` (standard X11) or creates borderless overlay windows (Unity/Wayland environments).
- **`Stop()`** — Clears drawn lines using `GXclear` XOR function and flushes the X11 display.

Both classes extend `EventEmitter` and auto-call `Stop()` on object destruction (`~` event).

## Usage Example

```javascript
var border;

if (process.platform === 'win32') {
    border = new windows_monitorborder();
} else {
    border = new linux_monitorborder();
}

// Start animated border on all monitors
border.Start();

// Stop and clear borders after 5 seconds
setTimeout(function () {
    border.Stop();
}, 5000);
```

## Platform Notes

| Platform | Renderer | Border Style |
|---|---|---|
| Windows | GDI via `user32.dll` / `gdi32.dll` | Animated red/yellow `FillRect` segments |
| Linux (standard) | X11 `XDrawLine` with XOR GC | XOR-drawn border lines |
| Linux (Unity) | X11 `XCreateSimpleWindow` overlays | Borderless always-on-top windows |
