Provides a UPnP (Universal Plug and Play) client implementation for discovering, connecting to, and interacting with UPnP devices on a local network via SSDP multicast, XML description parsing, and SOAP-based action invocation.

## Key Components

- **`upnpdevice(descriptionUrl, usn, cp, localInterface)`** — Represents a discovered UPnP device. Fetches and parses the device description document, manages an embedded HTTP event server for receiving UPnP notifications, and emits `alive`, `bye`, `error`, and `serviceLoaded` events.
- **`upnpservice(parentDevice, xmlDoc)`** — Represents a UPnP service within a device. Loads the SCPD (Service Control Protocol Description) XML to enumerate available actions and state variables.
- **`upnpaction(service, xmlDoc)`** — Represents an invocable UPnP action. Builds and sends SOAP HTTP POST requests to the device's control URL and returns a `Promise` resolving to the response body.
- **`upnpargument(action, xmlDoc)`** — Models a single input/output argument for a UPnP action, linked to its related state variable.

## Usage Example

```javascript
var upnp = require('./upnp');

// Create a UPnP control point and start discovery
var cp = upnp.createControlPoint();

// Listen for discovered devices
cp.on('device', function (device) {
    console.log('Found device:', device.friendlyName);

    // Load all services on the device
    device.loadAllServices();

    device.on('serviceLoaded', function () {
        // Find a specific service
        var service = device.getService('urn:schemas-upnp-org:service:WANIPConnection:1');
        if (service) {
            // Invoke an action with arguments
            var action = service.getAction('GetExternalIPAddress');
            action.invoke({}).then(function (result) {
                console.log('External IP:', result.NewExternalIPAddress);
            }).catch(function (err) {
                console.error('Action failed:', err);
            });
        }
    });
});

// Start SSDP discovery
cp.search('upnp:rootdevice');
```

## Notes

- Requires custom modules: `promise`, `parseXml`, `MemoryStream` (non-standard Node.js builtins).
- The embedded event server (`_startEventServer`) listens on a dynamic port on the specified local interface to receive UPnP `NOTIFY` callbacks.
- Source: [`upnp.js`](https://github.com/flamingo-stack/meshagent/blob/main/upnp.js)
