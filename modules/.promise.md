A custom Promise implementation built on Node.js `EventEmitter`, providing `then`, `catch`, `finally`, `Promise.resolve`, `Promise.reject`, and `Promise.all` semantics without relying on the native V8 Promise engine. Designed for embedded/mesh agent environments where fine-grained lifecycle control is needed.

## Key Components

| Export / Symbol | Description |
|---|---|
| `Promise(promiseFunc)` | Constructor — mirrors the standard `new Promise((resolve, reject) => …)` API |
| `Promise.prototype.then` | Chains resolved/rejected handlers; returns a new child `Promise` |
| `Promise.prototype.catch` | Registers a rejection handler; clears any pending uncaught-rejection timer |
| `Promise.prototype.finally` | Registers a handler that fires on `settled` regardless of outcome |
| `Promise.resolve(value)` | Static factory — returns an already-resolved `Promise` |
| `Promise.reject(reason)` | Static factory — returns an already-rejected `Promise` |
| `Promise.all(list)` | Static combinator — resolves when all promises in the list resolve (implementation truncated in source) |
| `event_switcher(callee, target)` | Binds a callback to a specific `this` context for internal event dispatch |
| `event_forwarder(src, srcName, tgt, tgtName)` | Forwards a named event from one emitter to another |
| `getRootPromise(obj)` | Walks the `parentPromise` chain to find the root promise |

## Usage Example

```javascript
var Promise = require('./promise');

// Basic resolve/reject
new Promise(function (resolve, reject) {
    setTimeout(function () { resolve('hello'); }, 100);
})
.then(function (value) {
    console.log('Resolved:', value); // "Resolved: hello"
    return 'chained';
})
.then(function (value) {
    console.log('Chained:', value);  // "Chained: chained"
})
.catch(function (err) {
    console.error('Error:', err);
})
.finally(function () {
    console.log('Done');
});

// Static helpers
Promise.resolve(42).then(function (v) { console.log(v); }); // 42
Promise.reject(new Error('fail')).catch(function (e) { console.error(e.message); });

// Promise.all
Promise.all([
    Promise.resolve(1),
    Promise.resolve(2)
]).then(function (results) {
    console.log(results); // [1, 2]
});
```

> **Note:** This is a custom event-driven Promise implementation, not the native V8 Promise. Uncaught rejections are surfaced via `process.emit('uncaughtException', …)`.
