A WSMAN (Web Services Management) stack implementation for Intel AMT (Active Management Technology) devices, providing methods to perform standard WS-Management operations over HTTP/HTTPS.

## Key Components

- **`WsmanStackCreateService`** — Factory function that creates a WSMAN service object. Accepts either a config object with a `transport` property or positional arguments `(CreateWsmanComm, host, port, user, pass, tls, extra)`.
- **`PerformAjax`** — Core method that wraps SOAP envelope construction and delegates to the underlying transport layer, parsing XML responses via `amt-xml`.
- **`ExecGet`** — Performs a WS-Transfer GET operation on a resource URI.
- **`ExecPut`** — Performs a WS-Transfer PUT operation to update a resource.
- **`ExecCreate`** — Performs a WS-Transfer CREATE operation.
- **`ExecDelete`** — Performs a WS-Transfer DELETE operation.
- **`ExecEnum`** — Initiates a WS-Enumeration Enumerate operation.
- **`ExecPull`** — Pulls results from an active enumeration context.
- **`ExecMethod`** / **`ExecMethodXml`** — Invokes a CIM method on a resource, accepting args as a JS object or pre-formatted XML.
- **`ExecSubscribe`** / **`ExecUnSubscribe`** — Manages WS-Eventing subscriptions with optional digest authentication.
- **`CancelAllQueries`** — Cancels all pending requests via the transport layer.

## Usage Example

```javascript
const WsmanStack = require('./amt-wsman');
const WsmanComm  = require('./amt-wsman-comm');

const stack = WsmanStackCreateService({
  transport: WsmanComm,
  host: '192.168.1.100',
  port: 16992,
  user: 'admin',
  pass: 'Password123!',
  tls: false
});

const powerStateURI = 'http://schemas.dmtf.org/wbem/wscim/1/cim-schema/2/CIM_AssociatedPowerManagementService';

// GET a resource
stack.ExecGet(powerStateURI, (stack, name, response, status) => {
  if (status === 200) {
    console.log('Response:', response.Body);
  }
});

// Invoke a method with arguments
stack.ExecMethod(
  'http://schemas.dmtf.org/wbem/wscim/1/cim-schema/2/CIM_PowerManagementService',
  'RequestPowerStateChange',
  { PowerState: 2, ManagedElement: null },
  (stack, name, response, status) => { console.log(status); }
);
```
