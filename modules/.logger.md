Lightweight structured logging module for the MeshAgent, providing timestamped log output with configurable severity levels and a fixed `tool_id=meshcentral-agent` tag on every line.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `debug` | Function | Logs a `DEBUG` message (suppressed unless level is set to `DEBUG`) |
| `info` | Function | Logs an `INFO` message (default minimum level) |
| `warn` | Function | Logs a `WARN` message |
| `error` | Function | Logs an `ERROR` message |
| `setLevel` | Function | Sets the minimum log level by name (`'DEBUG'`–`'ERROR'`) or numeric value (0–3) |
| `getLevel` | Function | Returns the current log level name as a string |
| `LOG_LEVELS` | Object | Numeric constants: `DEBUG=0`, `INFO=1`, `WARN=2`, `ERROR=3` |

Output format per line:

```text
2024-11-01T12:00:00.000Z INFO Starting agent tool_id=meshcentral-agent
```

## Usage Example

```javascript
const logger = require('./logger');

// Default level is INFO — debug messages are suppressed
logger.info('Agent started');
logger.warn('Connection retry attempt');
logger.error('Failed to reach server');

// Enable verbose debug logging
logger.setLevel('DEBUG');
logger.debug('Raw payload received');

// Inspect current level
console.log(logger.getLevel()); // 'DEBUG'

// Silence everything except warnings/errors
logger.setLevel('WARN');
```

> **Note:** Calling `setLevel` with an unrecognized string logs a warning and leaves the current level unchanged. Numeric values `0`–`3` are also accepted directly via `LOG_LEVELS`.
