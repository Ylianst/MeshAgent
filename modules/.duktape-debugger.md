A Node.js module that implements a Duktape JavaScript debugger interface, providing a TCP-based debug protocol client with an embedded web UI for inspecting and controlling JavaScript execution in Duktape-based runtimes.

## Key Components

- **`DuktapeDebugger` class** — Core debugger class extending `EventEmitter` that manages the TCP connection to a Duktape debug target, handles the binary debug protocol, and serves the embedded web debugger UI
- **`dbgHTML`** — Base64-encoded HTML/CSS/JS string containing the self-contained web debugger front-end UI (rendered at `/` via the HTTP server)
- **Debug protocol commands** — Methods for controlling execution: `pauseResume()`, `stepOver()`, `stepInto()`, `stepOut()`, `attachDebugger()`
- **Breakpoint management** — Functions for setting, clearing, and listing breakpoints against source files and line numbers
- **Variable inspection** — Support for querying local variables, the call stack, and evaluating expressions in the current debug context
- **Event emissions** — Emits events such as `status`, `print`, `alert`, `log`, and `detached` for integrating with host applications

## Usage Example

```javascript
var DuktapeDebugger = require('./duktape-debugger');

// Create a debugger instance connected to a Duktape runtime
var dbg = new DuktapeDebugger({
    host: '127.0.0.1',
    port: 9091,       // Duktape debug port
    httpPort: 9090    // Web UI port
});

dbg.on('status', function (status) {
    console.log('Debugger status:', status);
});

dbg.on('detached', function () {
    console.log('Debugger detached from target');
});

// Open a browser to http://localhost:9090 to access the web UI
```
