`lme_heci.js` implements the Local Manageability Engine (LME) HECI (Host Embedded Controller Interface) communication layer for Intel AMT (Active Management Technology). It manages APF (Agent Presence Framework) protocol message handling over a HECI connection, enabling port-forwarding and TCP proxying between local network sockets and the Intel ME firmware.

## Key Components

- **`lme_object`** — Channel state tracker storing AMT channel IDs, tx/rx window sizes, local port, and connection status (`LME_CS_FREE`, `LME_CS_CONNECTED`).
- **`stream_bufferedWrite`** — A custom duplex-style buffered stream with `read()`/`write()` methods and `readable`/`drain` events, used to pace data writes according to the AMT tx window size.
- **`lme_heci`** — Main class that wraps the `heci` module, emits `connect`/`error` events, and dispatches APF protocol messages.

**APF Message Handlers inside `lme_heci`:**

| Constant | Value | Description |
|---|---|---|
| `APF_SERVICE_REQUEST` | 5 | Accepts `pfwd@amt.intel.com` / `auth@amt.intel.com` services |
| `APF_GLOBAL_REQUEST` | 80 | Sets up `tcpip-forward` TCP listeners on requested ports |
| `APF_CHANNEL_OPEN_CONFIRMATION` | 91 | Completes channel setup, wires socket ↔ buffered stream |
| `APF_CHANNEL_WINDOW_ADJUST` | 93 | Updates tx window, resumes buffered writes |
| `APF_CHANNEL_DATA` | 94 | Forwards data to local TCP socket, sends window adjust ACK |
| `APF_CHANNEL_CLOSE` | 97 | Closes the associated local socket |
| `APF_PROTOCOLVERSION` | 192 | Echoes back version negotiation response |

## Usage Example

```javascript
var lme_heci = require('./lme_heci');

var lms = new lme_heci();

lms.on('error', function(e) {
    console.error('LME error:', e);
});

lms.on('connect', function() {
    console.log('Connected to Intel ME via HECI');
    // AMT will now forward tcpip-forward requests;
    // TCP servers are created automatically per APF_GLOBAL_REQUEST
});

lms.connect(); // initiates HECI connection
```

## Notes

- Requires the native `heci` module (Intel ME driver binding) and the `net` built-in.
- Flow control is implemented via `txWindow` — the buffered stream pauses the source socket when the window is exhausted and resumes on `APF_CHANNEL_WINDOW_ADJUST`.
