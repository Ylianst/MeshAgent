Dispatches code execution to a Windows child process via dual IPC channels, enabling cross-user method invocation using the Windows Task Scheduler.

## Key Components

- **`dispatch(options)`** — Main entry point. Spawns a child process under a specified Windows user account (via `win-tasks` COM API or SCHTASKS/PowerShell fallback), establishes two named pipe IPC channels, and sends modules/launch instructions to the child.
- **`connect(ipc)`** — Called by the child process to connect back to the parent's named pipes, receive module definitions, and execute the dispatched function.
- **`ipc_connection(s)`** — Handles the primary IPC connection; sends `addModule` and `launch` commands to the child.
- **`ipc2_connection(s)`** — Handles the secondary (control) IPC connection; exposes `invoke` for calling methods on the child's proxy stream.
- **`ipc_invoke(method, args)`** — Sends an `invoke` command over the control channel to call a method on the child's active stream object.
- **`dispatcher_shutdown()`** — Closes both IPC server channels.
- **`empty_func` / `empty_func2`** — Cleanup callbacks that null out back-references to prevent memory leaks from strong GC references.

## Usage Example

```javascript
// Parent process: dispatch a module method to run as a different user
var dispatcher = require('win-dispatcher');

var handle = dispatcher.dispatch({
  user: 'DOMAIN\\targetuser',
  modules: [
    { name: 'my-module', script: myModuleSource }
  ],
  launch: {
    module: 'my-module',
    method: 'run',
    args: ['arg1', 'arg2'],
    split: false
  }
});

handle.on('connection', function(stream) {
  // Primary IPC stream to child is ready
  handle.invoke('pause', []);
});

// To shut down the child dispatcher:
handle.close();
```

> **Note:** This module is Windows-only and relies on named pipes (`\\.\pipe\taskRedirection-*`), `win-tasks`, `win-console`, and `user-sessions` — all part of the MeshAgent runtime environment. See the full source at [`modules/win-dispatcher.js`](https://github.com/flamingo-stack/meshagent/blob/main/modules/win-dispatcher.js).
