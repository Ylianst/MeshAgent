Diagnostic/test script that monitors X11 cursor change events on Linux using the XFixes extension, logging cursor metadata (serial, dimensions, CRC, name) to the console.

## Key Components

- **XFixes Extension Setup** — Loads `monitor-info` native bindings and creates proxy methods for `XFixesSelectCursorInput`, `XFixesGetCursorImage`, `XFixesGetCursorName`, and `XFixesQueryExtension`
- **Display Initialization** — Opens the X11 display, enumerates screens, and creates a root/fake window; auto-resolves `XAUTHORITY`/`DISPLAY` env vars via `user-sessions` if not set
- **Cursor Event Listener** — Subscribes to `XFixesCursorNotify` events via `DescriptorEvents`, polling `XPending` to drain the X11 event queue
- **Cursor Image Extraction** — Reads raw ARGB pixel data from `XFixesGetCursorImage`, handles both 32-bit and 64-bit pointer sizes, computes a CRC32c checksum, and resolves the cursor atom name

## Usage Example

```bash
# Run as a standalone diagnostic tool (not intended as a library import)
meshagent linux-cursors.js
```

```javascript
// Ensure X11 environment is available before execution
process.env.DISPLAY = ':0';
process.env.XAUTHORITY = '/home/user/.Xauthority';

// Script auto-detects and subscribes to cursor changes,
// printing output similar to:
// cursor_serial: 42
// 32 32 CRC: 1a2b3c4d
// NAME => left_ptr
```

## Notes

- Requires the **XFixes** X11 extension to be present on the host; throws if unavailable
- Pointer-size branching (`GM.PointerSize == 8`) handles both x86 and x86-64 architectures
- Intended as a **debugging/diagnostic utility** — not a reusable module (no exports)
- Source: [`linux-cursors.js`](https://github.com/flamingo-stack/meshagent/blob/main/linux-cursors.js)
