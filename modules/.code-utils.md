Utility module for compressing, embedding, and extracting JavaScript modules to/from native C source files (specifically `ILibDuktape_Polyfills.c`), enabling on-the-fly deflate/inflate of JS modules compiled into a MeshAgent binary.

## Key Components

### Array Prototype Polyfills
- **`getParameterEx(name, defaultValue)`** — Finds a CLI argument by exact prefix, stripping surrounding quotes
- **`getParameter(name, defaultValue)`** — Wraps `getParameterEx` with `--` prefix convention
- **`getParameterIndex(name)`** — Returns the index of a `--name=value` argument
- **`deleteParameter(name)`** — Removes a `--name=value` argument in place
- **`getParameterValue(i)`** — Extracts the value portion of a `--key=value` argument at index `i`

### Core Functions
- **`expand(options)`** — Reads a C file, parses the `AUTO-GENERATED BODY` block, and decompresses embedded base64 JS modules to disk
- **`expand2(options)`** — Exports modules directly from a live agent binary via `getModules()` / `getJSModule()`
- **`writeExpandedModules(options)`** — Writes extracted module objects as `.js` files to `expandedPath`
- **`readExpandedModules(options)`** — Reads `.js` files from `expandedPath`, compresses them, and formats them as C `duk_peval_string_noresult` statements
- **`shrink(options)`** — Orchestrates the full compress-and-embed pipeline (reads expanded modules → inserts back into C file)
- **`insertCompressed(options)`** — Rewrites the `AUTO-GENERATED BODY` section of the target C file with freshly compressed modules

## Usage Example

```javascript
// Extract embedded modules from the default C file to disk
expand({ filePath: 'microscript/ILibDuktape_Polyfills.c', expandedPath: 'modules_expanded' });

// Edit JS files in modules_expanded/, then re-embed them
shrink({ expandedPath: 'modules_expanded', filePath: 'microscript/ILibDuktape_Polyfills.c' });

// Or via CLI arguments
// node code-utils.js --filePath=path/to/file.c --expandedPath=output_dir
```
