Provides a Node.js interface for communicating with Intel AMT (Active Management Technology) firmware via the HECI (Host Embedded Controller Interface) protocol, enabling low-level AMT provisioning and device information queries.

## Key Components

| Export/Method | Description |
|---|---|
| `amt_heci` | Constructor — creates an event-emitting HECI connection to the AMT firmware GUID |
| `sendCommand(cmd, data, callback, ...args)` | Core method that queues and dispatches raw AMT HECI commands with a 12-byte header |
| `getCommand(chunk)` | Parses a raw response buffer into a structured `{IsResponse, Command, Status, Data}` header |
| `getVersion(cb)` | Retrieves AMT BIOS and component version strings |
| `getUuid(cb)` | Returns the AMT device UUID formatted as a standard hyphenated string |
| `getProvisioningState(cb)` | Returns provisioning state (`PRE`, `IN`, `POST`) |
| `getProvisioningMode(cb)` | Returns provisioning mode (`NONE`, `ENTERPRISE`, `SMALL_BUSINESS`, `REMOTE_ASSISTANCE`) |
| `getControlMode(cb)` | Returns control mode (`NONE_RPAT`, `CLIENT`, `ADMIN`) |
| `getMACAddresses(cb)` | Returns dedicated and host MAC addresses |
| `getDnsSuffix(cb)` | Returns the AMT DNS suffix string |
| `getCertHashEntries(cb)` | Retrieves all trusted certificate hash entries from AMT |
| `getLocalSystemAccount(cb)` | Retrieves the AMT local system account credentials |
| `unprovision(mode, cb)` | Deactivates AMT provisioning for the given mode |

## Usage Example

```javascript
var amt_heci = require('./amt_heci');

var amt = new amt_heci();

amt.on('error', function(err) {
    console.error('HECI error:', err);
});

amt.on('connect', function() {
    // Query AMT UUID
    amt.getUuid(function(result) {
        if (result) {
            console.log('AMT UUID:', result.uuid);
        }
    });

    // Query provisioning state
    amt.getProvisioningState(function(result) {
        if (result) {
            console.log('State:', result.stateStr); // "PRE", "IN", or "POST"
        }
    });

    // Retrieve all trusted certificate hashes
    amt.getCertHashEntries(function(entries) {
        entries.forEach(function(e) {
            console.log(e.name, e.hashAlgorithmStr, e.certificateHash);
        });
    });
});
```

> **Note:** Requires a Linux/Windows system with Intel AMT hardware and the native `heci` module available. Commands are queued internally — responses are matched to requests in FIFO order via the `queue` module.
