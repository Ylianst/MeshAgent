A lightweight DHCP client module that sends broadcast DISCOVER packets and parses OFFER responses to retrieve network configuration data (IP address, subnet mask, gateway, DNS, etc.) for a device.

## Key Components

- **`dhcp` module** — Main export; builds and transmits DHCPv4 DISCOVER packets over UDP broadcast and parses the returned OFFER.
- **`getDHCPInfo()`** — Primary async function that initiates a DHCP discovery, resolves with a structured object containing network configuration fields.
- **`parseDHCPResponse(buf)`** — Parses raw DHCP OFFER packet bytes into a human-readable options object (option 1 = subnet mask, option 3 = router, option 6 = DNS, etc.).
- **`buildDHCPDiscover(mac)`** — Constructs a standards-compliant DHCPDISCOVER packet buffer from the device MAC address.
- **Embedded `promise2` module** — A bundled polyfill providing Promise semantics (`then`, `catch`, `finally`) for environments without native Promise support.

## Usage Example

```javascript
var dhcp = require('dhcp');

// Fetch DHCP configuration for the current interface
dhcp.getDHCPInfo().then(function(info) {
    console.log('Assigned IP:  ', info.assignedIP);
    console.log('Subnet Mask:  ', info.subnetMask);
    console.log('Gateway:      ', info.router);
    console.log('DNS Servers:  ', info.dns);
}).catch(function(err) {
    console.error('DHCP discovery failed:', err);
});
```

> **Note:** This module is designed for embedded/agent environments (e.g., MeshAgent) and relies on raw UDP socket access. It is not intended for use in standard Node.js browser-side contexts.
