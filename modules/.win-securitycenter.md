Queries the Windows Security Center (WSC) via native `Wscapi.dll` APIs to retrieve and monitor the health status of Firewall, AntiVirus, and Auto Update. Not supported on Windows Server SKUs where WSC is absent.

## Key Components

| Export / Symbol | Description |
|---|---|
| `module.exports` (EventEmitter `j`) | Main export; emits `changed` when security status changes |
| `getStatus()` | Returns current health of `firewall`, `antiVirus`, and `autoUpdate` as status strings |
| `statusString(val)` | Maps WSC health codes to `'OK'`, `'WARNING'`, `'PROBLEM'`, or `'UNKNOWN'` |
| `WscGetSecurityProviderHealth` | Native API call to retrieve provider health |
| `WscRegisterForChanges` | Registers a native callback for WSC change events |
| `WscUnRegisterChanges` | Unregisters the change callback on object teardown (`~` event) |

**Health status constants:**

| Constant | Value | Meaning |
|---|---|---|
| `WSC_SECURITY_PROVIDER_HEALTH_GOOD` | `0` | `'OK'` |
| `WSC_SECURITY_PROVIDER_HEALTH_NOTMONITORED` | `1` | `'WARNING'` |
| `WSC_SECURITY_PROVIDER_HEALTH_POOR` | `2` | `'PROBLEM'` |
| `WSC_SECURITY_PROVIDER_HEALTH_SNOOZE` | `3` | `'WARNING'` |

## Usage Example

```javascript
// Only works on Windows non-Server editions
const secCenter = require('./win-securitycenter');

// Poll current status
const status = secCenter.status();
console.log(status.firewall);    // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'
console.log(status.antiVirus);   // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'
console.log(status.autoUpdate);  // 'OK' | 'WARNING' | 'PROBLEM' | 'UNKNOWN'

// Listen for real-time security status changes
secCenter.on('changed', () => {
    const updated = secCenter.status();
    console.log('Security status changed:', updated);
});
```

> **Platform note:** Throws `'win-securitycenter not supported on this platform'` on non-Windows systems or if `Wscapi.dll` fails to load (e.g., Windows Server SKUs).
