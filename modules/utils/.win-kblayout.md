A code generation utility that reads a Windows keyboard layout lookup table and generates switch-case code in both JavaScript and C for mapping keyboard layout codes to language names.

## Key Components

- **`win-kblayout_table.txt`** – External data file containing hex keyboard layout codes paired with language/locale names (one per line)
- **JavaScript `toLang(val)` generator** – Builds a JS switch-case function mapping numeric layout IDs (decoded from hex via `Buffer.readUInt32BE()`) to language name strings
- **C `switch` generator** – Builds a C switch-case block using `int64_t` comparisons for short names (<8 chars) and a nested switch for longer names (≥8 chars), leveraging `bignum` for little-endian integer encoding
- **`clipboard` module** – Writes the generated code string directly to the system clipboard

## Usage Example

```bash
# Run directly from the project directory (path-sensitive)
node win-kblayout.js
# Outputs: "Value saved to clipboard..."
# Generated code is copied to clipboard for pasting into source files
```

```javascript
// Sample output generated for the JS block:
function toLang(val)
{
   var ret;
   switch(val)
   {
      case '1033':       // Numeric form of hex layout code
         ret = 'English';
         break
      // ...
      default:
         ret = null;
      break
   }
   return(ret);
}
```

> **Note:** The C code generation block is unreachable at runtime — `process.exit()` is called after the JavaScript block is copied to clipboard. The C generator exists as dead code, likely a development artifact for generating a companion C lookup function.
