Provides a Node.js interface for monitoring and querying Linux D-Bus signals by spawning `dbus-monitor` as a child process and parsing its output into structured JavaScript objects.

## Key Components

- **`dbus(address, uid, env)`** — Constructor that spawns a `dbus-monitor` shell process to listen for D-Bus signals on either the session bus (when `uid` is provided) or the system bus. Emits a `signal` event with parsed signal data.
- **`dbus.hasService(name)`** — Static synchronous method that checks whether a named D-Bus service exists by scanning `/usr/share/dbus-1/services/*.service`.
- **`dbus.getServices([grep], [options])`** — Static synchronous method that lists active D-Bus session bus service names via `dbus-send`, with optional string filtering and child process options.

## Usage Example

```javascript
const dbus = require('./linux-dbus');

// Monitor a D-Bus session signal for a specific interface
const monitor = new dbus('org.freedesktop.NetworkManager', 1000, null);
monitor.on('signal', function (sig) {
    console.log('Received D-Bus signal:', sig);
    // sig.value, sig.data, sig.interface, etc.
});

// Check if a service exists (synchronous)
const exists = dbus.hasService('org.freedesktop.NetworkManager');
console.log('Service exists:', exists);

// List all active session bus services (synchronous)
const services = dbus.getServices('freedesktop');
console.log('Matching services:', services);
```

> **Note:** `hasService` and `getServices` use synchronous `waitExit()` and must run in an environment where that method is available (MeshAgent's custom Node.js runtime). Signal parsing supports `string`, `boolean`, `array`, and `dict entry` D-Bus value types.
