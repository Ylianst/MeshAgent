Renders a native Windows desktop notification bar using Win32 API calls via `_GenericMarshal`. Provides floating, draggable notification windows with bitmap rendering through GDI+ for use in Windows agent UI overlays.

## Key Components

- **Win32 Constants** — Extensive set of window messages (`WM_*`), styles (`WS_*`, `BS_*`, `SS_*`), and control constants for native window creation and event handling
- **GDI+ Integration** (`gdip`) — Wraps `Gdiplus.dll` methods for image loading, bitmap creation, scaling (`GdipCreateBitmapFromStream`, `GdipCreateHBITMAPFromBitmap`, `GdipSetSmoothingMode`), and resource cleanup
- **Shlwapi Bridge** (`SHM`) — Uses `SHCreateMemStream` from `Shlwapi.dll` to convert in-memory image buffers (Base64-encoded icons) into GDI-compatible streams
- **Embedded Icons** — Base64-encoded PNG assets (`x_icon`, `pin_icon_1`) for close and pin buttons, decoded at runtime into native bitmaps
- **Native Proxy Factory** (`GM`) — `_GenericMarshal` creates type-safe native DLL proxies with pointer-size awareness (`ptrsize`) for 32/64-bit compatibility

## Usage Example

```javascript
// Module is loaded internally by the MeshAgent on Windows platforms
// Platform guard prevents loading on non-Windows systems
if (process.platform === 'win32') {
    const notifyBar = require('./notifybar-desktop');
    // notifyBar exposes a window constructor used by the agent tray/UI layer
    // to display session notifications to the logged-in desktop user
}
```

> **Platform:** Windows only (`process.platform === 'win32'`). On other platforms the GDI+ and Shlwapi proxy initialization is skipped entirely.
