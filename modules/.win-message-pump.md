Windows message pump abstraction for Node.js on Windows, providing an event-driven interface for creating and managing native Win32 windows via P/Invoke bindings through `_GenericMarshal`.

## Key Components

**`WindowsMessagePump(options)`** — Main constructor that:
- Sets up Win32 API bindings (`Kernel32.dll`, `User32.dll`, `Gdi32.dll`) via `_GenericMarshal`
- Registers a window class and creates a native window with configurable styles, position, and dimensions
- Installs a `WndProc` callback to route Win32 messages as Node.js events

**Events**
| Event | Description |
|-------|-------------|
| `hwnd` | Fired when the native window is successfully created, passes the window handle |
| `message` | Fired for each Win32 message (`WM_*`), with `message`, `wparam`, `lparam`, `hwnd`, and `dispatcher` |
| `error` | Fired if window creation fails |
| `exit` | Fired when the message pump stops (WM_QUIT) |

**Internal Methods**
- `_startPump()` — Drives the `GetMessage` / `TranslateMessage` / `DispatchMessage` loop asynchronously
- `_addCreateWindowEx(...)` — Queues additional child window creation before the pump starts
- `_startPump_continuation()` — Resolves pending window-creation promises and resumes the pump

## Usage Example

```javascript
const WindowsMessagePump = require('./win-message-pump');

const pump = new WindowsMessagePump({
    window: {
        title: 'My Window',
        x: 100, y: 100,
        width: 800, height: 600,
        winstyles: 0x00CF0000,   // WS_OVERLAPPEDWINDOW
        exstyles: 0x00000088     // WS_EX_TOOLWINDOW | WS_EX_TOPMOST
    }
});

pump.on('hwnd', (hwnd) => {
    console.log('Window created, handle:', hwnd.Val);
});

pump.on('message', (msg) => {
    if (msg.message === 0x0010) { // WM_CLOSE
        // Return a value to suppress DefWindowProc
        msg.dispatcher.EndDispatcher(null);
    }
});

pump.on('exit', () => {
    console.log('Message pump stopped');
});
```

> **Platform:** Windows only. Requires the `_GenericMarshal` native addon available in the [MeshAgent](https://github.com/flamingo-stack/meshagent) runtime.
