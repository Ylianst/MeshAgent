Cross-platform system service manager that handles installation, removal, starting, stopping, and status querying of OS-level services across Windows, Linux (systemd/upstart), and macOS (launchd).

## Key Components

### Helper Functions

- **`failureActionToInteger(action)`** — Converts failure action strings (`'NONE'`, `'SERVICE_RESTART'`, `'REBOOT'`) to integer codes
- **`extractFileName(filePath)`** — Extracts a filename from a path string or file descriptor object
- **`extractFileSource(filePath)`** — Returns the source path from a string or file descriptor object
- **`prepareFolders(folderPath)`** — Recursively creates directories if they don't exist
- **`parseServiceStatus(token)`** — Parses a Windows `SERVICE_STATUS` binary token into a structured JS object

### OpenFrame Parameter Handling

- **`formatOpenFrameParams(parameters, stripQuotes)`** — Normalizes and orders OpenFrame CLI flags (`--openframe-mode`, `--openframe-token-path`, `--openframe-secret`) from `--key=value` format into separate tokens
- **`applyOpenFrameParams(options, reg)`** — Applies OpenFrame parameters to the Windows registry `ImagePath` entry
- **`applyOpenFrameParamsDarwin(parameters)`** — macOS-specific variant that strips quotes for plist compatibility

### Platform-Specific Service Table Queries (Linux)

- **`_upstart_GetServiceTable()`** — Queries running Upstart services via `initctl list`, returns a JSON map of service names to state/PID
- **`_systemd_GetServiceTable()`** — Queries running systemd services via `systemctl`, returns a JSON map of service names to state

## Usage Example

```javascript
// Normalize OpenFrame CLI parameters before applying to a service
const params = ['--openframe-mode', '--openframe-token-path="/opt/token"', '--extra-flag', 'value'];
const formatted = formatOpenFrameParams(params, false);
// Result: ['--openframe-mode', '--openframe-token-path', '/opt/token', '--extra-flag', 'value']

// Prepare installation directory
prepareFolders('/opt/meshagent/services/myservice');

// Parse a Windows service status binary
const status = parseServiceStatus(token);
console.log(status.state); // e.g. 'RUNNING'
console.log(status.pid);   // e.g. 1234
```
