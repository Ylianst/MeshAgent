Utility module for parsing and enumerating Mesh Agent log file entries, handling both standard log lines and platform-specific crash entries (Windows and Linux).

## Key Components

- **`parseLine(entry)`** — Internal function that parses a single log line using regex patterns. Handles standard timestamped entries, Windows crash entries (file/line/function), Linux crash stacks (hex addresses, symbol info, crash IDs), and extracts agent hash, timestamp, message, file, and line number.
- **`readLog_data(buffer)`** — Stream data handler that accumulates buffered input and processes each line by calling `parseLine`.
- **`readLogEx(path)`** — Reads a log file at the given path via a Node.js read stream and returns an array of all parsed log entry objects.
- **`readLog(criteria, path)`** — High-level entry point that reads the log and filters results. Accepts a count (< 1000 returns last N entries), a timestamp (returns entries newer than that time), or no criteria (returns all entries).

**Exports:** `{ read: readLog, readEx: readLogEx }`

## Usage Example

```javascript
const agentLog = require('./util-agentlog');

// Read the last 50 log entries from the default log path
const recent = agentLog.read(50);

// Read all entries newer than a given timestamp
const sinceDate = agentLog.read('2024-01-15T10:00:00');

// Read all entries from a specific log file
const all = agentLog.readEx('/var/log/meshagent.log');

// Each entry has the shape:
// { t: <unix timestamp>, m: <message>, h?: <agent hash>, f?: <file>, l?: <line>, s?: [...], sx?: [...] }
console.log(recent);
```

## Log Entry Object Shape

| Field | Description |
|---|---|
| `t` | Unix timestamp (seconds) |
| `m` | Log message text |
| `h` | Agent hash (16-char hex, if present) |
| `f` | Source file name (crash entries) |
| `l` | Source line number (crash entries) |
| `fn` | Function name (Windows crash) |
| `s` | Linux crash stack (file:line array) |
| `sx` | Linux crash stack hex addresses |
