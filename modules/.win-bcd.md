Provides a Node.js interface to Windows Boot Configuration Data (BCD) via `bcdedit.exe`, enabling Safe Mode service management and boot mode configuration for Windows-based agents.

## Key Components

| Export | Description |
|---|---|
| `getKeys()` | Fetches all current bootloader key/value pairs by parsing `bcdedit /enum {current}` output |
| `getKey(key)` | Returns a single BCD value by key name |
| `setKey(key, value)` | Sets a BCD key/value pair on the current boot entry |
| `deleteKey(key)` | Removes a BCD key from the current boot entry |
| `enableSafeModeService(serviceName)` | Registers a service to run in Safe Mode with Networking via the Windows registry |
| `disableSafeModeService(serviceName)` | Removes a service from the Safe Mode allowed list |
| `isSafeModeService(serviceName)` | Returns `true` if the named service is registered for Safe Mode |
| `restart(delay)` | Triggers an immediate (or delayed) system restart via `shutdown.exe` |
| `bootMode` *(property)* | Read-only property returning `'NORMAL'`, `'SAFE_MODE'`, or `'SAFE_MODE_NETWORK'` |

> **Note:** When running as a 32-bit process on 64-bit Windows, BCD read/write functions (`getKeys`, `getKey`, `setKey`, `deleteKey`, `bootMode`) are **not exported**, as `bcdedit.exe` does not function correctly in that context. Safe Mode registry functions and `restart` remain available.

## Usage Example

```javascript
var bcd = require('./win-bcd');

// Check current boot mode
console.log(bcd.bootMode); // 'NORMAL' | 'SAFE_MODE' | 'SAFE_MODE_NETWORK'

// Allow a service to run in Safe Mode with Networking
bcd.enableSafeModeService('MeshAgent');

// Verify registration
if (bcd.isSafeModeService('MeshAgent')) {
    console.log('MeshAgent is registered for Safe Mode');
}

// Configure next boot for Safe Mode with Networking
bcd.setKey('safeboot', 'Network');

// Restart the machine after 30 seconds
bcd.restart(30);

// Remove Safe Mode service registration
bcd.disableSafeModeService('MeshAgent');

// Delete a BCD key
bcd.deleteKey('safeboot');
```
