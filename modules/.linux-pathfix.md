Checks whether `/sbin` is present in the Linux `PATH` environment variable, and appends it if missing.

## Key Components

- **`checkPath()`** — Main exported function. Spawns a shell process to inspect the current `$PATH` using `awk`, then conditionally appends `:/sbin` via `process.setenv()` if `/sbin` is not found.

## Usage Example

```javascript
const checkPath = require('./linux-pathfix');

// Call early in application startup to ensure /sbin is available
checkPath();
```

## Notes

- Only executes on `process.platform === 'linux'`; no-op on other platforms.
- Uses a synchronous `child.waitExit()` pattern, blocking until the shell subprocess completes.
- Designed to be called once at startup before any commands that rely on tools located in `/sbin` (e.g., `ifconfig`, `ip`, `iptables`).
