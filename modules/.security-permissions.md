Centralizes file and folder permission management for security-critical MeshAgent files, providing functions to set, verify, and remediate permissions across platforms (POSIX/macOS/Linux).

## Key Components

### Permission Policy (`SECURE_FILE_PERMISSIONS`)
A configuration map defining octal mode, owner, and group for each file type:

| Key | Mode | Description |
|---|---|---|
| `.msh` | `0o600` | Server config & credentials (critical) |
| `.db` | `0o600` | Agent identity & certificates (critical) |
| `binary` | `0o755` | Main agent executable (critical) |
| `bundle` | `0o755` | macOS `.app` bundle (critical) |
| `.log` | `0o644` | Agent log file |
| `installDir` | `0o755` | Installation directory |
| `plist` | `0o644` | macOS LaunchDaemon plist |
| `initScript` | `0o755` | Linux SysV init script |
| `systemdService` | `0o644` | systemd unit file |

### Functions

- **`getEffectiveUid()`** — Returns the current effective UID via `process.getuid()` or falls back to the `user-sessions` module for Duktape environments.
- **`setSecurePermissions(filePath, fileType, options)`** — Applies `chmod` and `chown` to a file according to its policy. Supports `dryRun` and `skipChown` options.
- **`verifyPermissions(filePath, fileType)`** — Checks a file's current permissions against policy without modifying it. Returns a result object with `valid`, `issues`, and `stats`.

## Usage Example

```javascript
var secPerms = require('./security-permissions');

// Apply secure permissions to a credential file
var result = secPerms.setSecurePermissions('/opt/meshagent/meshagent.msh', '.msh');
if (result.success) {
    console.log('Actions taken:', result.actions.join(', '));
} else {
    console.error('Errors:', result.errors.join(', '));
}

// Dry-run to preview what would change
var preview = secPerms.setSecurePermissions('/opt/meshagent/meshagent', 'binary', { dryRun: true });
console.log('Would execute:', preview.actions);

// Verify without modifying
var check = secPerms.verifyPermissions('/opt/meshagent/meshagent.db', '.db');
if (!check.valid) {
    console.warn('Permission issues:', check.issues);
}
```
