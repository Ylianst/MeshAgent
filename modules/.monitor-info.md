Cross-platform monitor information retrieval module that detects connected displays and their properties (resolution, position, DPI) on Windows, Linux, and FreeBSD systems.

## Key Components

- **`getLibInfo(libname)`** — Internal helper that locates shared library paths using `ldconfig` or filesystem scanning on Linux/FreeBSD.
- **`monitorinfo()`** — Main constructor that initializes platform-specific native bindings and exposes monitor detection logic.
  - **Windows**: Uses `user32.dll` (`EnumDisplayMonitors`) and optionally `SHCore.dll` (`GetDpiForMonitor`) for DPI-aware monitor enumeration.
  - **Linux**: Resolves paths for X11 libraries (`libX11`, `libXtst`, `libXext`, `libXfixes`, `libxkbfile`) via `_check()`.
  - **FreeBSD**: Uses `lib-finder` module to locate the same X11 libraries.
- **`getInfo()`** *(Windows)* — Returns a `Promise` resolving to an array of monitor objects with `left`, `top`, `right`, `bottom`, and `dpi` properties.
- **`MOTIF_FLAGS`** — Constants for window manager hint flags (move, resize, minimize, etc.).

## Usage Example

```javascript
var monitorInfo = require('monitor-info');

// Windows: get display geometry and DPI for all monitors
monitorInfo.getInfo().then(function(monitors) {
    monitors.forEach(function(m, i) {
        console.log('Monitor ' + i + ':', m.left, m.top, m.right, m.bottom, '@', m.dpi, 'dpi');
    });
});

// Linux/FreeBSD: resolve X11 library locations before use
monitorInfo._check();
console.log('libX11 path:', monitorInfo.Location_X11LIB);
```

## Notes

- Library paths can be overridden via environment variables (e.g., `Location_X11LIB`, `Location_X11TST`) on Linux.
