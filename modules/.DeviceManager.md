Windows Device Manager interface for enumerating and querying hardware devices via the Windows Setup API (`SetupAPI.dll`) and Configuration Manager (`CfgMgr32.dll`). Windows-only; throws on non-Windows platforms.

## Key Components

- **`DeviceManager()`** — Constructor that initializes native proxies to `Kernel32.dll`, `SetupAPI.dll`, and `CfgMgr32.dll` via `_GenericMarshal`. Sets up DEVPKEY property keys for device node status and problem codes.
- **`getDevices(options)`** — Enumerates all present system devices, collecting per-device properties including hardware ID, friendly name, manufacturer, device class, description, and location paths.
- **`CM_PROB_CODE`** — Lookup table mapping Windows Configuration Manager problem codes (e.g., `0x00000016` → `'DISABLED'`) to human-readable strings.
- **`SPDRP_*` constants** — Windows Setup API device registry property identifiers used as arguments to `SetupDiGetDeviceRegistryPropertyA`.

## Usage Example

```javascript
// Windows only — will throw on Linux/macOS
var DeviceManager = require('./DeviceManager');

var dm = new DeviceManager();
var devices = dm.getDevices();

devices.forEach(function(device) {
    console.log('HW ID:       ', device.hwid);
    console.log('Name:        ', device.friendlyName);
    console.log('Manufacturer:', device.manufacturer);
    console.log('Class:       ', device.class);
    console.log('Description: ', device.description);
});

// Each device entry shape:
// {
//   hwid:         'PCI\\VEN_8086&DEV_...',
//   friendlyName: 'Intel(R) Network Adapter',
//   manufacturer: 'Intel',
//   class:        'Net',
//   description:  'Ethernet Controller',
//   locationPaths: '...'  // if available
// }
```

> **Platform requirement:** This module is strictly Windows-only. Instantiation on any other OS throws `'Only Supported on Windows'`.
