Cross-platform utility for retrieving, managing, and resetting the MeshAgent node identity by reading certificate hashes or node IDs from the agent's local database and Windows registry.

## Key Components

| Export | Description |
|---|---|
| `module.exports` (`_meshNodeId`) | Returns the agent's unique node ID as a hex string, derived from the `SelfNodeCert` PFX hash or fallback `NodeID` stored in the agent's `.db` file |
| `module.exports.serviceName` (`_meshName`) | Resolves the agent's service name by checking `_MSH().meshServiceName`, the Windows registry, or the system service manager |
| `module.exports.resetNodeId` (`_resetNodeId`) | Writes a `ResetNodeId=1` flag to the Windows registry under `Software\Open Source\<serviceName>` |
| `module.exports.checkResetNodeId` (`_checkResetNodeId`) | Checks for and atomically clears the `ResetNodeId` registry flag; returns `true` if a reset was requested |

## Platform Behavior

- **Windows**: Locates the `.db` file next to the `.exe`, reads the cert hash or `NodeID` buffer; uses `win-registry` for service name lookup and node ID reset.
- **Linux**: Uses the executable path with `.db` appended.
- **macOS (bundled)**: Detects `.app/Contents/MacOS/` in the exec path and resolves the `.db` file from the current working directory.

## Usage Example

```javascript
const meshNodeId = require('./_agentNodeId');

// Get current node ID
const nodeId = meshNodeId();
console.log('Node ID:', nodeId); // e.g. "a3f9c1..."

// Get the agent service name
const name = meshNodeId.serviceName();
console.log('Service name:', name); // e.g. "meshagent"

// Check and consume a pending node ID reset (Windows only)
if (meshNodeId.checkResetNodeId(name)) {
    console.log('Node ID reset was requested, proceeding with reset...');
}

// Schedule a node ID reset on next agent start (Windows only)
meshNodeId.resetNodeId();
```

> **Note:** `resetNodeId` and `checkResetNodeId` are Windows-only operations and rely on the `win-registry` native module. On Linux/macOS, only `meshNodeId()` and `serviceName()` are applicable.
