Collects and normalizes hardware identifier information from Linux systems, including BIOS/board metadata, CPU, GPU, storage, memory, and USB devices.

## Key Components

- **`trimIdentifiers(val)`** — Removes falsy, `'None'`, or empty-string fields from an identifier object.
- **`trimResults(val)`** — Strips private fields (prefixed with `_`) and null/zero values from an array of result objects.
- **`brief(headers, obj)`** — Filters an array of objects to only include specified header keys.
- **`dataHandler(c)`** — Stream data collector appending child process stdout/stderr chunks to a string buffer.
- **`linux_identifiers()`** — Main entry point that gathers system hardware info on Linux via:
  - `/sys/class/dmi/id` (DMI/SMBIOS fields: BIOS, board, product)
  - `/sys/firmware/devicetree` (Raspberry Pi fallback)
  - `dmidecode` (memory slot details)
  - `lspci` (GPU info)
  - `lshw` (storage devices)
  - `df` (mounted volumes)
  - `usb-devices` (USB device enumeration)
  - `/proc/cpuinfo` / `lscpu` (CPU model name)

## Usage Example

```javascript
const identifiers = require('./identifiers');

// Collect Linux hardware identifiers
const info = identifiers.linux_identifiers();

console.log(info.identifiers);
// {
//   board_vendor: 'Dell Inc.',
//   board_name: 'OptiPlex 7080',
//   bios_version: '1.5.0',
//   cpu_name: 'Intel(R) Core(TM) i7-10700',
//   gpu_name: ['NVIDIA GeForce RTX 3060'],
//   ...
// }

console.log(info.linux.memory);
// { 'Memory Device': [ { Locator: 'DIMM A1', Size: '16 GB', ... } ] }

console.log(info.linux.volumes);
// [ { size: '100G', used: '40G', mount_point: '/', type: 'ext4' }, ... ]
```

> **Note:** `linux_identifiers()` requires Linux with access to `/sys`, and optionally `dmidecode`, `lshw`, `lspci`, and `usb-devices` binaries. Execution uses synchronous child processes (`waitExit`), typical of the MeshAgent runtime environment.
