Provides helper utilities for Windows-specific platform operations, currently exposing taskbar management functionality via Windows Registry manipulation.

## Key Components

### `winutils` (class, exported as singleton)

- **`taskBar.autoHide(tsid, value)`** — Gets or sets the Windows taskbar auto-hide setting for a specific user session.
  - `tsid` — Session ID used to resolve the domain and username.
  - `value` — `true` to enable auto-hide, `false` to disable, `null`/omitted to query the current state.
  - Reads/writes the `StuckRects3` registry key under `HKEY_USERS`.
  - When setting a value, automatically restarts `explorer.exe` to apply the change.
  - Returns the current auto-hide state (`boolean`) after any write operation.

## Usage Example

```javascript
var winUtils = require('./win-utils');

// Query current taskbar auto-hide state
var isAutoHide = winUtils.taskBar.autoHide(sessionId, null);
console.log('Auto-hide enabled:', isAutoHide);

// Enable taskbar auto-hide
var newState = winUtils.taskBar.autoHide(sessionId, true);
console.log('Auto-hide now set to:', newState);

// Disable taskbar auto-hide
winUtils.taskBar.autoHide(sessionId, false);
```

## Dependencies

| Module | Purpose |
|---|---|
| `win-registry` | Registry read/write operations |
| `user-sessions` | Resolves domain and username from session ID |
| `process-manager` | Locates and kills `explorer.exe` to apply changes |

> **Note:** This module is Windows-only. It will not function on non-Windows platforms and requires appropriate registry access permissions for the target user session.
