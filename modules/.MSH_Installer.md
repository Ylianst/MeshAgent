Embeds a Mesh policy (MSH) configuration block into a binary executable, supporting both unsigned and signed Windows PE binaries as well as Linux executables.

## Key Components

- **`mshLength()`** — Reads the currently running executable and returns the length of any embedded MSH block by checking for the `exeMeshPolicyGuid` trailer signature. Returns `0` if no MSH is found.
- **`addMsh(options)`** — Streams a source binary to a destination with the MSH payload appended. Handles three cases:
  - Unsigned Windows (PE) binaries — appends MSH, length, and GUID directly after the binary.
  - Signed Windows (PE) binaries — patches `CertificateTableSize` and `certificateDwLength` in the PE headers before appending the MSH with quad-alignment padding.
  - Non-Windows (Linux/other) binaries — same as unsigned; appends MSH trailer directly.
- **CLI mode** — When executed directly, accepts `-i <mshFile>` and `-o <outputFile>` flags to produce a self-contained MSH-integrated binary, or `-mshlen` to inspect an existing embedded MSH length.

## Usage Example

```javascript
const addMsh = require('./MSH_Installer');
const fs = require('fs');

// Embed an MSH file into an existing binary
const options = {
  platform: 'win32',                                      // or 'linux'
  sourceFileName: '/path/to/meshagent.exe',
  destinationStream: fs.createWriteStream('output.exe', { flags: 'wb' }),
  msh: fs.readFileSync('/path/to/policy.msh')
};

options.destinationStream.on('close', () => console.log('Done'));
addMsh(options);

// Check if the current executable has an embedded MSH
const len = addMsh.len();
console.log('Embedded MSH length:', len); // 0 if none
```

```bash
# CLI usage
node MSH_Installer.js -i policy.msh -o meshagent-configured.exe
node MSH_Installer.js -mshlen
```
