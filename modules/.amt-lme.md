This module implements the Intel AMT Local Management Engine (LME) interface, handling the APF (AMT Port Forwarding) protocol over HECI to create local TCP proxies for AMT services like KVM, SOL, and IDER.

## Key Components

- **`lme_object`** — Channel state container tracking channel IDs, window sizes, local port, and connection status for each forwarded connection.
- **`stream_bufferedWrite`** — A duplex-like buffered stream that queues write chunks and emits `readable`/`drain` events, used to pace data within APF transmit windows.
- **`lme_heci(options)`** — Main export. Creates and manages a HECI connection to the AMT LME, handles all APF protocol messages (service negotiation, global requests, channel lifecycle, data forwarding), and binds local TCP server sockets for port forwarding.

### APF Protocol Constants

Constants map numeric opcodes to their APF protocol meanings (e.g., `APF_CHANNEL_OPEN = 90`, `APF_CHANNEL_DATA = 94`, `APF_PROTOCOLVERSION = 192`).

### Key Methods on `lme_heci`

- **`bindDuplexStream(socket, family, port)`** — Registers a new TCP socket as an APF channel, sending `APF_CHANNEL_OPEN` to AMT.
- Internal HECI `data` handler — Dispatches incoming APF commands: service requests, `tcpip-forward` bind requests, channel confirmations, window adjustments, data frames, and channel close.

## Usage Example

```javascript
var lme = require('amt-lme');
var lmeInstance = new lme();

lmeInstance.on('connect', function () {
    console.log('LME connected and ready');
});

lmeInstance.on('bind', function (bindings) {
    console.log('AMT ports bound:', Object.keys(bindings));
});

lmeInstance.on('error', function (err) {
    console.error('LME error:', err);
});
```

> **Note:** Requires the `heci` native module for HECI device access and optionally `amt-xml` for XML parsing. Debug mode (binding to `0.0.0.0` on offset ports) can be enabled by passing `{ debug: true }` to the constructor.
