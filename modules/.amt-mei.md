Brief description of the file's purpose in 1-2 sentences.

`amt-mei.js` provides a JavaScript interface for communicating with Intel AMT (Active Management Technology) via the HECI/MEI (Host Embedded Controller Interface / Management Engine Interface) PTHI (Platform Trust High-level Interface) channel. It exposes a queue-based command API for querying AMT hardware state, provisioning details, and device identifiers from the MeshAgent runtime.

## Key Components

| Export / Symbol | Description |
|---|---|
| `amt_heci` | Main constructor function; inherits from EventEmitter and manages the singleton HECI connection lifecycle |
| `g_internal` | Module-level singleton holding the request queue (`_rq`), active HECI handle (`_amt`), and error retry counter |
| `retry_pthi_later()` | Reconnection helper; retries PTHI connect up to 20 times with 250ms delay before emitting a fatal error |
| `sendCommand(cmd, data, callback, ...opts)` | Core method; enqueues a framed PTHI request and lazily opens the HECI channel |
| `getCommand(chunk)` | Parses a raw HECI response buffer into a structured header object (`IsResponse`, `Command`, `Status`, `Data`) |
| `getVersion(cb)` | Retrieves AMT BIOS and firmware version strings (command `26`) |
| `getUuid(cb)` | Retrieves the AMT device UUID formatted as a standard hyphenated string (command `0x5c`) |
| `getProvisioningState(cb)` | Returns provisioning state (`PRE` / `IN` / `POST`) (command `17`) |
| `getProvisioningMode(cb)` | Returns provisioning mode string (`NONE`, `ENTERPRISE`, etc.) (command `8`) |
| `getEHBCState(cb)` | Returns Enterprise Host Based Configuration state (command `132`) |
| `getControlMode(cb)` | Returns AMT control mode (`CLIENT`, `ADMIN`, etc.) (command `107`) |
| `getMACAddresses(cb)` | Returns dedicated and host MAC addresses as colon-delimited hex strings (command `37`) |
| `getDnsSuffix(cb)` | Returns the configured AMT DNS suffix (command `54`) |

## Usage Example

```javascript
var amt = require('./amt-mei');
var pthi = new amt();

// Query AMT firmware version
pthi.getVersion(function(version) {
    if (version) {
        console.log('BIOS Version:', version.BiosVersion);
        version.Versions.forEach(function(v) {
            console.log(v.Description + ':', v.Version);
        });
    }
});

// Query provisioning state
pthi.getProvisioningState(function(state) {
    if (state) {
        console.log('State:', state.stateStr); // "PRE", "IN", or "POST"
    }
});

// Query AMT UUID
pthi.getUuid(function(result) {
    if (result) {
        console.log('UUID:', result.uuid);
        // e.g. "4c4c4544-0056-3910-804e-b8c04f485631"
    }
});

// Listen for connection errors
pthi.on('error', function(err) {
    console.error('AMT PTHI error:', err);
});
```

> **Note:** This module requires the `heci` and `MeshAgent` native modules available in the MeshAgent runtime environment. It is not intended for use in standard Node.js environments.
