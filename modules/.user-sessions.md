Manages Windows Terminal Services (WTS) user sessions on Windows platforms, providing utilities to enumerate sessions, query session attributes, monitor power state changes, and track session lock/unlock events via native Win32 API interop.

## Key Components

- **`UserSessions`** — Main constructor/class (EventEmitter) that wraps Windows WTS, Advapi32, Kernel32, and User32 APIs
- **`columnParse(data, delimiter)`** — Utility to split and filter delimited strings
- **Events** — `changed`, `locked`, `unlocked` for session state tracking
- **`isRoot()`** — Checks if the current process runs with Administrator privileges
- **`getProcessOwnerName(pid)`** — Returns username, domain, and session ID for a given process ID
- **`getRawSessionAttribute(sessionId, attr)`** — Returns raw buffer for a WTS session attribute
- **`getSessionAttribute(sessionId, attr)`** — Returns UTF-8 string for a WTS session attribute
- **`consoleUid()`** — Returns the active console session ID
- **`getUsername(uid)` / `getDomain(uid)`** — Retrieve username or domain for a session
- **`Current(cb)`** — Enumerates all current WTS sessions with state info

## Usage Example

```javascript
var UserSessions = require('./user-sessions');

var sessions = new UserSessions();

// Listen for lock/unlock events
sessions.on('locked', function () {
    console.log('Session locked');
});
sessions.on('unlocked', function () {
    console.log('Session unlocked');
});

// Get active console session info
try {
    var uid = sessions.consoleUid();
    console.log('Active session ID:', uid);
    console.log('Username:', sessions.getUsername(uid));
    console.log('Domain:', sessions.getDomain(uid));
} catch (e) {
    console.error('No active console session:', e);
}

// Check if running as Administrator
if (sessions.isRoot()) {
    console.log('Running with admin privileges');
}

// Enumerate all sessions
sessions.Current(function (sessionList) {
    console.log('Sessions:', sessionList);
});
```

> **Note:** This module is Windows-only (`process.platform == 'win32'`). It requires the `_GenericMarshal` native module for Win32 API interop. Source: [`user-sessions.js`](https://github.com/flamingo-stack/meshagent/blob/main/user-sessions.js)
