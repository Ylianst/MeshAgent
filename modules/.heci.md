Provides a Node.js duplex stream interface for communicating with Intel ME (Management Engine) via the HECI (Host Embedded Controller Interface) protocol on Windows and Linux platforms.

## Key Components

- **`heci_create()`** — Factory function that instantiates a `Duplex` stream wired to the HECI device, managing overlapped I/O on Windows and non-blocking I/O on Linux.
- **`connect(guid, options)`** — Initiates a HECI client session by sending a `CLIENT_CONNECT` IOCTL with the target GUID; emits `connect` on success or `error` on failure.
- **`descriptorPath()`** — Resolves the OS-level device path (`/dev/mei`, `/dev/mei0` on Linux; SetupAPI enumeration on Windows).
- **`createDescriptor(path)`** — Opens a file/device handle to the HECI path using `fs.openSync` (Linux) or `kernel32.CreateFileA` (Windows).
- **`_pendingWrites` / `_processWrite()`** — Internal write queue ensuring ordered, overlapped writes to the device.
- **Win32 Native Proxies** — Loads `SetupAPI.dll` and `Kernel32.dll` via `_GenericMarshal` for device enumeration and file I/O.

## Usage Example

```javascript
const heci = require('./heci');

// Create a HECI session stream
const session = heci.create();

session.on('connect', () => {
  console.log('Connected, max buffer:', session.MaxBufferSize);
  session.write(Buffer.from([0x01, 0x02, 0x03]));
});

session.on('data', (chunk) => {
  console.log('Received:', chunk.toString('hex'));
});

session.on('error', (err) => {
  console.error('HECI error:', err);
});

// Connect to a specific Intel ME client GUID
session.connect('12345678-1234-1234-1234-123456789abc', { noPipeline: 0 });
```

> **Platform support:** Windows (via `SetupAPI` + `Kernel32`) and Linux (`/dev/mei*`). Throws `'HECI not supported'` on other platforms.
