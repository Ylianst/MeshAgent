A Windows-specific native UI dialog framework for building custom windows and dialog boxes via Win32 API calls through the `_GenericMarshal` P/Invoke bridge.

## Key Components

**Win32 Constants** — Comprehensive set of Windows API constants covering:
- Window styles (`WS_VISIBLE`, `WS_CHILD`, `WS_TABSTOP`)
- Window messages (`WM_CREATE`, `WM_COMMAND`, `WM_LBUTTONDOWN`, etc.)
- Button/edit/static control styles (`BS_*`, `ES_*`, `SS_*`)
- Font weight/family/quality constants (`FW_*`, `FF_*`, `DEFAULT_QUALITY`, etc.)
- GDI+ rendering constants (`HALFTONE`, `SmoothingModeAntiAlias`, `InterpolationModeBicubic`)
- Image/cursor constants (`STM_SETIMAGE`, `IDC_ARROW`, `IDC_HAND`)

**`defaultImage`** — Base64-encoded PNG bitmap embedded as a string, used as a fallback/default image resource for dialogs.

**`ptrsize`** — Pointer size derived from `_GenericMarshal`, enabling 32/64-bit compatible struct marshaling.

## Usage Example

```javascript
// This module is consumed internally by the MeshAgent Windows UI subsystem.
// Constants are used when constructing Win32 windows and controls.

const dialog = require('./win-dialog');

// Example: referencing exported constants for window creation
const style = dialog.WS_VISIBLE | dialog.WS_CHILD | dialog.WS_TABSTOP;
const buttonStyle = dialog.BS_DEFPUSHBUTTON | dialog.BS_MULTILINE;

// Send a font message to a control
sendMessage(hwnd, dialog.WM_SETFONT, hFont, true);
```
