Implements HTTP Digest Authentication (RFC 2617) for outgoing HTTP requests, handling the challenge-response handshake, MD5 hashing of credentials, and transparent retry on 401 responses.

## Key Components

### `http_digest` (module export)
Factory singleton with a single method:
- **`create(username, password)`** or **`create({ username, password, qop? })`** — Returns a new `http_digest_instance`.

### `http_digest_instance`
Manages per-session digest state (`_NC` nonce count, `_CNONCE` client nonce).
- **`request(uri | options)`** — Issues an HTTP request wrapped in a `Writable` stream. Automatically retries with digest credentials if the server returns `401`.
- **`get(uri)`** — Convenience alias for `request(uri)`.

### Internal Helpers
- **`generateAuthHeaders(imsg, options, digest)`** — Parses `WWW-Authenticate` header and computes the MD5-based `Authorization` header (supports `auth` and `auth-int` QoP modes).
- **`checkEventForwarding(digestRequest, eventName)`** — Proxies events (`upgrade`, `error`, `continue`, `timeout`, `drain`) from the inner HTTP request up to the digest wrapper.

## Usage Example

```javascript
var digest = require('./http-digest');

// Create an instance with credentials
var client = digest.create('admin', 'secret');
client.http = require('http'); // inject the http module

// Simple GET
var req = client.get('http://example.com/protected/resource');
req.on('response', function(res) {
    console.log('Status:', res.statusCode);
});

// POST with a body
var req = client.request({
    method: 'POST',
    host: 'example.com',
    path: '/api/data'
});
req.on('response', function(res) {
    console.log('Status:', res.statusCode);
});
req.write(Buffer.from(JSON.stringify({ key: 'value' })));
req.end();
```
