Defines a comprehensive mapping of x86 CPU feature flags as numeric bit-position constants, mirroring the Linux kernel's CPUID feature definitions for use in system capability detection.

## Key Components

- **`cpu_feature` object** — A flat namespace containing ~150+ named constants, each encoding a `(word * 32 + bit)` position corresponding to a specific CPUID leaf and bit.

### Feature Groups

| Word | Source | CPUID Leaf |
|------|--------|------------|
| 0 | Intel-defined | `0x00000001` EDX |
| 1 | AMD-defined | `0x80000001` |
| 2 | Transmeta-defined | `0x80860001` |
| 3 | Linux-defined (misc) | Various |
| 4 | Intel-defined | `0x00000001` ECX |
| 5 | VIA/Cyrix/Centaur | `0xC0000001` |
| 6 | Extended AMD | `0x80000001` ECX |
| 7 | Auxiliary flags | — |

## Usage Example

```javascript
var cpuflags = require('./linux-cpuflags');

// Check if a parsed CPUID bitmask includes a specific feature
function hasFeature(cpuidWords, featureConst) {
  var word = Math.floor(featureConst / 32);
  var bit  = featureConst % 32;
  return !!(cpuidWords[word] & (1 << bit));
}

// Example: test for AES-NI and AVX support
var words = getCPUIDWords(); // platform-specific
if (hasFeature(words, cpuflags.X86_FEATURE_AES)) {
  console.log('AES-NI supported');
}
if (hasFeature(words, cpuflags.X86_FEATURE_AVX)) {
  console.log('AVX supported');
}
```

> **Note:** The file contains a minor typo — word 3 entries briefly reference `cpu_Feature` (capital F) instead of `cpu_feature`, which will cause runtime errors for those four constants (`CXMMX`, `K6_MTRR`, `CYRIX_ARR`, `CENTAUR_MCR`).
