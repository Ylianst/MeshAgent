Handles pre-update file processing by detecting and extracting ZIP-compressed update packages before applying them. If the update file is not a ZIP, it passes through unchanged.

## Key Components

- **`start(updatePath)`** — Main export. Accepts a file path, checks if it's a ZIP archive, extracts the single contained file back to the original path, and resolves a promise when complete. Rejects if the ZIP contains more or fewer than one file, or if any filesystem operation fails.

## Usage Example

```javascript
const updateHelper = require('./update-helper');

updateHelper.start('/path/to/update.bin')
  .then(function (result) {
    if (result === 'done') {
      console.log('Update file was unzipped and replaced successfully');
    } else {
      console.log('File was not a ZIP, no extraction needed');
    }
  })
  .catch(function (err) {
    console.error('Update preparation failed:', err);
  });
```

## Behavior Notes

- **Non-ZIP passthrough:** If `updatePath` is not a ZIP file, the promise resolves immediately with no value and no file changes occur.
- **Single-file constraint:** The ZIP must contain exactly one file; any other count rejects with `'Unexpected contents in zip file'`.
- **Atomic replacement:** Extracts to `<updatePath>_unzipped`, deletes the original, copies the extracted file back to `updatePath`, then removes the temp file.
- **Cleanup:** The ZIP reader is always closed after extraction, whether successful or not.
