Lightweight XML parser that converts an XML string into a traversable DOM-like tree structure without any external dependencies.

## Key Components

### `_turnToXml(text)`
The main exported function. Parses an XML string and returns a root object with the following query methods:
- `getElementsByTagName(name)` — finds all descendant elements by local name
- `getElementsByTagNameNS(ns, name)` — finds all descendants matching namespace and local name
- `getChildElementsByTagName(name)` — finds direct children by local name

### `_treeBuilder`
Internal stack-based builder used during parsing. Manages element nesting and namespace resolution via `nsTable`, walking up the stack to resolve inherited namespace prefixes.

### `_turnToXmlRec(text)`
Core recursive parser. Splits raw XML text on `<` and `>` delimiters, builds element nodes with `name`, `localName`, `namespace`, `attributes`, `childNodes`, and `textContent` fields.

### `attributes.get()`
Custom method attached to each element's attributes array, supporting single-arg lookup by name or two-arg lookup by namespace + name.

## Usage Example

```javascript
const parseXml = require('./parseXml');

const xml = `
  <root xmlns="http://example.com">
    <item id="1">Hello</item>
    <item id="2">World</item>
  </root>
`;

const doc = parseXml(xml);

// Find all <item> elements
const items = doc.getElementsByTagName('item');
items.forEach(item => {
  console.log(item.textContent);         // "Hello", "World"
  console.log(item.attributes.get('id')); // { name: 'id', value: '1', ... }
});

// Namespace-aware lookup
const nsItems = doc.getElementsByTagNameNS('http://example.com', 'item');
```

> **Note:** This parser uses simple string splitting rather than a full XML tokenizer. It handles basic namespace declarations (`xmlns`, `xmlns:prefix`) and self-closing tags, but is not a spec-compliant XML parser. Suitable for well-structured, predictable XML payloads.
