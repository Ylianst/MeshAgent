Parses and decodes raw SMBIOS (System Management BIOS) firmware tables on Windows and Linux, extracting hardware metadata such as processor, memory, system identity, slots, and Intel AMT configuration.

## Key Components

- **`SMBiosTables`** — Main constructor that initializes platform-specific native bindings (Windows via `Kernel32.dll`, Linux via `dmidecode`)
- **`get(callback)`** — Retrieves raw SMBIOS binary data from the OS and returns the parsed table structure
- **`parse(data)`** — High-level aggregator that calls all sub-parsers and returns a combined hardware info object
- **`processorInfo(data)`** — Extracts CPU socket, manufacturer, speed, core/thread counts, and status from SMBIOS type 4
- **`memoryInfo(data)`** — Reads physical memory array location and max capacity from SMBIOS type 16
- **`systemInfo(data)`** — Decodes system UUID and wake reason from SMBIOS type 1
- **`systemSlots(data)`** — Lists expansion slot names from SMBIOS type 9
- **`amtInfo(data)`** — Detects Intel AMT/vPro capabilities (KVM, SOL, TXT, VMX, ME version) from SMBIOS types 130/131
- **`_parse(SMData)`** — Low-level binary parser that walks the raw SMBIOS byte stream and groups structures by type
- **`_canonicalizeData(data)`** — Linux-only helper that converts `dmidecode` text output into a binary-compatible buffer

## Usage Example

```javascript
var SMBiosTables = require('./smbios');
var smbios = new SMBiosTables();

// Async retrieval with callback
smbios.get(function(data) {
    if (!data) { console.log('Failed to read SMBIOS'); return; }

    // Parse all hardware info at once
    var info = smbios.parse(data);
    console.log('System UUID:', info.systemInfo.uuid);
    console.log('Wake Reason:', info.systemInfo.wakeReason);
    console.log('Processors:', info.processorInfo);
    console.log('AMT Enabled:', info.amtInfo.AMT);
});

// Synchronous (Windows only)
var data = smbios.get();
var memInfo = smbios.memoryInfo(data);
console.log('Memory Location:', memInfo.location);
```
