Locates shared libraries and binaries on Linux and FreeBSD systems by querying package managers and system utilities.

## Key Components

- **`find(name)`** — Default export. Searches for shared libraries provided by a named package. On FreeBSD, uses `pkg info` with shell parsing; on Linux, delegates to `monitor-info.getLibInfo()`. Returns an array of `{ name, location }` objects.
- **`hasBinary(bin)`** — Checks whether a binary exists on the system using `whereis`. Returns `true`/`false`; always returns `false` on non-Linux/FreeBSD platforms.
- **`findBinary(bin)`** — Locates the full path of a binary using `whereis`. Returns the path string or `null` if not found or on unsupported platforms.

## Usage Example

```javascript
const libFinder = require('./lib-finder');

// Find shared libraries for a package
const libs = libFinder('libssl');
// Returns: [{ name: 'libssl.so.1.1', location: '/usr/lib/x86_64-linux-gnu/libssl.so.1.1' }]

// Check if a binary exists
if (libFinder.hasBinary('curl')) {
  console.log('curl is available');
}

// Get the full path of a binary
const curlPath = libFinder.findBinary('curl');
// Returns: '/usr/bin/curl' or null
```

> **Platform support:** Linux and FreeBSD only. `find()` returns `undefined` and `hasBinary()`/`findBinary()` return `false`/`null` on other platforms (e.g., Windows, macOS).
