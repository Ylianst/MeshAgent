A script compiler, decompiler, and runner engine for Intel AMT (Active Management Technology) binary scripts, providing execution of bytecode instructions including WS-Management operations, variable management, and control flow.

## Key Components

| Export/Function | Description |
|---|---|
| `module.exports.setup(binary, startvars)` | Initializes a script execution context from binary bytecode |
| `obj.start(stepspeed)` | Begins timed step-by-step script execution |
| `obj.stop()` | Halts execution and clears the interval timer |
| `obj.reset()` | Resets instruction pointer and variables to initial state |
| `obj.step()` | Executes a single instruction from the bytecode |
| `obj.getVar(name)` / `obj.setVar(name, val)` | Dot-notation variable get/set with nested object support |
| `script_functionTable1` | Opcode names for core instructions (nop, jump, set, print, etc.) |
| `script_functionTable2` / `script_functionTableX2` | Function names and implementations for math/encoding ops |
| `httpErrorTable` | Maps HTTP/WSMAN error codes to human-readable strings |

Helper utilities: `ReadShort`, `ReadInt`, `ShortToStr`, `IntToStr` (big/little-endian binary read/write), `btoa`/`atob`, `passwordcheck`, `MakeToArray`.

## Usage Example

```javascript
const amtScript = require('./amt-script');

// Load a compiled AMT binary script
const fs = require('fs');
const binary = fs.readFileSync('script.bin');

// Initialize with starting variables
const ctx = amtScript.setup(binary, {
    host: '192.168.1.100',
    user: 'admin'
});

// Wire up console output
ctx.onConsole = (msg) => console.log('[AMT]', msg);

// Wire up completion callback
ctx.onCompleted = (success) => console.log('Done:', success);

// Reset state and start execution at 10ms/step
ctx.reset();
ctx.start(10); // stepspeed in milliseconds

// Stop early if needed
// ctx.stop();
```

## Notes

- Binary scripts must begin with magic header `0x247D2945` followed by a 2-byte version (`<= 1`)
- Arguments in bytecode support variable interpolation via `{varName}` syntax
- Temp variables prefixed with `__` are cleared on each step
- Source lives at [`amt-script.js`](https://github.com/flamingo-stack/meshagent/blob/main/amt-script.js)
