Brief description of `agent-selftest.js`: This file contains a large base64-encoded JPEG image asset and a commented action-type reference map used for agent self-testing and UI operations within the MeshAgent platform.

## Key Components

- **`img` (variable)** — A base64-encoded JPEG image string (prefixed with `image/jpeg,base64,...`) used as a visual asset within agent self-test or UI rendering contexts.
- **Action type reference map (comment block)** — Documents the supported `action` and `msg.type` values the agent can dispatch, including:
  - `msg` actions: `console`, `tunnel`, `messagebox`, `ps`, `pskill`, `services`, `serviceStop`, `serviceStart`, `serviceRestart`, `deskBackground`, `openUrl`, `getclip`, `setclip`, `userSessions`
  - Top-level actions: `acmactivate`, `wakeonlan`, `runcommands`, `toast`, `amtPolicy`, `sysinfo`

## Usage Example

```javascript
// The img variable holds a base64-encoded JPEG for use in agent UI contexts
const agentSelftest = require('./agent-selftest');

// Access the embedded image asset
console.log(agentSelftest.img); // "image/jpeg,base64,iVBORw0KGgo..."

// Supported action dispatch pattern (referenced by comment block)
const action = {
  action: 'msg',
  msg: {
    type: 'console',
    value: 'Running self-test...'
  }
};
```
