Parses WSMAN/AMT XML responses into structured JSON objects and provides a lightweight XML parser that works without external dependencies.

## Key Components

- **`ParseWsman(xml)`** *(exported)* — Converts a WSMAN XML envelope into a JSON object with `Header` and `Body` properties. Extracts the method name from the body's root element (stripping `_OUTPUT` suffixes).
- **`_ParseWsmanRec(node)`** — Recursively walks XML child nodes, auto-converting `"true"`/`"false"` strings to booleans, numeric strings to integers, repeated sibling elements to arrays, and attributes to `@`-prefixed keys.
- **`_PutObjToBodyXml(resuri, putObj)`** — Serializes a JavaScript object back to WSMAN-namespaced XML for PUT operations, handling `ReferenceParameters` and array values.
- **`_turnToXml(text)` / `_turnToXmlRec(text)`** — Lightweight drop-in XML parser (no external dependency) that tokenizes raw XML strings into a DOM-like tree with `childNodes`, `attributes`, `localName`, `namespace`, and `getElementsByTagName`.
- **`_treeBuilder`** — Internal stack-based helper used by `_turnToXmlRec` to manage element nesting and namespace resolution.

## Usage Example

```javascript
const amtXml = require('./amt-xml');

const rawXml = `<Envelope>
  <Header><a:Action>http://schemas.xmlsoap.org/ws/2004/09/transfer/GetResponse</a:Action></Header>
  <Body><g:AMT_GeneralSettings_OUTPUT><g:HostName>mydevice</g:HostName></g:AMT_GeneralSettings_OUTPUT></Body>
</Envelope>`;

const parsed = amtXml.ParseWsman(rawXml);
// {
//   Header: { Action: 'http://...GetResponse', Method: 'AMT_GeneralSettings' },
//   Body: { HostName: 'mydevice' }
// }
console.log(parsed.Body.HostName); // 'mydevice'
```
