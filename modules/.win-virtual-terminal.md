Provides a Node.js interface to the Windows PseudoConsole (ConPTY) API, enabling creation and management of virtual terminal sessions for running shell processes like `cmd.exe` or PowerShell with full VT/ANSI support.

## Key Components

| Export/Method | Description |
|---|---|
| `supported` | Boolean property indicating whether the current Windows build supports PseudoConsoles (requires Windows 10 1809+) |
| `Create(path, width, height)` | Spawns an arbitrary executable inside a PseudoConsole and returns a `Duplex` stream for I/O |
| `Start(width, height)` | Convenience wrapper that launches `cmd.exe` in a PseudoConsole |
| `StartPowerShell(width, height)` | Convenience wrapper that launches PowerShell, with x64/x86 path resolution |
| `PowerShellCapable()` | Returns `true` if a PowerShell binary is found on the system |
| `stream.resizeTerminal(w, h)` | Resizes the active PseudoConsole via `ResizePseudoConsole` Win32 API |

## Usage Example

```javascript
// Only available on win32 platform
const vt = require('./win-virtual-terminal');

if (vt.supported) {
  // Start a cmd.exe session at 120x40 columns/rows
  const terminal = vt.Start(120, 40);

  // Read output from the terminal
  terminal.on('data', (chunk) => {
    process.stdout.write(chunk);
  });

  // Write input to the terminal
  terminal.write('dir\r\n');

  // Resize the terminal window
  terminal.resizeTerminal(160, 50);

  // Start PowerShell instead
  if (vt.PowerShellCapable()) {
    const psTerminal = vt.StartPowerShell(120, 40);
    psTerminal.write('Get-Process\r\n');
  }
}
```

> **Note:** This module only exports on `win32` platforms. The underlying `_GenericMarshal` dependency is a native MeshAgent binding used to invoke Win32 APIs directly.
