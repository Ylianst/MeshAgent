Provides a Windows certificate store interface by wrapping the native `Crypt32.dll` and `Ncrypt.dll` APIs via generic marshalling, enabling certificate lookup and crypto provider access from JavaScript.

## Key Components

- **`certstore` (constructor)** — Initializes native proxies for `Crypt32.dll` and `Ncrypt.dll`, exposes store location constants (`LOCAL_MACHINE`, `CURRENT_USER`), and registers available crypto providers.
- **`OpenCryptoProvider()`** — Attempts to open a Windows NCrypt storage provider (tries Platform Crypto Provider first, then Software Key Storage Provider). Returns a handle with an auto-close finalizer.
- **`OpenStore(provider, location)`** — Opens the `MY` certificate store for the given crypto provider handle and location flag. Returns a store handle with an auto-close finalizer.
- **`GetCertificate(CN, location)`** — Encodes an X.500 subject name string, searches the certificate store by subject name, and returns a parsed TLS certificate object if found.

## Usage Example

```javascript
const certstore = require('./win-certstore');

// Retrieve a certificate by Common Name from the local machine store
try {
    const cert = certstore.GetCertificate(
        'CN=MyDevice',
        certstore.STORE_LOCATION.LOCAL_MACHINE
    );
    console.log('Certificate found:', cert);
} catch (err) {
    console.error('Certificate lookup failed:', err);
}
```

> **Note:** This module is Windows-only and depends on the internal `_GenericMarshal` native binding. It is exported as a singleton instance and is intended for use within the [MeshAgent](https://github.com/flamingo-stack/meshagent) runtime environment.
