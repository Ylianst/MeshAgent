Provides a Windows WMI (Windows Management Instrumentation) interface for querying system information via COM interop, enabling async and synchronous WQL queries against WMI namespaces.

## Key Components

- **`CLSID_WbemAdministrativeLocator` / `IID_WbemLocator`** — COM class/interface identifiers for instantiating the WMI locator.
- **`LocatorFunctions`, `ServiceFunctions`, `ResultsFunctions`, `ResultFunctions`** — COM vtable function name arrays for marshaling `IWbemLocator`, `IWbemServices`, `IEnumWbemClassObject`, and `IWbemClassObject` interfaces respectively.
- **`QueryAsyncHandler`** — COM callback sink implementing `IWbemObjectSink` (`QueryInterface`, `AddRef`, `Release`, `Indicate`, `SetStatus`) for async WQL query results.
- **`enumerateProperties(j, fields)`** — Introspects a WMI class object's properties, handling scalar and `VT_ARRAY`-typed VARIANT values (integers, booleans, strings) via `SafeArrayAccessData`.
- **`OleAut32`** — Native proxy to `OleAut32.dll` used for `SafeArrayAccessData` / `SafeArrayUnaccessData` calls.
- **`wmi_handlers`** — Registry object for tracking active WMI handler instances.

## Usage Example

```javascript
// Query WMI for processor information (conceptual usage)
var wmi = require('win-wmi');

wmi.query('ROOT\\CIMV2', 'SELECT * FROM Win32_Processor', ['Name', 'NumberOfCores'])
  .then(function (results) {
    for (var i = 0; i < results.length; i++) {
      console.log(results[i].Name, results[i].NumberOfCores);
    }
  })
  .catch(function (err) {
    console.error('WMI query failed:', err);
  });
```

> **Note:** This module is Windows-only and relies on `_GenericMarshal` and `win-com` native bindings available in the MeshAgent runtime environment.
