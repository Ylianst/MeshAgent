Provides ZIP file reading, parsing, and extraction functionality for Node.js, supporting both file-system extraction and in-memory stream-based access with CRC verification.

## Key Components

- **`read(path)`** — Opens a ZIP file at the given path and returns a Promise resolving to a `zippedObject`.
- **`zippedObject`** — Core class wrapping a parsed ZIP archive with the following members:
  - `files` *(property)* — Array of file names contained in the archive.
  - `getStream(name)` — Returns a readable stream for a named entry (supports stored and deflate compression).
  - `extractAll(destFolder)` — Extracts all entries to disk with CRC validation; returns a Promise.
  - `extractAllStreams()` — Extracts all entries into in-memory `Buffer` objects; returns a Promise resolving to an array of `{ name, buffer }` results.
  - `crc(name)` — Returns the stored CRC-32 value for a named entry.
  - `readLocalHeader(name)` — Reads and logs the local file record header (debug utility).
  - `close()` — Closes the underlying file descriptor.
- **`checkFolderPath(dest)`** — Recursively creates intermediate directories before extraction.
- **`extractNext(p)`** — Internal helper that sequentially extracts pending entries with CRC verification.

## Usage Example

```javascript
const zipReader = require('./zip-reader');

// Extract all files to disk
zipReader.read('/path/to/archive.zip')
  .then(zip => zip.extractAll('/output/folder'))
  .then(() => console.log('Extraction complete'))
  .catch(err => console.error('Failed:', err));

// Read all entries as in-memory buffers
zipReader.read('/path/to/archive.zip')
  .then(zip => zip.extractAllStreams())
  .then(results => {
    results.forEach(({ name, buffer }) => {
      console.log(`${name}: ${buffer.length} bytes`);
    });
  });

// Stream a single file entry
zipReader.read('/path/to/archive.zip')
  .then(zip => {
    const stream = zip.getStream('config/settings.json');
    stream.pipe(process.stdout);
  });
```

> **Note:** Deflate-compressed entries require the `compressed-stream` native module. Stored (uncompressed) entries use a built-in pass-through duplex stream.
