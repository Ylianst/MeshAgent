Windows user consent dialog module that renders a GDI+ graphics-based consent prompt with embedded icon and default image assets for the MeshAgent remote management system.

## Key Components

- **`HALFTONE`** (`4`) — GDI+ `HatchStyle` constant for halftone brush patterns
- **`SmoothingModeAntiAlias`** (`5`) — GDI+ smoothing mode for anti-aliased rendering
- **`InterpolationModeBicubic`** (`8`) — GDI+ interpolation mode for high-quality image scaling
- **`x_icon`** — Base64-encoded PNG of the close/X button icon (100×100 px)
- **`default_image`** — Base64-encoded PNG used as the default background/branding image in the consent dialog

## Usage Example

```javascript
// Typically required internally by the MeshAgent consent subsystem
const userConsent = require('./win-userconsent');

// Access embedded image assets (base64 PNG strings)
const iconData = userConsent.x_icon;
const bgImage  = userConsent.default_image;

// GDI+ rendering constants are exported for use in native drawing calls
const smoothing     = userConsent.SmoothingModeAntiAlias;   // 5
const interpolation = userConsent.InterpolationModeBicubic; // 8
const halftone      = userConsent.HALFTONE;                 // 4
```

## Notes

- This file is Windows-specific and relies on GDI+ via the MeshAgent native binding layer.
- The embedded base64 assets avoid filesystem I/O at runtime, keeping the consent dialog self-contained.
- Constants map directly to GDI+ enumeration values consumed by the native Windows rendering pipeline.
