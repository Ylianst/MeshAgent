Dual-purpose utility for the MeshCentral agent installer: when executed as a Node.js script it bundles itself into a self-contained interactive setup binary; when run as that binary it provides a GUI/CLI-driven install, uninstall, connect, and update workflow for the mesh agent service.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `exeJavaScriptGuid` | Constant | Magic GUID used to mark the embedded JavaScript payload boundary in the output binary |
| `msh` | Object | Parsed `.msh` configuration (mesh server URL, IDs, service name, display name, install flags) |
| `translation` | Object | Multilingual string table (English + Korean built-in); missing entries fall back to English |
| `_install(parms)` | Function | Writes the `.msh` file and spawns a `child_process` full-install of the agent |
| `_uninstall()` | Function | Spawns a `child_process` full-uninstall of the agent service |
| `getParameter` / `getParameterEx` | Array prototype extensions | Parses `--key=value` CLI arguments with optional default values |
| `messageBoxCapabilities` | Object | Caches zenity/kdialog availability to avoid repeated GUI-capability probes |

## CLI Flags

```text
-mesh           Print parsed .msh config as JSON and exit
-translations   Print all translation strings as JSON and exit
-upgrade        Re-run install preserving --installPath and -- flags
-connect        Run agent in foreground without installing as a service
-install        Install agent as a system service
-uninstall      Remove agent service
-update         Update agent binary in place
-lang=<code>    Override UI language (e.g. -lang=ko)
-help           Print available commands
```

## Usage Example

```javascript
// Build the standalone interactive binary from the source tree
node modules/interactive.js
// → writes ./interactive (native binary + embedded JS payload)

// Run the generated binary to install the agent
./interactive -install

// Run with a specific language override
./interactive -lang=ko

// Dump the active mesh configuration
./interactive -mesh
```

> **Note:** The `/*****/` sentinel comments delimit the build-time code (binary creation) from the runtime code (UI workflow). During the build phase, everything between the two sentinels is replaced with the serialized `msh` config object before being appended to the executable.
