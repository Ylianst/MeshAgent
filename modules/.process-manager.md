Cross-platform process enumeration utility that provides a unified API for listing and inspecting running processes on Windows, Linux, macOS, and FreeBSD.

## Key Components

- **`processManager()`** — Constructor that initializes platform-specific native bindings (Win32 via `_GenericMarshal`/`kernel32.dll`) or child process hooks (POSIX systems).
- **`getProcesses(callback)`** — Enumerates all running processes and returns a `pid → processInfo` object map. Each entry includes `pid`, `cmd`, `path` (Windows), and `user`.
- **`enumerateProcesses()`** — Promise-based wrapper around `getProcesses()`, resolving with the same process map.
- **`getProcessInfo(pid)`** — Returns detailed info for a single process (Linux: parses `/proc/<pid>/status`; Windows: uses a named pipe IPC approach).

## Platform Support

| Platform | Method |
|---|---|
| `win32` | `CreateToolhelp32Snapshot` + `QueryFullProcessImageNameW` via `kernel32.dll` |
| `linux` | `ps` with `awk` JSON output + `/proc/<pid>/cmdline` fallback |
| `darwin` / `freebsd` | `ps -axo` with `awk` JSON output |

## Usage Example

```javascript
const processManager = require('./process-manager');

const pm = new processManager();

// Callback-based
pm.getProcesses(function(processes) {
    for (const pid in processes) {
        console.log(processes[pid]); // { pid, cmd, user, path? }
    }
});

// Promise-based
pm.enumerateProcesses().then(function(processes) {
    console.log(Object.keys(processes).length + ' processes running');
});

// Single process info (Linux only)
const info = pm.getProcessInfo(1234);
console.log(info.Name, info.VmRSS);
```
