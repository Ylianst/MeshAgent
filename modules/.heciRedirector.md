Provides a bidirectional WebSocket-based tunnel for redirecting Intel HECI (Host Embedded Controller Interface) communication between a client and an AMT/LME service over HTTP upgrade connections.

## Key Components

- **`heciRedirector`** — Constructor function exported as a singleton with two primary methods:
  - **`redirect(options)`** — Client-side: registers a `heci` module object that establishes a WebSocket tunnel to a `/heciRedirect` endpoint, creating a `Duplex` stream for bidirectional data flow. Supports `connect()` and `disconnect()` operations targeting `AMT` (PTHI) or `LME` services.
  - **`listen(options)`** — Server-side: starts an HTTP server that accepts WebSocket upgrade requests, receives `Connect` commands, and bridges the connection to the underlying native `heci` module (piping data between the WebSocket and the HECI device).

## Usage Example

```javascript
const heciRedirector = require('./heciRedirector');

// --- Server side: listen for incoming tunnel connections ---
heciRedirector.listen({ port: 16993 });

// --- Client side: redirect HECI through a remote endpoint ---
heciRedirector.redirect({
    host: 'localhost',
    port: 16993
});

// Access the injected 'heci' module object (registered via addModuleObject)
const heci = require('heci');
const session = heci.create();

session.on('connect', () => {
    console.log('HECI session connected');
});

session.on('error', (err) => {
    console.error('HECI error:', err);
});

// Connect to the AMT PTHI service
session.connect('AMT', {});
```

## Notes

- The module is exported as a **singleton** (`new heciRedirector()`), so both `redirect` and `listen` share the same instance.
- The client and server communicate via JSON-encoded command frames (`Connect`, `Event`) over the WebSocket channel; raw binary data is passed through directly.
- Relies on `addModuleObject` being available in the global scope (MeshAgent-specific runtime).
