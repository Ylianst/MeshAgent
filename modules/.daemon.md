Provides a lightweight process daemon utility for spawning and auto-restarting child processes, with optional stdout passthrough and SIGTERM handling.

## Key Components

- **`start(path, parameters, options)`** — Spawns a child process using `execFile`, wires up stdout/stderr forwarding, and attaches an exit handler. Returns an `EventEmitter`-based object that emits `done` when the process exits without triggering a restart.
- **`agent()`** — Convenience wrapper that re-launches the current Node.js executable (with its arguments) under daemon supervision, configured to auto-restart on crash and exit cleanly on code `6565`.
- **`stdoutHandler(c)`** — Internal handler that forwards child process stdout/stderr to the parent process when `options.stdout` is enabled.
- **`exitHandler(code)`** — Internal handler that either restarts the child (if `crashRestart` is enabled and the exit code doesn't match `options.exit`) or emits the `done` event to signal clean shutdown.

## Usage Example

```javascript
const daemon = require('./daemon');

// Spawn and auto-restart a process on crash
const handle = daemon.start(
  '/usr/bin/node',
  ['worker.js', '--port', '3000'],
  {
    crashRestart: true, // auto-restart on non-zero exit
    exit: 0,           // exit code that signals intentional stop
    stdout: true       // pipe child stdout to parent process
  }
);

handle.on('done', () => {
  console.log('Process exited cleanly, no restart.');
  process.exit();
});

// Or use the built-in agent mode to self-daemonize the current script
// (called from a launcher entry point)
daemon.agent();
```

> **Note:** On non-Windows platforms, the daemon registers a `SIGTERM` handler that calls `process.exit()`, allowing graceful shutdown signals to propagate correctly to the supervised process.
