Intel AMT Communication Stack service layer that wraps WSMAN protocol operations (GET, PUT, CREATE, DELETE, ENUMERATE, SUBSCRIBE) for managing Intel Active Management Technology devices.

## Key Components

- **`AmtStackCreateService(wsmanStack)`** — Factory function that constructs the AMT stack object wrapping a WSMAN transport layer
- **`obj.Get / Put / Create / Delete`** — Single-resource WSMAN CRUD operations
- **`obj.Exec / ExecWithXml`** — WSMAN method invocation with optional XML argument serialization
- **`obj.Subscribe / UnSubscribe`** — WSMAN event subscription management
- **`obj.Enum`** — WSMAN ENUMERATE + PULL operation with concurrency throttling via `MaxActiveEnumsCount`
- **`obj.BatchEnum`** — Sequential batch enumeration across multiple AMT/CIM/IPS resource classes
- **`obj.BatchGet`** — Sequential batch GET operations
- **`obj.CompleteName(name)`** — Resolves short class names (`AMT_*`, `CIM_*`, `IPS_*`) to full WSMAN URIs
- **`obj.GetPendingActions()`** — Returns count of all in-flight and queued operations
- **`obj.onProcessChanged`** — Progress callback fired when pending action count changes
- **`obj.RequestPowerStateChange`** — Convenience wrapper for `CIM_PowerManagementService` power state transitions
- **`obj.SetBootConfigRole`** — Convenience wrapper for `CIM_BootService` boot configuration

## Usage Example

```javascript
var amtStack = AmtStackCreateService(wsmanStack);

// Track progress
amtStack.onProcessChanged = function(current, max) {
  console.log(`Progress: ${current}/${max}`);
};

// Fetch a single AMT resource
amtStack.Get('AMT_GeneralSettings', function(stack, name, response, status) {
  if (status === 200) console.log(response.Body);
});

// Batch enumerate multiple resource classes
amtStack.BatchEnum('inventory', ['AMT_EthernetPortSettings', 'CIM_ComputerSystem'], function(stack, name, results, status) {
  console.log(results['AMT_EthernetPortSettings'].response);
}, null, true);

// Power action
amtStack.RequestPowerStateChange(5, function(stack, name, response, status) {
  console.log('Power state changed:', status);
});
```
