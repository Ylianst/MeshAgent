Provides a Linux ACPI event listener that connects to the `acpid` daemon socket and emits parsed hardware events (e.g., power button, lid, battery) as a Node.js `EventEmitter`.

## Key Components

- **`linux_acpi` class** — Singleton constructor that extends `EventEmitter` with a single `acpi` event
- **`supported` property** — Read-only boolean indicating whether `/var/run/acpid.socket` exists on the host
- **`_client`** — Unix socket connection to `/var/run/acpid.socket`; parses incoming newline-delimited ACPI event strings into structured objects
- **`acpi` event** — Emitted per event with `{ name, type, value }` where `type` and `value` are decoded from hex-encoded 32-bit big-endian integers

## Usage Example

```javascript
const acpi = require('./linux-acpi');

if (acpi.supported) {
    acpi.on('acpi', function (event) {
        console.log('ACPI event received:', event);
        // event = { name: 'button/power', type: 0x00000080, value: 0x00000001 }

        if (event.name === 'button/power') {
            console.log('Power button pressed');
        }
        if (event.name === 'button/lid') {
            console.log('Lid state changed, value:', event.value);
        }
    });
} else {
    console.warn('ACPI socket not available on this system');
}
```

## Notes

- Exported as a **singleton** via `module.exports = new linux_acpi()`
- Requires the `acpid` daemon to be running (`/var/run/acpid.socket` must exist)
- Handles partial TCP chunks by pushing incomplete lines back to the stream buffer
- Part of the [MeshAgent](https://github.com/flamingo-stack/meshagent) device management agent
