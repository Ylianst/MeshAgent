A command-line utility for inspecting and manipulating the MeshAgent's `SimpleDataStore` database file, enabling read/write operations on key-value entries used by the agent.

## Key Components

| Command | Description |
|---|---|
| `compact` | Compacts the database to reclaim space |
| `get` / `getx` | Retrieves a value as string or hex-encoded buffer |
| `put` / `putx` | Writes a string or hex-decoded buffer value |
| `list` / `keys` / `keynum` | Lists all keys sorted alphabetically, or fetches by index |
| `delete` | Removes a key from the database |
| `export` | Writes a database entry to a file (handles `CoreModule`/`RecoveryModule` specially) |
| `import` | Reads a `.js` file and stores it compressed (handles `CoreModule`/`RecoveryModule` specially) |

The database path is auto-resolved relative to the executable: `<execPath>.db` on Linux/macOS, `<execPath>.db` replacing `.exe` on Windows. Write-mode is only enabled for mutating commands (`compact`, `put`, `putx`, `delete`, `import`).

## Usage Example

```bash
# List all keys in the database
meshagent.db list

# Get a value by key
meshagent.db get disableUpdate

# Set a string value
meshagent.db put disableUpdate true

# Set a hex-encoded binary value
meshagent.db putx MyBinaryKey deadbeef

# Export CoreModule to a file
meshagent.db export CoreModule

# Import CoreModule from file (compressed)
meshagent.db import CoreModule

# Delete a key
meshagent.db delete noUpdateCoreModule

# Compact the database
meshagent.db compact
```

> **Commonly used keys:** `disableUpdate`, `noUpdateCoreModule`
