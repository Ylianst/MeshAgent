Provides cross-platform scheduled task management for Windows, Linux, and macOS, wrapping OS-native scheduling mechanisms (`schtasks`, cron, `launchd`) to create, query, and modify recurring tasks that start system services.

## Key Components

- **`task` constructor** — Main class instantiated per platform; sets `_ObjectID` to `'task-scheduler'`
- **`getTaskXml(name)`** *(Windows)* — Retrieves the XML definition of a named scheduled task via `schtasks.exe`
- **`getActionCommand(name, xml?)`** *(Windows)* — Parses and returns the `<Command>` value from a task's XML
- **`editActionCommand(name, action, argString, xml?)`** *(Windows)* — Rewrites a task's `<Exec>` block, exports UTF-16 XML, then re-creates the task via `schtasks`
- **`advancedEditActionCommand(name, action, argString)`** *(Windows)* — Uses PowerShell `Set-ScheduledTask` for modern task editing
- **`advancedSupport`** *(Windows, computed property)* — Boolean indicating whether the `ScheduledTasks` PowerShell module is available
- **`create(options)`** — Cross-platform task creation returning a Promise; supports `minute`, `hourly`, `daily`, `weekly`, `monthly`, `day`, `month`, `time`, `name`, and `service` option keys

## Usage Example

```javascript
const task = require('./task-scheduler');
const scheduler = new task();

// Create a daily scheduled task that starts a service
scheduler.create({
  name: 'MyApp/DailyRestart',
  service: 'meshagent',
  daily: 1,
  time: '03:00'
}).then(() => {
  console.log('Task created successfully');
}).catch((code) => {
  console.error('Failed to create task, exit code:', code);
});

// Windows only: read and modify an existing task's action
const xml = scheduler.getTaskXml('MyApp\\DailyRestart');
scheduler.editActionCommand('MyApp\\DailyRestart', 'C:\\new\\path.exe', '--flag value', xml);
```

> **Platform notes:** `getTaskXml`, `getActionCommand`, `editActionCommand`, and `advancedEditActionCommand` are only attached on `win32`. The `create` method branches internally for `win32`, `linux`, and `darwin` (macOS via `launchd`).
