Cross-platform native message box utility for displaying modal dialogs to users on Windows (via `user32.dll MessageBoxW`) and Linux (via `zenity`), returning a Promise that resolves or rejects based on the user's button response.

## Key Components

### Constants
- **Button layout flags** (`MB_OK`, `MB_YESNO`, `MB_OKCANCEL`, etc.) — Windows MessageBox button configuration bitmasks
- **Icon flags** (`MB_ICONEXCLAMATION`, `MB_ICONQUESTION`, etc.) — Windows MessageBox icon bitmasks
- **Response IDs** (`IDOK`, `IDYES`, `IDNO`, `IDCANCEL`, etc.) — Return values from the native dialog

### Classes

| Class | Platform | Description |
|---|---|---|
| `messageBox` | Windows | Spawns a child container process that calls `user32.dll MessageBoxW` asynchronously |
| `linux_messageBox` | Linux | Uses `zenity` for GTK-based dialogs; auto-detects binary path and capability flags |

### Methods

- **`create(title, caption, timeout, layout, sid)`** — Creates and displays a modal dialog. Returns a Promise; resolves on OK/Yes, rejects on No/Cancel or timeout
- **`slave()`** — Internal IPC slave method invoked in the child container process on Windows
- **`zenity`** (lazy getter) — Detects `zenity` binary path and probes for `--timeout`, `--extra-button`, and `--version` support

## Usage Example

```javascript
const mb = require('message-box');

// Display a Yes/No confirmation dialog (Windows/Linux)
mb.create('My App', 'Do you want to proceed?', 30, null, null)
  .then(function () {
    // User clicked Yes / OK
    console.log('Confirmed');
  })
  .catch(function (reason) {
    // User clicked No/Cancel, or dialog timed out
    console.log('Declined or timed out:', reason);
  });

// Display an alert (OK only) with a 60-second timeout
mb.create('Alert', 'Operation complete.', 60, 'alert', null);
```

> **Note:** On Windows, dialogs run in a child container via IPC using `_GenericMarshal` and `user32.dll`. On Linux, `zenity` must be installed and accessible. Session targeting is handled automatically via `user-sessions`.
