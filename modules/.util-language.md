Utility module that detects and returns the current OS language locale, with a comprehensive Windows LCID-to-BCP 47 language tag conversion helper.

## Key Components

- **`toLang(val)`** — Converts a Windows LCID (Locale Identifier) numeric string to its corresponding BCP 47 language tag (e.g., `'1033'` → `'en-US'`). Covers 150+ locales sourced from the [MS-OE376 specification](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/6c085406-a698-4e12-9d4d-c3b0ee3dbc4a).

## Usage Example

```javascript
const lang = require('./util-language');

// Resolve the current OS language locale
lang.getLanguage(function(locale) {
    console.log(locale); // e.g., 'en-US', 'fr-FR', 'ja-JP'
});

// Internal LCID conversion (Windows-specific)
const tag = toLang('1036'); // Returns 'fr-FR'
const tag2 = toLang('1041'); // Returns 'ja-JP'
```

## Notes

- `toLang()` is an internal Windows-only helper; on Linux/macOS the module reads locale from environment variables or system commands instead.
- Returns BCP 47 language tags compatible with `Intl` APIs and `Accept-Language` headers.
- Part of the [MeshAgent](https://github.com/flamingo-stack/meshagent) agent utility layer used by the Flamingo/OpenFrame platform for locale-aware operations.
