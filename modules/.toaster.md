Cross-platform toast notification utility that displays system-level popup notifications using platform-native mechanisms (PowerShell on Windows, zenity/notify-send on Linux/macOS/FreeBSD).

## Key Components

- **`findPath(app)`** *(Unix only)* — Helper that locates a binary's full path using `whereis`, with FreeBSD fallback to `/usr/local/bin/`.
- **`Toaster`** — Constructor function exposing the main notification interface.
- **`Toaster.Toast(title, caption, tsid)`** — Displays a toast notification for the given title/caption under the specified session ID (`tsid`). Returns a `Promise` that resolves with `'DISMISSED'` when the user dismisses or the timeout expires.

## Platform Behavior

| Platform | Mechanism | Notes |
|---|---|---|
| `win32` | PowerShell `NotifyIcon` | Runs under the console user's session; 10-second auto-dismiss timeout |
| `linux` | zenity / notify-send / D-Bus | Falls back through available tools; fakes notification if D-Bus unavailable |
| `freebsd` | Same as Linux | Checks `/usr/local/bin/` as extra fallback |
| `darwin` | `whereis`-based lookup | macOS path resolution via shell |

## Usage Example

```javascript
var Toaster = require('./toaster');
var toaster = new Toaster();

toaster.Toast('MeshCentral', 'Agent connected successfully', null)
    .then(function(result) {
        // result === 'DISMISSED'
        console.log('Toast dismissed');
    })
    .catch(function(err) {
        console.error('Toast failed:', err);
    });
```

> **Note:** `title` defaults to the MeshAgent `displayName` when set to `'MeshCentral'`. Pass a non-null `tsid` to target a specific user session (Windows only).
