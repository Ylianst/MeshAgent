Implements the standard PAC (Proxy Auto-Configuration) helper functions used within a proxy `.pac` file environment to evaluate hostnames, IP subnets, and DNS resolution for routing decisions.

## Key Components

| Function | Description |
|---|---|
| `dnsDomainIs(target, host)` | Returns `true` if `target` hostname belongs to the specified domain |
| `shExpMatch(host, exp)` | Matches a hostname or URL against a shell-style glob expression (`*`, `?`) |
| `isInNet(target, address, mask)` | Checks whether a resolved IP falls within a given subnet |
| `dnsResolve(host)` | Resolves a hostname to its first IP address string |
| `isPlainHostName(host)` | Returns `true` if the hostname contains no dots |
| `localHostOrDomainIs(target, host)` | Returns `true` if the resolved address exactly matches `host` |
| `isResolvable(host)` | Returns `true` if DNS resolution succeeds for the given hostname |
| `dnsDomainLevels(host)` | Returns the number of dots (domain levels) in a hostname |
| `weekdayRange` / `dateRange` / `timeRange` | Stub implementations for time-based PAC rules |

## Usage Example

```javascript
// Route traffic through proxy only for internal domain
function FindProxyForURL(url, host) {
  // Match any subdomain of example.internal
  if (dnsDomainIs(host, ".example.internal")) {
    return "PROXY proxy.internal:8080";
  }

  // Match glob pattern
  if (shExpMatch(host, "*.corp.*")) {
    return "PROXY proxy.corp:3128";
  }

  // Check subnet membership
  if (isInNet(host, "10.0.0.0", "255.0.0.0")) {
    return "DIRECT";
  }

  // Skip proxy for plain hostnames (e.g. "intranet")
  if (isPlainHostName(host)) {
    return "DIRECT";
  }

  return "PROXY default.proxy:8080";
}
```

> **Note:** `isInNet` and `dnsResolve` depend on an underlying `resolve()` function expected to be provided by the PAC execution environment (e.g., MeshAgent's network layer).
