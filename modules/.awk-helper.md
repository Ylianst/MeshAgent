Utility script that constructs an `awk`/`loginctl` shell command string and copies it to the system clipboard for easy reuse.

## Key Components

- **`child.stdin` mock object** — Simulates a writable stream, accumulating command fragments via repeated `write()` calls into a single string (`child.stdin.str`).
- **AWK command builder** — Assembles a pipeline that parses `loginctl list-sessions` output, filters sessions belonging to UIDs ≥ 1000 (standard Linux user accounts), excludes PTY sessions, and formats results as a JSON array of `{ uid, sid }` objects.
- **`require('clipboard')`** — Writes the assembled command string to the system clipboard.
- **Platform-aware exit** — On Linux, keeps the process alive for 5 seconds (clipboard typically requires an active process on X11), then exits. On other platforms, exits immediately.

## Usage Example

Run directly with Node.js to place the generated `awk` command on your clipboard:

```bash
node awk-helper.js
# clipboard active for 5 seconds
```

Then paste the command into a terminal to get active user sessions as JSON:

```bash
loginctl list-sessions | tr '\n' '`' | awk '{ ... }'
# [{"uid": "1000", "sid": "3"},{"uid": "1001", "sid": "7"}]
```

The generated command filters out:
- System accounts (UID < 1000)
- Sessions with no seat or PTY-only sessions (`pts/`)

> **Note:** This script depends on a `clipboard` module available in the MeshAgent runtime (see [source](https://github.com/flamingo-stack/meshagent/blob/main/awk-helper.js)) and is intended as a Linux developer utility for testing session enumeration logic.
