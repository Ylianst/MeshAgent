Centralizes macOS-specific utility functions for app bundle detection, launchd service naming, plist path resolution, and system operations like `ditto` copying and `PlistBuddy` execution.

## Key Components

| Export | Type | Description |
|---|---|---|
| `PATHS` | Constant | macOS filesystem paths (`/Library/LaunchDaemons/`, `ditto`, `launchctl`, etc.) |
| `DOMAINS` | Constant | launchd domain strings (`system`, `gui/`) |
| `BUNDLE` | Constant | App bundle subdirectory suffixes (`.app/Contents/MacOS/`, etc.) |
| `isRunningFromBundle` | Function | Returns `true` if the process is running from inside a `.app` bundle |
| `getBundleParentDirectory` | Function | Extracts the parent directory of the `.app` bundle from a binary path |
| `getBundlePathFromBinaryPath` | Function | Strips the `Contents/MacOS/...` suffix to return the `.app` root path |
| `sanitizeIdentifier` | Function | Normalizes a string to reverse-DNS-safe lowercase (hyphens/underscores only) |
| `buildServiceId` | Function | Builds a composite launchd service ID (e.g., `meshagent.ServiceName.CompanyName`) |
| `getPlistPath` | Function | Returns the full plist file path for a daemon or agent by service ID |
| `getLaunchdDomain` | Function | Returns `system` or `gui/{uid}` for launchd domain targeting |
| `getLaunchdPath` | Function | Combines domain and service ID into a `launchctl`-compatible path string |
| `copyBundleWithDitto` | Function | Copies an `.app` bundle using `ditto`, preserving signatures and metadata |
| `executePlistBuddy` | Function | Runs a `PlistBuddy -c` command synchronously on a target plist file |

## Usage Example

```javascript
const macOS = require('./macOSHelpers');

// Check if running from a bundle
if (macOS.isRunningFromBundle()) {
    const bundleDir = macOS.getBundleParentDirectory();
    // bundleDir => '/opt/meshagent/'
}

// Build a launchd service ID
const serviceId = macOS.buildServiceId('MeshAgent', 'Flamingo');
// => 'meshagent.meshagent.flamingo'

// Get plist path for a daemon
const plistPath = macOS.getPlistPath(serviceId, 'daemon');
// => '/Library/LaunchDaemons/meshagent.meshagent.flamingo.plist'

// Build a launchctl target path
const domain = macOS.getLaunchdDomain(null);       // => 'system'
const target = macOS.getLaunchdPath(domain, serviceId);
// => 'system/meshagent.meshagent.flamingo'

// Copy a bundle preserving codesign metadata
macOS.copyBundleWithDitto('/tmp/MeshAgent.app', '/Applications/MeshAgent.app');

// Read a value from a plist
const version = macOS.executePlistBuddy('Print :CFBundleVersion', plistPath);
```
