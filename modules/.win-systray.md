Windows system tray icon manager that creates and manages notification area icons with context menus via PowerShell, supporting both local system and user-session contexts.

## Key Components

- **`createTrayIcon(trayOptions)`** — Spawns a PowerShell child process that renders a `NotifyIcon` with a context menu. Communicates back via stdout using `<<TID:>>` and `<<menuitem:>>` protocol tokens. Returns a promise with a `.remove()` method.
- **`localsystem_createTrayIcon(trayOptions)`** — Variant used when the process runs as the local system account (TSID 0). Delegates tray creation to a user-session dispatcher via `win-dispatcher`, enabling cross-session tray icons.
- **`postMessage(tid)`** — Sends `WM_QUIT` to the PowerShell thread by thread ID using `User32.dll` via `_GenericMarshal`, terminating the tray icon cleanly.
- **Module export** — Automatically selects `localsystem_createTrayIcon` or `createTrayIcon` based on the process owner's TSID. Throws on non-Windows platforms.

## Usage Example

```javascript
const systray = require('win-systray');

const tray = systray.createTrayIcon({
  title: 'My Agent',
  menuItems: [
    {
      text: 'Open Dashboard',
      func: function () { console.log('Dashboard clicked'); }
    },
    {
      text: 'Exit',
      func: function () { tray.remove(); process.exit(0); }
    }
  ]
});

// Remove the tray icon manually
tray.remove();
```

### `trayOptions` Reference

| Property | Type | Description |
|---|---|---|
| `title` | `string` | Tooltip text shown on hover |
| `menuItems` | `Array` | List of `{ text, func }` context menu entries |
| `user` | `string` | Target username (auto-detected if omitted) |
| `tsid` | `number` | Terminal session ID override |
| `split` | `boolean` | Internal flag for dispatcher mode |
