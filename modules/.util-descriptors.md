A platform-aware utility module for enumerating and managing open file descriptors in the current process, with additional helpers for safe `execv` execution and Windows process handle retrieval.

## Key Components

| Export | Platform | Description |
|---|---|---|
| `getOpenDescriptors()` | Linux, FreeBSD | Returns an array of all open file descriptor numbers for the current process |
| `closeDescriptors(fdArray)` | Linux, FreeBSD | Iterates an array of file descriptors and closes each one (skips stdin/stdout/stderr: fd ≤ 2) via glibc |
| `_execv(exePath, argarr)` | Linux, FreeBSD | Closes all open descriptors before invoking native `execv()` to prevent fd leakage into child processes |
| `getLibc()` | Linux, FreeBSD | Resolves and returns a native marshaler for glibc exposing `execv` and `close` |
| `getProcessHandle(pid)` | Windows | Returns a `HANDLE` to the specified PID via `kernel32.OpenProcess` with `SYNCHRONIZE` access |

**Platform behavior:**
- **Linux** — reads open descriptors from `/proc/<pid>/fd`
- **FreeBSD** — uses `procstat -f <pid>` via a shell child process
- **Other platforms** — `getOpenDescriptors` and `closeDescriptors` throw `"Not supported on <platform>"`

## Usage Example

```javascript
const descriptors = require('./util-descriptors');

// List all open file descriptors
const fds = descriptors.getOpenDescriptors();
console.log('Open descriptors:', fds); // e.g. [0, 1, 2, 5, 7]

// Close all non-standard descriptors
descriptors.closeDescriptors([...fds]);

// Execute a new process, safely closing all open fds first
descriptors._execv('/usr/bin/node', ['node', 'app.js']);

// Windows only: get a process handle by PID
if (process.platform === 'win32') {
  const handle = descriptors.getProcessHandle(1234);
}
```
