Cross-platform KVM (Keyboard-Video-Mouse) helper module that manages user sessions and virtual display environments for remote desktop access, with extended Linux support for Wayland/X11 configuration and virtual session spawning via Xvfb.

## Key Components

### Functions

| Function | Platform | Description |
|---|---|---|
| `getUsers()` | All | Returns active/connected user sessions keyed by session/UID |
| `spawnVirtualSession(vuid)` | Linux | Launches a virtual X session via `xvfb-run` for a given user |
| `hasVirtualSessionSupport()` | Linux | Checks if the system can support virtual sessions (loginctl + Xvfb + DM) |
| `loginUids()` | Linux | Returns spawnable UIDs mapped to virtual session metadata |
| `waylandStatus()` | Linux | Parses GDM config to determine if Wayland is enabled |
| `disableWayland()` | Linux | Patches GDM config to force X11 mode |
| `enableWayland()` | Linux | Restores GDM config to allow Wayland |
| `waylandDM()` | Linux | Detects which GDM variant is installed (`gdm` or `gdm3`) |

### Module Exports

- **Linux:** Full export including `createVirtualSession`, `hasVirtualSessionSupport`, `users`, `loginUids`, `allowed`, `waylandStatus`, `disableWayland`, `enableWayland`, `waylandDM`
- **Non-Linux:** Stub export with no-op `createVirtualSession`, `hasVirtualSessionSupport: false`, `users`, `allowed`

## Usage Example

```javascript
const kvmHelper = require('./kvm-helper');

// Get all active user sessions
const activeSessions = kvmHelper.users();
console.log(activeSessions);

// Linux only: check virtual session support
if (kvmHelper.hasVirtualSessionSupport) {
  // Spawn a virtual X session for UID 1001
  const resolvedUid = kvmHelper.createVirtualSession(1001);
  console.log('Session UID:', resolvedUid);
}

// Linux only: manage Wayland
if (kvmHelper.waylandStatus()) {
  kvmHelper.disableWayland(); // force X11 for KVM compatibility
}

// Check which display manager is in use
console.log('DM:', kvmHelper.waylandDM()); // 'gdm', 'gdm3', or ''
```

> **Note:** Virtual session spawning (`createVirtualSession`) requires `xvfb-run` and a supported desktop manager (`gnome-session`, `startlxde`, or `startxfce4`) to be installed on the host system.
