Queries Windows volume information and BitLocker encryption status by combining data from two WMI namespaces into a single structured result.

## Key Components

- **`getVolumes()`** — Internal function that queries `Win32_Volume` for general disk volume metadata and `Win32_EncryptableVolume` for BitLocker status, then merges both datasets keyed by `DeviceID`.
- **`trimObject(j)`** — Utility that strips null values, empty strings, and `__`-prefixed WMI metadata properties. Also normalizes negative `SerialNumber` values to unsigned 32-bit integers via little-endian buffer reinterpretation.
- **`module.exports.getVolumes`** — Safe public wrapper that returns an empty object `{}` on any error (e.g., non-Windows environments or missing WMI access).

## Usage Example

```javascript
const { getVolumes } = require('./win-volumes');

const volumes = getVolumes();

for (const [deviceId, info] of Object.entries(volumes)) {
  console.log(`Volume: ${deviceId}`);
  console.log(`  Label: ${info.Label}`);
  console.log(`  Capacity: ${info.Capacity}`);
  console.log(`  BitLocker Status: ${info.ProtectionStatus ?? 'N/A'}`);
}
```

> **Note:** This module is Windows-only. It depends on `win-wmi` for WMI queries. On non-Windows systems or when WMI is unavailable, `getVolumes()` returns `{}` silently.
