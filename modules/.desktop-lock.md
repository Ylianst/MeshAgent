Cross-platform desktop lock utility that triggers the OS-level workstation lock/screen lock mechanism on Windows, Linux, and macOS.

## Key Components

- **`desktopLock` class** — Singleton class with `_ObjectID` of `'desktop-lock'`
- **`lock()`** — Main method that locks the workstation using platform-specific commands:
  - **Windows** — Invokes `RunDll32.exe user32.dll,LockWorkStation` via `cmd.exe`, respecting elevated (`isRoot`) session type
  - **Linux** — Runs `loginctl lock-sessions` via `/bin/sh`, throws on stderr output
  - **macOS** — Delegates to the `message-box` module's `lock()` method
  - **Other platforms** — Throws `'Not supported on <platform>'`

## Usage Example

```javascript
const desktopLock = require('./desktop-lock');

try {
    desktopLock.lock();
    console.log('Workstation locked successfully');
} catch (e) {
    console.error('Lock failed:', e);
}
```

> **Note:** The module exports a singleton instance — no instantiation is required. On Linux, any stderr output from `loginctl lock-sessions` is treated as a failure and throws `'Failed'`. On Windows, the process type is set based on whether the agent is running as root/SYSTEM via the `user-sessions` module.
