A post-build automation script that computes a SHA-384 hash of the compiled executable and archives versioned copies of the `.exe` and `.pdb` files into a structured directory.

## Key Components

- **SHA384 hash computation** — Streams the current executable (`process.execPath`) through a `SHA384Stream` to generate a content-based hash
- **Archive directory management** — Creates an `archive/` folder alongside the executable if it does not already exist
- **Versioned output folder** — Names the archive subfolder using the executable's base name and the first 16 hex characters of its hash (e.g., `archive/meshagent_a1b2c3d4e5f67890/`)
- **File copy streams** — Pipes both the `.exe` and `.pdb` files into the versioned archive folder using Node.js read/write streams
- **`OnFinish` callback** — Tracks a `pending` counter (set to `2`) and calls `process.exit()` only after both file copies complete

## Usage Example

This script is intended to run automatically as a post-build step, not manually. Invoke it via your build tool configuration:

```javascript
// package.json example
{
  "scripts": {
    "postbuild": "node PostBuild.js"
  }
}
```

```bash
# Or invoke directly after compilation
node PostBuild.js
```

> **Platform note:** This script currently supports **Windows only**. On other platforms it logs an unsupported message and exits immediately.

## Notes

- Requires the [`SHA384Stream`](https://www.npmjs.com/package/SHA384Stream) npm package
- The archive folder is created at the same directory level as the executable
- Designed for Windows PE binaries where `.pdb` debug symbol files are co-located with the `.exe`
