Streams ZIP archive creation by compressing files using deflate and writing valid ZIP format headers, central directory records, and end-of-central-directory records to a Node.js Duplex stream.

## Key Components

- **`write(options)`** — Main export. Accepts an `options` object with a `files` array and optional `basePath`, returns a Node.js `Duplex` stream that emits compressed ZIP data.
- **`checkFiles(files)`** — Recursively resolves directories into individual file paths.
- **`getBaseFolder(val)`** — Determines the common base path prefix to strip from file names inside the archive.
- **`convertToMSDOSTime(datetimestring)`** — Converts an ISO 8601 timestamp to MS-DOS packed date/time format required by the ZIP spec.
- **`next(options)`** — Internal function that processes the next file in the queue: writes a Local File Record (LFR) header, compresses via `compressed-stream`, and updates CRC/size fields.
- **`finished(options)`** — Internal function called after all files are processed; writes Central Directory Records (CDR) and the End of Central Directory Record (EOCDR).

### Stream Events

| Event | Description |
|---|---|
| `progress` | Emitted per file with `(filePath, percentComplete)` |
| `cancel` | Emitted after cancellation is complete |

## Usage Example

```javascript
const zipWriter = require('./zip-writer');

const stream = zipWriter.write({
  files: ['/path/to/file1.txt', '/path/to/folder/'],
  basePath: '/path/to/' // optional: override base path stripping
});

stream.on('progress', (file, percent) => {
  console.log(`${file}: ${percent}%`);
});

stream.on('cancel', () => {
  console.log('Cancelled');
});

stream.pipe(require('fs').createWriteStream('output.zip'));
stream.resume();

// Optional: cancel mid-stream
// stream.cancel(() => console.log('done cancelling'));
```
