Parses Windows Portable Executable (PE) binary files to extract metadata including architecture format, section headers, certificate data, resource tables, and version information.

## Key Components

| Function | Description |
|---|---|
| `parse(exePath)` | Main entry point — reads a PE file and returns a structured metadata object |
| `readResourceTable(fd, ptr, offset)` | Recursively reads the `.rsrc` section resource directory table |
| `readResourceItem(fd, ptr, offset)` | Reads a single resource data entry |
| `getVersionInfoData(fd, header)` | Extracts the raw version info (`RT_VERSION`) buffer from resources |
| `readFixedFileInfoStruct(buf, ptr)` | Parses the `VS_FIXEDFILEINFO` structure (file/product version numbers) |
| `readStringFilesStruct(buf, ptr, len)` | Parses `StringFileInfo` blocks from version resources |
| `readStringTableStruct(buf, ptr)` | Parses a `StringTable` entry within `StringFileInfo` |
| `readStringStructs(buf, ptr, len)` | Parses individual key/value `String` entries |
| `padPointer(ptr)` | Returns the next 4-byte aligned offset |

## Usage Example

```javascript
const PE_Parser = require('./PE_Parser');

try {
    const info = PE_Parser.parse('C:\\Windows\\System32\\notepad.exe');

    console.log(info.format);                  // 'x64' or 'x86'
    console.log(info.CertificateTableAddress); // Authenticode cert offset
    console.log(info.certificate);             // Base64-encoded certificate
    console.log(info.sections);               // { '.text': {...}, '.rsrc': {...}, ... }
    console.log(info.versionInfo);            // Parsed VS_VERSIONINFO data
} catch (err) {
    console.error('Failed to parse PE:', err);
}
```

## Returned Object Fields

| Field | Description |
|---|---|
| `format` | `'x86'` or `'x64'` |
| `sections` | Map of PE section names to section header data |
| `certificate` | Base64-encoded Authenticode certificate (if present) |
| `resources` | Parsed resource directory tree |
| `versionInfo` | Parsed version info strings |
| `rva[]` | Array of Data Directory RVA/size entries |
| `CheckSumPos` | File offset of the PE checksum field |
