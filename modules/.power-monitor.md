Cross-platform power monitoring module that tracks AC/battery state and controls display sleep/wake across Windows, Linux, and macOS.

## Key Components

### Events

| Event | Description |
|---|---|
| `changed` | General power state change |
| `sx` | System sleep/wake transition |
| `batteryLevel` | Battery percentage update |
| `acdc` | AC/battery source switch (`'AC'` or `'BATTERY'`) |
| `display` | Display state change |

### Methods

- **`sleepDisplay(force)`** — Puts the display to sleep. Returns a promise. Supports `win32` and `darwin`; rejects on other platforms.
- **`wakeDisplay()`** — Wakes the display. Returns a promise. Supports `win32` and `darwin`; resolves silently on other platforms.

### Platform Behavior

- **Windows** — Uses `User32.dll` (`SendMessageA`) for sleep and `Kernel32.dll` (`SetThreadExecutionState`) for wake. Delegates to a user-session child process when running as `LocalSystem`.
- **Linux** — Reads `/sys/class/power_supply` for AC/battery paths; listens to `linux-acpi` events; polls battery level every 5 minutes.
- **macOS** — Uses `pmset` via shell for battery/AC state; polls every 5 minutes; uses `caffeinate` for display wake.

## Usage Example

```javascript
const power = require('./power-monitor');

// Listen for AC/battery transitions
power.on('acdc', (source) => {
  console.log('Power source:', source); // 'AC' or 'BATTERY'
});

// Listen for battery level changes
power.on('batteryLevel', (level) => {
  console.log('Battery:', level + '%');
});

// Sleep the display
power.sleepDisplay().then(() => {
  console.log('Display sleeping');
}).catch((err) => {
  console.error('Sleep failed:', err);
});

// Wake the display
power.wakeDisplay().then(() => {
  console.log('Display awake');
});
```

> **Note:** The module exports a singleton instance. New `acdc` and `batteryLevel` listeners receive the current state immediately upon registration.
