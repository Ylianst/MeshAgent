Provides a JavaScript wrapper around the Windows Task Scheduler COM API, enabling programmatic creation, configuration, and registration of Windows scheduled tasks using native COM interop via the `_GenericMarshal` module.

## Key Components

### Constants
- **CLSID/IID identifiers** — COM GUIDs for `TaskScheduler`, `TimeTrigger`, and `ExecAction` interfaces
- **`TASK_LOGON_*`** — Logon type constants (e.g., `TASK_LOGON_SERVICE_ACCOUNT`, `TASK_LOGON_INTERACTIVE_TOKEN`)
- **`TASK_TRIGGER_*`** — Trigger type constants (e.g., `TASK_TRIGGER_BOOT`, `TASK_TRIGGER_DAILY`)
- **`TASK_ACTION_*`** — Action type constants (e.g., `TASK_ACTION_EXEC`, `TASK_ACTION_COM_HANDLER`)
- **`TASK_CREATE_OR_UPDATE`** — Task registration flags

### COM Interface VTable Definitions
- **`TaskServiceFunctions`** — Maps `ITaskService` vtable ([MSDN ref](https://learn.microsoft.com/en-us/windows/win32/api/taskschd/nn-taskschd-itaskservice))
- **`TaskFolderFunctions`** — Maps `ITaskFolder` vtable
- **`TaskDefinitionFunctions`** — Maps `ITaskDefinition` vtable
- **`TriggerCollectionFunctions`** / **`TriggerFunctions`** / **`TimeTriggerFunctions`** — Trigger management vtables
- **`ActionCollectionFunctions`** — Action management vtable
- **`PrincipalFunctions`** / **`TaskSettingsFunctions`** / **`IdleSettingsFunctions`** — Task configuration vtables

### Utility Functions
- **`ConvertStringArray(strarr)`** — Converts a JavaScript string array into a COM-compatible `VARIANT` containing a `SAFEARRAY` of `BSTR` values using `OleAut32` APIs

## Usage Example

```javascript
const winTasks = require('./win-tasks');

// ConvertStringArray is used internally to pass string arrays
// to COM interfaces that expect VARIANT SAFEARRAY of BSTR
const variantArray = ConvertStringArray(['arg1', 'arg2', 'arg3']);
// Returns a GM variable containing a VT_ARRAY | VT_BSTR VARIANT
```

## Dependencies

- [`_GenericMarshal`](https://github.com/flamingo-stack/meshagent) — Native COM/memory interop module
- `OleAut32.dll` — Windows OLE automation library (SafeArray and VARIANT management)
