Cross-platform utility module that detects the system's default network route by querying the OS routing table, returning the interface name/index and metric for the lowest-cost default gateway.

## Key Components

| Export | Platform | Description |
|--------|----------|-------------|
| `windows_defaultRoute()` | `win32` | Uses `Iphlpapi.dll!GetIpForwardTable` via native proxy to read the IP forward table and find the lowest-metric default route (destination `0.0.0.0`) |
| `linux_defaultRoute()` | `linux` | Shells out to `ip route` and parses `default dev <iface>` entries via `awk` |
| `bsd_defaultRoute()` | `freebsd` / `darwin` | Shells out to `netstat -rn -f inet` and parses the default route interface with `awk` |

**Return shape** (all platforms):
```javascript
{ interface: <string|number>, metric: <number> }
// or null if no default route is found
```

- On Windows, `interface` is the adapter index (integer) and `metric` is the numeric route metric.
- On Linux/BSD, `interface` is the interface name string (e.g. `"eth0"`) and `metric` is hardcoded to `1`.

## Usage Example

```javascript
const getDefaultRoute = require('./default_route');

const route = getDefaultRoute();

if (route) {
  console.log('Default route interface:', route.interface);
  console.log('Route metric:', route.metric);
} else {
  console.log('No default route found');
}
```
