WSMAN communication factory for AMT (Intel Active Management Technology) devices, implemented using the Duktape JavaScript runtime's HTTP stack with digest authentication support.

## Key Components

- **`CreateWsmanComm(config)`** — Factory function that creates and returns a WSMAN communication object. Accepts either a config object (`host`, `port`, `authToken`, `tls`) or positional arguments (`host`, `port`, `user`, `pass`, `tls`).

### Returned Object Methods

| Method | Description |
|---|---|
| `PerformAjax(postdata, callback, tag, pri, url, action)` | Queues or immediately executes a WSMAN POST request. Set `pri=1` for high-priority (front of queue). |
| `PerformNextAjax()` | Dequeues and dispatches the next pending request. |
| `PerformAjaxEx(...)` | Executes the HTTP request directly via `http-digest`. |
| `CancelAllQueries(status)` | Flushes the pending queue, calling each callback with the given error status. |
| `gotNextMessages(...)` | Handles successful HTTP 200 responses. |
| `gotNextMessagesError(...)` | Handles HTTP errors and fires the callback with an error status. |

## Usage Example

```javascript
const CreateWsmanComm = require('./amt-wsman-duk');

// Create via config object (token-based auth)
const comm = CreateWsmanComm({
  host: '192.168.1.100',
  port: 16992,
  authToken: 'myToken',
  tls: 0
});

// Or via positional args (digest auth)
const comm2 = CreateWsmanComm('192.168.1.100', 16992, 'admin', 'P@ssw0rd', 0);

// Send a WSMAN request
comm.PerformAjax('<wsman envelope...>', function(data, status, tag) {
  if (status === 200) {
    console.log('Response:', data);
  } else {
    console.error('Error status:', status);
  }
}, 'myTag', 0);

// Abort all pending calls on shutdown
comm.CancelAllQueries(503);
```

## Notes

- `MaxActiveAjaxCount` defaults to `1`; concurrent requests are queued in `PendingAjax`.
- Set `FailAllError = 999` to silently drop all responses (useful during teardown).
- Digest auth is lazily initialized on the first request via the `http-digest` Duktape module.
- TLS certificate verification is disabled (`rejectUnauthorized: false`).
