Reads Authenticode Opus information from a signed Windows PE file and provides server-lock validation for MeshAgent deployments.

## Key Components

| Export | Description |
|---|---|
| `module.exports` (`read`) | Extracts the SPC Opus Info (description + URL) embedded in a file's Authenticode signature |
| `module.exports.locked` | Parses a Opus URL to extract a locked `dns` host and `serverid` |
| `module.exports.checkMSH` | Validates the running agent binary's Opus-embedded server lock against the active MSH configuration |

## Usage Example

```javascript
const opus = require('./win-authenticode-opus');

// Read Opus info from a signed executable
const info = opus(process.execPath);
// info => { description: "MeshAgent", url: "https://mesh.example.com?serverId=abc123" }

// Parse lock parameters from the Opus URL
const lock = opus.locked(info.url);
// lock => { dns: "mesh.example.com", id: "abc123" }

// Validate the running binary's lock against MSH config (throws on mismatch)
opus.checkMSH();
```

## How It Works

`read` uses the Windows `Crypt32.dll` API via `_GenericMarshal` to:

1. Open the embedded PKCS#7 signature with `CryptQueryObject`
2. Retrieve signer info via `CryptMsgGetParam`
3. Walk authenticated attributes looking for OID `1.3.6.1.4.1.311.2.1.12` (SPC Opus Info)
4. Decode the blob with `CryptDecodeObject` and return the wide-string `description` and `url` fields

> **Windows only.** Requires `_GenericMarshal` and `Crypt32.dll`. Returns `null` if no Opus attribute is found or the binary is unsigned.
