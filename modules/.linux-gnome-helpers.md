Linux GNOME and mount-point utilities for the MeshAgent Linux agent, providing proxy settings, desktop wallpaper management, and filesystem mount enumeration via shell child processes.

## Key Components

| Export | Description |
|---|---|
| `getProxySettings(uid)` | Reads GNOME proxy configuration via `gsettings` for a given user ID, returning mode, host, port, authentication, and exception list |
| `getDesktopWallpaper(uid)` | Retrieves the current GNOME desktop background URI for a given user ID |
| `setDesktopWallpaper(uid, filePath)` | Sets the GNOME desktop background for a given user ID, resolving the correct D-Bus session |
| `mounts()` | Enumerates Linux filesystem mount points and their types by parsing `mount` output |
| `available` *(property)* | Boolean indicating whether `gsettings` is present on the system |
| `_location` *(property)* | Resolved path to the `gsettings` binary |
| `scriptVersion` *(property)* | Parsed major/minor version of `/usr/bin/script` |

> **Note:** This module is Linux-only. The `module.exports` block is gated on `process.platform === 'linux'`.

## Usage Example

```javascript
const gnome = require('./linux-gnome-helpers');

// Check if gsettings is available
if (gnome.available) {
    // Get proxy settings for user with UID 1000
    const proxy = gnome.getProxySettings(1000);
    console.log(proxy);
    // { mode: 'manual', host: '10.0.0.1', port: 8080, ... }

    // Get current wallpaper path
    const wallpaper = gnome.getDesktopWallpaper(1000);
    console.log(wallpaper); // '/usr/share/backgrounds/gnome/adwaita.jpg'

    // Set a new wallpaper
    gnome.setDesktopWallpaper(1000, '/home/user/wallpaper.png');
}

// List all mount points
const mounts = gnome.mounts();
console.log(mounts);
// { '/': 'ext4', '/boot': 'vfat', '/home': 'ext4', ... }
```
