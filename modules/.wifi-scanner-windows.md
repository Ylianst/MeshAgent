Windows Wi-Fi scanning module that wraps the native Windows WLAN API (`wlanapi.dll`) via a generic marshal proxy, enabling wireless network enumeration and scan operations on Windows.

## Key Components

- **`Wireless`** — Main constructor (exported as singleton) that opens a WLAN handle, registers for scan notifications, and exposes scan/query methods
- **`_Scan()`** — Enumerates WLAN interfaces and triggers a native `WlanScan` call; returns `true` on success
- **`OnNotify()`** — Callback fired on WLAN scan-complete notifications; parses BSS list entries and emits `Scan` events with `AccessPoint` objects
- **`AccessPoint`** — Simple data class holding `ssid`, `bssid`, `rssi`, and `lq` (link quality) for a discovered network
- **`GetConnectedNetwork()`** — Queries the current association state; returns an `AccessPoint` for the connected network or throws if disconnected

## Usage Example

```javascript
const wifi = require('./wifi-scanner-windows');

// Listen for discovered access points
wifi.on('Scan', (ap) => {
    console.log(`Found: ${ap.ssid} [${ap.bssid}] LQ: ${ap.lq}`);
});

// Trigger a scan on the first WLAN interface
const started = wifi.Scan();
console.log('Scan started:', started);

// Get the currently connected network
try {
    const current = wifi.GetConnectedNetwork();
    console.log('Connected to:', current.toString());
} catch (err) {
    console.error(err);
}
```

> **Note:** This module is Windows-only and requires the `_GenericMarshal` native module available in the [MeshAgent](https://github.com/flamingo-stack/meshagent) runtime. It exports a pre-instantiated singleton, so `require`-ing it immediately opens a WLAN handle.
