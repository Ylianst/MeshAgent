Sets the minimum required Windows platform version for the project by defining the `_WIN32_WINNT` macro.

## Key Components

| Macro | Value | Description |
|---|---|---|
| `_WIN32_WINNT` | `0x0600` | Targets Windows Vista as the minimum supported platform |

## Usage Example

```c
// targetver.h is typically included via stdafx.h or pch.h
#include "targetver.h"
#include <windows.h>

// After inclusion, Windows Vista+ APIs are available
// To target a different minimum Windows version, modify before including:
#define _WIN32_WINNT 0x0601  // Windows 7
#include "targetver.h"
```

## Notes

- The guard `#ifndef _WIN32_WINNT` ensures the macro is only defined if not already set externally (e.g., via compiler flags).
- Common `_WIN32_WINNT` values:

  | Value | Target OS |
  |---|---|
  | `0x0600` | Windows Vista |
  | `0x0601` | Windows 7 |
  | `0x0602` | Windows 8 |
  | `0x0A00` | Windows 10 |

- Refer to [Microsoft's documentation](https://learn.microsoft.com/en-us/cpp/porting/modifying-winver-and-win32-winnt) for the full list of platform version constants.
