Precompiled header file that aggregates frequently used system includes to speed up compilation across the meshagent project.

## Key Components

| Include | Purpose |
|---|---|
| `targetver.h` | Defines the minimum supported Windows platform version |
| `<stdio.h>` | Standard C I/O functions (`printf`, `fopen`, etc.) |
| `<tchar.h>` | Generic-text mapping macros for Unicode/MBCS portability (`_T()`, `TCHAR`) |

## Usage Example

```c
// Any meshagent source file that includes stdafx.h
// gains access to all aggregated headers automatically:
#include "stdafx.h"

int main() {
    _tprintf(_T("Hello from meshagent\n"));
    return 0;
}
```

## Notes

- `#pragma once` ensures the header is included only once per translation unit, preventing duplicate symbol errors.
- Add project-wide, infrequently changing headers here to maximise precompiled header (PCH) benefits.
- Platform-specific to Windows/MSVC builds; cross-platform targets should conditionally exclude this file.
