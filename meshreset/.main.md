Windows-only utility for resetting or fully removing the MeshAgent installation, handling process termination, service management, registry cleanup, and database core removal.

## Key Components

| Function | Description |
|---|---|
| `killProcess` | Terminates a process by name using Windows Toolhelp32 snapshot API |
| `killProcess2` | Kills a process by name via `taskkill /F /T /IM` system command |
| `killService` | Stops a service by name via `taskkill /F /FI SERVICES` |
| `UninstallService` | Removes a Windows service via Service Control Manager |
| `GetServiceState` | Returns current service state (1–7) or 100 if not installed |
| `LaunchService` | Starts a stopped Windows service via SCM |
| `StopService` | Sends a stop control to a running Windows service |
| `removeDir` | Silently deletes a directory using `SHFileOperation` |
| `removeMeshCore` | Opens a MeshAgent `.db` file and deletes the `CoreModule` key, then compacts |
| `isFileExists` | Cross-platform file existence check using `_access` / `access` |
| `BreakSink` | `SIGINT` handler that suppresses further Ctrl+C interrupts |
| `main` | Entry point dispatching `reset` or `remove` subcommands |

## Usage Example

```bash
# Reset the agent: clears CoreModule from .db and restarts the service
meshutil.exe reset

# Fully remove the agent: kills processes, uninstalls services, cleans registry and folders
meshutil.exe remove
```

```c
// Reset flow (internal)
killProcess("meshagent.exe");
killProcess2("meshagent.exe");
killService("Mesh Agent");
StopService("Mesh Agent");
removeMeshCore("C:\\Program Files\\Mesh Agent\\MeshAgent.db");
LaunchService("Mesh Agent");

// Remove flow (internal)
UninstallService("Mesh Agent");
UninstallService("Mesh Agent v2");
RegDeleteKey(HKEY_LOCAL_MACHINE, "Software\\Open Source\\MeshAgent");
```

> **Platform:** Windows only. Requires elevated privileges for service management and registry deletion. Source available at [`main.c`](https://github.com/flamingo-stack/meshagent/blob/main/main.c).
