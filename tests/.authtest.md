Parses the local X server's authentication token by inspecting running processes for the `-auth` argument.

## Key Components

### `getAuthToken()`
Spawns a shell subprocess to run `ps` and `awk`, scanning the process list for an X server process started with a `-auth` flag. Returns the token string if found, or `null` if not.

## Usage Example

```javascript
// Run directly from the command line:
// node authtest.js

// Example output:
// AuthToken => /run/user/1000/gdm/Xauthority

const token = getAuthToken();
if (token) {
    console.log('Found X auth token:', token);
} else {
    console.log('No X auth token found in running processes.');
}
```

## Notes

- **Platform:** Linux/Unix only — relies on `/bin/sh`, `ps -e`, and `awk`
- **Mechanism:** Pipes `ps` output through `awk` to extract the user and command columns, then searches for `-auth <token>` in any X-related process arguments
- **Output:** Logs the token to stdout and exits immediately via `process.exit()`
- This is a **diagnostic/test utility**, not a library module — it executes on load and is not intended to be `require()`'d
