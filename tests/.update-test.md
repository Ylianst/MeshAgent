A self-contained test harness for validating the MeshAgent's self-update functionality. It simulates a MeshCentral server over HTTPS/WebSocket to push agent binary updates and verify the full update cycle.

## Key Components

- **`getParameterEx` / `getParameter`** — `Array.prototype` extensions for parsing CLI arguments in `--key=value` format.
- **`getCurrentUpdatePath()`** — Returns the current binary path to push, alternating between the primary and an optional alternate binary across update cycles.
- **MeshCommand constants** — Binary protocol command codes used in the WebSocket handshake and update exchange (e.g., `MeshCommand_AuthRequest`, `MeshCommand_AgentUpdate`, `MeshCommand_CoreModule`).
- **HTTPS server** — Listens on port `9250`; serves the agent binary at `GET /update` with progress logging.
- **WebSocket upgrade handler** — Manages the full binary authentication handshake (nonce exchange, SHA384 hash, RSA signature) and drives the agent update state machine.
- **`recoveryCore`** — Optionally loads `recoverycore.js` to test the JS-based update path instead of the native mechanism.

## Usage Example

```bash
# Run with elevated permissions (root/admin required)

# Basic 3-cycle update test
meshagent update-test.js --CycleCount=3

# Alternate between two binaries with random delay, using JS recoverycore
meshagent update-test.js --CycleCount=5 --AltBinary=/path/to/alt-agent --MinimumDelay=50 --MaximumDelay=500 --JS --RecoveryCore=/path/to/recoverycore

# Show all available options
meshagent update-test.js --help
```

## CLI Options

| Option | Description | Default |
|---|---|---|
| `--CycleCount=N` | Number of update cycles to run | `1` |
| `--MinimumDelay=N` | Min ms between cycles | `0` |
| `--MaximumDelay=N` | Max ms between cycles | `100` |
| `--AltBinary=path` | Alternate agent binary to alternate with | — |
| `--JS` | Use recoverycore JS update path | — |
| `--RecoveryCore=path` | Directory containing `recoverycore.js` | Current folder |

> **Note:** Requires root/elevated permissions. Source available at [`https://github.com/flamingo-stack/meshagent/blob/main/update-test.js`](https://github.com/flamingo-stack/meshagent/blob/main/update-test.js).
