Unit test suite for the `security-permissions` module, validating file permission management, ownership enforcement, and installation verification across various file types and scenarios.

## Key Components

| Function/Export | Description |
|---|---|
| `test(name, fn)` | Test runner with pass/fail tracking and stack trace output |
| `skip(name, reason)` | Marks tests as skipped with a reason |
| `assert(condition, message)` | Minimal assertion helper |
| `testsPassed / testsFailed / testsSkipped` | Global counters tracking test results |

## Test Coverage

| Test # | Scenario |
|---|---|
| 1 | Module exports all required functions and constants |
| 2 | `PERMISSIONS` definitions are correct (modes for `.msh`, `.db`, `binary`, `.log`) |
| 3 | `setSecurePermissions` fails gracefully on non-existent files |
| 4 | `setSecurePermissions` rejects unknown file types |
| 5 | Dry-run mode reports actions without modifying files |
| 6 | `setSecurePermissions` applies `0600` mode correctly |
| 7 | `verifyPermissions` detects incorrect modes |
| 8 | `verifyPermissions` accepts files with correct modes |
| 9 | `createFileSecure` creates files atomically with `0600` |
| 10–12 | `verifyInstallation` handles missing dirs, reports issues, and auto-fixes |
| 13 | `getSecurityMode` returns default `"fix"` |
| 14–15 | Path normalization and multi-file-type installation verification |
| Root-only | `chown` ownership enforcement (runs only when `process.getuid() === 0`) |

## Usage Example

```bash
# Run all tests (standard user — skips root-only tests)
node tests/security-permissions-test.js

# Run with root privileges to include ownership tests
sudo node tests/security-permissions-test.js
```

```javascript
// Inline test helper pattern used throughout the suite
test('setSecurePermissions applies correct mode', function() {
    var testFile = '/tmp/test-' + Date.now();
    fs.writeFileSync(testFile, 'data', { mode: 0o644 });

    var result = secPerms.setSecurePermissions(testFile, '.msh', { skipChown: true });

    assert(result.success === true, 'Should succeed');
    var mode = fs.statSync(testFile).mode & parseInt('777', 8);
    assert(mode === 0o600, 'Should be 0600');

    fs.unlinkSync(testFile);
});
```
