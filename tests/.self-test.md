Self-test module that initializes a minimal MSH (MeshAgent Shell) environment stub and embeds a base64-encoded JPEG image asset used for agent self-diagnostic and testing purposes.

## Key Components

- **`_MSH` function** — Stubs out the global `_MSH` factory, returning an empty object. This bootstraps the MeshAgent environment for isolated self-test execution without a full runtime.
- **`img` variable** — A base64-encoded JPEG image (`image/jpeg,base64,...`) embedded directly in the module, used as a test asset for validating image handling or agent communication payloads.

## Usage Example

```javascript
// The module sets up the _MSH global stub automatically on load
// _MSH is used internally by MeshAgent modules as an environment factory

const env = _MSH(); // Returns {}

// The embedded image can be referenced for self-test payloads
console.log(img.startsWith('image/jpeg,base64,')); // true
```
