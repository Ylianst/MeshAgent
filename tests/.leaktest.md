Interactive leak detection test harness for MeshAgent that monitors OS-level handle/resource counts while exercising IPC servers, WebSocket tunnels, child processes, and Windows-specific subsystems (WMI, registry, user sessions) via stdin commands.

## Key Components

| Export / Function | Description |
|---|---|
| `getHandleCount()` | Reads the current Windows process handle count via `kernel32.GetProcessHandleCount`; returns `0` on non-Windows |
| `startProcess()` | Spawns a child MeshAgent process and tracks it in the `processes` stack |
| `endProcess()` | Pops and kills the most recently spawned process |
| `startServer()` | Creates a named-pipe (Windows) or socket IPC server on a random port and pushes it onto the process stack |
| `startClient()` | Connects an IPC client to the most recent server; optionally pipes to a WebSocket tunnel (`global.tun`) |
| `webSocketClientTest(port)` | Opens a WebSocket client connection to a local WSS server and stores the stream in `global.tun` |
| `wmiTest()` | Creates a Windows Scheduled Task via `win-tasks` and reports handle counts before/after |
| `regTest()` | Queries a Windows registry key via `win-registry` and reports handle counts |
| `userTest()` | Resolves the current process owner and maps it to a registry user key |
| `startDispatch` / `stopDispatch` | (Partial) Windows message-dispatcher lifecycle helpers |
| `sample` / `sample2` | Duplex stream sentinels with finalizer listeners used to verify stream GC behaviour |

## Usage Example

```bash
# Run the test harness
meshagent leaktest.js
```

```text
Leak Test Started:
   server = Start IPC Server
   client = Start IPC Client
   start  = Spawn Child Process
   end    = Close spawned process
   exit   = Exit Test
   Current Handle Count => 142
```

```text
# Typical leak-detection session (type commands at the prompt)
SERVER        # start IPC server, note handle count
CLIENT        # connect client, note handle count
WSS           # start WebSocket server
WSC           # connect WebSocket client
TUNEND        # tear down tunnel, unpipe streams
GC            # trigger GC, verify handle count drops back
EXIT          # quit
```

> **Note:** Windows-only commands (`DISPATCH`, `WMI`, `REG`, `USER`, `PS`) require the `_GenericMarshal`, `win-tasks`, `win-registry`, and `win-virtual-terminal` native modules bundled with MeshAgent.
