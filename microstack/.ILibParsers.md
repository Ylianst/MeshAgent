Core parser utilities and platform abstraction header for the MicroStack networking library, providing cross-platform type definitions, semaphore wrappers, string/integer parsing helpers, memory safety polyfills, and chain lifecycle management primitives.

## Key Components

### Platform Abstraction
- **`HANDLE` / `SOCKET`** — Aliased to `int` on non-Windows platforms
- **`sem_t` wrappers** — Unified semaphore API across Windows (Event/Semaphore objects), POSIX, and macOS (GCD `dispatch_semaphore_t`)
- **`strncasecmp`, `gettimeofday`, `sprintf_s`** — POSIX polyfills for Windows; safe-string polyfills for non-Windows
- **`ILibSpinLock`** — Lightweight spinlock using `InterlockedCompareExchange` (Windows) or `__sync_bool_compare_and_swap` (GCC/Clang)
- **`ILibPtrCAST`** — `uint64_t`/`uint32_t` selected at compile time for safe pointer-to-integer casts on 32/64-bit targets

### Integer Parsing
- **`ILib_atoi_uint64_ex` / `ILib_atoi_uint32_ex` / `ILib_atoi_uint16_ex`** — Bounded string-to-integer parsers with explicit max-value enforcement
- **`ILib_atoi2_*` family** — Simpler no-error-code variants returning the parsed value directly
- Convenience macros (`ILib_atoi_uint64`, `ILib_atoi_int32`, etc.) map to the `_ex` functions with standard type limits

### String & Encoding
- **`ILibWideToUTF8Ex` / `ILibUTF8ToWideEx`** — Wide ↔ UTF-8 conversion (Windows only; no-ops on POSIX)
- **`ILibGetLocalTime`** — Formats local time into a caller-supplied buffer
- **`ILibGetTimeStamp`** — Returns a `long` timestamp

### Chain Lifecycle
- **`ILibIsChainBeingDestroyed(Chain)`** — Macro checking disposal flag
- **`ILibIsChainRunning(Chain)`** — Macro checking run state
- **`ILibIsRunningOnChainThread(chain)`** — Function verifying caller is on the chain thread
- **`ILibServerScope`** — Enum scoping server listeners (`All`, `LocalLoopback`, `LocalSegment`)
- **`ILibChain_ContinuationStates`** — Enum controlling async continuation flow

### Global Buffers
- **`ILibScratchPad[4096]`** — General-purpose scratch buffer
- **`ILibScratchPad2[65536]`** — Large scratch buffer (typically UDP packet processing)

## Usage Example

```c
#include "ILibParsers.h"

// Parse a bounded integer from a string
uint32_t port = 0;
if (ILib_atoi_uint32(&port, "8080", 4) == 0) {
    printf("Parsed port: %u\n", port);
}

// Spinlock usage
ILibSpinLock lock;
ILibSpinLock_Init(&lock);
ILibSpinLock_Lock(&lock);
// critical section
ILibSpinLock_UnLock(&lock);

// Check chain state before dispatching work
if (ILibIsChainRunning(myChain) && !ILibIsChainBeingDestroyed(myChain)) {
    // safe to enqueue work
}
```
