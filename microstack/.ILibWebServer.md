HTTP server session management and request handling API for the MicroStack embedded web server framework, providing HTTP/HTTPS and WebSocket transport capabilities.

## Key Components

### Core Types

| Type | Description |
|---|---|
| `ILibWebServer_ServerToken` | Opaque handle to a web server instance |
| `ILibWebServer_Session` | Struct holding all state for an active HTTP session |
| `ILibWebServer_Status` | Enum for send operation results (`ALL_DATA_SENT`, `NOT_ALL_DATA_SENT_YET`, `SEND_RESULTED_IN_DISCONNECT`, etc.) |
| `ILibWebServer_DoneFlag` | Enum indicating packet completion state (`Done`, `Partial`, `LastPartial`) |
| `ILibWebServer_WebSocket_DataTypes` | WebSocket frame types (`BINARY`, `TEXT`, `REQUEST`) |

### Callbacks

| Callback | Trigger |
|---|---|
| `ILibWebServer_Session_OnReceive` | Data received on a session |
| `ILibWebServer_Session_OnDisconnect` | Session disconnected |
| `ILibWebServer_Session_OnSendOK` | All pending send data flushed |
| `ILibWebServer_Session_OnSession` | New incoming session established |
| `ILibWebServer_VirtualDirectory` | Request matched a registered virtual directory |

### Key Functions

- **`ILibWebServer_CreateEx`** / **`ILibWebServer_CreateEx2`** — Create a web server instance bound to a chain, port, and connection limit
- **`ILibWebServer_RegisterVirtualDirectory`** / **`ILibWebServer_UnRegisterVirtualDirectory`** — Map URL paths to handlers
- **`ILibWebServer_Send`** / **`ILibWebServer_Send_Raw`** — Send HTTP responses
- **`ILibWebServer_UpgradeWebSocket`** — Upgrade an HTTP session to WebSocket
- **`ILibWebServer_WebSocket_Send`** / **`ILibWebServer_WebSocket_Close`** — WebSocket data transfer
- **`ILibWebServer_EnableHTTPS`** — Enable TLS with optional client certificate validation
- **`ILibWebServer_Digest_IsAuthenticated`** / **`ILibWebServer_Digest_ValidatePassword`** — HTTP Digest authentication helpers

## Usage Example

```c
// Create a web server on port 8080, max 10 connections
ILibWebServer_ServerToken server = ILibWebServer_Create(
    chain, 10, 8080, OnNewSession, NULL
);

// Register a virtual directory handler
ILibWebServer_RegisterVirtualDirectory(server, "/api", 4, OnApiRequest, NULL);

// Inside a session callback: send a raw HTTP response
void OnApiRequest(ILibWebServer_Session *session, struct packetheader *header,
                  char *body, int *begin, int end, int done, void *user)
{
    char *resp = "HTTP/1.1 200 OK\r\nContent-Length: 2\r\n\r\nOK";
    ILibWebServer_Send_Raw(session, resp, strlen(resp),
                           ILibAsyncSocket_MemoryOwnership_USER,
                           ILibWebServer_DoneFlag_Done);
}

// Upgrade to WebSocket
ILibWebServer_UpgradeWebSocket(session, 65536);
ILibWebServer_WebSocket_Send(session, "hello", 5,
    ILibWebServer_WebSocket_DataType_TEXT,
    ILibAsyncSocket_MemoryOwnership_USER,
    ILibWebServer_WebSocket_FragmentFlag_Complete);
```
