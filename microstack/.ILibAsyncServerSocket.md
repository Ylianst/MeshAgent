Async TCP server socket module providing non-blocking, event-driven server functionality for the MicroStack networking library. Manages multiple concurrent client connections with configurable callbacks for connect, disconnect, receive, and send events.

## Key Components

### Types

| Type | Description |
|---|---|
| `ILibAsyncServerSocket_ServerModule` | Opaque handle to the server module instance |
| `ILibAsyncServerSocket_ConnectionToken` | Per-session connection state (aliased from `ILibAsyncSocket_SocketModule`) |

### Callbacks

| Callback | Triggered When |
|---|---|
| `ILibAsyncServerSocket_OnConnect` | A new client connects; set a user object per session |
| `ILibAsyncServerSocket_OnDisconnect` | A client disconnects normally |
| `ILibAsyncServerSocket_OnReceive` | Data arrives; advance `p_beginPointer` to mark consumed bytes |
| `ILibAsyncServerSocket_OnInterrupt` | Session interrupted by `ILibStopChain` |
| `ILibAsyncServerSocket_OnSendOK` | Pending send backlog has been flushed |
| `ILibAsyncServerSocket_BufferReAllocated` | Receive buffer was reallocated; adjust stored pointers by `newOffset` |

### Key Functions

- **`ILibCreateAsyncServerSocketModule`** — Macro to create a server on a port with a connection limit and initial buffer size
- **`ILibCreateAsyncServerSocketModuleWithMemory`** — Extended creation with per-server and per-session mapped memory regions
- **`ILibCreateAsyncServerSocketModuleWithMemoryEx`** — Bind to a specific `sockaddr` instead of a port number
- **`ILibAsyncServerSocket_GetPortNumber`** — Retrieve the bound port
- **`ILibAsyncServerSocket_GetConnections`** — Enumerate active connection tokens
- **`ILibAsyncServerSocket_StopListening`** / **`ILibAsyncServerSocket_ResumeListening`** — Pause and resume accepting new connections
- **`ILibAsyncServerSocket_SetTag`** / **`ILibAsyncServerSocket_GetTag`** — Attach arbitrary user data to the server module

### Macros (delegate to `ILibAsyncSocket`)

- `ILibAsyncServerSocket_Send` — Write data to a session
- `ILibAsyncServerSocket_Disconnect` — Close a session
- `ILibAsyncServerSocket_GetPendingBytesToSend` / `ILibAsyncServerSocket_GetTotalBytesSent` / `ILibAsyncServerSocket_ResetTotalBytesSent`

## Usage Example

```c
void OnConnect(ILibAsyncServerSocket_ServerModule server,
               ILibAsyncServerSocket_ConnectionToken conn, void **user)
{
    printf("Client connected\n");
    *user = mySessionState; // attach session data
}

void OnReceive(ILibAsyncServerSocket_ServerModule server,
               ILibAsyncServerSocket_ConnectionToken conn,
               char *buffer, int *p_beginPointer, int endPointer,
               ILibAsyncServerSocket_OnInterrupt *onInterrupt,
               void **user, int *PAUSE)
{
    // Echo received data back
    ILibAsyncServerSocket_Send(server, conn, buffer + *p_beginPointer,
                               endPointer - *p_beginPointer,
                               ILibAsyncSocket_MemoryOwnership_USER);
    *p_beginPointer = endPointer; // mark all bytes consumed
}

void OnDisconnect(ILibAsyncServerSocket_ServerModule server,
                  ILibAsyncServerSocket_ConnectionToken conn, void *user) {}
void OnInterrupt(ILibAsyncServerSocket_ServerModule server,
                 ILibAsyncServerSocket_ConnectionToken conn, void *user) {}
void OnSendOK(ILibAsyncServerSocket_ServerModule server,
              ILibAsyncServerSocket_ConnectionToken conn, void *user) {}

// Create a server on port 8080, max 10 connections, 4KB initial buffer
ILibAsyncServerSocket_ServerModule srv = ILibCreateAsyncServerSocketModule(
    chain, 10, 8080, 4096, 0,
    OnConnect, OnDisconnect, OnReceive, OnInterrupt, OnSendOK);
```

> **Receive buffer contract:** Always advance `*p_beginPointer` by the number of bytes consumed. Unconsumed bytes remain in the buffer; if none are consumed and more data arrives, the buffer grows automatically.
