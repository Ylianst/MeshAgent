A file-backed key-value store implementing a hash table with SHA-384 integrity verification, automatic compaction, and optional in-memory caching.

## Key Components

### Types
- **`ILibSimpleDataStore`** — Opaque handle (`void*`) representing a store instance
- **`ILibSimpleDataStore_KeyEnumerationHandler`** — Callback for key iteration
- **`ILibSimpleDataStore_SizeWarningHandler`** — Callback triggered when store exceeds a size limit
- **`ILibSimpleDataStore_WriteErrorHandler`** — Callback invoked on write failures
- **`ILibSimpleDataStore_GetValuesHandler`** — Callback for iterating cached values

### Constants
| Constant | Value | Description |
|---|---|---|
| `ILibSimpleDataStore_MaxKeyLength` | `1024` | Maximum key length in bytes |
| `ILibSimpleDataStore_MaxUnspecifiedValueLen` | `16384` | Default max value length |
| `ILibSimpleDataStore_MaxFilePath` | `4096` | Maximum file path length |

### Core Functions

| Function / Macro | Description |
|---|---|
| `ILibSimpleDataStore_Create(filePath)` | Open or create a store at `filePath` |
| `ILibSimpleDataStore_CreateCachedOnly()` | Create an in-memory-only store |
| `ILibSimpleDataStore_Close(ds)` | Flush and close the store |
| `ILibSimpleDataStore_Put(ds, key, value)` | Write a key-value pair |
| `ILibSimpleDataStore_Get(ds, key, buf, len)` | Read a value by key |
| `ILibSimpleDataStore_GetInt(ds, key, default)` | Read an integer value with fallback |
| `ILibSimpleDataStore_GetHash(ds, key)` | Retrieve stored SHA-384 hash for a key |
| `ILibSimpleDataStore_Delete(ds, key)` | Remove a key |
| `ILibSimpleDataStore_EnumerateKeys(ds, cb, user)` | Iterate all keys via callback |
| `ILibSimpleDataStore_Compact(ds)` | Compact the file, reclaiming dirty space |
| `ILibSimpleDataStore_Lock / UnLock(ds)` | Thread-safety primitives |
| `ILibSimpleDataStore_ConfigSizeLimit(ds, size, cb, user)` | Set size warning threshold |
| `ILibSimpleDataStore_ConfigCompact(ds, minDirtySize)` | Configure auto-compaction trigger |

## Usage Example

```c
// Open store, write, read, then close
ILibSimpleDataStore ds = ILibSimpleDataStore_Create("/var/data/mystore.db");

if (ds != NULL) {
    // Write a value
    ILibSimpleDataStore_Put(ds, "hostname", "agent.local");

    // Read back
    char buf[256];
    int len = ILibSimpleDataStore_Get(ds, "hostname", buf, sizeof(buf));
    if (len > 0) {
        printf("hostname: %.*s\n", len, buf);
    }

    // Enumerate all keys
    ILibSimpleDataStore_EnumerateKeys(ds,
        [](ILibSimpleDataStore sender, char* key, int keyLen, void* user) {
            printf("Key: %.*s\n", keyLen, key);
        }, NULL);

    // Delete a key
    ILibSimpleDataStore_Delete(ds, "hostname");

    ILibSimpleDataStore_Close(ds);
}
```
