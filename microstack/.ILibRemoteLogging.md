Remote logging module header for MeshAgent that provides structured, module-aware diagnostic logging with support for remote transport, file output, and command dispatch. All functionality is conditionally compiled via the `_REMOTELOGGING` preprocessor flag — when disabled, all macros become no-ops with zero runtime overhead.

## Key Components

### Enumerations

| Type | Purpose |
|---|---|
| `ILibRemoteLogging_Modules` | Bitmask identifying the subsystem emitting a log entry (WebRTC, KVM, AsyncSocket, etc.) |
| `ILibRemoteLogging_Flags` | Verbosity levels 1–5 plus a disable flag |
| `ILibRemoteLogging_Command_Logger_Flags` | File transport control: enable, reset, read, and reconfigure |

### Callbacks

- `ILibRemoteLogging_OnWrite` — invoked when a log entry is ready for output
- `ILibRemoteLogging_OnCommand` — invoked when a remote command targets a specific module
- `ILibRemoteLogging_OnRawForward` — invoked for raw binary forwarding to an alternate sink

### Core Functions (active when `_REMOTELOGGING` is defined)

| Function | Description |
|---|---|
| `ILibRemoteLogging_Create` | Allocates a logger instance bound to an output callback |
| `ILibRemoteLogging_CreateFileTransport` | Attaches a file-backed transport for a given module/flag set |
| `ILibRemoteLogging_printf` | Formats and emits a log message for a module at a verbosity level |
| `ILibRemoteLogging_RegisterCommandSink` | Registers a command handler for a specific module |
| `ILibRemoteLogging_Dispatch` | Routes an incoming raw log packet to the appropriate command sink |
| `ILibRemoteLogging_Forward` | Forwards raw log data through the raw-forward callback |
| `ILibRemoteLogging_IsModuleSet` | Checks whether a module is currently active |
| `ILibRemoteLogging_Destroy` | Frees all logger resources |

## Usage Example

```c
// Create logger with a custom write callback
void myWriter(ILibRemoteLogging module, char* data, int dataLen, void *ctx) {
    fwrite(data, 1, dataLen, stdout);
}

ILibRemoteLogging logger = ILibRemoteLogging_Create(myWriter);

// Emit a log entry for the WebRTC STUN/ICE module at verbosity level 1
ILibRemoteLogging_printf(
    logger,
    ILibRemoteLogging_Modules_WebRTC_STUN_ICE,
    ILibRemoteLogging_Flags_VerbosityLevel_1,
    "ICE candidate gathered: %s",
    ILibRemoteLogging_ConvertAddress(addr)
);

// Attach a file transport
ILibRemoteLogging_CreateFileTransport(
    logger,
    ILibRemoteLogging_Modules_Agent_P2P,
    ILibRemoteLogging_Flags_VerbosityLevel_2,
    "/var/log/meshagent.log", 22
);

ILibRemoteLogging_Destroy(logger);
```
