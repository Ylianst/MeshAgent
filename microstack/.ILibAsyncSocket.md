Async TCP client socket module for the MicroStack networking library, providing non-blocking TCP connection management with optional TLS/SSL support.

## Key Components

### Types & Enumerations

| Type | Description |
|------|-------------|
| `ILibAsyncSocket_SocketModule` | Opaque handle (`void*`) representing a socket instance |
| `ILibAsyncSocket_SendStatus` | Enum indicating send result: `ALL_DATA_SENT`, `NOT_ALL_DATA_SENT_YET`, `SEND_ON_CLOSED_SOCKET_ERROR`, `BUFFER_TOO_LARGE` |
| `ILibAsyncSocket_MemoryOwnership` | Enum controlling buffer lifetime: `CHAIN`, `STATIC`, `USER`, or `BIO` (TLS) |
| `ILibAsyncSocket_TLS_Mode` | TLS role: `Client`, `Server`, or `Server_with_TLSDetectLogic` |

### Callbacks

| Callback | Triggered When |
|----------|---------------|
| `ILibAsyncSocket_OnData` | Data arrives on the socket |
| `ILibAsyncSocket_OnConnect` | Connection is established or fails |
| `ILibAsyncSocket_OnDisconnect` | Connection closes normally |
| `ILibAsyncSocket_OnSendOK` | Queued (partial) sends complete |
| `ILibAsyncSocket_OnInterrupt` | Chain is stopped mid-session |
| `ILibAsyncSocket_OnBufferReAllocated` | Internal receive buffer is resized |

### Key Functions

- **`ILibCreateAsyncSocketModule`** — Create a socket module and attach it to a chain
- **`ILibAsyncSocket_ConnectTo`** — Initiate a TCP connection to a remote address
- **`ILibAsyncSocket_Send`** — Macro to send data (wraps `ILibAsyncSocket_SendTo_MultiWrite`)
- **`ILibAsyncSocket_Disconnect`** — Close the connection
- **`ILibAsyncSocket_UseThisSocket`** — Adopt an existing OS socket handle
- **`ILibAsyncSocket_SetSSLContextEx`** — Attach an OpenSSL `SSL_CTX` for TLS
- **`ILibAsyncSocket_GetUser` / `SetUser`** — Attach custom user data to the socket

## Usage Example

```c
// Data received callback
void OnData(ILibAsyncSocket_SocketModule mod, char *buffer,
            int *begin, int end,
            ILibAsyncSocket_OnInterrupt *interrupt, void **user, int *pause)
{
    // Process buffer[*begin .. end]
    *begin = end; // mark all bytes consumed
}

void OnConnect(ILibAsyncSocket_SocketModule mod, int connected, void *user)
{
    if (connected) {
        const char *msg = "Hello";
        ILibAsyncSocket_Send(mod, (char*)msg, strlen(msg),
                             ILibAsyncSocket_MemoryOwnership_STATIC);
    }
}

void OnDisconnect(ILibAsyncSocket_SocketModule mod, void *user) { }
void OnSendOK(ILibAsyncSocket_SocketModule mod, void *user) { }

// Setup
ILibAsyncSocket_SocketModule sock = ILibCreateAsyncSocketModule(
    chain, 4096, OnData, OnConnect, OnDisconnect, OnSendOK);

ILibAsyncSocket_ConnectTo(sock, localAddr, remoteAddr, NULL, myUserData);
```
