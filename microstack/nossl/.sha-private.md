Private internal header defining the core bitwise helper macros used in SHA hash computations, as specified by FIPS-180-2 and RFC 4634.

## Key Components

| Macro | Description |
|---|---|
| `SHA_Ch(x, y, z)` | "Choice" function — selects bits from `y` where `x` is 1, from `z` where `x` is 0 |
| `SHA_Maj(x, y, z)` | "Majority" function — outputs 1 where at least two of the three inputs are 1 |
| `SHA_Parity(x, y, z)` | XOR of all three inputs; used in SHA-1 round functions |

Two implementations of `SHA_Ch` and `SHA_Maj` are provided:

- **Default (FIPS-180-2 canonical):** Uses the standard XOR/AND/NOT form.
- **`USE_MODIFIED_MACROS`:** Potentially faster equivalent form using fewer NOT operations.

## Usage Example

```c
/* Internal SHA round function usage (simplified) */
#include "sha-private.h"

uint32_t e = 0xABCDEF01, f = 0x12345678, g = 0x9ABCDEF0;

/* Choice: selects bits from f or g based on e */
uint32_t ch  = SHA_Ch(e, f, g);

/* Majority: bit-level majority vote */
uint32_t maj = SHA_Maj(e, f, g);

/* Parity: XOR of three values (SHA-1 rounds) */
uint32_t par = SHA_Parity(e, f, g);

/* Enable optimized macros at compile time */
// gcc -DUSE_MODIFIED_MACROS sha_impl.c
```

> **Note:** This is an internal header not intended for direct use by application code. It is sourced from the [Yubico C client](https://github.com/Yubico/yubico-c-client) and guards against double-inclusion via `_SHA_PRIVATE__H`.
