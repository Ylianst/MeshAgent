Header file defining the SHA-1 cryptographic hash algorithm interface, providing data structures and function declarations for computing SHA-1 digests used in message authentication and integrity verification.

## Key Components

| Component | Type | Description |
|---|---|---|
| `HASH_LENGTH` | Macro | SHA-1 digest size (20 bytes / 160 bits) |
| `BLOCK_LENGTH` | Macro | SHA-1 block size (64 bytes / 512 bits) |
| `sha1nfo` / `SHA_CTX` | Struct/Typedef | Internal SHA-1 context holding buffer, state, and HMAC fields |
| `sha1_write()` | Function | Feeds input data into the SHA-1 context incrementally |
| `sha1_result()` | Function | Finalizes computation and returns the 20-byte digest pointer |
| `SHA1_Init()` | Function | Initializes a `SHA_CTX` context for a new hash operation |
| `SHA1_Update` | Macro | OpenSSL-compatible alias for `sha1_write()` |
| `SHA1_Final` | Macro | OpenSSL-compatible alias that copies the result via `memcpy` |

## Usage Example

```c
#include "sha1.h"
#include <stdio.h>

int main(void) {
    SHA_CTX ctx;
    uint8_t digest[HASH_LENGTH];
    const char *msg = "hello world";

    /* Initialize, feed data, finalize */
    SHA1_Init(&ctx);
    SHA1_Update(&ctx, msg, 11);
    SHA1_Final(digest, &ctx);

    /* Print raw digest bytes */
    for (int i = 0; i < HASH_LENGTH; i++) {
        printf("%02x", digest[i]);
    }
    printf("\n");
    return 0;
}
```

The `SHA1_Update` / `SHA1_Final` macros mirror the OpenSSL API, making this implementation a drop-in replacement in codebases that target that interface.

> **Note:** SHA-1 is considered cryptographically weak for security-sensitive use cases (e.g., digital signatures). Use SHA-256 or stronger for new security-critical code.
