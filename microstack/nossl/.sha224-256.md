RFC 4634-compliant implementation of the SHA-224 and SHA-256 cryptographic hash algorithms, derived from the Yubico C client library. Provides context-based incremental hashing with support for both byte-aligned and sub-byte message inputs.

## Key Components

### Public Functions

| Function | Description |
|---|---|
| `SHA224Reset` | Initializes a `SHA224Context` with SHA-224 initial hash values |
| `SHA224Input` | Feeds byte-aligned data into the SHA-224 context |
| `SHA224FinalBits` | Appends 1–7 trailing bits to the SHA-224 message |
| `SHA224Result` | Finalizes and returns the 28-byte (224-bit) digest |
| `SHA256Reset` | Initializes a `SHA256Context` with SHA-256 initial hash values |
| `SHA256Input` | Feeds byte-aligned data into the SHA-256 context |
| `SHA256FinalBits` | Appends 1–7 trailing bits to the SHA-256 message |
| `SHA256Result` | Finalizes and returns the 32-byte (256-bit) digest |

### Internal Helpers

- **`SHA224_256Reset`** — Shared reset logic; accepts the appropriate initial hash vector (`SHA224_H0` or `SHA256_H0`)
- **`SHA224_256ProcessMessageBlock`** — Core 64-round compression function operating on 512-bit blocks
- **`SHA224_256PadMessage`** — Applies FIPS-180-2 padding (0x80 byte + zero fill + 64-bit length)
- **`SHA224_256Finalize`** — Calls pad, clears sensitive message buffer, marks context as computed
- **`SHA224_256ResultN`** — Extracts `n` bytes from the intermediate hash state into the output array

### Key Macros

- `SHA256_ROTR` / `SHA256_ROTL` / `SHA256_SHR` — Bitwise rotate/shift primitives
- `SHA256_SIGMA0/1`, `SHA256_sigma0/1` — FIPS-180-2 schedule and compression functions
- `SHA224_256AddLength` — 64-bit length accumulator with overflow/corruption detection

## Usage Example

```c
#include "sha.h"

/* Compute a SHA-256 digest */
SHA256Context ctx;
uint8_t digest[SHA256HashSize];
const uint8_t *data = (const uint8_t *)"hello world";

SHA256Reset(&ctx);
SHA256Input(&ctx, data, 11);
SHA256Result(&ctx, digest);

/* Compute a SHA-224 digest */
SHA224Context ctx224;
uint8_t digest224[SHA224HashSize];

SHA224Reset(&ctx224);
SHA224Input(&ctx224, data, 11);
SHA224Result(&ctx224, digest224);
```

> **Note:** Both `SHA224Input` and `SHA256Input` may be called multiple times before `Result` to hash streaming or chunked data.
