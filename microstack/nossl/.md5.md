Public-domain, OpenSSL-compatible MD5 Message-Digest Algorithm header (RFC 1321), transparently delegating to OpenSSL's `<openssl/md5.h>` when available.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `MD5_u32plus` | Portable alias for any 32-bit or wider unsigned integer (`unsigned int`) |
| `MD5_CTX` | MD5 context struct holding running state: bit-length counters (`lo`, `hi`), digest registers (`a`, `b`, `c`, `d`), input `buffer[64]`, and working `block[16]` |

### Functions

| Function | Description |
|----------|-------------|
| `MD5_Init(ctx)` | Initializes an `MD5_CTX` to its starting state |
| `MD5_Update(ctx, data, size)` | Feeds `size` bytes of `data` into the running digest |
| `MD5_Final(result, ctx)` | Finalizes the digest and writes the 16-byte MD5 hash into `result` |

## Usage Example

```c
#include "md5.h"
#include <stdio.h>

int main(void) {
    MD5_CTX ctx;
    unsigned char digest[16];
    const char *msg = "hello world";

    MD5_Init(&ctx);
    MD5_Update(&ctx, msg, 11);
    MD5_Final(digest, &ctx);

    for (int i = 0; i < 16; i++)
        printf("%02x", digest[i]);
    printf("\n"); /* 5eb63bbbe01eeed093cb22bb8f5acdc3 */
    return 0;
}
```

> **Note:** When `HAVE_OPENSSL` is defined at compile time, this header defers entirely to `<openssl/md5.h>`, ensuring drop-in compatibility with OpenSSL-linked projects.
