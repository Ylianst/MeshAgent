SHA/HMAC cryptographic hash interface header implementing FIPS PUB 180-1/180-2 algorithms (SHA-1, SHA-224, SHA-256, SHA-384, SHA-512) and RFC 2104 HMAC, sourced from the [Yubico C client library](https://github.com/Yubico/yubico-c-client).

## Key Components

### Return Codes
| Code | Meaning |
|------|---------|
| `shaSuccess` | Operation completed successfully |
| `shaNull` | Null pointer parameter passed |
| `shaInputTooLong` | Input data exceeds limit |
| `shaStateError` | Invalid call sequence |
| `shaBadParam` | Invalid parameter |

### Context Structures
- **`SHA1Context`** — State for SHA-1 (160-bit) hashing
- **`SHA256Context`** — State for SHA-256/SHA-224 (256/224-bit) hashing
- **`SHA512Context`** — State for SHA-512/SHA-384 (512/384-bit); supports `USE_32BIT_ONLY` compile flag
- **`SHA224Context`** / **`SHA384Context`** — Aliases to SHA-256/SHA-512 contexts respectively
- **`USHAContext`** — Unified context wrapping all SHA variants via a union
- **`HMACContext`** — HMAC state holding a `USHAContext` and outer padding buffer

### Function Families
Each SHA variant exposes four operations: `Reset`, `Input`, `FinalBits`, and `Result`. Unified (USHA) wrappers dispatch dynamically via `SHAversion`. HMAC is available as a one-shot call (`hmac`) or streaming interface (`hmacReset` / `hmacInput` / `hmacFinalBits` / `hmacResult`).

## Usage Example

```c
#include "sha.h"

/* One-shot HMAC-SHA256 */
uint8_t digest[USHAMaxHashSize];
const unsigned char *msg = (const unsigned char *)"hello";
const unsigned char *key = (const unsigned char *)"secret";

int rc = hmac(SHA256, msg, 5, key, 6, digest);
if (rc != shaSuccess) {
    /* handle error */
}

/* Streaming SHA-256 */
SHA256Context ctx;
uint8_t hash[SHA256HashSize];

SHA256Reset(&ctx);
SHA256Input(&ctx, (const uint8_t *)"part1", 5);
SHA256Input(&ctx, (const uint8_t *)"part2", 5);
SHA256Result(&ctx, hash);
```

> **Note:** Defined in [`sha.h`](https://github.com/flamingo-stack/meshagent/blob/main/sha.h). The `SHA512Context` layout changes when compiled with `-DUSE_32BIT_ONLY` for platforms without native 64-bit integer support.
