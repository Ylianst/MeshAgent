Implementation of SHA-384 and SHA-512 cryptographic hash functions per FIPS PUB 180-2, including a 32-bit-only compatibility mode that emulates 64-bit arithmetic using paired 32-bit word arrays.

## Key Components

### Macros (32-bit mode, `USE_32BIT_ONLY`)

| Macro | Purpose |
|---|---|
| `SHA512_SHR` / `SHA512_SHL` | 64-bit logical shift right/left using two 32-bit words |
| `SHA512_OR` / `SHA512_XOR` / `SHA512_AND` | 64-bit bitwise operations |
| `SHA512_TILDA` | 64-bit bitwise NOT |
| `SHA512_ADD` / `SHA512_ADDTO2` / `SHA512_ADDTO4` | 64-bit and 128-bit addition with carry propagation |
| `SHA512_ROTR` | 64-bit rotate right |
| `SHA512_SIGMA0` / `SHA512_SIGMA1` | Upper-case Σ compression functions |
| `SHA512_sigma0` / `SHA512_sigma1` | Lower-case σ message schedule functions |
| `SHA_Ch` / `SHA_Maj` | Choice and Majority logical functions (FIPS-180-2 §4.1.3) |
| `SHA384_512AddLength` | Accumulates processed message length with corruption detection |

### Static Functions (prototyped)

- `SHA384_512Reset` — Initializes context with algorithm-specific IV constants
- `SHA384_512ProcessMessageBlock` — Core 80-round compression function
- `SHA384_512Finalize` — Applies padding and extracts digest
- `SHA384_512PadMessage` — Appends FIPS-compliant length-encoded padding
- `SHA384_512ResultN` — Copies `HashSize` bytes of digest into output buffer

### Initial Hash Values

- `SHA384_H0` — 16 × `uint32_t` constants for SHA-384 IV (FIPS-180-2 §5.3.3)
- `SHA512_H0` — 16 × `uint32_t` constants for SHA-512 IV (FIPS-180-2 §5.3.4)

## Usage Example

```c
#include "sha.h"

/* Compute a SHA-512 digest */
SHA512Context ctx;
uint8_t digest[SHA512HashSize];
const char *msg = "hello";

SHA512Reset(&ctx);
SHA512Input(&ctx, (const uint8_t *)msg, strlen(msg));
SHA512Result(&ctx, digest);

/* Compute a SHA-384 digest */
SHA384Context ctx384;
uint8_t digest384[SHA384HashSize];

SHA384Reset(&ctx384);
SHA384Input(&ctx384, (const uint8_t *)msg, strlen(msg));
SHA384Result(&ctx384, digest384);
```

> **Portability note:** Define `USE_32BIT_ONLY` at compile time on platforms without native 64-bit integer support. The 32-bit emulation path represents each 64-bit word as a two-element `uint32_t` array and implements all arithmetic via the macros above.
