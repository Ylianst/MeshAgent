Header file defining the WebRTC, STUN/ICE, SCTP, and TURN protocol interfaces for the Microstack networking library, enabling peer-to-peer data channel communication with NAT traversal support.

## Key Components

### Enumerations

| Enum | Purpose |
|---|---|
| `ILibStun_Results` | NAT type detection results (Full Cone, Symmetric, Restricted, etc.) |
| `ILibWebRTC_TURN_ConnectFlags` | TURN relay mode: disabled, enabled, or always-relay |
| `ILibWebRTC_DataChannel_ReliabilityModes` | SCTP reliability modes (reliable, unordered, partial-reliable timed/rexmit) |
| `ILibWebRTC_DataChannel_CloseStatus` | Data channel close operation result codes |

### STUN & ICE Methods

- `ILibStunClient_Start` — Initializes the STUN/ICE client on a given chain and port
- `ILibStunClient_PerformNATBehaviorDiscovery` — Detects NAT type via RFC5780
- `ILibStun_SetIceOffer` / `ILibStun_SetIceOffer2` — Process incoming ICE offers and generate answers
- `ILibStun_GenerateIceOffer` — Creates a local ICE offer with credentials

### ORTC Methods

- `ILibORTC_GetLocalParameters` — Retrieves local ICE/DTLS credentials and certificate hash
- `ILibORTC_SetRemoteParameters` — Configures remote ICE/DTLS parameters
- `ILibORTC_AddRemoteCandidate` — Adds a remote ICE candidate

### WebRTC Data Channel Methods

- `ILibWebRTC_OpenDataChannel` — Opens a new SCTP data channel by stream ID
- `ILibWebRTC_CloseDataChannel` / `ILibWebRTC_CloseDataChannel_ALL` — Closes one or all data channels
- `ILibWebRTC_SetCallbacks` — Registers handlers for channel open, close, ACK, and offer-updated events

### SCTP Methods

- `ILibSCTP_Send` / `ILibSCTP_SendEx` — Sends data over a specific SCTP stream
- `ILibSCTP_Pause` / `ILibSCTP_Resume` — Flow control for SCTP sessions
- `ILibSCTP_SetUser` through `ILibSCTP_SetUser4` — Attach up to four user state values to a session

### TURN Methods

- `ILibStun_GetTurnClient` — Retrieves the TURN client module handle
- Callback typedefs for: connect, allocate, refresh, permission, data indication, and channel binding

## Usage Example

```c
// Start STUN client and begin ICE negotiation
void* stunModule = ILibStunClient_Start(chain, 0, OnStunResult);
ILibStunClient_SetOptions(stunModule, sslCtx, certThumbprint);

// Register WebRTC data channel callbacks
ILibWebRTC_SetCallbacks(stunModule,
    OnDataChannel,
    OnDataChannelClosed,
    OnDataChannelAck,
    OnOfferUpdated);

// Generate a local ICE offer
char* offer = NULL;
int offerLen = ILibStun_GenerateIceOffer(stunModule, &offer, "user", "pass");

// After receiving remote offer, set it and get the answer
char* answer = NULL;
ILibStun_SetIceOffer(stunModule, remoteOffer, remoteOfferLen, &answer);

// Open a data channel on stream 1
ILibWebRTC_OpenDataChannel(stunModule, 1, "control", 7);

// Send data over SCTP stream
ILibSCTP_Send(sctpSession, 1, buffer, bufferLen);
```
