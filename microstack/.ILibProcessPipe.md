Cross-platform MicroStack API header for managing child processes and named/anonymous pipes, providing spawn, I/O, and lifecycle control across Windows and POSIX platforms.

## Key Components

### Types & Handles
- `ILibProcessPipe_Manager` — opaque handle for the pipe manager (chain-attached)
- `ILibProcessPipe_Process` — opaque handle representing a spawned child process
- `ILibProcessPipe_Pipe` — opaque handle for a readable/writable pipe endpoint

### Callbacks
| Callback | Trigger |
|---|---|
| `ILibProcessPipe_Process_OutputHandler` | Data received on stdout/stderr |
| `ILibProcessPipe_Process_SendOKHandler` | Pipe write buffer drained |
| `ILibProcessPipe_Process_ExitHandler` | Child process exited |
| `ILibProcessPipe_Pipe_ReadHandler` | Data available on a raw pipe |
| `ILibProcessPipe_Pipe_BrokenPipeHandler` | Pipe connection broken |

### Spawn Types (`ILibProcessPipe_SpawnTypes`)
Controls process context: `DEFAULT`, `USER`, `WINLOGON`, `TERM`, `DETACHED`, `SPECIFIED_USER`, `POSIX_DETACHED`.

### Core Functions
- `ILibProcessPipe_Manager_Create` — attach a pipe manager to a MicroStack chain
- `ILibProcessPipe_Manager_SpawnProcessEx4` — spawn a child process with full control over type, session, and environment (use convenience macros for simpler calls)
- `ILibProcessPipe_Process_AddHandlers` — register stdout/stderr/exit/sendOK callbacks
- `ILibProcessPipe_Process_WriteStdIn` / `ILibProcessPipe_Process_CloseStdIn` — write to or close the child's stdin
- `ILibProcessPipe_Process_SoftKill` / `ILibProcessPipe_Process_HardKill` — graceful or forced termination
- `ILibProcessPipe_Pipe_Write` / `ILibProcessPipe_Pipe_AddPipeReadHandler` — raw pipe I/O
- `ILibProcessPipe_Pipe_Pause` / `ILibProcessPipe_Pipe_Resume` — flow control on a pipe reader
- `ILibProcessPipe_Pipe_CreateFromExisting` — wrap an existing OS handle/fd as a managed pipe

## Usage Example

```c
// Create manager and spawn a child process
ILibProcessPipe_Manager mgr = ILibProcessPipe_Manager_Create(chain);

char *args[] = { "/bin/sh", "-c", "echo hello", NULL };
ILibProcessPipe_Process proc = ILibProcessPipe_Manager_SpawnProcess(
    mgr, "/bin/sh", args
);

// Register I/O and exit handlers
ILibProcessPipe_Process_AddHandlers(
    proc,
    4096,
    onExit,    // ILibProcessPipe_Process_ExitHandler
    onStdOut,  // ILibProcessPipe_Process_OutputHandler
    onStdErr,  // ILibProcessPipe_Process_OutputHandler
    onSendOK,  // ILibProcessPipe_Process_SendOKHandler
    userData
);

// Write to stdin
ILibProcessPipe_Process_WriteStdIn(
    proc, "input\n", 6, ILibTransport_MemoryOwnership_USER
);
ILibProcessPipe_Process_CloseStdIn(proc);
```
