Monitors network interface IP address changes and notifies registered callbacks when the host's IP address configuration changes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ILibIPAddressMonitor` | `typedef void*` | Opaque handle representing a monitor instance |
| `ILibIPAddressMonitor_Handler` | `typedef` (function pointer) | Callback signature invoked on IP address change events |
| `ILibMemory_IPAddressMonitor_CONTAINER_SIZE` | `extern int` | Pre-allocated memory container size for the monitor object |
| `ILibIPAddressMonitor_Create` | Function | Creates and registers a new IP address monitor on an ILib chain |

### `ILibIPAddressMonitor_Handler` Signature

```c
void handler(ILibIPAddressMonitor sender, void *user);
```

| Parameter | Description |
|-----------|-------------|
| `sender` | The monitor instance that triggered the event |
| `user` | Arbitrary user-provided context pointer |

## Usage Example

```c
#include "ILibIPAddressMonitor.h"

void OnIPAddressChanged(ILibIPAddressMonitor sender, void *user)
{
    // React to IP address change (e.g., rebind sockets, notify peers)
    printf("IP address change detected\n");
}

void SetupMonitor(void *chain)
{
    void *myContext = NULL; // optional user context

    ILibIPAddressMonitor monitor = ILibIPAddressMonitor_Create(
        chain,
        OnIPAddressChanged,
        myContext
    );

    // Monitor is now active; callbacks fire on IP address changes
    // Lifetime is managed by the ILib chain
}
```

## Notes

- The monitor integrates with the ILib microstack chain and follows its lifecycle — no explicit teardown is required.
- `ILibMemory_IPAddressMonitor_CONTAINER_SIZE` is used internally for pre-allocated memory pools; consumers should not modify it directly.
- Source: [`ILibIPAddressMonitor.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibIPAddressMonitor.h)
