HTTP client module header providing MicroStack APIs for managing HTTP/HTTPS requests, WebSocket connections, and response handling in a non-blocking, pipelined architecture.

## Key Components

### Types & Handles
- **`ILibWebClient_RequestManager`** – Manages a pool of HTTP client connections (created via `ILibCreateWebClient`)
- **`ILibWebClient_StateObject`** – Represents a single HTTP client connection
- **`ILibWebClient_RequestToken`** – Handle for a specific pipelined request

### Enumerations
- **`ILibWebClient_ReceiveStatus`** – Tracks receive progress (`MoreDataToBeReceived`, `Complete`, `Partial`, `LastPartial`, `Connection_Established`)
- **`ILibWebClient_DoneCode`** – Parse completion codes including header/body size errors
- **`ILibWebClient_WebSocket_DataTypes`** – WebSocket frame types (`BINARY`, `TEXT`, `REQUEST`)

### Key Functions

| Function | Purpose |
|---|---|
| `ILibCreateWebClient(poolSize, chain)` | Creates an HTTP client manager with a connection pool |
| `ILibWebClient_PipelineRequest(...)` | Submits a pipelined HTTP request using a `packetheader` |
| `ILibWebClient_PipelineRequestEx(...)` | Raw buffer variant of pipeline request |
| `ILibWebClient_PipelineStreamedRequest(...)` | Initiates a streamed/chunked request body |
| `ILibWebClient_StreamRequestBody(...)` | Appends body data to a streamed request |
| `ILibWebClient_Pause/Resume(wcdo)` | Flow control on a connection |
| `ILibWebClient_Disconnect(wcdo)` | Closes an active connection |
| `ILibWebClient_SetTLS(...)` | Configures TLS/SSL context |
| `ILibWebClient_EnableHTTPS(...)` | Enables HTTPS with certificate pinning |
| `ILibWebClient_Parse_Range(...)` | Parses HTTP `Range` headers |

### Callbacks
- **`ILibWebClient_OnResponse`** – Invoked with received headers and body data
- **`ILibWebClient_OnSendOK`** – Fires when all pending sends complete
- **`ILibWebClient_OnDisconnect`** – Fires on session disconnect
- **`ILibWebClient_OnSslConnection`** / **`OnHttpsConnection`** – TLS validation hooks

### WebSocket Constants
Bitmask definitions for WebSocket frame parsing (`WEBSOCKET_FIN`, `WEBSOCKET_OPCODE`, `WEBSOCKET_MASK`) and opcode values (`TEXT`, `BINARY`, `CLOSE`, `PING`, `PONG`).

## Usage Example

```c
// Create an HTTP client manager attached to an event chain
ILibWebClient_RequestManager mgr = ILibCreateWebClient(5, chain);

// Define a response callback
void OnResponse(ILibWebClient_StateObject wso, int interrupt,
                struct packetheader *hdr, char *body,
                int *begin, int end,
                ILibWebClient_ReceiveStatus status,
                void *user1, void *user2, int *pause)
{
    if (ILibWebClientIsStatusOk(hdr->StatusCode) &&
        status == ILibWebClient_ReceiveStatus_Complete)
    {
        // Process complete response body
        printf("Body: %.*s\n", end - *begin, body + *begin);
    }
}

// Build and pipeline an HTTP GET request
struct packetheader *pkt = ILibCreateEmptyPacket();
ILibSetVersion(pkt, "1.1", 3);
ILibSetDirective(pkt, "GET", 3, "/index.html", 11);

ILibWebClient_RequestToken tok = ILibWebClient_PipelineRequest(
    mgr, (struct sockaddr*)&remoteAddr, pkt, OnResponse, NULL, NULL);

// Enable HTTPS if needed (requires TLS build)
ILibWebClient_EnableHTTPS(mgr, &leafCert, caCert, OnHttpsConnection);
```
