Cryptographic utilities header for the MeshAgent project, providing hashing, encoding, file I/O, and (when TLS is enabled) full certificate and public-key cryptography via OpenSSL or platform-native backends.

## Key Components

### Hash Constants

| Macro | Size |
|---|---|
| `UTIL_MD5_HASHSIZE` | 16 bytes |
| `UTIL_SHA1_HASHSIZE` | 20 bytes |
| `UTIL_SHA256_HASHSIZE` | 32 bytes |
| `UTIL_SHA384_HASHSIZE` | 48 bytes |
| `UTIL_SHA512_HASHSIZE` | 64 bytes |

### Hashing Functions

- `util_md5` / `util_md5hex` — MD5 digest (raw or hex string)
- `util_sha1` — SHA-1 digest
- `util_sha256` — SHA-256 digest
- `util_sha384` / `util_sha384file` — SHA-384 digest or file hash

### Encoding Utilities

- `util_tohex` / `util_tohex2` / `util_tohex_lower` — binary-to-hex conversion
- `util_hexToint` / `util_hexToBuf` — hex string parsing

### File I/O

- `util_writefile` / `util_appendfile` — write or append data to file
- `util_readfile` — read file into buffer (with max-length guard)
- `util_deletefile` — delete a file

### Random Data

- `util_random` — fills buffer with cryptographically random bytes
- `util_randomtext` — fills buffer with random printable text

### TLS / OpenSSL (when `MICROSTACK_NOTLS` is **not** defined)

- **`util_cert`** struct — wraps an `X509` certificate and `EVP_PKEY` private key
- `util_mkCert` / `util_mkCertEx` — generate root, TLS server, or TLS client certificates
- `util_to_p12` / `util_from_p12` — PKCS#12 serialization
- `util_to_cer` / `util_from_cer` / `util_from_pem` — DER/PEM import/export
- `util_sign` / `util_verify` — CMS/PKCS#7 sign and verify
- `util_encrypt` / `util_decrypt` — CMS envelope encrypt/decrypt
- `util_rsaencrypt` / `util_rsadecrypt` / `util_rsaverify` — raw RSA operations
- `util_certhash` / `util_keyhash` — SHA hash of certificate or public key

### No-TLS Backend (`MICROSTACK_NOTLS`)

Provides portable SHA-256/384/512, SHA-1, and MD5 context macros unified under the standard `SHA256_CTX`, `SHA256_Init`, `SHA256_Update`, `SHA256_Final` naming — backed by Windows BCrypt (`bcrypt.h`) or bundled software implementations on other platforms.

### Debug Macros

- `MSG(...)` — platform-aware debug print (stdout, Android logcat, or NaCl)
- `DEBUGSTATEMENT(x)` — conditionally compiled debug block; no-op in release builds

## Usage Example

```c
#include "ILibCrypto.h"

// SHA-256 hash of a buffer
char hash[UTIL_SHA256_HASHSIZE];
util_sha256("hello world", 11, hash);

// Hex-encode the result
char hex[UTIL_SHA256_HASHSIZE * 2 + 1];
util_tohex(hash, UTIL_SHA256_HASHSIZE, hex);

// Generate a TLS client certificate (OpenSSL build)
struct util_cert root, client;
util_from_pem("root.pem", &root);
util_mkCert(&root, &client, 2048, 365, "CN=device", CERTIFICATE_TLS_CLIENT, NULL);

char *p12data;
int p12len = util_to_p12(client, "password", &p12data);
util_freecert(&client);
```
