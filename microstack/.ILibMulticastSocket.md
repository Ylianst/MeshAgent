UDP multicast socket abstraction layer for the MeshAgent network stack, providing IPv4/IPv6 multicast group management, unicast, broadcast, Wake-on-LAN, and TTL control over async UDP sockets.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ILibMulticastSocket_Create` | Function | Creates and registers a multicast socket (IPv4/IPv6) on the async chain |
| `ILibMulticastSocket_Unicast` | Function | Sends a UDP packet to a single target address |
| `ILibMulticastSocket_BroadcastIF` | Function | Broadcasts data on a specific local network interface |
| `ILibMulticastSocket_Broadcast` | Function | Broadcasts data across all available network interfaces |
| `ILibMulticastSocket_ResetMulticast` | Function | Resets or cleans up multicast group memberships |
| `ILibMulticastSocket_WakeOnLan` | Function | Sends a Wake-on-LAN magic packet to a target MAC address |
| `ILibSetTTL` | Function | Sets the Time-To-Live value for outgoing multicast packets |

## Usage Example

```c
#include "ILibMulticastSocket.h"

void OnDataReceived(ILibAsyncUDPSocket_SocketModule socketModule,
                    char *buffer, int bufferLength,
                    struct sockaddr_in6 *remoteAddr,
                    void *user, int *PAUSE) {
    // Handle incoming multicast data
}

// Create a multicast socket bound to a chain
struct sockaddr_in mcast4 = {0};
mcast4.sin_family      = AF_INET;
mcast4.sin_port        = htons(1900);
inet_pton(AF_INET, "239.255.255.250", &mcast4.sin_addr);

void *mcSocket = ILibMulticastSocket_Create(
    chain,          // ILib chain
    4096,           // receive buffer size
    1900,           // local port
    &mcast4,        // IPv4 multicast group
    NULL,           // no IPv6 group
    OnDataReceived, // data callback
    userData,       // user context
    0               // no loopback
);

// Broadcast a discovery message on all interfaces
ILibMulticastSocket_Broadcast(mcSocket, "M-SEARCH * HTTP/1.1\r\n", 21, 1);

// Set packet TTL to limit network hops
ILibSetTTL(mcSocket, 4);
```

## Notes

- Depends on [`ILibAsyncSocket.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibAsyncSocket.h) for the underlying async UDP transport.
- The `loopback` flag on `Create` controls whether multicast packets are looped back to the sending host.
- `ILibMulticastSocket_ResetMulticast` with `cleanuponly = 1` drops group memberships without re-joining, useful during shutdown.
