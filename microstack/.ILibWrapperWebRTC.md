WebRTC wrapper API header providing the Microstack abstraction layer for creating and managing WebRTC peer connections, data channels, ICE/DTLS negotiation, and STUN/TURN configuration.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `ILibWrapper_WebRTC_ConnectionFactory` | Factory object for creating WebRTC connections |
| `ILibWrapper_WebRTC_Connection` | Encapsulates a WebRTC peer connection |
| `ILibWrapper_WebRTC_DataChannel` | Struct for peer-to-peer data channel send/receive |

### Callbacks

| Callback | Trigger |
|----------|---------|
| `ILibWrapper_WebRTC_DataChannel_OnDataChannelAck` | Remote peer ACKs data channel creation |
| `ILibWrapper_WebRTC_DataChannel_OnData` | Data received on a channel |
| `ILibWrapper_WebRTC_DataChannel_OnRawData` | Raw typed data received (51=String, 53=Binary) |
| `ILibWrapper_WebRTC_DataChannel_OnClosed` | Data channel closed |
| `ILibWrapper_WebRTC_Connection_OnConnect` | SCTP session connect/disconnect |
| `ILibWrapper_WebRTC_Connection_OnDataChannel` | New data channel established |
| `ILibWrapper_WebRTC_Connection_OnSendOK` | Send buffer flushed |

### Factory Functions

- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnectionFactory` — Create a factory with random or specified local UDP port
- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnectionFactory2` — Create a factory with explicit TLS certificate
- `ILibWrapper_WebRTC_ConnectionFactory_InitCrypto` — Deferred crypto initialization using `ILibWebWrapperWebRTC_ConnectionFactory_INIT_CRYPTO_LATER`
- `ILibWrapper_WebRTC_ConnectionFactory_SetTurnServer` — Configure TURN server with credentials
- `ILibWrapper_WebRTC_ConnectionFactory_PerformSTUN` — Perform STUN discovery

### Connection Creation

- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnection` — Create an unconnected peer connection
- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnection2` — Same, with extra memory allocation
- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnectionEx` — Create connection from an ICE offer block (MeshCentral)
- `ILibWrapper_WebRTC_ConnectionFactory_CreateConnectionEx2` — Same, with extra memory allocation

## Usage Example

```c
// Create a factory on a random UDP port
ILibWrapper_WebRTC_ConnectionFactory factory =
    ILibWrapper_WebRTC_ConnectionFactory_CreateConnectionFactory(chain, 0);

// Configure TURN server
ILibWrapper_WebRTC_ConnectionFactory_SetTurnServer(
    factory, &turnServer,
    "user", 4,
    "pass", 4,
    turnFlags
);

// Create an unconnected peer connection
ILibWrapper_WebRTC_Connection conn =
    ILibWrapper_WebRTC_ConnectionFactory_CreateConnection(
        factory,
        onConnectHandler,
        onDataChannelHandler,
        onSendOKHandler
    );

// In the data channel callback, register data handlers
dataChannel->Header.DataChannelCallbacks.OnBinaryData = myBinaryHandler;
dataChannel->Header.DataChannelCallbacks.OnStringData = myStringHandler;
dataChannel->userData = myContext;
```
