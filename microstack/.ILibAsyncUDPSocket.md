Async UDP socket module for the MicroStack networking library, providing non-blocking UDP send/receive operations with multicast, broadcast, and socket lifecycle management.

## Key Components

### Types

| Type | Description |
|---|---|
| `ILibAsyncUDPSocket_SocketModule` | Opaque handle representing a UDP socket instance |
| `ILibAsyncUDPSocket_Reuse` | Enum controlling exclusive (`0`) or shared (`1`) socket binding |
| `ILibAsyncUDPSocket_OnData` | Callback fired when UDP data is received |
| `ILibAsyncUDPSocket_OnSendOK` | Callback fired when a previously blocked send completes |

### Functions

| Function | Description |
|---|---|
| `ILibAsyncUDPSocket_CreateEx` | Creates and binds a UDP socket, attaching it to a processing chain |
| `ILibAsyncUDPSocket_JoinMulticastGroupV4/V6` | Joins an IPv4 or IPv6 multicast group |
| `ILibAsyncUDPSocket_DropMulticastGroupV4/V6` | Leaves a multicast group |
| `ILibAsyncUDPSocket_SetMulticastInterface` | Sets the outbound multicast interface |
| `ILibAsyncUDPSocket_SetMulticastTTL` | Sets multicast TTL hop limit |
| `ILibAsyncUDPSocket_SetMulticastLoopback` | Enables or disables multicast loopback |
| `ILibAsyncUDPSocket_SetBroadcast` | Enables or disables broadcast on the socket |
| `ILibAsyncUDPSocket_GetSocket` | Returns the underlying `SOCKET` handle |

### Macros (delegating to `ILibAsyncSocket`)

- `ILibAsyncUDPSocket_SendTo` — sends a UDP datagram to a remote address
- `ILibAsyncUDPSocket_GetLocalInterface` / `SetLocalInterface` — get/set the bound local address
- `ILibAsyncUDPSocket_GetLocalPort` — returns the bound port in host order
- `ILibAsyncUDPSocket_GetPendingBytesToSend` / `GetTotalBytesSent` / `ResetTotalBytesSent` — send statistics
- `ILibAsyncUDPSocket_Resume` — resumes a paused socket

## Usage Example

```c
// Data received callback
void OnUDPData(ILibAsyncUDPSocket_SocketModule mod, char *buf, int len,
               struct sockaddr_in6 *remote, void *user, void *user2, int *PAUSE)
{
    // Process received datagram
}

// Create a UDP socket bound to any interface on port 5000
struct sockaddr_in6 localAddr = {0};
localAddr.sin6_family = AF_INET6;
localAddr.sin6_port   = htons(5000);

ILibAsyncUDPSocket_SocketModule sock = ILibAsyncUDPSocket_CreateEx(
    chain, 4096,
    (struct sockaddr *)&localAddr,
    ILibAsyncUDPSocket_Reuse_SHARED,
    OnUDPData, NULL, myUserObject
);

// Send a datagram
struct sockaddr_in6 dest = { /* target address */ };
ILibAsyncUDPSocket_SendTo(sock, &dest, "hello", 5, ILibAsyncSocket_MemoryOwnership_STATIC);
```

> **Note:** The socket must be added to a chain that is not yet running when `ILibAsyncUDPSocket_CreateEx` is called. Source: [`ILibAsyncUDPSocket.h`](https://github.com/flamingo-stack/meshagent/blob/main/ILibAsyncUDPSocket.h)
