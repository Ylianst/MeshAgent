OpenSSL low-level dynamic array (stack) API header. Defines the `OPENSSL_STACK` type and its full manipulation interface; in practice, consume this indirectly via the type-safe `STACK_OF(T)` macros.

## Key Components

### Types

| Type | Description |
|---|---|
| `OPENSSL_STACK` | Opaque stack structure (`struct stack_st`) |
| `OPENSSL_sk_compfunc` | Comparator callback: `int fn(const void*, const void*)` |
| `OPENSSL_sk_freefunc` | Element destructor callback: `void fn(void*)` |
| `OPENSSL_sk_copyfunc` | Element copy callback: `void* fn(const void*)` |

### Core Functions

| Function | Description |
|---|---|
| `OPENSSL_sk_new` / `sk_new_null` / `sk_new_reserve` | Allocate a stack, optionally with a comparator or pre-reserved capacity |
| `OPENSSL_sk_reserve` | Pre-allocate capacity to avoid repeated reallocations |
| `OPENSSL_sk_push` / `sk_unshift` | Append to end / prepend to front |
| `OPENSSL_sk_pop` / `sk_shift` | Remove and return from end / front |
| `OPENSSL_sk_insert` / `sk_delete` / `sk_delete_ptr` | Insert at position; delete by index or pointer |
| `OPENSSL_sk_find` / `sk_find_ex` / `sk_find_all` | Search (exact, approximate, or count all matches) |
| `OPENSSL_sk_dup` | Shallow copy; `sk_deep_copy` for element-level copy |
| `OPENSSL_sk_pop_free` | Free stack and all elements via a destructor |
| `OPENSSL_sk_sort` / `sk_is_sorted` | Sort in-place; query sort state |
| `OPENSSL_sk_zero` | Clear all elements without freeing the stack |

Deprecated pre-1.1.0 aliases (e.g. `sk_push`, `sk_pop`) are preserved behind `OPENSSL_NO_DEPRECATED_1_1_0`.

## Usage Example

```c
#include <openssl/stack.h>

/* Prefer the type-safe macro layer in real code */
static int str_cmp(const void *a, const void *b) {
    return strcmp((const char *)a, (const char *)b);
}

OPENSSL_STACK *sk = OPENSSL_sk_new(str_cmp);

OPENSSL_sk_push(sk, "beta");
OPENSSL_sk_push(sk, "alpha");
OPENSSL_sk_sort(sk);

for (int i = 0; i < OPENSSL_sk_num(sk); i++) {
    printf("%s\n", (const char *)OPENSSL_sk_value(sk, i));
}

/* Free stack only (elements are string literals here) */
OPENSSL_sk_free(sk);
```

> **Prefer `STACK_OF(T)`** from `<openssl/safestack.h>` over raw `OPENSSL_STACK` calls to get compile-time type checking.
