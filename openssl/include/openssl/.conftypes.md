Defines the internal (now-deprecated) concrete structures for OpenSSL's configuration subsystem, exposing the previously opaque `CONF` and `CONF_METHOD` types.

## Key Components

### `struct conf_method_st` (`CONF_METHOD`)
A virtual-dispatch table for configuration backends. Contains function pointers that define how a configuration implementation:

| Field | Purpose |
|---|---|
| `name` | Human-readable backend name |
| `create` / `init` / `destroy` | Lifecycle management |
| `destroy_data` | Frees backend-specific payload |
| `load_bio` / `load` | Parses config from a `BIO` stream or named file |
| `dump` | Serializes config to a `BIO` |
| `is_number` / `to_int` | Character classification helpers |

### `struct conf_st` (`CONF`)
The runtime configuration object. Holds:

| Field | Purpose |
|---|---|
| `meth` | Pointer to the active `CONF_METHOD` vtable |
| `meth_data` | Opaque backend-private data |
| `data` | Hash table (`LHASH_OF(CONF_VALUE)`) of parsed key-value entries |
| `flag_dollarid` | Enables `$variable` expansion |
| `flag_abspath` | Forces absolute path resolution for includes |
| `includedir` | Base directory for `include` directives |
| `libctx` | Associated `OSSL_LIB_CTX` for provider/algorithm context |

## Usage Example

```c
/* Direct struct access is deprecated — use the public CONF API instead */
#include <openssl/conf.h>

CONF *cfg = NCONF_new(NULL);          /* allocates conf_st via default method */
long eline = 0;
NCONF_load(cfg, "/etc/ssl/openssl.cnf", &eline);

const char *val = NCONF_get_string(cfg, "req", "default_bits");
NCONF_free(cfg);
```

> **Deprecation notice:** Direct access to `conf_st` and `conf_method_st` fields is deprecated as of OpenSSL 3.x. These structures will become opaque in a future release. Prefer the stable `NCONF_*` / `CONF_*` public API.
