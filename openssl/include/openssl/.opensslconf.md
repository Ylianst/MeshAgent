Compatibility header that re-exports OpenSSL build configuration and macro definitions by including `openssl/configuration.h` and `openssl/macros.h`. Serves as a legacy umbrella include to maintain backward compatibility with code that includes `opensslconf.h` directly.

## Key Components

| Component | Description |
|---|---|
| `openssl/configuration.h` | Build-time configuration constants and feature flags |
| `openssl/macros.h` | OpenSSL macro definitions |
| Include guard `OPENSSL_OPENSSLCONF_H` | Prevents multiple inclusion |

## Usage Example

```c
/* Include opensslconf.h for build configuration and macros */
#include <openssl/opensslconf.h>

/* After inclusion, configuration macros are available, e.g.: */
#ifdef OPENSSL_NO_SSL3
    /* SSL 3.0 was disabled at build time */
#endif
```

> **Note:** In modern OpenSSL (3.x), prefer including `openssl/configuration.h` and `openssl/macros.h` directly. This header exists primarily for backward compatibility.
