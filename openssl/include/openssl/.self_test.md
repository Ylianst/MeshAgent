Public API header for OpenSSL's FIPS self-test framework, defining event phases, test type categories, descriptor constants, and the callback-driven interface used to monitor and intercept cryptographic self-test execution.

## Key Components

### Event Phase Constants
String constants describing the lifecycle of a test event:

| Constant | Value |
|---|---|
| `OSSL_SELF_TEST_PHASE_NONE` | `"None"` |
| `OSSL_SELF_TEST_PHASE_START` | `"Start"` |
| `OSSL_SELF_TEST_PHASE_CORRUPT` | `"Corrupt"` |
| `OSSL_SELF_TEST_PHASE_PASS` | `"Pass"` |
| `OSSL_SELF_TEST_PHASE_FAIL` | `"Fail"` |

### Test Type Constants (`OSSL_SELF_TEST_TYPE_*`)
Categories identifying the class of self-test, including module/install integrity, KATs (Known Answer Tests) for ciphers, digests, signatures, KDFs, KEM, and key agreement, plus DRBG and continuous RNG tests.

### Descriptor Constants (`OSSL_SELF_TEST_DESC_*`)
Sub-category strings identifying the specific algorithm under test (e.g., `AES_GCM`, `SHA2`, `ECDSA`, `HKDF`, `ML-DSA`, `ML-KEM`, `SLH-DSA`).

### Functions

| Function | Description |
|---|---|
| `OSSL_SELF_TEST_set_callback` | Registers a callback on a `OSSL_LIB_CTX` to receive test events |
| `OSSL_SELF_TEST_get_callback` | Retrieves the currently registered callback and argument |
| `OSSL_SELF_TEST_new` | Allocates a new self-test object bound to a callback |
| `OSSL_SELF_TEST_free` | Releases a self-test object |
| `OSSL_SELF_TEST_onbegin` | Signals the start of a test with type and descriptor |
| `OSSL_SELF_TEST_oncorrupt_byte` | Optionally corrupts a byte for negative testing; returns 0 to abort |
| `OSSL_SELF_TEST_onend` | Signals test completion with pass/fail result |

## Usage Example

```c
/* Callback to log or intercept self-test events */
static int my_self_test_cb(const OSSL_PARAM params[], void *arg)
{
    const char *phase = NULL, *type = NULL, *desc = NULL;

    OSSL_PARAM_get_utf8_string_ptr(
        OSSL_PARAM_locate_const(params, OSSL_PROV_PARAM_SELF_TEST_PHASE),
        &phase);
    OSSL_PARAM_get_utf8_string_ptr(
        OSSL_PARAM_locate_const(params, OSSL_PROV_PARAM_SELF_TEST_TYPE),
        &type);
    OSSL_PARAM_get_utf8_string_ptr(
        OSSL_PARAM_locate_const(params, OSSL_PROV_PARAM_SELF_TEST_DESC),
        &desc);

    fprintf(stderr, "Self-test: phase=%s type=%s desc=%s\n",
            phase, type, desc);
    return 1; /* returning 0 during CORRUPT phase triggers failure */
}

/* Register the callback before loading the FIPS provider */
OSSL_SELF_TEST_set_callback(libctx, my_self_test_cb, NULL);
```
