OpenSSL OBJ (Objects) API header providing ASN.1 object identifier (OID) registration, lookup, naming, and binary search utilities used throughout the OpenSSL library.

## Key Components

### Types & Constants

| Name | Description |
|---|---|
| `OBJ_NAME` | Struct holding a named object entry (`type`, `alias`, `name`, `data`) |
| `OBJ_NAME_TYPE_*` | Type constants for MD, cipher, PKEY, MAC, KDF methods |
| `OBJ_NAME_ALIAS` | Flag marking an entry as an alias (`0x8000`) |
| `OBJ_BSEARCH_VALUE_ON_NOMATCH` / `OBJ_BSEARCH_FIRST_VALUE_ON_MATCH` | Binary search behavior flags |

### OBJ_NAME Registry Functions

- `OBJ_NAME_init()` — Initialize the name registry
- `OBJ_NAME_new_index()` — Register a new name type with custom hash/compare/free callbacks
- `OBJ_NAME_get/add/remove()` — CRUD operations on named entries
- `OBJ_NAME_do_all/do_all_sorted()` — Iterate over all registered names

### NID / OID Conversion

- `OBJ_nid2obj/nid2ln/nid2sn()` — NID → ASN1_OBJECT / long name / short name
- `OBJ_obj2nid/txt2nid/ln2nid/sn2nid()` — Reverse lookups to NID
- `OBJ_txt2obj/obj2txt()` — Text string ↔ ASN1_OBJECT conversion
- `OBJ_cmp()` — Compare two ASN1_OBJECT values

### Custom OID Registration

- `OBJ_new_nid()` — Allocate new NID(s)
- `OBJ_create()` — Register a new OID with short/long name
- `OBJ_add_object()` — Add an existing ASN1_OBJECT to the table
- `OBJ_create_objects()` — Bulk-load OIDs from a BIO stream

### Signature Algorithm Helpers

- `OBJ_find_sigid_algs/find_sigid_by_algs()` — Decompose/look up combined signature NIDs
- `OBJ_add_sigid()` — Register a signature+digest+key NID triple

### Binary Search Macros

Type-safe wrappers around `OBJ_bsearch_` / `OBJ_bsearch_ex_`:

- `DECLARE_OBJ_BSEARCH_CMP_FN` / `IMPLEMENT_OBJ_BSEARCH_CMP_FN` — Static (file-local) typed bsearch
- `DECLARE_OBJ_BSEARCH_GLOBAL_CMP_FN` / `IMPLEMENT_OBJ_BSEARCH_GLOBAL_CMP_FN` — Exported typed bsearch
- `OBJ_bsearch` / `OBJ_bsearch_ex` — Convenience macros with type checking

## Usage Example

```c
#include <openssl/objects.h>

/* Look up a built-in OID by short name */
int nid = OBJ_sn2nid("SHA256");
const char *ln = OBJ_nid2ln(nid);   /* "sha256WithRSAEncryption" etc. */

/* Register a custom OID */
int my_nid = OBJ_create("1.2.3.4.5", "myShortName", "My Long Name");

/* Convert text OID string to ASN1_OBJECT */
ASN1_OBJECT *obj = OBJ_txt2obj("1.2.840.113549.1.1.11", 1 /* no_name */);
char buf[64];
OBJ_obj2txt(buf, sizeof(buf), obj, 0); /* writes dotted OID or name */
ASN1_OBJECT_free(obj);

/* Decompose a signature NID into digest + key NIDs */
int dig_nid, pkey_nid;
OBJ_find_sigid_algs(NID_sha256WithRSAEncryption, &dig_nid, &pkey_nid);
```
