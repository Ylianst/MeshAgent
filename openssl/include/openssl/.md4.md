OpenSSL MD4 message digest algorithm header, providing the interface for computing MD4 hashes. All APIs in this file are deprecated as of OpenSSL 3.0.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MD4_DIGEST_LENGTH` | Macro | Output digest size in bytes (16) |
| `MD4_CBLOCK` | Macro | Input block size in bytes (64) |
| `MD4_LBLOCK` | Macro | Block size in 32-bit words (16) |
| `MD4_LONG` | Type alias | At least 32-bit unsigned integer (`unsigned int`) |
| `MD4_CTX` | Struct | Holds MD4 incremental hashing state (registers A/B/C/D, bit counts, data buffer) |
| `MD4_Init` | Function | Initializes an `MD4_CTX` |
| `MD4_Update` | Function | Feeds data into an in-progress MD4 computation |
| `MD4_Final` | Function | Finalizes the hash and writes 16-byte digest |
| `MD4` | Function | One-shot convenience: hash a buffer, return digest pointer |
| `MD4_Transform` | Function | Processes a single 64-byte block (low-level) |

## Usage Example

```c
#include <openssl/md4.h>
#include <stdio.h>

/* All MD4 APIs are deprecated in OpenSSL 3.0+ */
int main(void) {
    const unsigned char input[] = "hello";
    unsigned char digest[MD4_DIGEST_LENGTH];

    /* One-shot hash */
    MD4(input, sizeof(input) - 1, digest);

    for (int i = 0; i < MD4_DIGEST_LENGTH; i++)
        printf("%02x", digest[i]);
    printf("\n");

    /* Incremental hashing */
    MD4_CTX ctx;
    MD4_Init(&ctx);
    MD4_Update(&ctx, input, sizeof(input) - 1);
    MD4_Final(digest, &ctx);

    return 0;
}
```

> **Warning:** MD4 is cryptographically broken and all functions are marked `OSSL_DEPRECATEDIN_3_0`. Use SHA-256 or stronger via `EVP_DigestInit_ex` for any security-sensitive application.
