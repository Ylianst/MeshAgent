OpenSSL legacy DES (Data Encryption Standard) API header, declaring types, constants, macros, and function prototypes for single and triple-DES encryption. All declarations are deprecated as of OpenSSL 3.0.

## Key Components

### Types
- **`DES_cblock`** — 8-byte DES block (`unsigned char[8]`)
- **`const_DES_cblock`** — const-compatible 8-byte block alias
- **`DES_key_schedule`** — 16-round expanded key structure (`DES_ks`)
- **`DES_LONG`** — platform word type (`unsigned int`)

### Constants / Macros
- `DES_ENCRYPT` / `DES_DECRYPT` — direction flags (`1` / `0`)
- `DES_CBC_MODE` / `DES_PCBC_MODE` — cipher mode selectors
- `DES_KEY_SZ` / `DES_SCHEDULE_SZ` — size helpers
- `DES_ecb2_encrypt`, `DES_ede2_*` — 2-key triple-DES convenience wrappers (map to 3-key variants with `k1` reused)

### Key Management Functions
- `DES_set_key_checked` / `DES_set_key_unchecked` — expand a raw key into a schedule
- `DES_set_odd_parity` — fix key parity bits
- `DES_check_key_parity` / `DES_is_weak_key` — key validation
- `DES_random_key` — generate a random DES key

### Encryption Modes
- `DES_ecb_encrypt` — Electronic Codebook
- `DES_cbc_encrypt` / `DES_ncbc_encrypt` — CBC (use `ncbc`; `cbc` does not update IV)
- `DES_ede3_cbc_encrypt` — Triple-DES CBC
- `DES_cfb_encrypt` / `DES_cfb64_encrypt` / `DES_ede3_cfb64_encrypt` — CFB variants
- `DES_ofb_encrypt` / `DES_ofb64_encrypt` / `DES_ede3_ofb64_encrypt` — OFB variants
- `DES_pcbc_encrypt` — Propagating CBC
- `DES_crypt` / `DES_fcrypt` — Unix crypt(3) wrappers

## Usage Example

```c
#include <openssl/des.h>

/* Deprecated — for legacy compatibility only */
DES_cblock key_data = {0x01,0x23,0x45,0x67,0x89,0xAB,0xCD,0xEF};
DES_cblock ivec     = {0};
DES_key_schedule ks;
unsigned char plaintext[8]  = "Hello!!";
unsigned char ciphertext[8] = {0};

DES_set_odd_parity(&key_data);
DES_set_key_checked(&key_data, &ks);

/* Encrypt one block using CBC */
DES_ncbc_encrypt(plaintext, ciphertext, 8, &ks, &ivec, DES_ENCRYPT);
```

> **⚠️ Deprecated:** All APIs in this header are marked `OSSL_DEPRECATEDIN_3_0`. Use EVP-based APIs (e.g., `EVP_EncryptInit_ex`) for new code.
