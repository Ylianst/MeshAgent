## Usage Example

These codes surface through OpenSSL's standard error API:

```c
#include <openssl/crypto.h>
#include <openssl/cryptoerr.h>
#include <openssl/err.h>

void check_error(void) {
    unsigned long err_code = ERR_get_error();

    if (ERR_GET_REASON(err_code) == CRYPTO_R_INVALID_NULL_ARGUMENT) {
        fprintf(stderr, "Null argument passed to crypto function\n");
    }

    /* Print full human-readable error string */
    ERR_print_errors_fp(stderr);
}
```
