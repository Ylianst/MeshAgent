## Key Components

### BIO Type Classes
- `BIO_TYPE_DESCRIPTOR` — socket/fd/connect/accept BIOs
- `BIO_TYPE_FILTER` — transform data in transit (SSL, MD, cipher, base64, buffer)
- `BIO_TYPE_SOURCE_SINK` — produce or consume data (mem, file, null, BIO pair)

### Control Codes (`BIO_CTRL_*`)
Integer constants passed to `BIO_ctrl()` to query or configure BIO behaviour — reset, flush, EOF detection, MTU settings, KTLS status, peer address, and SCTP parameters.

### Flags (`BIO_FLAGS_*`)
Bitmask values tracking I/O state: `BIO_FLAGS_READ`, `BIO_FLAGS_WRITE`, `BIO_FLAGS_SHOULD_RETRY`, `BIO_FLAGS_MEM_RDONLY`, `BIO_FLAGS_IN_EOF`.

### Retry Macros
Convenience wrappers around `BIO_test_flags()` / `BIO_set_flags()`:
- `BIO_should_retry(b)`, `BIO_should_read(b)`, `BIO_should_write(b)`

### Callback Event Codes (`BIO_CB_*`)
Passed to BIO callbacks on free, read, write, puts, gets, ctrl, and multi-message send/receive.

int n = BIO_read(mem, buf, sizeof(buf));

/* Check if more data is available */
