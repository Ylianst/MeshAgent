OpenSSL legacy AES low-level API header, providing direct AES key scheduling, block encryption/decryption, and multiple cipher mode operations. All declarations are deprecated as of OpenSSL 3.0 in favor of the EVP high-level interface.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `AES_BLOCK_SIZE` | `16` | AES block size in bytes (always 128-bit) |
| `AES_ENCRYPT` | `1` | Direction flag for encryption |
| `AES_DECRYPT` | `0` | Direction flag for decryption |
| `AES_MAXNR` | `14` | Maximum number of AES rounds (AES-256) |

### Types

- **`AES_KEY`** — Expanded round key structure holding `rd_key[4*(AES_MAXNR+1)]` and a `rounds` count. Size is intentionally exposed for EVP layer compatibility.

### Functions (all deprecated in OpenSSL 3.0)

| Function | Description |
|---|---|
| `AES_set_encrypt_key` | Expand a raw user key for encryption |
| `AES_set_decrypt_key` | Expand a raw user key for decryption |
| `AES_encrypt` / `AES_decrypt` | Single-block ECB operation |
| `AES_ecb_encrypt` | ECB mode (single block, direction via `enc` flag) |
| `AES_cbc_encrypt` | CBC mode with IV |
| `AES_cfb128_encrypt` / `AES_cfb1_encrypt` / `AES_cfb8_encrypt` | CFB variants (128-bit, 1-bit, 8-bit) |
| `AES_ofb128_encrypt` | OFB mode |
| `AES_ige_encrypt` | IGE mode (IV is **two** blocks) |
| `AES_bi_ige_encrypt` | Bi-directional IGE (IV is **four** blocks, requires two keys) |
| `AES_wrap_key` / `AES_unwrap_key` | RFC 3394 AES key wrapping |

## Usage Example

> ⚠️ These APIs are deprecated. Prefer `EVP_EncryptInit_ex` / `EVP_aes_256_cbc()` in new code.

```c
#include <openssl/aes.h>

/* Legacy AES-128 CBC encrypt — deprecated, for reference only */
void legacy_aes_cbc_encrypt(const unsigned char *key_bytes,
                             const unsigned char *in,
                             unsigned char *out,
                             size_t len,
                             unsigned char *iv) {
    AES_KEY aes_key;

    /* Expand key for encryption (bits = 128) */
    if (AES_set_encrypt_key(key_bytes, 128, &aes_key) != 0) {
        /* handle error */
        return;
    }

    /* Encrypt in CBC mode; iv is updated in-place */
    AES_cbc_encrypt(in, out, len, &aes_key, iv, AES_ENCRYPT);
}
```

**Modern EVP equivalent (recommended):**

```c
#include <openssl/evp.h>

EVP_CIPHER_CTX *ctx = EVP_CIPHER_CTX_new();
EVP_EncryptInit_ex(ctx, EVP_aes_128_cbc(), NULL, key_bytes, iv);
EVP_EncryptUpdate(ctx, out, &out_len, in, in_len);
EVP_EncryptFinal_ex(ctx, out + out_len, &final_len);
EVP_CIPHER_CTX_free(ctx);
```
