## Usage Example

These codes surface through the standard OpenSSL error queue. Inspect them after a failed HTTP operation:

```c
#include <openssl/http.h>
#include <openssl/err.h>
#include <openssl/httperr.h>

void check_http_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    switch (reason) {
        case HTTP_R_CONNECT_FAILURE:
            fprintf(stderr, "HTTP: connection failed\n");
            break;
        case HTTP_R_TLS_NOT_ENABLED:
            fprintf(stderr, "HTTP: TLS support not compiled in\n");
            break;
        case HTTP_R_TOO_MANY_REDIRECTIONS:
            fprintf(stderr, "HTTP: redirect loop detected\n");
            break;
        default:
            fprintf(stderr, "HTTP error code: %d\n", reason);
    }
}
```
