FIPS compliance indicator callback interface for OpenSSL, allowing applications to register and retrieve callbacks that are triggered when FIPS-approved operations are performed.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `OSSL_INDICATOR_CALLBACK` | `typedef` | Callback signature receiving operation `type`, `desc` description, and `OSSL_PARAM` array |
| `OSSL_INDICATOR_set_callback` | Function | Registers an indicator callback on a given `OSSL_LIB_CTX` |
| `OSSL_INDICATOR_get_callback` | Function | Retrieves the currently registered callback from a given `OSSL_LIB_CTX` |

## Usage Example

```c
#include <openssl/indicator.h>
#include <openssl/params.h>
#include <stdio.h>

/* Callback invoked when a FIPS indicator event occurs */
int my_indicator_cb(const char *type, const char *desc,
                    const OSSL_PARAM params[])
{
    printf("FIPS indicator: type=%s desc=%s\n", type, desc);
    /* Return 1 to allow the operation to proceed */
    return 1;
}

int main(void)
{
    OSSL_LIB_CTX *libctx = OSSL_LIB_CTX_new();
    OSSL_INDICATOR_CALLBACK *cb = NULL;

    /* Register the callback */
    OSSL_INDICATOR_set_callback(libctx, my_indicator_cb);

    /* Verify registration */
    OSSL_INDICATOR_get_callback(libctx, &cb);
    if (cb == my_indicator_cb)
        printf("Callback registered successfully.\n");

    OSSL_LIB_CTX_free(libctx);
    return 0;
}
```

## Notes

- The callback returns `int`; returning `0` typically signals rejection of the operation.
- Pass `NULL` as the callback to `OSSL_INDICATOR_set_callback` to deregister.
- Callbacks are scoped per `OSSL_LIB_CTX`, enabling per-context FIPS indicator handling in multi-tenant applications.
