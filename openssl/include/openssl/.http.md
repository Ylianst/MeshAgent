OpenSSL HTTP client API header providing both low-level and high-level interfaces for making HTTP/HTTPS requests, URL parsing, and proxy support within the OpenSSL library.

## Key Components

### Constants & Macros

| Macro | Value | Description |
|---|---|---|
| `OSSL_HTTP_PORT` | `"80"` | Default HTTP port |
| `OSSL_HTTPS_PORT` | `"443"` | Default HTTPS port |
| `OSSL_HTTP_DEFAULT_MAX_LINE_LEN` | `4096` | Max HTTP line length |
| `OSSL_HTTP_DEFAULT_MAX_RESP_LEN` | `102400` | Max response size |
| `OSSL_HTTP_DEFAULT_MAX_CRL_LEN` | `33554432` | Max CRL response size |

### Low-Level API (`OSSL_HTTP_REQ_CTX`)

- **`OSSL_HTTP_REQ_CTX_new`** / **`OSSL_HTTP_REQ_CTX_free`** — allocate/free request context
- **`OSSL_HTTP_REQ_CTX_set_request_line`** — set HTTP method, server, port, path
- **`OSSL_HTTP_REQ_CTX_add1_header`** — add custom HTTP headers
- **`OSSL_HTTP_REQ_CTX_set1_req`** — attach ASN.1-encoded request body
- **`OSSL_HTTP_REQ_CTX_nbio`** / **`OSSL_HTTP_REQ_CTX_exchange`** — non-blocking I/O and full request/response exchange
- **`OSSL_HTTP_REQ_CTX_set_max_response_length`** — cap response buffer size

### High-Level API

- **`OSSL_HTTP_open`** — open a persistent HTTP/HTTPS connection
- **`OSSL_HTTP_get`** — simple HTTP GET to a URL
- **`OSSL_HTTP_transfer`** — full request/response transfer with connection reuse
- **`OSSL_HTTP_close`** — close connection and free context
- **`OSSL_HTTP_proxy_connect`** — establish a CONNECT tunnel through a proxy

### Auxiliary

- **`OSSL_HTTP_parse_url`** / **`OSSL_parse_url`** — decompose a URL into scheme, user, host, port, path, query, fragment
- **`OSSL_HTTP_adapt_proxy`** — resolve effective proxy server respecting `no_proxy` rules
- **`OSSL_HTTP_bio_cb_t`** — callback type for BIO update on connect/disconnect

## Usage Example

```c
#include <openssl/http.h>

/* Simple HTTP GET */
BIO *resp = OSSL_HTTP_get(
    "http://example.com/resource",  /* url        */
    NULL,                           /* proxy      */
    NULL,                           /* no_proxy   */
    NULL, NULL,                     /* bio, rbio  */
    NULL, NULL,                     /* cb, arg    */
    0,                              /* buf_size   */
    NULL,                           /* headers    */
    "application/ocsp-response",    /* expected content type */
    1,                              /* expect ASN.1 */
    OSSL_HTTP_DEFAULT_MAX_RESP_LEN,
    30                              /* timeout (s) */
);

if (resp != NULL) {
    /* process response BIO */
    BIO_free(resp);
}

/* URL parsing */
char *host = NULL, *port = NULL, *path = NULL;
int port_num, use_ssl;
OSSL_HTTP_parse_url("https://example.com:8443/api",
                    &use_ssl, NULL, &host, &port,
                    &port_num, &path, NULL, NULL);
/* use_ssl=1, host="example.com", port_num=8443, path="/api" */
OPENSSL_free(host); OPENSSL_free(port); OPENSSL_free(path);
```
