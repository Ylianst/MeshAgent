OpenSSL public API header defining the HPKE (Hybrid Public Key Encryption) interface as specified in [RFC 9180](https://www.rfc-editor.org/rfc/rfc9180).

## Key Components

### Types & Structures

| Symbol | Description |
|--------|-------------|
| `OSSL_HPKE_SUITE` | Struct holding `kem_id`, `kdf_id`, and `aead_id` algorithm identifiers |
| `OSSL_HPKE_CTX` | Opaque context object for an HPKE session |
| `OSSL_HPKE_SUITE_DEFAULT` | Convenience macro: X25519 + HKDF-SHA256 + AES-128-GCM (P-256 fallback without ECX) |

### Mode Constants

`OSSL_HPKE_MODE_BASE`, `OSSL_HPKE_MODE_PSK`, `OSSL_HPKE_MODE_AUTH`, `OSSL_HPKE_MODE_PSKAUTH`

### Algorithm ID Constants

- **KEM:** `P256 (0x10)`, `P384 (0x11)`, `P521 (0x12)`, `X25519 (0x20)`, `X448 (0x21)`
- **KDF:** `HKDF-SHA256/384/512 (0x01–0x03)`
- **AEAD:** `AES-GCM-128/256 (0x01–0x02)`, `ChaCha20-Poly1305 (0x03)`, `export-only (0xFFFF)`

### Core API Functions

| Function | Purpose |
|----------|---------|
| `OSSL_HPKE_CTX_new` / `_free` | Create/destroy a sender or receiver context |
| `OSSL_HPKE_encap` | Sender: encapsulate a key against a recipient public key |
| `OSSL_HPKE_seal` | Sender: encrypt plaintext with optional AAD |
| `OSSL_HPKE_keygen` | Generate a KEM keypair |
| `OSSL_HPKE_decap` | Receiver: decapsulate the sender's encapsulated key |
| `OSSL_HPKE_open` | Receiver: decrypt ciphertext |
| `OSSL_HPKE_export` | Derive an export secret from the HPKE context |
| `OSSL_HPKE_get_grease_value` | Generate GREASE values for TLS extension padding |

## Usage Example

```c
/* Sender side */
OSSL_HPKE_SUITE suite = OSSL_HPKE_SUITE_DEFAULT;
OSSL_HPKE_CTX *sctx = OSSL_HPKE_CTX_new(OSSL_HPKE_MODE_BASE, suite,
                                          OSSL_HPKE_ROLE_SENDER,
                                          NULL, NULL);

unsigned char enc[128];
size_t enclen = sizeof(enc);
OSSL_HPKE_encap(sctx, enc, &enclen, recipient_pub, publen, info, infolen);

unsigned char ct[256];
size_t ctlen = sizeof(ct);
OSSL_HPKE_seal(sctx, ct, &ctlen, aad, aadlen, plaintext, ptlen);
OSSL_HPKE_CTX_free(sctx);

/* Receiver side */
OSSL_HPKE_CTX *rctx = OSSL_HPKE_CTX_new(OSSL_HPKE_MODE_BASE, suite,
                                          OSSL_HPKE_ROLE_RECEIVER,
                                          NULL, NULL);
OSSL_HPKE_decap(rctx, enc, enclen, recipient_priv, info, infolen);

unsigned char pt[256];
size_t ptlen = sizeof(pt);
OSSL_HPKE_open(rctx, pt, &ptlen, aad, aadlen, ct, ctlen);
OSSL_HPKE_CTX_free(rctx);
```
