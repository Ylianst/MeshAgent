Public API header for OpenSSL CMP (Certificate Management Protocol) logging and error-reporting utilities, providing severity-leveled logging infrastructure with pluggable callbacks.

## Key Components

### Functions

| Function | Description |
|---|---|
| `OSSL_CMP_log_open()` | Initializes the CMP logging subsystem |
| `OSSL_CMP_log_close()` | Tears down the CMP logging subsystem |
| `OSSL_CMP_print_to_bio()` | Writes a formatted log message to a `BIO` output stream |
| `OSSL_CMP_print_errors_cb()` | Flushes the OpenSSL error queue through a custom log callback |

### Types

| Type | Description |
|---|---|
| `OSSL_CMP_severity` | Integer alias representing a syslog-compatible severity level |
| `OSSL_CMP_log_cb_t` | Function pointer type for custom log handlers `(func, file, line, level, msg)` |

### Severity Levels

Mirrors standard `syslog.h` levels (`0`–`8`):

```text
EMERG(0) → ALERT(1) → CRIT(2) → ERR(3) →
WARNING(4) → NOTICE(5) → INFO(6) → DEBUG(7) → TRACE(8)
```

## Usage Example

```c
#include <openssl/cmp_util.h>

/* Custom log handler */
int my_log_cb(const char *func, const char *file, int line,
              OSSL_CMP_severity level, const char *msg) {
    if (level <= OSSL_CMP_LOG_WARNING)
        fprintf(stderr, "[%d] %s:%d %s(): %s\n", level, file, line, func, msg);
    return 1;
}

int main(void) {
    OSSL_CMP_log_open();

    /* Redirect error queue output through custom callback */
    OSSL_CMP_print_errors_cb(my_log_cb);

    OSSL_CMP_log_close();
    return 0;
}
```

> **Note:** The entire header is conditionally compiled under `OPENSSL_NO_CMP`. Ensure your OpenSSL build includes CMP support before linking against these symbols.
