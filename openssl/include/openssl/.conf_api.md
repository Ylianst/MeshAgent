Internal OpenSSL configuration API header providing low-level access to `CONF` structure internals. These functions underpin the public `CONF_*` API and are not intended for direct use in application code.

## Key Components

| Function | Description |
|---|---|
| `_CONF_new_section` | Creates a new named section within a `CONF` object |
| `_CONF_get_section` | Retrieves a section `CONF_VALUE` by name |
| `_CONF_get_section_values` | Returns the full stack of `CONF_VALUE` entries for a section |
| `_CONF_add_string` | Adds a key-value entry to a section |
| `_CONF_get_string` | Looks up a string value by section and name |
| `_CONF_get_number` | Looks up a numeric (`long`) value by section and name |
| `_CONF_new_data` | Initializes the internal data store of a `CONF` object |
| `_CONF_free_data` | Frees the internal data store of a `CONF` object |

## Usage Example

```c
#include <openssl/conf.h>
#include <openssl/conf_api.h>

/* Directly access a section and its values (internal use) */
CONF *conf = NCONF_new(NULL);

if (_CONF_new_data(conf)) {
    CONF_VALUE *section = _CONF_new_section(conf, "my_section");

    /* Retrieve a string value from a known section */
    const char *val = _CONF_get_string(conf, "my_section", "my_key");

    /* Retrieve all values in a section */
    STACK_OF(CONF_VALUE) *vals =
        _CONF_get_section_values(conf, "my_section");

    _CONF_free_data(conf);
}

NCONF_free(conf);
```

> **Note:** These `_CONF_*` symbols are internal OpenSSL APIs. Prefer the public `NCONF_*` / `CONF_*` functions in application code. The `HEADER_CONF_API_H` define is retained only for pre-3.0 compatibility.
