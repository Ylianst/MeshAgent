OpenSSL tracing API header that defines categories, consumer registration functions, and producer macros for structured diagnostic output via BIO channels.

## Key Components

### Trace Categories
21 named categories (`OSSL_TRACE_CATEGORY_*`) covering subsystems such as `TLS`, `TLS_CIPHER`, `CONF`, `X509V3_POLICY`, `HTTP`, `PROVIDER`, and more. `OSSL_TRACE_CATEGORY_ALL` (0) acts as a catch-all fallback.

### Consumer API (Registration)
| Function | Purpose |
|---|---|
| `OSSL_trace_set_channel()` | Attach a `BIO*` sink to a category |
| `OSSL_trace_set_callback()` | Attach an `OSSL_trace_cb` function instead of a BIO |
| `OSSL_trace_set_prefix()` | Set per-group prefix string |
| `OSSL_trace_set_suffix()` | Set per-group suffix string |

`OSSL_trace_cb` receives `buffer`, `count`, `category`, `cmd` (`BEGIN`/`WRITE`/`END`), and a user `data` pointer.

### Producer API (Emitting Traces)
| Symbol | Purpose |
|---|---|
| `OSSL_trace_begin()` / `OSSL_trace_end()` | Lock/unlock a trace group, returns `BIO*` |
| `OSSL_TRACE_BEGIN(cat)` / `OSSL_TRACE_END(cat)` | Convenience block macros exposing `trc_out` |
| `OSSL_TRACE_CANCEL(cat)` | Early-exit from a trace block |
| `OSSL_TRACE_ENABLED(cat)` | Boolean check before expensive work |
| `OSSL_TRACE()` / `OSSL_TRACE1()`…`OSSL_TRACE9()` | One-shot printf-style macros |
| `OSSL_TRACE_STRING()` | Dump binary/text buffers (max `OSSL_TRACE_STRING_MAX` = 80) |

When `OPENSSL_NO_TRACE` or `FIPS_MODULE` is defined, all macros compile to dead code with zero runtime cost.

## Usage Example

```c
/* --- Consumer: register a callback --- */
size_t my_tracer(const char *buf, size_t count,
                 int category, int cmd, void *data) {
    if (cmd == OSSL_TRACE_CTRL_WRITE)
        fwrite(buf, 1, count, stderr);
    return count;
}

OSSL_trace_set_callback(OSSL_TRACE_CATEGORY_TLS, my_tracer, NULL);

/* --- Producer: emit a structured trace group --- */
OSSL_TRACE_BEGIN(TLS) {
    BIO_fprintf(trc_out, "Handshake started, version=0x%04x\n", ver);
} OSSL_TRACE_END(TLS);

/* --- Producer: one-shot convenience macro --- */
OSSL_TRACE1(INIT, "Library initialised, pid=%d\n", getpid());

/* --- Guard expensive work --- */
if (OSSL_TRACE_ENABLED(BN_CTX)) {
    /* build expensive debug string only when tracing is active */
}
```
