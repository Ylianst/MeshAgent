OpenSSL Blowfish symmetric cipher header (deprecated since OpenSSL 3.0). Defines the `BF_KEY` structure and declares low-level Blowfish encryption/decryption functions for ECB, CBC, CFB64, and OFB64 block cipher modes.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `BF_BLOCK` | `8` | Block size in bytes |
| `BF_ROUNDS` | `16` | Number of Blowfish rounds |
| `BF_ENCRYPT` | `1` | Encrypt direction flag |
| `BF_DECRYPT` | `0` | Decrypt direction flag |
| `BF_LONG` | `unsigned int` | Must be at least 32 bits wide |

### Types

- **`BF_KEY`** — Key schedule struct containing the P-array (`P[18]`) and S-boxes (`S[4][256]`).

### Functions (All deprecated in OpenSSL 3.0)

| Function | Description |
|---|---|
| `BF_set_key` | Initializes a `BF_KEY` from raw key bytes |
| `BF_encrypt` / `BF_decrypt` | Raw 64-bit block encrypt/decrypt |
| `BF_ecb_encrypt` | Electronic Codebook (ECB) mode |
| `BF_cbc_encrypt` | Cipher Block Chaining (CBC) mode |
| `BF_cfb64_encrypt` | 64-bit Cipher Feedback (CFB64) mode |
| `BF_ofb64_encrypt` | 64-bit Output Feedback (OFB64) mode |
| `BF_options` | Returns compile-time options string |

## Usage Example

```c
#include <openssl/blowfish.h>

/* ⚠️ Deprecated since OpenSSL 3.0 — use EVP API instead */
BF_KEY key;
unsigned char iv[BF_BLOCK] = {0};
unsigned char plaintext[BF_BLOCK]  = "hello!!";
unsigned char ciphertext[BF_BLOCK] = {0};

BF_set_key(&key, 16, (const unsigned char *)"mysecretkey12345");
BF_cbc_encrypt(plaintext, ciphertext, BF_BLOCK, &key, iv, BF_ENCRYPT);
```

> **⚠️ Deprecation Warning:** All symbols in this header are guarded by `OPENSSL_NO_DEPRECATED_3_0`. For new code, use the [EVP API](https://www.openssl.org/docs/man3.0/man3/EVP_EncryptInit_ex.html) with `EVP_bf_cbc()` or equivalent.
