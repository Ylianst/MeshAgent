OpenSSL Big Number (BIGNUM) library public API header, providing arbitrary-precision integer arithmetic operations used throughout OpenSSL for cryptographic computations.

## Key Components

### Type Definitions & Macros
- **`BN_ULONG`** — Platform-specific unsigned integer type (32-bit or 64-bit)
- **`BN_BYTES`**, **`BN_BITS2`**, **`BN_BITS`**, **`BN_TBIT`** — Word-size constants derived from platform width
- **`BN_FLG_MALLOCED`**, **`BN_FLG_STATIC_DATA`**, **`BN_FLG_CONSTTIME`**, **`BN_FLG_SECURE`** — BIGNUM behavior flags
- **`BN_RAND_TOP_*`** / **`BN_RAND_BOTTOM_*`** — Constants controlling random number generation constraints

### Memory & Context Management
- **`BN_new()`** / **`BN_secure_new()`** / **`BN_free()`** / **`BN_clear_free()`** — BIGNUM allocation and secure zeroing
- **`BN_CTX_new()`** / **`BN_CTX_secure_new()`** / **`BN_CTX_free()`** — Temporary variable context pool
- **`BN_CTX_start()`** / **`BN_CTX_get()`** / **`BN_CTX_end()`** — Context frame management

### Arithmetic Operations
- **`BN_add()`**, **`BN_sub()`**, **`BN_mul()`**, **`BN_sqr()`**, **`BN_div()`** — Core arithmetic
- **`BN_mod_*()`** — Modular arithmetic (add, sub, mul, sqr, exp, lshift)
- **`BN_mod_exp_mont()`** / **`BN_mod_exp_mont_consttime()`** — Montgomery modular exponentiation, including constant-time variant

### Conversion & I/O
- **`BN_bin2bn()`** / **`BN_bn2bin()`** — Big-endian byte array conversion
- **`BN_lebin2bn()`** / **`BN_native2bn()`** — Little-endian and native byte order variants
- **`BN_mpi2bn()`** / **`BN_bn2mpi()`** — MPI wire format conversion

### Random Number Generation
- **`BN_rand()`** / **`BN_rand_ex()`** — Public random BIGNUMs
- **`BN_priv_rand()`** / **`BN_priv_rand_range()`** — Private/sensitive random values

### Callbacks
- **`BN_GENCB`** — Generation callback structure for long operations (prime generation, key generation)
- **`BN_GENCB_set()`** / **`BN_GENCB_set_old()`** / **`BN_GENCB_call()`** — Callback registration and invocation

## Usage Example

```c
#include <openssl/bn.h>

/* Compute r = (a^p) mod m using constant-time Montgomery exponentiation */
void example_modexp(void) {
    BN_CTX *ctx = BN_CTX_new();
    BIGNUM *a = BN_new();
    BIGNUM *p = BN_new();
    BIGNUM *m = BN_new();
    BIGNUM *r = BN_new();

    BN_set_word(a, 3);
    BN_set_word(p, 65537);   /* common RSA public exponent */
    BN_hex2bn(&m, "FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEFFFFFC2F");

    /* Constant-time exponentiation (timing-safe) */
    BN_set_flags(p, BN_FLG_CONSTTIME);
    BN_mod_exp(r, a, p, m, ctx);

    BN_free(a); BN_free(p); BN_free(m); BN_free(r);
    BN_CTX_free(ctx);
}

/* Generate a random 256-bit BIGNUM in a range */
void example_rand(void) {
    BN_CTX *ctx = BN_CTX_new();
    BIGNUM *range = BN_new();
    BIGNUM *rnd   = BN_new();

    BN_hex2bn(&range, "FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF");
    BN_rand_range(rnd, range);

    BN_free(range); BN_free(rnd);
    BN_CTX_free(ctx);
}
```

> **Note:** Always pair `BN_CTX_start()` / `BN_CTX_end()` when borrowing temporaries from a context, and use `BN_FLG_CONSTTIME` or `BN_mod_exp_mont_consttime()` for any secret exponent to prevent timing side-channel leaks.
