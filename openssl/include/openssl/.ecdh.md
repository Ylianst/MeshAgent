Compatibility header that re-exports the OpenSSL EC (Elliptic Curve) API by including `<openssl/ec.h>`. This header exists as a legacy shim, allowing older code that referenced `<openssl/ecdh.h>` directly to continue compiling without modification.

## Key Components

- **`<openssl/ec.h>`** — The unified OpenSSL elliptic curve header, which provides all ECDH (Elliptic Curve Diffie-Hellman) key exchange primitives:
  - `EC_KEY` — Elliptic curve key object
  - `ECDH_compute_key()` — Core ECDH shared secret derivation
  - `EC_KEY_generate_key()` — Key pair generation

## Usage Example

```c
/* Legacy code — include ecdh.h directly */
#include <openssl/ecdh.h>

int derive_shared_secret(EC_KEY *local_key, const EC_POINT *peer_pubkey) {
    unsigned char secret[32];
    int secret_len;

    secret_len = ECDH_compute_key(
        secret, sizeof(secret),
        peer_pubkey,
        local_key,
        NULL  /* no KDF */
    );

    if (secret_len <= 0) {
        /* handle error */
        return -1;
    }
    return secret_len;
}
```

> **Note:** In modern OpenSSL (1.1.0+), prefer including `<openssl/ec.h>` directly. This shim exists purely for backward compatibility with code targeting older OpenSSL layouts.
