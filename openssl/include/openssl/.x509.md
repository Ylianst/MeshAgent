OpenSSL's public header for X.509 certificate infrastructure, providing type definitions, stack macros, and function declarations for creating, parsing, validating, and managing X.509 certificates, CRLs, and related PKI structures.

## Key Components

### Core Types
- **`X509`** — Represents a complete X.509 certificate
- **`X509_CRL`** — Certificate Revocation List structure
- **`X509_REVOKED`** — Single revoked certificate entry within a CRL
- **`X509_NAME`** — Distinguished Name (DN) for subject/issuer fields

### Type-Safe Stack Macros
The header defines typed stack collections (`STACK_OF(T)`) for each core type, each with a full set of operations:

| Macro Pattern | Description |
|---|---|
| `sk_X509_new(cmp)` | Create new stack with comparator |
| `sk_X509_push(sk, ptr)` | Append element |
| `sk_X509_pop_free(sk, fn)` | Free stack and all elements |
| `sk_X509_find(sk, ptr)` | Search by value |
| `sk_X509_deep_copy(sk, cp, fn)` | Clone stack and elements |
| `sk_X509_sort(sk)` | Sort in-place |

Stack collections are provided for: `X509`, `X509_NAME`, `X509_REVOKED`, and `X509_CRL`.

### Dependencies
Pulls in `evp.h`, `asn1.h`, `bio.h`, `ec.h`, `sha.h`, and conditionally `rsa.h`/`dsa.h`/`dh.h` (deprecated in OpenSSL 1.1.0+).

## Usage Example

```c
#include <openssl/x509.h>
#include <openssl/bio.h>

/* Load a certificate from a PEM file and inspect its subject */
FILE *fp = fopen("cert.pem", "r");
X509 *cert = PEM_read_X509(fp, NULL, NULL, NULL);
fclose(fp);

if (cert) {
    X509_NAME *subj = X509_get_subject_name(cert);
    char buf[256];
    X509_NAME_oneline(subj, buf, sizeof(buf));
    printf("Subject: %s\n", buf);
    X509_free(cert);
}

/* Build a stack of certificates */
STACK_OF(X509) *chain = sk_X509_new_null();
sk_X509_push(chain, cert);
/* ... process chain ... */
sk_X509_pop_free(chain, X509_free);
```
