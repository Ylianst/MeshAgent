OpenSSL dynamic hash table interface header providing type-safe wrappers around a generic chained hash table implementation (`OPENSSL_LHASH`).

## Key Components

### Core Types

| Type | Description |
|---|---|
| `OPENSSL_LHASH` | Opaque hash table structure |
| `OPENSSL_LH_NODE` | Individual hash table node |
| `OPENSSL_LH_COMPFUNC` | Comparison function pointer |
| `OPENSSL_LH_HASHFUNC` | Hash function pointer |
| `OPENSSL_LH_DOALL_FUNC` | Iterator callback (no arg) |
| `OPENSSL_LH_DOALL_FUNCARG` | Iterator callback (with arg) |

### Core API Functions

- **`OPENSSL_LH_new`** — Allocate a hash table with custom hash/compare functions
- **`OPENSSL_LH_free`** / **`OPENSSL_LH_flush`** — Destroy or empty a table
- **`OPENSSL_LH_insert`** / **`OPENSSL_LH_delete`** / **`OPENSSL_LH_retrieve`** — CRUD operations
- **`OPENSSL_LH_doall`** / **`OPENSSL_LH_doall_arg`** — Iterate over all entries
- **`OPENSSL_LH_strhash`** — Built-in string hash function
- **`OPENSSL_LH_error`** — Check for allocation errors
- **`OPENSSL_LH_set_down_load`** / **`OPENSSL_LH_get_down_load`** — Control load factor threshold (`LH_LOAD_MULT = 256`)

### Type-Safe Macro System

- **`LHASH_OF(type)`** — Declares a typed hash table struct (`lhash_st_<type>`)
- **`DEFINE_LHASH_OF_EX(type)`** — Generates inline typed wrappers (e.g., `lh_MyType_insert`, `lh_MyType_retrieve`)
- **`DECLARE_LHASH_HASH_FN` / `IMPLEMENT_LHASH_HASH_FN`** — Type-safe hash callback helpers
- **`DECLARE_LHASH_COMP_FN` / `IMPLEMENT_LHASH_COMP_FN`** — Type-safe compare callback helpers

## Usage Example

```c
/* Define a typed hash table for a custom struct */
typedef struct { int id; char *name; } MyEntry;

static unsigned long my_hash(const MyEntry *e) {
    return OPENSSL_LH_strhash(e->name);
}
static int my_cmp(const MyEntry *a, const MyEntry *b) {
    return strcmp(a->name, b->name);
}

DEFINE_LHASH_OF_EX(MyEntry);

/* Create and use the table */
LHASH_OF(MyEntry) *ht = lh_MyEntry_new(my_hash, my_cmp);

MyEntry item = { 1, "hello" };
lh_MyEntry_insert(ht, &item);

MyEntry key = { 0, "hello" };
MyEntry *found = lh_MyEntry_retrieve(ht, &key);

lh_MyEntry_free(ht);
```

> **Deprecation note:** Stats functions (`OPENSSL_LH_stats_bio`, `OPENSSL_LH_node_stats_bio`) are deprecated as of OpenSSL 3.1. Legacy `lh_*` aliases from pre-1.1.0 are preserved under `OPENSSL_NO_DEPRECATED_1_1_0`.
