## Usage Example

These codes are not raised directly; they appear in error state inspection via OpenSSL's error API:

```c
#include <openssl/bio.h>
#include <openssl/err.h>
#include <openssl/bioerr.h>

BIO *bio = BIO_new_connect("example.com:443");
if (!bio) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == BIO_R_CONNECT_ERROR) {
        fprintf(stderr, "BIO connect failed\n");
    } else if (reason == BIO_R_CONNECT_TIMEOUT) {
        fprintf(stderr, "BIO connect timed out\n");
    }
}
```
