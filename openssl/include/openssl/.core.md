Core type definitions and foundational data structures shared between the OpenSSL core and provider modules, enabling communication across the provider interface boundary.

## Key Components

### Opaque Handle Types
- **`OSSL_CORE_HANDLE`** — Opaque handle for provider-to-core upcalls
- **`OPENSSL_CORE_CTX`** — Core context handle
- **`OSSL_CORE_BIO`** — Core BIO handle

### Structs
- **`ossl_dispatch_st`** (`OSSL_DISPATCH`) — Function dispatch table entry mapping a `function_id` to a function pointer; arrays are terminated by `function_id == 0`
- **`ossl_item_st`** (`OSSL_ITEM`) — Generic `int`↔`pointer` map element for error code/string tables; arrays terminated by `id == 0 && ptr == NULL`
- **`ossl_algorithm_st`** (`OSSL_ALGORITHM`) — Ties algorithm names, property strings, and dispatch table implementations together; arrays terminated by `algorithm_names == NULL`
- **`ossl_param_st`** (`OSSL_PARAM`) — Uniform key/value parameter passing structure with type, data buffer, and size fields; arrays terminated by `key == NULL`

### Parameter Data Type Constants
| Constant | Value | Description |
|---|---|---|
| `OSSL_PARAM_INTEGER` | 1 | Arbitrary-length signed integer |
| `OSSL_PARAM_UNSIGNED_INTEGER` | 2 | Arbitrary-length unsigned integer |
| `OSSL_PARAM_REAL` | 3 | Native C floating-point |
| `OSSL_PARAM_UTF8_STRING` | 4 | Printable string (copied) |
| `OSSL_PARAM_OCTET_STRING` | 5 | Raw byte string (copied) |
| `OSSL_PARAM_UTF8_PTR` | 6 | Pointer to printable string (fragile) |
| `OSSL_PARAM_OCTET_PTR` | 7 | Pointer to byte string (fragile) |

### Callback Typedefs
- **`OSSL_provider_init_fn`** — Provider entry point; receives core dispatch table, returns provider dispatch table and context
- **`OSSL_thread_stop_handler_fn`** — Registered by providers to receive thread-stop notifications
- **`OSSL_CALLBACK`** — Generic callback receiving an `OSSL_PARAM` array and caller data
- **`OSSL_INOUT_CALLBACK`** — Callback with separate input and output `OSSL_PARAM` arrays
- **`OSSL_PASSPHRASE_CALLBACK`** — Specialized callback for passphrase retrieval

## Usage Example

```c
/* Implementing a provider entry point */
int OSSL_provider_init(const OSSL_CORE_HANDLE *handle,
                       const OSSL_DISPATCH *in,
                       const OSSL_DISPATCH **out,
                       void **provctx)
{
    /* Walk the core's dispatch table */
    for (const OSSL_DISPATCH *fn = in; fn->function_id != 0; fn++) {
        /* bind core functions by ID */
    }

    /* Build and return the provider's dispatch table */
    static const OSSL_DISPATCH provider_fns[] = {
        { OSSL_FUNC_PROVIDER_GETTABLE_PARAMS, (void (*)(void))my_gettable },
        OSSL_DISPATCH_END
    };
    *out = provider_fns;

    /* Pass a key/value parameter */
    OSSL_PARAM params[2];
    int version = 3;
    params[0].key       = "version";
    params[0].data_type = OSSL_PARAM_INTEGER;
    params[0].data      = &version;
    params[0].data_size = sizeof(version);
    params[1]           = (OSSL_PARAM){ NULL }; /* terminator */

    return 1;
}
```
