## Usage Example

These codes surface via the standard OpenSSL error API after a failed RAND operation:

```c
#include <openssl/rand.h>
#include <openssl/err.h>
#include <openssl/randerr.h>

unsigned char buf[32];
if (RAND_bytes(buf, sizeof(buf)) != 1) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == RAND_R_PRNG_NOT_SEEDED) {
        fprintf(stderr, "PRNG has not been seeded\n");
    } else if (reason == RAND_R_DRBG_NOT_INITIALISED) {
        fprintf(stderr, "DRBG not initialised\n");
    } else {
        fprintf(stderr, "RAND error %d: %s\n", reason, ERR_reason_error_string(err));
    }
}
```
