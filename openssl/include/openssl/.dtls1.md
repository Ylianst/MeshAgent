DTLS 1.x protocol constants and configuration header for OpenSSL's Datagram TLS implementation.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `DTLS1_VERSION_MAJOR` | `0xFE` | Major version byte for all DTLS versions |
| `DTLS_ANY_VERSION` | `0x1FFFF` | Sentinel for methods supporting multiple DTLS versions |
| `DTLS_MIN_VERSION` | `DTLS1_VERSION` | Minimum supported DTLS version (deprecated ≥ 3.0) |
| `DTLS_MAX_VERSION` | `DTLS1_2_VERSION` | Maximum supported DTLS version (deprecated ≥ 3.0) |
| `DTLS1_COOKIE_LENGTH` | `255` | Maximum DTLS cookie length in bytes |
| `DTLS1_RT_HEADER_LENGTH` | `13` | Record layer header length in bytes |
| `DTLS1_HM_HEADER_LENGTH` | `12` | Handshake message header length in bytes |
| `DTLS1_CCS_HEADER_LENGTH` | `1` | ChangeCipherSpec header length in bytes |
| `DTLS1_AL_HEADER_LENGTH` | `2` | Alert header length in bytes |
| `DTLS1_TMO_ALERT_COUNT` | `12` | Retransmit timeout alert threshold count |
| `DTLS1_HM_BAD_FRAGMENT` | `-2` | Error code for malformed handshake fragment |
| `DTLS1_HM_FRAGMENT_RETRY` | `-3` | Signal to retry handshake fragment reassembly |

## Usage Example

```c
#include <openssl/dtls1.h>

/* Version negotiation check */
if (version == DTLS_ANY_VERSION) {
    /* Method accepts DTLS1_VERSION through DTLS1_2_VERSION */
}

/* Validate incoming record header buffer size */
if (buf_len < DTLS1_RT_HEADER_LENGTH) {
    /* Incomplete record header */
    return DTLS1_HM_BAD_FRAGMENT;
}

/* Allocate handshake message buffer including header */
uint8_t hm_buf[DTLS1_HM_HEADER_LENGTH + payload_len];

/* Cookie validation */
if (cookie_len > DTLS1_COOKIE_LENGTH) {
    /* Cookie exceeds maximum allowed length */
}
```

## Notes

- Actual `DTLS1_VERSION` and `DTLS1_2_VERSION` numeric values are defined in [`<openssl/prov_ssl.h>`](https://github.com/flamingo-stack/meshagent/blob/main/openssl/prov_ssl.h).
- The `DTLS_MIN_VERSION` and `DTLS_MAX_VERSION` macros are deprecated as of OpenSSL 3.0 and guarded by `OPENSSL_NO_DEPRECATED_3_0`.
