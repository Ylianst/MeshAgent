OpenSSL core cryptography header providing foundational types, memory management macros, threading primitives, atomic operations, and extension data APIs used throughout the OpenSSL library.

## Key Components

### Thread Synchronization
- **`CRYPTO_RWLOCK`** — Opaque read/write lock type
- **`CRYPTO_THREAD_lock_new/free`** — Lock lifecycle management
- **`CRYPTO_THREAD_read_lock` / `CRYPTO_THREAD_write_lock` / `CRYPTO_THREAD_unlock`** — Lock acquisition and release

### Atomic Operations
- **`CRYPTO_atomic_add` / `CRYPTO_atomic_add64`** — Thread-safe integer addition
- **`CRYPTO_atomic_and` / `CRYPTO_atomic_or`** — Bitwise atomic operations
- **`CRYPTO_atomic_load` / `CRYPTO_atomic_store`** — Atomic memory access

### Memory Management Macros
Wrappers that inject `__FILE__`/`__LINE__` for allocation tracing:
- **`OPENSSL_malloc` / `OPENSSL_zalloc` / `OPENSSL_free`** — Standard heap allocation
- **`OPENSSL_clear_free` / `OPENSSL_secure_malloc`** — Secure/zeroing variants
- **`OPENSSL_aligned_alloc`** — Alignment-aware allocation

### String Utilities
- **`OPENSSL_strlcpy` / `OPENSSL_strlcat` / `OPENSSL_strnlen`** — Safe string operations
- **`OPENSSL_buf2hexstr` / `OPENSSL_hexstr2buf`** — Hex encoding/decoding
- **`OPENSSL_strcasecmp` / `OPENSSL_strncasecmp`** — Case-insensitive comparison

### Version Information
- **`OPENSSL_version_major/minor/patch`** — Numeric version components
- **`OpenSSL_version`** — String info by type constant (`OPENSSL_VERSION`, `OPENSSL_CFLAGS`, etc.)
- **`OPENSSL_info`** — Runtime path/config info constants (`OPENSSL_INFO_CONFIG_DIR`, etc.)

### Extension Data (`CRYPTO_EX_DATA`)
Per-object application data slots for SSL, X509, RSA, EC\_KEY, and other OpenSSL object classes:
- **`CRYPTO_get_ex_new_index`** — Register new/dup/free callbacks for a class
- **`CRYPTO_new_ex_data` / `CRYPTO_dup_ex_data` / `CRYPTO_free_ex_data`** — Lifecycle management

## Usage Example

```c
#include <openssl/crypto.h>

/* Thread-safe counter using CRYPTO_RWLOCK */
static int counter = 0;
CRYPTO_RWLOCK *lock = CRYPTO_THREAD_lock_new();

void increment(void) {
    int result;
    CRYPTO_atomic_add(&counter, 1, &result, lock);
}

/* Secure allocation and zeroing on free */
void process_key(size_t keylen) {
    unsigned char *keybuf = OPENSSL_secure_zalloc(keylen);
    if (keybuf == NULL)
        return;

    /* ... use keybuf ... */

    OPENSSL_secure_clear_free(keybuf, keylen);
}

/* Hex encoding */
void encode(const unsigned char *data, long len) {
    char *hex = OPENSSL_buf2hexstr(data, len);
    /* hex is caller-freed */
    OPENSSL_free(hex);
}

/* Version check */
void check_version(void) {
    if (OPENSSL_version_major() < 3)
        fprintf(stderr, "OpenSSL 3.x required\n");
}

/* Cleanup */
void teardown(void) {
    CRYPTO_THREAD_lock_free(lock);
}
```
