Simple text-based database header from OpenSSL, providing a lightweight flat-file database structure with indexed lookup support, used primarily for certificate management tools like `ca`.

## Key Components

### Struct: `TXT_DB`
Core database structure containing:
- `num_fields` — number of columns per row
- `data` — stack of string arrays holding all rows
- `index` — array of hash tables for indexed fields
- `qual` — per-field qualifier/filter function pointers
- `error`, `arg1`, `arg2`, `arg_row` — error state and diagnostic context

### Error Codes
| Constant | Value | Meaning |
|---|---|---|
| `DB_ERROR_OK` | `0` | Success |
| `DB_ERROR_MALLOC` | `1` | Memory allocation failure |
| `DB_ERROR_INDEX_CLASH` | `2` | Duplicate index key |
| `DB_ERROR_INDEX_OUT_OF_RANGE` | `3` | Field index out of bounds |
| `DB_ERROR_NO_INDEX` | `4` | No index defined for field |
| `DB_ERROR_INSERT_INDEX_CLASH` | `5` | Insert would violate index uniqueness |
| `DB_ERROR_WRONG_NUM_FIELDS` | `6` | Row has incorrect column count |

### Functions
- `TXT_DB_read(BIO *in, int num)` — parse a tab-delimited database from a BIO stream
- `TXT_DB_write(BIO *out, TXT_DB *db)` — serialize the database back to a BIO stream
- `TXT_DB_create_index(db, field, qual, hash, cmp)` — build a hash index on a named field with optional qualifier
- `TXT_DB_get_by_index(db, idx, value)` — lookup a row by indexed field value
- `TXT_DB_insert(db, value)` — insert a new row, enforcing index constraints
- `TXT_DB_free(db)` — release all database memory

## Usage Example

```c
#include <openssl/txt_db.h>
#include <openssl/bio.h>

/* Read a flat-file database from disk */
BIO *bio = BIO_new_file("index.txt", "r");
TXT_DB *db = TXT_DB_read(bio, 6);  /* 6 fields per row */
BIO_free(bio);

/* Create a hash index on field 3 (e.g., serial number) */
TXT_DB_create_index(db, 3, NULL,
                    (OPENSSL_LH_HASHFUNC)lh_strhash,
                    (OPENSSL_LH_COMPFUNC)strcmp);

/* Lookup a row by indexed field */
OPENSSL_STRING *row = TXT_DB_get_by_index(db, 3, key);

TXT_DB_free(db);
```
