## Key Components

| Constant | Value | Description |
|---|---|---|
| `OBJ_R_OID_EXISTS` | 102 | A duplicate OID was detected during object registration |
| `OBJ_R_UNKNOWN_NID` | 101 | An unknown Numeric Identifier (NID) was referenced |
| `OBJ_R_UNKNOWN_OBJECT_NAME` | 103 | An unrecognized object name was provided |

## Usage Example

```c
#include <openssl/objects.h>
#include <openssl/objectserr.h>
#include <openssl/err.h>

int register_custom_oid(const char *oid_str, const char *short_name) {
    int nid = OBJ_txt2nid(oid_str);

    if (nid == NID_undef) {
        /* Handle OBJ_R_UNKNOWN_NID case */
        unsigned long err = ERR_get_error();
        if (ERR_GET_REASON(err) == OBJ_R_UNKNOWN_NID) {
            /* Safe to create a new OID */
            nid = OBJ_create(oid_str, short_name, NULL);
        }
    }

    return nid;
}
```
