OpenSSL ASN.1 type definitions, tag constants, string flags, and core data structure declarations for DER/BER encoding and decoding operations.

## Key Components

### Tag Class Constants (`V_ASN1_*`)
Defines ASN.1 tag values for universal types (BOOLEAN=1, INTEGER=2, BIT_STRING=3, OCTET_STRING=4, etc.), tag classes (UNIVERSAL, APPLICATION, CONTEXT_SPECIFIC, PRIVATE), and special sentinels like `V_ASN1_UNDEF`, `V_ASN1_ANY`, and `V_ASN1_NEG`.

### Bitmask String Type Flags (`B_ASN1_*`)
Single-bit flags used with `d2i_ASN1_type_bytes()` and `ASN1_mbstring_copy()` to indicate acceptable string types (e.g., `B_ASN1_UTF8STRING`, `B_ASN1_PRINTABLESTRING`, `B_ASN1_UTCTIME`).

### Core Structures
- **`asn1_string_st`** (`ASN1_STRING`) — Base type holding a typed byte buffer (`length`, `type`, `data`, `flags`), used for virtually all ASN.1 string and time values.
- **`ASN1_ENCODING`** — Stores raw DER encoding (`enc`, `len`, `modified`) to preserve wire bytes for signature validation.
- **`asn1_string_table_st`** (`ASN1_STRING_TABLE`) — Constraint table entry with NID, min/max size, and mask/flags.

### Stack Macros
Type-safe `STACK_OF(X509_ALGOR)` and `STACK_OF(ASN1_STRING_TABLE)` wrappers providing `push`, `pop`, `find`, `sort`, `dup`, and `deep_copy` operations via the OpenSSL safe-stack API.

### MBSTRING Flags
`MBSTRING_UTF8`, `MBSTRING_ASC`, `MBSTRING_BMP`, `MBSTRING_UNIV` — used with multibyte string conversion functions.

## Usage Example

```c
#include <openssl/asn1.h>

/* Create and populate an ASN1_STRING */
ASN1_STRING *str = ASN1_STRING_new();
ASN1_STRING_set(str, "Hello", 5);

/* Check the type tag */
if (ASN1_STRING_type(str) == V_ASN1_UTF8STRING) {
    /* handle UTF-8 content */
}

/* Use a type-safe X509_ALGOR stack */
STACK_OF(X509_ALGOR) *alg_stack = sk_X509_ALGOR_new_null();
sk_X509_ALGOR_push(alg_stack, algor);
sk_X509_ALGOR_pop_free(alg_stack, X509_ALGOR_free);

ASN1_STRING_free(str);
```
