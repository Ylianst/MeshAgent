Defines the OpenSSL provider dispatch table interface, establishing the function identity constants and type-safe accessor macros used for communication between the OpenSSL core and cryptographic providers.

## Key Components

### Core Macro

**`OSSL_CORE_MAKE_FUNC(type, name, args)`** — Generates two artifacts for each dispatch function:
- A function signature typedef: `OSSL_FUNC_<name>_fn`
- A type-safe inline extractor: `OSSL_FUNC_<name>(const OSSL_DISPATCH *opf)`

### Function Identity Groups

| Range | Category |
|-------|----------|
| 1–10 | Core parameter/error management |
| 11–12 | OBJ database (sigid, OID creation) |
| 20–31 | Memory allocation (malloc, free, secure variants) |
| 40–50 | BIO I/O operations |
| 95–100 | Indicators and self-test callbacks |
| 101–104 | OS entropy/nonce seeding |
| 105–111 | Provider registry management |

### Base Types

- **`OSSL_FUNC`** — Generic `void (*)(void)` function pointer for heterogeneous dispatch arrays
- **`OSSL_DISPATCH`** — Array-based dispatch table terminated by entry `0`

## Usage Example

```c
/* Extracting a typed function pointer from a dispatch table */
const OSSL_DISPATCH *dispatch = get_provider_dispatch();

/* Type-safe extraction via generated inline accessor */
OSSL_FUNC_core_get_params_fn *get_params = OSSL_FUNC_core_get_params(dispatch);

/* Invoke the extracted function */
OSSL_PARAM params[] = { OSSL_PARAM_END };
int rc = get_params(core_handle, params);

/* Implementing a provider init that receives the core dispatch table */
int OSSL_provider_init(const OSSL_CORE_HANDLE *handle,
                       const OSSL_DISPATCH *in,
                       const OSSL_DISPATCH **out,
                       void **provctx) {
    for (; in->function_id != 0; in++) {
        switch (in->function_id) {
        case OSSL_FUNC_CORE_GET_PARAMS:
            c_get_params = OSSL_FUNC_core_get_params(in);
            break;
        case OSSL_FUNC_CORE_NEW_ERROR:
            c_new_error = OSSL_FUNC_core_new_error(in);
            break;
        }
    }
    return 1;
}
```
