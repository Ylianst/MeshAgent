OpenSSL block cipher mode of operation interfaces, providing function prototypes and type definitions for CBC, CTR, OFB, CFB, CTS, GCM, CCM, XTS, OCB, and key-wrap modes over 128-bit block ciphers.

## Key Components

### Function Pointer Types

| Type | Description |
|---|---|
| `block128_f` | Single 128-bit block encrypt/decrypt |
| `cbc128_f` | CBC mode bulk operation |
| `ecb128_f` | ECB mode bulk operation |
| `ctr128_f` | CTR mode bulk operation (block-granular) |
| `ccm128_f` | CCM-optimized bulk operation with CMAC |
| `ocb128_f` | OCB mode bulk operation with offset/checksum |

### Mode Families

- **CBC/ECB** — `CRYPTO_cbc128_encrypt/decrypt`
- **CTR** — `CRYPTO_ctr128_encrypt`, `CRYPTO_ctr128_encrypt_ctr32`
- **OFB** — `CRYPTO_ofb128_encrypt`
- **CFB** — `CRYPTO_cfb128_encrypt` (128-bit), `_8` (8-bit), `_1` (1-bit)
- **CTS** — `CRYPTO_cts128_*` and `CRYPTO_nistcts128_*` (ciphertext stealing variants)
- **GCM** — `GCM128_CONTEXT`-based AEAD with tag generation/verification
- **CCM** — `CCM128_CONTEXT`-based AEAD with nonce and tag length parameters
- **XTS** — `CRYPTO_xts128_encrypt` for disk-sector encryption
- **Key Wrap** — `CRYPTO_128_wrap/unwrap` and padded `_pad` variants (RFC 3394/5649)
- **OCB** — `OCB128_CONTEXT`-based AEAD (conditionally compiled via `OPENSSL_NO_OCB`)

## Usage Example

```c
#include <openssl/modes.h>
#include <openssl/aes.h>

/* CBC encrypt using a custom block function */
AES_KEY aes_key;
AES_set_encrypt_key(raw_key, 128, &aes_key);

unsigned char ivec[16] = {0};
CRYPTO_cbc128_encrypt(plaintext, ciphertext, len,
                      &aes_key, ivec,
                      (block128_f)AES_encrypt);

/* GCM AEAD encrypt */
GCM128_CONTEXT *gcm = CRYPTO_gcm128_new(&aes_key, (block128_f)AES_encrypt);
CRYPTO_gcm128_setiv(gcm, iv, iv_len);
CRYPTO_gcm128_aad(gcm, aad, aad_len);
CRYPTO_gcm128_encrypt(gcm, plaintext, ciphertext, len);

unsigned char tag[16];
CRYPTO_gcm128_tag(gcm, tag, sizeof(tag));
CRYPTO_gcm128_release(gcm);
```
