OpenSSL X.509 Attribute Certificate (RFC 5755) public API header, providing types, ASN.1 codec declarations, and functions for creating, parsing, signing, verifying, and inspecting `X509_ACERT` attribute certificate structures.

## Key Components

### Core Types

| Type | Description |
|---|---|
| `X509_ACERT` | Top-level attribute certificate structure |
| `X509_ACERT_INFO` | Inner TBSAttributeCertificate info block |
| `OSSL_ISSUER_SERIAL` | Issuer name + serial number pair |
| `OSSL_OBJECT_DIGEST_INFO` | Digest over a public key, cert, or other object |
| `OSSL_IETF_ATTR_SYNTAX` | IETF attribute value container (RFC 5755 §4.4) |
| `OSSL_TARGET` / `OSSL_TARGET_CERT` | Target identity structures |

### I/O & Encoding

- `d2i_X509_ACERT_bio` / `i2d_X509_ACERT_bio` — DER decode/encode via BIO
- `d2i_X509_ACERT_fp` / `i2d_X509_ACERT_fp` — DER decode/encode via `FILE*`
- `DECLARE_PEM_rw(X509_ACERT, X509_ACERT)` — PEM read/write helpers

### Signing & Verification

- `X509_ACERT_sign` — Sign with a private key and digest algorithm
- `X509_ACERT_sign_ctx` — Sign using a pre-initialized `EVP_MD_CTX`
- `X509_ACERT_verify` — Verify signature against a public key

### Field Accessors (get/set)

- **Holder:** `X509_ACERT_get0_holder_entityName`, `_baseCertId`, `_digest`
- **Validity:** `X509_ACERT_get0_notBefore` / `notAfter`, `set1_notBefore` / `set1_notAfter`
- **Issuer/Serial:** `X509_ACERT_get0_issuerName`, `get0_serialNumber`, `set1_issuerName`, `set1_serialNumber`
- **Attributes:** `get_attr`, `add1_attr`, `delete_attr`, `add_attr_nconf`
- **Extensions:** `get_ext_d2i`, `add1_ext_i2d`, `get0_extensions`

### Object Digest Constants

```c
#define OSSL_OBJECT_DIGEST_INFO_PUBLIC_KEY       0
#define OSSL_OBJECT_DIGEST_INFO_PUBLIC_KEY_CERT  1
#define OSSL_OBJECT_DIGEST_INFO_OTHER            2  /* not for RFC 5755 */
```

## Usage Example

```c
#include <openssl/x509_acert.h>

/* Parse a DER-encoded attribute certificate from a BIO */
BIO *bio = BIO_new_file("acert.der", "rb");
X509_ACERT *acert = d2i_X509_ACERT_bio(bio, NULL);
BIO_free(bio);

/* Inspect validity window */
const ASN1_TIME *nb = X509_ACERT_get0_notBefore(acert);
const ASN1_TIME *na = X509_ACERT_get0_notAfter(acert);

/* Verify against issuer public key */
EVP_PKEY *pub = /* load issuer key */;
int ok = X509_ACERT_verify(acert, pub);

/* Print to stdout BIO */
BIO *out = BIO_new_fp(stdout, BIO_NOCLOSE);
X509_ACERT_print(out, acert);

X509_ACERT_free(acert);
BIO_free(out);
```
