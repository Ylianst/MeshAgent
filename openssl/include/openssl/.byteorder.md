Portable byte-order conversion header providing host↔big-endian and host↔little-endian store/load functions for 16-, 32-, and 64-bit integers, with platform-optimized intrinsics where available.

## Key Components

### Platform Macros (internal, undefined after use)

Temporary macros map to platform-native swap intrinsics before being consumed by the inline functions and then `#undef`'d:

| Macro family | Platforms |
|---|---|
| `_byteswap_*` intrinsics | MSVC ≥ 1300 |
| `htobe*/be*toh/htole*/le*toh` | glibc ≥ 2.19, FreeBSD, NetBSD, OpenBSD |
| `OSSwap*` | macOS/Apple |

Falls back to manual byte-shift logic when no platform support is detected.

### Store Functions

Write an integer to a byte buffer in the specified endianness and return a pointer past the written bytes:

- `OPENSSL_store_u16_le` / `OPENSSL_store_u16_be`
- `OPENSSL_store_u32_le` / `OPENSSL_store_u32_be`
- `OPENSSL_store_u64_le` / `OPENSSL_store_u64_be`

### Load Functions

Read an integer from a byte buffer in the specified endianness and return a pointer past the consumed bytes:

- `OPENSSL_load_u16_le` / `OPENSSL_load_u16_be`
- `OPENSSL_load_u32_le` / `OPENSSL_load_u32_be`
- `OPENSSL_load_u64_le` / `OPENSSL_load_u64_be`

## Usage Example

```c
#include <openssl/byteorder.h>

/* Serialize a 32-bit value big-endian into a buffer */
unsigned char buf[4];
unsigned char *p = OPENSSL_store_u32_be(buf, 0xDEADBEEF);
/* buf == { 0xDE, 0xAD, 0xBE, 0xEF }, p points past end */

/* Deserialize a 64-bit little-endian value from a buffer */
uint64_t val;
const unsigned char *q = OPENSSL_load_u64_le(&val, network_buf);
/* q advances 8 bytes, val holds the host-order result */
```

All functions are `static inline`, producing optimal code (typically a single load/swap/store instruction sequence) on supported compilers.
