## Key Components

### Core Macro: `STACK_OF(type)`
Declares a typed stack struct (`struct stack_st_<type>`), used as the opaque handle for all typed stack operations.

### Stack Definition Macros

| Macro | Purpose |
|---|---|
| `DEFINE_STACK_OF(t)` | Define a stack of mutable `t` elements |
| `DEFINE_STACK_OF_CONST(t)` | Define a stack of `const t` elements |
| `DEFINE_SPECIAL_STACK_OF(t1, t2)` | Define a named stack wrapping a different underlying type |
| `DEFINE_SPECIAL_STACK_OF_CONST(t1, t2)` | Const variant of the above |
| `SKM_DEFINE_STACK_OF(t1, t2, t3)` | Core implementation macro generating all typed inline functions |
| `SKM_DEFINE_STACK_OF_INTERNAL(t1, t2, t3)` | Internal variant generating only type-check helpers (no public API functions) |
