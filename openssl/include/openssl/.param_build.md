Header file providing the OpenSSL parameter builder API (`OSSL_PARAM_BLD`), which offers a dynamic, incremental way to construct `OSSL_PARAM` arrays without manually managing memory or array sizing.

## Key Components

### Lifecycle Functions

| Function | Description |
|---|---|
| `OSSL_PARAM_BLD_new()` | Allocates and initializes a new parameter builder |
| `OSSL_PARAM_BLD_to_param()` | Finalizes the builder and returns a heap-allocated `OSSL_PARAM` array |
| `OSSL_PARAM_BLD_free()` | Frees the builder (does **not** free the array from `to_param`) |

### Push Functions

Typed push functions for appending key-value pairs to the builder:

- **Integers:** `push_int`, `push_uint`, `push_long`, `push_ulong`, `push_int32`, `push_uint32`, `push_int64`, `push_uint64`
- **Other scalars:** `push_size_t`, `push_time_t`, `push_double`
- **Big numbers:** `push_BN` (BIGNUM), `push_BN_pad` (BIGNUM with fixed byte-width padding)
- **Strings:** `push_utf8_string` (copies data), `push_utf8_ptr` (stores pointer only)
- **Binary data:** `push_octet_string` (copies data), `push_octet_ptr` (stores pointer only)

All push functions return `1` on success, `0` on failure.

## Usage Example

```c
#include <openssl/param_build.h>
#include <openssl/params.h>

OSSL_PARAM *build_params(int key_bits, const BIGNUM *prime) {
    OSSL_PARAM_BLD *bld = OSSL_PARAM_BLD_new();
    if (bld == NULL)
        return NULL;

    /* Push typed values by key name */
    if (!OSSL_PARAM_BLD_push_int(bld, "bits", key_bits)
        || !OSSL_PARAM_BLD_push_BN(bld, "prime", prime)) {
        OSSL_PARAM_BLD_free(bld);
        return NULL;
    }

    /* Finalize into a flat OSSL_PARAM array */
    OSSL_PARAM *params = OSSL_PARAM_BLD_to_param(bld);
    OSSL_PARAM_BLD_free(bld); /* bld no longer needed */

    /* Caller must free params with OSSL_PARAM_free() */
    return params;
}
```

> **Note:** `_ptr` variants (`push_utf8_ptr`, `push_octet_ptr`) store a reference to the caller's buffer rather than copying it. Ensure the buffer outlives the resulting `OSSL_PARAM` array.
