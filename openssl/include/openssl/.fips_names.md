Defines string constant names for FIPS provider configuration parameters used during self-testing and runtime behavior control in OpenSSL.

## Key Components

| Constant | String Value | Purpose |
|---|---|---|
| `OSSL_PROV_FIPS_PARAM_MODULE_MAC` | `"module-mac"` | Calculated MAC of the FIPS module binary |
| `OSSL_PROV_FIPS_PARAM_INSTALL_VERSION` | `"install-version"` | Version of the FIPS install process |
| `OSSL_PROV_FIPS_PARAM_INSTALL_MAC` | `"install-mac"` | Calculated MAC of the install status indicator |
| `OSSL_PROV_FIPS_PARAM_INSTALL_STATUS` | `"install-status"` | Current install status indicator value |
| `OSSL_PROV_FIPS_PARAM_CONDITIONAL_ERRORS` | `"conditional-errors"` | Controls whether conditional test failures trigger an error state |

**Backwards Compatibility Aliases** (map to `OSSL_PROV_PARAM_*` equivalents):
- `OSSL_PROV_FIPS_PARAM_SECURITY_CHECKS`
- `OSSL_PROV_FIPS_PARAM_TLS1_PRF_EMS_CHECK`
- `OSSL_PROV_FIPS_PARAM_DRBG_TRUNC_DIGEST`

All parameters are of type `OSSL_PARAM_UTF8_STRING`.

## Usage Example

```c
#include <openssl/fips_names.h>
#include <openssl/core.h>

/* Query FIPS provider self-test parameters */
OSSL_PARAM params[] = {
    OSSL_PARAM_utf8_string(OSSL_PROV_FIPS_PARAM_MODULE_MAC,
                           mac_buf, sizeof(mac_buf)),
    OSSL_PARAM_utf8_string(OSSL_PROV_FIPS_PARAM_INSTALL_STATUS,
                           status_buf, sizeof(status_buf)),
    OSSL_PARAM_END
};

/* Pass to FIPS provider get_params */
provider_get_params(fips_provider, params);
```
