OpenSSL parameter array API header providing macros and functions for constructing, querying, and manipulating `OSSL_PARAM` structures used to pass typed key-value data between OpenSSL providers and callers.

## Key Components

### Macros — Static Array Construction
| Macro | Purpose |
|---|---|
| `OSSL_PARAM_END` | Null terminator for a parameter array |
| `OSSL_PARAM_DEFN(key, type, addr, sz)` | Base definition macro |
| `OSSL_PARAM_int/uint/long/ulong/int32/uint32/int64/uint64/size_t/time_t/double` | Typed integer/float param definitions |
| `OSSL_PARAM_BN(key, bn, sz)` | BigNumber param definition |
| `OSSL_PARAM_utf8_string/octet_string/utf8_ptr/octet_ptr` | String and buffer param definitions |

### Functions — Runtime Construction
- `OSSL_PARAM_construct_*()` — Build `OSSL_PARAM` structs at runtime for all supported types
- `OSSL_PARAM_construct_end()` — Create the array terminator

### Functions — Lookup
- `OSSL_PARAM_locate()` / `OSSL_PARAM_locate_const()` — Search a param array by key name

### Functions — Get/Set
- `OSSL_PARAM_get_*(p, val)` / `OSSL_PARAM_set_*(p, val)` — Typed accessors for all supported types including `BN`, UTF-8, and octet strings

### Functions — Utilities
- `OSSL_PARAM_allocate_from_text()` — Populate a param from a text key/value pair
- `OSSL_PARAM_modified()` / `OSSL_PARAM_set_all_unmodified()` — Track modification state
- `OSSL_PARAM_dup()` / `OSSL_PARAM_merge()` / `OSSL_PARAM_free()` — Array lifecycle management
- `OSSL_PARAM_print_to_bio()` — Debug output to a BIO

## Usage Example

```c
/* Static array construction */
int my_int = 0;
char my_str[64];

OSSL_PARAM params[] = {
    OSSL_PARAM_int("version", &my_int),
    OSSL_PARAM_utf8_string("name", my_str, sizeof(my_str)),
    OSSL_PARAM_END
};

/* Locate and read a parameter */
const OSSL_PARAM *p = OSSL_PARAM_locate_const(params, "version");
if (p != NULL)
    OSSL_PARAM_get_int(p, &my_int);

/* Runtime construction */
OSSL_PARAM rt_params[2];
int val = 42;
rt_params[0] = OSSL_PARAM_construct_int("answer", &val);
rt_params[1] = OSSL_PARAM_construct_end();

/* Check if a param was modified by the callee */
if (OSSL_PARAM_modified(&params[0]))
    printf("version was set to %d\n", my_int);
```
