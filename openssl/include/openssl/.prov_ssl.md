Defines SSL/TLS and QUIC protocol version constants and limits for use by OpenSSL providers.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `SSL_MAX_MASTER_KEY_LENGTH` | `48` | Maximum master key length in bytes |
| `SSL3_VERSION` | `0x0300` | SSL 3.0 |
| `TLS1_VERSION` | `0x0301` | TLS 1.0 |
| `TLS1_1_VERSION` | `0x0302` | TLS 1.1 |
| `TLS1_2_VERSION` | `0x0303` | TLS 1.2 |
| `TLS1_3_VERSION` | `0x0304` | TLS 1.3 |
| `DTLS1_VERSION` | `0xFEFF` | DTLS 1.0 |
| `DTLS1_2_VERSION` | `0xFEFD` | DTLS 1.2 |
| `DTLS1_BAD_VER` | `0x0100` | Legacy/broken DTLS version identifier |
| `OSSL_QUIC1_VERSION` | `0x0000001` | QUIC version 1 (4-byte encoding) |

## Usage Example

```c
#include <openssl/prov_ssl.h>

/* Validate a TLS protocol version reported by a peer */
int is_supported_tls_version(uint16_t version) {
    switch (version) {
        case TLS1_2_VERSION:
        case TLS1_3_VERSION:
            return 1;
        default:
            return 0;
    }
}

/* Allocate a master key buffer of maximum size */
unsigned char master_key[SSL_MAX_MASTER_KEY_LENGTH];

/* Distinguish QUIC from TLS by version integer width */
int is_quic(uint32_t version) {
    return version == OSSL_QUIC1_VERSION;
}
```

> **Note:** SSL/TLS versions use a 2-byte unsigned integer; QUIC uses a 4-byte unsigned integer — ensure correct integer types when comparing version values across protocols.
