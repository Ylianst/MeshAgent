OpenSSL HMAC (Hash-based Message Authentication Code) header providing both a one-shot HMAC computation function and a legacy context-based streaming API.

## Key Components

### Active API

| Function | Description |
|---|---|
| `HMAC()` | One-shot HMAC computation — the only non-deprecated function in this header |

### Deprecated Context API (removed in OpenSSL 3.0)

| Function | Description |
|---|---|
| `HMAC_CTX_new()` | Allocate a new HMAC context |
| `HMAC_CTX_free()` | Free an HMAC context |
| `HMAC_CTX_reset()` | Reset context for reuse |
| `HMAC_Init_ex()` | Initialize context with key and digest |
| `HMAC_Update()` | Feed data into the HMAC computation |
| `HMAC_Final()` | Finalize and output the HMAC digest |
| `HMAC_CTX_copy()` | Copy context state |
| `HMAC_CTX_get_md()` | Retrieve the digest algorithm from a context |
| `HMAC_size()` | Get output size of the HMAC |

> **Note:** All `HMAC_CTX_*` and `HMAC_Init_ex/Update/Final` functions are deprecated as of OpenSSL 3.0. Use the EVP MAC API (`EVP_MAC_*`) for new code.

## Usage Example

```c
#include <openssl/hmac.h>
#include <openssl/evp.h>

/* One-shot HMAC-SHA256 (current recommended approach) */
const char *key  = "secret";
const char *data = "message to authenticate";
unsigned char digest[EVP_MAX_MD_SIZE];
unsigned int  digest_len = 0;

unsigned char *result = HMAC(
    EVP_sha256(),
    key, (int)strlen(key),
    (const unsigned char *)data, strlen(data),
    digest, &digest_len
);

if (result) {
    /* digest contains digest_len bytes of HMAC-SHA256 output */
}
```

For OpenSSL 3.0+ projects, prefer `EVP_MAC_CTX` via `EVP_MAC_fetch()` for the streaming use case instead of the deprecated context functions.
