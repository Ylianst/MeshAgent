OpenSSL PEM (Privacy Enhanced Mail) header defining constants, macros, and function signatures for encoding and decoding cryptographic objects in PEM format via `FILE*` and `BIO` I/O streams.

## Key Components

### PEM Type String Constants
Defines `PEM_STRING_*` macros for all standard PEM header labels (e.g., `PEM_STRING_X509`, `PEM_STRING_RSA`, `PEM_STRING_PKCS8`, `PEM_STRING_ECPRIVATEKEY`).

### PEM Type Flags
- `PEM_TYPE_ENCRYPTED` (10)
- `PEM_TYPE_MIC_ONLY` (20)
- `PEM_TYPE_MIC_CLEAR` (30)
- `PEM_TYPE_CLEAR` (40)

### Function Signature Macros
Templates for generating consistent PEM I/O function prototypes:
- `PEM_read_cb_fnsig` / `PEM_read_cb_ex_fnsig` — read with password callback (+ optional `OSSL_LIB_CTX`)
- `PEM_write_fnsig` / `PEM_write_cb_fnsig` — write with/without encryption callback
- `PEM_write_ex_fnsig` / `PEM_write_cb_ex_fnsig` — extended variants with library context

### Implementation Macros
Inline function body generators for PEM read/write over `FILE*` and `BIO`:
- `IMPLEMENT_PEM_read_fp` / `IMPLEMENT_PEM_read_bio`
- `IMPLEMENT_PEM_write_fp` / `IMPLEMENT_PEM_write_bio`
- `IMPLEMENT_PEM_write_cb_fp` / `IMPLEMENT_PEM_write_cb_bio`
- Composite: `IMPLEMENT_PEM_rw`, `IMPLEMENT_PEM_rw_cb`

### Declaration Macros
Forward-declaration helpers (e.g., `DECLARE_PEM_read_fp`, `DECLARE_PEM_write_cb_fp`) respecting `OPENSSL_NO_STDIO` guards.

## Usage Example

```c
#include <openssl/pem.h>
#include <openssl/x509.h>
#include <stdio.h>

/* Read a certificate from a PEM file */
X509 *load_cert(const char *path) {
    FILE *fp = fopen(path, "r");
    if (!fp) return NULL;

    X509 *cert = PEM_read_X509(fp, NULL, NULL, NULL);
    fclose(fp);
    return cert;
}

/* Write a certificate to a PEM file */
int save_cert(X509 *cert, const char *path) {
    FILE *fp = fopen(path, "w");
    if (!fp) return 0;

    int rc = PEM_write_X509(fp, cert);
    fclose(fp);
    return rc;
}

/* Write an encrypted private key using a password callback */
int save_private_key(EVP_PKEY *pkey, FILE *fp,
                     pem_password_cb *cb, void *userdata) {
    return PEM_write_PrivateKey(fp, pkey,
                                EVP_aes_256_cbc(),
                                NULL, 0, cb, userdata);
}
```
