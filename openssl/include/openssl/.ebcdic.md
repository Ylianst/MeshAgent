Provides EBCDIC-to-ASCII and ASCII-to-EBCDIC character encoding conversion utilities, part of the OpenSSL library's platform compatibility layer for mainframe (z/OS, OS/390) environments.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `os_toascii` | `const unsigned char[256]` | Lookup table mapping EBCDIC byte values to ASCII |
| `os_toebcdic` | `const unsigned char[256]` | Lookup table mapping ASCII byte values to EBCDIC |
| `ebcdic2ascii()` | Function | Converts a buffer from EBCDIC encoding to ASCII in-place |
| `ascii2ebcdic()` | Function | Converts a buffer from ASCII encoding to EBCDIC in-place |

All symbols are prefixed with `_openssl_` via macros to avoid name collisions with system or third-party libraries.

## Usage Example

```c
#include <openssl/ebcdic.h>
#include <string.h>

int main(void) {
    /* Single-byte table lookup: EBCDIC -> ASCII */
    unsigned char ebcdic_char = 0xC1; /* EBCDIC 'A' */
    unsigned char ascii_char  = os_toascii[ebcdic_char];

    /* Buffer conversion: ASCII -> EBCDIC */
    const char *src = "Hello";
    char dest[6];
    memset(dest, 0, sizeof(dest));
    ascii2ebcdic(dest, src, strlen(src));

    /* Convert back: EBCDIC -> ASCII */
    char roundtrip[6];
    memset(roundtrip, 0, sizeof(roundtrip));
    ebcdic2ascii(roundtrip, dest, strlen(src));

    return 0;
}
```

> **Note:** `ebcdic2ascii()` and `ascii2ebcdic()` write directly into `dest` and return a pointer to it. The caller is responsible for ensuring `dest` has sufficient space (`count` bytes).
