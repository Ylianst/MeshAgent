Defines the known object type constants used with `OSSL_PARAM` parameter `OSSL_OBJECT_PARAM_TYPE` for OpenSSL's provider-core object identification system.

## Key Components

| Constant | Value | Corresponding Type |
|---|---|---|
| `OSSL_OBJECT_UNKNOWN` | `0` | Unknown/unrecognized object |
| `OSSL_OBJECT_NAME` | `1` | `char *` |
| `OSSL_OBJECT_PKEY` | `2` | `EVP_PKEY *` |
| `OSSL_OBJECT_CERT` | `3` | `X509 *` |
| `OSSL_OBJECT_CRL` | `4` | `X509_CRL *` |

## Usage Example

```c
#include <openssl/core_object.h>
#include <openssl/core_names.h>

/* Inspect an OSSL_PARAM array to determine what object type was returned */
void inspect_object_type(const OSSL_PARAM params[]) {
    const OSSL_PARAM *p = OSSL_PARAM_locate_const(params, OSSL_OBJECT_PARAM_TYPE);
    int object_type = OSSL_OBJECT_UNKNOWN;

    if (p != NULL)
        OSSL_PARAM_get_int(p, &object_type);

    switch (object_type) {
        case OSSL_OBJECT_NAME:
            /* Handle as char * name */
            break;
        case OSSL_OBJECT_PKEY:
            /* Handle as EVP_PKEY * */
            break;
        case OSSL_OBJECT_CERT:
            /* Handle as X509 * */
            break;
        case OSSL_OBJECT_CRL:
            /* Handle as X509_CRL * */
            break;
        default:
            /* Unknown object */
            break;
    }
}
```

> **Note:** Additional associated `OSSL_PARAM` element descriptions (such as `OSSL_OBJECT_PARAM_TYPE`) are defined in `core_names.h`.
