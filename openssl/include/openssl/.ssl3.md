SSL/TLS version 3 protocol constants, cipher suite identifiers, and record layer size definitions used by OpenSSL's SSL/TLS implementation.

## Key Components

### Signalling Cipher Suite Values (SCSVs)
- `SSL3_CK_SCSV` — Renegotiation info signal (RFC 5746, `0x030000FF`)
- `SSL3_CK_FALLBACK_SCSV` — Downgrade prevention signal (`0x03005600`)

### Cipher Suite Identifiers (`SSL3_CK_*`)
Numeric codes for all SSLv3 cipher suites across key exchange types:
- **RSA** — `SSL3_CK_RSA_NULL_MD5` through `SSL3_CK_RSA_DES_192_CBC3_SHA`
- **DH/DHE/EDH** — Static and ephemeral Diffie-Hellman variants with DSS/RSA
- **ADH** — Anonymous DH suites (no authentication)

### Cipher Suite Names
- `SSL3_RFC_*` — RFC-standard cipher names (e.g., `"TLS_RSA_WITH_3DES_EDE_CBC_SHA"`)
- `SSL3_TXT_*` — OpenSSL short names (e.g., `"DES-CBC3-SHA"`)
- `SSL3_TXT_EDH_*` — Legacy aliases for backward compatibility; prefer `SSL3_TXT_DHE_*`

### Protocol Size Constants
| Constant | Value | Purpose |
|---|---|---|
| `SSL3_MASTER_SECRET_SIZE` | 48 | Master secret length |
| `SSL3_RANDOM_SIZE` | 32 | Client/server random length |
| `SSL3_RT_HEADER_LENGTH` | 5 | Record layer header size |
| `SSL3_RT_MAX_PLAIN_LENGTH` | 16384 | Max plaintext per record |
| `SSL3_RT_MAX_MD_SIZE` | 64 | Max MAC/digest size |
| `SSL3_ALIGN_PAYLOAD` | 8 | Payload alignment for performance |

### Record Content Types (`SSL3_RT_*`)
- Standard: `CHANGE_CIPHER_SPEC` (20), `ALERT` (21), `HANDSHAKE` (22), `APPLICATION_DATA` (23)
- Pseudo: `SSL3_RT_HEADER`, `SSL3_RT_INNER_CONTENT_TYPE`
- QUIC extensions: `SSL3_RT_QUIC_DATAGRAM` through `SSL3_RT_QUIC_FRAME_PADDING`

### Alert Definitions
- Levels: `SSL3_AL_WARNING` (1), `SSL3_AL_FATAL` (2)
- Codes: `SSL3_AD_CLOSE_NOTIFY` (0) through `SSL3_AD_ILLEGAL_PARAMETER` (47)

## Usage Example

```c
#include <openssl/ssl3.h>

/* Check record content type */
void inspect_record(int content_type, size_t length) {
    if (content_type == SSL3_RT_HANDSHAKE) {
        /* Validate record does not exceed max plain length */
        if (length > SSL3_RT_MAX_PLAIN_LENGTH) {
            /* Handle oversized record */
        }
    }

    if (content_type == SSL3_RT_ALERT) {
        /* Process alert record */
    }
}

/* Reference a cipher suite by its OpenSSL short name */
const char *suite = SSL3_TXT_RSA_DES_192_CBC3_SHA; /* "DES-CBC3-SHA" */
```

> **Note:** SSLv3 cipher suites defined here are deprecated and insecure. Use TLS 1.2+ cipher suites from `tls1.h` in production code.
