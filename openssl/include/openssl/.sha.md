OpenSSL public header declaring the SHA-1, SHA-224, SHA-256, SHA-384, and SHA-512 hash algorithm interfaces, including both legacy low-level context APIs (deprecated in OpenSSL 3.0) and the current one-shot convenience functions.

## Key Components

### Digest Length Constants

| Constant | Value |
|---|---|
| `SHA_DIGEST_LENGTH` | 20 bytes (SHA-1) |
| `SHA224_DIGEST_LENGTH` | 28 bytes |
| `SHA256_DIGEST_LENGTH` | 32 bytes |
| `SHA384_DIGEST_LENGTH` | 48 bytes |
| `SHA512_DIGEST_LENGTH` | 64 bytes |

### Context Structs (deprecated since OpenSSL 3.0)

- **`SHA_CTX`** — SHA-1 state (five 32-bit words + block buffer)
- **`SHA256_CTX`** — Shared state for SHA-224 and SHA-256 (eight 32-bit words)
- **`SHA512_CTX`** — Shared state for SHA-384 and SHA-512 (eight 64-bit words, union buffer)

### Low-Level API (deprecated, `OPENSSL_NO_DEPRECATED_3_0`)

Streaming `Init` / `Update` / `Final` + block-level `Transform` for each algorithm family (SHA1, SHA224/256, SHA384/512).

### One-Shot API (current, preferred)

```c
unsigned char *SHA1  (const unsigned char *d, size_t n, unsigned char *md);
unsigned char *SHA224(const unsigned char *d, size_t n, unsigned char *md);
unsigned char *SHA256(const unsigned char *d, size_t n, unsigned char *md);
unsigned char *SHA384(const unsigned char *d, size_t n, unsigned char *md);
unsigned char *SHA512(const unsigned char *d, size_t n, unsigned char *md);
```

## Usage Example

```c
#include <openssl/sha.h>
#include <stdio.h>

int main(void) {
    const unsigned char data[] = "hello";
    unsigned char digest[SHA256_DIGEST_LENGTH];

    /* Preferred one-shot API */
    SHA256(data, sizeof(data) - 1, digest);

    for (int i = 0; i < SHA256_DIGEST_LENGTH; i++)
        printf("%02x", digest[i]);
    printf("\n");
    return 0;
}
```

> **Note:** The low-level `SHA256_Init` / `SHA256_Update` / `SHA256_Final` streaming API is marked `OSSL_DEPRECATEDIN_3_0`. Prefer the one-shot functions above or the higher-level EVP digest API (`EVP_DigestInit_ex`, `EVP_DigestUpdate`, `EVP_DigestFinal_ex`) for new code.
