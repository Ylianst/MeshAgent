OpenSSL header defining the CAST-128 symmetric block cipher interface. All functions and types declared here are deprecated as of OpenSSL 3.0 and should not be used in new code.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `CAST_BLOCK` | `8` | Block size in bytes |
| `CAST_KEY_LENGTH` | `16` | Maximum key length in bytes |
| `CAST_ENCRYPT` | `1` | Encrypt operation flag |
| `CAST_DECRYPT` | `0` | Decrypt operation flag |

### Types

- **`CAST_KEY`** — Key schedule structure containing 32 `CAST_LONG` subkey words and a `short_key` flag for reduced-round operation with shorter keys

### Functions (all deprecated in OpenSSL 3.0)

| Function | Description |
|---|---|
| `CAST_set_key` | Expands a raw key into a `CAST_KEY` schedule |
| `CAST_ecb_encrypt` | Encrypts/decrypts a single ECB block |
| `CAST_encrypt` / `CAST_decrypt` | Low-level single-block operations |
| `CAST_cbc_encrypt` | CBC mode encryption/decryption |
| `CAST_cfb64_encrypt` | CFB-64 mode streaming encryption |
| `CAST_ofb64_encrypt` | OFB-64 mode streaming encryption |

## Usage Example

> ⚠️ **Deprecated:** Avoid in new code. Use the EVP API (`EVP_EncryptInit_ex`, etc.) with `EVP_cast5_cbc()` instead.

```c
#include <openssl/cast.h>

/* Legacy CAST-128 CBC encryption (deprecated, OpenSSL < 3.0 only) */
CAST_KEY key;
unsigned char raw_key[CAST_KEY_LENGTH] = { /* 16 bytes */ };
unsigned char iv[CAST_BLOCK]           = { /* 8 bytes  */ };
unsigned char plaintext[8]  = "example!";
unsigned char ciphertext[8] = {0};

CAST_set_key(&key, CAST_KEY_LENGTH, raw_key);
CAST_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                 &key, iv, CAST_ENCRYPT);
```
