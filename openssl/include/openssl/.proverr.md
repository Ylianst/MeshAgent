Auto-generated OpenSSL header defining numeric reason codes for the provider (`PROV`) error subsystem, used to identify specific failure conditions across cryptographic operations.

## Key Components

### Error Code Macros (`PROV_R_*`)

A flat set of `#define` constants mapping human-readable error names to unique integer codes. Codes are grouped loosely by functional area:

| Category | Example Codes |
|---|---|
| Cipher / Encryption | `PROV_R_BAD_DECRYPT` (100), `PROV_R_CIPHER_OPERATION_FAILED` (102) |
| Key Management | `PROV_R_INVALID_KEY` (158), `PROV_R_MISSING_KEY` (128) |
| DRBG / Entropy | `PROV_R_ERROR_RETRIEVING_ENTROPY` (189), `PROV_R_NOT_INSTANTIATED` (193) |
| FIPS Module | `PROV_R_FIPS_MODULE_IN_ERROR_STATE` (225), `PROV_R_SELF_TEST_POST_FAILURE` (216) |
| KDF / Derivation | `PROV_R_DERIVATION_FUNCTION_INIT_FAILED` (205), `PROV_R_FAILED_DURING_DERIVATION` (164) |
| ML-DSA / ML-KEM | `PROV_R_ML_DSA_NO_FORMAT` (245), `PROV_R_ML_KEM_NO_FORMAT` (246) |
| Padding | `PROV_R_ILLEGAL_OR_UNSUPPORTED_PADDING_MODE` (165), `PROV_R_PSS_SALTLEN_TOO_SMALL` (172) |

## Usage Example

```c
#include <openssl/proverr.h>
#include <openssl/err.h>

/* Check a provider error after a failed operation */
unsigned long err_code = ERR_get_error();

if (ERR_GET_REASON(err_code) == PROV_R_INVALID_KEY_LENGTH) {
    fprintf(stderr, "Provider error: invalid key length\n");
}
```
