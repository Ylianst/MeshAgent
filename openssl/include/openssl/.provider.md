Public API header for managing OpenSSL providers — loadable modules that supply cryptographic algorithm implementations to an `OSSL_LIB_CTX`.

## Key Components

| Function | Purpose |
|---|---|
| `OSSL_PROVIDER_set_default_search_path` / `get0_default_search_path` | Configure the filesystem path used to locate provider shared libraries |
| `OSSL_PROVIDER_load` / `load_ex` | Load a named provider, optionally passing `OSSL_PARAM` configuration |
| `OSSL_PROVIDER_try_load` / `try_load_ex` | Attempt to load without failing if the provider is unavailable; controls fallback retention |
| `OSSL_PROVIDER_unload` | Release a loaded provider |
| `OSSL_PROVIDER_available` | Check whether a named provider is currently available |
| `OSSL_PROVIDER_do_all` | Iterate over all active providers via a callback |
| `OSSL_PROVIDER_get_params` / `gettable_params` | Retrieve runtime parameters from a provider |
| `OSSL_PROVIDER_self_test` | Trigger the provider's internal self-test |
| `OSSL_PROVIDER_get_capabilities` | Query provider-advertised capabilities |
| `OSSL_PROVIDER_add_conf_parameter` / `get_conf_parameters` / `conf_get_bool` | Set and retrieve UTF-8 configuration parameters; parse boolean values |
| `OSSL_PROVIDER_query_operation` / `unquery_operation` | Look up algorithm implementations for a given operation ID |
| `OSSL_PROVIDER_add_builtin` | Register a statically linked provider with a custom init function |
| `OSSL_PROVIDER_get0_name` | Return the provider's registered name |

## Usage Example

```c
#include <openssl/provider.h>

/* Load the built-in "default" and "legacy" providers */
OSSL_LIB_CTX *libctx = OSSL_LIB_CTX_new();

OSSL_PROVIDER_set_default_search_path(libctx, "/usr/lib/ossl-modules");

OSSL_PROVIDER *deflt = OSSL_PROVIDER_load(libctx, "default");
OSSL_PROVIDER *legacy = OSSL_PROVIDER_try_load(libctx, "legacy", 1);

if (deflt == NULL) {
    /* handle error */
}

/* Query a boolean config parameter */
int fips_approved_only = OSSL_PROVIDER_conf_get_bool(deflt,
                                                     "fips_approved_only",
                                                     0);

/* Clean up */
OSSL_PROVIDER_unload(legacy);
OSSL_PROVIDER_unload(deflt);
OSSL_LIB_CTX_free(libctx);
```
