TLS 1.x protocol constants, extension type definitions, alert codes, and function declarations for OpenSSL's TLS implementation.

## Key Components

### Version Constants
- `TLS_ANY_VERSION` (`0x10000`) — sentinel for multi-version methods
- `TLS1_VERSION_MAJOR/MINOR`, `TLS1_1_*`, `TLS1_2_*` — wire-format version bytes
- `TLS1_get_version(s)` / `TLS1_get_client_version(s)` — macros to extract TLS version from an `SSL*`

### Alert Codes (`TLS1_AD_*`, `TLS13_AD_*`)
Numeric alert codes from RFC 5246/8446, e.g. `TLS1_AD_UNKNOWN_CA` (48), `TLS13_AD_MISSING_EXTENSION` (109).

### Extension Types (`TLSEXT_TYPE_*`)
IANA-assigned extension type values covering:
- SNI (`server_name = 0`), ALPN (`application_layer_protocol_negotiation = 16`), session tickets (`session_ticket = 35`)
- TLS 1.3 extensions: `psk` (41), `key_share` (51), `supported_versions` (43), `early_data` (42)
- Raw Public Keys: `client_cert_type` (19), `server_cert_type` (20)

### Signature & Hash Algorithm Identifiers
`TLSEXT_signature_*` and `TLSEXT_hash_*` constants including GOST algorithm support.

### Certificate Compression (`TLSEXT_comp_cert_*`)
Values for RFC 8879 certificate compression: `zlib`, `brotli`, `zstd`.

### Key Public Functions
- `SSL_export_keying_material()` — RFC 5705 keying material export
- `SSL_export_keying_material_early()` — TLS 1.3 early exporter secret
- `SSL_get_peer_signature_type_nid()` / `SSL_get_signature_type_nid()`
- `SSL_get_sigalgs()` / `SSL_get_shared_sigalgs()` — signature algorithm negotiation
- `SSL_check_chain()` — certificate chain validation
- `SSL_CTX_set_tlsext_max_fragment_length()` / `SSL_set_tlsext_max_fragment_length()`

## Usage Example

```c
#include <openssl/tls1.h>

/* Export RFC 5705 keying material */
unsigned char out[32];
if (SSL_export_keying_material(ssl, out, sizeof(out),
                               "EXPORTER-my-app", 15,
                               NULL, 0, 0) != 1) {
    /* handle error */
}

/* Check negotiated TLS version */
int ver = TLS1_get_version(ssl);
if (ver == TLS1_3_VERSION) {
    /* TLS 1.3 path */
}

/* Set SNI hostname before connect */
SSL_set_tlsext_host_name(ssl, "example.com");

/* Restrict max fragment length to 4096 bytes */
SSL_set_tlsext_max_fragment_length(ssl, TLSEXT_max_fragment_length_4096);
```
