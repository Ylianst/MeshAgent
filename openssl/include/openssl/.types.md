Forward declarations and opaque type aliases for all major OpenSSL data structures, providing a single inclusion point for type definitions used across the OpenSSL API.

## Key Components

**ASN.1 Types**
- `ASN1_INTEGER`, `ASN1_BIT_STRING`, `ASN1_OCTET_STRING`, `ASN1_UTF8STRING`, etc. — all aliased to `asn1_string_st` (or `ASN1_STRING` when `NO_ASN1_TYPEDEFS` is defined)
- `ASN1_BOOLEAN`, `ASN1_NULL` — mapped to `int`

**Cryptographic Primitives**
- `BIGNUM`, `BN_CTX`, `BN_MONT_CTX`, `BN_RECP_CTX`, `BN_BLINDING`, `BN_GENCB` — big number arithmetic
- `EVP_CIPHER`, `EVP_CIPHER_CTX`, `EVP_MD`, `EVP_MD_CTX` — symmetric cipher and digest contexts
- `EVP_MAC`, `EVP_KDF`, `EVP_RAND`, `EVP_PKEY`, `EVP_SKEY` — MAC, KDF, PRNG, and key objects
- `HMAC_CTX` — HMAC context

**PKI / X.509**
- `X509`, `X509_CRL`, `X509_NAME`, `X509_STORE`, `X509_STORE_CTX`, `X509_VERIFY_PARAM`
- `OCSP_RESPONSE`, `OCSP_RESPID`, `SCT`, `CTLOG` — OCSP and Certificate Transparency

**Legacy Algorithm Types** *(deprecated since 3.0)*
- `RSA`, `DSA`, `EC_KEY`, `DH` — conditionally compiled via `OPENSSL_NO_DEPRECATED_3_0`

**Provider / OSSL Framework**
- `OSSL_PROVIDER`, `OSSL_LIB_CTX`, `OSSL_DISPATCH`, `OSSL_PARAM`, `OSSL_ALGORITHM`
- `OSSL_ENCODER`, `OSSL_DECODER`, `OSSL_SELF_TEST`

**Utility**
- `BIO`, `BUF_MEM`, `ENGINE`, `SSL`, `SSL_CTX`, `CONF`
- `pem_password_cb` — callback typedef for PEM password prompts
- `OSSL_FUTURE_CONST` — macro set to `const` in OpenSSL 4+, empty otherwise

## Usage Example

```c
#include <openssl/types.h>

/* Use opaque types without knowing their internal layout */
EVP_MD_CTX *ctx = EVP_MD_CTX_new();
EVP_PKEY    *key = NULL;
X509        *cert = NULL;
OSSL_LIB_CTX *libctx = OSSL_LIB_CTX_new();

/* pem_password_cb signature */
int my_passwd_cb(char *buf, int size, int rwflag, void *userdata) {
    strncpy(buf, (char *)userdata, size);
    return (int)strlen(buf);
}
```
