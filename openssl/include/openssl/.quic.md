Public QUIC SSL method declarations and RFC 9000 transport error code constants for OpenSSL's QUIC implementation.

## Key Components

### SSL Methods
| Function | Description |
|---|---|
| `OSSL_QUIC_client_method()` | Returns `SSL_METHOD` for standard (non-thread-assisted) QUIC client operation |
| `OSSL_QUIC_client_thread_method()` | Returns `SSL_METHOD` for thread-assisted QUIC client operation |
| `OSSL_QUIC_server_method()` | Returns `SSL_METHOD` for QUIC server operation |

### Transport Error Codes (RFC 9000 §20.1)
Standard QUIC error codes in the range `0x00`–`0x10`, including:
- `OSSL_QUIC_ERR_NO_ERROR` (`0x00`) — clean close
- `OSSL_QUIC_ERR_INTERNAL_ERROR` (`0x01`)
- `OSSL_QUIC_ERR_FLOW_CONTROL_ERROR` (`0x03`)
- `OSSL_QUIC_ERR_PROTOCOL_VIOLATION` (`0x0A`)
- `OSSL_QUIC_ERR_AEAD_LIMIT_REACHED` (`0x0F`)

### Crypto Error Range
- `OSSL_QUIC_ERR_CRYPTO_ERR_BEGIN` / `OSSL_QUIC_ERR_CRYPTO_ERR_END` (`0x0100`–`0x01FF`) — TLS alert-mapped errors
- `OSSL_QUIC_ERR_CRYPTO_ERR(X)` — macro to compute a crypto error from a TLS alert code

### Local Errors
- `OSSL_QUIC_LOCAL_ERR_IDLE_TIMEOUT` (`0xFFFFFFFFFFFFFFFF`) — local idle timeout sentinel

## Usage Example

```c
#include <openssl/quic.h>

/* Create a QUIC client SSL context */
SSL_CTX *ctx = SSL_CTX_new(OSSL_QUIC_client_method());

/* Or use thread-assisted mode for non-blocking I/O */
SSL_CTX *ctx_threaded = SSL_CTX_new(OSSL_QUIC_client_thread_method());

/* Map a TLS alert (e.g., alert 40) to a QUIC crypto error code */
uint64_t err = OSSL_QUIC_ERR_CRYPTO_ERR(40);
/* err == 0x0128 */

/* Server-side context */
SSL_CTX *srv_ctx = SSL_CTX_new(OSSL_QUIC_server_method());
```

> **Note:** All symbols are conditionally compiled under `OPENSSL_NO_QUIC`. Ensure your OpenSSL build includes QUIC support before using this header.
