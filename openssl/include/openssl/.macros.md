Portable utility macros for OpenSSL, providing cross-compiler abstractions for deprecation annotations, API compatibility level gating, string composition, and diagnostic helpers.

## Key Components

| Macro | Purpose |
|---|---|
| `OPENSSL_MSTR(x)` | Stringifies a preprocessor token via double-expansion |
| `NON_EMPTY_TRANSLATION_UNIT` | Silences compiler warnings on otherwise-empty translation units |
| `OSSL_DEPRECATED(since)` | Marks a declaration deprecated since a given OpenSSL version (MSVC/GCC/Clang/Sun) |
| `OSSL_DEPRECATED_FOR(since, msg)` | Same as above but attaches a migration message |
| `OPENSSL_API_LEVEL` | Normalized integer API level derived from `OPENSSL_API_COMPAT` or the build-configured default |
| `OSSL_DEPRECATEDIN_X_Y[_FOR]` | Per-version guards; emit deprecation attributes when the target API level meets or exceeds that version |
| `OPENSSL_NO_DEPRECATED_X_Y` | Defined when deprecated symbols for that version should be excluded |
| `OPENSSL_FILE` / `OPENSSL_LINE` | Redefinable wrappers for `__FILE__`/`__LINE__`; collapse to empty/0 when `OPENSSL_NO_FILENAMES` is set |
| `OPENSSL_FUNC` | Portable function-name macro (`__func__`, `__FUNCTION__`, or `"(unknown function)"`) |
| `OSSL_CRYPTO_ALLOC` | Annotates allocator functions (`__attribute__((malloc))` / `__declspec(restrict)`) |

## Usage Example

```c
/* Suppress deprecation warnings for APIs removed in OpenSSL 3.0 */
#define OPENSSL_API_COMPAT 30000
#include <openssl/macros.h>

/* Mark a function deprecated since 3.0, with a migration hint */
OSSL_DEPRECATEDIN_3_0_FOR("Use EVP_DigestInit_ex2 instead")
int legacy_digest_init(void);

/* Allocator annotation */
OSSL_CRYPTO_ALLOC void *my_alloc(size_t n);

/* Stringify a version constant at compile time */
const char *ver = "Built against OpenSSL " OPENSSL_MSTR(OPENSSL_VERSION_MAJOR);

/* Use portable source location */
printf("%s:%d [%s]\n", OPENSSL_FILE, OPENSSL_LINE, OPENSSL_FUNC);
```

> **API level format:** For OpenSSL 3.x and later, pass `MAJOR * 10000 + MINOR * 100` (e.g., `30200` for 3.2). Legacy 0.x/1.x builds accept the packed hex form `0xMNNFFPPSL`.
