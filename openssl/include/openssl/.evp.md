OpenSSL's primary high-level cryptographic API header, providing a unified interface for message digests, symmetric ciphers, asymmetric keys, and related cryptographic operations.

## Key Components

### Constants & Macros
- **Size limits**: `EVP_MAX_MD_SIZE` (64), `EVP_MAX_KEY_LENGTH` (64), `EVP_MAX_IV_LENGTH` (16), `EVP_MAX_BLOCK_LENGTH` (32)
- **Key type identifiers**: `EVP_PKEY_RSA`, `EVP_PKEY_EC`, `EVP_PKEY_ED25519`, `EVP_PKEY_X25519`, `EVP_PKEY_ML_DSA_*`, `EVP_PKEY_SLH_DSA_*` (post-quantum)
- **Key selection flags**: `EVP_PKEY_PUBLIC_KEY`, `EVP_PKEY_PRIVATE_KEY`, `EVP_PKEY_KEYPAIR`, `EVP_PKEY_KEY_PARAMETERS`
- **MD context flags**: `EVP_MD_CTX_FLAG_ONESHOT`, `EVP_MD_CTX_FLAG_FINALISE`, `EVP_MD_CTX_FLAG_PAD_PSS`

### Core API Groups
- **Digest (MD)**: `EVP_MD_CTX_*`, `EVP_DigestInit_ex`, `EVP_DigestUpdate`, `EVP_DigestFinal_ex`
- **Cipher**: `EVP_CIPHER_CTX_*`, `EVP_EncryptInit_ex`, `EVP_DecryptFinal_ex`
- **Public Key**: `EVP_PKEY_*` operations for sign, verify, encrypt, decrypt, key exchange
- **Properties**: `EVP_set_default_properties`, `EVP_default_properties_enable_fips`

### Deprecated (pre-3.0)
`EVP_MD_meth_*` and `EVP_CIPHER_meth_*` low-level method constructors — replaced by the provider-based API in OpenSSL 3.0.

## Usage Example

```c
/* Compute SHA-256 digest */
EVP_MD_CTX *ctx = EVP_MD_CTX_new();
const EVP_MD *md = EVP_sha256();
unsigned char digest[EVP_MAX_MD_SIZE];
unsigned int digest_len;

EVP_DigestInit_ex(ctx, md, NULL);
EVP_DigestUpdate(ctx, data, data_len);
EVP_DigestFinal_ex(ctx, digest, &digest_len);
EVP_MD_CTX_free(ctx);

/* Enable FIPS mode globally */
EVP_default_properties_enable_fips(NULL, 1);
```
