OpenSSL Certificate Management Protocol (CMP) public header defining RFC 4210/RFC 9483 data types, status codes, failure info bit flags, and the core API for PKI certificate lifecycle operations (enrollment, update, revocation).

## Key Components

### Constants & Macros

| Name | Purpose |
|---|---|
| `OSSL_CMP_PVNO_2` / `OSSL_CMP_PVNO_3` | CMP protocol version numbers (default: v2) |
| `OSSL_CMP_PKIFAILUREINFO_*` | Bit positions (0–26) for PKI failure reason codes |
| `OSSL_CMP_CTX_FAILINFO_*` | Bitmask flags (powers of 2) for failure info in context |
| `OSSL_CMP_PKISTATUS_*` | PKI status integers: `accepted(0)` through `keyUpdateWarning(6)`, plus internal sentinels (-3 to -1) |
| `OSSL_CMP_CERTORENCCERT_*` | Discriminates plain certificate (0) vs. encrypted cert (1) |

## Usage Example

```c
#include <openssl/cmp.h>

/* Create a CMP context and check failure info after an operation */
OSSL_CMP_CTX *ctx = OSSL_CMP_CTX_new(NULL, NULL);

/* After a failed CMP exchange, inspect failure bits */
int failinfo = OSSL_CMP_CTX_get_failInfoCode(ctx);
if (failinfo & OSSL_CMP_CTX_FAILINFO_badRequest) {
    fprintf(stderr, "CMP error: bad request\n");
}
if (failinfo & OSSL_CMP_CTX_FAILINFO_certRevoked) {
    fprintf(stderr, "CMP error: certificate already revoked\n");
}

OSSL_CMP_CTX_free(ctx);
```
