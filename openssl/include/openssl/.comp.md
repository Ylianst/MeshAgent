OpenSSL compression API header providing context management, block-level compression/decompression, and SSL compression method support via zlib, brotli, and zstd backends.

## Key Components

### Context Management
- `COMP_CTX_new(meth)` — allocates a new compression context for the given method
- `COMP_CTX_free(ctx)` — releases a compression context
- `COMP_CTX_get_method(ctx)` — retrieves the method associated with a context
- `COMP_CTX_get_type(ctx)` / `COMP_get_type(meth)` — returns the numeric type identifier
- `COMP_get_name(meth)` — returns the human-readable method name

### Compression Operations
- `COMP_compress_block(ctx, out, olen, in, ilen)` — compresses a block of data
- `COMP_expand_block(ctx, out, olen, in, ilen)` — decompresses a block of data

### Compression Methods
| Function | Description |
|---|---|
| `COMP_zlib()` | Streaming zlib method |
| `COMP_zlib_oneshot()` | One-shot zlib method |
| `COMP_brotli()` | Streaming brotli method |
| `COMP_brotli_oneshot()` | One-shot brotli method |
| `COMP_zstd()` | Streaming zstd method |
| `COMP_zstd_oneshot()` | One-shot zstd method |

### BIO Filter Methods (when `OPENSSL_BIO_H` is included)
- `BIO_f_zlib()`, `BIO_f_brotli()`, `BIO_f_zstd()` — BIO filter methods for transparent compression in I/O chains

### SSL Compression Stack (`SSL_COMP`)
Type-safe stack macros (`sk_SSL_COMP_*`) wrapping `OPENSSL_sk_*` for managing ordered collections of `SSL_COMP` entries used internally by the TLS stack.

## Usage Example

```c
#include <openssl/comp.h>

/* Compress a buffer using zlib */
COMP_METHOD *method = COMP_zlib();
COMP_CTX    *ctx    = COMP_CTX_new(method);

unsigned char out[4096];
unsigned char in[]  = "Hello, compressed world!";

int compressed_len = COMP_compress_block(ctx, out, sizeof(out),
                                         in, sizeof(in) - 1);
if (compressed_len < 0) {
    /* handle error */
}

unsigned char restored[4096];
int restored_len = COMP_expand_block(ctx, restored, sizeof(restored),
                                     out, compressed_len);

COMP_CTX_free(ctx);
```

> **Note:** Compression support is conditionally compiled. Guard usage with `#ifndef OPENSSL_NO_COMP` checks in consuming code.
