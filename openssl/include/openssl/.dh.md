OpenSSL Diffie-Hellman (DH) key exchange API header providing parameter generation, key management, and KDF configuration interfaces for both legacy low-level and modern EVP-based usage.

## Key Components

### Parameter Generation Type Constants
| Macro | Value | Description |
|---|---|---|
| `DH_PARAMGEN_TYPE_GENERATOR` | `0` | Safe prime generator |
| `DH_PARAMGEN_TYPE_FIPS_186_2` | `1` | FIPS 186-2 standard |
| `DH_PARAMGEN_TYPE_FIPS_186_4` | `2` | FIPS 186-4 standard |
| `DH_PARAMGEN_TYPE_GROUP` | `3` | Named safe prime group |

### EVP_PKEY_CTX Functions (Modern API)
- **`EVP_PKEY_CTX_set_dh_paramgen_type()`** — Sets parameter generation method
- **`EVP_PKEY_CTX_set_dh_paramgen_prime_len()`** — Sets prime length in bits
- **`EVP_PKEY_CTX_set_dh_nid()`** — Sets named group by NID (e.g., RFC 7919)
- **`EVP_PKEY_CTX_set_dh_kdf_type()`** / **`get`** — Configures X9.42 KDF
- **`EVP_PKEY_CTX_set_dh_kdf_md()`** — Sets KDF digest algorithm
- **`EVP_PKEY_CTX_set0_dh_kdf_ukm()`** — Sets user keying material

### Legacy Low-Level API (Deprecated in OpenSSL 3.0)
- **`DH_new()`** / **`DH_free()`** — Lifecycle management
- **`DH_generate_parameters_ex()`** — Parameter generation
- **`DH_generate_key()`** / **`DH_compute_key()`** — Key exchange
- **`DH_check()`** / **`DH_check_pub_key()`** — Parameter and key validation
- **`DH_get0_pqg()`** / **`DH_set0_pqg()`** — Access prime `p`, subprime `q`, generator `g`

### Modulus Limits
- `OPENSSL_DH_MAX_MODULUS_BITS` — `10000`
- `OPENSSL_DH_CHECK_MAX_MODULUS_BITS` — `32768`
- `OPENSSL_DH_FIPS_MIN_MODULUS_BITS` — `1024`

## Usage Example

```c
/* Modern EVP-based DH key generation (OpenSSL 3.x preferred) */
EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_DH, NULL);
EVP_PKEY_paramgen_init(ctx);

/* Use RFC 7919 named group */
EVP_PKEY_CTX_set_dh_paramgen_type(ctx, DH_PARAMGEN_TYPE_GROUP);
EVP_PKEY_CTX_set_dh_nid(ctx, NID_ffdhe2048);

EVP_PKEY *params = NULL;
EVP_PKEY_paramgen(ctx, &params);

/* Generate key pair from params */
EVP_PKEY_CTX *kctx = EVP_PKEY_CTX_new(params, NULL);
EVP_PKEY *pkey = NULL;
EVP_PKEY_keygen_init(kctx);
EVP_PKEY_keygen(kctx, &pkey);

EVP_PKEY_free(pkey);
EVP_PKEY_free(params);
EVP_PKEY_CTX_free(kctx);
EVP_PKEY_CTX_free(ctx);
```

> **Note:** All `DH_*` low-level functions are deprecated as of OpenSSL 3.0. Use `EVP_PKEY_CTX_*` APIs for new code.
