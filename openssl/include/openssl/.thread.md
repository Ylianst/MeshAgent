OpenSSL public header providing thread pool configuration and capability query APIs for `OSSL_LIB_CTX` instances.

## Key Components

### Feature Flags

| Flag | Value | Description |
|------|-------|-------------|
| `OSSL_THREAD_SUPPORT_FLAG_THREAD_POOL` | `1U<<0` | Indicates thread pool support is available |
| `OSSL_THREAD_SUPPORT_FLAG_DEFAULT_SPAWN` | `1U<<1` | Indicates default thread spawning is supported |

### Functions

| Function | Signature | Description |
|----------|-----------|-------------|
| `OSSL_get_thread_support_flags` | `uint32_t (void)` | Returns a bitmask of supported threading capabilities |
| `OSSL_set_max_threads` | `int (OSSL_LIB_CTX *, uint64_t)` | Sets the maximum number of threads for a library context; returns non-zero on success |
| `OSSL_get_max_threads` | `uint64_t (OSSL_LIB_CTX *)` | Retrieves the current thread limit for a library context |

## Usage Example

```c
#include <openssl/thread.h>

void configure_threading(OSSL_LIB_CTX *ctx) {
    /* Check if thread pool is supported before configuring */
    uint32_t flags = OSSL_get_thread_support_flags();

    if (flags & OSSL_THREAD_SUPPORT_FLAG_THREAD_POOL) {
        /* Limit OpenSSL to 4 worker threads */
        if (!OSSL_set_max_threads(ctx, 4)) {
            fprintf(stderr, "Failed to set max threads\n");
            return;
        }

        uint64_t max = OSSL_get_max_threads(ctx);
        printf("Max threads configured: %llu\n", (unsigned long long)max);
    }
}
```

> Pass `NULL` as `ctx` to target the default global library context.
