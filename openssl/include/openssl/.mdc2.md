MDC2 (Message Digest with Cipher 2) hash algorithm interface header, part of the OpenSSL library. Defines the context structure and function declarations for computing MDC2 digests using DES block cipher operations. **All functions are deprecated as of OpenSSL 3.0.**

## Key Components

### Constants

| Name | Value | Description |
|---|---|---|
| `MDC2_DIGEST_LENGTH` | `16` | Output digest size in bytes |
| `MDC2_BLOCK` | `8` | Internal block size in bytes |

### `MDC2_CTX` Structure

Context struct holding MDC2 hashing state (deprecated in OpenSSL 3.0):

| Field | Type | Description |
|---|---|---|
| `num` | `unsigned int` | Bytes currently buffered |
| `data` | `unsigned char[8]` | Current data block |
| `h`, `hh` | `DES_cblock` | DES cipher state blocks |
| `pad_type` | `unsigned int` | Padding type, `1` or `2` (default: `1`) |

### Functions (Deprecated since OpenSSL 3.0)

- **`MDC2_Init`** — Initializes an `MDC2_CTX` context
- **`MDC2_Update`** — Feeds data into an active MDC2 digest operation
- **`MDC2_Final`** — Finalizes and outputs the 16-byte digest
- **`MDC2()`** — One-shot convenience function: hashes a buffer and returns the digest

## Usage Example

```c
#include <openssl/mdc2.h>

/* Deprecated one-shot usage (OpenSSL < 3.0) */
unsigned char digest[MDC2_DIGEST_LENGTH];
const unsigned char *input = (unsigned char *)"hello";

MDC2(input, 5, digest);

/* Incremental usage */
MDC2_CTX ctx;
MDC2_Init(&ctx);
MDC2_Update(&ctx, input, 5);
MDC2_Final(digest, &ctx);
```

> **Note:** MDC2 APIs are fully deprecated in OpenSSL 3.0+. Use the EVP digest interface (`EVP_DigestInit`, `EVP_DigestUpdate`, `EVP_DigestFinal`) with `EVP_mdc2()` for forward-compatible code, or migrate to a modern hash algorithm such as SHA-256.
