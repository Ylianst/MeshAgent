## Key Components

### Preprocessor Guards
- `OPENSSL_DSAERR_H` — standard include guard preventing double inclusion
- `OPENSSL_NO_DSA` — compile-time guard; all reason codes are excluded if DSA support is disabled

## Usage Example

```c
#include <openssl/dsa.h>
#include <openssl/dsaerr.h>
#include <openssl/err.h>

void check_dsa_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == DSA_R_MISSING_PARAMETERS) {
        fprintf(stderr, "DSA key is missing required parameters\n");
    } else if (reason == DSA_R_MODULUS_TOO_LARGE) {
        fprintf(stderr, "DSA modulus p exceeds the allowed size\n");
    }
}
```
