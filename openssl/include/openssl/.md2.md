OpenSSL MD2 message digest algorithm header, providing the low-level C interface for computing MD2 hashes. All APIs in this header are **deprecated as of OpenSSL 3.0** and should not be used in new code.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MD2_DIGEST_LENGTH` | Macro | Output digest size: 16 bytes (128 bits) |
| `MD2_BLOCK` | Macro | Internal block size: 16 bytes |
| `MD2_INT` | Typedef | Underlying integer type (`unsigned char`) |
| `MD2_CTX` | Struct | MD2 hash state: accumulates `num`, `data`, `cksm`, and `state` across incremental updates |
| `MD2_Init` | Function | Initializes an `MD2_CTX` context |
| `MD2_Update` | Function | Feeds input data into the hash context |
| `MD2_Final` | Function | Finalizes the hash and writes the 16-byte digest |
| `MD2` | Function | One-shot convenience function: hash a buffer in a single call |
| `MD2_options` | Function | Returns a string describing compile-time options |

## Usage Example

```c
/* Deprecated — for legacy reference only. Use EVP_DigestInit/Update/Final instead. */
#include <openssl/md2.h>

unsigned char digest[MD2_DIGEST_LENGTH];
MD2_CTX ctx;

MD2_Init(&ctx);
MD2_Update(&ctx, (const unsigned char *)"hello", 5);
MD2_Final(digest, &ctx);

/* Or, using the one-shot form: */
unsigned char *result = MD2(
    (const unsigned char *)"hello", 5, digest
);
```

> **Warning:** MD2 is cryptographically broken and unavailable by default in OpenSSL 3.0+. Use `EVP_MD_CTX` with `EVP_md5()` or a modern digest (SHA-256, SHA-3) for any new implementation.
