OpenSSL SRP (Secure Remote Password) protocol header providing deprecated-in-3.0 structures, stack types, and utility functions for password-authenticated key exchange without transmitting passwords.

## Key Components

### Structures

| Type | Description |
|------|-------------|
| `SRP_gN_cache` | Caches base64-encoded BIGNUM pairs (generator `g` and prime `N`) |
| `SRP_user_pwd` | Stores per-user SRP credentials: identity, salt (`s`), verifier (`v`), group params (`g`, `N`) |
| `SRP_VBASE` | Verifier database holding user password stacks, gN cache, and default group params |
| `SRP_gN` | Internal g/N group parameter pair with string identifier |

### Stack Macros

Type-safe `STACK_OF()` collections are defined for all three types via `SKM_DEFINE_STACK_OF_INTERNAL`, exposing the standard OpenSSL stack API:

- `sk_SRP_gN_cache_*` — push, pop, find, sort, dup, deep\_copy, etc.
- `sk_SRP_user_pwd_*` — same operations for user password entries
- `sk_SRP_gN_*` — same operations for group parameter pairs

### Deprecated API Functions (`OSSL_DEPRECATEDIN_3_0`)

| Function | Purpose |
|----------|---------|
| `SRP_user_pwd_new` / `SRP_user_pwd_free` | Allocate/free user credential entries |
| `SRP_user_pwd_set_gN` | Assign group params to a user entry |
| `SRP_user_pwd_set1_ids` | Set user ID and info strings |
| `SRP_user_pwd_set0_sv` | Assign salt and verifier BIGNUMs |
| `SRP_VBASE_new` / `SRP_VBASE_free` | Create/destroy verifier database |
| `SRP_VBASE_init` | Load verifier database from file |
| `SRP_VBASE_add0_user` | Add a user entry to the database |
| `SRP_VBASE_get1_by_user` | Look up user (caller owns returned pointer) |
| `SRP_create_verifier_ex` | Generate salt and verifier for a user/password pair |

## Usage Example

```c
#include <openssl/srp.h>

/* Deprecated pre-3.0 pattern — migrate to EVP_PKEY SRP APIs in OpenSSL 3.x */
SRP_VBASE *vbase = SRP_VBASE_new(NULL);
if (SRP_VBASE_init(vbase, "/etc/srp_verifiers") != SRP_NO_ERROR) {
    /* handle error */
}

SRP_user_pwd *upwd = SRP_VBASE_get1_by_user(vbase, "alice");
if (upwd != NULL) {
    /* use upwd->v (verifier) and upwd->s (salt) for SRP handshake */
    SRP_user_pwd_free(upwd);
}

SRP_VBASE_free(vbase);
```

> **⚠️ Deprecation Notice:** All types and functions in this header are marked `OSSL_DEPRECATEDIN_3_0`. New code should use the OpenSSL 3.x EVP-based SRP APIs instead.
