OpenSSL RFC 3161 Time-Stamp Protocol (TSP) header, providing types, constants, and function declarations for creating, encoding, decoding, and verifying cryptographic timestamp requests and responses.

## Key Components

### Core Types
- `TS_REQ` — Timestamp request structure
- `TS_RESP` — Timestamp response structure
- `TS_TST_INFO` — TSTInfo token contained within a response
- `TS_MSG_IMPRINT` — Message imprint (hash algorithm + digest)
- `TS_ACCURACY` — Timestamp accuracy (seconds/milliseconds/microseconds)
- `TS_STATUS_INFO` — Response status and failure information
- `TS_RESP_CTX` — Context for generating timestamp responses

### Status & Failure Constants
| Constant | Value | Meaning |
|---|---|---|
| `TS_STATUS_GRANTED` | 0 | Request accepted |
| `TS_STATUS_REJECTION` | 2 | Request rejected |
| `TS_INFO_BAD_ALG` | 0 | Unrecognized hash algorithm |
| `TS_INFO_SYSTEM_FAILURE` | 25 | Internal TSA error |

### Response Generation Callbacks
- `TS_serial_cb` — Provides unique serial numbers (<160 bits)
- `TS_time_cb` — Provides current time (seconds + microseconds since epoch)
- `TS_extension_cb` — Handles custom extensions in requests

### Response Context Flags
- `TS_TSA_NAME` (`0x01`) — Include TSA name in response
- `TS_ORDERING` (`0x02`) — Set ordering flag to true
- `TS_ESS_CERT_ID_CHAIN` (`0x04`) — Include full certificate chain

## Usage Example

```c
/* Create and configure a TSA response context */
TS_RESP_CTX *ctx = TS_RESP_CTX_new();

/* Required: set signer certificate and key */
TS_RESP_CTX_set_signer_cert(ctx, signer_cert);
TS_RESP_CTX_set_signer_key(ctx, signer_key);

/* Required: set default policy OID */
TS_RESP_CTX_set_def_policy(ctx, policy_oid);

/* Accept SHA-256 digests */
TS_RESP_CTX_add_md(ctx, EVP_sha256());

/* Optional: set accuracy to 1 second */
TS_RESP_CTX_set_accuracy(ctx, 1, 0, 0);

/* Parse an incoming DER-encoded request */
TS_REQ *req = d2i_TS_REQ_bio(bio_in, NULL);

/* Generate a timestamp response */
TS_RESP *resp = TS_RESP_CTX_create_response(ctx, req);

/* Serialize response */
i2d_TS_RESP_bio(bio_out, resp);

/* Cleanup */
TS_RESP_free(resp);
TS_REQ_free(req);
TS_RESP_CTX_free(ctx);
```
