## Usage Example

These codes are typically checked after an `OSSL_STORE` API call fails:

```c
#include <openssl/store.h>
#include <openssl/storeerr.h>
#include <openssl/err.h>

OSSL_STORE_CTX *ctx = OSSL_STORE_open("file:///etc/ssl/cert.pem", NULL, NULL, NULL, NULL);
if (ctx == NULL) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == OSSL_STORE_R_UNREGISTERED_SCHEME) {
        fprintf(stderr, "No loader for this URI scheme\n");
    } else if (reason == OSSL_STORE_R_PATH_MUST_BE_ABSOLUTE) {
        fprintf(stderr, "Provide an absolute path\n");
    }
}
```
