OpenSSL header defining the RIPEMD-160 cryptographic hash algorithm interface, providing the context structure and low-level digest functions (deprecated as of OpenSSL 3.0).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `RIPEMD160_DIGEST_LENGTH` | Macro | Output digest size in bytes (20 bytes / 160 bits) |
| `RIPEMD160_CBLOCK` | Macro | Block size in bytes (64) |
| `RIPEMD160_LBLOCK` | Macro | Block size in 32-bit words (16) |
| `RIPEMD160_CTX` | Struct | Hash state context holding chaining variables (`A`–`E`), bit count, and data buffer |
| `RIPEMD160_Init` | Function | Initializes a `RIPEMD160_CTX` context |
| `RIPEMD160_Update` | Function | Feeds data into an in-progress hash computation |
| `RIPEMD160_Final` | Function | Finalizes the hash and writes the 20-byte digest |
| `RIPEMD160` | Function | One-shot convenience wrapper over Init/Update/Final |
| `RIPEMD160_Transform` | Function | Processes a single raw 64-byte block (low-level) |

> ⚠️ All functions are marked `OSSL_DEPRECATEDIN_3_0`. Use the EVP digest API (`EVP_DigestInit_ex`, `EVP_DigestUpdate`, `EVP_DigestFinal_ex`) with `EVP_ripemd160()` in OpenSSL 3.x instead.

## Usage Example

**Legacy API (deprecated, OpenSSL < 3.0):**

```c
#include <openssl/ripemd.h>

unsigned char digest[RIPEMD160_DIGEST_LENGTH];
RIPEMD160_CTX ctx;

RIPEMD160_Init(&ctx);
RIPEMD160_Update(&ctx, data, data_len);
RIPEMD160_Final(digest, &ctx);
```

**Recommended EVP API (OpenSSL 3.x):**

```c
#include <openssl/evp.h>

unsigned char digest[EVP_MAX_MD_SIZE];
unsigned int digest_len;
EVP_MD_CTX *ctx = EVP_MD_CTX_new();

EVP_DigestInit_ex(ctx, EVP_ripemd160(), NULL);
EVP_DigestUpdate(ctx, data, data_len);
EVP_DigestFinal_ex(ctx, digest, &digest_len);
EVP_MD_CTX_free(ctx);
```
