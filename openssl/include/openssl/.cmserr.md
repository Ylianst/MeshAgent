## Key Components

**Guard Macros**
- `OPENSSL_CMSERR_H` — standard include guard with `#pragma once`
- `OPENSSL_NO_CMS` — feature flag; entire error table is omitted if CMS support is disabled

## Usage Example

```c
#include <openssl/cmserr.h>
#include <openssl/err.h>

/* Check for a specific CMS error reason after a failed operation */
void check_cms_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == CMS_R_NO_PRIVATE_KEY) {
        fprintf(stderr, "CMS failed: private key not available\n");
    } else if (reason == CMS_R_CERTIFICATE_VERIFY_ERROR) {
        fprintf(stderr, "CMS failed: certificate verification error\n");
    }
}
```
