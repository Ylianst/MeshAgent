## Usage Example

These codes appear when calling `ERR_GET_REASON()` after a CONF API failure:

```c
#include <openssl/conf.h>
#include <openssl/err.h>
#include <openssl/conferr.h>

CONF *cfg = NCONF_new(NULL);
if (!NCONF_load(cfg, "openssl.cnf", NULL)) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == CONF_R_MISSING_EQUAL_SIGN) {
        fprintf(stderr, "Config parse error: missing '=' in key-value pair\n");
    } else if (reason == CONF_R_NO_SUCH_FILE) {
        fprintf(stderr, "Config file not found\n");
    }
}
```
