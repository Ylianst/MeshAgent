OpenSSL DSA (Digital Signature Algorithm) public API header, providing structures, constants, and function declarations for DSA key management, signing, verification, and parameter generation.

## Key Components

### EVP_PKEY_CTX Parameter Generation Controls
Modern (non-deprecated) API for configuring DSA parameter generation via `EVP_PKEY_CTX`:

| Function | Purpose |
|---|---|
| `EVP_PKEY_CTX_set_dsa_paramgen_bits` | Set prime modulus bit length |
| `EVP_PKEY_CTX_set_dsa_paramgen_q_bits` | Set subgroup order bit length |
| `EVP_PKEY_CTX_set_dsa_paramgen_md_props` | Set hash algorithm and properties |
| `EVP_PKEY_CTX_set_dsa_paramgen_seed` | Set deterministic generation seed |
| `EVP_PKEY_CTX_set_dsa_paramgen_gindex` | Set generator index |

### Constants & Macros
- `OPENSSL_DSA_MAX_MODULUS_BITS` — Maximum allowed modulus size (10000 bits)
- `OPENSSL_DSA_FIPS_MIN_MODULUS_BITS` — FIPS minimum modulus (1024 bits)
- `DSS_prime_checks` — Primality check iterations (64, covers 128-bit security level)
- `EVP_PKEY_CTRL_DSA_PARAMGEN_*` — Low-level control codes

### DSA_SIG Structure (non-deprecated)
- `DSA_SIG_new` / `DSA_SIG_free` — Lifecycle management
- `DSA_SIG_get0` / `DSA_SIG_set0` — Access `r` and `s` signature components

### Deprecated (OpenSSL 3.0) DSA API
Legacy direct DSA object manipulation — all marked `OSSL_DEPRECATEDIN_3_0`:
- Key/parameter accessors: `DSA_get0_pqg`, `DSA_set0_pqg`, `DSA_get0_key`, `DSA_set0_key`
- Sign/verify: `DSA_do_sign`, `DSA_do_verify`, `DSA_sign`, `DSA_verify`
- Lifecycle: `DSA_new`, `DSA_free`, `DSA_up_ref`
- Custom method table: `DSA_METHOD` get/set functions for sign, verify, mod_exp callbacks

## Usage Example

```c
/* Modern EVP-based DSA key generation (OpenSSL 3.0+) */
#include <openssl/dsa.h>
#include <openssl/evp.h>

EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_DSA, NULL);
EVP_PKEY_paramgen_init(ctx);

/* Configure 2048-bit DSA parameters */
EVP_PKEY_CTX_set_dsa_paramgen_bits(ctx, 2048);
EVP_PKEY_CTX_set_dsa_paramgen_q_bits(ctx, 256);

EVP_PKEY *params = NULL;
EVP_PKEY_paramgen(ctx, &params);

/* Sign using EVP_DigestSign* (preferred over deprecated DSA_sign) */
EVP_PKEY_CTX_free(ctx);
EVP_PKEY_free(params);
```

> **Note:** The low-level `DSA_*` functions are deprecated in OpenSSL 3.0. Use the `EVP_PKEY` and `EVP_DigestSign`/`EVP_DigestVerify` APIs for new code.
