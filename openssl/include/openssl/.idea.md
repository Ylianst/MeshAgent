Public header for OpenSSL's IDEA (International Data Encryption Algorithm) symmetric block cipher, providing legacy encryption/decryption APIs. All declared functions are deprecated as of OpenSSL 3.0.

## Key Components

### Constants
| Macro | Value | Description |
|---|---|---|
| `IDEA_BLOCK` | `8` | Block size in bytes |
| `IDEA_KEY_LENGTH` | `16` | Key length in bytes |
| `IDEA_ENCRYPT` | `1` | Encrypt direction flag |
| `IDEA_DECRYPT` | `0` | Decrypt direction flag |

### Types
- **`IDEA_INT`** — `unsigned int` base type for IDEA operations
- **`IDEA_KEY_SCHEDULE`** — Key schedule struct holding a `9×6` array of `IDEA_INT` subkeys

### Functions (Deprecated in 3.0)

| Function | Description |
|---|---|
| `IDEA_options()` | Returns a string describing build options |
| `IDEA_set_encrypt_key()` | Expands a 16-byte key into an encrypt schedule |
| `IDEA_set_decrypt_key()` | Derives a decrypt schedule from an encrypt schedule |
| `IDEA_ecb_encrypt()` | Encrypts a single 8-byte block (ECB mode) |
| `IDEA_cbc_encrypt()` | CBC mode encrypt/decrypt |
| `IDEA_cfb64_encrypt()` | CFB-64 mode encrypt/decrypt |
| `IDEA_ofb64_encrypt()` | OFB-64 mode encryption |
| `IDEA_encrypt()` | Low-level single-block encrypt |

Legacy lowercase aliases (e.g. `idea_ecb_encrypt`) are provided for pre-1.1.0 compatibility via `#define`.

## Usage Example

```c
#include <openssl/idea.h>

/* Deprecated — avoid in new code; use EVP_* APIs instead */
IDEA_KEY_SCHEDULE eks, dks;
unsigned char key[IDEA_KEY_LENGTH] = { /* 16 bytes */ };
unsigned char iv[IDEA_BLOCK]       = { 0 };
unsigned char in[16], out[16];

IDEA_set_encrypt_key(key, &eks);
IDEA_set_decrypt_key(&eks, &dks);

/* CBC encrypt */
IDEA_cbc_encrypt(in, out, sizeof(in), &eks, iv, IDEA_ENCRYPT);
```

> **Note:** All APIs in this header are marked `OSSL_DEPRECATEDIN_3_0`. Use the EVP high-level interface (`EVP_EncryptInit_ex`, etc.) for new code, as IDEA support may be removed in a future OpenSSL release.
