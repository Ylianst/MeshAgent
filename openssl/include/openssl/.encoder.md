Public API header for OpenSSL's encoder subsystem, providing interfaces to serialize cryptographic objects (keys, certificates, etc.) into formats such as PEM, DER, and other output structures.

## Key Components

### Encoder Management
| Function | Description |
|---|---|
| `OSSL_ENCODER_fetch` | Fetch an encoder by name and properties from a library context |
| `OSSL_ENCODER_up_ref` | Increment reference count |
| `OSSL_ENCODER_free` | Release an encoder object |
| `OSSL_ENCODER_is_a` | Check if encoder matches a given name |

### Encoder Context (`OSSL_ENCODER_CTX`)
| Function | Description |
|---|---|
| `OSSL_ENCODER_CTX_new` | Allocate a new encoder context |
| `OSSL_ENCODER_CTX_free` | Release an encoder context |
| `OSSL_ENCODER_CTX_set_output_type` | Set target output format (e.g., `"PEM"`, `"DER"`) |
| `OSSL_ENCODER_CTX_set_output_structure` | Set output structure (e.g., `"PKCS8"`) |
| `OSSL_ENCODER_CTX_set_cipher` | Enable encryption of the encoded output |
| `OSSL_ENCODER_CTX_set_passphrase` | Set raw passphrase for encryption |
| `OSSL_ENCODER_CTX_set_selection` | Select which key components to encode (public/private) |
| `OSSL_ENCODER_CTX_new_for_pkey` | Convenience constructor for encoding `EVP_PKEY` objects |

### Output Functions
| Function | Description |
|---|---|
| `OSSL_ENCODER_to_bio` | Encode to an OpenSSL `BIO` |
| `OSSL_ENCODER_to_fp` | Encode to a `FILE*` (when stdio is available) |
| `OSSL_ENCODER_to_data` | Encode to a raw byte buffer |

### Callback Types
- **`OSSL_ENCODER_CONSTRUCT`** — supplies the object to encode per encoder instance
- **`OSSL_ENCODER_CLEANUP`** — cleans up construct data after encoding

## Usage Example

```c
/* Encode an EVP_PKEY private key to PEM on stdout */
OSSL_ENCODER_CTX *ctx = OSSL_ENCODER_CTX_new_for_pkey(
    pkey,
    OSSL_KEYMGMT_SELECT_PRIVATE_KEY,
    "PEM",
    "PKCS8",
    NULL
);

if (ctx == NULL) {
    /* handle error */
}

/* Optionally encrypt with a passphrase */
OSSL_ENCODER_CTX_set_cipher(ctx, "AES-256-CBC", NULL);
OSSL_ENCODER_CTX_set_passphrase(ctx, (unsigned char *)"secret", 6);

OSSL_ENCODER_to_fp(ctx, stdout);

OSSL_ENCODER_CTX_free(ctx);
```
