CMAC (Cipher-based Message Authentication Code) legacy API header from OpenSSL, providing deprecated context-based CMAC operations scheduled for removal in OpenSSL 3.0+.

## Key Components

### Opaque Type
- **`CMAC_CTX`** — Opaque context structure holding CMAC state; deprecated since OpenSSL 3.0

### Deprecated Functions (`OSSL_DEPRECATEDIN_3_0`)

| Function | Description |
|---|---|
| `CMAC_CTX_new()` | Allocates a new CMAC context |
| `CMAC_CTX_cleanup(ctx)` | Clears context state without freeing |
| `CMAC_CTX_free(ctx)` | Frees a CMAC context |
| `CMAC_CTX_get0_cipher_ctx(ctx)` | Returns the internal `EVP_CIPHER_CTX` |
| `CMAC_CTX_copy(out, in)` | Copies a CMAC context |
| `CMAC_Init(ctx, key, keylen, cipher, impl)` | Initializes CMAC with key and cipher |
| `CMAC_Update(ctx, data, dlen)` | Feeds data into the CMAC computation |
| `CMAC_Final(ctx, out, poutlen)` | Finalizes and outputs the MAC |
| `CMAC_resume(ctx)` | Resumes a finalized context for additional data |

## Usage Example

> ⚠️ These APIs are **deprecated as of OpenSSL 3.0**. Prefer the `EVP_MAC` API with `CMAC` as the algorithm.

```c
/* Legacy CMAC usage (pre-3.0) */
CMAC_CTX *ctx = CMAC_CTX_new();
unsigned char mac[16];
size_t mac_len;

CMAC_Init(ctx, key, 16, EVP_aes_128_cbc(), NULL);
CMAC_Update(ctx, message, message_len);
CMAC_Final(ctx, mac, &mac_len);
CMAC_CTX_free(ctx);
```

```c
/* Modern replacement using EVP_MAC (OpenSSL 3.0+) */
EVP_MAC *mac = EVP_MAC_fetch(NULL, "CMAC", NULL);
EVP_MAC_CTX *ctx = EVP_MAC_CTX_new(mac);
/* ... configure params with EVP_MAC_init() ... */
EVP_MAC_free(mac);
```

## Notes

- The entire header is guarded by `OPENSSL_NO_CMAC` — if CMAC support is disabled at build time, no symbols are exposed
- All functions require `OPENSSL_NO_DEPRECATED_3_0` to **not** be defined; defining it excludes the legacy API entirely
- Compile with `-DOPENSSL_NO_DEPRECATED_3_0` to enforce migration to the modern `EVP_MAC` interface
