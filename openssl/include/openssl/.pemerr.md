Auto-generated OpenSSL header defining numeric reason codes for PEM subsystem errors, used to classify and report failures during PEM encoding, decoding, and key parsing operations.

## Key Components

### PEM Reason Code Macros

All constants follow the `PEM_R_*` naming convention and map a descriptive error name to a unique integer code (100–133).

| Macro | Code | Description |
|---|---|---|
| `PEM_R_BAD_BASE64_DECODE` | 100 | Base64 decoding failed |
| `PEM_R_BAD_DECRYPT` | 101 | Decryption of PEM data failed |
| `PEM_R_BAD_END_LINE` | 102 | Malformed PEM footer line |
| `PEM_R_BAD_IV_CHARS` | 103 | Invalid characters in IV field |
| `PEM_R_BAD_PASSWORD_READ` | 104 | Password could not be read |
| `PEM_R_NO_START_LINE` | 108 | Missing PEM header (`-----BEGIN...`) |
| `PEM_R_NOT_ENCRYPTED` | 106 | Expected encrypted PEM, found plaintext |
| `PEM_R_UNSUPPORTED_CIPHER` | 113 | Cipher algorithm not supported |
| `PEM_R_UNSUPPORTED_ENCRYPTION` | 114 | Encryption scheme not supported |
| `PEM_R_HEADER_TOO_LONG` | 128 | PEM header exceeds size limit |
| `PEM_R_MISSING_DEK_IV` | 129 | DEK-Info IV is absent |
| `PEM_R_UNSUPPORTED_PVK_KEY_TYPE` | 133 | PVK key type not recognized |

> Full set covers Base64, decryption, IV handling, password reading, key blob parsing (RSA/DSS/PVK), and header validation errors.

## Usage Example

These codes are consumed via the standard OpenSSL error API — you do not set them directly:

```c
#include <openssl/pem.h>
#include <openssl/err.h>

EVP_PKEY *key = PEM_read_PrivateKey(fp, NULL, NULL, NULL);
if (!key) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == PEM_R_NO_START_LINE) {
        fprintf(stderr, "Error: missing PEM header line\n");
    } else if (reason == PEM_R_BAD_DECRYPT) {
        fprintf(stderr, "Error: wrong passphrase or corrupt data\n");
    } else {
        ERR_print_errors_fp(stderr);
    }
}
```
