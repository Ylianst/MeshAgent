RC4 stream cipher interface header from OpenSSL, declaring the legacy RC4 encryption key structure and core cipher functions (deprecated since OpenSSL 3.0).

## Key Components

### Struct
- **`RC4_KEY`** — Key state structure containing integer indices `x`, `y` and a 256-element substitution box (`data`). Conditionally compiled when `OPENSSL_NO_DEPRECATED_3_0` is not defined.

### Functions (Deprecated in OpenSSL 3.0)

| Function | Description |
|---|---|
| `RC4_options()` | Returns a string describing RC4 build options |
| `RC4_set_key()` | Initializes an `RC4_KEY` from raw key bytes |
| `RC4()`| Encrypts or decrypts a data buffer using the initialized key (XOR stream cipher — same function for both directions) |

### Compile-Time Guards
- `OPENSSL_NO_RC4` — Omits all RC4 declarations if RC4 support is disabled at build time
- `OPENSSL_NO_DEPRECATED_3_0` — Suppresses the struct and all three functions when targeting OpenSSL 3.0+ without legacy APIs

## Usage Example

```c
#include <openssl/rc4.h>

/* Only valid when building against pre-3.0 OpenSSL or with legacy enabled */
#ifndef OPENSSL_NO_DEPRECATED_3_0

RC4_KEY key;
const unsigned char raw_key[] = "mysecretkey";
const unsigned char plaintext[] = "Hello, World!";
unsigned char ciphertext[sizeof(plaintext)];

/* Initialize key schedule */
RC4_set_key(&key, sizeof(raw_key) - 1, raw_key);

/* Encrypt (or decrypt — RC4 is symmetric) */
RC4(&key, sizeof(plaintext) - 1, plaintext, ciphertext);

#endif
```

> **⚠️ Security Warning:** RC4 is cryptographically broken and deprecated. Do not use it in new code. Prefer AES-GCM or ChaCha20-Poly1305 via the EVP API instead.
