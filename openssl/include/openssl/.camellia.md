OpenSSL legacy header declaring the Camellia symmetric block cipher API, deprecated as of OpenSSL 3.0 in favor of the EVP high-level interface.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `CAMELLIA_BLOCK_SIZE` | `16` | Block size in bytes (128-bit) |
| `CAMELLIA_ENCRYPT` | `1` | Encryption direction flag |
| `CAMELLIA_DECRYPT` | `0` | Decryption direction flag |
| `CAMELLIA_TABLE_BYTE_LEN` | `272` | Key schedule table size in bytes |

### Types

- **`CAMELLIA_KEY`** — Key structure holding the expanded key schedule (`rd_key`) and round count (`grand_rounds`); 64-bit aligned via a `double` union member.

### Deprecated Functions (`OSSL_DEPRECATEDIN_3_0`)

| Function | Description |
|---|---|
| `Camellia_set_key` | Expands a raw key (128/192/256-bit) into a `CAMELLIA_KEY` |
| `Camellia_encrypt` / `Camellia_decrypt` | Single-block ECB operations |
| `Camellia_ecb_encrypt` | ECB mode (direction controlled by `enc` flag) |
| `Camellia_cbc_encrypt` | CBC mode with IV |
| `Camellia_cfb128_encrypt` / `Camellia_cfb1_encrypt` / `Camellia_cfb8_encrypt` | CFB modes (128-bit, 1-bit, 8-bit feedback) |
| `Camellia_ofb128_encrypt` | OFB mode |
| `Camellia_ctr128_encrypt` | CTR mode with counter/ecount buffers |

## Usage Example

> ⚠️ These APIs are deprecated in OpenSSL 3.0+. Use the EVP interface (`EVP_EncryptInit_ex` with `EVP_camellia_128_cbc()`) instead.

```c
#include <openssl/camellia.h>

/* Legacy usage — avoid in new code */
CAMELLIA_KEY key;
unsigned char user_key[16] = { /* 128-bit key bytes */ };
unsigned char iv[CAMELLIA_BLOCK_SIZE] = { 0 };
unsigned char in[32]  = { /* plaintext */ };
unsigned char out[32] = { 0 };

Camellia_set_key(user_key, 128, &key);
Camellia_cbc_encrypt(in, out, sizeof(in), &key, iv, CAMELLIA_ENCRYPT);
```

**Preferred modern alternative:**

```c
EVP_CIPHER_CTX *ctx = EVP_CIPHER_CTX_new();
EVP_EncryptInit_ex(ctx, EVP_camellia_128_cbc(), NULL, user_key, iv);
```
