Minimal OpenSSL PEM compatibility header that bridges legacy `HEADER_PEM2_H` guard definitions with the modern `OPENSSL_PEM2_H` include guard, while pulling in PEM error definitions.

## Key Components

| Component | Description |
|---|---|
| `OPENSSL_PEM2_H` | Primary include guard preventing double-inclusion |
| `HEADER_PEM2_H` | Deprecated legacy include guard, defined when `OPENSSL_NO_DEPRECATED_3_0` is not set |
| `<openssl/pemerr.h>` | Included unconditionally to expose PEM-related error codes |

## Usage Example

```c
/* Typically included transitively via <openssl/pem.h>;
   direct inclusion is rarely needed. */
#include <openssl/pem2.h>

/* After inclusion, PEM error codes from pemerr.h are available,
   e.g. when handling PEM decode failures: */
void check_pem_error(void) {
    unsigned long err = ERR_get_error();
    if (ERR_GET_LIB(err) == ERR_LIB_PEM) {
        /* Handle PEM-specific error */
    }
}
```

## Notes

- This header is part of OpenSSL's deprecation migration from pre-3.0 naming conventions (`HEADER_*`) to `OPENSSL_*` style guards.
- Defining `OPENSSL_NO_DEPRECATED_3_0` suppresses the legacy `HEADER_PEM2_H` macro, which is recommended for new code targeting OpenSSL 3.x.
- The primary content of this header is the re-export of `<openssl/pemerr.h>`; it carries no standalone type or function declarations.
