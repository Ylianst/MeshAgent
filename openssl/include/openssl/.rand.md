OpenSSL public header defining the random number generation (RNG) API, including DRBG configuration, entropy seeding, and byte generation functions.

## Key Components

### Constants
- `RAND_DRBG_STRENGTH` — Default DRBG security strength (256 bits, per NIST SP 800-90Ar1)
- `OSSL_PROV_RANDOM_PUBLIC` / `OSSL_PROV_RANDOM_PRIVATE` — Provider random call target selectors

### Core Functions
| Function | Description |
|---|---|
| `RAND_bytes()` | Generate cryptographically secure random bytes (public use) |
| `RAND_priv_bytes()` | Generate random bytes for private/sensitive material |
| `RAND_bytes_ex()` | `RAND_bytes` with explicit `OSSL_LIB_CTX` and strength |
| `RAND_priv_bytes_ex()` | `RAND_priv_bytes` with explicit `OSSL_LIB_CTX` and strength |

### DRBG / Context Management
| Function | Description |
|---|---|
| `RAND_get0_primary()` | Retrieve the primary DRBG context |
| `RAND_get0_public()` | Retrieve the public DRBG context |
| `RAND_get0_private()` | Retrieve the private DRBG context |
| `RAND_set0_public()` | Replace the public DRBG |
| `RAND_set0_private()` | Replace the private DRBG |
| `RAND_set_DRBG_type()` | Configure DRBG algorithm, cipher, and digest |
| `RAND_set_seed_source_type()` | Configure the entropy seed source |

### Entropy & Seeding
- `RAND_seed()` — Add entropy data to the RNG state
- `RAND_add()` — Add entropy with an explicit randomness estimate
- `RAND_poll()` — Poll the OS for entropy
- `RAND_keep_random_devices_open()` — Control whether `/dev/random`-style devices stay open

### File Operations
- `RAND_load_file()` — Load entropy from a file
- `RAND_write_file()` — Save RNG state to a file
- `RAND_file_name()` — Get the default seed file path

### Deprecated (≥ 3.0)
- `RAND_METHOD` / `rand_meth_st` — Legacy custom RNG method table
- `RAND_set_rand_method()`, `RAND_get_rand_method()`, `RAND_OpenSSL()`
- `RAND_set_rand_engine()` — ENGINE-based RNG override

## Usage Example

```c
#include <openssl/rand.h>
#include <stdio.h>

int main(void) {
    unsigned char buf[32];

    /* Generate 32 bytes of public random data */
    if (RAND_bytes(buf, sizeof(buf)) != 1) {
        fprintf(stderr, "RAND_bytes failed\n");
        return 1;
    }

    /* Generate 32 bytes for private/key material */
    if (RAND_priv_bytes(buf, sizeof(buf)) != 1) {
        fprintf(stderr, "RAND_priv_bytes failed\n");
        return 1;
    }

    /* Context-scoped generation with explicit 256-bit strength */
    OSSL_LIB_CTX *ctx = OSSL_LIB_CTX_new();
    RAND_bytes_ex(ctx, buf, sizeof(buf), 256);
    OSSL_LIB_CTX_free(ctx);

    return 0;
}
```
