OpenSSL asynchronous job and wait-context API header, providing types, constants, and function declarations for non-blocking cryptographic operations using cooperative coroutine-style jobs.

## Key Components

### Types
- **`ASYNC_JOB`** — Opaque handle representing an asynchronous job
- **`ASYNC_WAIT_CTX`** — Context for tracking file descriptors and callbacks used to signal job completion
- **`ASYNC_callback_fn`** — Callback signature `int (*)(void *arg)` invoked when a job is ready
- **`ASYNC_stack_alloc_fn` / `ASYNC_stack_free_fn`** — Custom allocator hooks for coroutine stack memory
- **`OSSL_ASYNC_FD`** — Platform-specific file descriptor (`HANDLE` on Windows, `int` on POSIX)

### Constants
| Constant | Meaning |
|---|---|
| `ASYNC_ERR` | Job start failed |
| `ASYNC_NO_JOBS` | No job slots available |
| `ASYNC_PAUSE` | Job paused, awaiting I/O |
| `ASYNC_FINISH` | Job completed |
| `ASYNC_STATUS_OK` | Wait context status: ready |
| `ASYNC_STATUS_EAGAIN` | Wait context status: retry |

### Key Functions
- **`ASYNC_init_thread`** / **`ASYNC_cleanup_thread`** — Initialize/teardown per-thread async job pool
- **`ASYNC_start_job`** — Launch or resume an async job; returns one of the `ASYNC_*` status codes
- **`ASYNC_pause_job`** — Suspend the currently running job, yielding control back to the caller
- **`ASYNC_WAIT_CTX_new`** / **`ASYNC_WAIT_CTX_free`** — Allocate/free a wait context
- **`ASYNC_WAIT_CTX_set_wait_fd`** / **`ASYNC_WAIT_CTX_get_all_fds`** — Manage fds used to poll for job readiness
- **`ASYNC_set_mem_functions`** — Override default stack allocator

## Usage Example

```c
#include <openssl/async.h>

static int my_async_func(void *arg) {
    /* ... do work, then pause waiting for hardware ... */
    ASYNC_pause_job();
    /* ... complete work after resumption ... */
    return 1;
}

void run_async(void) {
    ASYNC_JOB *job = NULL;
    ASYNC_WAIT_CTX *ctx = ASYNC_WAIT_CTX_new();
    int ret, status;

    /* Initialize the thread's async pool (max 10 jobs, pre-alloc 1) */
    ASYNC_init_thread(10, 1);

    do {
        status = ASYNC_start_job(&job, ctx, &ret,
                                 my_async_func, NULL, 0);
        if (status == ASYNC_PAUSE) {
            /* Poll OSSL_ASYNC_FD descriptors from ctx, then loop */
            OSSL_ASYNC_FD fd;
            size_t numfds;
            ASYNC_WAIT_CTX_get_all_fds(ctx, &fd, &numfds);
            /* ... select/epoll on fd ... */
        }
    } while (status == ASYNC_PAUSE);

    ASYNC_WAIT_CTX_free(ctx);
    ASYNC_cleanup_thread();
}
```
