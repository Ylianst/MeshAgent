OpenSSL error handling header that defines the error code infrastructure, library identifiers, error state structures, and public API for recording, retrieving, and formatting errors across all OpenSSL subsystems.

## Key Components

### Error State Structure (`err_state_st`)
A fixed-size circular buffer (16 slots) holding per-thread error state including flags, marks, error codes, associated data, file/line/function info.

### Library Identifiers (`ERR_LIB_*`)
Numeric constants (1–128) identifying each OpenSSL subsystem (e.g., `ERR_LIB_SSL`, `ERR_LIB_RSA`, `ERR_LIB_EVP`). `ERR_LIB_USER` (128) is the base for application-defined libraries.

### Error Code Encoding
32-bit packed error codes with distinct layouts for system errors (bit 31 set, POSIX errno in lower bits) and OpenSSL errors (8-bit library + 23-bit reason including 5 reason-flag bits).

### Decode Helpers (inline functions)
| Function | Description |
|---|---|
| `ERR_GET_LIB(errcode)` | Extract library identifier |
| `ERR_GET_REASON(errcode)` | Extract reason code |
| `ERR_GET_RFLAGS(errcode)` | Extract reason flags |
| `ERR_FATAL_ERROR(errcode)` | Test `ERR_RFLAG_FATAL` |
| `ERR_COMMON_ERROR(errcode)` | Test `ERR_RFLAG_COMMON` |

### Key Macros
- `ERR_PACK(lib, func, reason)` — pack a library + reason into an error code
- `ERR_SYSTEM_ERROR(errcode)` — test whether code represents a system error
- `ERR_RFLAG_FATAL` / `ERR_RFLAG_COMMON` — reason flags for fatal and cross-library errors
- Deprecated per-library shims (`SSLerr`, `RSAerr`, etc.) forward to `ERR_raise_data`

## Usage Example

```c
#include <openssl/err.h>

/* Raise an error in a custom library */
ERR_raise(ERR_LIB_USER, ERR_R_MALLOC_FAILURE);

/* Retrieve and print the latest error */
unsigned long code = ERR_get_error();
if (code != 0) {
    fprintf(stderr, "Library : %d\n", ERR_GET_LIB(code));
    fprintf(stderr, "Reason  : %d\n", ERR_GET_REASON(code));
    fprintf(stderr, "Fatal?  : %d\n", ERR_FATAL_ERROR(code));
    ERR_print_errors_fp(stderr);
}

/* Pack a custom error code */
unsigned long packed = ERR_PACK(ERR_LIB_USER, 0, 42);
```
