OpenSSL MD5 header defining the MD5 hashing interface, including the context structure and low-level hash computation functions (deprecated as of OpenSSL 3.0).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MD5_DIGEST_LENGTH` | Macro | Output digest size in bytes (`16`) |
| `MD5_CBLOCK` | Macro | Block size in bytes (`64`) |
| `MD5_LBLOCK` | Macro | Block size in 32-bit words (`16`) |
| `MD5_LONG` | Typedef macro | Underlying word type (`unsigned int`, ≥32 bits) |
| `MD5_CTX` | Struct | Holds MD5 state: registers A/B/C/D, bit counts, and data buffer |
| `MD5_Init` | Function | Initializes an `MD5_CTX` |
| `MD5_Update` | Function | Feeds data into the running hash |
| `MD5_Final` | Function | Finalizes and writes the 16-byte digest |
| `MD5` | Function | One-shot convenience: init → update → final |
| `MD5_Transform` | Function | Processes a single raw 64-byte block (low-level) |

> ⚠️ All functions and the `MD5_CTX` struct are deprecated in OpenSSL 3.0. Use the EVP digest API instead.

## Usage Example

**Legacy API (deprecated, OpenSSL < 3.0):**

```c
#include <openssl/md5.h>
#include <stdio.h>

void legacy_md5(const unsigned char *data, size_t len) {
    unsigned char digest[MD5_DIGEST_LENGTH];
    MD5_CTX ctx;

    MD5_Init(&ctx);
    MD5_Update(&ctx, data, len);
    MD5_Final(digest, &ctx);
}
```

**Recommended EVP API (OpenSSL 3.0+):**

```c
#include <openssl/evp.h>

void evp_md5(const unsigned char *data, size_t len) {
    unsigned char digest[EVP_MAX_MD_SIZE];
    unsigned int digest_len;
    EVP_MD_CTX *ctx = EVP_MD_CTX_new();

    EVP_DigestInit_ex(ctx, EVP_md5(), NULL);
    EVP_DigestUpdate(ctx, data, len);
    EVP_DigestFinal_ex(ctx, digest, &digest_len);
    EVP_MD_CTX_free(ctx);
}
```
