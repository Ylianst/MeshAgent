Platform detection and portability header for OpenSSL, establishing OS-specific macros, symbol visibility definitions, and portable type aliases used throughout the OpenSSL library.

## Key Components

### OS Detection Macros

| Macro | Platform |
|---|---|
| `OPENSSL_SYS_UNIX` | Default (Unix assumed if none match) |
| `OPENSSL_SYS_WINDOWS` | Any Microsoft Windows variant |
| `OPENSSL_SYS_WIN32` / `OPENSSL_SYS_WIN64` | 32/64-bit Windows |
| `OPENSSL_SYS_VMS` | OpenVMS (DEC/HP) |
| `OPENSSL_SYS_LINUX` | Linux |
| `OPENSSL_SYS_UEFI` | UEFI firmware environments |
| `OPENSSL_SYS_VOS` | Stratus VOS |

### Symbol Visibility

- **`OPENSSL_EXPORT`** — marks symbols for export from a shared library; expands to `__declspec(dllexport)` on Windows DLL builds
- **`OPENSSL_EXTERN`** — declares imported symbols; expands to `__declspec(dllimport)` on Windows DLL builds

### Portable Type Definitions

- **`ossl_ssize_t`** / **`OSSL_SSIZE_MAX`** — signed size type, mapped to `ssize_t`, `__int64`, or `INTN` per platform
- **`ossl_intmax_t`** / **`ossl_uintmax_t`** — largest available integer types (`intmax_t` or `int64_t` fallback)
- Standard `int8_t`–`uint64_t` typedefs for UEFI and older MSVC targets lacking `<stdint.h>`

### Portability Macros

- **`ossl_inline`** — maps to `inline`, `__inline__`, `__inline`, or empty depending on compiler
- **`ossl_noreturn`** — maps to `_Noreturn` (C11), `__attribute__((noreturn))` (GCC), or empty
- **`ossl_unused`** — maps to `__attribute__((unused))` on GCC/Clang, or empty
- **`__owur`** — optionally enables `__warn_unused_result__` when `UNUSEDRESULT_DEBUG` is defined

## Usage Example

```c
#include <openssl/e_os2.h>

/* Use portable types */
ossl_ssize_t bytes_read;

/* Use portable inline */
static ossl_inline int clamp(int v, int lo, int hi) {
    return v < lo ? lo : v > hi ? hi : v;
}

/* Conditionally compile per platform */
#ifdef OPENSSL_SYS_WINDOWS
    /* Windows-specific path */
#else
    /* POSIX path */
#endif
```
