Provides the OpenSSL ENGINE API interface, defining constants, flags, control commands, and type definitions for integrating hardware cryptographic accelerators and custom algorithm implementations into OpenSSL.

## Key Components

### Method Flags (`ENGINE_METHOD_*`)
Bitmask constants controlling which cryptographic algorithm implementations an engine handles:
- `ENGINE_METHOD_RSA`, `ENGINE_METHOD_DSA`, `ENGINE_METHOD_DH`, `ENGINE_METHOD_EC` — asymmetric algorithms
- `ENGINE_METHOD_CIPHERS`, `ENGINE_METHOD_DIGESTS` — symmetric/hash algorithms
- `ENGINE_METHOD_RAND` — random number generation
- `ENGINE_METHOD_ALL` / `ENGINE_METHOD_NONE` — convenience masks

### Engine Behavior Flags (`ENGINE_FLAGS_*`)
- `ENGINE_FLAGS_MANUAL_CMD_CTRL` — engine handles its own control commands
- `ENGINE_FLAGS_BY_ID_COPY` — `ENGINE_by_id()` returns a new copy each call
- `ENGINE_FLAGS_NO_REGISTER_ALL` — excludes engine from bulk registration

### Control Command Constants (`ENGINE_CTRL_*`)
Numbered commands (1–18+) for engine introspection and configuration, including loading configuration files, enumerating supported commands, and managing user interface callbacks. Engine-specific commands should start at `ENGINE_CMD_BASE` (200).

### Key Types
- `ENGINE_CMD_DEFN` — struct describing a single engine control command (number, name, description, input flags)
- `ENGINE_GEN_FUNC_PTR` — generic function pointer
- `ENGINE_GEN_INT_FUNC_PTR` — function pointer accepting an `ENGINE *`
- `ENGINE_CTRL_FUNC_PTR` — control function pointer with full parameter set

## Usage Example

```c
/* Register and initialize an ENGINE, enabling RSA and ECDSA offload */
ENGINE *e = ENGINE_by_id("pkcs11");
if (e) {
    /* Pass a configuration file path via control command */
    ENGINE_ctrl_cmd_string(e, "MODULE_PATH", "/usr/lib/pkcs11.so", 0);

    if (ENGINE_init(e)) {
        /* Offload RSA and EC operations to the hardware engine */
        ENGINE_set_default(e, ENGINE_METHOD_RSA | ENGINE_METHOD_EC);
    }
    ENGINE_free(e);
}

/* Enumerate engine control commands */
ENGINE_CMD_DEFN defns[] = {
    { ENGINE_CMD_BASE,     "PIN",   "Set PKCS#11 PIN", ENGINE_CMD_FLAG_STRING },
    { ENGINE_CMD_BASE + 1, "SLOT",  "Set slot ID",     ENGINE_CMD_FLAG_NUMERIC },
    { 0, NULL, NULL, 0 }  /* null terminator */
};
ENGINE_set_cmd_defns(e, defns);
```

> **Deprecation note:** The ENGINE API is deprecated as of OpenSSL 3.0. New code should use the [provider API](https://www.openssl.org/docs/man3.0/man7/provider.html) instead.
