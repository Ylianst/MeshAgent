DTLS-SRTP protection profile definitions and API declarations for negotiating SRTP cipher suites over DTLS connections using OpenSSL.

## Key Components

### Protection Profile Constants

| Constant | Value | Standard |
|---|---|---|
| `SRTP_AES128_CM_SHA1_80` | `0x0001` | RFC 4568 |
| `SRTP_AES128_CM_SHA1_32` | `0x0002` | RFC 4568 |
| `SRTP_AEAD_AES_128_GCM` | `0x0007` | RFC 7714 |
| `SRTP_AEAD_AES_256_GCM` | `0x0008` | RFC 7714 |
| `SRTP_DOUBLE_AEAD_AES_128_GCM_AEAD_AES_128_GCM` | `0x0009` | RFC 8723 |
| `SRTP_ARIA_128_CTR_HMAC_SHA1_80` | `0x000B` | RFC 8269 |

### API Functions (guarded by `OPENSSL_NO_SRTP`)

- **`SSL_CTX_set_tlsext_use_srtp`** — registers supported SRTP profiles on an SSL context (colon-separated profile name string)
- **`SSL_set_tlsext_use_srtp`** — registers supported profiles on a per-connection SSL object
- **`SSL_get_srtp_profiles`** — retrieves the stack of negotiated/available SRTP profiles
- **`SSL_get_selected_srtp_profile`** — returns the single profile selected after handshake

## Usage Example

```c
#include <openssl/ssl.h>
#include <openssl/srtp.h>

/* Advertise AES-128 GCM and AES-128 CM/SHA1-80 during DTLS handshake */
SSL_CTX *ctx = SSL_CTX_new(DTLS_method());

if (SSL_CTX_set_tlsext_use_srtp(ctx, "SRTP_AEAD_AES_128_GCM:SRTP_AES128_CM_SHA1_80") != 0) {
    /* handle error */
}

/* After handshake, retrieve the negotiated profile */
SSL *ssl = SSL_new(ctx);
/* ... perform handshake ... */

SRTP_PROTECTION_PROFILE *profile = SSL_get_selected_srtp_profile(ssl);
if (profile) {
    printf("Negotiated SRTP profile: %s (0x%04x)\n",
           profile->name, profile->id);
}
```
