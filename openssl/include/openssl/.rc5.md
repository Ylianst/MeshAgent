Header file defining the RC5-32 symmetric block cipher interface from OpenSSL, providing key scheduling and encryption/decryption operations across ECB, CBC, CFB64, and OFB64 modes.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `RC5_32_BLOCK` | `8` | Block size in bytes |
| `RC5_32_KEY_LENGTH` | `16` | Default key length (max 255) |
| `RC5_8_ROUNDS` | `8` | 8-round variant |
| `RC5_12_ROUNDS` | `12` | 12-round variant |
| `RC5_16_ROUNDS` | `16` | 16-round variant |
| `RC5_ENCRYPT` | `1` | Encrypt direction flag |
| `RC5_DECRYPT` | `0` | Decrypt direction flag |

### Key Structure

```c
typedef struct rc5_key_st {
    int rounds;                              /* Number of rounds */
    RC5_32_INT data[2 * (RC5_16_ROUNDS + 1)]; /* Expanded key schedule */
} RC5_32_KEY;
```

### Deprecated Functions (Removed in OpenSSL 3.0)

- `RC5_32_set_key` — Initializes key schedule from raw bytes and round count
- `RC5_32_ecb_encrypt` — Single-block ECB encrypt/decrypt
- `RC5_32_encrypt` / `RC5_32_decrypt` — Raw block operations on `unsigned long` data
- `RC5_32_cbc_encrypt` — CBC mode with IV
- `RC5_32_cfb64_encrypt` — CFB64 streaming mode
- `RC5_32_ofb64_encrypt` — OFB64 streaming mode

## Usage Example

> **⚠️ Deprecated:** All RC5 APIs are marked `OSSL_DEPRECATEDIN_3_0`. Use the EVP API instead.

```c
#include <openssl/rc5.h>

RC5_32_KEY key;
unsigned char raw_key[RC5_32_KEY_LENGTH] = { /* 16 bytes */ };
unsigned char iv[RC5_32_BLOCK] = { 0 };
unsigned char plaintext[64] = "Hello, RC5!";
unsigned char ciphertext[64];

/* Initialize key with 12 rounds */
RC5_32_set_key(&key, RC5_32_KEY_LENGTH, raw_key, RC5_12_ROUNDS);

/* Encrypt using CBC mode */
RC5_32_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                   &key, iv, RC5_ENCRYPT);
```

> **Note:** `OPENSSL_NO_RC5` may be defined at build time to disable RC5 entirely. Guard usage with `#ifndef OPENSSL_NO_RC5`.
