## Usage Example

Reason codes are used indirectly via OpenSSL's error queue. Check them after a failed ASN.1 operation:

```c
#include <openssl/asn1.h>
#include <openssl/asn1err.h>
#include <openssl/err.h>

ASN1_INTEGER *val = d2i_ASN1_INTEGER(NULL, &der_buf, der_len);
if (val == NULL) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == ASN1_R_DECODE_ERROR) {
        fprintf(stderr, "ASN.1 decode error: malformed DER input\n");
    } else if (reason == ASN1_R_DEPTH_EXCEEDED) {
        fprintf(stderr, "ASN.1 structure too deeply nested\n");
    } else {
        fprintf(stderr, "ASN.1 error %d: %s\n", reason, ERR_reason_error_string(err));
    }
}
```
