## Usage Example

```c
#include <openssl/x509err.h>
#include <openssl/err.h>

void check_x509_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    switch (reason) {
        case X509_R_CERTIFICATE_VERIFICATION_FAILED:
            fprintf(stderr, "Certificate verification failed\n");
            break;
        case X509_R_UNSUPPORTED_ALGORITHM:
            fprintf(stderr, "Unsupported signing algorithm\n");
            break;
        case X509_R_NO_CERTIFICATE_FOUND:
            fprintf(stderr, "No certificate found in store\n");
            break;
        default:
            fprintf(stderr, "Unknown X509 error: %d\n", reason);
    }
}
```

These codes are typically retrieved via `ERR_GET_REASON()` after an OpenSSL X.509 API call returns an error, and are not used directly by application code.
