OpenSSL header defining the SEED block cipher interface — a 128-bit symmetric encryption algorithm standardized by KISA (Korea Information Security Agency).

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `SEED_BLOCK_SIZE` | `16` | Block size in bytes (128-bit) |
| `SEED_KEY_LENGTH` | `16` | Key length in bytes (128-bit) |

### Types

- **`SEED_KEY_SCHEDULE`** — Key schedule structure holding 32 expanded key words (`unsigned int` or `unsigned long` depending on `SEED_LONG` platform flag)

### Functions (Deprecated in OpenSSL 3.0)

| Function | Description |
|---|---|
| `SEED_set_key` | Expands a 16-byte raw key into a `SEED_KEY_SCHEDULE` |
| `SEED_encrypt` | Encrypts a single 16-byte block (ECB, raw) |
| `SEED_decrypt` | Decrypts a single 16-byte block (ECB, raw) |
| `SEED_ecb_encrypt` | ECB mode encrypt/decrypt |
| `SEED_cbc_encrypt` | CBC mode encrypt/decrypt with IV |
| `SEED_cfb128_encrypt` | CFB-128 mode encrypt/decrypt with IV and offset |
| `SEED_ofb128_encrypt` | OFB-128 mode encrypt with IV and offset |

## Usage Example

```c
#include <openssl/seed.h>

/* NOTE: All SEED functions are deprecated in OpenSSL 3.0.
 * Prefer EVP_* APIs for new code. */

unsigned char key[SEED_KEY_LENGTH]   = { /* 16-byte key */ };
unsigned char iv[SEED_BLOCK_SIZE]    = { /* 16-byte IV  */ };
unsigned char plaintext[64]          = { /* input data  */ };
unsigned char ciphertext[64];

SEED_KEY_SCHEDULE ks;
SEED_set_key(key, &ks);

/* CBC encrypt */
SEED_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                 &ks, iv, /*enc=*/1);
```

> **Note:** All functions are marked `OSSL_DEPRECATEDIN_3_0`. Use the `EVP_*` cipher API (e.g., `EVP_aes_128_cbc`) for new code. The entire header is conditionally compiled out when `OPENSSL_NO_SEED` is defined.
