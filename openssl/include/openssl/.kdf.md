OpenSSL Key Derivation Function (KDF) public API header, providing both the modern `EVP_KDF`-based interface and the legacy `EVP_PKEY`-based interface for cryptographic key derivation algorithms including HKDF, TLS 1.x PRF, SSHKDF, and scrypt.

## Key Components

### Modern EVP_KDF API
| Function | Description |
|---|---|
| `EVP_KDF_fetch` | Load a KDF algorithm by name from a provider |
| `EVP_KDF_CTX_new` / `EVP_KDF_CTX_free` | Allocate/free a KDF context |
| `EVP_KDF_derive` | Perform key derivation into an output buffer |
| `EVP_KDF_CTX_set_params` | Configure algorithm parameters via `OSSL_PARAM` |
| `EVP_KDF_CTX_get_kdf_size` | Query the output key size |
| `EVP_KDF_do_all_provided` | Iterate over all available KDF implementations |

### HKDF Mode Constants
| Constant | Value | Meaning |
|---|---|---|
| `EVP_KDF_HKDF_MODE_EXTRACT_AND_EXPAND` | `0` | Full HKDF (default) |
| `EVP_KDF_HKDF_MODE_EXTRACT_ONLY` | `1` | Extract phase only |
| `EVP_KDF_HKDF_MODE_EXPAND_ONLY` | `2` | Expand phase only |

### SSHKDF Key Type Constants
Six constants (`65`–`70`) define SSH key derivation direction and purpose (IV, encryption key, integrity key; client-to-server or server-to-client).

### Legacy EVP_PKEY KDF API
Convenience wrappers for TLS 1.x PRF, HKDF, and scrypt using `EVP_PKEY_CTX`, retained for backward compatibility with pre-3.0 OpenSSL code.

## Usage Example

```c
/* Derive a key using HKDF (modern API) */
EVP_KDF *kdf = EVP_KDF_fetch(NULL, "HKDF", NULL);
EVP_KDF_CTX *ctx = EVP_KDF_CTX_new(kdf);
EVP_KDF_free(kdf);

OSSL_PARAM params[] = {
    OSSL_PARAM_construct_utf8_string("digest", "SHA256", 0),
    OSSL_PARAM_construct_octet_string("key", ikm, ikm_len),
    OSSL_PARAM_construct_octet_string("salt", salt, salt_len),
    OSSL_PARAM_construct_octet_string("info", info, info_len),
    OSSL_PARAM_construct_end()
};

unsigned char out[32];
EVP_KDF_derive(ctx, out, sizeof(out), params);
EVP_KDF_CTX_free(ctx);
```
