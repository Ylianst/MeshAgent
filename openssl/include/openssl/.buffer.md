Dynamic memory buffer management interface from OpenSSL, providing a growable byte buffer abstraction (`BUF_MEM`) with optional secure memory allocation.

## Key Components

### Struct

| Name | Description |
|---|---|
| `buf_mem_st` (`BUF_MEM`) | Core buffer struct holding `data` pointer, current `length`, allocated `max` size, and `flags` |

### Flags

| Flag | Value | Description |
|---|---|---|
| `BUF_MEM_FLAG_SECURE` | `0x01` | Allocates buffer in OpenSSL secure heap (zeroed on free) |

### Functions

| Function | Description |
|---|---|
| `BUF_MEM_new()` | Allocates a new standard buffer |
| `BUF_MEM_new_ex(flags)` | Allocates a new buffer with flags (e.g., secure memory) |
| `BUF_MEM_free(a)` | Frees the buffer and its data |
| `BUF_MEM_grow(str, len)` | Grows buffer to at least `len` bytes; returns new size or 0 on failure |
| `BUF_MEM_grow_clean(str, len)` | Like `BUF_MEM_grow` but zeroes newly allocated memory |
| `BUF_reverse(out, in, siz)` | Reverses `siz` bytes from `in` into `out` |

### Deprecated Macros (pre-3.0 compatibility)

`BUF_strdup`, `BUF_strndup`, `BUF_memdup`, `BUF_strlcpy`, `BUF_strlcat`, `BUF_strnlen` — all map directly to their `OPENSSL_*` equivalents.

## Usage Example

```c
#include <openssl/buffer.h>

/* Standard buffer */
BUF_MEM *buf = BUF_MEM_new();
if (buf == NULL) handle_error();

/* Grow to hold 256 bytes */
if (BUF_MEM_grow(buf, 256) == 0) handle_error();

memcpy(buf->data, payload, 256);
buf->length = 256;

BUF_MEM_free(buf);

/* Secure buffer (zeroed on free) */
BUF_MEM *secure_buf = BUF_MEM_new_ex(BUF_MEM_FLAG_SECURE);
BUF_MEM_grow_clean(secure_buf, 128);
/* ... use secure_buf->data ... */
BUF_MEM_free(secure_buf);
```
