Auto-generated OpenSSL header defining numeric reason codes for ENGINE subsystem errors, guarded by `OPENSSL_NO_ENGINE`.

## Key Components

**Error Reason Code Macros** — Integer constants (100–151) mapped to specific ENGINE failure conditions:

| Macro | Code | Meaning |
|---|---|---|
| `ENGINE_R_ALREADY_LOADED` | 100 | Engine already loaded |
| `ENGINE_R_DSO_FAILURE` | 104 | Dynamic shared object error |
| `ENGINE_R_INIT_FAILED` | 109 | Engine initialization failed |
| `ENGINE_R_FAILED_LOADING_PRIVATE_KEY` | 128 | Private key load error |
| `ENGINE_R_FAILED_LOADING_PUBLIC_KEY` | 129 | Public key load error |
| `ENGINE_R_NOT_INITIALISED` | 117 | Engine not yet initialized |
| `ENGINE_R_UNIMPLEMENTED_CIPHER` | 146 | Cipher not implemented |
| `ENGINE_R_VERSION_INCOMPATIBILITY` | 145 | Version mismatch |

**Compile Guards:**
- `OPENSSL_NO_ENGINE` — entire reason code block is omitted when ENGINE support is disabled
- `#pragma once` + traditional include guard (`OPENSSL_ENGINEERR_H`)

## Usage Example

```c
#include <openssl/engineerr.h>
#include <openssl/err.h>

void check_engine_error(void) {
    unsigned long err = ERR_get_error();

    if (ERR_GET_REASON(err) == ENGINE_R_NOT_INITIALISED) {
        fprintf(stderr, "Engine was not initialized before use.\n");
    } else if (ERR_GET_REASON(err) == ENGINE_R_DSO_FAILURE) {
        fprintf(stderr, "Failed to load dynamic engine library.\n");
    }
}
```
