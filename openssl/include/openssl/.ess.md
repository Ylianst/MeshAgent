OpenSSL Enhanced Security Services (ESS) header providing ASN.1 structures and functions for RFC 2634/5035 signing certificate attributes used in CMS/S-MIME signatures.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `ESS_ISSUER_SERIAL` | Issuer and serial number pair identifying a certificate |
| `ESS_CERT_ID` | Certificate identifier (SHA-1 hash + optional issuer/serial) for ESS v1 |
| `ESS_SIGNING_CERT` | RFC 2634 signing certificate attribute containing `ESS_CERT_ID` list |
| `ESS_CERT_ID_V2` | Certificate identifier with configurable hash algorithm for ESS v2 |
| `ESS_SIGNING_CERT_V2` | RFC 5035 signing certificate v2 attribute containing `ESS_CERT_ID_V2` list |

### Stack Macros

Type-safe `STACK_OF` wrappers are defined for both `ESS_CERT_ID` and `ESS_CERT_ID_V2`, exposing standard operations: `push`, `pop`, `shift`, `insert`, `find`, `dup`, `deep_copy`, `sort`, `free`, and `pop_free`.

### ASN.1 Functions

Each structure gets allocation (`new`/`free`), DER encode/decode, and duplication functions via `DECLARE_ASN1_*` macros.

### High-Level API

| Function | Description |
|----------|-------------|
| `OSSL_ESS_signing_cert_new_init` | Creates an ESS v1 `ESS_SIGNING_CERT` from a signing cert and optional chain |
| `OSSL_ESS_signing_cert_v2_new_init` | Creates an ESS v2 `ESS_SIGNING_CERT_V2` with a specified hash algorithm |
| `OSSL_ESS_check_signing_certs` | Validates signing cert attributes against a provided certificate chain |

## Usage Example

```c
#include <openssl/ess.h>
#include <openssl/x509.h>

/* Build an ESS v2 signing cert attribute using SHA-256 */
ESS_SIGNING_CERT_V2 *attr = OSSL_ESS_signing_cert_v2_new_init(
    EVP_sha256(),
    signcert,   /* signing X509 * */
    certs,      /* STACK_OF(X509) * chain, may be NULL */
    1           /* include issuer/serial */
);

/* Verify signing certs in a CMS chain */
int ok = OSSL_ESS_check_signing_certs(NULL, attr, chain, 1);

ESS_SIGNING_CERT_V2_free(attr);
```
