Public API header for OpenSSL's generic object decoder framework, providing types and functions to fetch, configure, and drive decoding of cryptographic objects (keys, certificates, etc.) from BIO, FILE, or raw data sources.

## Key Components

### Core Decoder Object (`OSSL_DECODER`)
| Function | Description |
|---|---|
| `OSSL_DECODER_fetch()` | Load a named decoder from a provider |
| `OSSL_DECODER_up_ref()` / `OSSL_DECODER_free()` | Reference counting and cleanup |
| `OSSL_DECODER_get0_name()` / `get0_properties()` / `get0_description()` | Introspection accessors |
| `OSSL_DECODER_is_a()` | Check decoder type by name |
| `OSSL_DECODER_do_all_provided()` | Iterate all available decoders |

### Decoder Context (`OSSL_DECODER_CTX`)
| Function | Description |
|---|---|
| `OSSL_DECODER_CTX_new()` / `_free()` | Context lifecycle |
| `OSSL_DECODER_CTX_set_input_type()` / `_set_input_structure()` | Configure expected input format |
| `OSSL_DECODER_CTX_set_selection()` | Restrict decoded key component type |
| `OSSL_DECODER_CTX_add_decoder()` / `_add_extra()` | Populate decoder chain |
| `OSSL_DECODER_CTX_set_passphrase*()` | Passphrase callbacks for encrypted inputs |
| `OSSL_DECODER_CTX_set_construct()` / `_set_cleanup()` | Output construction callbacks |

### Decode Operations
- `OSSL_DECODER_from_bio()` — decode from a `BIO` stream
- `OSSL_DECODER_from_fp()` — decode from a `FILE*` (when stdio is available)
- `OSSL_DECODER_from_data()` — decode from a raw byte buffer

### High-Level Helper
- `OSSL_DECODER_CTX_new_for_pkey()` — convenience constructor that sets up a full decode pipeline targeting an `EVP_PKEY`

### Callbacks
```c
typedef int  OSSL_DECODER_CONSTRUCT(OSSL_DECODER_INSTANCE *inst,
                                    const OSSL_PARAM *params,
                                    void *construct_data);
typedef void OSSL_DECODER_CLEANUP(void *construct_data);
```

## Usage Example

```c
/* Decode a PEM private key from a BIO */
EVP_PKEY *pkey = NULL;
OSSL_DECODER_CTX *ctx = OSSL_DECODER_CTX_new_for_pkey(
    &pkey,
    "PEM",          /* input_type   */
    NULL,           /* input_struct */
    "RSA",          /* keytype      */
    OSSL_KEYMGMT_SELECT_PRIVATE_KEY,
    NULL, NULL      /* default lib context, no property query */
);

if (ctx != NULL) {
    OSSL_DECODER_CTX_set_passphrase(ctx,
        (const unsigned char *)"secret", 6);

    if (OSSL_DECODER_from_bio(ctx, bio))
        /* pkey is now populated */;

    OSSL_DECODER_CTX_free(ctx);
}
```
