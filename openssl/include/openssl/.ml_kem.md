Public API constants for ML-KEM (Module-Lattice Key Encapsulation Mechanism), a NIST post-quantum cryptography standard (FIPS 203). Defines size parameters for the three ML-KEM security levels.

## Key Components

### Shared Secret Size

| Constant | Value | Description |
|---|---|---|
| `OSSL_ML_KEM_SHARED_SECRET_BYTES` | `32` | Output shared secret size (all variants) |

### ML-KEM-512 (128-bit security)

| Constant | Value |
|---|---|
| `OSSL_ML_KEM_512_BITS` | `512` |
| `OSSL_ML_KEM_512_SECURITY_BITS` | `128` |
| `OSSL_ML_KEM_512_CIPHERTEXT_BYTES` | `768` |
| `OSSL_ML_KEM_512_PUBLIC_KEY_BYTES` | `800` |

### ML-KEM-768 (192-bit security)

| Constant | Value |
|---|---|
| `OSSL_ML_KEM_768_BITS` | `768` |
| `OSSL_ML_KEM_768_SECURITY_BITS` | `192` |
| `OSSL_ML_KEM_768_CIPHERTEXT_BYTES` | `1088` |
| `OSSL_ML_KEM_768_PUBLIC_KEY_BYTES` | `1184` |

### ML-KEM-1024 (256-bit security)

| Constant | Value |
|---|---|
| `OSSL_ML_KEM_1024_BITS` | `1024` |
| `OSSL_ML_KEM_1024_SECURITY_BITS` | `256` |
| `OSSL_ML_KEM_1024_CIPHERTEXT_BYTES` | `1568` |
| `OSSL_ML_KEM_1024_PUBLIC_KEY_BYTES` | `1568` |

## Usage Example

```c
#include <openssl/ml_kem.h>

/* Allocate buffers for ML-KEM-768 key exchange */
uint8_t ciphertext[OSSL_ML_KEM_768_CIPHERTEXT_BYTES];
uint8_t public_key[OSSL_ML_KEM_768_PUBLIC_KEY_BYTES];
uint8_t shared_secret[OSSL_ML_KEM_SHARED_SECRET_BYTES];

/* Select variant based on required security level */
size_t ct_len;
if (required_security_bits <= OSSL_ML_KEM_512_SECURITY_BITS)
    ct_len = OSSL_ML_KEM_512_CIPHERTEXT_BYTES;
else if (required_security_bits <= OSSL_ML_KEM_768_SECURITY_BITS)
    ct_len = OSSL_ML_KEM_768_CIPHERTEXT_BYTES;
else
    ct_len = OSSL_ML_KEM_1024_CIPHERTEXT_BYTES;
```

> **Note:** All three variants produce an identical 32-byte shared secret (`OSSL_ML_KEM_SHARED_SECRET_BYTES`), differing only in key and ciphertext sizes versus security strength trade-offs.
