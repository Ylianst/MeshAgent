OpenSSL legacy RC2 symmetric cipher header, providing the low-level RC2 block cipher API. All declarations in this file are **deprecated as of OpenSSL 3.0** and should not be used in new code.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `RC2_BLOCK` | `8` | Block size in bytes |
| `RC2_KEY_LENGTH` | `16` | Default key length in bytes |
| `RC2_ENCRYPT` | `1` | Encrypt direction flag |
| `RC2_DECRYPT` | `0` | Decrypt direction flag |

### Types (Deprecated)

- **`RC2_INT`** — Unsigned int used internally for key data storage
- **`RC2_KEY`** — Key schedule struct holding 64 `RC2_INT` words, populated by `RC2_set_key()`

### Functions (All Deprecated in 3.0)

| Function | Description |
|---|---|
| `RC2_set_key()` | Expands raw key bytes into an `RC2_KEY` schedule |
| `RC2_ecb_encrypt()` | Encrypts/decrypts a single ECB block |
| `RC2_encrypt()` / `RC2_decrypt()` | Raw block encrypt/decrypt on `unsigned long` data |
| `RC2_cbc_encrypt()` | CBC mode encrypt/decrypt over a buffer |
| `RC2_cfb64_encrypt()` | CFB-64 mode streaming encrypt/decrypt |
| `RC2_ofb64_encrypt()` | OFB-64 mode streaming encrypt |

## Usage Example

```c
/* Legacy RC2 CBC encryption — NOT recommended for new code */
#include <openssl/rc2.h>

RC2_KEY key;
unsigned char raw_key[RC2_KEY_LENGTH] = { /* 16 key bytes */ };
unsigned char iv[RC2_BLOCK]           = { /* 8 IV bytes  */ };
unsigned char plaintext[64]           = { /* input data  */ };
unsigned char ciphertext[64];

/* Expand key schedule */
RC2_set_key(&key, RC2_KEY_LENGTH, raw_key, 128);

/* Encrypt in CBC mode */
RC2_cbc_encrypt(plaintext, ciphertext, sizeof(plaintext),
                &key, iv, RC2_ENCRYPT);
```

> **Warning:** RC2 is a legacy cipher deprecated in OpenSSL 3.0 and disabled when `OPENSSL_NO_RC2` is defined. Use AES via the EVP API (e.g., `EVP_aes_128_cbc()`) in all new implementations.
