Compatibility shim header that redirects legacy `#include <openssl/ossl_typ.h>` includes to the modern `<openssl/types.h>` header.

## Key Components

- **Single include directive** — unconditionally includes `<openssl/types.h>`, exposing all OpenSSL type definitions to callers.

## Usage Example

```c
/* Legacy code — still works via this compatibility header */
#include <openssl/ossl_typ.h>

/* Modern equivalent — preferred in new code */
#include <openssl/types.h>
```

## Notes

- No new symbols are defined here; all types come from `<openssl/types.h>`.
- Existing code referencing `ossl_typ.h` requires no changes.
- New code should include `<openssl/types.h>` directly.
