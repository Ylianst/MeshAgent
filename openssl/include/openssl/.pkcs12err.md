## Usage Example

Inspect the error queue after a failed PKCS12 operation to retrieve the reason code:

```c
#include <openssl/pkcs12.h>
#include <openssl/pkcs12err.h>
#include <openssl/err.h>

PKCS12 *p12 = d2i_PKCS12_fp(fp, NULL);
if (!p12) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == PKCS12_R_DECODE_ERROR) {
        fprintf(stderr, "Failed to decode PKCS12 structure\n");
    } else if (reason == PKCS12_R_MAC_VERIFY_FAILURE) {
        fprintf(stderr, "MAC verification failed - wrong password?\n");
    }
}
```
