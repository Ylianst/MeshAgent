OpenSSL OSSL\_STORE API header defining the interface for opening, reading, and closing channels to cryptographic resource stores (keys, certificates, CRLs) via URI-based loaders.

## Key Components

### Types & Structures

- **`OSSL_STORE_CTX`** — Opaque context representing an open store channel
- **`OSSL_STORE_INFO`** — Container for a single loaded data item (key, cert, CRL, etc.)
- **`OSSL_STORE_SEARCH`** — Search criterion for filtering store contents
- **`OSSL_STORE_LOADER`** — Provider-backed loader for a URI scheme
- **`OSSL_STORE_post_process_info_fn`** — Callback to transform or drop loaded items

### Store Lifecycle Functions

| Function | Description |
|---|---|
| `OSSL_STORE_open()` | Open a store channel by URI |
| `OSSL_STORE_open_ex()` | Open with explicit `OSSL_LIB_CTX` and properties |
| `OSSL_STORE_attach()` | Attach to an existing `BIO` instead of a URI |
| `OSSL_STORE_load()` | Read the next data item from the channel |
| `OSSL_STORE_eof()` | Check if all items have been read |
| `OSSL_STORE_error()` | Check if an error occurred |
| `OSSL_STORE_close()` | Close the channel and free the context |
| `OSSL_STORE_delete()` | Delete a store object by URI |

### `OSSL_STORE_INFO` Types

| Constant | Value | Data Type |
|---|---|---|
| `OSSL_STORE_INFO_NAME` | 1 | `char *` |
| `OSSL_STORE_INFO_PARAMS` | 2 | `EVP_PKEY *` |
| `OSSL_STORE_INFO_PUBKEY` | 3 | `EVP_PKEY *` |
| `OSSL_STORE_INFO_PKEY` | 4 | `EVP_PKEY *` |
| `OSSL_STORE_INFO_CERT` | 5 | `X509 *` |
| `OSSL_STORE_INFO_CRL` | 6 | `X509_CRL *` |

### Search Types

- `OSSL_STORE_SEARCH_BY_NAME` — Match by subject/issuer name
- `OSSL_STORE_SEARCH_BY_ISSUER_SERIAL` — Match by issuer and serial
- `OSSL_STORE_SEARCH_BY_KEY_FINGERPRINT` — Match by digest fingerprint
- `OSSL_STORE_SEARCH_BY_ALIAS` — Match by alias string

## Usage Example

```c
#include <openssl/store.h>

/* Open a store, iterate loaded items, close */
OSSL_STORE_CTX *ctx = OSSL_STORE_open(
    "file:/etc/ssl/certs/ca-bundle.crt",
    NULL, NULL, NULL, NULL
);

while (!OSSL_STORE_eof(ctx)) {
    OSSL_STORE_INFO *info = OSSL_STORE_load(ctx);
    if (info == NULL) continue;

    if (OSSL_STORE_INFO_get_type(info) == OSSL_STORE_INFO_CERT) {
        X509 *cert = OSSL_STORE_INFO_get0_CERT(info);
        /* use cert ... */
    }
    OSSL_STORE_INFO_free(info);
}

OSSL_STORE_close(ctx);
```

```c
/* Search for a certificate by name before loading */
X509_NAME *name = /* build name */;
OSSL_STORE_SEARCH *search = OSSL_STORE_SEARCH_by_name(name);
OSSL_STORE_find(ctx, search);   /* must be called before first load */
OSSL_STORE_expect(ctx, OSSL_STORE_INFO_CERT);

OSSL_STORE_INFO *info = OSSL_STORE_load(ctx);
OSSL_STORE_SEARCH_free(search);
```

> **Note:** `OSSL_STORE_ctrl()` and `OSSL_STORE_vctrl()` are deprecated as of OpenSSL 3.0. Use `OSSL_PARAM`-based APIs via `OSSL_STORE_open_ex()` instead.
