Compatibility header stub for the deprecated SSLv2 protocol, retained in OpenSSL 3.x solely to avoid breaking legacy code that includes it.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `SSL2_VERSION` | `0x0002` | Protocol version identifier for SSL 2.0 |
| `SSL2_MT_CLIENT_HELLO` | `1` | Message type constant for SSLv2 Client Hello handshake message |
| `HEADER_SSL2_H` | *(defined)* | Legacy include guard, available only when `OPENSSL_NO_DEPRECATED_3_0` is **not** set |

## Usage Example

```c
#include <openssl/ssl2.h>

/* Check negotiated protocol version against the SSLv2 identifier */
if (version == SSL2_VERSION) {
    /* SSLv2 is broken and must not be used in new code */
    fprintf(stderr, "SSLv2 is not supported\n");
}
```

> **Warning:** SSLv2 is cryptographically broken. These constants exist only for backward-compatibility checks (e.g., detecting a peer offering SSLv2). Do not negotiate or implement SSLv2 in any new or existing code.

## Notes

- Full SSLv2 support was removed in OpenSSL 1.1.0; this header is a minimal stub.
- The `OPENSSL_NO_DEPRECATED_3_0` macro controls whether the legacy `HEADER_SSL2_H` guard is exposed — suppress it by compiling with `-DOPENSSL_NO_DEPRECATED_3_0` to catch deprecated usage early.
- The `#pragma once` guard works alongside the traditional `#ifndef` guard for broader compiler compatibility.
