Provides the ECDSA (Elliptic Curve Digital Signature Algorithm) interface by including the OpenSSL EC library header, making all EC and ECDSA functionality available to consumers of this header.

## Key Components

- **`openssl/ec.h`** — Transitively exposes the full OpenSSL EC API, including:
  - `ECDSA_sign` / `ECDSA_verify` — Sign and verify data using ECDSA
  - `ECDSA_do_sign` / `ECDSA_do_verify` — Low-level sign/verify returning `ECDSA_SIG` structures
  - `ECDSA_SIG` — Opaque struct representing an ECDSA signature (r, s components)
  - `EC_KEY` — Key object used for both signing and verification

## Usage Example

```c
#include "ecdsa.h"  /* pulls in openssl/ec.h */

/* Sign a 32-byte digest with an EC private key */
unsigned int sig_len;
unsigned char sig[ECDSA_size(ec_key)];

if (ECDSA_sign(0, digest, 32, sig, &sig_len, ec_key) != 1) {
    /* handle error */
}

/* Verify the signature with the corresponding public key */
int ok = ECDSA_verify(0, digest, 32, sig, sig_len, ec_key);
if (ok != 1) {
    /* verification failed */
}
```
