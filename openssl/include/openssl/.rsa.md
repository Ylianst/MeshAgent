OpenSSL RSA public key cryptography header defining the RSA algorithm interface, padding modes, PSS/OAEP parameters, and EVP_PKEY context controls for RSA operations.

## Key Components

### Constants & Flags

| Constant | Value | Description |
|---|---|---|
| `OPENSSL_RSA_MAX_MODULUS_BITS` | 16384 | Maximum RSA modulus size |
| `RSA_F4` | 0x10001 | Common public exponent (65537) |
| `RSA_PKCS1_PADDING` | 1 | PKCS#1 v1.5 padding |
| `RSA_PKCS1_OAEP_PADDING` | 4 | OAEP padding (recommended) |
| `RSA_PKCS1_PSS_PADDING` | 6 | PSS padding (signatures) |
| `RSA_PSS_SALTLEN_DIGEST` | -1 | Salt length matches digest |
| `RSA_PSS_SALTLEN_AUTO` | -2 | Auto-detect salt on verify |

### RSA Type Flags

```text
RSA_FLAG_TYPE_RSA       0x0000  - Standard RSA
RSA_FLAG_TYPE_RSASSAPSS 0x1000  - RSA-PSS signature scheme
RSA_FLAG_TYPE_RSAESOAEP 0x2000  - RSA-OAEP encryption scheme
```

### EVP_PKEY_CTX Functions (Current API)

- **Padding:** `EVP_PKEY_CTX_set_rsa_padding()`, `EVP_PKEY_CTX_get_rsa_padding()`
- **PSS:** `EVP_PKEY_CTX_set_rsa_pss_saltlen()`, `EVP_PKEY_CTX_set_rsa_pss_keygen_md()`
- **OAEP:** `EVP_PKEY_CTX_set_rsa_oaep_md()`, `EVP_PKEY_CTX_set0_rsa_oaep_label()`
- **MGF1:** `EVP_PKEY_CTX_set_rsa_mgf1_md()`, `EVP_PKEY_CTX_get_rsa_mgf1_md()`
- **Key generation:** `EVP_PKEY_CTX_set_rsa_keygen_bits()`, `EVP_PKEY_CTX_set_rsa_keygen_primes()`
- **Convenience macro:** `EVP_RSA_gen(bits)` — generates an RSA `EVP_PKEY` directly

### Deprecated API (pre-3.0)

Low-level `RSA_*` functions (`RSA_new`, `RSA_generate_key_ex`, `RSA_set0_key`, etc.) are marked `OSSL_DEPRECATEDIN_3_0` and should be replaced with EVP-layer equivalents.

## Usage Example

```c
#include <openssl/rsa.h>
#include <openssl/evp.h>

/* Generate a 2048-bit RSA key (OpenSSL 3.x preferred API) */
EVP_PKEY *pkey = EVP_RSA_gen(2048);

/* Configure OAEP padding on an encryption context */
EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new(pkey, NULL);
EVP_PKEY_encrypt_init(ctx);
EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING);
EVP_PKEY_CTX_set_rsa_oaep_md(ctx, EVP_sha256());

/* Configure PSS for signing */
EVP_PKEY_CTX *sctx = EVP_PKEY_CTX_new(pkey, NULL);
EVP_PKEY_sign_init(sctx);
EVP_PKEY_CTX_set_rsa_padding(sctx, RSA_PKCS1_PSS_PADDING);
EVP_PKEY_CTX_set_rsa_pss_saltlen(sctx, RSA_PSS_SALTLEN_DIGEST);

EVP_PKEY_CTX_free(ctx);
EVP_PKEY_CTX_free(sctx);
EVP_PKEY_free(pkey);
```

> **Note:** Direct `RSA_*` struct manipulation is deprecated in OpenSSL 3.0. Use the `EVP_PKEY` / `EVP_PKEY_CTX` API for all new code. FIPS-compliant builds require a minimum modulus of 2048 bits (`OPENSSL_RSA_FIPS_MIN_MODULUS_BITS`).
