## Key Components

### Lifecycle Functions
- `UI_new()` / `UI_new_method()` — Create a UI instance (default or with a custom method)
- `UI_free()` — Destroy a UI instance

### String & Prompt Management
- `UI_add_input_string()` / `UI_dup_input_string()` — Add/copy an input prompt
- `UI_add_verify_string()` / `UI_dup_verify_string()` — Add/copy a verification prompt
- `UI_add_input_boolean()` / `UI_dup_input_boolean()` — Add/copy a yes/no prompt
- `UI_add_info_string()` / `UI_add_error_string()` — Add informational or error text

### Input Flags
- `UI_INPUT_FLAG_ECHO` (`0x01`) — Echo input to screen
- `UI_INPUT_FLAG_DEFAULT_PWD` (`0x02`) — Use a default password from user data
- `UI_INPUT_FLAG_USER_BASE` (`16`) — Base bit for user-defined flags

### Processing & Control
- `UI_process()` — Execute the full UI session (open → write → flush → read → close)
- `UI_ctrl()` — Send control commands (`UI_CTRL_PRINT_ERRORS`, `UI_CTRL_IS_REDOABLE`)
- `UI_construct_prompt()` — Build a standard prompt string (heap-allocated, free with `OPENSSL_free()`)

### Method Management
- `UI_OpenSSL()` — Built-in console method
- `UI_null()` — No-op placeholder method
- `UI_set_default_method()` / `UI_get_default_method()` — Global method configuration
- `UI_set_method()` / `UI_get_method()` — Per-instance method override

### User Data & Ex-Data
- `UI_add_user_data()` / `UI_dup_user_data()` / `UI_get0_user_data()` — Attach arbitrary caller data
- `UI_set_ex_data()` / `UI_get_ex_data()` — OpenSSL extensible data slots

#include <openssl/ui.h>

int read_password(char *buf, int buf_size) {
    UI *ui = UI_new();
    if (!ui) return -1;

    /* Add a password prompt; result stored in buf */
    int idx = UI_add_input_string(ui, "Enter pass phrase: ",
                                  0,        /* no echo flag */
                                  buf, 4, buf_size - 1);
    if (idx < 0) { UI_free(ui); return -1; }

    /* Run the UI session */
    int rc = UI_process(ui);
    if (rc == 0) {
        /* Retrieve result by index */
        const char *result = UI_get0_result(ui, idx);
        /* use result... */
    }

    UI_free(ui);
    return rc; /* 0 = success, -1 = error, -2 = cancelled */
}

/* Build a standard prompt: "Enter pass phrase for foo.key:" */
char *prompt = UI_construct_prompt(NULL, "pass phrase", "foo.key");
/* ... use prompt ... */
