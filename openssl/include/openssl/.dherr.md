## Usage Example

These codes are consumed via OpenSSL's error-reporting API — never set directly by application code:

```c
#include <openssl/dh.h>
#include <openssl/err.h>
#include <openssl/dherr.h>

void check_dh_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    if (reason == DH_R_NO_PRIVATE_VALUE) {
        fprintf(stderr, "DH private key not set\n");
    } else if (reason == DH_R_MODULUS_TOO_LARGE) {
        fprintf(stderr, "DH modulus exceeds size limit\n");
    }
}
```
