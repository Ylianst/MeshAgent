OpenSSL header defining the Whirlpool cryptographic hash function interface (512-bit digest), including the context structure and low-level API — all marked deprecated as of OpenSSL 3.0.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `WHIRLPOOL_DIGEST_LENGTH` | `64` (512/8) | Output digest size in bytes |
| `WHIRLPOOL_BBLOCK` | `512` | Block size in bits |
| `WHIRLPOOL_COUNTER` | `32` (256/8) | Bit-length counter size in bytes |

### `WHIRLPOOL_CTX` Structure

Internal state container for incremental hashing (deprecated in OpenSSL 3.0):

- `H` — union holding the 512-bit hash state, aligned to 64 bits via `double`
- `data` — current input block buffer (64 bytes)
- `bitoff` — bit offset within the current block
- `bitlen` — accumulated message bit-length counter

### Deprecated API Functions

| Function | Description |
|---|---|
| `WHIRLPOOL_Init` | Initializes a `WHIRLPOOL_CTX` |
| `WHIRLPOOL_Update` | Feeds byte-aligned data into the hash |
| `WHIRLPOOL_BitUpdate` | Feeds arbitrary-bit-length data into the hash |
| `WHIRLPOOL_Final` | Finalizes and outputs the 64-byte digest |
| `WHIRLPOOL` | One-shot convenience: hash a buffer and return the digest |

## Usage Example

> ⚠️ All functions below are deprecated as of OpenSSL 3.0. Prefer the `EVP_Digest` API with `EVP_whirlpool()`.

```c
#include <openssl/whrlpool.h>
#include <stdio.h>

/* Legacy one-shot Whirlpool hash */
void whirlpool_example(const void *data, size_t len) {
    unsigned char md[WHIRLPOOL_DIGEST_LENGTH];

    WHIRLPOOL(data, len, md);

    for (int i = 0; i < WHIRLPOOL_DIGEST_LENGTH; i++)
        printf("%02x", md[i]);
    printf("\n");
}

/* Legacy incremental hashing */
void whirlpool_incremental(const void *chunk1, size_t len1,
                           const void *chunk2, size_t len2) {
    WHIRLPOOL_CTX ctx;
    unsigned char md[WHIRLPOOL_DIGEST_LENGTH];

    WHIRLPOOL_Init(&ctx);
    WHIRLPOOL_Update(&ctx, chunk1, len1);
    WHIRLPOOL_Update(&ctx, chunk2, len2);
    WHIRLPOOL_Final(md, &ctx);
}
```
