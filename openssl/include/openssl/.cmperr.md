## Key Components

**Guard & Conditional Compilation**

**Error Reason Code Macros (`CMP_R_*`)**

All constants are integer-valued `#define` macros in the range 100–205. Major categories include:

| Category | Example Codes |
|---|---|
| Message creation errors | `CMP_R_ERROR_CREATING_CERTREQ`, `CMP_R_ERROR_CREATING_GENM` |
| Validation / protection | `CMP_R_ERROR_VALIDATING_PROTECTION`, `CMP_R_ERROR_PROTECTING_MESSAGE` |
| Missing inputs | `CMP_R_MISSING_PRIVATE_KEY`, `CMP_R_MISSING_TRUST_STORE` |
| Protocol state errors | `CMP_R_UNEXPECTED_PKIBODY`, `CMP_R_TRANSACTIONID_UNMATCHED` |
| Key / algorithm issues | `CMP_R_UNSUPPORTED_ALGORITHM`, `CMP_R_WRONG_ALGORITHM_OID` |
| Central key generation | `CMP_R_FAILED_EXTRACTING_CENTRAL_GEN_KEY`, `CMP_R_MISSING_CENTRAL_GEN_KEY` |

## Usage Example

```c
#include <openssl/cmp.h>
#include <openssl/cmperr.h>
#include <openssl/err.h>

void check_cmp_error(void) {
    unsigned long err = ERR_get_error();
    int reason = ERR_GET_REASON(err);

    switch (reason) {
        case CMP_R_MISSING_PRIVATE_KEY:
            fprintf(stderr, "Private key required for CMP operation\n");
            break;
        case CMP_R_ERROR_VALIDATING_PROTECTION:
            fprintf(stderr, "CMP message protection validation failed\n");
            break;
        case CMP_R_TRANSACTIONID_UNMATCHED:
            fprintf(stderr, "CMP transaction ID mismatch\n");
            break;
        default:
            ERR_print_errors_fp(stderr);
    }
}
```
