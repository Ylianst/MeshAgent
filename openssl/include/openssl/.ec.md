OpenSSL Elliptic Curve (EC) public API header providing data types, constants, and function declarations for elliptic curve cryptography operations over GF(p) and GF(2^m) fields.

## Key Components

### Types & Enums
- **`EC_GROUP`** — represents an elliptic curve and its parameters
- **`EC_POINT`** — represents a point on an elliptic curve
- **`EC_METHOD`** *(deprecated in 3.0)* — backend implementation method
- **`point_conversion_form_t`** — encoding format: `COMPRESSED`, `UNCOMPRESSED`, or `HYBRID`
- **`ECPKPARAMETERS` / `ECPARAMETERS`** — ASN.1 parameter structures

### Constants
| Constant | Value | Purpose |
|---|---|---|
| `OPENSSL_EC_EXPLICIT_CURVE` | `0x000` | Explicit curve parameter encoding |
| `OPENSSL_EC_NAMED_CURVE` | `0x001` | Named curve OID encoding |
| `EVP_PKEY_ECDH_KDF_NONE` | `1` | No KDF for ECDH |
| `EVP_PKEY_ECDH_KDF_X9_63` | `2` | X9.63 KDF for ECDH |
| `OPENSSL_ECC_MAX_FIELD_BITS` | `661` | Maximum EC field size in bits |

### Key Function Groups

**`EVP_PKEY_CTX` ECDH Controls**
- `EVP_PKEY_CTX_set_ec_paramgen_curve_nid()` — set curve by NID
- `EVP_PKEY_CTX_set_ec_param_enc()` — set named vs. explicit encoding
- `EVP_PKEY_CTX_set_ecdh_cofactor_mode()` / `get` — cofactor DH mode
- `EVP_PKEY_CTX_set_ecdh_kdf_type/md/outlen/ukm()` — configure ECDH KDF

**`EC_GROUP` Management**
- `EC_GROUP_dup()` / `EC_GROUP_copy()` / `EC_GROUP_free()` — lifecycle
- `EC_GROUP_set_generator()` / `EC_GROUP_get0_generator()` — generator point
- `EC_GROUP_get_order()` / `EC_GROUP_get0_order()` / `EC_GROUP_order_bits()` — group order
- `EC_GROUP_get_cofactor()` / `EC_GROUP_get0_cofactor()` — cofactor access
- `EC_GROUP_set_curve()` / `EC_GROUP_get_curve_name()` — curve parameters
- `EC_GROUP_get0_field()` / `EC_GROUP_get_field_type()` — field access

## Usage Example

```c
#include <openssl/ec.h>
#include <openssl/evp.h>

/* Generate an EC key pair on P-256 and configure ECDH */
EVP_PKEY_CTX *ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_EC, NULL);
EVP_PKEY_keygen_init(ctx);

/* Set curve to NIST P-256 using named curve encoding */
EVP_PKEY_CTX_set_ec_paramgen_curve_nid(ctx, NID_X9_62_prime256v1);
EVP_PKEY_CTX_set_ec_param_enc(ctx, OPENSSL_EC_NAMED_CURVE);

EVP_PKEY *pkey = NULL;
EVP_PKEY_keygen(ctx, &pkey);

/* Inspect the underlying EC_GROUP */
const EC_GROUP *group = EC_GROUP_get0_group(EVP_PKEY_get0_EC_KEY(pkey));
int curve_nid = EC_GROUP_get_curve_name(group);          /* NID_X9_62_prime256v1 */
int order_bits = EC_GROUP_order_bits(group);              /* 256 */
point_conversion_form_t form =
    EC_GROUP_get_point_conversion_form(group);            /* POINT_CONVERSION_UNCOMPRESSED */

EVP_PKEY_free(pkey);
EVP_PKEY_CTX_free(ctx);
```

> **Note:** `EC_METHOD`-based APIs (`EC_GFp_*_method`, `EC_GROUP_new`, `EC_GROUP_clear_free`, etc.) are deprecated as of OpenSSL 3.0. Prefer the `EVP_PKEY` high-level API for new code.
