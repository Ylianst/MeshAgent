Provides a portable `struct timeval` definition across platforms by including the minimum necessary system headers.

## Key Components

- **Platform guard (`OPENSSL_SYS_WINDOWS`)** — On Windows, conditionally includes `<winsock2.h>` only if neither `<winsock.h>` nor `<winsock2.h>` has already been included (detected via `_WINSOCKAPI_`), preventing conflicts in applications that prefer the older Winsock header.
- **POSIX fallback** — On non-Windows systems, includes `<sys/time.h>` to provide `struct timeval`.

## Usage Example

```c
/* Include this header anywhere struct timeval is required,
   instead of conditionally including platform-specific headers. */
#include <openssl/e_ostime.h>

struct timeval tv;
tv.tv_sec  = 5;
tv.tv_usec = 0;
```

> **Note:** Avoid including `<winsock.h>` or `<winsock2.h>` directly alongside this header on Windows; the `_WINSOCKAPI_` guard ensures safe co-existence, but including both explicitly can still cause conflicts depending on include order.
