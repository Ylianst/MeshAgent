Compatibility header that re-exports legacy KDF (Key Derivation Function) error codes from OpenSSL by including `cryptoerr_legacy.h`.

## Key Components

- **Include guard** — `OPENSSL_KDFERR_H` with `#pragma once` for double-protection against multiple inclusion.
- **`openssl/cryptoerr_legacy.h`** — Transitional header that consolidates legacy error codes (including KDF-related ones) from pre-3.0 OpenSSL into a single location.

## Usage Example

```c
#include <openssl/kdferr.h>
#include <openssl/kdf.h>

void check_kdf_error(void) {
    /* Legacy KDF error codes (e.g., KDF_R_* macros) are available
       via the transitively included cryptoerr_legacy.h */
    unsigned long err = ERR_get_error();
    if (err != 0) {
        fprintf(stderr, "KDF error: %lu\n", err);
    }
}
```

## Notes

- Introduced in OpenSSL 3.x as a shim to preserve backward compatibility for code referencing the old standalone `kdferr.h`.
- No new symbols are defined here; all content comes from `cryptoerr_legacy.h`.
- Projects targeting OpenSSL 3.x+ should prefer the unified error API directly rather than relying on this legacy header.
