OpenSSL source tarball versions and checksums
=============================================

The version + sha256 pair to paste into the workflow_dispatch form of
.github/workflows/build-openssl-job.yml. The workflows derive the upstream
release tag from the version themselves (1.x is tagged OpenSSL_1_1_1w, 3.x
and later openssl-3.5.7), so these two fields are all a rebuild needs.

Latest release of every OpenSSL line, as of 2026-08-20. The sha256 values are
upstream's own openssl-<version>.tar.gz.sha256 release assets, not computed
locally; 1.1.1w matches the pin already in state.txt and build/env.sh, and the
3.5.7 and 3.0.21 tarballs were downloaded and re-hashed to confirm the
published asset matches the artifact. Support dates are from
openssl-library.org/policies/releasestrat/.

Refreshing this file
--------------------
Upstream publishes the checksum beside each tarball; re-read it rather than
computing one locally:

  v=3.5.7
  case $v in 1.*) tag="OpenSSL_$(echo $v | tr . _)";; *) tag="openssl-$v";; esac
  curl -sSL https://github.com/openssl/openssl/releases/download/$tag/openssl-$v.tar.gz.sha256

3.x prints "<sha256> *openssl-<version>.tar.gz"; 1.1.1w prints the bare hash.

  newest tags:   gh api repos/openssl/openssl/releases -q '.[].tag_name'
  support dates: https://openssl-library.org/policies/releasestrat/
