Header for a C library that decrypts and extracts authentication tokens from AES-256 encrypted files, with optional path configuration.

## Key Components

### `extract_token`

```text
char* extract_token(const char* secret, const char* token_path);
```

Decrypts a token file using a 32-byte AES-256 key and returns the plaintext token string.

| Parameter | Type | Description |
|---|---|---|
| `secret` | `const char*` | 32-byte key for AES-256 decryption |
| `token_path` | `const char*` | Path to encrypted token file; defaults to `/etc/openframe/token.txt` if `NULL` or empty |

**Returns:** Heap-allocated decrypted token string, or `NULL` on failure. **Caller is responsible for freeing the returned pointer.**

## Usage Example

```c
#include "token_extractor.h"
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    const char* secret = "my32byteAES256secretkeyXXXXXXXX";

    /* Use default path: /etc/openframe/token.txt */
    char* token = extract_token(secret, NULL);
    if (!token) {
        fprintf(stderr, "Failed to extract token\n");
        return 1;
    }

    printf("Token: %s\n", token);
    free(token); /* Caller must free */
    return 0;
}
```

> **Note:** This header is C++-compatible via the `extern "C"` guard, allowing use in mixed-language projects.

## Notes

- The `secret` parameter must be exactly 32 bytes to satisfy AES-256 key length requirements.
- Returns `NULL` on decryption failure, missing file, or invalid input — always check before use.
- Part of the [MeshAgent](https://github.com/flamingo-stack/meshagent) OpenFrame token management subsystem.
